# 心脏瓣膜病

> 心脏瓣膜病是由多种原因引起的心脏瓣膜狭窄或/和反流所致的心脏疾病，导致心腔压力负荷（狭窄）或容量负荷（反流）异常，最终出现[[心力衰竭]]和[[心律失常]]。

## 概述

| 项目 | 内容 |
|------|------|
| **常见病因** | 风湿性心脏病（发展中国家年轻人群最常见）、老年退行性钙化（发达国家及老年人最常见）、先天性畸形（二叶主动脉瓣）、黏液样变性、感染性心内膜炎 |
| **风湿热瓣膜受累比例** | 二尖瓣 70%，二尖瓣+主动脉瓣 20~30%，单纯主动脉瓣 2~5%，三尖瓣/肺动脉瓣少见 |
| **老年退行性病变** | 主动脉瓣病变最常见，其次为二尖瓣 |
| **联合瓣膜病** | 两个或以上瓣膜同时受累 |

## 四种瓣膜病核心鉴别

| 特征 | 二尖瓣狭窄（MS） | 二尖瓣关闭不全（MR） | 主动脉瓣狭窄（AS） | 主动脉瓣关闭不全（AR） |
|------|:---:|:---:|:---:|:---:|
| **主要病因** | 风湿热（>90%） | 风心病、二尖瓣脱垂、腱索断裂、感染性心内膜炎 | 退行性钙化（成人最常见）、二叶瓣畸形、风湿性 | 风心病、二叶瓣畸形、感染性心内膜炎、主动脉根部扩张 |
| **血流动力学** | 左心房压力↑→肺淤血→肺动脉高压→右心衰 | 左心室容量负荷↑→左心衰 | 左心室压力负荷↑→向心性肥厚→心肌缺血 | 左心室容量负荷↑→左室扩张→左心衰 |
| **主要症状** | 劳力性呼吸困难、咯血、咳嗽 | 疲乏、呼吸困难（晚期） | **三联征**：心绞痛、晕厥、呼吸困难 | 心悸、头颈部动脉搏动感、呼吸困难 |
| **听诊** | 心尖区舒张中晚期隆隆样杂音，S₁亢进、开瓣音 | 心尖区全收缩期吹风样杂音，向左腋部传导 | 胸骨右缘第2肋间粗糙喷射性收缩期杂音（递增-递减型），向颈部传导 | 主动脉瓣区/胸骨左缘高调递减型叹气样舒张期杂音，坐位前倾呼气末明显 |
| **心音/体征** | S₁亢进（瓣叶弹性好时），二尖瓣面容 | S₁减弱，心尖搏动向左下移位 | S₂减弱或消失，颈动脉搏动延迟，**脉压减小** | **周围血管征**：水冲脉、毛细血管搏动征、枪击音、Duroziez双重音、点头征；**脉压增宽** |
| **心电图** | "二尖瓣型P波"（P波增宽伴切迹），电轴右偏，右室肥厚 | 左心房增大（P波增宽呈双峰），左室肥厚，房颤 | 左室肥厚伴劳损，左心房增大 | 左室肥厚劳损，电轴左偏 |
| **X线** | 梨形心，左心房增大，肺动脉段隆起 | 左心房、左心室增大 | 心影正常或轻度增大，升主动脉扩张 | 靴形心（主动脉型），左心室明显增大 |
| **超声心动图** | 二尖瓣前叶城墙样改变、穹顶状、鱼钩样，瓣口面积缩小 | 二尖瓣心房侧收缩期反流束，左心房左心室增大 | 瓣叶增厚钙化，开放幅度减小，跨瓣流速增快 | 主动脉瓣关闭不能合拢，左心室流出道全舒张期反流束 |

## 二尖瓣狭窄（MS）

### 病因与病理

风湿热是二尖瓣狭窄的主要病因（占风湿性心脏病的 25% 为单纯 MS）。急性风湿热后至少 2 年才形成明显狭窄。病理改变：瓣叶交界融合、纤维化、钙化，腱索增粗缩短，瓣口呈鱼嘴样改变。

### 狭窄程度分级

| 程度 | 瓣口面积（cm²） | 平均压力阶差（mmHg） | 肺动脉压（mmHg） |
|------|:---:|:---:|:---:|
| 轻度 | >2.5 | <5 | <30 |
| 中度 | 1.6~2.5 | 5~9 | 30~<50 |
| 重度 | <1.6 | >9 | ≥50 |

### 临床表现

**症状**：
- 呼吸困难：最早出现，晚期静息时也可发生
- 咯血：支气管静脉破裂致大量咯血（可为早期首发症状）、痰中带血、急性肺水肿时粉红色泡沫痰
- 咳嗽（夜间多见，左心房压迫左主支气管）
- 声音嘶哑（压迫左侧喉返神经）、吞咽困难（压迫食管）

**体征**：
- **二尖瓣面容**：双颧绀红色（重度狭窄）
- **心尖区低调舒张中晚期隆隆样杂音**，局限不传导，左侧卧位最明显，可触及舒张期震颤
- **S₁亢进**（拍击样）和**开瓣音**：提示瓣叶弹性好
- 肺动脉高压时：P₂亢进，Graham-Steell杂音（相对性肺动脉瓣关闭不全）

### 并发症

| 并发症 | 特点 |
|--------|------|
| **房颤** | 最常见的心律失常并发症；可诱发心力衰竭，使心排血量降低 20%~25% |
| **急性肺水肿** | 重度MS的严重并发症，可致死 |
| **血栓栓塞** | 20%的病人发生体循环栓塞；80%的栓塞病人有房颤；2/3为脑栓塞 |
| **右心衰竭** | 晚期常见并发症 |
| **感染性心内膜炎** | 少见 |
| **肺部感染** | 肺淤血易诱发 |

### 治疗

| 治疗方法 | 内容 |
|----------|------|
| **药物治疗** | 利尿剂改善症状；β受体拮抗剂/地高辛/非二氢吡啶类钙通道阻滞剂控制房颤心室率；**中重度MS合并房颤用华法林抗凝（INR 2~3）**，不用NOAC |
| **经皮球囊二尖瓣成形术（PBMV）** | 适应证：重度单纯MS、瓣叶柔软无明显钙化（Wilkins评分≤8）、无左心房血栓、无MR |
| **外科手术** | 人工瓣膜置换术：适用于不适合PBMV的重度MS；直视分离术（因复发率高已逐步淘汰） |

> 急性肺水肿处理要点：选用扩张静脉的硝酸酯类药物（而非扩张小动脉的药物），正性肌力药物对MS肺水肿无益。

## 二尖瓣关闭不全（MR）

### 病因

二尖瓣结构（瓣叶、瓣环、腱索、乳头肌）任何部分异常均可导致 MR。

| 病变部位 | 慢性病因 | 急性/亚急性病因 |
|----------|----------|----------------|
| **瓣叶-瓣环** | 风湿性、黏液样变性、瓣环钙化、结缔组织病、先天性（二尖瓣裂） | 感染性心内膜炎、外伤、人工瓣瓣周漏 |
| **腱索-乳头肌** | 瓣膜脱垂、乳头肌功能不全 | 腱索断裂（原发性/继发性）、[[急性心肌梗死]]并发乳头肌断裂、创伤 |
| **心肌（相对性）** | 扩张型心肌病、肥厚型梗阻性心肌病、[[冠心病]] | — |

### 反流程度分级

| 参数 | 轻度 | 中度 | 重度 |
|------|:---:|:---:|:---:|
| 有效反流口面积（EROA，cm²） | <0.20 | 0.20~0.39 | ≥0.40 |
| 反流容积（ml） | <30 | 30~59 | ≥60 |
| 缩流颈宽度（cm） | <0.3 | 0.3~0.7 | >0.7 |

### 临床表现

- **急性**：严重反流（腱索/乳头肌断裂）可迅速发生急性左心衰、急性肺水肿或心源性休克
- **慢性**：代偿期长（>20年可无症状），一旦发生[[心力衰竭]]则进展迅速；疲乏无力、呼吸困难
- **体征**：心尖区全收缩期吹风样杂音 ≥3/6 级；前叶损害为主→向左腋部传导；后叶损害为主→向心底部传导；二尖瓣脱垂可有收缩中期喀喇音

### 治疗

- **急性MR**：内科治疗为术前过渡（硝普钠、利尿剂）；外科手术为根本措施（紧急/择期人工瓣膜置换或修复）
- **慢性MR**：无症状者定期随访；有症状重度原发性MR→外科手术（人工瓣膜置换或二尖瓣修复术）
- **经导管二尖瓣缘对缘修复术（TEER）**：用于外科手术高危病人的介入治疗

## 主动脉瓣狭窄（AS）

### 病因

| 类型 | 特点 |
|------|------|
| **先天性畸形** | 二叶瓣畸形最常见（人群 1%~2%），40岁后发病；单叶瓣畸形（婴儿期严重狭窄） |
| **退行性钙化** | 成人AS最常见原因；65岁以上约2%，85岁以上达4% |
| **风湿性** | 多合并主动脉瓣反流和二尖瓣病变 |

### 狭窄程度评估

| 程度 | 射流速度（m/s） | 平均压力阶差（mmHg） | 瓣口面积（cm²） |
|------|:---:|:---:|:---:|
| 轻度 | <3 | <25 | 1.5~2.0 |
| 中度 | 3~3.9 | 25~39 | 1.0~1.5 |
| 重度 | ≥4 | ≥40 | ≤1.0 |

### 典型三联征

| 症状 | 发生率 | 机制 | 预后（不行手术治疗） |
|------|:---:|------|------|
| **心绞痛** | ~60%（最常见、最早出现） | 心肌耗氧↑ + 冠脉灌注↓ | 约50% 5年内死亡 |
| **晕厥** | 15%~30% | 劳力时外周血管扩张而心排血量不能增加；心律失常 | 约50% 3年内死亡 |
| **呼吸困难** | ~95%（晚期首发症状） | 左心衰竭→肺淤血 | 约50% 2年内死亡 |

### 体征

- 心尖区收缩期抬举样搏动；**脉压减小**；颈动脉搏动明显延迟
- **胸骨右缘第2肋间粗糙喷射性收缩期杂音**（递增-递减型，3/6级以上），向颈部传导
- S₂减弱或消失（主动脉瓣成分）；可有S₄

### 治疗

| 方法 | 说明 |
|------|------|
| **药物治疗** | 无特异性药物；对症支持（控制血压、利尿、ACEI）；**慎用血管扩张药**（硝酸酯类、硝苯地平可能降低冠脉灌注压） |
| **外科人工瓣膜置换术** | 主要治疗方法；适应证：有症状的重度AS |
| **经导管主动脉瓣置换术（TAVR）** | 年龄>65岁重度AS病人的主要治疗手段之一 |
| **经皮球囊主动脉瓣成形术（PBAV）** | 限于血流动力学不稳定时的过渡治疗（术后再狭窄率高） |

## 主动脉瓣关闭不全（AR）

### 病因

| 类型 | 病因 |
|------|------|
| **主动脉瓣本身病变（慢性）** | 风湿性心脏病（我国约2/3的AR）、二叶瓣畸形、感染性心内膜炎、退行性钙化、主动脉瓣脱垂 |
| **主动脉根部扩张（慢性）** | Marfan综合征、梅毒性主动脉炎、高血压、主动脉夹层、强直性脊柱炎 |
| **急性AR** | 感染性心内膜炎、胸部创伤、主动脉夹层、人工瓣膜撕裂 |

### 周围血管征（慢性AR特征性体征）

| 体征 | 含义 |
|------|------|
| **水冲脉（Corrigan征）** | 脉搏骤起骤落 |
| **毛细血管搏动征（Quincke征）** | 轻压指甲床可见毛细血管搏动 |
| **股动脉枪击音（Traube征）** | 听诊器轻压股动脉可闻收缩期和舒张期双重杂音 |
| **Duroziez双重音** | 听诊器压迫股动脉可闻双期杂音 |
| **点头征（De Musset征）** | 头部随心动周期节律性点头 |
| **脉压增宽** | 收缩压增高、舒张压降低 |

### 听诊特点

| 杂音类型 | 特点 |
|----------|------|
| **主动脉瓣区舒张期杂音** | 高调递减型叹气样，舒张早期出现，坐位前倾呼气末最明显，向心尖区传导 |
| **Austin-Flint杂音** | 心尖区柔和低调舒张期隆隆样杂音（相对性二尖瓣狭窄），需与MS鉴别 |
| **收缩中期杂音** | 严重AR时，大量心搏出量通过主动脉瓣所致（非器质性AS） |

### AR严重程度判定

| 程度 | 射流宽度 | 反流分数 |
|------|----------|:---:|
| 轻度 | <LVOT的25% | <30% |
| 中度 | LVOT的25%~65% | 30%~50% |
| 重度 | >LVOT的65% | >50% |

### 治疗

- **慢性**：轻度每3~5年随访；重度有症状或LVEF<55%/LVESD>50mm→外科主动脉瓣置换术
- **急性**：内科治疗为术前过渡（硝普钠、正性肌力药物）；尽早外科手术（人工瓣膜置换或主动脉瓣修复术）

## 多瓣膜病（联合瓣膜病）

| 组合 | 特点 |
|------|------|
| **MS + AS** | MS会掩盖AS表现（左室充盈受限→跨瓣压差降低，可能低估AS严重度），心绞痛不明显 |
| **MS + AR** | MS使左室扩张延缓，周围血管征不明显 |
| **AS + MR** | 危险组合，前者加重MR，后者减少左室前负荷，早期发生左心衰 |
| **MR + AR** | 左室承受双重容量负荷，较早发生左心衰 |

## 风湿热

风湿热是心脏瓣膜病的主要病因之一，由A群乙型溶血性链球菌感染后异常免疫反应所致。

### Jones诊断标准（1992年修订）

| 主要表现 | 次要表现 | 链球菌感染证据 |
|----------|----------|---------------|
| 心脏炎 | 既往风湿热病史 | 近期猩红热史 |
| 多发性关节炎 | 关节痛 | 咽拭子培养链球菌阳性 |
| 舞蹈病 | 发热 | 抗链球菌抗体滴度升高 |
| 环形红斑 | ESR增快、CRP阳性 | |
| 皮下结节 | PR间期延长 | |

> 诊断：2项主要表现，或1项主要表现+2项次要表现（有前驱链球菌感染证据的前提下）。

### 预防

- **一级预防**：改善环境、预防上呼吸道感染
- **二级预防**：苄星青霉素每3~4周肌注，至少5年或至25岁；有风湿性心脏病者至少10年或至40岁，甚至终身
