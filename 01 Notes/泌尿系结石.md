# 泌尿系结石

## 概述

泌尿系结石（尿石症）是泌尿外科常见病。男性多于女性，好发于30~50岁，南方多于北方。

### 结石成分

| 成分 | 占比 | 特点 |
|------|------|------|
| 草酸钙 | ~80%（最常见） | X线不透光（阳性结石） |
| 磷酸钙 | ~10% | 不透光 |
| 尿酸结石 | ~5% | 透X线（阴性结石，CT可显示） |
| 胱氨酸结石 | ~1% | 半透光 |

### 危险因素

饮水量少、高温环境（汗多尿少）、高蛋白/高嘌呤/高草酸饮食、内分泌疾病（甲状旁腺功能亢进→高钙血症）、尿路梗阻/感染/异物

### 病理生理

结石→尿路梗阻→肾积水→肾功能损害；结石+感染→肾盂肾炎→尿源性脓毒症；长期结石刺激→慢性炎症→鳞状细胞癌风险。

## 上尿路结石（肾与输尿管结石）

### 临床表现

| 症状/体征 | 特点 |
|-----------|------|
| **腰腹部绞痛（肾绞痛）** | 结石在输尿管内移动→突发性剧烈腰腹部绞痛→向**同侧腰部、会阴部放射** |
| 血尿 | 肉眼或镜下血尿，活动后加重 |
| 膀胱刺激征 | 输尿管末端结石→尿频、尿急 |
| 恶心呕吐 | 过度疼痛反射+神经刺激 |
| 肾区叩痛（+） | — |
| 感染/梗阻 | 发热、脓尿、肾盂积水 |

### 诊断

| 检查 | 用途 |
|------|------|
| **非增强螺旋CT** | **首选**——所有类型结石（包括阴性结石）均可显示，灵敏度接近100% |
| 尿常规 | 镜下血尿（RBC+）、WBC增高→合并感染 |
| 超声 | 筛查肾积水、肾盂/肾盏大结石，孕妇首选 |
| 静脉肾盂造影（IVP） | 了解分肾功能、梗阻程度 |

### 治疗原则

| 结石大小 | 治疗 |
|----------|------|
| <5mm | 保守排石（多饮水+药物排石+解痉止痛）→**90%可自行排出** |
| 5~10mm | 药物排石或**ESWL**（体外震波碎石） |
| 10~20mm | ESWL或**输尿管镜碎石取石术（URS）** |
| >20mm或鹿角形结石 | **PCNL**（经皮肾镜碎石取石术） |

**肾绞痛处理**：NSAIDs（首选，如酮咯酸/双氯芬酸钠）、α₁受体阻断药（坦索罗辛，松弛输尿管平滑肌帮助排石）。

## 膀胱结石

- **临床表现**：排尿突然中断+**变换体位后可继续排尿**（特征性表现）；排尿痛（向会阴部放射）+终末血尿
- **诊断**：超声→结石可随体位移动；X线平片；膀胱镜
- **治疗**：膀胱镜碎石取石（激光/气压弹道）；开放手术（巨大结石）

---

## 尿道结石

- 好发于男性（尿道长且弯曲），多由膀胱结石排入尿道
- **临床表现**：排尿困难、尿线中断/变细、尿道剧痛
- **前尿道结石**：尿道口可触及，经尿道口取出或内镜下碎石
- **后尿道结石**：将结石推回膀胱→按膀胱结石处理
