# 妊娠合并病毒性肝炎


## 概述

病毒性肝炎是由肝炎病毒引起的以肝脏病变为主的传染性疾病，致病病毒包括HAV、HBV、HCV、HDV、HEV五种。除HBV为DNA病毒外，其余均为RNA病毒。我国是乙型肝炎高发国家，妊娠合并重型肝炎仍是我国孕产妇死亡的重要原因之一。

## 妊娠期肝脏生理变化

- 基础代谢率增高，肝内糖原储备减少
- 大量雌激素在肝内灭活，妨碍脂肪转运和胆汁排泄
- 胎儿代谢产物经母体肝脏解毒
- 分娩时体力消耗、缺氧、酸性代谢产物增多→肝脏负担加重

以上变化使肝炎病情易进展，但不增加对肝炎病毒的易感性。

## 对母儿的影响

- 妊娠中晚期重型肝炎风险增加
- 凝血功能障碍→产后出血风险增加
- 流产、早产、死胎和新生儿死亡风险增加
- HBV垂直传播：即使联合免疫，仍有10%～15%婴儿免疫失败

## 肝炎病毒的垂直传播

| 病毒 | 垂直传播特点 |
|------|------------|
| HAV | 经消化道传播，一般不经胎盘，分娩过程接触母体血液可致新生儿感染 |
| HBV | 垂直传播是慢性HBV感染的主要原因，新生儿感染后＞80%成为慢性携带者 |
| HCV | 垂直传播发生率约4%～7%，母血HCV-RNA滴度高时传播率增加 |
| HDV | 依赖HBV，传播途径同HBV |
| HEV | 少数垂直传播病例 |

## 诊断

### 病史与临床表现

- 有肝炎患者密切接触史，半年内血制品输注史
- 消化系统症状（食欲减退、恶心、呕吐、腹胀、肝区痛）+乏力、畏寒、发热、黄疸
- **乙型肝炎血清学标志物意义**：

| 标志物 | 临床意义 |
|--------|---------|
| HBsAg | HBV感染特异性标志 |
| HBsAb | 曾感染或已接种疫苗，有免疫力 |
| HBeAg | 血中有HBV复制，反映传染性强弱 |
| HBeAb | HBV复制趋于停止，传染性减低 |
| HBcAb-IgM | HBV复制阶段，出现于肝炎早期 |
| HBcAb-IgG | 肝炎恢复期或慢性感染 |

### 实验室检查

- **ALT**：最常用的反映肝细胞损伤程度的敏感指标
- **胆红素**：在预后评估上较ALT及AST更有价值；"胆酶分离"提示肝细胞坏死严重，预后不良
- **PTA**：判断病情严重程度和预后的主要指标；**PTA＜40%是诊断重型肝炎的重要标志**

### 重型肝炎诊断要点

符合以下3点可临床诊断：①乏力、食欲缺乏、恶心呕吐；②PTA＜40%；③血清总胆红素＞171μmol/L。其他表现：黄疸迅速加深、肝脏缩小、肝臭、肝性脑病、肝肾综合征。

## 鉴别诊断

| 疾病 | 鉴别要点 |
|------|---------|
| 妊娠期肝内胆汁淤积症 | 瘙痒+胆汁酸升高，肝炎标志物阴性，分娩后迅速好转 |
| 妊娠期急性脂肪肝（AFLP） | 肝炎标志物阴性；尿胆红素阴性（重型肝炎为阳性）；终止妊娠后1周左右好转 |
| HELLP综合征 | 在妊娠期高血压疾病基础上发生，终止妊娠后迅速好转 |
| 妊娠剧吐肝损害 | 妊娠早期，纠正水电解质紊乱后好转，无黄疸 |
| 药物性肝损害 | 有肝毒性药物服用史，停药后恢复 |

## 处理

### 妊娠期处理

- 轻症急性肝炎：护肝、对症、支持疗法，治疗后好转可继续妊娠
- 慢性活动性肝炎：病情加重、治疗效果差者考虑终止妊娠

### 分娩期

- 评估肝功能及凝血功能，备好血液制品
- 避免产程过长，防治产后出血

### 产褥期

- HBsAg阳性产妇的新生儿经主动+被动免疫后**可以母乳喂养**
- 不宜哺乳者用生麦芽或芒硝退奶，**禁用雌激素**

### 重型肝炎处理

多学科协同诊疗，尽快终止妊娠（以剖宫产为宜）。积极防治产后出血、肝性脑病、肝肾综合征和感染。

## 垂直传播阻断

### HBV新生儿免疫方案

| 新生儿情况 | HBIG | 乙肝疫苗接种 |
|-----------|------|------------|
| 母亲HBsAg(-)，足月/体重≥2000g | 不需要 | 3针：0、1、6月 |
| 母亲HBsAg(+)，足月/体重≥2000g | 出生12h内（越快越好） | 3针：首针出生12h内 |
| 母亲HBsAg(+)，早产/体重＜2000g | 出生12h内+1月龄重复1次 | 4针：出生12h内、3～4周、再隔1月、再隔5月 |

妊娠中晚期HBV-DNA＞2×10⁵IU/ml者，可于妊娠28周开始予替诺福韦抗病毒治疗。
