# 肾上腺皮质功能减退症

> 原发性慢性肾上腺皮质功能减退症（Addison病）由双侧肾上腺绝大部分被毁所致，以糖皮质激素和盐皮质激素分泌不足为主要表现，最具特征者为全身皮肤色素沉着。

## 分类

| 类型 | 病变部位 | 盐皮质激素 | ACTH |
|------|----------|-----------|------|
| **原发性（Addison病）** | 双侧肾上腺 | 分泌不足 | 明显增高 |
| 继发性 | 下丘脑-垂体 | 不受影响 | 降低 |

## 病因

| 病因 | 说明 |
|------|------|
| **肾上腺结核** | 常见病因，常合并肺、肾等其他部位结核，肾上腺干酪样坏死→纤维化、钙化 |
| **自身免疫性肾上腺炎** | 两侧肾上腺皮质被毁、纤维化，可检出抗肾上腺自身抗体 |
| 恶性肿瘤转移 | 淋巴瘤、白血病浸润 |
| 其他 | 淀粉样变性、双侧肾上腺切除、放疗、酮康唑/米托坦等药物、血管栓塞 |
| 先天性 | 肾上腺脑白质营养不良症（长链脂肪酸代谢异常，同时累及神经和肾上腺） |

### 自身免疫性多内分泌腺体综合征（APS）

| 类型 | 人群 | 三联征 | 遗传 |
|------|------|--------|------|
| APS I型 | 儿童 | Addison病 + 甲旁减 + 黏膜皮肤白念珠菌病 + 卵巢早衰 | AR |
| APS II型 | 成人 | Addison病 + 自身免疫性甲状腺疾病 + **[[1型糖尿病]]** | 显性 |

## 临床表现

### 最具特征性表现

**全身皮肤色素加深**，暴露处、摩擦处、乳晕、瘢痕等处尤为明显，黏膜色素沉着见于齿龈、舌部、颊黏膜。系垂体ACTH、黑素细胞刺激素分泌增多所致。

### 各系统表现

| 系统 | 表现 |
|------|------|
| 神经精神 | 乏力、淡漠、易疲劳，重者嗜睡、意识模糊、精神失常 |
| 胃肠道 | 食欲减退、**嗜咸食**、恶心呕吐腹泻（提示病情加重） |
| 心血管 | **低血压**、心脏缩小、心音低钝、直立性昏厥 |
| 代谢 | 糖异生减弱→**低血糖** |
| 肾脏/电解质 | 排泄水负荷能力减弱→稀释性低钠血症；ADH释放增多→加重低钠 |
| 生殖系统 | 女性阴毛腋毛脱落、闭经；男性性功能减退 |
| 免疫 | 对感染、外伤等应激的抵抗力减弱 |
| 伴随症状 | 若病因为结核，可有低热、盗汗、消瘦 |

### 肾上腺危象

为本病急骤加重的表现，是内科急症。

| 项目 | 内容 |
|------|------|
| **诱因** | 感染、创伤、手术、分娩、过劳、大量出汗、呕吐、腹泻、失水、突然中断糖皮质激素治疗 |
| **表现** | 恶心呕吐、腹痛腹泻、严重脱水、**低血压**、心率快脉细弱、精神失常、高热、**低血糖**、**低钠血症**（血钾可低可高） |
| **转归** | 如不及时抢救→休克、昏迷、死亡 |

## 实验室检查

### 生化

| 指标 | 改变 |
|------|------|
| **血钠** | **降低** |
| **血钾** | **升高**（一般不重） |
| 高血钙 | 轻度或中度（糖皮质激素促进肾、肠排钙） |
| 低血糖 | 空腹低血糖，OGTT低平曲线 |
| 血常规 | 正细胞正色素贫血、中性粒细胞减少、淋巴细胞相对增多、嗜酸性粒细胞增多 |

### 激素检查

| 检查 | 结果 |
|------|------|
| 基础血/尿皮质醇 | 常降低（也可接近正常） |
| **血浆ACTH** | **明显增高**，常88~440pmol/L（正常<18pmol/L） |
| **ACTH兴奋试验** | **最具诊断价值**，ACTH兴奋后血皮质醇峰值<500nmol/L提示肾上腺皮质功能减退 |
| 血醛固酮 | 降低或在正常低限，肾素活性升高（原发性）；继发性两者均正常 |

### 影像学

- 结核：肾上腺增大及钙化阴影
- 自身免疫：肾上腺不增大

## 诊断与鉴别诊断

最具有诊断价值者为**ACTH兴奋试验**（反映肾上腺储备功能）。

应与慢性消耗性疾病鉴别。出现以下情况应考虑肾上腺危象：
- 疾病不重但出现严重循环虚脱、脱水、休克
- 不明原因低血糖
- 难以解释的呕吐
- 体检发现色素沉着、白斑病、体毛稀少

## 治疗

### 一、基础治疗（终身）

#### 糖皮质激素替代

| 项目 | 内容 |
|------|------|
| 常用药物 | 氢化可的松（20~30mg/d→15~20mg/d）或可的松（25~37.5mg/d） |
| 服药方式 | 模拟分泌昼夜节律：清晨2/3，下午4时前1/3 |
| 应激时 | 有发热等并发症时适当加量 |

#### 食盐及盐皮质激素

| 项目 | 内容 |
|------|------|
| 食盐 | 每日至少8~10g，大量出汗/腹泻时增加 |
| 盐皮质激素 | 若仍有头晕/乏力/血压偏低，加氟氢可的松0.05~0.1mg/d（上午8时顿服） |
| 减量指征 | 出现水肿、高血压、低血钾 |

### 二、病因治疗

- 活动性结核：积极抗结核治疗（替代剂量的糖皮质激素不影响结核控制）
- 自身免疫病：检查其他腺体功能，进行相应治疗

### 三、肾上腺危象治疗（内科急症）

| 步骤 | 方案 |
|------|------|
| **补充液体** | 第1~2天生理盐水2000~3000ml/d，补充葡萄糖溶液避免低血糖 |
| **糖皮质激素** | 立即静注氢化可的松100mg + 每6h静滴100mg，第2~3天减至300mg/d分次静滴，病情好转逐渐减少直至口服 |
| 积极治疗感染及其他诱因 | |

### 四、外科手术或应激时治疗

- 严重应激：氢化可的松约300mg/d，数日内逐步减至维持量
- 较轻短暂应激：氢化可的松100mg/d，酌情递减
