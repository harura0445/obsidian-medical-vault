# 产前检查与孕期保健

![[04 Attachments/妇产科-妊娠诊断_p21.webp]]

## 概述

产前检查与孕期保健是降低孕产妇和围产儿病率及死亡率、减少出生缺陷的重要措施。内容包括规范的产前检查、健康教育、胎儿健康评估、营养管理和用药指导。

## 产前检查

### 检查时间与次数

推荐产前检查**7～11次**，有高危因素者可酌情增加。

| 检查次数 | 孕周 | 重点 |
|----------|------|------|
| 第1次 | 6～13周 | 建立孕期保健手册，确定孕周，评估高危因素，必查项目全套 |
| 第2次 | 14～19周 | 无创产前筛查（NIPT 12～22周），中孕期血清学筛查（15～20周） |
| 第3次 | 20～24周 | **胎儿系统超声筛查**（大排畸），血常规，尿常规 |
| 第4次 | 25～28周 | **75g OGTT**（妊娠期糖尿病筛查），血常规 |
| 第5次 | 29～32周 | 产科超声，关注胎位及胎动 |
| 第6次 | 33～36周 | GBS筛查（35～37周），NST（32～34周后） |
| 第7～11次 | 37～41周 | 每周1次，产科超声，NST每周1次 |

### 推算预产期（EDC）

末次月经（LMP）第1日起，**月份+9或-3，日数+7**。妊娠14周前用超声**CRL**复核预产期最准确。若LMP推算与早期超声相差>5日，应以超声结果校正。

### 产科检查方法

#### 腹部检查——四步触诊法

| 步骤 | 手法 | 目的 |
|------|------|------|
| 第1步 | 两手置宫底部 | 测宫底高度，判断宫底胎儿部分（头/臀） |
| 第2步 | 两手置腹部左右侧 | 分辨胎背（平坦饱满）与肢体（高低不平） |
| 第3步 | 右手握耻骨联合上方 | 查清先露部为头/臀，确定是否衔接 |
| 第4步 | 两手置先露部两侧向下按 | 核对先露诊断，确定入盆程度 |

**胎心听诊**：枕先露→脐右（左）下方；臀先露→脐右（左）上方；肩先露→近脐部下方。

#### 骨盆测量

**骨盆外测量**：坐骨结节间径（出口横径，正常8.5～9.5cm）；出口后矢状径（正常8～9cm）；两者之和>15cm表明出口狭窄不明显。耻骨弓角度：正常90°，<80°为异常。

**骨盆内测量**：

| 测量项目 | 正常值 | 意义 |
|----------|--------|------|
| 对角径（DC） | 12.5～13.0cm | DC − 1.5～2.0cm = 骨盆入口前后径（真结合径） |
| 坐骨棘间径 | ≈10cm | 中骨盆横径 |
| 坐骨切迹宽度 | 3横指（5.5～6.0cm） | <3横指为中骨盆狭窄 |

### 高龄孕妇保健

年龄≥35岁为高龄孕妇。妊娠风险增加（流产、染色体异常、子痫前期、GDM、FGR、早产、死胎）。≥40岁建议直接产前诊断，妊娠40周前适时终止妊娠。

## 评估胎儿健康的技术

### 高危儿标准

孕龄<37周或≥42周；出生体重<2500g；小于/大于胎龄儿；Apgar评分0～3分；产时感染；高危妊娠产妇的新生儿等。

### 胎儿宫内状况监测

#### 胎动监测

孕妇自我评价的简易有效方法。妊娠28周后**胎动<6次/2小时**提示胎儿缺氧可能。

#### 电子胎心监护（EFM）

| 指标 | 定义 |
|------|------|
| 基线 | 正常110～160次/分。心动过速>160持续≥10分钟；心动过缓<110持续≥10分钟 |
| 基线变异 | **最重要的评价指标**。正常：中等变异（振幅6～25次/分）。消失：0；微小：≤5；显著：>25 |
| 加速 | ≥32周：加速≥15次/分×≥15秒；<32周：≥10次/分×≥10秒 |
| 早期减速 | 对称缓慢下降，最低点与宫缩峰同步，开始到最低≥30秒 |
| 晚期减速 | 对称缓慢下降，最低点**延迟于**宫缩峰，提示胎儿缺氧 |
| 变异减速 | 突发显著下降，开始到最低<30秒，与宫缩无固定规律 |
| 正弦波形 | 平滑正弦波样摆动，频率固定3～5次/分，持续≥20分钟，提示严重缺氧 |

#### NST（无应激试验）

| 结果 | 基线变异 | 加速（≥32周） | 处理 |
|------|----------|---------------|------|
| 正常（有反应型） | 6～25次/分 | 40min内≥2次加速≥15×15 | 继续随访 |
| 不典型（可疑型） | ≤5持续<40min | 40～80min内<2次 | 需进一步评估 |
| 异常（无反应型） | ≤5持续≥80min | >80min内<2次 | 全面评估、BPP、必要时终止妊娠 |

#### OCT（缩宫素激惹试验）

用缩宫素诱导宫缩+EFM记录。**阴性**：无晚期减速或重度变异减速。**阳性**：≥50%宫缩伴晚期减速。

#### 三级电子胎心监护判读

| 分级 | 标准 | 意义与处理 |
|------|------|-----------|
| Ⅰ类 | 基线110～160，中度变异，无晚期/变异减速，有/无加速 | 胎儿酸碱平衡正常，常规监护 |
| Ⅱ类 | 除Ⅰ类和Ⅲ类之外的所有图形 | 需综合评估，持续监护 |
| Ⅲ类 | 基线无变异+（复发性晚期减速/变异减速/心过缓）或正弦波形 | 胎儿缺氧，需立即纠正或紧急终止妊娠 |

## 孕期营养和体重管理

### 膳食指南（5条核心推荐）

1. 补充叶酸，常吃含铁食物，选用碘盐
2. 孕吐严重者少量多餐
3. 中晚期增加奶、鱼、禽、蛋、瘦肉（中期+50g/d，晚期+75g/d）
4. 适量身体活动
5. 禁烟酒

**关键营养素**：叶酸0.4～0.8mg/d至孕3月；钙中期起600mg/d；碘230μg/d；铁中期起视需要补充。

### 体重管理

| 孕前BMI | 孕期总增重范围 | 中晚期每周增重 |
|----------|---------------|---------------|
| <18.5（低体重） | 11.0～16.0kg | 0.46kg |
| 18.5～24.0（正常） | 8.0～14.0kg | 0.37kg |
| 24.0～28.0（超重） | 7.0～11.0kg | 0.30kg |
| ≥28.0（肥胖） | 5.0～9.0kg | 0.22kg |

## 产科合理用药

### 基本原则

①用药须有明确指征；②选用有效且对胎儿相对安全的药物；③单独用药，避免联合；④选用结论肯定的药物，避免新药；⑤严格掌握剂量和持续时间；⑥妊娠早期尽量推迟到中晚期用药。

### 药物的妊娠分类（FDA）

| 类别 | 定义 |
|------|------|
| A类 | 对照研究证实对胎儿无危害 |
| B类 | 危害证据不足或不能证实 |
| C类 | 动物实验有危害，无人类对照研究，权衡利弊使用 |
| D类 | 对胎儿有危害，但临床必需且无替代，充分权衡使用 |
| X类 | 明显致畸，**妊娠期禁用** |

### 用药时孕龄与损害关系

| 时期 | 影响 |
|------|------|
| 受精后2周内 | "全或无"：胚胎死亡流产或无异常 |
| 受精后3～8周 | **致畸高度敏感期**（神经15～25日，心脏21～40日，肢体和眼睛24～46日） |
| 受精后9周～足月 | 影响生长和功能，神经系统分化持续至晚期及新生儿期 |

## 孕期常见症状及处理

| 症状 | 处理要点 |
|------|----------|
| 消化系统症状 | 维生素B6 10～20mg bid/tid；妊娠剧吐按专病处理 |
| 贫血 | 非贫血SF<30μg/L：补铁60mg/d；确诊缺铁性贫血：100～200mg/d |
| 腰背痛 | 休息、局部热敷，必要时药物治疗 |
| 下肢肌肉痉挛 | 补钙600～1500mg/d |
| 下肢水肿 | 休息后消退属正常；不消退需排查妊娠期高血压疾病 |
| 便秘 | 多饮水、多纤维素、运动，必要时缓泻剂，慎用开塞露 |
| 仰卧位低血压 | 侧卧位即可恢复 |
