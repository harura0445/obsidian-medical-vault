# 慢性肾衰竭

> 慢性肾衰竭（CRF）是各种慢性肾脏病（CKD）持续进展至后期的共同结局，以代谢产物潴留、水电解质及酸碱平衡失调和全身各系统症状为表现的临床综合征。

## 定义和分期

### CKD定义

各种原因引起的肾脏结构或功能异常≥3个月，包括出现肾脏损伤标志（白蛋白尿、尿沉渣异常、肾小管相关病变、组织学检查异常及影像学检查异常）或有肾移植病史，伴或不伴GFR下降；或不明原因的GFR下降＜60ml/(min·1.73m²)≥3个月。

### CKD分期 (K/DOQI)

| 分期 | 特征 | GFR [ml/(min·1.73m²)] | 防治目标 |
|------|------|------------------------|----------|
| 1 | GFR正常或升高 | ≥90 | 病因诊治，缓解症状 |
| 2 | GFR轻度降低 | 60~89 | 评估、延缓进展 |
| 3a | GFR轻到中度降低 | 45~59 | 延缓进展，评估并发症 |
| 3b | GFR中到重度降低 | 30~44 | 延缓进展，评估并发症 |
| 4 | GFR重度降低 | 15~29 | 综合治疗，肾脏替代治疗准备 |
| 5 | ESRD | <15或透析 | 适时肾脏替代治疗 |

### CRF vs CKD

CRF的概念早于CKD，指CKD引起的GFR下降及代谢紊乱和临床症状组成的综合征，多等同于CKD 4~5期。

## 流行病学

2022年我国CKD患病率为8.2%。发达国家以糖尿病肾脏病、高血压肾小动脉硬化为主要病因；中国最常见病因仍是[[原发性肾小球疾病]]，但糖尿病肾脏病导致CKD的比例明显增加。

### 常见病因

| 类别 | 疾病 |
|------|------|
| 肾小球疾病 | 原发性/继发性肾小球肾炎 |
| 肾小管间质疾病 | 慢性间质性肾炎、[[肾盂肾炎|慢性肾盂肾炎]]、高尿酸性肾病、梗阻性肾病 |
| 血管性疾病 | 高血压肾小动脉硬化、肾血管疾病 |
| 代谢性疾病 | **糖尿病肾脏病** |
| 遗传性疾病 | 多囊肾病、遗传性肾炎 |

## CKD进展的危险因素

### 渐进性发展因素

| 因素 | 
|------|
| 高血糖 |
| 高血压 |
| 蛋白尿（包括微量白蛋白尿） |
| 低蛋白血症 |
| 吸烟 |
| 贫血、高脂血症、老年、尿毒症毒素蓄积 |

### 急性加重因素

| 因素 | 说明 |
|------|------|
| 有效血容量不足 | 低血压、脱水、大出血、休克（最主要原因之一） |
| 肾毒性药物 | NSAIDs、氨基糖苷类抗生素、造影剂、含马兜铃酸中草药 |
| 肾脏疾病复发或加重 | 原发/继发性肾炎活动等 |
| 严重高血压未控制 | |
| 泌尿道梗阻 | |
| 严重感染、高钙血症、肝衰竭、心衰 | |

## 发病机制

| 机制 | 说明 |
|------|------|
| 肾单位高灌注、高滤过 | 残余肾单位高滤过→肾小球硬化→肾单位进一步丧失 |
| 肾单位高代谢 | 肾小管高代谢→肾小管萎缩、间质纤维化 |
| 上皮细胞表型转化 | 肾小管上皮细胞→肌成纤维细胞 |
| 细胞外基质增生 | TGF-β1等因子高表达，基质金属蛋白酶下调 |
| 醛固酮增多 | 参与肾小球硬化和间质纤维化 |
| 肾脏固有细胞凋亡 | 与肾小球硬化、间质纤维化密切相关 |

### 尿毒症毒素分类

| 类别 | 分子量 | 代表物质 | 相关症状 |
|------|--------|----------|----------|
| 小分子 | <500Da | 尿素氮、胍类、胺类、酚类、钾、磷 | 临床症状 |
| 中分子 | 500~5000Da | 多肽类、蛋白质类、PTH | 尿毒症脑病、内分泌紊乱、免疫低下 |
| 大分子 | >5000Da | β₂-微球蛋白、维生素A | 远期并发症 |

## 临床表现

### 1. 水、电解质代谢紊乱

| 紊乱类型 | 表现与机制 |
|----------|-----------|
| **代谢性酸中毒** | GFR>25时AG正常高氯性酸中毒；GFR<25时高AG性"尿毒症性酸中毒"；HCO₃⁻<15mmol/L出现明显症状 |
| **水钠代谢紊乱** | 水钠潴留→稀释性低钠血症、水肿、高血压；少数可出现低钠低血容量 |
| **钾代谢紊乱** | GFR<20~25时排钾下降→高钾血症；少数出现低钾血症 |
| **钙磷代谢紊乱** | 高磷血症、低钙血症→继发性甲状旁腺功能亢进 |
| 镁代谢紊乱 | GFR<20时轻度高镁血症 |

### 2. 蛋白质、糖、脂和维生素代谢紊乱

| 类别 | 表现 |
|------|------|
| 蛋白质 | 氮质血症、白蛋白下降、必需氨基酸下降 |
| 糖代谢 | 糖耐量减低多见，偶发低血糖 |
| 脂代谢 | 高甘油三酯血症为主，VLDL升高，HDL降低 |
| 维生素 | 维生素A升高、维生素B₆及叶酸缺乏 |

### 3. 心血管系统表现（最主要死因，占尿毒症死因45%~60%）

| 表现 | 说明 |
|------|------|
| **高血压和左心室肥厚** | 水钠潴留、RAAS激活、血管舒张因子不足 |
| **心力衰竭** | 尿毒症期患病率65%~70% |
| 尿毒症性心肌病 | 代谢废物潴留和贫血所致 |
| 心包病变 | 心包积液常见，与尿毒症毒素、低蛋白血症有关 |
| 血管钙化和动脉粥样硬化 | 进展迅速，血液透析病人更重 |

### 4. 各系统表现汇总

| 系统 | 表现 |
|------|------|
| **胃肠道**（最早表现） | 食欲缺乏、恶心、呕吐、口腔有尿味、消化道出血 |
| 呼吸系统 | 气短气促，Kussmaul呼吸，尿毒症肺水肿（"蝴蝶翼"征） |
| **血液系统** | 肾性贫血（EPO减少）、出血倾向（血小板功能降低）、血栓形成倾向 |
| 神经肌肉系统 | 乏力、失眠→性格改变、记忆力减退→尿毒症脑病（谵妄、昏迷）；周围神经病变（肢端袜套样感觉丧失）、不宁腿综合征 |
| 内分泌功能紊乱 | 1,25-(OH)₂D₃不足、EPO缺乏、继发性甲旁亢、性腺功能减退 |
| 骨骼病变（CKD-MBD） | 高转化性骨病（最常见，纤维囊性骨炎）、低转化性骨病（骨软化症）、混合型骨病 |

## 诊断

主要依据病史、肾功能检查及相关临床表现。辅助鉴别要点：

| 指标 | CRF | AKI |
|------|-----|-----|
| 双肾大小 | 常缩小（部分不缩小） | 正常或增大 |
| 贫血 | 常存在 | 早期可不明显 |
| 低钙高磷 | 常存在 | 较少见 |
| PTH | 升高 | 正常 |

特殊类型：
- **CRF急性加重**：CRF本身较重，急性加重过程不典型
- **CRF基础上AKI**：CKD较轻，AKI相对突出

## 治疗

### 治疗目标

| 项目 | 目标值 |
|------|--------|
| 血压（尿蛋白≥30mg/g） | <130/80mmHg |
| 血压（尿蛋白<30mg/g） | <140/90mmHg |
| 空腹血糖 | 5.0~7.2mmol/L |
| HbA1c | <6.5%~8.0% |
| 蛋白尿 | <0.5g/24h |
| GFR下降速度 | <4ml/(min·1.73m²·年) |

### 控制危险因素

| 措施 | 说明 |
|------|------|
| **控制高血压** | 目标<130/80mmHg，ACEI/ARB首选（扩张出球小动脉、减少蛋白尿） |
| **RAAS抑制剂** | ACEI/ARB减少肾小球高滤过、减轻蛋白尿；非奈利酮（非甾体MRA）减缓糖尿病CKD进展 |
| **严格控制血糖** | 空腹5.0~7.2，HbA1c<6.5%~8.0% |
| **控制蛋白尿** | 尽可能<0.5g/24h |
| **SGLT2i** | 无论是否合并糖尿病均可显著减缓CKD进展 |
| **GLP-1RA** | 降低糖尿病合并CKD心血管事件 |

### 营养治疗

| CKD分期 | 蛋白摄入量 |
|---------|-----------|
| CKD 1~2期 | 0.8~1g/(kg·d) |
| CKD 3期起（非透析） | 0.6~0.8g/(kg·d) |
| 透析病人 | 1.0~1.2g/(kg·d) |

- 热量：30~35kcal/(kg·d)
- 约50%蛋白质应为高生物价蛋白
- 可补充α-酮酸制剂0.075~0.12g/(kg·d)
- 磷摄入<800mg/d，钠摄入<2g/d（NaCl<5g/d）

### 并发症药物治疗

| 并发症 | 治疗 |
|--------|------|
| 代谢性酸中毒 | 口服碳酸氢钠1.5~15g/d |
| 高钾血症 | 限钾、碳酸氢钠、袢利尿剂、葡萄糖+胰岛素、聚苯乙烯磺酸钙、血钾>6.5mmol/L时血液透析 |
| 肾性贫血 | rHuEPO（80~120U/kg/周），目标Hb 110~120g/L；罗沙司他；补充铁剂 |
| 低钙高磷/肾性骨病 | 骨化三醇、磷结合剂（碳酸钙、司维拉姆、碳酸镧）、西那卡塞 |
| 高脂血症 | 他汀类药物（50岁以上非透析CKD病人） |
| 感染 | 剂量按GFR调整，选择肾毒性最小药物 |

### 肾脏替代治疗

| 治疗方式 | 适应证 |
|----------|--------|
| **血液透析** | GFR<10ml/min（非糖尿病），GFR<15ml/min（糖尿病），明显尿毒症症状 |
| **腹膜透析** | 同上 |
| **肾移植** | 最佳替代疗法，可恢复正常肾功能（包括内分泌和代谢功能） |

对于CKD 4期以上或预计6个月内需要透析的病人，建议进行替代治疗准备。
