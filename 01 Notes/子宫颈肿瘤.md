# 子宫颈肿瘤

## 概述

子宫颈肿瘤包括良性肿瘤（子宫颈平滑肌瘤、息肉等）和恶性肿瘤。子宫颈癌是女性生殖系统最常见的恶性肿瘤，高危型 **HPV 持续感染**是其最主要的致病因素。通过筛查可早期发现并治愈。

## 子宫颈上皮内瘤变（CIN / SIL）

### 概述

子宫颈上皮内瘤变（cervical intraepithelial neoplasia，CIN）是与子宫颈浸润癌密切相关的一组子宫颈病变，亦是子宫颈癌的癌前病变。WHO 女性生殖系统肿瘤分类（2020）采用**低级别鳞状上皮内病变（LSIL）**和**高级别鳞状上皮内病变（HSIL）**的两级分类法。

| 旧分类 | 新分类 | 处理 |
|--------|--------|------|
| CIN Ⅰ | LSIL | 大多自然消退，可随访观察 |
| CIN Ⅱ/Ⅲ | HSIL | 需治疗，具有进展为浸润癌的风险 |

### 病因

- **高危型 HPV 持续感染**：HPV16、18 是最常见致癌亚型，导致约 70% 子宫颈癌
- 其他高危因素：多个性伴侣、初次性生活过早、多产、吸烟、免疫抑制

### 诊断

遵循**三阶梯技术**：
1. **子宫颈细胞学**（TCT/LCT/LBP）和/或 **高危型 HPV 检测**
2. **阴道镜检查**
3. **子宫颈活组织病理检查**（确诊金标准）

### 治疗

| 病变 | 处理 |
|------|------|
| **LSIL** | 多数自然消退，可随访；持续 ≥2 年或有进展可物理治疗 |
| **HSIL** | 子宫颈锥形切除术（LEEP 或冷刀锥切），切除病灶 + 明确有无浸润癌 |

## 子宫颈癌

### 病理

| 类型 | 占比 | 特点 |
|------|------|------|
| **鳞状细胞癌** | 75%~80% | 最常见，与 HPV 高度相关 |
| 腺癌 | 20%~25% | 近年比例上升 |
| 腺鳞癌 | 3%~5% | 预后较鳞癌差 |

### 转移途径

| 途径 | 特点 |
|------|------|
| **直接蔓延** | 最主要，向阴道、子宫体、子宫旁组织、膀胱、直肠侵犯 |
| 淋巴转移 | 一级组：子宫旁→闭孔→髂内/髂外；二级组：髂总→腹主动脉旁 |
| 血行转移 | 极少见，晚期→肺、肝、骨 |

### 临床分期（FIGO 2018）

| 分期 | 标准 |
|------|------|
| **Ⅰ期** | 肿瘤局限于子宫颈（不考虑宫体侵犯） |
| ⅠA | 镜下浸润癌，深度 ≤5mm |
| ⅠB | 镜下浸润深度 >5mm 或肉眼可见病灶 |
| **Ⅱ期** | 肿瘤超出子宫，未达骨盆壁或阴道下 1/3 |
| **Ⅲ期** | 侵犯骨盆壁/阴道下 1/3 / 肾盂积水/区域淋巴结转移 |
| **Ⅳ期** | 侵犯膀胱或直肠黏膜 / 远处转移 |

### 临床表现

| 症状 | 要点 |
|------|------|
| **阴道流血** | 最常见，早期为**接触性出血**（性生活后或妇科检查后），晚期为不规则阴道流血 |
| **阴道排液** | 白色/血性/稀薄如水样/米泔水样，有腥臭味 |
| **晚期症状** | 压迫→尿频、尿急、便秘、下肢肿痛；侵犯→输尿管梗阻→肾盂积水→尿毒症 |

**体征**：外生型→菜花状赘生物，易出血；内生型→子宫颈增大质硬呈桶状；溃疡型→凹陷性溃疡。

### 诊断

- **子宫颈脱落细胞学 + HPV 检测**：筛查首选
- **阴道镜检查 + 活检**：确诊依据
- 临床分期依靠妇科检查，FIGO 分期为临床分期（非手术病理分期）

### 治疗

以**手术和放疗**为主，化疗为辅的综合治疗。

| 分期 | 治疗原则 |
|------|----------|
| **ⅠA1** | 筋膜外全子宫切除术（保育→子宫颈锥切） |
| **ⅠA2~ⅡA** | 广泛性全子宫切除 + 盆腔淋巴结清扫（根治性子宫切除术） |
| **ⅡB~ⅣA** | **同步放化疗**（放疗 + 顺铂增敏） |
| **ⅣB / 复发** | 姑息化疗、靶向治疗（贝伐珠单抗）、免疫治疗 |

### 预防

- **HPV 疫苗**：一级预防
- **筛查**：细胞学 + HPV 检测（25 岁开始，3~5 年一次）
- 及时治疗 CIN → 阻断进展为浸润癌

## 预后与随访

- 早期（Ⅰ期）5 年生存率 >90%，晚期 ~20%~50%
- 术后 2 年内每 3~6 个月复查，3~5 年每 6~12 个月复查
