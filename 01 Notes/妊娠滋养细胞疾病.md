# 妊娠滋养细胞疾病

## 概述

妊娠滋养细胞疾病（gestational trophoblastic disease，GTD）是一组来源于胎盘滋养细胞的疾病，包括**葡萄胎、侵蚀性葡萄胎、绒毛膜癌（绒癌）**和**胎盘部位滋养细胞肿瘤**（PSTT）等。

| 类型 | 性质 |
|------|------|
| 葡萄胎 | 良性病变（完全性和部分性） |
| 侵蚀性葡萄胎 | 恶性，葡萄胎基础上发生 |
| 绒毛膜癌 | **高度恶性**，可发生在葡萄胎、流产、足月产后 |
| PSTT | 罕见，中间型滋养细胞来源 |

## 葡萄胎

### 概述

因妊娠后胎盘绒毛滋养细胞增生、间质水肿，形成大小不等的水泡，水泡间借蒂相连成串，形如葡萄，故称葡萄胎。分为**完全性葡萄胎**和**部分性葡萄胎**。

### 病因与分类

| 类型 | 核型 | 特点 |
|------|------|------|
| **完全性葡萄胎（CHM）** | 经典 46,XX（父系二倍体） | 空卵 + 单倍体精子（23,X）复制→46,XX；10% 为 46,XY。**不含胎儿组织** |
| **部分性葡萄胎（PHM）** | 69,XXX/XXY/XYY（三倍体） | 正常卵子 + 2 个精子或一个二倍体精子。可见**胎儿或胚胎组织**，多早期死亡 |

### 病理

| 特征 | 完全性 | 部分性 |
|------|--------|--------|
| 绒毛水肿 | 弥漫性 | 局灶性 |
| 滋养细胞增生 | 显著（环绕整个绒毛） | 轻度、局灶性（仅合体滋养细胞） |
| 绒毛间质 | 血管消失 | 可见胎儿有核红细胞和血管 |

### 临床表现

| 症状 | 要点 |
|------|------|
| **停经后阴道流血** | 最常见症状，多在停经 8~12 周出现，量多少不定 |
| **子宫异常增大** | 子宫 > 停经月份（因宫腔积血和水泡过度增生） |
| 妊娠剧吐 | 较正常妊娠更早更重 |
| 子痫前期征象 | 24 周前出现有诊断意义 |
| **甲状腺功能亢进** | β-hCG 具有促甲状腺活性→少数患者出现轻度甲亢 |
| 卵巢黄素化囊肿 | 双侧卵巢多房囊肿，hCG 刺激所致，清除后自行消退 |

### 诊断

- **超声**：特征性表现 — "**落雪征**"或"**蜂窝征**"（宫腔内大小不等无回声区）
- **hCG 测定**：显著高于正常妊娠，>100,000 IU/L 具有辅助诊断价值
- 病理检查：确诊依据

### 治疗

| 步骤 | 要点 |
|------|------|
| **清宫** | 一经确诊立即清宫。选用吸刮术，在输液、备血条件下由有经验医师实施 |
| 子宫切除术 | 40 岁以上、无生育要求可考虑，但不能预防恶变 |
| **预防性化疗** | 高危因素（年龄 >40 岁、hCG >100,000、子宫明显大于停经月份、随访困难）可考虑 MTX 或 Act-D 单药化疗 |

### 随访（关键）

清宫后**每周测 hCG 直至正常**（连续 3 次正常），之后：
- 每月 1 次 × 6 个月
- 每 2 个月 1 次 × 6 个月
- **总共随访至少 1 年**
- 随访期间**严格避孕 1 年**（推荐口服避孕药，后改用避孕套）

## 侵蚀性葡萄胎

- 葡萄胎组织侵入子宫肌层或发生转移
- 均发生于葡萄胎后，多在葡萄胎清宫术后 **6 个月内**发病
- 病理：可见**绒毛结构**（与绒癌鉴别的关键）
- 治疗：以**化疗为主**，低危→单药化疗（MTX 或 Act-D），高危→联合化疗。无生育要求者可行全子宫切除术

## 绒毛膜癌（绒癌）

### 概述

高度恶性的滋养细胞肿瘤，可继发于**葡萄胎（50%）、流产后（25%）、足月产（25%）**几种情况。

### 病理

- 大体：暗红色结节，质脆，极易出血
- 镜下：**无绒毛结构**（与侵蚀性葡萄胎鉴别的关键）。滋养细胞高度增生，侵犯血管，广泛出血坏死

### 临床表现

| 症状 | 要点 |
|------|------|
| **阴道流血** | 最常见，产后/流产后/葡萄胎清宫后不规则出血 |
| **转移灶症状** | 血行转移是主要特点 |
| → 肺转移 | 最常见，咳嗽、咯血、胸痛 |
| → 阴道转移 | 紫蓝色结节，破裂→大出血 |
| → 脑转移 | 头痛、恶心呕吐、抽搐、偏瘫，**主要致死原因** |
| → 肝转移 | 右上腹痛、黄疸，预后差 |

### 诊断

- 葡萄胎、流产或足月产后出现不规则阴道流血 + hCG 持续升高→高度怀疑
- 影像学（超声/MRI/CT）：原发灶及转移灶
- 病理：见滋养细胞增生浸润、无绒毛结构

### 治疗

以**化疗为主的综合治疗**。

- **低危**：单药化疗（MTX 或 Act-D）
- **高危**：联合化疗（**EMA-CO 方案**最常用 — 依托泊苷+MTX+Act-D + 环磷酰胺+长春新碱）
- 全子宫切除术：无生育要求、化疗不敏感或发生难以控制的大出血
- 脑转移：全脑放疗 + 鞘内注射 MTX

## 预后与随访

- 绒癌治愈率高（>90%），化疗敏感性好
- 治疗后 hCG 正常后**严密随访 ≥1 年**，严格避孕
- 治愈后再次妊娠不增加先天性畸形率
