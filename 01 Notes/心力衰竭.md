# 心力衰竭

> 心力衰竭是各种原因导致心脏结构和/或功能异常，使心脏收缩和/或充盈障碍，引起心排血量下降或心腔内压力增高的复杂临床综合征，主要表现为活动耐量下降和液体潴留。

## 概述

心力衰竭（heart failure，HF）是心血管疾病的终末期阶段和最主要的死因。我国≥35岁人群心衰患病率约1.3%，估计患病人数890万，且发病率和患病率均在增长。[[冠心病]]、高血压已成为慢性心衰的最主要病因，冠心病居首位。[[慢性肺源性心脏病]]和高原性心脏病在我国也具有一定的地域高发性。

心功能不全（cardiac dysfunction）是一个更广泛的概念，伴有临床症状的心功能不全称之为心力衰竭。

## 分型/分类

### 按发生部位

| 类型 | 特征 |
|------|------|
| 左心衰竭 | 左心室代偿功能不全所致，临床上较为常见 |
| 右心衰竭 | 右心室代偿功能不全所致 |
| 全心衰竭 | 左心衰竭和右心衰竭同时存在 |

### 按发生速度

| 类型 | 特征 |
|------|------|
| 急性心衰 | 急性的严重心肌损害、结构破坏、心律失常或突然加重的心脏负荷，使心功能在短时间内急剧恶化 |
| 慢性心衰 | 缓慢发展过程，一般均有代偿性心脏扩大或肥厚 |

### 按左心室射血分数（LVEF）

| 分类 | LVEF | 说明 |
|------|------|------|
| HFrEF（射血分数降低的心衰） | **≤40%** | 传统概念中的收缩性心衰 |
| HFmrEF（射血分数轻度降低型心衰） | 41%~49% | 以轻度收缩功能障碍为主 |
| HFpEF（射血分数保留型心衰） | ≥50% | 通常存在充盈压升高、舒张功能受损，既往称舒张性心衰 |
| HFimpEF（射血分数改善的心衰） | 既往≤40%，治疗后＞40% | 需定期监测LVEF变化 |

> 大多数HFrEF病人同时存在舒张功能不全，HFpEF病人也可能存在一定程度的收缩功能异常。

## 心功能分级与分期

### NYHA心功能分级

| 分级 | 症状 |
|------|------|
| Ⅰ级 | 日常活动量不受限制，一般活动不引起乏力、呼吸困难等心衰症状 |
| Ⅱ级 | 体力活动轻度受限，休息时无自觉症状，一般活动下出现心衰症状 |
| Ⅲ级 | 体力活动明显受限，低于平时一般活动即引起心衰症状 |
| Ⅳ级 | 不能从事任何体力活动，休息状态下也存在心衰症状，活动后加重 |

### 心力衰竭分期

| 分期 | 临床特征 |
|------|----------|
| A期（心衰危险因素阶段） | 存在心衰高危因素，尚无心脏结构或功能异常，无心衰症状/体征 |
| B期（前心衰阶段） | 无心衰症状/体征，已出现心脏结构改变（左心室肥厚、既往心梗等） |
| C期（症状性心衰阶段） | 已有心脏结构改变或功能异常，既往或目前有心衰症状/体征 |
| D期（晚期心衰阶段） | 严格优化治疗后仍有明显症状，常伴心源性恶病质，须反复住院 |

## 病因与危险因素

### 基本病因

| 类别 | 机制 | 常见疾病 |
|------|------|----------|
| 心肌收缩力降低 | 原发性心肌损害 | [[冠心病]]、[[急性心肌梗死]]、心肌炎、扩张型心肌病、肥厚型心肌病 |
| | 继发性心肌损害 | [[糖尿病]]、甲状腺疾病、心脏淀粉样变、结缔组织病、心脏毒性药物 |
| 心室舒张和充盈受限 | 心肌顺应性减退 | 肥厚型心肌病、[[心房颤动]]快心室率 |
| 压力负荷（后负荷）过重 | 收缩期射血阻力增加 | 高血压、主动脉瓣狭窄、[[肺动脉高压]]、肺动脉瓣狭窄 |
| 容量负荷（前负荷）过重 | 回心血量增加 | [[心脏瓣膜病]]、先天性心脏病、[[贫血]]、甲亢 |

### 诱因

| 诱因 | 说明 |
|------|------|
| **感染** | **最常见诱因**，尤其是呼吸道感染。发热增加心率及心肌耗氧量 |
| 心律失常 | [[心房颤动]]是最重要的诱因之一，快速型心律失常和严重缓慢型心律失常均可诱发 |
| 心脏前、后负荷增加 | 钠盐摄入过多、静脉输液过快过多、过度劳累、妊娠分娩、情绪波动 |
| 治疗不当 | 不恰当停用或减用治疗药物 |
| 原有心脏病变加重或合并其他疾病 | 冠心病发生心梗、风湿活动、合并[[慢性肾脏病|肾功能不全]]、[[贫血]]等 |

## 病理生理

心衰始于危险因素对心脏的作用，代偿机制长期过度激活导致心肌损害加重和心室重塑，最终失代偿。

### 心脏本身机制

**Frank-Starling机制**：心脏前负荷增加→回心血量增多→心室舒张末期容积增加→心肌收缩力增强→心排血量增加。心肌收缩功能减低时，该机制不能维持正常心排血量，导致心室舒张末压力增高，出现肺循环和/或体循环淤血。

**收缩功能不全**：Frank-Starling代偿失效，心室舒张末压力增高，心房压、静脉压随之升高。

**舒张功能不全**：
- 主动舒张障碍：钙离子回摄入肌质网及泵出胞外的耗能过程受损（心肌缺血、容量负荷过重、衰老）
- 心室肌顺应性减退及充盈障碍（心室肥厚、心内膜纤维化，如高血压病、肥厚型心肌病）

### 神经体液机制

| 机制 | 代偿作用 | 失代偿后果 |
|------|----------|------------|
| 交感-肾上腺髓质系统增强 | 增强心肌收缩力、提高心率、收缩血管保证重要器官灌注 | 后负荷增加、心肌耗氧增加、NE对心肌细胞直接毒性作用、促心律失常 |
| RAAS系统增强 | 收缩血管升高血压、水钠潴留增加循环血量 | 促进心肌和非心肌细胞肥大增殖、心脏纤维化、加重心室和血管重塑 |
| 钠尿肽系统增强 | 利钠排水、抑制醛固酮和ADH分泌、拮抗ATⅡ缩血管作用 | 代偿不足以对抗RAAS和交感系统的过度激活 |
| 精氨酸加压素（AVP）升高 | 抗利尿、收缩血管 | 长期增加使心衰恶化 |

### 心室重塑

心室重塑（ventricular remodeling）是心衰发生发展的**基本病理机制**。心肌细胞坏死减少、纤维化增加使心室顺应性下降，形成恶性循环，最终导致不可逆的终末阶段。

## 临床表现

### 左心衰竭——以肺循环淤血及心排血量降低为主要表现

#### 症状

| 症状 | 特征 |
|------|------|
| **劳力性呼吸困难** | 最早出现的症状，运动使回心血量增加，肺淤血加重 |
| 夜间阵发性呼吸困难 | 入睡后因憋气惊醒，被迫取坐位，端坐休息后缓解 |
| 端坐呼吸 | 肺淤血达一定程度，不能平卧 |
| **急性肺水肿** | 呼吸困难最严重的形式，可伴哮鸣音（"心源性哮喘"） |
| 咳嗽、咳痰、咯血 | 白色浆液性泡沫状痰为特点，急性发作可出现粉红色泡沫样痰 |
| 乏力、疲倦、头晕、心悸 | 器官组织灌注不足及代偿性心率加快 |
| 少尿及肾功能损害 | 肾血流量减少所致 |

#### 体征

- **肺部湿啰音**：从肺底部逐渐至全肺，侧卧时下垂侧啰音较多
- **心脏体征**：心脏扩大、心率增快、相对性二尖瓣关闭不全的反流性杂音、P2亢进、奔马律
- **发绀**：中央型发绀（呼吸膜水肿增厚致氧气交换障碍）

### 右心衰竭——以体循环淤血为主要表现

#### 症状

| 症状 | 特征 |
|------|------|
| **消化道症状** | 胃肠道及肝淤血导致腹胀、食欲缺乏、恶心、呕吐——最常见症状 |
| 劳力性呼吸困难 | 心排血量下降、缺氧所致，与左心衰肺淤血性呼吸困难不同 |

#### 体征

| 体征 | 特征 |
|------|------|
| **水肿** | 始于身体低垂部位的对称性凹陷性水肿 |
| **颈静脉征** | 颈静脉充盈、怒张，**肝颈静脉反流征阳性**具特征性 |
| 肝大 | 肝淤血肿大伴压痛，持续慢性右心衰可致心源性[[肝硬化]] |
| 浆膜腔积液 | 胸腔积液（双侧多见、右侧为甚），严重者出现腹腔积液 |
| 心脏体征 | 右心室舒张期奔马律、右心扩大、相对性三尖瓣关闭不全的反流性杂音 |

### 全心衰竭

同时出现左、右心衰的症状及体征。大多数由左心衰竭发展而来，此时右心排血量减少，左心前负荷减少，呼吸困难等肺淤血症状反而有所减轻。

## 辅助检查

### 实验室检查

| 检查 | 临床意义 |
|------|----------|
| **BNP/NT-proBNP** | 心衰诊断、预后和疗效评估的核心指标；BNP<35ng/L或NT-proBNP<125ng/L通常可排除慢性心衰；NT-proBNP半衰期更长、更稳定 |
| 肌钙蛋白 | 明确是否存在[[急性心肌梗死|急性冠脉综合征]]；伴脑钠肽升高是心衰预后的强预测因子 |
| 常规检查 | 血常规、尿常规、肝肾功能、电解质、甲状腺功能、血清铁蛋白等 |

> 约20%的HFpEF病人BNP/NT-proBNP水平正常。老龄、女性升高，肥胖者降低。肾功能不全、肺栓塞、感染等也可引起升高。

### 影像学检查

| 检查 | 用途 |
|------|------|
| **超声心动图** | **诊断和评估心衰最主要的影像学检查**；可评估各心腔大小、瓣膜结构功能、EF值；E/e'≥15可确诊HFpEF |
| X线检查 | 心衰与肺部疾病鉴别；反映肺淤血（肺门血管影增强、Kerley B线、肺门蝴蝶状等） |
| 心脏磁共振（CMR） | 精确计算心室容积和EF值；LGE技术区分缺血性与非缺血性改变；用于疑似心肌炎、心肌淀粉样变等 |
| 冠状动脉造影 | 有[[冠心病]]危险因素或心肌缺血症状的病人 |

### 其他检查

| 检查 | 说明 |
|------|------|
| 6分钟步行试验 | 评估运动耐力：<150m为重度心衰，150~450m中度，>450m轻度 |
| 右心漂浮导管（Swan-Ganz导管） | 重症心衰血流动力学评估；PCWP≥15mmHg或LVEDP≥16mmHg可确诊HFpEF |
| 心肺运动试验 | 适用于慢性稳定型心衰，评估心功能、判断心脏移植可行性 |

## 诊断与鉴别诊断

### 诊断思路

1. 根据病史、症状、体格检查、心电图、X线胸片判断有无心衰可能性
2. 通过**脑钠肽检测**和**超声心动图**明确是否存在心衰及其类型
3. 进一步确定病因和诱因
4. 评估病情严重程度、预后及合并症

### 鉴别诊断

| 需鉴别的疾病 | 鉴别要点 |
|--------------|----------|
| [[慢性阻塞性肺疾病]]（COPD、[[支气管哮喘]]、肺栓塞） | 根据基础疾病史、心脏体征、肺功能和肺部影像学检查 |
| 心包积液、缩窄性心包炎 | 同样有颈静脉怒张、肝大、下肢水肿，超声心动图、CT、CMR可鉴别 |
| 其他引起水肿的疾病 | 肾性水肿、肝性水肿、低蛋白血症、甲状腺功能减退；非心源性水肿无颈静脉怒张 |
| 贫血、肥胖、神经肌肉疾病 | 尤其在HFpEF诊断时需充分评估，避免过度诊断 |

## 治疗

治疗目标：防止和延缓心衰发生发展；缓解临床症状，提高生活质量；改善长期预后，降低病死率与再住院率。

### 慢性心力衰竭的治疗

#### 一般治疗

- **体重管理**：日常监测体重，反映体液潴留及利尿剂疗效
- **饮食管理**：适当限盐，难治性心衰及终末期心衰需适当限盐
- **休息与活动**：急性期或病情不稳定时限制体力活动；稳定后适量运动，制订个体化运动方案
- **病人教育**：健康生活方式、避免诱因、规范服药、自我监测、合理随访

#### 病因和诱因治疗

积极治疗基础疾病，消除诱因（尤其是感染），控制快心室率[[心房颤动]]，纠正甲状腺功能异常、[[贫血]]、肾功能不全、电解质紊乱。

#### 药物治疗

##### 1. 利尿剂——控制体液潴留

无论何种心衰，只要存在体液潴留都应使用。

| 类型 | 代表药物 | 特点 |
|------|----------|------|
| 袢利尿剂 | 呋塞米 | 强效，作用于髓袢升支粗段，排钠排钾。注意低血钾 |
| 噻嗪类利尿剂 | 氢氯噻嗪 | 中效，GFR＜30ml/min时作用明显受限；可引起高尿酸血症 |
| 保钾利尿剂 | 螺内酯、氨苯蝶啶、阿米洛利 | 利尿作用弱，多与其他利尿剂联用预防低血钾 |
| AVP受体拮抗剂 | 托伐普坦 | 不增加排钠，用于伴低钠血症、利尿剂抵抗者 |

##### 2. RAAS抑制剂

| 药物 | 作用机制 | 适应证 | 注意事项 |
|------|----------|--------|----------|
| ACEI | 抑制ACE减少ATⅡ生成，改善心室重塑 | HFrEF首选；HFmrEF可考虑；HFpEF合并高血压等适应证时考虑 | 副作用：低血压、肾功能恶化、高血钾、干咳、血管性水肿 |
| ARB | 阻断AT1受体，无抑制缓激肽降解作用 | ACEI不耐受者的替代 | 干咳和血管性水肿较少见 |
| ARNI（沙库巴曲缬沙坦） | 抑制脑啡肽酶+阻断AT1受体 | HFrEF推荐作为初始治疗或替代ACEI/ARB；HFmrEF和HFpEF可考虑使用 | 禁忌同ACEI |

##### 3. β受体拮抗剂

抑制交感神经过度激活的不利作用，保护心肌细胞，改善心室重塑。**HFrEF和HFmrEF病人除非存在禁忌，均推荐使用。**

- 常用药物：美托洛尔、比索洛尔、卡维地洛
- 小剂量起始，逐渐增加达最大耐受剂量并长期维持
- 禁忌证：支气管痉挛性疾病、严重心动过缓、二度及以上房室传导阻滞、严重周围血管疾病、重度急性心衰
- **不可突然停药**

##### 4. 醛固酮受体拮抗剂（MRA）

阻断醛固酮效应，抑制心室重塑，在各类型心衰中均能改善预后。**推荐使用于各类型症状性慢性心衰病人。**

| 药物 | 特点 |
|------|------|
| 螺内酯（第一代） | 同时拮抗雄激素，长期服用引起男性乳腺增生 |
| 依普利酮（第二代） | 选择性醛固酮受体拮抗剂，对雄激素拮抗作用弱，尤适用于老龄、[[糖尿病]]和肾功能不全病人 |

禁忌证：血钾≥5.0mmol/L或eGFR≤30ml/(min·1.73m²)

##### 5. SGLT2抑制剂（SGLT2i）

通过抑制近端肾小管钠-葡萄糖重吸收，促进尿糖和钠排泄，同时改善能量代谢、内皮功能、抑制炎症和纤维化。**推荐使用于所有EF类型心衰病人。**

- 常用药物：达格列净、恩格列净（每次10mg，每日1次）
- 禁忌证：严重肾功能不全、收缩压<95mmHg
- 警惕：血糖正常的酮症酸中毒、生殖器和软组织感染

##### 6. 洋地黄类药物

| 项目 | 内容 |
|------|------|
| 药理作用 | ①正性肌力作用（抑制Na⁺-K⁺-ATP酶）；②抑制心脏传导系统（房室交界区最明显）；③迷走神经兴奋；④减少肾小管钠重吸收并抑制肾素分泌 |
| 适应证 | 应用利尿剂、ACEI/ARB/ARNI、β受体拮抗剂、MRA和SGLT2i后仍持续有症状的HFrEF病人；症状性心衰伴房颤快心室率者 |
| 常用药物 | 地高辛0.125~0.25mg/d，70岁以上或肾功能损害者予更小剂量，血药浓度维持0.5~0.9μg/L |
| 禁忌证 | ①病态窦房结综合征、二度及以上房室传导阻滞；②心梗急性期（<24小时）；③预激综合征伴房颤或房扑；④肥厚型梗阻性心肌病 |

##### 7. 其他药物

| 药物 | 机制 | 适应证 |
|------|------|--------|
| 伊伐布雷定 | 选择性抑制窦房结If电流，减慢窦性心率 | β受体拮抗剂基础上LVEF≤35%、心功能Ⅱ~Ⅳ级、窦性心律、HR≥70次/分 |
| 维立西呱（sGC刺激剂） | 增强NO-sGC-cGMP信号通路 | 近期心衰失代偿后稳定、LVEF<45%的症状性心衰 |

> 慢性心衰治疗不推荐常规使用血管扩张药物，仅在伴有心绞痛或高血压时可考虑联合治疗。

#### 非药物治疗

| 治疗 | 适应证 |
|------|--------|
| CRT（心脏再同步治疗） | 优化药物治疗3个月以上仍持续症状、窦性心律、NYHA Ⅱ~Ⅳ级、LVEF≤35%、QRS>130ms |
| ICD（植入型心律转复除颤器） | LVEF≤35%的NYHA Ⅱ~Ⅲ级病人的一级预防；心搏骤停幸存者的二级预防 |
| LVAD（左室辅助装置） | 心脏移植术前过渡治疗和终末期心衰替代治疗 |
| 心脏移植 | 终末期心衰的最终治疗方法 |

### 急性心力衰竭的治疗

#### 初始评估和紧急干预

首先评估是否存在循环或呼吸衰竭——1小时内纠正休克和呼吸衰竭。迅速识别需要紧急处理的病因：[[急性心肌梗死|急性冠脉综合征]]、高血压急症、严重心律失常、急性肺栓塞、心脏压塞等。

#### 一般处理

| 措施 | 说明 |
|------|------|
| 体位 | 半卧位或端坐位，双腿下垂，减少静脉回流 |
| 吸氧 | 立即高流量鼻管给氧 |
| 镇静 | 吗啡3~5mg静脉注射，用于急性肺水肿病人，舒张小血管减轻心脏负荷 |
| 容量管理 | 监测24小时出入液量，保持液体负平衡 |

#### 按临床分型治疗（干湿冷暖分型）

| 分型 | 淤血 | 低灌注 | 治疗方案 |
|------|------|--------|----------|
| "干暖"型 | 无 | 无 | 调整口服药物即可 |
| "干冷"型 | 无 | 有 | 适当扩容，无效则给正性肌力药 |
| "湿暖"型 | 有 | 无 | 高血压型首选血管扩张剂+利尿剂；淤血型首选利尿剂+血管扩张剂 |
| "湿冷"型 | 有 | 有 | 收缩压≥90mmHg给血管扩张剂+利尿剂，无效加正性肌力药；收缩压<90mmHg首选正性肌力药，无效用血管收缩药 |

#### 药物治疗

| 药物类别 | 代表药物 | 特点 |
|----------|----------|------|
| **利尿剂** | 呋塞米静脉注射 | 首选静脉袢利尿剂，保持出入量负平衡 |
| **血管扩张剂** | 硝普钠 | 动静脉双重扩张，适用于严重心衰伴肺水肿。含氰化物，使用不超过72小时 |
| | 硝酸酯类（硝酸甘油） | 扩张小静脉，降低回心血量。适用于合并高血压、冠心病、二尖瓣反流 |
| | α受体拮抗剂（乌拉地尔） | 扩张动脉，用于合并高血压、主动脉夹层 |
| | rhBNP（重组人脑利钠肽） | 扩张静脉和动脉，兼有利钠利尿和抑制RAAS、交感神经作用 |
| **正性肌力药** | 多巴胺/多巴酚丁胺 | β受体激动剂，短期使用改善低灌注；长期使用β受体拮抗剂的病人不推荐 |
| | 左西孟旦 | 钙离子增敏剂，增加心肌收缩力并扩张血管 |
| | 洋地黄类（毛花苷丙） | 主要用于房颤伴快速心室率（>110次/分）者 |
| **血管收缩剂** | 去甲肾上腺素 | 用于正性肌力药无效的显著低血压病人 |

#### 非药物治疗（急性心衰）

- 机械通气（无创CPAP/BiPAP或气管插管）
- 连续性肾脏替代治疗（CRRT）：高容量负荷对利尿剂抵抗、肾功能严重受损者
- 机械辅助循环支持：IABP、ECMO、LVAD

## 预后

心衰的预后取决于基础病因、心功能分级、治疗依从性和合并症。通过治疗只能延缓而不能逆转心衰分期。A期和B期病人通过积极干预可阻止进展为症状性心衰，D期心衰5年生存率极低，心脏移植是最终治疗选项。
