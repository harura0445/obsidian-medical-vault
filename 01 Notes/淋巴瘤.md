# 淋巴瘤（Lymphoma）

## 概述

[[淋巴瘤]]（lymphoma）是起源于[[淋巴结]]和[[肠相关淋巴组织|淋巴组织]]的**恶性肿瘤**，属于免疫系统的恶性肿瘤。根据病理类型不同，淋巴瘤可分为**霍奇金淋巴瘤**（Hodgkin Lymphoma, [[霍奇金淋巴瘤|HL]]）和**非霍奇金淋巴瘤**（non-Hodgkin Lymphoma, [[非霍奇金淋巴瘤|NHL]]）两大类。

### 流行病学

- 我国发病率：约 6.68/10 万
- 男性发病率：7.71/10 万
- 女性发病率：16.6/10 万（B细胞淋巴瘤）、11.2/10 万（T/NK细胞淋巴瘤）
- 死亡率：约 3.75/10 万
- HL 占所有淋巴瘤的 **8%-11%**，NHL 占 **89%-91%**
- HL 好发于 **25-40岁** 和 **60岁以上** 双峰分布
- NHL 好发于 **60-75岁** 老年人

## 病因与危险因素

### 感染因素

- **[[EB病毒]]**（Epstein-Barr virus, EBV）：1976 年发现与[[伯基特淋巴瘤|Burkitt淋巴瘤]]密切相关
- **[[人类T淋巴细胞病毒]]**（HTLV-I/II）：与成人T细胞白血病/淋巴瘤（[[成人T细胞白血病/淋巴瘤|ATLL]]）相关
- 人类疱疹病毒 8 型（HHV-8）：与原发性渗出性淋巴瘤相关
- **[[幽门螺杆菌]]**（HP）：与胃 [[MALT淋巴瘤]] 相关

### 其他因素

- **免疫功能低下**：器官移植后免疫抑制治疗、[[HIV]]感染/AIDS患者
- **[[自身免疫性疾病]]**：如 [[干燥综合征]]、[[系统性红斑狼疮]] 等
- **环境因素**：放射线暴露、化学毒物接触
- **遗传因素**：染色体 **-6、-8** 异常等

### 病理机制

恶性淋巴细胞在淋巴结或结外淋巴组织内**克隆性增生**，形成肿块，破坏正常淋巴结结构，并可侵犯全身各器官。

## 病理分型/分类

### 霍奇金淋巴瘤（HL）的分类

根据 2016 年 WHO 分类，HL 分为：

1. **结节性淋巴细胞为主型霍奇金淋巴瘤**（Nodular lymphocyte predominant Hodgkin lymphoma, [[NLPHL]]）
2. **经典型霍奇金淋巴瘤**（Classical Hodgkin lymphoma, [[CHL]]）
   - 结节硬化型经典型霍奇金淋巴瘤（Nodular sclerosis CHL, [[NSCHL]]）
   - 混合细胞型经典型霍奇金淋巴瘤（Mixed cellularity CHL, [[MCCHL]]）
   - 淋巴细胞丰富型经典型霍奇金淋巴瘤（Lymphocyte-rich CHL, [[LRCHL]]）
   - 淋巴细胞消减型经典型霍奇金淋巴瘤（Lymphocyte-depleted CHL, [[LDCHL]]）

### 非霍奇金淋巴瘤（NHL）的分类

NHL 根据细胞来源分为 **B细胞**、**T细胞** 和 **NK细胞** 三大类。

#### B细胞淋巴瘤（WHO 2016 分类）

| 分类 | 常见类型 |
|------|---------|
| 前体B细胞肿瘤 | B淋巴母细胞白血病/淋巴瘤 |
| **成熟B细胞肿瘤** | [[慢性淋巴细胞白血病]]/[[小淋巴细胞淋巴瘤]]（CLL/SLL）、[[B幼淋巴细胞白血病]]（B-PLL）、[[脾边缘区淋巴瘤]]（SMZL）、[[毛细胞白血病]]（HCL） |
| **MALT淋巴瘤** | 结外边缘区淋巴瘤（MALT lymphoma）、[[淋巴结边缘区淋巴瘤]]（NMZL） |
| **滤泡性淋巴瘤** | [[滤泡性淋巴瘤]]（FL） |
| **套细胞淋巴瘤** | [[套细胞淋巴瘤]]（MCL） |
| **弥漫大B细胞淋巴瘤** | [[弥漫大B细胞淋巴瘤]]（DLBCL, NOS）、生发中心B细胞型（GCB）、活化B细胞型（non-GCB） |
| **伯基特淋巴瘤** | [[伯基特淋巴瘤]]（Burkitt lymphoma） |
| **高级别B细胞淋巴瘤** | 伴MYC和BCL2和/或BCL6重排（[[HGBL]]） |

#### T/NK细胞淋巴瘤（WHO 2016 分类）

| 分类 | 常见类型 |
|------|---------|
| **T幼淋巴细胞白血病** | [[T幼淋巴细胞白血病]]（T-PLL） |
| **T大颗粒淋巴细胞白血病** | [[T大颗粒淋巴细胞白血病]]（T-LGL） |
| **侵袭性NK细胞白血病** | [[侵袭性NK细胞白血病]] |
| **结外NK/T细胞淋巴瘤** | [[结外NK/T细胞淋巴瘤]]（鼻型） |
| **肠道T细胞淋巴瘤** | [[肠病相关T细胞淋巴瘤]]（EATL） |
| **肝脾T细胞淋巴瘤** | [[肝脾T细胞淋巴瘤]]（HSTL） |
| **皮下脂膜炎样T细胞淋巴瘤** | [[皮下脂膜炎样T细胞淋巴瘤]]（SPTCL） |
| **蕈样肉芽肿** | [[蕈样肉芽肿]]（MF）/ [[Sezary综合征]]（SS） |
| **间变大细胞淋巴瘤** | [[间变大细胞淋巴瘤]]（ALCL, ALK+/ALK-） |
| **血管免疫母细胞T细胞淋巴瘤** | [[血管免疫母细胞T细胞淋巴瘤]]（AITL） |

### 免疫表型

#### 霍奇金淋巴瘤

- R-S 细胞（[[Reed-Sternberg细胞]]）：CD30⁺、CD15⁺（经典型HL）
- 肿瘤细胞表面常表达 CD25

#### B细胞淋巴瘤

- **B细胞标志**：[[CD19]]⁺、[[CD20]]⁺、[[CD22]]⁺、[[CD79a]]⁺、[[PAX5]]⁺
- **滤泡性淋巴瘤**：CD10⁺、BCL-2⁺、t(14;18) 易位
- **套细胞淋巴瘤**：CD5⁺、Cyclin D1⁺
- **DLBCL**：根据免疫表型分为 GCB 型和非 GCB 型（ABC 型）

#### T细胞淋巴瘤

- **T细胞标志**：CD3⁺、CD4⁺、CD8⁺
- **ALCL**：CD30⁺、t(2;5) 易位、ALK 表达
- **蕈样肉芽肿**：CD4⁺、CD8⁻

## 临床表现

### 共性（HL 与 NHL 的共同表现）

- **不明原因的[[发热]]**：持续性发热（>38℃）
- **无痛性淋巴结肿大**：最常见首发症状
- **[[盗汗]]**：夜间大量出汗
- **体重下降**：6个月内不明原因体重下降 >10%

![[04 Attachments/内科学-淋巴瘤-临床表现共性差异.webp]]

### 差异（HL 与 NHL 的区别）

#### 霍奇金淋巴瘤（HL）

> 淋巴结向心性分布，好发于青年

**首见症状**：
- 无痛性颈部或锁骨上淋巴结肿大

**压迫症状**：
- 疼痛
- 纵隔压迫：咳嗽、胸闷、气急
- [[上腔静脉压迫综合征]]

**全身症状**：
- [[发热]]
- 乏力
- 全身皮肤瘙痒（HL 特征性表现）
- 饮酒后淋巴结疼痛（HL 特征性表现）

**浸润症状**：
- 肺浸润
- 胸腔积液
- 胸腰椎骨质破坏

**血常规特点**：
- 常有轻度[[贫血]]
- 部分患者嗜酸粒细胞升高
- 骨髓涂片可找到 R-S 细胞（[[Reed-Sternberg细胞]]）

![[04 Attachments/内科学-淋巴瘤-HL临床表现.webp]]

#### 非霍奇金淋巴瘤（NHL）

> 淋巴结跳跃性分布，可见于各年龄组，男性多于女性；发展迅速，易于播散，结外倾向明显

**淋巴结肿大**：
- 颈和锁骨上淋巴结肿大（无痛性）为首见表现
- 呈**跳跃性分布**（区别于 HL 的向心性分布）
- 有结外浸润，压迫症状广泛

**咽淋巴环受累**（10%-15%）：
- 吞咽困难
- 鼻塞

**结外器官广泛受累**：

| 部位 | 发生率与表现 |
|------|------------|
| **胃肠道** | NHL 最常见的结外部位（约 33.5%），可累及食管、胃、小肠、大肠 |
| **骨髓** | 1/3 ～ 2/3 患者可受累 |
| **中枢神经系统** | 约 10%，累及脑膜和脊髓 |
| **骨** | 溶骨性破坏，胸腰椎最多见，其次为股骨、肋骨、骨盆、颅骨 |
| **肾脏** | 约 33.5% |
| **皮肤** | 肿块、皮下结节、溃疡 |
| **肝与脾** | 肝脾肿大 |
| **肺与纵隔** | 肺门及纵隔受累 |
| **胸部** | 肺、胸膜、心脏、胸壁 |
| **泌尿生殖系统** | 可受累 |
| **其他** | 甲状腺、乳腺、胸腺、肾上腺等 |

**全身表现**：
- [[发热]]、[[盗汗]]、体重下降（B 症状）
- 皮肤病变
- 神经系统症状
- [[贫血]]
- **合并白血病**：低分化 NHL 易合并白血病，大多为急性淋巴细胞白血病
- 血液异常
- 免疫反应

**血常规特点**：
- 少数患者淋巴细胞绝对数和相对值增高
- 骨髓细胞可找到异常淋巴细胞
- 骨活检可发现淋巴瘤细胞浸润，提高诊断率

## 辅助检查

### 实验室检查

| 检查项目 | 临床意义 |
|---------|---------|
| **[[LDH]]** | 升高提示肿瘤负荷大，预后不良 |
| **AKP（碱性磷酸酶）** | 升高提示骨髓侵犯 |
| **β2-微球蛋白（[[β2-MG]]）** | 升高提示肿瘤负荷大 |
| **[[CRP]]（C反应蛋白）** | 炎症/肿瘤活动指标 |
| **[[ESR]]（血沉）** | 增快提示疾病活动 |
| **血常规** | 可有 [[贫血]]、血小板减少 |
| **血清铁蛋白** | 升高提示肿瘤负荷 |
| **可溶性CD25（sCD25）** | T细胞淋巴瘤活动指标 |

### 影像学检查

- **[[CT检查|CT]]**：评估纵隔、腹膜后、盆腔淋巴结及脏器受累
- **[[MRI]]**：评估中枢神经系统及骨髓侵犯
- **[[PET-CT]]**：**金标准**——用于分期、疗效评估和复发监测
  - 标准化摄取值（SUV）反映肿瘤代谢活性
  - Deauville 评分标准用于疗效判断

![[04 Attachments/内科学-淋巴瘤-辅助检查.webp]]

### 特殊检查

- **[[骨髓细胞学检测|骨髓穿刺+活检]]**：明确骨髓是否受累
- **[[淋巴结活检]]**：**确诊金标准**——完整淋巴结切除活检
- **[[免疫组化]]**（IHC）：明确免疫表型和分型
- **[[流式细胞术]]**：检测细胞表面标志
- **PCR** 检测：
  - **TCR 基因重排**（T细胞淋巴瘤）
  - **IgH 基因重排**（B细胞淋巴瘤）
  - **bcl-2 易位**：t(14;18)（FL）
  - **bcl-6 重排**（DLBCL）
- **染色体核型分析**：t(14;18)、t(8;14)、t(2;5) 等

## 诊断与分期

### 诊断标准

**确诊依靠病理活检**（完整淋巴结切除或粗针穿刺），结合免疫组化、流式细胞术和分子检测完成分型诊断。

### Ann Arbor 分期（Cotswolds 修订版）

| 分期 | 累及范围 |
|------|---------|
| **I期** | 单个淋巴结区域（I）或单个结外器官局限受累（I_E） |
| **II期** | 横膈同侧两个或以上淋巴结区域（II），可伴同侧局限结外器官受累（II_E） |
| **III期** | 横膈两侧淋巴结区域受累（III），可伴脾脏受累（III_S）、结外器官局限受累（III_E）或两者兼有（III_SE） |
| **IV期** | 弥漫性结外器官受累，如骨髓、肝脏、肺、脑等 |

**全身症状分组**：
- **A组**：无 B 症状
- **B组**：有 B 症状（不明原因发热 >38℃、盗汗、6个月内体重下降 >10%）

![[04 Attachments/内科学-淋巴瘤-AnnArbor分期.webp]]

### 预后评估

#### 国际预后指数（IPI）

适用于侵袭性 NHL（如 DLBCL）：
- 年龄 >60 岁
- LDH >正常上限
- ECOG ≥2 分
- Ann Arbor III-IV 期
- 结外受累 >1 处

**危险分层**：0-1 分（低危）、2 分（低中危）、3 分（高中危）、4-5 分（高危）

#### 其他预后指数

| 类型 | 预后指数 |
|------|---------|
| DLBCL | **IPI**、**aaIPI**（年龄调整IPI） |
| 滤泡性淋巴瘤 | **FLIPI**、**FLIPI2** |
| 套细胞淋巴瘤 | **MIPI** |
| 外周T细胞淋巴瘤 | **PIT** |
| HL | **IPS**（国际预后评分） |
| NK/T细胞淋巴瘤 | **KPI** |

## 治疗

### 霍奇金淋巴瘤的治疗

#### 化疗方案

**ABVD 方案**（HL 一线标准化疗）：

| 药物 | 剂量（mg/m²） | 给药途径 | 给药时间 |
|------|--------------|---------|---------|
| ADM（[[阿霉素]]/多柔比星） | 25 | IV | d1, d15 |
| BLM（[[博来霉素]]） | 10 | IV | d1, d15 |
| VCR（[[长春新碱]]） | 6 | IV | d1, d15 |
| DTIC（[[达卡巴嗪]]） | 375 | IV | d1, d15 |

**COPP 方案**：用于不能耐受 ABVD 的患者

#### 放疗

- **60Co** 或直线加速器局部放疗
- 剂量：**40-50 Gy**（病灶区）
- 可用于早期 HL 或化疗后残留病灶
- 近年来提倡 **"Y"型野** 或 **"斗篷野"** 放疗

![[04 Attachments/内科学-淋巴瘤-ABVD方案.webp]]

### 非霍奇金淋巴瘤的治疗

#### 一线化疗方案

**CHOP 方案**（NHL 一线标准化疗）：

| 药物 | 剂量 | 给药途径 | 给药时间 |
|------|------|---------|---------|
| CTX（[[环磷酰胺]]） | 750 mg/m² | IV | d1 |
| ADM（[[阿霉素]]/多柔比星） | 50 mg/m² | IV | d1 |
| VCR（[[长春新碱]]） | 1.4 mg/m²（最大 2 mg） | IV | d1 |
| PDN（[[泼尼松]]） | 100 mg | PO | d1-d5 |

周期：每 **21 天** 为一周期，共 **2-3 周期**，通常完成 **6 周期**

![[04 Attachments/内科学-淋巴瘤-CHOP方案.webp]]

#### 挽救化疗方案（复发/难治）

| 方案 | 主要药物 |
|------|---------|
| **ICE** | [[异环磷酰胺]]、卡铂、[[依托泊苷]] |
| **DHAP** | [[地塞米松]]、高剂量阿糖胞苷、顺铂 |
| **ESHAP** | 依托泊苷、甲泼尼龙、高剂量阿糖胞苷、顺铂 |
| **HY-CVAD** | 环磷酰胺、长春新碱、阿霉素、地塞米松 |
| **EPOCH** | 依托泊苷、泼尼松、长春新碱、环磷酰胺、阿霉素 |
| **CHOPE** | CHOP + 依托泊苷 |

#### 免疫治疗与靶向治疗

1. **[[利妥昔单抗]]**（Rituximab）：抗 CD20 单克隆抗体——B细胞淋巴瘤一线
2. **[[靶向药物|BTK抑制剂]]**：伊布替尼等——套细胞淋巴瘤、CLL
3. **[[免疫调节剂]]**：来那度胺
4. **PD-1/PD-L1 抑制剂**：用于复发难治 HL
5. **[[抗体药物偶联物]]**（ADC）：Brentuximab vedotin（抗CD30）
6. **双特异性抗体**（BiTE）
7. **[[CAR-T细胞治疗]]**：复发/难治 B 细胞淋巴瘤

### 造血干细胞移植

- **自体造血干细胞移植**（[[造血干细胞移植|auto-HSCT]]）：化疗敏感复发患者
- **异基因造血干细胞移植**（[[造血干细胞移植|allo-HSCT]]）：年轻高危/难治患者
- 适用于 **<65 岁**、无严重器官功能障碍的患者

## 预后

### 霍奇金淋巴瘤的预后

- **早期 HL（I-II 期）**：5 年生存率约 **94.3%**
- **晚期 HL（III-IV 期）**：5 年生存率约 **27.4%**
- IPS 评分越高，预后越差

### 非霍奇金淋巴瘤的预后

- NHL 的预后高度依赖**病理亚型**和**IPI 评分**
- 侵袭性 NHL（DLBCL）经 R-CHOP 治疗后 5 年生存率约 60-70%
- 惰性 NHL（FL、CLL/SLL）中位生存期 7-10 年
- III-IV 期、LDH >500 U/L、≥2 处结外受累为不良预后因素

## 预防

- 避免 [[EBV]]、[[HTLV]] 等病毒感染
- 根除 [[幽门螺杆菌]]（HP）可降低胃 MALT 淋巴瘤风险
- 避免有害化学物质和过度放射线暴露
- 积极治疗 [[自身免疫性疾病]]
- 定期体检，发现无痛性淋巴结肿大及时就医
