# 特发性血小板减少性紫癜

> 一种以血小板过度破坏和生成减少为特点的自身免疫病，是临床上最常见的出血性疾病，年发病率（5~10）/10万。

## 概述

原发免疫性血小板减少症（ITP），既往称特发性血小板减少性紫癜，以**自身抗体介导的血小板破坏**和**巨核细胞生成血小板不足**为核心机制。成人ITP多呈慢性经过，育龄期女性发病率高于男性，60岁以上人群发病率为60岁以下人群的2倍。

## 病因与发病机制

病因未明。发病机制涉及两个主要环节：

| 机制 | 具体过程 |
|------|----------|
| **血小板破坏增加** | 50%~70%患者可检出抗血小板糖蛋白自身抗体 → 致敏血小板被单核-巨噬系统吞噬；CTL直接破坏血小板 |
| **血小板生成不足** | 自身抗体损伤巨核细胞或抑制其释放血小板；CTL抑制巨核细胞凋亡；TPO水平相对不足 |

## 临床表现

| 表现 | 特点 |
|------|------|
| 皮肤黏膜出血 | 瘀点、瘀斑、鼻出血、牙龈出血、**月经过多**，外伤后止血不易 |
| 严重出血 | 内脏出血、颅内出血（可危及生命） |
| 乏力 | 部分患者明显 |
| 失血性贫血 | 出血过多或长期月经过多所致 |
| 脾脏 | **一般不大**（重要鉴别点） |

部分患者仅有血小板减少而无出血症状。

## 实验室检查

| 检查项目 | 结果 |
|----------|------|
| 血小板计数 | **减少**，血小板平均体积偏大 |
| 凝血功能 | PT、APTT **正常** |
| 出血时间 | **延长** |
| 束臂试验 | 阳性 |
| 骨髓象 | 巨核细胞数正常或增加，**成熟障碍**，产板型巨核细胞显著减少 |
| 自身抗体 | ~70%患者抗血小板糖蛋白自身抗体阳性 |
| TPO水平 | 正常或轻度升高 |

## 诊断与鉴别诊断

### 诊断要点（排除性诊断）

1. 至少2次检查血小板计数减少，血细胞形态无异常
2. 体检**脾一般不大**
3. 骨髓检查：巨核细胞数正常或增多，有成熟障碍
4. **排除其他继发性血小板减少症**

### 分型与分期

| 分型 | 定义 |
|------|------|
| 新诊断ITP | 确诊后3个月以内 |
| 持续性ITP | 确诊后3~12个月血小板持续减少 |
| 慢性ITP | 血小板减少持续超过12个月 |
| 重症ITP | 血小板＜10×10⁹/L，伴活动性出血 |
| 难治性ITP | 一线、二线治疗及脾切除均无效 |

### 鉴别诊断

须排除：假性血小板减少、[[再生障碍性贫血]]、脾功能亢进、骨髓增生异常性肿瘤、[[白血病]]、[[系统性红斑狼疮]]、药物性免疫性血小板减少等。

## 治疗

治疗目标：**以最小毒性维持血小板在安全水平以上**，减少出血、提高生活质量。血小板＞30×10⁹/L且无出血倾向者可观察随访。

### 急症处理

适用于血小板＜10×10⁹/L伴严重出血、颅内出血、近期手术/分娩者：

| 措施 | 剂量/方案 |
|------|-----------|
| IVIG | 400mg/(kg·d)×5天；或1.0g/(kg·d)×2天 |
| 大剂量甲泼尼龙 | 1g/d×3天，静脉滴注 |
| 促血小板生成药物 | rhTPO、艾曲泊帕、罗普司亭等 |
| 血小板输注 | 仅用于危及生命的出血 |

### 一线治疗

| 药物 | 方案 |
|------|------|
| **大剂量地塞米松** | 40mg/d×4天，无效者10天后可重复 |
| **泼尼松** | 1mg/(kg·d)，起效后尽快减量，6~8周内停用 |
| IVIG | 用于急症、不能耐受激素者、妊娠/分娩前 |

### 二线治疗

适用于初始激素治疗失败或半年内复发者：

| 方案 | 要点 |
|------|------|
| **促血小板生成药物** | rhTPO、艾曲泊帕、海曲泊帕、阿伐曲泊帕、罗普司亭，1~2周起效，须个体化维持 |
| **抗CD20单抗**（利妥昔单抗） | 375mg/m²每周1次×4次，用药后4~8周起效 |
| **脾切除** | 激素无效且确诊≥12~24个月，术前须接种疫苗 |

### 三线治疗

- 地西他滨：3.5mg/(m²·d)×3天，间隔3周，共3~6周期
- 全反式维A酸（ATRA）+ 达那唑联合
- 长春新碱、环孢素、硫唑嘌呤、吗替麦考酚酯等（个体化选择）

## 预后

ITP目前尚不能根治，多数患者经治疗后血小板可达安全水平。出血风险随年龄增高而增加，颅内出血是主要致死原因。
