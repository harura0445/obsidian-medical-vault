# 阑尾疾病

## 解剖生理

- 阑尾起于盲肠末端，位于右髂窝，体表投影：**McBurney点**（脐与右髂前上棘连线中外1/3交点）
- 阑尾动脉：回结肠动脉终末支（无侧支循环），血供障碍易致坏疽穿孔
- 阑尾静脉：回流至回结肠静脉→肠系膜上静脉→门静脉，感染可致**门静脉炎**和肝脓肿
- 阑尾系膜：短于阑尾本身→阑尾弯曲
- 阑尾是淋巴器官，具有一定的免疫功能

## 急性阑尾炎

### 病因

| 因素 | 机制 |
|------|------|
| 管腔梗阻 | 最常见原因——粪石、淋巴滤泡增生、异物、肿瘤 |
| 细菌入侵 | 梗阻后管腔内细菌大量繁殖（大肠埃希菌、厌氧菌） |
| 神经反射 | 胃肠道功能紊乱→阑尾痉挛→管腔狭窄 |

### 病理分型

| 类型 | 病理改变 |
|------|----------|
| 单纯性阑尾炎 | 黏膜及黏膜下层炎症，浆膜充血 |
| 化脓性阑尾炎 | 全层化脓，浆膜面脓性渗出物 |
| 坏疽性阑尾炎 | 管壁坏死呈暗紫色，易穿孔 |
| 阑尾周围脓肿 | 穿孔后炎症被大网膜和周围组织包裹 |

### 临床表现

**主要症状**：

| 症状 | 特点 |
|------|------|
| **转移性右下腹痛** | 最典型——初为脐周或上腹部隐痛→数小时后转移至右下腹并固定 |
| 恶心呕吐 | 早期反射性 |
| 发热 | 一般为低热，寒战高热提示静脉炎或穿孔 |
| 其他 | 腹泻（盆腔位阑尾）、尿频（盲肠后位阑尾刺激输尿管） |

**主要体征**：

| 体征 | 说明 |
|------|------|
| **右下腹局限性压痛** | McBurney点最明显 |
| **反跳痛** | 腹膜炎体征 |
| **腹肌紧张** | 病变加重→局限性腹膜炎 |
| 结肠充气试验（Rovsing征） | 按压左下腹→右下腹痛 |
| 闭孔肌试验 | 内旋髋关节→疼痛（盆腔位阑尾炎） |
| 腰大肌试验 | 右髋后伸→疼痛（盲肠后位阑尾炎） |

**辅助检查**：
- 血常规：WBC↑、中性粒比例↑
- 超声：阑尾增粗、壁增厚、周围积液/脓肿
- CT：增强CT诊断准确率高（怀疑时可做）

### 诊断与鉴别诊断

根据转移性右下腹痛+McBurney点压痛+白细胞升高，诊断不难。主要鉴别：

| 疾病 | 鉴别要点 |
|------|----------|
| 急性胃肠炎 | 恶心呕吐腹泻为主，腹痛位置不固定 |
| 右侧输尿管结石 | 腰背部放射痛、血尿、肾区叩痛 |
| 消化性溃疡穿孔 | 有溃疡病史、突发上腹剧痛、板状腹、膈下游离气体 |
| Meckel憩室炎 | 术前难鉴别，常术中发现 |
| 妇科急症（右侧异位妊娠、卵巢囊肿扭转、盆腔炎） | 育龄女性须排除——妊娠试验、妇科超声 |

### 治疗原则

**一经诊断，尽早手术**（除非已形成阑尾周围脓肿）。

**手术治疗**：

| 术式 | 要点 |
|------|------|
| 开腹阑尾切除术 | 经典术式，经McBurney切口 |
| 腹腔镜阑尾切除术 | 恢复快、创伤小，已成为主流 |

**非手术治疗**：仅适用于早期单纯性阑尾炎、或阑尾周围脓肿形成初期。使用有效抗生素+支持治疗。

**阑尾周围脓肿**：先行保守治疗，炎症消退3个月后行择期阑尾切除术。若脓肿增大，穿刺引流。

### 并发症

| 并发症 | 说明 |
|--------|------|
| 穿孔 | 弥漫性腹膜炎，发生率随病程延长增加 |
| 阑尾周围脓肿 | 穿孔后包裹 |
| 门静脉炎 | 感染栓子经阑尾静脉→门静脉→肝脓肿 |
| 腹腔脓肿 | 弥漫性腹膜炎后 |

### 特殊类型阑尾炎

| 类型 | 特点 |
|------|------|
| **小儿阑尾炎** | 体征不典型、易穿孔、弥漫性腹膜炎、全身症状重 |
| **老年阑尾炎** | 症状轻体征轻→易延误→穿孔率高 |
| **妊娠阑尾炎** | 阑尾位置随子宫增大上移→压痛位置偏高；手术相对安全（中孕最佳），保守有流产风险 |
| **异位阑尾炎** | 盲肠未降至右髂窝（高位/盆腔位/左侧）→症状不典型 |

## 慢性阑尾炎

- 多有急性阑尾炎发作史
- 反复右下腹隐痛或不适
- 查体：右下腹局限性压痛
- 钡灌肠：阑尾不充盈或充盈不规则
- 治疗：择期阑尾切除术
