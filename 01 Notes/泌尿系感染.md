# 泌尿系统感染

## 概述

致病菌侵入泌尿系统引起的炎症反应。最常见的细菌感染之一。

### 致病菌

| 致病菌 | 占比 | 说明 |
|--------|------|------|
| **大肠埃希菌** | ~80% | 绝大多数社区获得性UTI |
| 变形杆菌 | 5%~10% | 与结石形成有关（产脲酶菌→尿液碱化→磷酸铵镁结石） |
| 肺炎克雷伯菌 | 5% | 常见于糖尿病患者 |
| 铜绿假单胞菌 | — | 院内感染、器械操作后 |
| 粪肠球菌 | — | 复杂性UTI |

### 感染途径

| 途径 | 特点 |
|------|------|
| **上行感染** | **最常见**——细菌从尿道外口→尿道→膀胱→输尿管→肾盂 |
| 血行感染 | 少见——菌血症播散至肾 |
| 淋巴感染 | 罕见 |
| 直接蔓延 | 邻近器官感染→泌尿系统 |

### 分类

- **非复杂性UTI**：结构/功能正常的泌尿系统
- **复杂性UTI**：伴有解剖/功能异常的泌尿系统（结石、梗阻、留置尿管、免疫抑制等）

## 急性肾盂肾炎

感染累及肾盂和肾实质。

### 临床表现

| 表现 | 特点 |
|------|------|
| **发热** | 寒战、高热（>38.5℃），弛张热 |
| 腰背痛 | 单侧或双侧肾区叩击痛（+） |
| 膀胱刺激征 | 尿频、尿急、尿痛 |
| 全身中毒症状 | 恶心呕吐、乏力、纳差 |

### 诊断

尿常规（**白细胞尿/脓尿**、镜下血尿、蛋白尿）+ 尿培养（菌落计数>10⁵ CFU/ml）+ 血培养（发热者）；超声/CT排除梗阻。

### 治疗

- **抗生素**：经验性用头孢三代/氟喹诺酮→根据药敏调整（疗程7~14天）
- 充分饮水+对症降温
- 梗阻性肾盂肾炎→紧急引流（输尿管支架/肾造瘘）

## 急性膀胱炎

- **临床表现**：**尿频、尿急、尿痛**（三联征）+ 耻骨上区不适/疼痛，一般无发热
- **诊断**：尿常规（WBC/RBC+）+ 尿培养
- **治疗**：短程抗生素（3天）——复方新诺明/磷霉素/呋喃妥因

---

## 泌尿系统结核

几乎全部为继发性，原发灶多为肺结核。结核分枝杆菌→血行播散至肾皮质→形成结核性肉芽肿→干酪样坏死→破坏肾实质和尿路。

### 临床表现

- **慢性持续性膀胱刺激征**（最为突出，尿频、尿急、尿痛）——抗生素治疗无效
- 终末血尿、脓尿
- 肾区叩痛
- 全身结核中毒症状（晚期）

### 诊断

- **尿抗酸杆菌培养**：**诊断金标准**，但培养时间长（6~8周）
- 尿液分子生物学（PCR-TB）：快速
- IVP/CT：肾盏破坏、输尿管串珠样狭窄、肾自截

### 治疗

- **药物治疗为主**：异烟肼+利福平+吡嗪酰胺+乙胺丁醇（6~9个月标准方案）
- 手术：一侧严重毁损→肾切除术（前提：对侧肾功能正常）
