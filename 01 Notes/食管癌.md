# 食管癌（Esophageal Carcinoma）


---

## 概述

- **定义**：食管癌是发生于食管上皮的恶性肿瘤，是我国常见的消化道恶性肿瘤之一
- **流行病学**：
  - 我国食管癌以**鳞状细胞癌**为主（约80%），欧美以**腺癌**为主
  - 发病年龄高峰：**60~64岁**
  - 男女比例：1.3~2.7:1
  - 总体5年生存率约 **30%**

### 食管解剖要点

- **位置**：C6~Th11，长20~25cm（门齿—贲门约35~40cm）
- **临床分段**：颈段、胸段（上/中/下段）、腹段
- **四个生理狭窄**（异物滞留和癌的好发部位）：
  1. 颈部起始处（距门齿15cm）
  2. 主动脉弓斜跨处（距门齿22cm）
  3. 左主支气管跨过处（距门齿27cm）
  4. 膈肌裂孔处（距门齿40cm）

![[04 Attachments/外科学-食管癌-解剖-四个狭窄.webp]]

- **组织结构**：
  - 黏膜层：[[食管|复层鳞状上皮为主]]，下端渐变为柱状上皮
  - 肌层：内层环形肌（横纹肌+平滑肌），外层纵行肌
- **血液供应**：上段—甲状腺下动脉；中段—主动脉/支气管动脉食管支；下段—胃后/脾动脉分支
- **淋巴引流**：上段→颈淋巴结；中段→气管/支气管/后纵隔/膈淋巴结；下段→腹腔淋巴结
- **神经支配**：主要为迷走神经（副交感）和交感干

## 病因与发病机制

病因尚不完全明确，已知相关因素：

1. **亚硝胺类化合物**：存在于水、饮食中，也可体内合成，是强致癌剂
2. **微量元素缺乏**：钼、锌、钛等
3. **霉菌**：动物实验显示霉菌可诱发食管癌（白地霉菌、串珠镰刀菌等）
4. **饮食习惯**：烫、粗、硬、快食等物理刺激
5. **吸烟饮酒**：是重要危险因素
6. **遗传易感性**：约60%有家族史
7. **慢性炎症**：长期炎症刺激上皮增生 → 不典型增生

### 癌前病变

- [[Barrett食管]]（食管下段鳞状上皮被柱状上皮替代 → 食管腺癌风险↑）
- 食管慢性炎症伴不典型增生
- 相关笔记：[[消化道癌]]

## 病理分型与分期

### 病理类型

| 类型 | 占比 | 特点 |
|------|------|------|
| **鳞状细胞癌** | 我国约80%，欧美约50% | 最常见 |
| **腺癌** | 下段多见 | 起源于柱状上皮 |
| **混合癌** | 少见 | — |

### 病变分布

- **发病部位**：上段15%，中段50%（最常见），下段35%
- **病变特点**：跳跃性生长，可发生食管—胃双原发癌

### 临床大体分型

**早期食管癌**（局限于黏膜/黏膜下层）：
- 隐伏型、糜烂型、斑块型、乳头型

**中晚期食管癌**：
- **髓质型**：肿瘤在食管壁内浸润性生长，管壁增厚
- **蕈伞型**：肿瘤呈蘑菇状突入管腔
- **溃疡型**：肿瘤形成深溃疡，穿透管壁
- **缩窄型（硬化型）**：环形浸润，管腔严重狭窄

![[04 Attachments/外科学-食管癌-中晚期大体分型.webp]]

### 转移途径

1. **直接浸润**：侵犯邻近器官（气管、主动脉、心包等）
2. **淋巴转移**：最常见，呈跳跃性转移（上段→颈淋巴结；中段→纵隔；下段→腹腔）
3. **血行转移**：晚期可转移至肝、肺、骨等

### TNM分期（UICC第8版）

| 分期 | 标准 |
|------|------|
| **T分期** | Tis(高度不典型增生)→T1(黏膜/黏膜下层)→T2(肌层)→T3(纤维膜)→T4(邻近器官) |
| **N分期** | N0(无转移)→N1(1-2个)→N2(3-6个)→N3(≥7个) |
| **M分期** | M0(无远处转移)→M1(有远处转移) |
| **G分期** | G1(高分化)→G2(中分化)→G3(低分化)→G4(未分化) |

> **早期食管癌**定义为 T1aN0M0
> **局部晚期/进展期食管癌**定义为 T2~4NanyM0 或 TanyN1~3M0

## 临床表现

### 早期症状

- 吞咽时胸骨后**烧灼感/刺痛**
- 胸骨后闷胀不适、异物感
- 症状**时轻时重，断续发作**，进展缓慢

### 中期症状

- **进行性吞咽困难**——最典型症状
- 不同程度的[[体重减轻]]
- 持续性**胸背痛**——多提示肿瘤外侵

### 晚期症状

- **压迫症状**：
  - 压迫气管→[[咳嗽与咳痰|咳嗽]]、[[呼吸困难]]
  - 气管食管瘘→呛咳、[[发热|发烧]]、脓臭痰、[[肺炎]]
- **神经侵犯**：
  - [[喉返神经]]受累→[[声音嘶哑]]
  - [[膈神经]]受累→膈肌反常运动、呼吸困难
  - 颈交感干受累→[[Horner综合征]]
- **远处转移**：左锁骨上[[淋巴结]]肿大、肝转移（[[黄疸]]、[[腹水]]）
- **全身表现**：[[恶病质]]（严重消瘦、贫血、衰竭）

## 辅助检查

### 影像学检查

**1. X线吞钡检查**（首选筛查）

| 时期 | 表现 |
|------|------|
| 早期 | 黏膜皱襞中断、小充盈缺损、小龛影、管壁僵硬、蠕动中断 |
| 中晚期 | 大充盈缺损、管腔狭窄、梗阻、近段食管扩张 |

**2. CT检查**
- 评估肿瘤外侵范围、与邻近器官的关系
- 判断淋巴结转移和远处转移
- 协助TNM分期

**3. 电子胃镜（食管镜）**——最可靠的诊断手段
- 可直接观察病变并取活检
- 超声内镜（EUS）可评估浸润深度和淋巴结转移

![[04 Attachments/外科学-食管癌-诊断-X线胃镜.webp]]

### 其他检查

- 气管镜（评估气管受侵）
- [[淋巴结]]活检
- 同位素检查
- PET-CT（评估远处转移）

## 诊断与鉴别诊断

### 诊断流程

1. 临床症状：进行性吞咽困难是最典型表现
2. X线吞钡初筛
3. **电子胃镜+活检**——确诊金标准
4. CT/EUS评估分期

### 鉴别诊断

需与以下疾病鉴别：

- **贲门失弛缓症**：吞咽困难呈间歇性，X线吞钡呈"鸟嘴征"
- **食管良性狭窄**：多有腐蚀性或反流性食管炎病史
- **食管良性肿瘤**：如食管平滑肌瘤，病程长，一般状况好
- **食管憩室**

## 治疗

### 多学科综合治疗原则

食管癌治疗采用**手术 + 放疗 + 化疗 + 免疫治疗**的多学科综合治疗模式。

### 内镜下治疗（早期/癌前病变）

- **ESD**（内镜黏膜下剥离术）
- **EMR**（内镜下黏膜切除术）
- 适用于 T1aN0M0 早期食管癌及癌前病变

### 手术治疗（首选）

**适应证**：
1. 临床T1bN0M0期食管癌推荐直接根治性手术
2. 局部晚期/进展期食管癌——先行**新辅助治疗**（同步放化疗或化疗），再行手术

**禁忌证**：
1. Ⅳ期及部分Ⅲ期（侵及主动脉及气管）
2. 全身情况差、无法耐受手术

**手术原则**：食管次全切除，切缘距肿瘤边缘 ≥5cm；胃是最常用的替代物（亦可用结肠、空肠）

**常用术式**：
1. **经左胸食管切除，胸内食管—胃吻合术**（弓下/弓上）
2. **经右胸、中上腹食管切除，胸内食管—胃吻合术**（Ivor-Lewis术）
3. **经右胸、上腹、颈部食管切除，颈部食管—胃吻合术**（三切口术）
4. **胸腹联合切口**
5. **非开胸食管拔脱术**

![[04 Attachments/外科学-食管癌-手术径路.webp]]

**食管外科发展简史**：
- 1913 Torek：经胸食管癌切除
- 1940 吴英恺：胸段食管癌切除一期重建
- 1946 Ivor Lewis术
- 1978 Orringer：非开胸食管剥脱

### 放射治疗

- **术前放疗**：缩小肿瘤，提高切除率
- **术后放疗**：减少局部复发
- **根治性放疗**：多用于颈段/胸上段食管癌，或不能耐受手术者

### 化疗

- 新辅助化疗（术前）
- 辅助化疗（术后）
- 姑息性化疗（晚期）
- 常用方案：相关笔记见 [[消化道恶性肿瘤治疗方案]]（ECF方案用于食管癌）

### 免疫治疗

- 近年来免疫检查点抑制剂（如PD-1抑制剂）在食管癌治疗中取得突破
- 用于晚期/术后辅助治疗

## 并发症

### 术后并发症

| 并发症 | 发生率/特点 |
|--------|------------|
| **吻合口瘘** | 发生率5~10%，死亡率曾达50%→现已降至10%，强调早诊早治 |
| **吻合口狭窄** | 术后远期并发症 |
| **肺部感染** | 常见，与开胸手术相关 |
| **单纯脓胸** | 胸腔感染 |
| **乳糜胸** | 胸导管损伤 |
| **喉返神经损伤** | 声音嘶哑 |
| **膈疝** | 少见 |
| 术中并发症 | 大出血、急性呼吸/循环功能障碍 |

### 晚期并发症（姑息治疗）

- 胃造瘘术
- 支架置入术

---

## 预后

- 总体5年生存率约 **30%**
- 预后与**分期**密切相关：
  - 早期食管癌（T1aN0M0）——内镜下切除后5年生存率可达90%以上
  - 局部进展期——综合治疗后5年生存率约20~40%
  - 晚期——预后差

---

## 预防

1. **病因学预防**：避免亚硝胺摄入、戒烟限酒、避免烫食
2. **发病学预防**：处理癌前病变（[[Barrett食管]]、不典型增生）
3. **普查筛检**：高发区定期食管镜筛查
