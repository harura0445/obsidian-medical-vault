# 出血性疾病

> 因血管、血小板、凝血、抗凝及纤维蛋白溶解等止血机制缺陷或异常，导致自发性或轻度损伤后过度出血的疾病。

## 概述

出血性疾病是由先天性或获得性因素导致止血机制异常，以出血为主要表现的一组疾病。正常止血依赖**血管壁、血小板、凝血因子**三大要素协同作用。

## 正常止血机制

### 血管因素

血管受损时局部血管收缩是最早的反应，通过神经反射及多种介质调控。受损血管内皮细胞的作用：

| 功能 | 机制 |
|------|------|
| 促进血小板黏附 | 表达并释放 [[vWF]] |
| 启动外源性凝血 | 表达并释放 [[组织因子]]（TF） |
| 启动内源性凝血 | 基底胶原暴露，激活 [[凝血因子Ⅻ|FⅫ]] |
| 调节抗凝 | 表达并释放凝血酶调节蛋白（TM） |

### 血小板因素

血小板通过**黏附、聚集、释放**三步参与止血：

| 步骤 | 关键分子 |
|------|----------|
| 黏附 | GPⅠb 通过 vWF 桥梁与受损内皮下的胶原结合 |
| 聚集 | GPⅡb/Ⅲa 通过纤维蛋白原连接血小板 |
| 释放 | 活化后释放 TXA₂、5-HT 等活性物质 |

### 凝血因素

血管内皮损伤启动外源性及内源性凝血途径，最终形成纤维蛋白血栓。凝血过程依"瀑布学说"进行。

## 凝血机制

### 凝血因子

已知直接参与凝血过程的因子有14个（Ⅰ~ⅩⅢ + PK + HMWK），主要特性：

| 因子 | 同义名 | 合成部位 | 维生素K依赖 | 半衰期 |
|------|--------|----------|-------------|--------|
| Ⅰ | 纤维蛋白原 | 肝、巨核细胞 | - | 72~120h |
| Ⅱ | 凝血酶原 | 肝 | + | 60~70h |
| Ⅲ | 组织因子 | 组织、内皮、单核细胞 | - | — |
| Ⅶ | 稳定因子 | 肝 | + | 3~6h |
| Ⅷ | 抗血友病球蛋白 | 肝、脾、巨核细胞 | - | 8~12h |
| Ⅸ | Christmas因子 | 肝 | + | 18~24h |
| Ⅹ | Stuart-Prower因子 | 肝 | + | 30~40h |

### 凝血过程

现代凝血学说分为两个阶段：

| 阶段 | 途径 | 要点 |
|------|------|------|
| 启动阶段 | 外源性（TF途径） | TF-FⅦa复合物激活FⅩ，生成少量凝血酶 |
| 放大阶段 | 内源性衔接 | 少量凝血酶正反馈激活血小板、FⅤ、FⅧ、FⅪ |

共同通路：FⅩa + FⅤ + 磷脂 + Ca²⁺ → 凝血活酶 → 凝血酶原 → 凝血酶 → 纤维蛋白原 → 纤维蛋白

## 抗凝与纤溶系统

### 抗凝系统

| 抗凝物质 | 功能 |
|----------|------|
| [[抗凝血酶]]（AT） | 占血浆抗凝活性75%，灭活FⅩa及凝血酶 |
| 蛋白C系统 | PC/PS/TM，灭活FⅤ、FⅧ |
| 组织因子途径抑制物（TFPI） | 直接对抗FⅩa，抑制TF/FⅦa |
| 肝素 | 与AT结合增强其活性 |

### 纤溶系统

纤溶酶原经t-PA或u-PA激活转变为纤溶酶，降解纤维蛋白（原）产生**FDP**和**D-二聚体**。

## 出血性疾病分类

| 类型 | 先天性/遗传性 | 获得性 |
|------|---------------|--------|
| **血管壁异常** | 遗传性出血性毛细血管扩张症 | 过敏性紫癜、维生素C缺乏、感染 |
| **血小板异常** | 血小板无力症、巨大血小板综合征 | ITP、DIC、脾功能亢进、药物 |
| **凝血异常** | 血友病A/B、遗传性FⅪ缺乏 | 肝病、维生素K缺乏、抗凝药物 |
| **抗凝/纤溶异常** | — | 肝素过量、香豆素过量、溶栓药物 |
| **复合性异常** | 血管性血友病（vWD） | DIC |

## 出血特点鉴别

| 临床表现 | 血管/血小板性疾病 | 凝血障碍性疾病 |
|----------|-------------------|----------------|
| 性别 | 女性多见 | 80%~90%为男性 |
| 家族史 | 较少见 | 多见 |
| 皮肤瘀斑/紫癜 | **多见** | 罕见 |
| 深部血肿 | 罕见 | **常见** |
| 关节腔内出血 | 罕见 | **多见** |
| 内脏出血 | 偶见 | 常见 |
| 月经过多 | 多见 | 少见 |
| 术后渗血不止 | 可见 | **多见** |

## 实验室检查

### 筛选试验

| 试验 | 意义 |
|------|------|
| **BT**（出血时间） | 反映血小板功能及血管因素 |
| **血小板计数** | 血小板减少/增多 |
| **PT**（凝血酶原时间） | 反映外源性凝血途径（Ⅶ、Ⅹ、Ⅴ、Ⅱ、Ⅰ） |
| **APTT**（活化部分凝血活酶时间） | 反映内源性凝血途径（Ⅻ、Ⅺ、Ⅸ、Ⅷ、Ⅹ、Ⅴ、Ⅱ、Ⅰ） |
| **TT**（凝血酶时间） | 反映纤维蛋白原→纤维蛋白 |
| **纤维蛋白原** | 反映凝血第三阶段 |

### 各试验在不同疾病中的意义

| 疾病类型 | BT | 血小板计数 | PT | APTT | TT | FDP |
|----------|-----|-----------|-----|------|-----|-----|
| 血管性疾病 | 异常/正常 | 正常 | 正常 | 正常 | 正常 | 正常 |
| 血小板性疾病 | 异常/正常 | 异常/正常 | 正常 | 正常 | 正常 | 正常 |
| 凝血异常 | 正常 | 正常 | 异常 | 异常 | 异常/正常 | 正常 |
| 纤溶亢进 | 正常 | 正常 | 异常 | 异常 | 异常 | **异常** |

### 确诊试验

- **血管异常**：vWF、ET-1、TM测定
- **血小板异常**：血小板聚集试验、血小板表面CD62P、GPⅡb/Ⅲa和GPⅠb/Ⅸ检测
- **凝血异常**：各凝血因子抗原及活性测定
- **抗凝异常**：AT、PC、PS、FⅧ抗体、狼疮抗凝物
- **纤溶异常**：3P试验、FDP、D-二聚体、t-PA、PAI

## 诊断步骤

1. 确定是否属于出血性疾病
2. 大致区分血管/血小板异常还是凝血障碍
3. 判断数量异常或质量缺陷
4. 通过病史、家系调查确定先天性/获得性
5. 必要时行基因及分子生物学检测

## 治疗

### 病因防治

- 控制感染、治疗肝胆疾病、抑制异常免疫反应
- 避免使用加重出血的药物（阿司匹林、华法林、肝素等）

### 止血治疗

| 方法 | 内容 |
|------|------|
| 补充血小板/凝血因子 | 新鲜冰冻血浆、血小板悬液、冷沉淀、FⅧ |
| 止血药物 | 卡巴克洛、维生素K、氨甲苯酸、去氨加压素 |
| 重组活化因子Ⅶ（rFⅦa） | 直接激活FⅩ |
| 促血小板生成药物 | TPO、IL-11 |
| 局部处理 | 加压包扎、手术结扎 |

### 其他治疗

- **免疫治疗**：糖皮质激素、抗CD20单抗（用于ITP、有抑制物的血友病）
- **血浆置换**：用于TTP等
- **手术治疗**：脾切除、血肿清除、关节成形
- **基因治疗**：遗传性出血性疾病的新方向
