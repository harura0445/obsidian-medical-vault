# 子宫内膜异位症与子宫腺肌病


## 概述

子宫内膜异位症（endometriosis，EMT）和子宫腺肌病均由具有生长功能的异位子宫内膜所致，两者常可并存，但发病机制及组织发生不同，对卵巢激素的敏感性亦有显著差异。

- **子宫内膜异位症**：子宫内膜组织（腺体和间质）出现在子宫体以外部位，绝大多数位于盆腔
- **子宫腺肌病**：子宫内膜腺体及间质侵入子宫肌层生长

## 子宫内膜异位症

### 概述

内异症是生育期女性的多发病，约 10% 生育期女性患病，76%~85% 发病年龄在 25~45 岁。内异症是**激素依赖性疾病**，自然绝经或人工绝经后病灶可逐渐萎缩吸收。形态学上呈良性表现，但在临床行为学上极具侵袭性，易复发。

### 发病机制


| 学说 | 机制 |
|------|------|
| **种植学说** | 经血逆流（Sampson 学说）→内膜碎片经输卵管入盆腔种植；淋巴及静脉播散；医源性种植（剖宫产、会阴切口） |
| 体腔上皮化生学说 | 卵巢表面上皮、盆腔腹膜受激素/炎症反复刺激后转化为子宫内膜样组织 |
| 诱导学说 | 未分化腹膜组织在生化因素诱导下发展为子宫内膜组织 |
| 遗传因素 | 一级亲属患病风险为无家族史者的 7 倍；单卵双胎一方患病→另一方 75% |
| 免疫与炎症因素 | 免疫监视/杀伤功能减弱，腹腔液中巨噬细胞、促炎因子增加，PGE₂ 促进芳香化酶表达异常 |
| 在位内膜决定论 | 在位子宫内膜的黏附性、侵袭性、血管生成能力强于正常女性在位内膜 |

### 病理

基本病理变化为异位子宫内膜随卵巢激素变化发生**周期性出血**→周围纤维组织增生、囊肿和粘连形成。

#### 临床病理类型

| 类型 | 特点 |
|------|------|
| **卵巢型（卵巢子宫内膜异位囊肿）** | 最常见，80% 累及一侧，50% 累及双侧。囊内含陈旧咖啡色血液→"巧克力囊肿"。囊肿易反复破裂→粘连固定 |
| **腹膜型** | 分布于子宫骶韧带、直肠子宫陷凹和子宫后壁下段浆膜。分色素沉着型（蓝紫色结节）和无色素沉着型（红色/白色病变，更具生长活性） |
| **深部浸润型（DIE）** | 病灶浸润深度 ≥5mm，累及子宫骶韧带、直肠阴道隔、膀胱壁等 |
| **其他部位** | 瘢痕内异症、肺、胸膜等远处内异症 |

### 临床表现


内异症临床表现因人和病变部位而异，25% 患者无症状。

#### 症状

| 症状 | 要点 |
|------|------|
| **下腹痛和痛经** | 主要症状，**继发性痛经、进行性加重**。月经前 1~2 日开始，月经第 1 日最剧烈。疼痛程度与病灶大小不成正比 |
| **慢性盆腔痛** | 经期加重 |
| **性交痛** | 直肠子宫陷凹病灶，深部性交痛，经前期最明显 |
| **急腹痛** | 巧克力囊肿大破裂→囊内液流入盆腹腔→突发剧烈腹痛 + 恶心、呕吐 |
| **不孕** | 不孕率高达 50%。机制：盆腔粘连→输卵管梗阻、盆腔微环境改变、排卵障碍、未破卵泡黄素化综合征（LUFS）、自然流产率高达 40% |
| **月经异常** | 15%~30% 有经量增多、经期延长 |
| **其他部位症状** | 肠道：周期性腹痛、便血；膀胱：经期尿痛、尿频、血尿；呼吸道：经期咯血、气胸；切口瘢痕：周期性疼痛和包块 |

#### 体征

子宫后倾固定，直肠子宫陷凹/子宫骶韧带可触及**触痛性结节**，一侧或双侧附件处囊实性包块（活动度差）。囊肿破裂时腹膜刺激征阳性。

### 辅助检查

| 检查 | 用途 |
|------|------|
| **超声** | 诊断卵巢异位囊肿和膀胱、直肠内异症的重要方法，囊壁厚而粗糙，囊内细絮状光点 |
| **血清 CA125** | 可升高，重症更明显。灵敏度和特异度均不高，但可监测病情变化、评估疗效和预测复发 |
| **腹腔镜检查** | 国际公认的手术诊断最佳方法，可明确病变范围和分期，并行病理诊断 |
| MRI/CT | 评估 DIE 累及肠管、膀胱、输尿管范围；不做初选 |

### 诊断

生育期女性 + **继发性痛经进行性加重** + 不孕/慢性盆腔痛 + 妇科检查触及**盆腔触痛性结节**→临床诊断。腹腔镜检查可明确诊断。

**临床分期**：采用 ASRM 修正分期法（1997 年），在腹腔镜下根据病灶部位、数目、大小、粘连程度评分：
- Ⅰ期（微型）：1~5 分
- Ⅱ期（轻型）：6~15 分
- Ⅲ期（中型）：16~40 分
- Ⅳ期（重型）：>40 分

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| 卵巢恶性肿瘤 | 持续性腹痛腹胀、病情进展快、CA125 显著升高、HE4 升高、超声囊实性或实性 |
| 盆腔炎性包块 | 急性/反复盆腔感染史，疼痛无周期性，抗菌药物治疗有效 |
| 子宫腺肌病 | 疼痛多位于下腹正中、更剧烈，子宫均匀性增大、质硬、经期触痛明显 |

### 治疗


治疗目的：消除病灶、减轻疼痛、促进生育、减少复发。原则：根据年龄、症状、病变部位和范围及生育要求个体化治疗。

#### 药物治疗

适用于未合并不孕及附件包块（或附件包块直径 <4cm）、盆腔疼痛者。

| 药物 | 用法 | 备注 |
|------|------|------|
| **NSAID** | 按需应用，间隔 ≥6h | 抑制前列腺素合成，减轻疼痛 |
| **口服避孕药** | 每日 1 片，连续 6~9 月 | 假孕疗法，适用于轻度内异症 |
| **孕激素类** | 地诺孕素 2mg/d 口服 | **首选长期管理药物**，对肝肾及代谢影响小 |
| 甲羟孕酮 | 30mg/d 口服 | |
| 地屈孕酮 | 10~20mg/d，月经第 5~25 日 | |
| **LNG-IUS** | 宫内缓释系统 | 长效局部孕激素 |
| **GnRH-a** | 亮丙瑞林 3.75mg/28d；戈舍瑞林 3.6mg/28d，共 3~6 次 | "药物性卵巢切除"，可出现绝经症状和骨质丢失。3~6 个月后可给予反向添加治疗 |
| 孕三烯酮 | 2.5mg biw，6 月一疗程 | 抗孕激素 + 抗雌激素，假绝经疗法 |

> **反向添加治疗**：使用 GnRH-a 3~6 个月时加用戊酸雌二醇 0.5~1.0mg + 甲羟孕酮 2mg/d 或替勃龙 1.25mg/d，预防低雌激素相关症状和骨质丢失。

#### 手术治疗

适应证：药物治疗无效 / 合并不孕 / 附件包块直径 ≥4cm。**腹腔镜手术是首选**。

| 术式 | 适用人群 | 要点 |
|------|----------|------|
| 保留生育功能手术 | 年轻、有生育要求 | 切净所有异位病灶、分离粘连、保留子宫及至少部分卵巢。术后复发率约 40%，术后 6~12 个月是妊娠最佳时机 |
| 保留卵巢功能手术 | Ⅲ/Ⅳ期、无生育要求、45 岁以下 | 切除子宫及病灶，保留至少部分卵巢。术后复发率约 5% |
| 根治性手术 | 45 岁以上重症 | 切除子宫+双附件+所有病灶，术后不用雌激素者几乎不复发 |

#### 合并不孕处理

- 年龄 >35 岁 / 男方精液异常 / 配子运输障碍 → 直接 IVF-ET
- 年龄 ≤35 岁无男方因素 → 宫腹腔镜联合行内异症生育指数（EFI）评定
  - EFI ≥5 分：术后期待 6 个月自然妊娠
  - EFI ≤4 分：建议直接 IVF-ET

### 预防

- **防止经血逆流**：及时治疗梗阻性生殖道畸形、子宫颈粘连
- **药物避孕**：口服避孕药降低发病风险
- **防止医源性种植**：避免多次宫腔手术，经前不做输卵管通畅试验，人流吸宫时负压不宜过高

## 子宫腺肌病

### 概述

子宫内膜腺体及间质侵入子宫肌层生长。多发生于 30~50 岁经产妇，约 15% 合并内异症，约半数合并子宫肌瘤。35% 患者无典型症状。

### 发病机制

基底层子宫内膜缺乏黏膜下层、直接与肌层接触→内膜易于侵入肌层。**多次妊娠及分娩、人工流产、慢性子宫内膜炎**等因素造成内膜基底层损伤与发病密切相关。高水平雌孕激素刺激也是促进因素之一。

### 病理

| 类型 | 特点 |
|------|------|
| 弥漫型 | 异位内膜弥漫性生长，多累及后壁，子宫均匀性增大呈球形，一般 ≤12 周大小 |
| 局限型（子宫腺肌瘤） | 局限性生长形成结节/团块，与周围肌层无明显界限，手术难以彻底切除 |

镜下：肌层内岛状分布的异位内膜腺体及间质。异位腺体属基底层不成熟内膜，对雌激素有反应，对孕激素无反应/不敏感。

### 临床表现

| 症状 | 要点 |
|------|------|
| **月经过多** | 发生率 40%~50%，连续数个周期经量 >80ml |
| **进行性继发性痛经** | 发生率 30%~40%，疼痛位于下腹正中，经前 1 周开始→月经结束 |
| 不孕 | 约 20%，妊娠后流产、早产、产后出血风险增加 |

**体征**：子宫均匀增大或局限性结节隆起，质硬且有**压痛**（经期更明显）。

### 诊断

典型进行性痛经 + 月经过多 + 子宫均匀增大/局限性隆起、质硬有压痛→初步诊断。金标准为**病理诊断**。超声、MRI、CT 可辅助诊断。血清 CA125 可升高。

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| 子宫肌瘤 | 大多无痛经，包块边界清晰，CA125 无明显升高 |
| 子宫内膜癌 | 异常阴道流血为主，肿瘤标志物明显升高，宫腔镜内膜病理鉴别 |
| 子宫肉瘤 | 病灶边界不清、血流异常丰富，MRI + 活检辅助诊断 |

### 治疗


| 治疗 | 适用人群 | 方案 |
|------|----------|------|
| 药物治疗 | 症状轻、有生育要求、近绝经期 | NSAID、口服避孕药、孕激素、GnRH-a、LNG-IUS。停药后症状可复现 |
| 病灶切除术 | 年轻/希望生育的腺肌瘤患者 | 术后有复发风险 |
| 全子宫切除术 | 症状重、无生育要求、药物无效 | 是否保留卵巢取决于卵巢有无病变和患者年龄 |
| 介入治疗 | 不愿手术、排除恶性 | 高强度聚焦超声（HIFU）、子宫动脉栓塞术（UAE），仅能缩小病灶 |

## 预后与随访

内异症：2 年平均复发率 20%，5 年 50%。术后应药物巩固治疗减少复发。恶变率约 0.5%~1%，恶变主要部位在卵巢（子宫内膜样癌和透明细胞癌）。应长期管理，定期复查。
