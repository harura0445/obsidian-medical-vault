# 无菌术与外科感染

## 无菌术

### 概述

无菌术（asepsis）是针对微生物及感染途径所采取的一系列操作规范，包括**灭菌**（杀灭一切活的微生物，包括芽胞）和**消毒**（杀灭病原微生物和其他有害微生物）。

### 灭菌与消毒方法

| 方法 | 原理/参数 | 适用范围 |
|------|----------|----------|
| 高压蒸汽灭菌法 | 下排气式：121℃、102.9kPa、20~30min；预真空式：132~134℃、205.8kPa、4min | 大多数医用物品：手术器械、衣巾、敷料 |
| 化学气体灭菌法 | 环氧乙烷450~1200mg/L，37~63℃，1~6h；过氧化氢等离子体＞6mg/L，45~65℃，28~75min | 不耐高温湿热的物品：电子仪器、内镜、导管 |
| 煮沸法 | 100℃、15~20min；芽胞需≥1h；高原用压力锅（124℃、10min） | 金属器械、玻璃制品、橡胶类 |
| 药液浸泡法 | 2%中性戊二醛：消毒30min，灭菌10h | 锐利器械、内镜 |
| 干热灭菌法 | 160℃/2h、170℃/1h、180℃/30min | 玻璃、粉剂、油剂 |
| 电离辐射法 | ⁶⁰Co γ射线或电子射线 | 一次性无菌耗材（注射器、丝线） |

**高压蒸汽灭菌注意事项**：包裹体积≤40cm×30cm×30cm，包扎不宜过紧，包内/包外放置灭菌指示带，有效期2周。

### 手术人员的术前准备

1. **一般准备**：换手术室清洁鞋衣，帽子盖全部头发，口罩盖鼻孔，剪短指甲
2. **外科手消毒**：刷洗法按顺序刷洗手臂3分钟，清除暂居菌和部分常居菌
3. **穿无菌手术衣、戴无菌手套**

### 病人手术区准备

- 消毒规范：由手术区中心向四周涂擦（感染/肛门手术相反），消毒范围包括切口周围**15cm**
- 铺巾：切口周围覆盖≥四层无菌巾，先铺相对不洁区

### 手术中的无菌原则

1. 无菌空间：肩以下、腰以上、身前区（至腋中线）、双侧手臂；手术台台面
2. 不可在背后传递器械；坠落物品按污染处理
3. 手套破损或接触到有菌区应立即更换
4. 术前术后清点器械敷料，核对无误方可关腹
5. 切开空腔脏器前用纱布垫保护周围组织
6. 同侧人员调换位置应背对背转身
7. 参观人员距无菌区**30cm**以上，减少走动
8. 术中不开窗通风，空调风口勿吹向手术台

## 外科感染

### 概述

外科感染（surgical infection）指需要外科处理的感染，包括创伤、烧伤、手术相关感染。

| 分类方式 | 类型 | 示例 |
|----------|------|------|
| 按致病菌 | 非特异性感染 | 疖、痈、丹毒、急性乳腺炎、阑尾炎 |
| | 特异性感染 | 结核、破伤风、气性坏疽、念珠菌病 |
| 按病程 | 急性（<3周）/ 亚急性 / 慢性（>2月） | — |

**外科感染处理关键**：控制感染源、通畅引流，抗菌药物不能取代引流等外科处理。

### 疖与痈

| 项目 | 疖 | 痈 |
|------|----|----|
| 定义 | 单个毛囊及周围组织急性化脓性炎症 | 多个相邻毛囊同时感染或疖融合 |
| 致病菌 | 金黄色葡萄球菌 | 金黄色葡萄球菌 |
| 好发部位 | 头面、颈项、背部 | 项背部（"对口疔""搭背疮"） |
| 临床表现 | 红、肿、痛小硬结，有脓栓 | 皮肤硬肿、多个脓点、蜂窝状破溃、全身症状重 |
| 处理 | 热敷/理疗，脓栓剔出（**禁忌挤压**） | "++"形切开引流，清除失活组织 |

> **危险三角区**：鼻、上唇及周围，面疖/唇痈被挤压可致病菌经内眦静脉、眼静脉入颅，引起**颅内化脓性海绵状静脉窦炎**。

### 急性蜂窝织炎

急性蜂窝织炎是皮下、筋膜下或深部疏松结缔组织的急性弥漫性化脓性感染。致病菌多为溶血性链球菌，其次为金黄色葡萄球菌。表现为局部红、肿、热、痛，边界不清，可伴全身症状。治疗以抗生素为主，形成脓肿者切开引流。

### 丹毒

丹毒是皮肤淋巴管网受β-溶血性链球菌感染所致的急性非化脓性炎症。好发于下肢和面部，表现为片状红疹、色鲜红、边界清楚、稍隆起，可有水疱。治疗首选**青霉素**。

### 甲沟炎

甲沟炎是甲沟及其周围组织的感染，多因微小刺伤、挫伤、倒刺或剪指甲过深引起。致病菌多为金黄色葡萄球菌。早期局部红肿热痛，形成脓肿需切开引流。

### 破伤风

**致病菌**：破伤风梭菌（G⁺厌氧芽胞杆菌），产生破伤风痉挛毒素。

**临床表现**：
- 潜伏期：通常7天（24h~数月）
- 前驱症状：乏力、头痛、嚼肌紧张、烦躁
- 典型发作：**咀嚼肌**最先受累→张口困难/牙关紧闭→苦笑面容→颈项强直→角弓反张→呼吸肌痉挛致死
- 神志始终清楚，轻微刺激可诱发痉挛

**治疗原则**：
1. 清创去除毒素来源（敞开伤口、充分引流）
2. 中和游离毒素：TAT（破伤风抗毒素）或TIG（人体破伤风免疫球蛋白）
3. 控制和解除痉挛：镇静、避光安静环境
4. 防治并发症：保持呼吸道通畅，必要时气管切开
5. 抗生素：青霉素、甲硝唑

**预防**：主动免疫（破伤风类毒素）、被动免疫（TAT/TIG）。

### 气性坏疽

**致病菌**：产气荚膜梭菌（G⁺厌氧芽胞杆菌），产生α毒素（卵磷脂酶）。

**临床特点**：
- 潜伏期：1~4天
- 患肢沉重→剧烈胀痛→皮肤"青铜色"→水疱→捻发音（皮下气肿）
- 伤口溢出稀薄恶臭血性分泌物，肌肉呈"熟肉样"坏死
- 全身中毒症状严重，可迅速发展为休克、肾衰竭

**治疗**：
1. 紧急清创：广泛多处纵深切开，切除坏死肌肉，敞开引流
2. 抗生素：大剂量青霉素
3. 高压氧治疗
4. 截肢：肢体无法保留时的最后手段

### 抗菌药物的选择和应用原则

- 根据细菌培养和药敏结果选择
- 经验性用药覆盖常见致病菌
- 外科感染需配合充分引流
- 围手术期预防用药应在术前30~60min给药
- 避免滥用，减少耐药
