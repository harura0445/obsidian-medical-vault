# 妊娠期高血压疾病

![[04 Attachments/妇产科-妊高症_p2.webp]]

## 概述

妊娠期高血压疾病（HDP）是妊娠与血压升高并存的一组疾病，发生率5%～12%。包括5种类型，严重影响母婴健康，是孕产妇和围产儿病死率升高的主要原因。

## 分类与诊断标准

| 分类 | 诊断标准 |
|------|----------|
| **妊娠期高血压** | 妊娠20周后血压≥140/90mmHg，产后12周内恢复正常；尿蛋白(-) |
| **子痫前期** | 妊娠20周后血压≥140/90mmHg + 尿蛋白≥0.3g/24h或随机(++)或尿蛋白/肌酐≥0.3 |
| **子痫** | 子痫前期基础上发生不能用其他原因解释的抽搐 |
| **慢性高血压并发子痫前期** | 慢性高血压者妊娠20周后出现蛋白尿或蛋白尿增加/血压升高/终末器官损害 |
| **妊娠合并慢性高血压** | 妊娠20周前已确诊高血压或产后12周后高血压持续 |

**重度子痫前期诊断标准**（子痫前期+任何1项）：
- 血压≥160/110mmHg
- 血小板<100×10⁹/L
- 肝功能损害（转氨酶>正常2倍），严重持续右上腹痛
- 肾功能损害（肌酐>1.1mg/dl或正常2倍以上）
- 肺水肿
- 新发头痛（药物不能缓解）
- 视觉障碍

普遍认为**<34周发病为早发型子痫前期**。不再诊断"轻度"子痫前期。

## 病因与发病机制

![[04 Attachments/妇产科-妊高症_p6.webp]]

至今未完全阐明。子痫前期是**多因素、多机制、多通路**疾病。

### "两阶段"学说

- **第一阶段（临床前期）**：子宫螺旋动脉滋养细胞重塑障碍→"胎盘浅着床"→胎盘缺血缺氧→释放胎盘因子
- **第二阶段**：胎盘因子入血→系统性炎症激活+血管内皮细胞损伤→子痫前期临床表现

### 主要学说

| 学说 | 机制 |
|------|------|
| 子宫螺旋动脉重塑不足 | 绒毛外滋养细胞浸润能力受损，仅蜕膜层重塑，管腔为正常1/2，血流阻力增大 |
| 炎症免疫过度激活 | 母胎界面天然免疫异常，Th1/Th2向Th1偏移，Treg减少→免疫耐受降低 |
| 血管内皮损伤 | 扩血管物质（NO、PGI₂）↓，缩血管物质（ET、TXA₂）↑→血管痉挛 |
| 遗传因素 | 家族倾向性，多基因遗传与环境交互作用 |
| 营养缺乏 | 低白蛋白、钙/镁/锌/硒缺乏可能相关 |

## 病理生理变化

**基本病理生理变化：全身小血管痉挛和血管内皮细胞损伤。**

| 器官 | 病理变化 | 临床后果 |
|------|----------|----------|
| 脑 | 血管痉挛、通透性↑→脑水肿、充血、缺血、血栓 | 头痛、昏迷、脑疝、子痫 |
| 肾脏 | 肾小球扩张、内皮肿胀→蛋白尿；血流量和GFR↓ | 血尿酸/肌酐↑、肾衰竭 |
| 肝脏 | 门静脉周围出血、坏死 | 转氨酶↑、肝包膜下血肿、肝破裂 |
| 心血管 | 血管痉挛→外周阻力↑→低排高阻；心肌损伤→肺水肿 | 心力衰竭 |
| 血液 | 血管壁渗透性↑→血液浓缩 | 血细胞比容↑，高凝状态 |
| 子宫胎盘 | 螺旋动脉重塑不足→灌注↓，急性动脉粥样硬化 | FGR、胎儿窘迫、胎盘早剥 |

## 预测与预防

### 危险因素

- **高危因素**：子痫前期病史（尤其不良结局）、多胎妊娠、慢性高血压、1/2型糖尿病、肾脏疾病、自身免疫性疾病（SLE、APS）
- **中危因素**：初产、肥胖（BMI≥30）、家族史、年龄≥35岁、前次不良妊娠结局、妊娠间隔≥10年

### 预防措施

1. 适度锻炼
2. 低钙摄入者补钙：1.5～2.0g/d口服
3. 高危者阿司匹林：自**11～13周**开始，最晚不超过20周，100～150mg/d睡前口服至36周

## 治疗

### 治疗原则

**降压、解痉、镇静**；密切监测母儿情况；**适时终止妊娠是最有效的处理措施**。

### 降压治疗

- **指征**：血压≥160/110mmHg（重度）必须降压；≥140/90mmHg可考虑降压
- **目标**：130～139/80～89mmHg，维持在130/80mmHg左右
- **禁用**：ACEI、ARB。不推荐阿替洛尔、哌唑嗪。一般不使用利尿剂降压

| 药物 | 特点与用法 |
|------|-----------|
| 拉贝洛尔 | α+β受体拮抗剂，不影响肾及胎盘血流。口服50～150mg tid；静注20～80mg |
| 硝苯地平 | 钙通道阻滞剂。口服10mg q6～8h，24h<120mg。不主张舌下含化 |
| 甲基多巴 | 中枢α受体激动剂。250mg tid，最高2g/d |
| 乌拉地尔 | α受体拮抗剂。静注10～50mg或静滴 |
| 硝普钠 | 仅用于其他药物不佳的重度高血压。代谢产物有毒性 |

### 解痉治疗——硫酸镁

**硫酸镁是子痫治疗的一线药物**，也是重度子痫前期预防子痫发作的关键药物。不可作为降压药使用。

- **有效治疗浓度**：1.8～3.0mmol/L，**>3.5mmol/L出现中毒症状**
- **必备条件**（用药期间）：①膝反射存在；②呼吸≥16次/分；③尿量≥17ml/h或≥400ml/24h；④备有10%葡萄糖酸钙
- **中毒处理**：停用硫酸镁，缓慢静注（5～10分钟）10%葡萄糖酸钙10ml
- 方案：负荷量4～6g静脉注射（15～20min）→1～2g/h维持。24h总量不超过30g，时限不超过5日
- 产后继续使用**24～48小时**预防产后子痫

### 镇静与利尿

- 地西泮：2.5～5mg口服tid；静注10mg用于预防子痫
- 冬眠合剂：仅用于硫酸镁无效者（可致血压急剧下降）
- 利尿剂：不常规应用，仅用于水肿/肺水肿/脑水肿/心衰时。呋塞米、甘露醇（脑水肿，心衰禁用）

### 分娩时机

- **非重度子痫前期**：期待至37周及以上终止
- **重度子痫前期**：<24周病情不稳→终止；28～33周病情不稳→促肺成熟后终止；≥34周→终止
- 无剖宫产指征者可阴道试产，不能短期分娩者放宽剖宫产指征

## 子痫

是子痫前期-子痫最严重的阶段，**最常见死因为脑血管意外**。

- 控制抽搐：硫酸镁是首选药物
- 降低颅内压：20%甘露醇250ml快速静滴
- 控制血压：收缩压持续≥160mmHg或舒张压≥110mmHg时积极降压
- 一旦抽搐控制后即可考虑终止妊娠

## HELLP综合征

![[04 Attachments/妇产科-妊高症_p36.webp]]

以**溶血（Hemolysis）、肝酶升高（Elevated Liver enzymes）、血小板减少（Low Platelets）**为特点的一组综合征。

**诊断标准**：
- 血管内溶血：外周血见破碎红细胞，总胆红素≥20.5μmol/L，结合珠蛋白<250mg/L
- 肝酶升高：转氨酶>正常2倍，LDH≥600U/L
- 血小板减少：<100×10⁹/L

**LDH升高和结合珠蛋白降低是诊断的敏感指标**，常在胆红素和Hb变化前出现。

- 治疗唯一有效方法为**终止妊娠**
- 糖皮质激素：血小板<50×10⁹/L时可考虑使用地塞米松
- 禁忌阴部阻滞和硬膜外麻醉（血小板减少）

## 妊娠期肝内胆汁淤积症（ICP）

妊娠中晚期特有并发症。临床特征：**皮肤瘙痒**（首发症状，始于手掌脚掌，夜间加剧）+ **血清总胆汁酸（TBA）升高**。

| 严重程度 | TBA标准 | 终止妊娠时机 |
|----------|---------|-------------|
| 轻度 | 10≤TBA<40μmol/L | 38～40周 |
| 重度 | 40≤TBA<100μmol/L | 36～38周 |
| 极重度 | TBA≥100μmol/L | 35～36周 |

- 常用药物：**熊去氧胆酸（UDCA）** 1g/d；S-腺苷甲硫氨酸（SAMe）1g/d
- TBA≥100μmol/L与死胎相关，需积极终止
- ICP不是绝对剖宫产指征，但重度和极重度可放宽

## 妊娠期急性脂肪肝（AFLP）

罕见但病情危急。特征：消化道症状+肝功能异常+凝血功能障碍。起病急、进展快、病情重。

- **及时终止妊娠是治疗关键**
- 若短时间内不能经阴道分娩，应在改善凝血功能后尽快剖宫产
- 需与病毒性肝炎、HELLP综合征、ICP鉴别
- 为胎源性和产后自限性疾病，及时终止者预后较好
