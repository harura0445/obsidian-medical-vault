# 前置胎盘


## 概述

**妊娠28周以后，胎盘位置低于胎先露部，附着在子宫下段、下缘毗邻或覆盖宫颈内口。**是妊娠晚期阴道流血最常见的原因及严重并发症之一。

## 病因

1. **子宫内膜病变或损伤**：剖宫产史、多次流产刮宫、产褥感染→内膜炎或萎缩。前次剖宫产瘢痕妨碍胎盘上移
2. **胎盘异常**：副胎盘位于子宫下段；胎盘面积过大（双胎发生率高一倍）
3. **受精卵滋养层发育迟缓**：滋养层未发育到可着床阶段，受精卵已达宫腔下段
4. **其他**：辅助生殖技术、子宫形态异常、吸烟、前置胎盘既往史

前置胎盘是胎盘植入性疾病（PAS）的常见高危因素。

## 分类

按胎盘下缘与宫颈内口的关系（以处理前最后一次检查结果确定）：

| 类型 | 定义 |
|------|------|
| 完全性前置胎盘（中央性） | 胎盘组织完全覆盖宫颈内口 |
| 部分性前置胎盘 | 胎盘组织覆盖部分宫颈内口 |
| 边缘性前置胎盘 | 胎盘下缘达到宫颈内口，未超越 |
| 低置胎盘 | 胎盘边缘距宫颈内口<2cm |

## 临床表现

- **典型症状**：妊娠晚期或临产时发生**无诱因、无痛性反复阴道流血**
- 出血机制：子宫下段形成和宫口扩张→前置胎盘伸展性差→与附着处错位分离→血窦破裂
- 体征：子宫软、无压痛、轮廓清楚。胎先露高浮，1/3合并胎位异常。前壁前置胎盘可于耻骨联合上方闻及胎盘血流杂音

## 诊断

- **首选阴道超声检查**，准确性高于腹部超声。怀疑合并胎盘植入时行MRI
- 妊娠中期超声发现胎盘前置状态不直接诊断为前置胎盘，可随子宫下段形成而上移

## 对母儿影响

- **产时及产后出血**：子宫下段肌组织薄，收缩差，血窦不易关闭
- **贫血及感染**：反复出血→贫血，细菌经阴道上行感染
- **围产儿预后不良**：早产、低体重儿、胎儿窘迫甚至死亡

## 处理


治疗原则：**抑制宫缩、纠正贫血和适时终止妊娠**。

### 期待疗法

适用于妊娠<36周、胎儿存活、一般情况良好、阴道流血少者。
- 抑制宫缩（早产风险时）
- 纠正贫血（目标Hb≥110g/L，Hct≥0.30）
- 糖皮质激素促胎肺成熟（<34周）

### 终止妊娠

**剖宫产术是前置胎盘终止妊娠的主要方式。**

| 分型 | 择期终止时机 |
|------|-------------|
| 完全性前置胎盘 | 妊娠37周及以上 |
| 边缘性前置胎盘 | 妊娠38周及以上 |
| 有反复出血/合并PAS等 | 妊娠34～37周 |

阴道分娩仅用于边缘性前置胎盘/低置胎盘、枕先露、出血少、估计短时间内能结束分娩者。

### 术中止血措施

局部缝合、子宫压迫缝合术、宫腔纱条填塞术、子宫动脉/髂内动脉结扎术、子宫动脉栓塞术，无效时行**子宫切除术**。
