# 肠梗阻

## 定义

任何原因引起的肠内容物通过障碍统称肠梗阻，是常见的外科急腹症。

## 病因与分类

| 分类方式 | 类型 | 说明 |
|----------|------|------|
| 按病因 | **机械性**（最常见） | 肠外因素（粘连、疝）、肠壁因素（肿瘤、肠套叠）、肠腔内因素（异物、粪石） |
| | 动力性 | 麻痹性（腹膜炎/术后多见）+ 痉挛性（罕见） |
| | 血运性 | 肠系膜血管栓塞/血栓→肠缺血坏死 |
| 按血运 | 单纯性 | 仅肠内容物通过受阻，无血运障碍 |
| | **绞窄性** | 肠系膜血管受压→肠坏死穿孔 |
| 按部位 | 高位（空肠） / 低位（回肠） / 结肠（闭袢性） | — |
| 按程度 | 完全性 / 不完全性 | — |

> 分类可相互转化：单纯性→绞窄性，机械性→麻痹性，慢性不完全性→急性完全性。

## 病理和病理生理

### 局部改变

- 梗阻以上肠管积气积液→肠膨胀→肠壁变薄→缺血坏死穿孔
- 肠蠕动增强（早期）→减弱消失（晚期）
- 闭袢性梗阻时肠腔内压力升高更快→更易导致肠坏死

### 全身改变

| 改变 | 机制 |
|------|------|
| **水电解质紊乱** | 大量液体丢失（肠腔内积存+频繁呕吐+向腹腔渗出）→脱水、低钠、低钾、代谢性酸中毒 |
| **感染和中毒** | 肠内细菌大量繁殖+肠屏障功能破坏→菌血症、内毒素血症 |
| **休克** | 低血容量+感染/中毒→多器官功能障碍 |
| **呼吸循环障碍** | 腹压升高→膈肌抬高→呼吸受限+静脉回流减少 |

## 临床表现

### 共同的四大症状

| 症状 | 特点 |
|------|------|
| **腹痛** | 机械性：阵发性绞痛（有间歇）；麻痹性：持续性胀痛；绞窄性：剧烈持续性痛，可加剧 |
| **呕吐** | 高位梗阻：早、频繁、呕吐物为胃内容+胆汁；低位梗阻：晚、可吐粪样物 |
| **腹胀** | 高位：腹胀轻；低位：全腹胀明显；闭袢性：不对称腹胀 |
| **停止排气排便** | 完全性梗阻停止排气排便；高位/早期可排少量存留粪便 |

### 体征

- **腹部**：机械性→肠型和蠕动波、肠鸣音亢进（金属音/气过水声）；麻痹性→肠鸣音减弱或消失
- **绞窄征**：持续剧痛、发热、脉搏增快、腹膜炎体征、休克、血性腹水/呕吐物
- **直肠指诊**：直肠癌→触及肿块；肠套叠→指套染血

## 辅助检查

- **腹部X线平片**：阶梯状气液平面（机械性）；孤立胀大肠袢（绞窄可疑）
- CT：明确梗阻部位、病因、有无绞窄

## 诊断与鉴别诊断

**诊断步骤**：①是否肠梗阻？②机械性 vs 动力性？③单纯性 vs 绞窄性？④高位 vs 低位？⑤完全性 vs 不完全性？⑥梗阻原因？

### 绞窄性肠梗阻的提示

- 持续剧烈腹痛无间歇
- 早期出现休克，抗休克效果欠佳
- 腹膜炎体征（腹膜刺激征阳性）
- 血性呕吐物/血便、腹穿抽出血性液体
- X线显示孤立胀大、位置固定的肠袢

### 鉴别诊断

急性胰腺炎、急性胃肠炎、泌尿道结石、卵巢囊肿扭转等引起急性腹痛的疾病。

## 治疗原则

总原则：**纠正全身代谢紊乱、解除梗阻**。

### 基础治疗

胃肠减压、纠正水电解质酸碱平衡紊乱、抗生素、禁食、生长抑素（减少消化液分泌）。

### 手术治疗

绞窄性肠梗阻和大多数机械性肠梗阻需手术。

| 术式 | 适用情况 |
|------|----------|
| 粘连松解术 | 粘连性肠梗阻 |
| 肠切除+吻合术 | 坏死肠管（绞窄/肿瘤） |
| 肠短路吻合术 | 肿瘤无法切除 |
| 肠造口术 | 结肠梗阻、一般情况差 |

## 常见特殊类型肠梗阻

### 粘连性肠梗阻

- **最常见**的机械性肠梗阻类型
- 病因：腹部手术史（最常见）、腹膜炎
- **预防重于治疗**：术中减少浆膜损伤、防粘连材料、早期下床活动
- 治疗：多数可保守治疗成功；出现绞窄征→立即手术

### 肠扭转

- 一段肠袢沿其系膜长轴旋转→闭袢性+绞窄性肠梗阻
- **小肠扭转**：饱餐后剧烈活动→突发脐周剧痛→早期出现休克
- **乙状结肠扭转**：老年便秘者→腹痛+明显腹胀（不对称）+X线"鸟嘴征"
- 治疗：紧急手术复位+/-肠切除

### 肠套叠

- 一段肠管套入与其相连的肠管内
- **好发**：<2岁婴幼儿（原发性、回盲部多见）
- **三联征**：阵发性腹痛+果酱样血便+腹部"腊肠样"肿块
- 治疗：钡剂/空气灌肠复位（早期首选）；手术（晚期/失败/疑绞窄）
