# 冠心病

> 冠状动脉粥样硬化导致管腔狭窄或闭塞，引起心肌缺血、缺氧或坏死的心脏病，是动脉粥样硬化导致器官病变的最常见类型。

## 概述

冠状动脉粥样硬化性心脏病（coronary atherosclerotic heart disease）指冠状动脉发生[[动脉粥样硬化]]引起管腔狭窄或闭塞，导致心肌缺血、缺氧或坏死，简称冠心病（coronary artery disease, CAD；或 coronary heart disease, CHD），亦称缺血性心脏病（ischemic heart disease）。

冠心病是动脉粥样硬化性心血管疾病（ASCVD）的最常见类型，多发于 40 岁以上成人，男性发病早于女性，近年来发病呈年轻化趋势。

## 动脉粥样硬化（Atherosclerosis）

### 病因与危险因素

病因尚未完全确定，多种因素作用于不同环节：

| 分类 | 危险因素 | 说明 |
|------|----------|------|
| 不可改变 | 年龄 | 40 岁以上多见，49 岁后进展加快 |
| 不可改变 | 性别 | 男性高于女性（雌激素有保护作用），女性绝经期后发病率迅速增加 |
| 最重要 | **血脂异常** | TC、TG、LDL-C、VLDL-C、apo B 增高；HDL-C、apo A 降低。**LDL-C 是致动脉粥样硬化最肯定的因素**，是防治 ASCVD 的首要干预靶点 |
| 主要 | [[高血压]] | 内皮细胞损伤，LDL-C 易于进入动脉壁；60%~70% 冠脉粥样硬化者有高血压，患病风险增加 3~4 倍 |
| 主要 | [[糖尿病]]和糖耐量异常 | 发病率高出 2~4 倍，病变更早、更弥漫；2 型糖尿病视为"冠心病等危症" |
| 主要 | 吸烟 | 发病率和病死率增高 2~6 倍，与每日吸烟支数成正比；被动吸烟也是危险因素 |
| 主要 | 肥胖 | BMI ≥ 28 kg/m² 为肥胖；常伴高血压、糖尿病 |
| 主要 | 家族史 | 一级亲属男性 < 55 岁、女性 < 65 岁发病；[[家族性高胆固醇血症]]是常见因素 |

其他危险因素：A 型性格、口服避孕药、高热量/高脂饮食、缺乏体力活动、睡眠障碍等。

### 发病机制

**"损伤反应学说"**——动脉粥样硬化是一种炎症性疾病：

```
各种致炎因素（oxLDL-C、血管紧张素Ⅱ、尼古丁、血流切应力等）
        ↓
    内皮损伤（始动因素）
        ↓
  内皮表达黏附分子（P-选择素、VCAM-1）
        ↓
  单核细胞、淋巴细胞黏附并穿透内皮
        ↓
  单核细胞 → 巨噬细胞 → 吞噬 oxLDL-C → 泡沫细胞（脂质条纹）
        ↓
  炎症细胞释放 MCP-1、PDGF、FGF、TNF-α、IL-1
        ↓
  平滑肌细胞迁移增殖 + 细胞外基质合成 → 纤维斑块
        ↓
  炎症细胞凋亡 → MMPs 降解纤维帽 → 斑块破裂 → 血栓形成
```

靶向 IL-1β 的单克隆抗体卡纳单抗可在不降低血脂的情况下减少心血管事件，进一步验证了"炎症假说"。

### 病理解剖分型

动脉粥样硬化累及大型肌弹力型动脉（主动脉）和中型肌弹力型动脉（冠状动脉、脑动脉最常受累）。

| 分型 | 名称 | 特征 |
|------|------|------|
| Ⅰ型 | 脂质点 | 内膜小黄点，少量泡沫细胞 |
| Ⅱ型 | 脂质条纹 | 内膜黄色条纹，泡沫细胞成层，平滑肌细胞含脂滴 |
| Ⅲ型 | 斑块前期 | 细胞外出现脂滴，形成脂核但未形成脂质池 |
| Ⅳ型 | 粥样斑块 | 脂质池形成，内膜结构破坏，动脉壁变形 |
| **Ⅴ型** | **纤维粥样斑块** | **最具特征性病变**，纤维帽覆盖脂质池，管腔狭窄 |
| Ⅵ型 | 复合病变 | 纤维斑块 + 出血、坏死、溃疡、钙化、附壁血栓 |

**临床分类（更实用）**：

| 斑块类型 | 特点 | 临床后果 |
|----------|------|----------|
| 稳定型斑块 | 纤维帽厚，脂质池小 | 固定狭窄，CCS（稳定型心绞痛） |
| 不稳定型（易损型）斑块 | 纤维帽薄，脂质池大 | 斑块破裂 → ACS（UA/NSTEMI/STEMI） |

## 冠心病的分型

| 分类 | 包含类型 | 病理基础 |
|------|----------|----------|
| **慢性冠脉综合征（CCS）** | 稳定型心绞痛、缺血性心肌病、隐匿型冠心病、ACS 后稳定期或血运重建后稳定期 | 固定狭窄（斑块稳定） |
| **急性冠脉综合征（ACS）** | UA、NSTEMI、STEMI、猝死 | 斑块破裂/糜烂 + 血栓形成 ± 血管痉挛 |

CCS 和 ACS 是冠心病不同演变阶段：斑块破裂或侵蚀引起急性血栓事件时，CCS 即转变为 ACS。

### 发病机制（心肌缺血）

心肌氧摄取率已达 65%~75%（近乎最大），需氧增加时只能靠增加冠脉血流：

- **CCS 机制**：冠脉固定狭窄 ≥ 50%~75%，静息时能代偿，劳力/激动时需氧增加 → 供需失衡 → 心绞痛
- **ACS 机制**：不稳定斑块破裂/糜烂 + 血小板聚集/血栓形成 → 管腔急剧狭窄或闭塞 → 心肌氧供急剧减少

## 稳定型心绞痛（Stable Angina Pectoris）

稳定性心绞痛也称**劳力性心绞痛**，特点为阵发性前胸部压榨性疼痛，主要位于胸骨后，可放射至心前区和左上肢尺侧，常发生于劳力负荷增加时，持续数分钟，休息或含服硝酸酯制剂后缓解。疼痛性质、程度、频度、持续时间及诱发因素在数月内无明显变化。

### 临床表现

#### 症状

| 特征 | 描述 |
|------|------|
| 诱因 | 体力劳动、情绪激动（愤怒、焦急、兴奋）、饱食、寒冷、吸烟、心动过速、[[休克]]；疼痛发生于**劳力当时**（而非劳累之后） |
| 部位 | 胸骨体后，手掌大小，可波及心前区；放射至左肩、左臂内侧达无名指和小指，或至颈、咽、下颌 |
| 性质 | 压迫、发闷、紧缩感或烧灼感，**非针刺或刀扎样锐痛**；偶伴濒死感 |
| 持续时间 | 数分钟至十余分钟，多为 3~5 分钟，**不超过半小时** |
| 缓解方式 | 停止活动后缓解；舌下含服硝酸甘油等硝酸酯类药物在数分钟内缓解 |

#### 体征

平时一般无异常。发作时：

| 体征 | 说明 |
|------|------|
| 心率增快、血压升高、表情焦虑、皮肤冷或出汗 | 交感神经兴奋 |
| 第四或第三心音奔马律 | 心肌缺血致顺应性降低 |
| 暂时性心尖部收缩期杂音 | 乳头肌缺血 → 二尖瓣关闭不全 |

### 辅助检查

#### 心电图（ECG）

| 类型 | 表现 |
|------|------|
| 静息 ECG | 约半数正常；可能有陈旧性心梗改变或非特异性 ST-T 改变 |
| **发作时 ECG** | **ST 段压低 ≥ 0.1mV（心内膜下缺血）**，缓解后恢复；有时 T 波倒置或"假性正常化" |
| [[负荷试验\|ECG 负荷试验]]（平板运动） | ST 段水平形或下斜形压低 ≥ 0.1mV（J 点后 60~80ms）持续 2 分钟为阳性；有一定假阳性和假阴性 |
| Holter（24h 动态 ECG） | 发现 ST-T 动态改变、无症状性心肌缺血 |

> **禁忌**：心梗急性期、不稳定型心绞痛、明显[[心力衰竭]]、严重[[心律失常]]者禁做运动试验。

#### 其他检查

| 检查 | 用途 |
|------|------|
| 冠脉 CTA | 阴性预测价值高，判断管腔狭窄程度和斑块性质；CT-FFR < 0.80 提示心肌缺血 |
| 超声心动图 | 评估室壁运动，排除[[心脏瓣膜病]]（如主动脉瓣狭窄）、肥厚型心肌病 |
| 放射性核素（心肌灌注显像） | 负荷/静息对比判断缺血区 |
| **冠脉造影** | **诊断"金标准"**，管腔直径减少 70%~75% 以上严重影响血供 |
| IVUS / OCT | 斑块性质、腔内影像 |
| FFR / QFR | 冠脉功能学评估 |

#### 实验室检查

血糖、血脂了解危险因素；cTn、CK-MB 与 ACS 鉴别；NT-proBNP 了解心功能；血常规排除[[贫血]]。

### 严重程度分级（CCS 分级）

| 分级 | 描述 |
|------|------|
| Ⅰ级 | 日常体力活动不受限，仅在强、快或持续用力时发生心绞痛 |
| Ⅱ级 | 一般活动轻度受限：快走、饭后、寒冷、精神应激时发作；平地步行 200m 以上或登楼一层以上受限 |
| Ⅲ级 | 一般活动明显受限：平地步行 200m 内或登楼一层即诱发 |
| Ⅳ级 | 轻微活动或休息时即可发生 |

### 诊断与鉴别诊断

典型心绞痛特点 + 年龄/危险因素 + 发作时 ST-T 改变（或[[负荷试验]]阳性）即可诊断。

| 鉴别 | 关键区别 |
|------|----------|
| 急性冠脉综合征（UA/NSTEMI/STEMI） | 诱因不同（休息或轻微活动诱发）；心梗疼痛更剧烈持久，硝酸甘油不能完全缓解，心肌标志物升高 |
| X 综合征（冠脉微循环病变） | 多见于女性，ECG 负荷试验阳性但冠脉造影无狭窄，预后良好 |
| 肋间神经痛/肋软骨炎 | 刺痛或灼痛、持续性、沿神经走行有压痛 |
| 心脏神经症 | 短暂刺痛或持久隐痛，疲劳后出现，硝酸甘油无效 |
| 反流性食管炎等消化系统疾病 | 与进食、体位相关的烧心感 |

### 治疗

治疗原则：改善冠脉血供 + 降低心肌耗氧 → 改善症状；同时治疗粥样硬化 → 预防心梗和死亡，延长生存期。

#### 发作时治疗

| 措施 | 具体内容 |
|------|----------|
| 休息 | 立即停止活动 |
| 硝酸甘油 | 0.5mg 舌下含化或喷吸 1~2 次；1~2 分钟起效，约半小时作用消失 |
| 硝酸异山梨酯 | 5~10mg 舌下含化；2~5 分钟见效，维持 2~3 小时 |

> **第一次含用硝酸甘油时注意体位性低血压。**

#### 缓解期治疗

**（1）改善症状、减轻缺血的药物**

| 药物类别 | 作用机制 | 常用药物 | 备注 |
|----------|----------|----------|------|
| **β 受体拮抗剂** | 减慢心率、减弱心肌收缩力、降低血压 → 降低心肌耗氧 | 美托洛尔、比索洛尔 | 目标静息心率 55~60 次/分；严重心动过缓、高度 AVB、支气管哮喘禁用 |
| 硝酸酯类 | 扩张冠脉 + 扩张周围血管，降低前后负荷 | 硝酸异山梨酯、单硝酸异山梨酯 | 需保证无药间期（8~12h）防耐药 |
| 钙通道阻滞剂 | 抑制心肌收缩、扩张冠脉和周围血管 | 硝苯地平（二氢吡啶类）、地尔硫䓬、维拉帕米 | 非二氢吡啶类有负性肌力/传导作用，与 β 阻断剂合用需谨慎 |
| 其他 | 曲美他嗪（改善代谢）、尼可地尔（K+ 通道开放）、伊伐布雷定（If 电流抑制剂） | — | 用于 β 阻断剂/钙通道阻滞剂有禁忌或不耐受时 |

**（2）预防心肌梗死、改善预后的药物**

| 药物类别 | 核心药物 | 说明 |
|----------|----------|------|
| **抗血小板药物** | 阿司匹林 75~150mg/d（基石） | 所有无禁忌者均应使用；不耐受者用氯吡格雷 75mg/d 替代 |
| **调脂药物** | **他汀类**（阿托伐他汀、瑞舒伐他汀等） | 无论血脂水平如何，均需使用；目标 LDL-C < 1.8 mmol/L（70 mg/dL） |
| | 依折麦布（胆固醇吸收抑制剂） | 单用他汀不达标时联合 |
| | PCSK9 抑制剂（依洛尤单抗等） | 进一步降低 LDL-C |
| **ACEI/ARB/ARNI** | 卡托普利、依那普利、培哚普利等 | 合并高血压、糖尿病、心衰或左心室收缩功能不全的高危病人 |
| **β 受体拮抗剂** | 同上 | 心梗后病人可减少心血管事件 |

#### 血运重建治疗

| 方式 | 说明 |
|------|------|
| **PCI（经皮冠状动脉介入术）** | 包括球囊成形、支架植入、旋磨术等；提高生活质量，但心梗发生率和死亡率与药物治疗无显著差异；FFR/QFR < 0.80 提示缺血证据时行 PCI |
| **CABG（冠状动脉旁路移植术）** | 取大隐静脉、内乳动脉等作为旁路移植材料；左主干 + 多支病变（尤其是合并糖尿病）者更倾向于 CABG |

#### 二级预防（ABCDE 方案）

| 字母 | 内容 |
|------|------|
| A | Aspirin（抗血小板）+ Antianginal therapy（抗心绞痛）+ ACEI/ARB |
| B | Beta-blocker（β 阻断剂）+ Blood pressure（控制血压） |
| C | Cholesterol（控制血脂）+ Cigarette smoking cessation（戒烟） |
| D | Diet（控制饮食）+ Diabetes management（糖尿病治疗） |
| E | Education（健康教育）+ Exercise（运动） |

## 缺血性心肌病（概述）

属于冠心病的特殊类型或晚期阶段，临床表现类似于[[扩张型心肌病]]：心脏扩大、心力衰竭、心律失常。病理基础是冠脉粥样硬化长期导致心肌缺血、坏死、纤维化和瘢痕形成。

## 隐匿型冠心病（概述）

无临床症状但有心肌缺血客观证据（静息或负荷 ECG 异常、影像学证实）的冠心病。糖尿病病人无症状心肌缺血更多见。治疗原则同稳定型心绞痛。

## 不稳定型心绞痛 / 非 ST 段抬高型心肌梗死（UA/NSTEMI）（概述）

详见 [[急性心肌梗死]] 及 ACS 相关内容。UA/NSTEMI 合称为非 ST 段抬高型急性冠脉综合征（NSTEACS）：

| 类型 | 特点 |
|------|------|
| **UA** | 新发心肌缺血（含静息性）但**无心肌坏死**，cTn 阴性 |
| **NSTEMI** | 心肌缺血更严重，伴有**心肌坏死**，cTn 阳性 |

UA 的三种临床类型：

| 类型 | 表现 |
|------|------|
| 静息型心绞痛 | 休息时发作，持续 > 20 分钟 |
| 初发型心绞痛 | 首发 1~2 个月内，很轻活动即可诱发（CCS Ⅲ级） |
| 恶化型心绞痛 | 稳定型基础上心绞痛增强（更剧烈、时间长、更频繁） |

> 变异型心绞痛（冠脉痉挛）：静息胸痛伴一过性 ST 段抬高，为 UA 的特殊类型。

### 危险分层（简化）

| 危险级别 | 标准 | 策略 |
|----------|------|------|
| 极高危 | 血流动力学不稳定/心源性休克、药物无效的反复胸痛、致命性心律失常、伴机械并发症 | 紧急侵入治疗（< 2h） |
| 高危 | cTn 阳性/NSTEMI、GRACE > 140、ST-T 动态改变 | 早期侵入策略（< 24h） |
| 中危 | 糖尿病/肾功能不全/LVEF < 40%/心梗后心绞痛/PCI 或 CABG 史、GRACE 109~140 | 选择性侵入（< 72h） |
| 低危 | 无上述危险标准，无反复发作 | 优先无创检查 |

### 治疗要点

UA/NSTEMI 的治疗原则与稳定型心绞痛一致，但更强调：

1. **双联抗血小板（DAPT）**：阿司匹林 + 替格瑞洛（首选）或氯吡格雷，至少 12 个月
2. **抗凝治疗**：在抗血小板基础上常规给予肠外抗凝（普通肝素、低分子量肝素、磺达肝癸钠或比伐芦定）
3. **他汀**：尽早（24h 内）启用，目标 LDL-C < 1.4 mmol/L（55 mg/dL）且较基线降 50%
4. **RAAS 抑制剂**：无禁忌时 24h 内启用
5. **血运重建**：极高危 < 2h，高危 < 24h，中危 < 72h

## 预后

- 稳定型心绞痛：大多数能生存多年，但有发生急性心梗或猝死的风险；预后主要取决于冠脉病变范围（左主干 > 3 支 > 2 支 > 单支病变）和心功能状态
- UA/NSTEMI：住院死亡率低于 STEMI，但长期心血管事件率接近，需坚持二级预防
