# 巨幼细胞贫血

> 巨幼细胞贫血（megaloblastic anemia, MegA）是由于维生素B₁₂和（或）叶酸缺乏导致DNA合成障碍，使细胞核发育障碍所致的一类大细胞性贫血。

## 概述

- **核心缺陷**：DNA合成障碍 → 细胞核成熟延迟 → 核幼浆老（巨幼变）
- **主要病因**：叶酸缺乏、维生素B₁₂缺乏
- **血液学特征**：大细胞性贫血 + 骨髓巨幼样变 + 中性粒细胞核右移

## 病因与危险因素

### 叶酸缺乏的原因

- **摄入不足**：长期素食、烹饪过度（叶酸不耐热）、酗酒
- **需要量增加**：妊娠、哺乳、婴幼儿、溶血性贫血、恶性肿瘤
- **吸收障碍**：小肠吸收不良（乳糜泻、Crohn病）、药物（苯妥英钠、甲氨蝶呤）
- **丢失过多**：血液透析

### 维生素B₁₂缺乏的原因

- **摄入不足**：严格素食者（B₁₂仅存在于动物性食物）
- **吸收障碍**（最常见）：
  - **内因子缺乏** → [[恶性贫血]]（pernicious anemia）——自身免疫性胃壁细胞破坏
  - 胃切除术后（内因子减少）
  - 回肠末端切除/病变（B₁₂吸收部位）
  - 小肠细菌过度生长（竞争利用B₁₂）
  - 慢性胰腺炎
- **利用障碍**：一氧化氮（笑气）暴露

## 发病机制

- **叶酸**：参与一碳单位转移，是 dTMP 合成所必需 → 缺乏时 DNA 合成受限
- **维生素B₁₂**：作为甲硫氨酸合酶的辅酶，参与叶酸代谢循环（甲基叶酸陷阱）
  - B₁₂缺乏 → 叶酸无法被利用 → 功能性叶酸缺乏 → DNA合成障碍
- **结果**：造血细胞增殖减慢、核成熟障碍 → 巨幼变、无效红细胞生成

## 临床表现

### 血液系统表现

- **贫血貌**：苍白、乏力、头晕、活动后心悸气短
- 可有轻度**黄疸**（无效红细胞生成 → 胆红素↑）
- 少数可有出血倾向（血小板减少）

### 消化系统表现

- **舌炎**：舌乳头萎缩、舌面光滑（镜面舌）、疼痛
- **消化不良**：食欲不振、腹胀、腹泻

### 神经精神系统表现（B₁₂缺乏特有）

- **周围神经病变**：手足麻木、刺痛、袜套样感觉减退
- **脊髓后索损害**：位置觉、振动觉障碍、共济失调
- **精神症状**：抑郁、记忆力减退、痴呆
- 叶酸缺乏一般不引起神经系统症状

### 其他

- 皮肤色素沉着（仅见于B₁₂缺乏）
- 不孕不育

## 辅助检查

### 血象

- **大细胞性贫血**：Hb ↓、MCV ↑（>100 fl）、MCH ↑
- RBC 内可见 **卡波环（Cabot ring）**、**豪-杰小体（Howell-Jolly body）**
- 白细胞正常或减低，**中性粒细胞核右移**（分叶过多 > 5叶）
- 血小板正常或减低，可见巨大血小板
- Ret 增高或正常

![[04 Attachments/内科-巨幼细胞贫血-P135.webp]]

### 骨髓象

- **增生活跃或明显活跃**
- **红系**：显著增生，**巨幼红细胞**（幼核老浆）> 20%，可见核畸形、碎裂、多核
- **粒系**：相对减低，中性粒细胞巨幼变，巨幼杆状核多见
- **巨核系**：正常或减低，巨核胞体大、分叶多
- **骨髓铁染色**：PAS（-）

![[04 Attachments/内科-巨幼细胞贫血-P137.webp]]

### 生化检查

- **血清叶酸** < 3 ng/mL → 叶酸缺乏
- **血清维生素B₁₂** < 200 pg/mL → B₁₂缺乏
- **诊断性治疗试验**：
  - 生理剂量叶酸或B₁₂治疗后，Ret ↑、Hb ↑ → 支持诊断
  - ⚠️ 不可用大剂量叶酸治疗B₁₂缺乏（可加重神经症状）

![[04 Attachments/内科-巨幼细胞贫血-P143.webp]]

## 诊断与鉴别诊断

### 诊断要点

1. **大细胞性贫血**（MCV > 100 fl）
2. **骨髓巨幼样变** + 中性分叶核过分叶现象
3. **叶酸和/或维生素B₁₂水平降低**
4. **诊断性治疗有效**

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|---------|
| **[[再生障碍性贫血]]** | 正细胞性贫血，骨髓增生低下，Ret ↓ |
| **[[缺铁性贫血]]** | 小细胞低色素性，铁指标异常 |
| **骨髓增生异常综合征（MDS）** | 病态造血，染色体异常，叶酸/B₁₂水平正常 |
| **红白血病（M6）** | 骨髓原始细胞↑，幼红细胞PAS（+） |

## 治疗

### 补充治疗

#### 维生素B₁₂缺乏

- **首选**：肌肉注射维生素B₁₂（羟钴胺或氰钴胺）
- **初始**：1000 μg/次，每日1次，共1周；之后每周1次，共4周；此后每月1次维持
- **终生维持**：恶性贫血、胃切除术后等病因无法根除者

#### 叶酸缺乏

- **口服叶酸**：5–15 mg/日
- **疗程**：直至Hb恢复正常
- ⚠️ **重要**：B₁₂缺乏者必须先补B₁₂再补叶酸（单独补叶酸可消耗残存B₁₂，加重神经症状）

### 疗效评估

- 治疗1–2天后 Ret ↑
- 5–10天 Ret 达高峰
- 1–2周 Hb 开始上升
- 1–2个月 Hb 恢复正常

### 病因治疗

- 改善饮食结构：增加绿叶蔬菜（叶酸）、动物肝脏/肉类/蛋奶（B₁₂）
- 治疗原发病：小肠吸收不良、寄生虫感染等
- 停用相关药物

## 预后

- 治疗反应迅速，预后良好
- 神经症状恢复较慢（B₁₂缺乏），严重者可能遗留部分后遗症
- 恶性贫血患者需终生补充VitB₁₂

## 预防

- 合理膳食：保证绿叶蔬菜（叶酸）、动物性食品（B₁₂）摄入
- 孕期适当补充叶酸（预防胎儿神经管畸形）
- 长期素食者应常规补充维生素B₁₂
- 胃切除术后定期注射VitB₁₂
