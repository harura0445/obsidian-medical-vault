# 女性生殖系统解剖


## 概述

女性生殖系统包括内、外生殖器及其相关组织。骨盆与分娩关系密切，乳房是哺乳器官，均属于女性生殖系统的范畴。

## 女性生殖器官的发育

女性胚胎性染色体为XX，未分化性腺分化为卵巢，米勒管（副中肾管）是女性生殖管道的始基，在无雄激素作用下外生殖器自然分化为女性。

### 性腺的发育

- 胚胎第3～4周：卵黄囊内胚层出现原始生殖细胞
- 胚胎第5周：形成尿生殖嵴，内侧隆起为生殖腺嵴
- 胚胎第7周前：为未分化性腺
- 胚胎第10周后：初级性索退化→卵巢髓质，次级性索构成卵巢皮质

性腺分化取决于性染色体：XX时未分化性腺皮质分化为卵巢；XY时SRY基因编码TDF诱导睾丸分化。**抗米勒管激素（AMH）** 对于男性发育至关重要，缺乏时生殖器倾向女性发育。

### 生殖管道的发育

| 管道 | 分化结果 |
|------|----------|
| 米勒管头段 | 输卵管，头端开口→输卵管伞端 |
| 米勒管中段和下段融合 | 子宫体、子宫颈、阴道上1/3 |
| 尿生殖窦盆腔内部分远端 | 尿道、阴道下2/3 |

### 外生殖器的发育

胚胎第10周开始性别分化，第12周基本完成。未融合的阴唇阴囊隆起→大阴唇，未融合的尿生殖褶→小阴唇，生殖结节→阴蒂。

## 内、外生殖器

### 外生殖器（外阴）


位于两股内侧间，前为耻骨联合，后为会阴体。

| 结构 | 要点 |
|------|------|
| 阴阜 | 耻骨联合前面脂肪垫，青春期生长阴毛 |
| 大阴唇 | 纵行皮肤皱襞，含丰富血管、淋巴管和神经，外伤后易形成血肿 |
| 小阴唇 | 大阴唇内侧薄皮肤皱襞，富含神经末梢，非常敏感 |
| 阴蒂 | 与男性阴茎同源，由海绵体构成，具勃起性，富含神经末梢 |
| 阴道前庭 | 菱形区域，含前庭球、前庭大腺、尿道外口、阴道口及处女膜 |

**前庭大腺（巴氏腺）**：如黄豆大，腺管开口于阴道前庭后方。性兴奋时分泌黏液润滑。腺管口闭塞可形成囊肿，伴感染则形成脓肿。

### 内生殖器

位于真骨盆内，包括阴道、子宫、输卵管和卵巢。

#### 阴道

- 上宽下窄，前壁7～9cm，后壁10～12cm
- 阴道穹隆分前、后、左、右4部分，**后穹隆最深**，与直肠子宫陷凹紧密相邻，可经此穿刺引流或手术入路
- 黏膜为**非角化复层扁平上皮**，无腺体，受性激素影响有周期性变化
- 富有静脉丛，损伤易出血或形成血肿

#### 子宫


- 倒置梨形，重50～70g，长7～8cm，宽4～5cm，厚2～3cm
- 分为子宫体、子宫颈，二者间最狭窄处称**子宫峡部**（非孕期长约1cm，妊娠末期可达7～10cm形成子宫下段，为剖宫产常用切口部位）
- 子宫体与子宫颈比例：青春期前1:2，生育期2:1，绝经后1:1

**组织结构**：
- **子宫内膜**：功能层（受激素调控脱落）+ 基底层（不受激素影响）
- **子宫肌层**：平滑肌三层，中层"8"字形围绕血管，收缩时可压迫止血
- **子宫浆膜层**：覆盖子宫底部及前后面的脏腹膜

子宫颈管黏膜为单层高柱状上皮，阴道部为复层扁平上皮，**柱状上皮与鳞状上皮移行区是子宫颈癌的好发部位**。

**四对子宫韧带**：

| 韧带 | 功能 |
|------|------|
| 子宫阔韧带 | 限制子宫向两侧倾斜，内含血管、神经、淋巴管 |
| 子宫圆韧带 | 维持子宫前倾位置 |
| 子宫主韧带 | 固定子宫颈位置，**防止子宫脱垂的主要结构** |
| 子宫骶韧带 | 向后上牵引子宫颈，与圆韧带协同维持前屈前倾 |

#### 输卵管

全长8～14cm，由内向外分为4部分：间质部→峡部→壶腹部（**受精常发生于此**）→伞部（"拾卵"作用）。输卵管肌肉收缩和黏膜上皮均受性激素影响有周期性变化。

#### 卵巢

扁椭圆形性腺，约4cm×3cm×1cm，重5～6g。由外侧骨盆漏斗韧带和内侧卵巢固有韧带悬于盆壁与子宫之间。实质分为外层皮质（各级卵泡、黄体）和内层髓质（血管、神经、淋巴管）。

## 血管、淋巴及神经


### 动脉供应

| 动脉 | 来源 | 供应范围 |
|------|------|----------|
| 卵巢动脉 | 腹主动脉 | 卵巢、输卵管 |
| 子宫动脉 | 髂内动脉前干 | 子宫、子宫颈、阴道上段，在子宫颈外侧约1.5～2cm处**横跨输尿管** |
| 阴道动脉 | 髂内动脉前干 | 阴道中下段 |
| 阴部内动脉 | 髂内动脉前干 | 肛门、会阴、外生殖器 |

### 静脉

与同名动脉伴行，数目多于动脉，形成静脉丛并相互吻合。**左侧卵巢静脉直角汇入左肾静脉**，易发生回流受阻，故左侧盆腔静脉曲张较多。

### 淋巴引流

- **外生殖器淋巴**：腹股沟浅淋巴结→腹股沟深淋巴结→髂外淋巴结
- **内生殖器淋巴**：髂淋巴组、骶前淋巴组、腰淋巴组（腹主动脉旁）
- 阴道下段→腹股沟浅淋巴结；阴道上段、子宫颈→髂内及闭孔淋巴结
- 感染或恶性肿瘤时沿淋巴回流途径扩散转移

### 神经支配

- **外生殖器**：阴部神经（第2～4骶神经），含感觉和运动纤维
- **内生殖器**：自主神经（交感+副交感），下腹下丛（盆丛）分布
- 子宫平滑肌有自主节律活动，切除神经后仍能有节律收缩和分娩

## 骨盆及骨盆底


### 骨盆的组成

由骶骨、尾骨及左右两块髋骨（髂骨、坐骨、耻骨融合）组成。重要关节：耻骨联合（妊娠期受性激素影响变松动）、骶髂关节、骶尾关节。重要韧带：**骶棘韧带**（其宽度即坐骨切迹宽度，判断中骨盆狭窄的重要指标）、骶结节韧带。

### 骨盆分界

以耻骨联合上缘、髂耻缘、骶岬上缘连线为界：
- **假骨盆（大骨盆）**：分界线以上，与产道无直接关系
- **真骨盆（小骨盆）**：分界线以下，为胎儿娩出的骨产道

**坐骨棘**位于真骨盆中部，是衡量中骨盆横径和**胎先露下降程度**的重要标志。

### 骨盆类型（Callwell与Moloy分类）

| 类型 | 特征 | 我国女性占比 |
|------|------|-------------|
| 女型 | 入口横椭圆形，耻骨弓宽，坐骨棘间径≥10cm | 52%～58.9% |
| 扁平型 | 入口扁椭圆形，骶骨短，骨盆浅 | 23.2%～29% |
| 类人猿型 | 入口长椭圆形，前后径>横径，骨盆深 | 14.2%～18% |
| 男型 | 入口略呈三角形，漏斗形，易造成难产 | 1%～3.7% |

### 骨盆底


封闭骨盆出口，由多层肌肉和筋膜构成，承托盆腔脏器。

| 层次 | 组成 | 功能 |
|------|------|------|
| 外层 | 球海绵体肌、坐骨海绵体肌、会阴浅横肌、肛门外括约肌 | 汇合于中心腱 |
| 中层（尿生殖膈） | 会阴深横肌、尿道括约肌 | 覆盖骨盆出口前三角 |
| 内层（盆膈） | 肛提肌（耻尾肌+髂尾肌+坐尾肌） | **最重要支持结构** |

**会阴体**位于阴道口与肛门之间，厚3～4cm，妊娠后期变软，分娩时需保护避免裂伤。

## 邻近器官

女性生殖器与尿道、膀胱、输尿管、直肠、阑尾相邻。

| 器官 | 临床要点 |
|------|----------|
| 尿道 | 短而直（4～5cm），与阴道邻近，易发生泌尿系统感染 |
| 膀胱 | 排空时位于耻骨联合与子宫之间，充盈时可上移至腹腔 |
| 输尿管 | 在子宫颈外侧约1.5～2cm处**子宫动脉下方穿过**，手术时应避免损伤 |
| 直肠 | 前壁与阴道后壁相邻，分娩时保护会阴避免损伤肛管 |
| 阑尾 | 阑尾炎时可累及右侧附件，妊娠期增大子宫将阑尾推向外上侧 |

## 乳房

成年女性乳房位于第2～6肋水平。乳腺有15～20个乳腺叶，以乳头为中心呈**放射状**排列，脓肿切开引流时宜做放射状切口避免损伤输乳管。乳腺生理活动受腺垂体、肾上腺皮质、卵巢等分泌的激素影响。
