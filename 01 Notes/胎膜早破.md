# 胎膜早破

![[04 Attachments/妇产科-胎膜早破_p2.webp]]

## 概述

临产前胎膜自然破裂称为胎膜早破（PROM）。

| 分类 | 定义 |
|------|------|
| **足月胎膜早破** | 妊娠≥37周发生 |
| **未足月胎膜早破（PPROM）** | 妊娠＜37周发生 |

PPROM是早产的主要原因之一，单胎发生率2%～4%，双胎7%～20%。孕周越小，围产儿预后越差。

## 病因

1. **生殖道感染**：是最主要原因。厌氧菌、衣原体、B族链球菌（GBS）、淋病奈瑟球菌等上行感染→胎膜局部张力下降
2. **羊膜腔压力升高**：双胎、羊水过多、巨大胎儿
3. **胎膜受力不均**：胎位异常、头盆不称、宫颈机能不全
4. **创伤**：羊膜腔穿刺不当、性生活、腹部撞击
5. **营养因素**：铜、锌及维生素缺乏→胶原纤维/弹力纤维合成障碍
6. **其他**：PPROM史、妊娠中晚期出血、宫颈长度缩短、吸烟吸毒

## 临床表现

典型症状：突感较多液体自阴道流出，增加腹压时流液增多。少量间断流液需与尿失禁、阴道炎溢液鉴别。

## 诊断

### 胎膜早破的诊断

| 方法 | 阳性标准 |
|------|---------|
| 窥器检查 | 液体自宫颈口流出或后穹隆有液池形成 |
| 超声检查 | 羊水量较破膜前减少 |
| 阴道液pH测定 | pH≥6.5（羊水pH 7.1～7.3），注意血液/精液/细菌污染可致假阳性 |
| 阴道液涂片（ferning试验） | 见到羊齿状结晶 |
| 生化检测 | IGFBP-1、sICAM-1、PAMG-1，灵敏度及特异度高，不受外界干扰 |

### 绒毛膜羊膜炎的诊断

母体体温≥38℃伴有以下任一项：①阴道分泌物异味；②胎心率≥160次/分或母体心率≥100次/分；③母体外周血白细胞≥15×10⁹/L；④子宫激惹、宫体压痛。

## 对母儿的影响

| 对象 | 影响 |
|------|------|
| **母体** | 感染（随破膜时间和羊水减少程度加重）、胎盘早剥、剖宫产率增加 |
| **围产儿** | 早产、感染（吸入性肺炎、颅内感染、败血症）、脐带脱垂/受压、胎肺发育不良、胎儿骨骼发育异常（破膜早+羊水过少严重者） |

## 处理

![[04 Attachments/妇产科-胎膜早破_p16.webp]]

### 足月胎膜早破

- 破膜超过12小时应预防性应用抗菌药物
- 无剖宫产指征者：**破膜后2～12小时积极引产**
- 宫颈成熟：缩宫素引产；宫颈不成熟：前列腺素制剂促宫颈成熟

### 未足月胎膜早破

根据孕周、母胎状况、新生儿救治水平及家属意愿综合决策。

| 孕周 | 处理原则 |
|------|---------|
| **＜24周** | 胎儿存活率极低，母胎感染风险大，以引产为宜 |
| **24～27周** | 根据家属意愿及新生儿抢救能力决定是否期待治疗 |
| **28～33周** | 无继续妊娠禁忌（感染、胎盘早剥、脐带脱垂、胎儿窘迫）→期待治疗 |
| **34～36周** | 个体化处理，一般建议终止妊娠；不再使用宫缩抑制剂；GBS筛查阳性不建议期待 |

### 期待治疗内容

1. **促胎肺成熟**：＜34周予地塞米松/倍他米松
2. **预防感染**：抗菌药物5～7日为一个疗程；GBS阳性者首选青霉素
3. **抑制宫缩**：＜34周给予宫缩抑制剂48小时（配合糖皮质激素完成促肺成熟+宫内转运），感染/胎盘早剥时禁用
4. **胎儿脑神经保护**：＜34周有早产风险者予硫酸镁静滴预防早产儿脑瘫

## 预防

- 预防和治疗生殖道感染
- 补充足量维生素、钙、铜、锌
- 宫颈机能不全者行宫颈环扎术
- 避免突然腹压增加
