# 排卵障碍性异常子宫出血


## 概述


异常子宫出血（AUB）是指与正常月经的周期频率、规律性、经期长度、经期出血量不同，来源于子宫腔内的异常出血。与[[女性生殖系统生理|正常月经生理]]和[[闭经]]相对应，AUB是月经异常的常见表现。AUB-O约占AUB的50%，其中无排卵性AUB常见于青春期和绝经过渡期，排卵性AUB多发生于生育期。PCOS是AUB-O的常见原因之一，详见[[多囊卵巢综合征]]。AUB-M需排除[[绝经综合征|围绝经期]]子宫内膜癌变。

**PALM-COEIN分类**（9个亚型）：

| 分类 | 亚型 | 性质 |
|------|------|------|
| **P** | 子宫内膜息肉（AUB-P） | 器质性 |
| **A** | 子宫腺肌病（AUB-A） | 器质性 |
| **L** | 子宫平滑肌瘤（AUB-L） | 器质性 |
| **M** | 子宫内膜恶变和不典型增生（AUB-M） | 器质性 |
| **C** | 全身凝血相关疾病（AUB-C） | 非器质性 |
| **O** | 排卵障碍（AUB-O） | 非器质性 |
| **E** | 子宫内膜局部异常（AUB-E） | 非器质性 |
| **I** | 医源性（AUB-I） | 非器质性 |
| **N** | 未分类（AUB-N） | 非器质性 |

AUB-O约占AUB的50%，曾称"功能失调性子宫出血"（功血）。分为无排卵性和排卵性两类，详见[[多囊卵巢综合征|PCOS]]、[[闭经|闭经的WHO分型]]。

## 一、无排卵性异常子宫出血

### 病因与发病机制

正常月经的发生是下丘脑-垂体-卵巢轴调控下的周期性子宫内膜剥脱性出血。当机体受精神紧张、营养不良、代谢紊乱等影响时，可通过大脑皮质引起HPO轴功能失调。[[闭经|无排卵]]是导致AUB-O的核心机制。

**好发年龄及原因**：

| 时期 | 原因 |
|------|------|
| **青春期** | HPO轴反馈调节尚未成熟，FSH持续低水平，无LH峰形成 |
| **生育期** | 应激、肥胖、PCOS等因素 |
| **绝经过渡期** | 卵巢功能衰退，卵泡对促性腺激素反应低下，FSH升高但不形成排卵前LH峰 |

**出血机制**：
- **雌激素突破性出血（BTB）**：单一雌激素作用而无孕酮拮抗。低水平→间断少量出血；高水平→一段闭经后大量出血
- **雌激素撤退性出血**：雌激素水平突然下降，内膜失去支持而剥脱

**子宫内膜出血自限机制缺陷**：组织脆性增加、脱落不完全、血管结构与功能异常、凝血与纤溶异常、血管舒缩因子异常。

### 子宫内膜病理改变

| 病理类型 | 特点 |
|---------|------|
| **增殖期子宫内膜** | 月经后半期甚至经期仍为增殖期形态 |
| **子宫内膜增生不伴不典型增生** | 癌变风险1%～3% |
| **子宫内膜不典型增生（AEH/EIN）** | 癌变风险25%～33%，属于癌前病变（按AUB-M处理） |
| **萎缩型子宫内膜** | 少见 |

### 临床表现

月经紊乱（失去正常周期和出血自限性）：出血间隔长短不一，出血量多少不一（点滴→大量出血→贫血→休克）。可有痤疮、多毛、肥胖、泌乳。出血期间一般无腹痛。

### 诊断

必须除外造成AUB的其他原因。

**辅助检查**：

| 检查 | 目的 |
|------|------|
| **血常规** | 评估出血严重程度 |
| **hCG** | 排除妊娠相关疾病 |
| **超声** | 了解内膜厚度/回声，排除器质性病变 |
| **基础体温（BBT）** | 无排卵性呈单相型，最常用 |
| **生殖内分泌测定** | 黄体中期血孕酮<3ng/ml提示无排卵 |
| **诊断性刮宫** | 诊断+止血，适用于有性生活史、长期不规律出血、药物治疗无效或内膜癌高危因素者 |
| **宫腔镜** | 直视下活检，诊断准确率高 |

### 鉴别诊断

全身性疾病（血液病、肝病、甲状腺疾病）、异常妊娠或妊娠并发症、生殖道感染、生殖器官肿瘤、生殖道损伤、药物/IUD/异物、其他PALM-COEIN类型。

### 治疗

**治疗原则**：尽快止血、纠正贫血；调整月经周期，防止内膜病变和AUB复发。

| 时期 | 治疗重点 |
|------|---------|
| 青春期 | 止血、调经 |
| 生育期 | 止血、调经 + 促排卵（有生育要求者） |
| 绝经过渡期 | 止血、调经 + 除外内膜癌变 |

#### 止血

**性激素**（首选）：

| 方法 | 机制 | 适用 |
|------|------|------|
| **孕激素内膜脱落法** | 内膜转化为分泌期后完整脱落（"药物刮宫"） | Hb>90g/L、生命体征稳定 |
| **孕激素内膜萎缩法** | 高效合成孕激素使内膜萎缩 | 出血量较多 |
| **复方短效口服避孕药** | 雌孕激素同步作用 | 青春期和生育期首选 |
| **雌激素内膜修复法** | 大剂量雌激素促进内膜生长修复创面 | Hb<90g/L的青春期（较少用） |
| **GnRH-a** | 抑制[[女性生殖系统生理\|HPO轴]]至绝经后水平 | 难治性AUB |

**刮宫术**：迅速止血+诊断价值。适用于大量出血药物治疗无效、需内膜组织学检查者。绝经过渡期及病程长的生育期患者应首先考虑。

**辅助治疗**：氨甲环酸、酚磺乙胺、纠正贫血、预防感染。

#### 调节周期

| 方法 | 适用 |
|------|------|
| **孕激素后半周期疗法** | 各年龄段，体内有一定雌激素水平 |
| **复方短效口服避孕药** | 月经量多、痛经、痤疮、避孕需求 |
| **雌孕激素序贯法（人工周期）** | 内源性雌激素不足 |
| **LNG-IUS** | 生育期/围绝经期无生育需求，多种药物治疗失败 |

#### 促排卵

生育期有生育要求者：氯米芬（CC）、来曲唑（LE）、尿促性素（hMG）、绒促性素（hCG）。

#### 手术治疗

子宫内膜切除术（无生育要求、药物治疗不佳）；子宫切除术（各种治疗无效的最终选择）。

#### 不同时期的治疗选择要点

- **青春期**：首选孕激素脱落法或COC止血；不常规推荐诊刮术和宫腔镜
- **生育期**：止血同上，有生育要求者促排卵，无生育要求者推荐COC或LNG-IUS
- **绝经过渡期**：不推荐COC（血栓风险）；推荐诊刮/宫腔镜首次止血；LNG-IUS可长期保护子宫内膜

### 预后

青春期大部分3年内建立正常周期，病程>4～8年较难自然痊愈。生育期促排卵后妊娠可能性大，产后多数仍无排卵需长期管理。绝经过渡期多以绝经告终，个别发生癌变。

## 二、排卵性异常子宫出血

### 黄体功能不足

**机制**：FSH缺乏致卵泡发育不良、LH脉冲峰值不高致黄体发育不全。

**病理**：分泌反应落后2日。

**临床表现**：月经周期缩短（黄体期<11日）；不易受孕或早期流产。

**诊断**：BBT双相型但高温相<11日；内膜活检分泌反应落后2日。

**治疗**：促卵泡发育（CC/LE）；绒促性素促LH峰形成；黄体功能刺激/补充疗法（天然黄体酮）。

### 子宫内膜不规则脱落

**机制**：下丘脑-垂体-卵巢轴调节功能紊乱，黄体萎缩不全，内膜持续受孕激素影响不能如期完整脱落。

**病理**：月经第5～6日仍见分泌反应内膜（混合型子宫内膜）。

**临床表现**：周期正常，经期延长（9～10日）。

**诊断**：BBT双相型但下降缓慢；月经第5～7日诊刮病理仍示分泌期改变。

**治疗**：排卵后1～2日或下次月经前10～14日口服孕激素；或绒促性素促黄体功能；COC控制周期。

## AUB-E（子宫内膜局部异常）

原发于子宫内膜局部异常的AUB。有规律排卵，排除其他原因。可表现为月经过多、经间期出血或经期延长。

治疗：LNG-IUS首选（近1年无生育要求）；氨甲环酸/NSAIDs；短效口服避孕药；孕激素内膜萎缩治疗。

## 预后与随访

AUB-O是慢性疾病，需要长期管理。治疗后应定期随访，调整周期，监测内膜，预防复发和癌变。
