# 弥散性血管内凝血

> 在感染、肿瘤、病理产科、创伤等基础上，凝血过度活化导致广泛微血栓形成，凝血因子大量消耗并继发纤溶亢进，引起出血及微循环衰竭的临床综合征。

## 概述

DIC是一种**获得性临床综合征**，以全身凝血系统激活为特征，导致：
1. **广泛微血管血栓** → 器官缺血损伤
2. **凝血因子和血小板消耗** → 出血
3. **继发性纤溶亢进** → 加重出血

总发生率约占住院患者的1/1000。

## 病因

### 急性/亚急性DIC常见原因

| 类别 | 具体病因 |
|------|----------|
| **感染** | 革兰阴性/阳性菌、真菌、病毒、立克次体、原虫 |
| **恶性肿瘤** | 最常见于血液系统肿瘤（[[急性白血病]]、[[淋巴瘤]]等） |
| **病理产科** | 羊水栓塞、感染性流产、重症妊娠高血压、HELLP综合征、胎盘早剥 |
| 严重创伤/烧伤 | 大面积组织损伤 |
| 其他 | 重症急性胰腺炎、[[系统性红斑狼疮]]、毒蛇咬伤、热射病、药物中毒 |

### 慢性DIC

主要见于恶性实体瘤、死胎综合征、进展期肝病。

## 发病机制

关键环节是**凝血酶生成过量**并引起继发性纤溶亢进：

```
致病因素
→ 组织因子（TF）大量入血  +  血管内皮损伤（内源性途径）
→ 凝血酶大量生成
→ ├─ 消耗凝血因子 → PT/APTT延长 → 出血
   ├─ 激活血小板 → 血小板消耗 → 血小板减少
   ├─ 纤维蛋白形成 → 微血管血栓 → 器官损伤 + 微血管病性溶血
   └─ t-PA释放 → 纤溶亢进 → FDP↑↑ → 加重出血
```

## 临床表现

### DIC本身的四大临床特征

| 特征 | 表现 |
|------|------|
| **出血** | 广泛皮肤瘀点瘀斑、**静脉穿刺部位渗血**（特征性）、牙龈/鼻/消化道/肺出血、颅内出血（主要死因） |
| **微循环障碍** | 与失血量不成比例的低灌注，轻者一过性血压下降，重者**休克** |
| **血栓栓塞** | 肾、肺、肾上腺、皮肤、胃肠道、脑等微血栓，出现相应器官症状 |
| **血管内溶血** | 10%~20%出现黄疸、贫血、血红蛋白尿，血涂片见破碎红细胞 |

## 实验室检查

| 检查 | 变化 |
|------|------|
| 血小板计数 | **进行性下降**（急性DIC早期即可出现） |
| PT | **延长** |
| APTT | **延长** |
| TT | 延长 |
| 纤维蛋白原 | **降低**（但早期可正常或升高） |
| FDP | **显著升高** |
| D-二聚体 | **显著升高**（对DIC诊断特异度较高） |
| 3P试验 | 阳性 |
| 血涂片 | **破碎红细胞**、畸形红细胞 |

## 诊断

### ISTH显性DIC诊断积分系统

| 指标 | 0分 | 1分 | 2分 | 3分 |
|------|-----|-----|-----|-----|
| 血小板（×10⁹/L） | ＞100 | ≤100 | ≤50 | — |
| FDP/可溶性纤维蛋白单体 | 无增加 | — | 中度增加 | 显著增加 |
| PT延长 | ＜3s | 3~6s | ＞6s | — |
| 纤维蛋白原 | ＞1.0g/L | ≤1.0g/L | — | — |

**积分≥5分** → 符合DIC，每日重复积分

### 中国CDSS积分系统（2017）

| 积分项 | 分数 |
|--------|------|
| 存在导致DIC的原发病 | 2 |
| 不能用原发病解释的出血倾向 | 1 |
| 不能用原发病解释的微循环障碍/休克 | 1 |
| 广泛微血栓/脏器功能衰竭 | 1 |
| 实验室指标（血小板、D-二聚体、PT/APTT、纤维蛋白原分别计分） | 0~8 |

非恶性血液病：**≥7分**诊断DIC；恶性血液病：**≥6分**。

## 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| **严重肝病** | 有肝病史、黄疸突出、血小板减少较轻、FDP检出率低 |
| **TTP** | 血小板减少+微血管病性溶血，但凝血因子消耗和纤溶亢进不明显 |
| **原发性纤溶亢进** | 血小板正常、D-二聚体正常/轻度增高、3P试验阴性 |

## 治疗

### 1. 去除病因（最关键）

- 感染：足量敏感抗生素
- 恶性肿瘤：相应化疗
- 病理产科：终止妊娠

### 2. 抗凝治疗

| 药物 | 用法 | 备注 |
|------|------|------|
| **普通肝素** | ≤12500U/d，每6小时≤2500U，静脉/皮下，连用3~5天 | 小剂量即可 |
| **低分子量肝素** | 3000~5000U/d，皮下注射，连用3~5天 | 出血风险较低 |

禁忌：出血型DIC

### 3. 替代治疗

| 情况 | 措施 |
|------|------|
| PT延长超过正常对照1.3~1.5倍 | 新鲜冰冻血浆 |
| 纤维蛋白原＜1.0g/L | 冷沉淀 |
| 血小板＜(10~20)×10⁹/L，或＜50×10⁹/L伴明显出血 | 血小板输注 |

### 4. 器官支持治疗

- 容量复苏、纠正低血压和酸中毒
- 吸氧、机械通气
- 血管活性药物改善器官灌注
- 维持电解质平衡

## 预后

DIC是多种危重疾病的中间环节，预后取决于原发病的控制和器官功能支持。颅内出血和MODS是主要死因。
