# 产后出血

## 概述

产后出血（PPH）指胎儿娩出后24小时内，阴道分娩者出血量≥500ml，剖宫产者≥1000ml，或失血后伴有低血容量的症状/体征。严重产后出血指出血量≥1000ml。

发病率5%～10%（实际更高，因临床往往低估出血量）。**产后出血是导致我国孕产妇死亡的首位原因。**

## 病因

**四大原因：子宫收缩乏力、胎盘因素、软产道裂伤、凝血功能障碍。** 可共存、相互影响。

### 1. 子宫收缩乏力（最常见）

| 因素类别 | 具体因素 |
|---------|---------|
| 全身因素 | 精神过度紧张、疲乏、体质虚弱、高龄、肥胖、合并慢性疾病 |
| 产科因素 | 产程延长、急产、前置胎盘、胎盘早剥、妊娠期高血压疾病、宫腔感染 |
| 子宫因素 | 子宫过度膨胀（多胎、羊水过多、巨大胎儿）；子宫肌壁损伤（剖宫产史、肌瘤切除术后、多产次）；子宫病变（肌瘤、畸形、肌纤维变性） |
| 药物因素 | 产时过多使用镇静剂、麻醉剂、子宫收缩抑制剂 |

### 2. 胎盘因素

| 类型 | 特点 |
|------|------|
| **胎盘滞留** | 胎儿娩出后30分钟胎盘未排出（膀胱充盈、胎盘嵌顿、剥离不全） |
| **胎盘植入** | 粘连性/植入性/穿透性；部分性→已剥离面血窦开放大出血，完全性→无剥离出血不多 |
| **胎盘部分残留** | 部分胎盘小叶、副胎盘或胎膜残留→影响子宫收缩 |

### 3. 软产道裂伤

会阴、阴道、宫颈裂伤，严重者可达阴道穹隆、子宫下段甚至盆壁。原因：阴道手术助产、巨大胎儿、急产、软产道静脉曲张、组织弹性差。

**会阴裂伤分度**：

| 分度 | 损伤范围 |
|------|---------|
| Ⅰ度 | 会阴皮肤+阴道入口黏膜 |
| Ⅱ度 | 会阴体筋膜及肌层，累及阴道后壁黏膜 |
| Ⅲ度 | 肛门外括约肌断裂，直肠黏膜完整 |
| Ⅳ度 | 肛门、直肠和阴道完全贯通 |

### 4. 凝血功能障碍

原发（血小板减少、再障、肝病）或继发（DIC：胎盘早剥、死胎、羊水栓塞、重度子痫前期等产科并发症引起）。

## 诊断

关键在于**正确测量和估计出血量**，低估会丧失抢救时机。

### 出血量估计方法

| 方法 | 操作 |
|------|------|
| **称重法** | 失血量(ml)=[接血后湿重(g)-接血前干重(g)]/1.05 |
| **容积法** | 接血容器→量杯测量 |
| **面积法** | 按纱布浸血面积估计 |
| **休克指数法** | SI=脉率/收缩压；SI=1.0→失血1000ml(20%)；SI=1.5→1500ml(30%)；SI=2.0→≥2500ml(50%) |

### 出血原因判断

| 出血特点 | 提示原因 |
|---------|---------|
| 胎儿娩出后立即流出鲜红色血 | 软产道裂伤 |
| 胎儿娩出后数分钟流出暗红色血 | 胎盘因素 |
| 胎盘娩出后阴道流血较多 | 宫缩乏力/胎盘胎膜残留 |
| 血液不凝、持续出血 | 凝血功能障碍 |
| 阴道流血不多但低血容量明显+阴道疼痛 | 隐匿性软产道损伤（阴道血肿） |

## 处理

处理原则：**针对病因迅速止血、补充血容量纠正休克、防治感染。**

### 一般处理

呼叫支援、交叉配血、建立双静脉通道、保持气道通畅给氧、监测生命体征和出血量、留置尿管。

### 氨甲环酸

适用于各种病因的PPH，**产后3小时内尽早使用**：1g静滴（≥10分钟），30分钟后仍出血或24小时后再次出血可重复1次。

### 针对病因的处理

#### 子宫收缩乏力

1. **按摩/按压子宫**：腹部按摩法、腹部-阴道双手压迫法
2. **宫缩剂**：
   - 缩宫素：一线药物，5～10U/h持续静滴，24h总量≤60U
   - 麦角新碱：0.2mg im（禁用：妊娠期高血压疾病、特定心血管病）
   - 前列腺素类：卡前列素氨丁三醇（首选肌注）
3. **宫腔填塞**：球囊填塞或纱条填塞，排除妊娠物残留和子宫破裂
4. **子宫压缩缝合术**：B-Lynch缝合及其改良术式
5. **结扎盆腔血管**：子宫动脉上行/下行支、髂内动脉
6. **经导管动脉栓塞术（TAE）**：适用于保守治疗无效、生命体征平稳者
7. **切除子宫**：积极抢救无效、危及生命时的最后手段

#### 胎盘因素

- 胎盘滞留→立即取出；胎盘粘连→徒手剥离；疑胎盘植入→**停止剥离**，根据出血和剥离面积行保守治疗或子宫切除
- 完全性胎盘植入即使无活动性出血也应直接切除子宫

#### 软产道裂伤

彻底止血、按解剖层次缝合。宫颈裂伤缝合第一针应超过裂口顶端0.5cm。阴道壁血肿→切开清除积血+缝合止血。

#### 凝血功能障碍

补充凝血因子（新鲜冰冻血浆、冷沉淀、血小板、纤维蛋白原等），并发DIC按DIC处理。

### 输血治疗

- Hb＜60g/L：几乎均需输血
- Hb＜70g/L：可考虑输血
- 大量输血方案（MTP）：红细胞∶血浆∶血小板 = 1∶1∶1

## 预防

- **产前**：加强围产保健，防治贫血
- **产时**：正确处理各产程，**预防性使用宫缩剂**是处理第三产程最重要措施
- **产后**：产后2小时内密切监测生命体征、阴道流血量、宫高、膀胱充盈；鼓励早接触、早吸吮
