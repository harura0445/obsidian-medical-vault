# 消化期胃液分泌的分期
- 人为分期，3期几乎同时开始、互相重叠
- 神经调节为主 → 体液调节为主

 ## 头期 *cephalic phase*
 - 进食刺激头面部感受器引起的**神经反射**：条件反射、非条件反射
 - 迷走神经：乙酰胆碱；[[促胃液素释放肽]] (GRP) 
 - 特点: **量大（30%），酸度高，消化力强（酶多）**

 ## 胃期 *gastric phase*
 - 食物对胃机械和化学性刺激
 - 特点：**量最大（60%）, 酸度高, 消化力不如头期(酶稍少) **
 - 机制：神经、体液因素
	 1. 机械性刺激胃底胃体 → 迷走-迷走反射 (vagovagal reflex)
	 2. 机械性刺激胃底胃体 → 壁内神经丛局部反射
	 3. 机械性刺激幽门部 → 壁内神经丛 → G细胞释放[[促胃液素]]
	 4. 蛋白质消化产物肽和氨基酸 → G细胞释放[[促胃液素]]

## 肠期 *intestinal phase*
- 食糜对肠的机械和化学刺激
- 机制：主要体液调节食糜刺激十二指肠黏膜 → [[促胃液素]]、肠泌酸素（enterooxyntin）释放
- 特点：**量少（10%）, 酸度和消化力均较弱**
