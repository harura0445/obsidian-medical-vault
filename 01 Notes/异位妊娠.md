# 异位妊娠

## 概述

受精卵在宫腔以外着床称为异位妊娠，习惯称宫外孕。发病率2%～3%，是妊娠早期孕妇死亡的主要原因。以**输卵管妊娠**最常见（占95%），其中壶腹部妊娠最多见（约78%）。

少见的异位妊娠：卵巢妊娠、腹腔妊娠、宫颈妊娠、子宫阔韧带妊娠、子宫残角妊娠、剖宫产瘢痕妊娠（CSP）、宫内宫外复合妊娠。

---

## 一、输卵管妊娠

### 病因

1. **输卵管炎症**：最主要病因。黏膜炎使管腔变窄、纤毛功能受损；周围炎使输卵管扭曲、蠕动减弱
2. **输卵管妊娠史或手术史**：1次后再发风险约10%，≥2次再发风险＞25%
3. **输卵管发育不良或功能异常**
4. **辅助生殖技术**
5. **避孕失败**：宫内节育器、紧急避孕药失败
6. **其他**：子宫肌瘤/卵巢肿瘤压迫、子宫内膜异位症

### 病理结局

| 结局 | 特点 |
|------|------|
| **输卵管妊娠破裂** | 多见于峡部，妊娠6周左右；破裂后大量腹腔内出血→休克 |
| **输卵管妊娠流产** | 多见于壶腹部/伞部，妊娠8～12周；完全流产出血不多，不全流产可反复出血 |
| 胚胎停止发育并吸收 | 常被忽略，靠血hCG诊断 |
| 陈旧性异位妊娠 | 反复内出血→血肿机化变硬→粘连 |
| 继发性腹腔妊娠 | 胚胎从输卵管排入腹腔后存活并继续生长 |

### 临床表现

**典型异位妊娠三联征：停经、腹痛、阴道流血。**

| 症状/体征 | 特点 |
|-----------|------|
| **停经** | 6～8周停经史，20%～30%无停经史 |
| **腹痛** | 占95%，为主要症状；破裂时突感一侧下腹撕裂样疼痛，可伴恶心呕吐；血液积于直肠子宫陷凹→肛门坠胀感；刺激膈肌→肩部放射痛 |
| **阴道流血** | 占60%～80%，暗红色点滴状，一般不超过月经量；可伴蜕膜管型排出 |
| **晕厥与休克** | 腹腔内出血+剧烈腹痛，**出血程度与阴道流血量不成正比** |
| **体征** | 宫颈举痛/摇摆痛（主要体征）；阴道后穹隆饱满；子宫漂浮感；附件区包块 |

### 诊断

1. **超声检查**：首选经阴道超声。宫腔内未见孕囊+宫旁异常低回声区（见卵黄囊/胚芽/心管搏动可确诊）
2. **血hCG测定**：异位妊娠hCG水平较宫内妊娠低；若≥3500IU/L宫内未见孕囊应怀疑；＜3500IU/L需动态监测
3. **经阴道后穹隆穿刺**：抽出暗红色不凝血→腹腔积血；阴性不能排除
4. **腹腔镜检查**：不再作为诊断"金标准"，更多作为治疗手段
5. **诊断性刮宫**：很少应用，仅用于鉴别不能存活的宫内妊娠

### 鉴别诊断

需与流产、急性输卵管炎、急性阑尾炎、黄体破裂、卵巢肿瘤蒂扭转鉴别。

| 鉴别点 | 输卵管妊娠 | 流产 | 阑尾炎 | 黄体破裂 |
|--------|-----------|------|--------|---------|
| 停经 | 多有 | 有 | 无 | 多无 |
| 腹痛 | 一侧撕裂样→全腹 | 下腹中央阵发性 | 转移性右下腹痛 | 一侧突发 |
| 阴道流血 | 少、暗红色 | 少→多、鲜红色 | 无 | 无或如月经量 |
| 休克/外出血 | 不成正比 | 成正比 | — | — |
| 体温 | 正常或低热 | 正常 | 升高 | 正常 |

### 治疗

#### 手术治疗

适用于：生命体征不稳定或有腹腔内出血征象、异位妊娠进展（hCG＞3000IU/L或持续升高、有胎心搏动、大包块等）、随诊不可靠、药物禁忌或无效。

| 术式 | 适用人群 |
|------|---------|
| **保守手术** | 有生育要求的年轻女性：伞部→挤压术，壶腹部→切开取胚缝合，峡部→节段切除+断端吻合 |
| **根治手术** | 无生育要求、内出血休克急症：患侧输卵管切除术 |

**持续性异位妊娠**：保守手术后残留滋养细胞继续生长，术后血hCG不降/下降不满意，可予MTX治疗。

#### 药物治疗

MTX（甲氨蝶呤）治疗条件：生命体征稳定、未破裂、包块直径＜4cm、hCG＜5000IU/L、无明显腹腔内出血。

#### 期待治疗

条件：病情稳定、包块直径≤3cm无心管搏动、hCG＜2000IU/L且下降趋势。

## 二、其他部位妊娠

| 类型 | 特点 |
|------|------|
| **卵巢妊娠** | 诊断标准：输卵管完整、孕囊在卵巢组织内、以卵巢固有韧带与子宫相连、囊壁有卵巢组织 |
| **腹腔妊娠** | 继发性为主（输卵管妊娠流产/破裂后），母体病死率约5%，确诊后立即剖腹取胎 |
| **宫颈妊娠** | 无痛性阴道流血，宫颈桶状膨大变蓝；治疗：MTX±手术治疗 |
| **子宫残角妊娠** | 多14～20周破裂，确诊后切除残角子宫 |
| **剖宫产瘢痕妊娠（CSP）** | 剖宫产远期并发症，经阴道超声+彩色多普勒诊断；一旦确诊多建议终止妊娠 |
| **复合妊娠** | 宫内妊娠+异位妊娠并存，辅助生殖后发病率增高 |
