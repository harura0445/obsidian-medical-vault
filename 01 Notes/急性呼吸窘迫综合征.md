# 急性呼吸窘迫综合征

> 急性呼吸窘迫综合征（ARDS）是指由各种肺内和肺外致病因素所导致的急性[[呼吸衰竭]]，以弥漫性肺泡损伤（DAD）为病理特征，临床表现为呼吸窘迫及难治性低氧血症，肺部影像学显示双侧弥漫性渗出改变。

2012年柏林定义取消了ALI（急性肺损伤）命名，统一称为ARDS，原ALI相当于轻度ARDS。

---

## 病因

| 类别 | 因素 |
|------|------|
| **直接肺损伤（肺内因素）** | [[肺炎]]（最常见）、胃内容物吸入、肺挫伤、吸入性损伤（有毒气体）、溺水 |
| **间接肺损伤（肺外因素）** | 非肺源性感染中毒症、大面积创伤、[[急性胰腺炎]]、重度烧伤、非心源性休克、输血相关急性肺损伤、药物过量 |
| 新型病因 | 电子烟相关肺损伤、化疗药物/免疫检查点抑制剂相关肺损伤、病毒感染（COVID-19等） |

## 病理与病理生理

### 病理分期

| 分期 | 时间 | 病理特征 |
|------|------|----------|
| **渗出期** | 发病后前7天 | **弥漫性肺泡损伤（DAD）**：肺泡上皮和内皮细胞损伤，富含蛋白质的水肿液渗出，透明膜形成，肺泡萎陷。肺大体呈"湿肺"（暗红色肝样变，重量增加，切面有液体渗出） |
| **增生期** | 7~21天 | 炎性渗出液和透明膜吸收消散，Ⅱ型肺泡上皮增生修复，分泌新的表面活性物质，可分化为Ⅰ型上皮 |
| **纤维化期** | > 3~4周 | 肺泡腔和间质纤维化，腺泡结构破坏呈肺气肿样改变及肺大疱形成，易发生气压伤，出现顽固性高碳酸血症和肺动脉高压 |

### 核心病理生理

| 改变 | 机制与后果 |
|------|-----------|
| **肺容积缩小** | 功能残气量减少，有效参与气体交换的肺泡数量显著减少 → "婴儿肺"（baby lung） |
| **肺顺应性降低** | 肺水肿、肺泡萎陷、表面活性物质减少 |
| **严重V/Q比例失调** | 以分流为主要特征 → 顽固性低氧血症 |
| **病变"不均一"分布** | 重力依赖区以水肿和肺不张为主，通气极差；非重力依赖区通气功能基本正常 |
| **肺动脉高压** | 微血管闭塞、功能残气量减少致肺血管阻力增加，严重者出现急性肺心病 |

### 呼吸窘迫的发生机制

1. 低氧血症刺激颈动脉体和主动脉体化学感受器 → 反射性过度通气
2. 肺充血水肿刺激毛细血管旁J感受器 → 感受器反射性使呼吸加深加快

> 因过度通气代偿，PaCO₂早期表现为降低或正常。

## 临床表现

- **发病时间**：多数于原发病起病后72小时内发生，几乎不超过7天
- **最早症状**：呼吸增快，并进行性加重的呼吸困难、发绀
- **呼吸窘迫特点**：呼吸深快、费力，胸廓紧束感和严重憋气，**不能用通常的吸氧疗法改善**，亦不能用其他原发心肺疾病（[[胸膜疾病|气胸]]、[[慢性阻塞性肺疾病|肺气肿]]、肺不张、[[肺炎]]、[[心力衰竭]]）解释
- **早期体征**：可无异常或仅双肺少量细湿啰音
- **后期体征**：双肺水泡音、管状呼吸音

## 辅助检查

| 检查 | 表现 |
|------|------|
| **X线胸片** | 早期可正常或轻度间质改变 → 双侧斑片状/大片状磨玻璃或实变浸润影（快速多变，符合肺水肿特点）；后期可出现纤维化 |
| **胸部CT** | 更准确但受限于辐射和转运风险，诊断仍以X线胸片为主 |
| **肺部超声** | 双侧多发B线和/或实变征象，便捷、可动态评估，敏感性好但特异性一般 |
| **动脉血气分析** | PaO₂降低，PaCO₂降低（早期），pH升高（呼吸性碱中毒）；后期pH可低于正常，PaCO₂高于正常 |
| **氧合指数（PaO₂/FiO₂）** | 正常400~500mmHg，是诊断和严重程度分级的核心指标 |
| **心脏超声** | 有助于排除心源性肺水肿，应常规检查 |

## 诊断（柏林标准 + 2023新定义）

### 柏林标准（2012）

满足以下**四项**方可诊断：

1. **时间**：明确诱因下1周内出现的急性或进展性呼吸困难
2. **影像**：X线胸片/CT显示双肺浸润影，不能完全用胸腔积液、肺叶/全肺不张和结节影解释
3. **病因**：呼吸衰竭不能完全用心力衰竭或液体过负荷解释
4. **氧合（在PEEP/CPAP ≥ 5cmH₂O下）**：

| 严重程度 | PaO₂/FiO₂ |
|----------|-----------|
| 轻度 | 200 < PaO₂/FiO₂ ≤ 300 mmHg |
| 中度 | 100 < PaO₂/FiO₂ ≤ 200 mmHg |
| 重度 | PaO₂/FiO₂ ≤ 100 mmHg |

### 2023年ATS新定义的主要更新

- 可由经过培训的操作者行胸部超声评估双肺病变替代CT
- 不再强制要求PEEP/CPAP ≥ 5cmH₂O作为诊断前提
- 引入SpO₂/FiO₂作为氧合评估指标（SpO₂ ≤ 97%时）

## 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| **心源性肺水肿** | 卧位时呼吸困难加重，咳粉红色泡沫样痰，湿啰音多在肺底部，对强心利尿治疗有效，超声心动图可见心功能异常 |
| 大面积肺不张 | 影像学可鉴别 |
| 大量胸腔积液 | 影像学/超声可明确 |
| 弥漫性肺泡出血 | 病史及血液化验 |

> 需注意心源性肺水肿和ARDS可合并存在，PAWP > 18mmHg并非ARDS的排除标准。

## 治疗

### 治疗原则

原发病的治疗 + 脏器功能支持（核心：机械通气）+ 并发症处理。

### 原发病治疗

感染是ARDS最常见诱因，应积极寻找和控制感染源，经验性选择适宜抗生素。

### 纠正缺氧

目标：PaO₂ 55~80mmHg 或 SaO₂ 88%~95%。选择能达到目标氧合的最低吸氧浓度。

### 机械通气 —— 肺保护性通气策略

ARDS肺部病变具有"不均一性"和"小肺"特点，机械通气的关键在于：**复张萎陷肺泡并维持其开放，同时避免肺泡过度扩张和反复开闭造成的损伤**。

| 策略 | 要点 |
|------|------|
| **小潮气量通气** | 潮气量 **4~8 ml/kg** 理想体重，平台压控制在 **30 cmH₂O以下** |
| **高PEEP** | 中-重度ARDS使用较高水平PEEP，维持萎陷肺泡开放，防止剪切伤；根据FiO₂-PEEP对照表等个体化调节 |
| **允许性高碳酸血症** | 小潮气量导致CO₂潴留和pH > 7.2时，容忍高碳酸血症而非将纠正高碳酸血症作为通气目标 |
| **俯卧位通气** | 强烈推荐重度ARDS每日至少12小时；改善通气血流比例、促进分泌物引流、降低病死率 |
| **肺复张** | 短时间增加气道压力使萎陷肺泡开放 |
| **神经肌肉阻滞剂** | 用于重度ARDS早期合并难治性低氧血症或人机不协调者，短期应用（< 48小时） |

### 其他治疗措施

| 治疗 | 适应证/效果 |
|------|------------|
| **ECMO** | 原发病可逆的重度ARDS的挽救性治疗：优化机械通气下仍 PaO₂/FiO₂ < 50mmHg 持续 > 3h，或 < 80mmHg 持续 > 6h，或 pH < 7.25 伴 PaCO₂ ≥ 60mmHg 持续 > 6h |
| **限制性液体管理** | 基于CVP和尿量监测保证灌注前提下限制液体，可改善氧合、缩短机械通气时间 |
| **糖皮质激素** | COVID-19所致ARDS的标准治疗之一；非COVID-19 ARDS不推荐常规应用 |
| **抗凝治疗** | 评估血栓及出血风险后给予预防性抗凝 |
| **营养支持** | 尽早（入ICU后24~48h内）开启肠内营养；俯卧位通气者优先幽门后喂养 |
| **早期康复** | 降低ICU获得性衰弱发生率，缩短机械通气时间 |
| **VAP预防** | 实施呼吸机相关肺炎集束化预防管理 |

## 预后

- 病死率：26%~44%
- 预后与原发病和严重程度相关：感染中毒症/免疫功能低下者预后差
- 单纯死于呼吸衰竭者仅16%，49%死于MODS
- 老年（> 60岁）预后不佳
- 存活者大部分肺脏能完全恢复，部分遗留肺纤维化
