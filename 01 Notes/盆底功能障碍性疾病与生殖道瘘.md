# 盆底功能障碍性疾病与生殖道瘘

![[04 Attachments/妇产科-盆底_p2.webp]]

## 盆底支持结构的腔室理论

女性盆底由封闭骨盆出口的多层肌肉和筋膜组成，尿道、阴道和直肠经此贯穿而出。盆底组织承托子宫、膀胱和直肠等盆腔脏器并保持其正常位置。[[女性生殖系统解剖|盆底解剖结构]]和[[女性生殖系统生理|雌激素水平]]是维持盆底功能的重要基础。多次[[正常分娩|阴道分娩]]、[[产后出血|产伤]]是盆底功能障碍的最常见原因。

**腔室理论**：

| 方向 | 分腔 | 结构 |
|------|------|------|
| **垂直方向** | 前腔室 | 阴道前壁、膀胱、尿道 |
| | 中腔室 | 阴道顶部、子宫 |
| | 后腔室 | 阴道后壁、直肠 |
| **水平方向（DeLancey 三水平）** | 水平1（上层） | 子宫主韧带-子宫骶韧带复合体 |
| | 水平2（旁侧） | 肛提肌群及膀胱、直肠阴道筋膜 |
| | 水平3（远端） | 会阴体及括约肌 |

## 盆腔器官脱垂

### 概述

盆腔器官脱垂（POP）指盆腔器官脱出于阴道内或阴道外。任何阴道节段的前缘达到或超过处女膜缘外1cm。可单独发生，但一般联合发生。

| 类型 | 特点 |
|------|------|
| **阴道前壁膨出** | 上2/3→膀胱膨出；下1/3→尿道膨出 |
| **阴道后壁膨出** | 直肠膨出；可伴肠疝 |
| **子宫脱垂** | 子宫颈外口达坐骨棘水平以下 |
| **阴道穹隆脱垂** | 子宫切除术后阴道顶端支持结构缺损 |

### 病因

[[正常分娩|妊娠/分娩]]（特别是困难的阴道分娩）、[[绝经综合征|衰老（绝经后支持结构萎缩）]]、腹压增加（慢性咳嗽、肥胖、便秘、持续负重）、医源性原因。

### 临床表现

**症状**：轻者无症状。重者腰骶部酸痛或下坠感（站立/劳累后加重，卧床减轻）。阴道前壁膨出：尿频、排尿困难、压力性尿失禁（可随脱垂加重而消失）；阴道后壁膨出：便秘；脱出组织长期摩擦可致溃疡、出血。一般不影响月经和受孕。

**体征**：阴道前后壁或子宫颈/子宫体脱出阴道口外。脱垂黏膜增厚角化，可有溃疡。

### 临床分度

#### 子宫脱垂中国传统分度

| 分度 | 标准 |
|------|------|
| **Ⅰ度轻型** | 子宫颈外口距处女膜缘<4cm，未达处女膜缘 |
| **Ⅰ度重型** | 子宫颈已达处女膜缘，阴道口可见子宫颈 |
| **Ⅱ度轻型** | 子宫颈脱出阴道口，子宫体仍在阴道内 |
| **Ⅱ度重型** | 部分子宫体脱出阴道口 |
| **Ⅲ度** | 子宫颈与子宫体全部脱出阴道口外 |

#### 阴道前/后壁膨出分度（中国传统）

| 分度 | 标准 |
|------|------|
| **Ⅰ度** | 达处女膜缘，仍在阴道内 |
| **Ⅱ度** | 部分突出于阴道口外 |
| **Ⅲ度** | 全部突出于阴道口外 |

#### POP-Q分度法（国际通用）

| 分度 | 标准 |
|------|------|
| **0度** | 无脱垂 |
| **Ⅰ度** | 脱垂最远端在处女膜平面上>1cm（<-1cm） |
| **Ⅱ度** | 脱垂最远端在处女膜平面≤1cm（-1～+1cm） |
| **Ⅲ度** | 脱垂最远端超过处女膜平面>1cm，但<TVL-2cm |
| **Ⅳ度** | 下生殖道全长外翻（≥TVL-2cm） |

### 诊断

根据病史及检查确诊。嘱患者向下屏气判断脱垂最重程度并分度。注意有无溃疡。膀胱充盈时咳嗽观察有无压力性尿失禁。还应了解肛提肌肌力和生殖裂隙宽度。

### 治疗

![[04 Attachments/妇产科-盆底_p11.webp]]

治疗与否取决于对患者生活质量的影响。

#### 非手术治疗

用于POP-Q Ⅰ～Ⅱ度有症状者，也适用于希望保留生育功能或不能耐受手术的重度患者。

| 方法 | 特点 |
|------|------|
| **子宫托** | 一线治疗方法。分支撑型和填充型。需定期取出清洗。适用于全身状况不适宜手术、妊娠期和产后、膨出面溃疡术前准备 |
| **盆底康复治疗** | Kegel运动：收缩肛门3秒以上后放松，每次10～15min，每日2～3次。生物反馈效果更好 |
| **中药和针灸** | 促进盆底肌张力恢复 |

#### 手术治疗

脱垂超出处女膜的有症状患者可考虑。

| 术式 | 适用 |
|------|------|
| **阴道封闭术（LeFort）** | 年老体弱不能耐受大手术者（失去性功能） |
| **曼彻斯特手术** | 年轻宫颈延长的子宫脱垂：阴道前后壁修补+主韧带缩短+宫颈部分切除 |
| **骶骨固定术/骶棘韧带固定术** | 顶端悬吊重建Ⅰ水平（可经腹/腹腔镜/阴道） |
| **自身组织修复重建** | 骶棘韧带固定、子宫骶韧带悬吊、阴道前后壁修补 |
| **经阴道网片植入** | 顶端悬吊+网片筋膜重建（FDA已禁用，并发症严重） |

> 术后3个月内避免增加腹压和负重，禁性生活3个月。

## 压力性尿失禁

### 概述

压力性尿失禁（SUI）指腹压突然增加导致的尿液不自主流出，而非逼尿肌收缩引起。中国成年女性发生率18.9%。90%以上为解剖型（盆底组织松弛），<10%为尿道内括约肌障碍型（先天发育异常）。

### 临床表现

腹压增加下不自主溢尿是最典型症状。80%伴有阴道前壁膨出。

### 分度

| 分度 | 标准 |
|------|------|
| **Ⅰ度** | 剧烈腹压时（咳嗽、打喷嚏、慢跑） |
| **Ⅱ度** | 中度腹压时（快速运动、上下楼梯） |
| **Ⅲ度** | 轻度腹压时（站立位发生，仰卧可控） |

### 诊断

**压力试验**：膀胱充盈，咳嗽时观察尿道外口有无尿液溢出。

**指压试验（Bonney test）**：手指放入阴道前壁尿道两侧，向上抬高膀胱颈，再诱发压力试验，漏尿消失为阳性。

**棉签试验**：静息与Valsalva动作时角度差>30°提示解剖学支持薄弱。

**尿动力学检查**：区别逼尿肌异常收缩还是SUI。

### 治疗

**非手术治疗**（轻中度及术后辅助）：盆底肌肉锻炼、盆底电刺激、阴道局部雌激素治疗。30%～60%可改善症状。

**手术治疗**（中重度及非手术无效者）：

| 术式 | 特点 |
|------|------|
| **阴道无张力尿道中段悬吊带术（TVT/TOT）** | 目前应用最多，微创，术后1年治愈率约90% |
| **耻骨后膀胱尿道悬吊术（Burch）** | 术后1年治愈率85%～90% |

> Kelly阴道前壁修补术现已不推荐作为SUI有效术式（术后1年治愈率仅约30%）。

## 生殖道瘘

### 概述

由于各种原因导致生殖道与其毗邻器官之间形成异常通道。以尿瘘最常见，其次为粪瘘，可同时存在（混合性瘘）。

### 尿瘘

生殖道与泌尿道之间的异常通道。包括膀胱阴道瘘、尿道阴道瘘、膀胱尿道阴道瘘、输尿管阴道瘘等。

**病因**：产伤（坏死型/创伤型）、妇科手术损伤（分离粘连伤及膀胱/输尿管）、放疗、结核、肿瘤、子宫托不当。

**临床表现**：产后或盆腔手术后阴道无痛性持续性漏尿。发生时间：坏死型术后3～7日；直接损伤术后即漏；能量器械损伤后1～2周；放疗所致漏尿发生晚。

**诊断**：

| 试验 | 方法 |
|------|------|
| **亚甲蓝试验** | 膀胱注入稀释亚甲蓝，阴道内棉球蓝染→膀胱阴道瘘；无色/黄染→输尿管阴道瘘 |
| **靛胭脂试验** | 静脉注射靛胭脂，蓝色液体自阴道流出→输尿管阴道瘘 |
| **膀胱镜/输尿管镜** | 明确瘘孔位置、大小、数目 |
| **影像学** | 静脉肾盂造影、CTU |

**治疗**：手术修补为主。非手术治疗仅限于产后/术后1周内的小瘘孔（留置导尿管4周～3个月），15%～20%可自愈。手术时机：直接损伤尽早修补；其他原因等待3个月；放疗后等待12个月。

### 粪瘘

肠道与生殖道之间的异常通道，最常见为直肠阴道瘘。

**病因**：产伤（Ⅳ度会阴撕裂修补未愈）、盆腔手术损伤、炎性肠病、先天畸形、子宫托长期不取、恶性肿瘤/放疗。

**临床表现**：阴道内排出粪便。瘘孔大者成形粪便经阴道排出；小者肠内气体自阴道排出。

**诊断**：妇科检查+直肠指检。小瘘孔可用探针探查。小肠/结肠阴道瘘需钡剂灌肠。

**治疗**：手术修补为主。手术损伤者术中立即修补。压迫坏死性粪瘘等待3～6个月后手术。先天性者15岁后考虑。术前严格肠道准备，术后静脉高营养5～7日。

## 预防

- 提高产科质量，预防产伤
- 治疗导致慢性腹压增加的疾病
- 避免肥胖和重体力劳动
- 产后进行盆底肌肉锻炼
