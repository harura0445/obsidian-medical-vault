# 肝功能分级

肝功能分级是评估肝脏储备功能、指导治疗方案选择（尤其 [[TACE]]、肝切除、肝移植）及判断预后的核心工具。临床最常用的包括 **Child-Pugh 分级**、**MELD 评分** 和 **ALBI 分级**。

---

## Child-Pugh 分级

最经典、应用最广的肝功能评估系统，最初用于评估 [[肝硬化]] 门脉高压手术风险，现广泛用于 HCC 治疗决策（[[原发性肝癌]]、[[肝脏疾病]]）。

### 评分标准

| 指标 | 1 分 | 2 分 | 3 分 |
|------|------|------|------|
| **白蛋白（g/dL）** | > 3.5 | 2.8–3.5 | < 2.8 |
| **胆红素（mg/dL）** | < 2.0 | 2.0–3.0 | > 3.0 |
| **凝血酶原时间延长（秒）** | < 4 | 4–6 | > 6 |
| **腹水** | 无 | 轻度（可控） | 中度以上（顽固性） |
| **肝性脑病** | 无 | 1–2 级 | 3–4 级 |

### 分级与临床意义

| 分级 | 总分 | 意义 | TACE 相关 |
|------|------|------|-----------|
| **Child-Pugh A** | 5–6 分 | 肝功能代偿良好 | **适合 TACE**；也是肝切除的常规前提 |
| **Child-Pugh B** | 7–9 分 | 肝功能轻中度失代偿 | **相对适合 TACE**（需严格控制栓塞范围 + 保肝） |
| **Child-Pugh C** | 10–15 分 | 肝功能严重失代偿 | **TACE 绝对禁忌**（除非为等待肝移植桥接） |

> **临床决策参考**：TACE 要求肝功能 ≥ Child-Pugh B 级，若为 C 级首选保肝 → 争取回归 B 级；或直接评估肝移植。

## MELD 评分

Model for End-stage Liver Disease（终末期肝病模型）

### 计算公式

```
MELD = 3.78 × ln[胆红素(mg/dL)] 
     + 11.2 × ln[INR] 
     + 9.57 × ln[肌酐(mg/dL)] 
     + 6.43
```

> 结果取整数，最低 6，最高 40。若患者近一周内接受透析 ≥ 2 次，肌酐自动设为 4.0 mg/dL。

### 临床用途

| 用途 | 说明 |
|------|------|
| **肝移植优先分配** | MELD 评分越高 → 移植优先级越高 |
| **TACE 风险评估** | MELD > 10 → 术后肝衰竭风险↑，需谨慎选择 TACE |
| **门脉高压并发症** | 预测静脉曲张出血、自发性 [[腹膜炎]] 等 |

### MELD-Na

```
MELD-Na = MELD + 1.32 × (137 − Na⁺) − 0.033 × MELD × (137 − Na⁺)
```

- 纳入 **低钠血症** 因素，更准确预测移植等待期死亡率
- 血清 Na⁺ 水平限制在 125–137 mmol/L 之间

## ALBI 分级

Albumin-Bilirubin Grade（白蛋白-胆红素分级）

### 特点

- **仅需两个客观指标**：白蛋白 + 胆红素（不受主观判断如腹水、肝性脑病影响）
- 避免了 Child-Pugh 中 **腹水** 和 **肝性脑病** 的主观偏倚
- 在 HCC 预后分层中 **与 Child-Pugh 等效甚至更优**

### 计算公式

```
ALBI 评分 = (log₁₀ 胆红素[μmol/L] × 0.66) 
          + (白蛋白[g/L] × −0.085)
```

### 分级

| 分级 | 评分范围 | 意义 |
|------|---------|------|
| **ALBI 1 级** | ≤ −2.60 | 肝功能良好 |
| **ALBI 2 级** | > −2.60 ~ ≤ −1.39 | 肝功能中度受损 |
| **ALBI 3 级** | > −1.39 | 肝功能重度受损 |

> ALBI 对 TACE 患者的预后分层能力强，也被用于更精细地筛选 **Child-Pugh A 级** 中哪些患者真正适合 TACE（ALBI 1 级 vs ALBI 2 级的中位 OS 差异显著）。

---

## 三种系统对比

| 系统 | 客观性 | 区分度 | 移植优先分配 | TACE 适用 | 优势 |
|------|--------|--------|-------------|-----------|------|
| **Child-Pugh** | 部分主观（腹水/肝性脑病） | 中等（仅 3 级） | 否 | 是 | 经典，临床最熟悉 |
| **MELD** | 完全客观 | 连续变量（6–40） | **是** | 参考 | 移植金标准 |
| **ALBI** | 完全客观 | 3 级 + 连续评分 | 否 | **是** | 无主观偏倚，TACE预后分层强 |

---

## 在 TACE 中的应用

肝功能分级直接影响 TACE 的适应证判断与预后：

1. **适应证门槛**：Child-Pugh ≤ B 级（A 级最佳，B 级谨慎）
2. **禁忌红线**：Child-Pugh C 级（无肝移植计划时为绝对禁忌）
3. **联合治疗**：肝功能越好 → 联合靶向/免疫的耐受性越高
4. **重复治疗**：每次 TACE 后需重新评估肝功能，分级恶化应考虑延长治疗间隔或换用方案
5. **预后分层**：ALBI 可进一步区分 Child-Pugh A 级患者的真实肝功能储备

> **实践中**：TACE 术前常规计算 Child-Pugh 分级 + ALBI 评分，两者互补。若 Child-Pugh A 但 ALBI 2 级，应警惕术后肝损伤风险。
