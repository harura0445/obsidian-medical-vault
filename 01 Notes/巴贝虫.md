# 巴贝虫
- 巴贝虫(Babesia)是一种寄生于**脊椎动物红细胞内**的原虫，主要通过**硬蜱**在人与动物间传播或输血传播，引起的疾病称为巴贝虫病(babesiosis)，也是一种蜱媒传播的人兽共患寄生虫病。

## 生活史
- 巴贝虫生活史包括在哺乳动物的红细胞内发育和媒介**硬蜱**体内发育两个阶段，至少经历三个繁殖期：
	- ①配子生殖(gamogony)—在蜱肠中配子的形成和融合；
	- ②孢子增殖(sporogony) —在蜱唾液腺中的无性繁殖； 
	- ③裂体增殖(merogony) —在脊椎动物宿主红细胞内的无性繁殖。
- **蜱叮咬** → 将**子孢子（sporozoite）**注入血液
- **侵入红细胞** → 在红细胞内裂殖（裂殖形成滋养体 trophozoite → 分裂体 merozoite）
- **红细胞破裂** → 释放更多原虫感染其他红细胞
- 循环进行 → 造成溶血、贫血
- **蜱再次叮咬感染者血液** → 完成传播周期

## 致病
- 巴贝虫致病作用不仅与虫种及虫体在宿主红细胞内的增殖而引起红细胞溶解作用相关，还**与宿主的免疫状态相关**

## 临床表现
- 轻度到中度症状
	- 大多数巴贝斯虫病患者为轻度到中度临床表现，一般症状为不适、乏力和疲劳及间歇性发热， 
- 危重症状
	- hiv感染、恶性肿瘤、免疫抑制药物服用及脾切除等免疫缺陷患者往往出现危重症状。临床表现有起病急，高热、寒战、出汗、体温可高达40℃，**酷似疟疾**，还会伴随急性呼吸衰竭、弥散性血管内凝血、充血性心力衰竭、肝肾功能衰竭、脾梗塞甚至死亡。 
- 隐性感染
	- 隐性巴贝虫病主要表现为部分患者蜱叮咬后几周内会出现轻微的亚临床症状，随后症状自限性消失。
