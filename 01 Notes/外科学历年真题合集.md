# 外科学历年真题合集

> 本合集整理了 2018~2023 级外科学考试真题回忆，来源为微信公众号「B1休息区」投稿，涵盖临床五年制、临床八年制、预防医学、口腔医学、基础医学、临床药学等专业方向。题目按**题型→系统**分类编排，每题附答案、知识点标签及对应笔记链接。

---

## 一、选择题

### 无菌术与外科感染

#### Q1. 以下哪项是特异性外科感染？
- **来源**: 22临五上
- **答案**: **破伤风**。疖、痈等为非特异性感染（化脓性感染），破伤风由破伤风梭菌引起，属于特异性外科感染。
- **知识点**: 特异性感染, 破伤风, 外科感染分类
- **详见**: [[无菌术与外科感染]]

#### Q2. 痈的定义与处理？
- **来源**: 23口腔
- **答案**: **痈**是多个相邻毛囊及其周围组织的急性化脓性感染，好发于颈部和背部（项痈、背痈）。致病菌以金黄色葡萄球菌为主。治疗：切开引流（"+"或"++"切口）、全身应用抗生素、控制糖尿病等基础疾病。
- **知识点**: 痈, 金黄色葡萄球菌, 切开引流
- **详见**: [[无菌术与外科感染]]

#### Q3. 什么情况不需要预防性使用抗生素？
- **来源**: 23口腔
- **答案**: 清洁手术（I 类切口）、无明显污染、手术时间短、无植入物时一般不需预防性使用抗生素。以下情况需预防：①污染或感染手术；②手术时间长、创伤大；③涉及重要脏器；④有植入物；⑤免疫功能低下者。
- **知识点**: 预防性抗生素, 围手术期处理
- **详见**: [[无菌术与外科感染]]

### 休克

#### Q4. 失血性休克代偿期估计失血量是？
- **来源**: 18临八床旁
- **答案**: **800mL 以下**（< 20% 循环血量）。代偿期表现为心率加快、脉压减小、皮肤苍白湿冷，血压可正常或轻度下降。
- **知识点**: 失血性休克, 代偿期, 失血量
- **详见**: [[休克]]

#### Q5. 关于休克的一般紧急治疗，哪项不正确？
- **来源**: 18临八床旁
- **答案**: **采取平卧体位**（不正确）。休克体位应为**头胸和下肢均抬高约 20-30°**（休克卧位），以增加回心血量和改善呼吸。不正确的做法是平卧。
- **知识点**: 休克, 急救体位
- **详见**: [[休克]]

#### Q6. 脓毒性休克不恰当的处理方式是？
- **来源**: 22临五上
- **答案**: [根据考点提示整理] 脓毒性休克处理原则：①早期液体复苏（晶体液 30mL/kg）；②使用血管活性药物（去甲肾上腺素首选）；③经验性广谱抗生素（1 小时内）；④控制感染源（引流、清创）；⑤监测乳酸。不恰当的处理：仅用血管收缩剂而不充分补液、延迟使用抗生素。
- **知识点**: 脓毒性休克, 液体复苏, 抗生素
- **详见**: [[休克]]

### 围手术期与营养

#### Q7. 择期手术患者术后第一天体温 38℃，最可能的原因是？
- **来源**: 18临八床旁
- **答案**: **吸收热**。术后 1-3 天体温 ≤ 38.5°C，由组织损伤后分解产物吸收引起，为正常术后反应。伤口感染通常发热在术后 3-5 天，肺部感染有呼吸道症状。
- **知识点**: 术后发热, 吸收热
- **详见**: [[无菌术与外科感染]]

#### Q8. 术后并发尿路感染的基本原因是？
- **来源**: 18临八床旁
- **答案**: **尿潴留**。术后尿潴留 → 残余尿量增多 → 细菌繁殖 → 尿路感染。
- **知识点**: 术后并发症, 尿潴留, 尿路感染
- **详见**: [[无菌术与外科感染]]

### 乳房与甲状腺疾病

#### Q9. 下列乳腺疾病不会出现乳头内陷的是？
- **来源**: 22临五上
- **答案**: **乳腺囊性增生**。乳腺癌（尤其是侵及乳管时）、乳腺结核（纤维组织增生牵拉）均可致乳头内陷。乳腺囊性增生一般不引起乳头内陷。
- **知识点**: 乳头内陷, 乳腺癌, 乳腺囊性增生
- **详见**: [[乳腺疾病]]

#### Q10. 女，62 岁，左乳肿块 1.5cm，质地偏硬，边界欠清，可活动，腋窝未及淋巴结。首先考虑的诊断是？
- **来源**: 19预防
- **答案**: **乳腺癌**。中老年女性 + 乳房单发质硬肿块 + 边界欠清 → 首先考虑乳腺癌。乳腺纤维腺瘤多见于年轻女性、边界清晰。明确诊断最有价值的是**乳腺活组织检查**。
- **知识点**: 乳腺癌, 临床表现, 活检
- **详见**: [[乳腺疾病]]

#### Q11. 乳腺湿疹样癌的特征？
- **来源**: 21预防/基医/临药
- **答案**: **乳头乳晕区湿疹样改变**（Paget 病）：乳头乳晕红斑、糜烂、渗液、结痂，可伴瘙痒或灼痛。常合并乳腺导管内癌，预后相对较好。
- **知识点**: Paget 病, 湿疹样癌, 乳腺
- **详见**: [[乳腺疾病]]

#### Q12. 结节性甲状腺肿手术适应证？
- **来源**: 21预防/基医/临药
- **答案**: ①压迫气管、食管或喉返神经引起症状；②胸骨后甲状腺肿；③巨大甲状腺肿影响生活工作；④继发性甲亢；⑤疑有恶变。
- **知识点**: 结节性甲状腺肿, 手术适应证
- **详见**: [[甲状腺疾病]]

### 腹外疝与阑尾炎

#### Q13. 腹股沟管外环对应的解剖结构是？
- **来源**: 22临五上
- **答案**: **腹外斜肌腱膜**。外环（皮下环）是腹外斜肌腱膜在耻骨结节外上方形成的三角形裂隙。
- **知识点**: 腹股沟管, 外环, 腹外斜肌
- **详见**: [[腹外疝]]

#### Q14. 61 岁女性，腹股沟区包块不能回纳，怎么处理？
- **来源**: 22临五上
- **答案**: **股疝，行 McVay 术**。老年女性 + 腹股沟区嵌顿性包块 → 股疝（女性多见）。嵌顿性股疝需急诊手术，McVay 法修补。
- **知识点**: 股疝, McVay 修补术
- **详见**: [[腹外疝]]

#### Q15. 男性，26 岁，右侧腹股沟斜疝 3 年，应首先采用哪种术式？
- **来源**: 18临八床旁
- **答案**: **Bassini 法修补手术**。青壮年斜疝，首选 Bassini 法（加强腹股沟管后壁）。Ferguson 法加强前壁，McVay 法适用于股疝和巨大斜疝。
- **知识点**: 腹股沟斜疝, Bassini 术
- **详见**: [[腹外疝]]

#### Q16. 急性阑尾炎最常见的梗阻原因是？
- **来源**: 18临八床旁
- **答案**: **淋巴滤泡增生**（最常见），其次为粪石、食物残渣、蛔虫等。淋巴滤泡在青少年时期丰富，急性阑尾炎发病率高与此有关。
- **知识点**: 阑尾炎, 淋巴滤泡增生
- **详见**: [[阑尾疾病]]

#### Q17. McBurney 点在哪？
- **来源**: 23口腔, 22口腔
- **答案**: 脐与右髂前上棘连线中外 **1/3 交界处**，为阑尾根部体表投影点。McBurney 点压痛是急性阑尾炎最重要的体征。
- **知识点**: McBurney 点, 阑尾炎
- **详见**: [[阑尾疾病]]

### 胃十二指肠疾病

#### Q18. 一患者上腹痛、呕血、饮酒，哪个部位损伤？
- **来源**: 21预防/基医/临药
- **答案**: **胃窦/胃角**。饮酒后急性胃黏膜病变好发于胃窦部和胃角切迹处。
- **知识点**: 急性胃黏膜病变, 上消化道出血
- **详见**: [[胃十二指肠疾病]]

#### Q19. 70 岁，间断性上腹痛，近 2 月饱胀感、血红蛋白低，诊断？
- **来源**: 21预防/基医/临药
- **答案**: **胃癌**。老年 + 慢性上腹痛 + 近期饱胀感 + 贫血（Hb 降低），高度提示胃癌。
- **知识点**: 胃癌, 临床表现, 贫血
- **详见**: [[胃十二指肠疾病]]

#### Q20. 胃大部切除术后并发症？
- **来源**: 23口腔
- **答案**: ①早期并发症：出血、十二指肠残端破裂、吻合口漏/梗阻；②远期并发症：**倾倒综合征**、**碱性反流性胃炎**、**吻合口溃疡**、**残胃癌**、营养障碍（贫血、骨质疏松）。
- **知识点**: 胃大部切除术, 并发症
- **详见**: [[胃十二指肠疾病]]

### 肠梗阻

#### Q21. 下列哪个会引起肠梗阻坏死？
- **来源**: 21预防/基医/临药
- **答案**: **血运性肠梗阻**。血运性肠梗阻由于肠系膜血管栓塞或血栓形成，肠管缺血导致坏死。绞窄性肠梗阻也有血运障碍但选项中未列出。
- **知识点**: 血运性肠梗阻, 肠坏死
- **详见**: [[肠梗阻]]

#### Q22. 可用于鉴别单纯性与绞窄性肠梗阻最有效的检查是？
- **来源**: 18临八床旁
- **答案**: **腹腔穿刺抽出血性物**。绞窄性肠梗阻时肠壁缺血坏死，腹腔内可有血性渗出液，诊断性腹腔穿刺抽出暗红色/血性液体是绞窄的有力证据。
- **知识点**: 绞窄性肠梗阻, 腹腔穿刺
- **详见**: [[肠梗阻]]

#### Q23. 某患者 X 线发现孤立扩大肠襻，怎么处理？
- **来源**: 22临五上
- **答案**: **急诊手术**。孤立扩大肠襻是绞窄性肠梗阻的 X 线特征（"咖啡豆征"），需立即手术探查。
- **知识点**: 绞窄性肠梗阻, 咖啡豆征, 急诊手术
- **详见**: [[肠梗阻]]

### 结直肠与肛管疾病

#### Q24. 女，40 岁，排便次数增多，下腹隐痛，粪便有脓细胞及吞噬细胞，按慢性菌痢治疗效果不佳，首先应做？
- **来源**: 19预防
- **答案**: **直肠指检 + 电子结肠镜检**。排便习惯改变 + 脓血便 + 抗感染治疗无效 → 需排除结直肠癌，直肠指检是直肠癌最简单有效的筛查方法。
- **知识点**: 结直肠癌, 直肠指检, 电子结肠镜
- **详见**: [[结直肠癌]]

#### Q25. Left colon cancer vs Right colon cancer？
- **来源**: 20临八
- **答案**: **左半结肠癌**：以肠梗阻为主要表现（环形狭窄型多见），大便习惯改变、便血（暗红）、里急后重。**右半结肠癌**：以全身症状和贫血为主要表现（隆起型多见），右下腹包块、隐痛、缺铁性贫血。左半结肠癌致梗阻时需先减压再手术。
- **知识点**: 左半结肠癌, 右半结肠癌, 临床表现差异
- **详见**: [[结直肠癌]]

#### Q26. 内痔分期？
- **来源**: 20临八
- **答案**: I 度：便血，无痔核脱出；II 度：便血，排便时痔核脱出，便后自行回纳；III 度：痔核脱出需手推回纳；IV 度：痔核脱出不能回纳或嵌顿。
- **知识点**: 内痔, 分期
- **详见**: [[结直肠常见良性疾病]]

#### Q27. 高位肛瘘的首选治疗？
- **来源**: 18预防
- **答案**: **挂线疗法**。高位肛瘘经括约肌深部以上，直接切断肛管直肠环可致大便失禁，挂线疗法通过慢性切割避免了这一问题。
- **知识点**: 高位肛瘘, 挂线疗法
- **详见**: [[结直肠常见良性疾病]]

### 胆道疾病

#### Q28. 胆囊内胆固醇结石形成的最主要原因是？
- **来源**: 18临八床旁
- **答案**: **胆汁成分和理化性质改变**（胆固醇过饱和、胆汁酸盐/卵磷脂比例降低、促成核因子增加）。
- **知识点**: 胆固醇结石, 胆汁成分
- **详见**: [[胆道外科疾病]]

#### Q29. 关于早期无痛性黄疸容易发生于哪种疾病？
- **来源**: 22临五上
- **答案**: **胆管癌**。进行性、无痛性黄疸是胆管癌的典型表现。肝癌黄疸出现较晚，胆囊结石黄疸与胆绞痛相关。
- **知识点**: 胆管癌, 无痛性黄疸
- **详见**: [[胆道外科疾病]]

#### Q30. 关于肝内胆管结石错误的是？
- **来源**: 22临五上
- **答案**: **"不是胆固醇结石，应是胆色素结石"** 的说法是错误的（实际上肝内胆管结石以**胆色素结石**为主）。肝内胆管结石好发于左外叶和右后叶。
- **知识点**: 肝内胆管结石, 胆色素结石
- **详见**: [[胆道外科疾病]]

### 胰腺疾病

#### Q31. 胰腺癌好发部位？
- **来源**: 22临五上
- **答案**: **胰头**（占 70-80%）。胰头癌早期即可阻塞胆总管致梗阻性黄疸。
- **知识点**: 胰腺癌, 胰头
- **详见**: [[急性胰腺炎]]

#### Q32. 下列不属于急性胰腺炎手术指征的是？
- **来源**: 22临五上
- **答案**: **血淀粉酶大于 300U**。血淀粉酶升高是诊断依据而非手术指征。手术指征：①胰腺坏死感染；②腹腔间隔室综合征；③保守治疗无效；④诊断不明确。
- **知识点**: 急性胰腺炎, 手术指征
- **详见**: [[急性胰腺炎]]

#### Q33. Grey-Turner 征？
- **来源**: 21预防/基医/临药
- **答案**: 急性重症胰腺炎时，胰酶和血液沿腹膜后间隙渗至**双侧腰部皮下**，出现青紫色瘀斑，称为 **Grey-Turner 征**。脐周瘀斑称 **Cullen 征**。
- **知识点**: Grey-Turner 征, 重症胰腺炎
- **详见**: [[急性胰腺炎]]

### 肝脏疾病

#### Q34. 有关 AFP 升高的临床意义，下列哪项正确？
- **来源**: 19预防
- **答案**: **肝细胞癌术后 AFP 又升高提示复发**。解析：AFP > 400μg/L 持续 4 周（非 > 200）可诊断肝癌；肝转移癌 AFP 常正常；肝功能异常伴 AFP 升高不一定为肝癌（活动性肝病也可升高）；消化道其他肿瘤也可升高（如胃癌肝转移、生殖细胞肿瘤）。
- **知识点**: AFP, 肝细胞癌, 肿瘤标志物
- **详见**: [[肝脏疾病]]

#### Q35. 患者肝、双肾多发囊肿，父亲也有类似表现，可能是什么病？
- **来源**: 23口腔
- **答案**: **成人型多囊肾病**（ADPKD，常染色体显性遗传）。特征为双侧肾脏和肝脏多发囊肿，有家族史，可伴高血压和肾功能不全。
- **知识点**: 多囊肾, 多囊肝, 常染色体显性遗传
- **详见**: [[肝脏疾病]]

#### Q36. 与肝脓肿细菌进入无关的途径是？
- **来源**: 21预防/基医/临药
- **答案**: 肝脓肿细菌进入途径：①胆道逆行（最常见）；②肝动脉（全身感染血行播散）；③门静脉（腹腔感染）；④直接蔓延。不经过肝静脉。
- **知识点**: 肝脓肿, 感染途径
- **详见**: [[肝脏疾病]]

#### Q37. Glisson 鞘不包括哪个？
- **来源**: 21预防/基医/临药
- **答案**: Glisson 鞘包含**肝动脉、门静脉、肝管**（三联），不包括**肝静脉**。肝静脉走行于肝段间，不在 Glisson 鞘内。
- **知识点**: Glisson 鞘, 肝门三联
- **详见**: [[肝脏疾病]]

#### Q38. Child-Pugh 分级？
- **来源**: 21预防/基医/临药
- **答案**: Child-Pugh 分级评估肝硬化肝功能储备。5 项指标：**血清胆红素、血清白蛋白、凝血酶原时间、腹水、肝性脑病**。A 级 5-6 分（手术风险低），B 级 7-9 分，C 级 10-15 分（手术禁忌）。
- **知识点**: Child-Pugh 分级, 肝硬化
- **详见**: [[肝脏疾病]]

### 食管癌

#### Q39. The typical symptom of esophageal cancer is？
- **来源**: 19预防
- **答案**: **Progressive dysphagia（进行性吞咽困难）**。先为固体食物，后为半流质、流质吞咽困难——"进行性"是最具特征性的描述。
- **知识点**: 食管癌, 进行性吞咽困难
- **详见**: [[食管癌]]

#### Q40. 关于食管癌不正确的是？
- **来源**: 22临五上
- **答案**: **最好发于胸下段**（不正确）。食管癌最好发于**胸中段**，其次为胸下段、胸上段、颈段。
- **知识点**: 食管癌, 好发部位
- **详见**: [[食管癌]]

#### Q41. 食管癌组织 Lugol's 染色为？
- **来源**: 22临五下
- **答案**: **黄色/不着色**。正常食管鳞状上皮含糖原，Lugol 碘液染为棕褐色；癌变上皮缺乏糖原，碘染色呈黄色不染区，可用于内镜下早期诊断。
- **知识点**: 食管癌, Lugol 染色
- **详见**: [[食管癌]]

### 胸部外伤与肺癌

#### Q42. 中央型肺癌最常见的早期症状？
- **来源**: 19临五下, 23口腔
- **答案**: **刺激性咳嗽、血痰**。中央型肺癌发生于段及以上支气管，早期即刺激支气管黏膜引起刺激性干咳和痰中带血。
- **知识点**: 中央型肺癌, 刺激性咳嗽
- **详见**: [[肺癌]]

#### Q43. Pancoast 肿瘤（肺上沟瘤）？
- **来源**: 21预防/基医/临药, 18临八床旁
- **答案**: 肺尖部肿瘤，侵犯臂丛神经和颈交感神经链，导致：①**Horner 综合征**（同侧瞳孔缩小、上睑下垂、眼球内陷、面部无汗）；②**肩臂疼痛**（臂丛神经 C8-T1 受累）。
- **知识点**: Pancoast 肿瘤, Horner 综合征
- **详见**: [[肺癌]]

#### Q44. 胸腺瘤好发部位是？
- **来源**: 19临五下, 22临五下
- **答案**: **前上纵隔**。纵隔肿瘤有"四区定位"：前上纵隔→胸腺瘤/胸内甲状腺；前下纵隔→畸胎瘤；中纵隔→淋巴瘤；后纵隔→神经源性肿瘤。
- **知识点**: 胸腺瘤, 纵隔分区
- **详见**: [[肺癌]]

#### Q45. 进行性血胸的判断标准？
- **来源**: 22临五下, 19临五下
- **答案**: ①持续脉搏加快、血压进行性下降；②输血补液后血压仍不稳定；③闭式引流血量 ≥ **200mL/h，持续 3 小时**；④Hb、RBC 和 Hct 持续下降；⑤胸穿抽出不凝血。符合上述任一即需开胸探查。
- **知识点**: 进行性血胸, 开胸探查
- **详见**: [[胸部外伤]]

#### Q46. 连枷胸的病理生理状态是？
- **来源**: 19临五下, 22临五下
- **答案**: **纵隔扑动**。多根多处肋骨骨折致胸壁软化→**反常呼吸运动**（吸气时软化区凹陷、呼气时外凸）→纵隔随呼吸左右摆动→影响静脉回流和心排血量。
- **知识点**: 连枷胸, 反常呼吸, 纵隔扑动
- **详见**: [[胸部外伤]]

#### Q47. 开放性气胸的急救处理要点是？
- **来源**: 19临五下
- **答案**: **将开放性气胸变为闭合性气胸**（无菌敷料封闭胸壁伤口→胸腔闭式引流）。否则纵隔扑动可迅速致命。
- **知识点**: 开放性气胸, 急救
- **详见**: [[胸部外伤]]

#### Q48. 小细胞肺癌 2cm 无转移，治疗是？
- **来源**: 22临五下
- **答案**: **手术 + 化疗**。小细胞肺癌尽管对化疗/放疗敏感，但局限性（T1-2N0）仍以手术切除+术后辅助化疗为推荐方案。
- **知识点**: 小细胞肺癌, 手术+化疗
- **详见**: [[肺癌]]

#### Q49. 生物瓣膜最大的问题是？
- **来源**: 22临五下
- **答案**: **不耐用**（结构性瓣膜退化，需 10-15 年后再次换瓣）。机械瓣膜最大问题是需要**终身抗凝**。
- **知识点**: 生物瓣膜, 机械瓣膜
- **详见**: [[胸部外伤]]

#### Q50. Beck 三联征是什么？
- **来源**: 19临五下, 22临五下
- **答案**: **①心音遥远；②颈静脉怒张；③动脉压降低**。为**心脏压塞（心包填塞）** 的典型体征，是胸部外伤或心脏术后致命性并发症。
- **知识点**: Beck 三联征, 心包填塞
- **详见**: [[胸部外伤]]

### 骨折

#### Q51. 肱骨中段骨折，手不能背伸、手指不能伸直，损伤什么神经？
- **来源**: 23口腔
- **答案**: **桡神经**。肱骨中段（桡神经沟处）骨折易损伤桡神经，表现为"垂腕"（伸腕不能）、伸指不能、"虎口区"感觉障碍。
- **知识点**: 桡神经损伤, 垂腕
- **详见**: [[骨折概述]]

#### Q52. 骨折临床愈合标准，不确切的是？
- **来源**: 19临五下, 22临五下
- **答案**: **X 线摄片骨折线消失**（不确切）。骨折临床愈合标准：①局部无压痛及纵轴叩击痛；②局部无异常活动；③X 线示骨折线模糊，有连续性骨痂通过；④解除外固定后上肢可平举 1kg 1 分钟，下肢不扶拐平地步行 3 分钟。临床愈合时骨折线尚可见。
- **知识点**: 骨折愈合标准
- **详见**: [[骨折概述]]

#### Q53. 骨折愈合的第三期是？
- **来源**: 19临五下
- **答案**: **骨痂改造塑形期**。三期：①血肿炎症机化期（2-3 周）→②原始骨痂形成期（4-8 周）→③骨痂改造塑形期（8-12 周至 1-2 年）。
- **知识点**: 骨折愈合分期
- **详见**: [[骨折概述]]

#### Q54. 关节内骨折最常见的并发症是？
- **来源**: 22临五下
- **答案**: **创伤性关节炎**。关节内骨折若复位不良致关节面不平整，长期摩擦导致关节软骨磨损→创伤性关节炎。
- **知识点**: 关节内骨折, 创伤性关节炎
- **详见**: [[骨折概述]]

#### Q55. 胫骨下 1/3 骨折延迟愈合的原因是？
- **来源**: 22临五下
- **答案**: **血供差**。胫骨下 1/3 血供主要来自胫骨滋养动脉（从胫骨上 1/3 进入），下 1/3 骨折后远端血供显著减少，易致延迟愈合或不愈合。
- **知识点**: 胫骨骨折, 血供, 延迟愈合
- **详见**: [[骨折概述]]

#### Q56. 病理性骨折最易发生于？
- **来源**: 19临五下
- **答案**: **有恶性肿瘤病灶的肋骨**。病理性骨折指骨骼本身已有病变（肿瘤、骨质疏松、感染等），轻微外力即可导致骨折。
- **知识点**: 病理性骨折
- **详见**: [[骨折概述]]

#### Q57. 手背着地摔伤，考虑什么骨折？
- **来源**: 22临五下
- **答案**: **Smith 骨折**（屈曲型桡骨远端骨折）。跌倒时腕关节屈曲、手背着地所致，骨折远端向掌侧、近端向背侧移位，又称"反 Colles 骨折"。
- **知识点**: Smith 骨折, 桡骨远端骨折
- **详见**: [[骨折概述]]

#### Q58. 肱骨外科颈骨折可能损伤什么神经？
- **来源**: 22临五下
- **答案**: **腋神经**。腋神经绕肱骨外科颈走行，此处骨折易损伤腋神经，表现为三角肌萎缩、肩外展受限、"方肩"。
- **知识点**: 肱骨外科颈骨折, 腋神经
- **详见**: [[骨折概述]]

#### Q59. 最容易发生骨筋膜室综合征的骨折是？
- **来源**: 18临八床旁
- **答案**: **肱骨髁上伸直型骨折**。伸直型肱骨髁上骨折骨折近端向前下移位，可压迫或损伤肱动脉→前臂骨筋膜室综合征→**Volkmann 缺血性肌挛缩**。
- **知识点**: 骨筋膜室综合征, 肱骨髁上骨折
- **详见**: [[骨折概述]]

#### Q60. 骨折伴软组织肿胀，去除石膏后关节功能障碍，原因是？
- **来源**: 18临八床旁, 22临五下
- **答案**: **关节僵硬**（而非损伤性骨化或缺血性坏死）。长时间固定后缺乏功能锻炼→关节囊和肌肉挛缩→关节僵硬，是最常见的骨折后并发症之一。
- **知识点**: 关节僵硬, 功能锻炼
- **详见**: [[骨折概述]]

### 关节脱位与关节感染

#### Q61. 关节脱位最常见的体征？
- **来源**: 22临五下
- **答案**: **弹性固定**。关节脱位专有体征：①**畸形**（关节外形改变）；②**弹性固定**（关节固定于异常位置，被动活动有弹性阻力）；③**关节盂空虚**。
- **知识点**: 关节脱位, 弹性固定
- **详见**: [[关节脱位]]

#### Q62. 肩关节脱位以哪种方向最多见？
- **来源**: 22临五下
- **答案**: **前脱位**（占 95% 以上）。Dugas 征阳性（患侧肘部紧贴胸壁时手掌不能搭到健侧肩部）。
- **知识点**: 肩关节脱位, Dugas 征
- **详见**: [[关节脱位]]

#### Q63. 髋关节后脱位的典型畸形？
- **来源**: 19临五下, 20预防
- **答案**: 下肢**屈曲、内收、内旋、短缩**畸形。大转子（大粗隆）上移。
- **知识点**: 髋关节后脱位, 畸形
- **详见**: [[关节脱位]]

#### Q64. 化脓性关节炎的早期表现？
- **来源**: 23口腔
- **答案**: ①全身感染症状（高热、寒战）；②关节**红、肿、热、痛**，关节半屈曲位（关节囊最大容积减轻张力）；③关节穿刺抽得**脓性液体**是确诊依据；④血培养阳性率 50%。
- **知识点**: 化脓性关节炎, 关节穿刺
- **详见**: [[关节感染]]

#### Q65. 急性骨髓炎早期诊断最有力的证据？
- **来源**: 19临五下
- **答案**: **干骺端骨膜下穿刺有脓液**。X 线在发病 2 周内常无异常，局部分层穿刺抽得脓液是最直接的诊断依据。
- **知识点**: 急性血源性骨髓炎, 骨膜下穿刺
- **详见**: [[关节感染]]

### 腰椎退行性疾病

#### Q66. 间歇性跛行、可骑三轮车，诊断是？
- **来源**: 22临五下
- **答案**: **腰椎管狭窄症**。神经源性间歇性跛行：行走后下肢疼痛麻木、休息缓解，骑车时因腰椎前屈椎管相对扩大故症状减轻。腰椎间盘突出症的直腿抬高试验阳性，骑车不能缓解。
- **知识点**: 腰椎管狭窄症, 间歇性跛行
- **详见**: [[腰椎退行性疾病]]

#### Q67. 腰椎病与脊柱肿瘤最好用什么检查鉴别？
- **来源**: 22临五下
- **答案**: **MRI**。MRI 对软组织分辨率最高，可清晰显示椎间盘、脊髓、神经根、椎体骨髓及肿瘤侵犯范围。
- **知识点**: 腰椎, MRI, 脊柱肿瘤
- **详见**: [[腰椎退行性疾病]]

#### Q68. 颈椎病颌枕吊带牵引错误的是？
- **来源**: 19临五下
- **答案**: **适用于除交感神经型外的各型颈椎病**（错误）。颌枕吊带牵引适用于**神经根型**颈椎病，对**脊髓型**颈椎病牵引可能加重病情，应避免使用。
- **知识点**: 颈椎病, 颌枕牵引
- **详见**: [[腰椎退行性疾病]]

### 骨肿瘤

#### Q69. Codman 三角出现在什么肿瘤中？
- **来源**: 22口腔, 18预防, 22临五下
- **答案**: **骨肉瘤**（最常见的恶性骨肿瘤，好发于青少年长骨干骺端）。Codman 三角为骨膜被肿瘤掀起后形成的三角形骨膜反应影，X 线上呈现"日光射线"征象。
- **知识点**: Codman 三角, 骨肉瘤
- **详见**: [[骨肿瘤]]

#### Q70. 骨软骨瘤错误的是？
- **来源**: 22临五下
- **答案**: **症状明显**（错误）。骨软骨瘤是最常见的良性骨肿瘤，生长缓慢，一般无症状，常在无意中发现局部骨性隆起。X 线特征为干骺端外生性骨性突起。
- **知识点**: 骨软骨瘤, 良性骨肿瘤
- **详见**: [[骨肿瘤]]

#### Q71. 骨巨细胞瘤和骨肉瘤的 X 线特征？
- **来源**: 20临八
- **答案**: **骨巨细胞瘤**：偏心性、膨胀性、溶骨性破坏，"肥皂泡样"改变，好发于股骨远端和胫骨近端（骨端）。**骨肉瘤**：Codman 三角、"日光射线"样骨膜反应、软组织肿块影，好发于干骺端。
- **知识点**: 骨巨细胞瘤, 骨肉瘤, X 线
- **详见**: [[骨肿瘤]]

#### Q72. 骨肿瘤哪个有 Bence Jones 蛋白？
- **来源**: 18预防
- **答案**: **多发性骨髓瘤**。Bence Jones 蛋白（本周蛋白）为免疫球蛋白轻链，在尿中出现，是多发性骨髓瘤的特征性实验室检查异常。
- **知识点**: 多发性骨髓瘤, Bence Jones 蛋白
- **详见**: [[骨肿瘤]]

### 泌尿系结石与感染

#### Q73. 男性活动后腰痛血尿一日，诊断？
- **来源**: 21预防/基医/临药
- **答案**: **上尿路结石（肾/输尿管结石）**。活动后出现腰痛 + 血尿是上尿路结石的典型表现。诊断首选 B 超或 KUB（腹部平片）+ IVU（静脉尿路造影）。
- **知识点**: 上尿路结石, 腰痛血尿
- **详见**: [[泌尿系结石]]

#### Q74. 鉴别上尿路结石与腹腔钙化灶常用的检查方法是？
- **来源**: 22临五下
- **答案**: **腹部侧位 X 线平片**。侧位片上，上尿路结石阴影位于**脊柱前缘后方**（腹膜后），腹腔钙化灶位于脊柱前缘前方（腹腔内）。
- **知识点**: 上尿路结石, 侧位平片
- **详见**: [[泌尿系结石]]

### 泌尿系肿瘤与前列腺疾病

#### Q75. 71 岁女性，无痛性肉眼血尿 1 月，首要考虑诊断为？
- **来源**: 19临五下
- **答案**: **膀胱肿瘤**。老年 + 无痛性肉眼血尿（全程或终末）是膀胱癌最典型的表现。膀胱炎常有尿路刺激症状，膀胱结石有排尿中断。
- **知识点**: 膀胱癌, 无痛性血尿
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

#### Q76. 肾癌经典三联征？
- **来源**: 22临五下
- **答案**: **血尿、肿块、疼痛**。但三联征同时出现时多为晚期，现多数肾癌在体检时偶然发现（无症状）。
- **知识点**: 肾癌, 三联征
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

#### Q77. 82 岁男性，PSA 45.2ng/mL，为明确诊断首先考虑？
- **来源**: 19临五下
- **答案**: **前列腺穿刺活检**。PSA 显著升高（> 10ng/mL）+ 老年男性 → 高度怀疑前列腺癌，穿刺活检是确诊金标准。
- **知识点**: 前列腺癌, PSA, 穿刺活检
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

#### Q78. 良性前列腺增生症的手术适应证不包括？
- **来源**: 19临五下
- **答案**: **反复前列腺炎**。BPH 手术适应证：①反复尿潴留；②反复尿路感染；③继发性上尿路积水；④多发膀胱结石；⑤反复血尿；⑥肾功能损害。前列腺炎主要以内科治疗为主。
- **知识点**: BPH, 手术适应证
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

## 二、名词解释

### 无菌术与外科感染

#### Q1. 痈
- **来源**: 23口腔
- **答案**: 多个相邻**毛囊及其周围组织**的急性化脓性感染，由金黄色葡萄球菌引起，好发于颈背部，需切开引流（"+"或"++"切口）加全身抗生素治疗。
- **详见**: [[无菌术与外科感染]]

#### Q2. 面部危险三角
- **来源**: 18预防
- **答案**: 鼻根至两侧口角的**三角形区域**，此处的静脉无瓣膜且经眼静脉与海绵窦直接相通，感染可逆行进入颅内导致**海绵窦血栓性静脉炎**。
- **详见**: [[无菌术与外科感染]]

### 休克

#### Q3. 冷休克
- **来源**: 20临八
- **答案**: **低排高阻型休克**（低动力型），为感染性休克的常见类型。特征：心排血量降低、外周血管阻力增高、皮肤湿冷苍白、脉搏细速。常见于革兰阴性菌感染。
- **详见**: [[休克]]

### 乳房与甲状腺疾病

#### Q4. 酒窝征
- **来源**: 22口腔
- **答案**: 乳腺癌侵犯 **Cooper 韧带**（乳房悬韧带），使其缩短并牵拉皮肤，导致**局部皮肤凹陷**呈"酒窝样"改变，是乳腺癌的重要体征之一。
- **详见**: [[乳腺疾病]]

#### Q5. Modified radical mastectomy（乳腺癌改良根治术）
- **来源**: 19预防
- **答案**: 切除**患侧全部乳腺组织 + 胸小肌切除/保留 + 腋窝淋巴结清扫（I、II 水平）**，保留胸大肌，是当前最常用的乳腺癌手术方式。与 Halsted 根治术的区别在于保留胸大肌。
- **详见**: [[乳腺疾病]]

#### Q6. TSH 抑制治疗
- **来源**: 19预防
- **答案**: 口服超生理剂量的**左甲状腺素钠（L-T₄）**，通过负反馈抑制 **TSH** 分泌，减少 TSH 对甲状腺细胞（包括癌细胞）的增殖刺激。用于**分化型甲状腺癌术后**的抑制治疗。
- **详见**: [[甲状腺疾病]]

#### Q7. 甲状腺危象
- **来源**: 18临八床旁
- **答案**: 甲亢术后最严重的并发症，多发生于术后 **12-36 小时**内。表现为**高热（>39°C）、心动过速（>140 次/分）、烦躁、谵妄、呕吐腹泻**，死亡率高。紧急处理：碘剂、β 受体阻断剂、糖皮质激素、降温、对症支持。
- **详见**: [[甲状腺疾病]]

### 腹外疝与阑尾炎

#### Q8. 疝
- **来源**: 20临八
- **答案**: 体内器官或组织**离开正常解剖位置**，通过先天或后天形成的**薄弱点、缺损或孔隙**进入另一部位。腹外疝指腹腔内容物通过腹壁薄弱处突出至腹壁外。
- **详见**: [[腹外疝]]

#### Q9. Maydl 疝
- **来源**: 20预防
- **答案**: 一种特殊类型的嵌顿疝，疝囊内嵌顿的是**两个相邻的肠襻**，两者之间的肠管仍在腹腔内（呈"W"形），腹腔内的中间肠管可发生绞窄，即使疝囊内肠管尚存活。
- **详见**: [[腹外疝]]

#### Q10. McBurney 点
- **来源**: 23口腔, 22口腔
- **答案**: 脐与右髂前上棘连线的**中外 1/3 交界处**，为阑尾根部的体表投影，此点出现固定压痛是急性阑尾炎的典型体征。
- **详见**: [[阑尾疾病]]

### 胃十二指肠疾病

#### Q11. 倾倒综合征
- **来源**: 20临八
- **答案**: 胃大部切除术后，胃排空过快→高渗食糜快速进入小肠→①**早期倾倒**（餐后 30min）：大量细胞外液进入肠腔→血容量下降（心悸、出汗）和胃肠道症状（恶心、腹泻）；②**晚期倾倒**（餐后 2-3h）：反应性低血糖。
- **详见**: [[胃十二指肠疾病]]

#### Q12. 残胃癌
- **来源**: 20临八（缓）
- **答案**: 胃大部切除术后 **5 年以上**，残胃发生的原发性癌。与胆汁反流、胃内低酸环境、HP 感染等因素有关。Billroth II 式术后发生率高于 Billroth I 式。
- **详见**: [[胃十二指肠疾病]]

#### Q13. 早期胃癌
- **来源**: 18预防
- **答案**: 癌组织浸润深度**不超过黏膜下层**（不论有无淋巴结转移）。可分为隆起型（I 型）、表浅型（II 型）和凹陷型（III 型）。早期胃癌预后良好，5 年生存率 > 90%。
- **详见**: [[胃十二指肠疾病]]

### 肝脏疾病

#### Q14. 第一肝门 / 第二肝门
- **来源**: 20临八（缓）, 20预防
- **答案**: **第一肝门**：肝脏面横沟处，**肝动脉、门静脉、肝管**出入肝脏的部位。**第二肝门**：肝顶部下腔静脉沟处，**肝左、中、右静脉**汇入下腔静脉的部位。
- **详见**: [[肝脏疾病]]

#### Q15. 肝蒂
- **来源**: 21预防/基医/临药
- **答案**: 出入第一肝门的肝动脉、门静脉、肝管被肝十二指肠韧带包绕形成的解剖结构。肝门阻断时可用 Pringle 法（阻断肝蒂），每次阻断时间不超过 15-20 分钟。
- **详见**: [[肝脏疾病]]

#### Q16. 门静脉高压症
- **来源**: 19预防
- **答案**: 门静脉系统压力持续增高（正常 1.27-2.35kPa 即 13-24cmH₂O），临床表现为**脾大脾亢、食管胃底静脉曲张破裂出血、腹水**三联征。肝硬化是最常见原因。
- **详见**: [[肝脏疾病]]

### 胆道疾病

#### Q17. Mirizzi 综合征
- **来源**: 22临五上
- **答案**: 胆囊颈或胆囊管结石**嵌顿压迫肝总管**，导致肝总管狭窄或梗阻，出现梗阻性黄疸和胆管炎。需与胆管癌鉴别，手术治疗。
- **详见**: [[胆道外科疾病]]

### 食管癌

#### Q18. 上腔静脉梗阻综合征
- **来源**: 23口腔
- **答案**: 上腔静脉受**纵隔肿瘤**（如中央型肺癌、淋巴瘤）压迫或侵犯，导致头面部及上肢静脉回流受阻。临床表现：**头面部及上肢水肿、颈静脉怒张、呼吸困难、胸壁静脉曲张**。
- **详见**: [[食管癌]]

### 泌尿外科

#### Q19. 尿潴留
- **来源**: 23口腔, 19预防
- **答案**: 尿液**充满膀胱而不能自行排出**。急性尿潴留为突然发生、膀胱胀痛、迫切需要排尿而无法排出。需紧急导尿。常见原因：机械性梗阻（BPH、尿道结石）和动力性梗阻（麻醉后、脊髓损伤）。
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

#### Q20. BPH（良性前列腺增生）
- **来源**: 19临五下
- **答案**: **Benign Prostatic Hyperplasia**，老年男性最常见的泌尿系统疾病，组织学表现为前列腺腺体和间质增生，临床表现为**进行性排尿困难**（尿频、尿急、夜尿增多、排尿踌躇、尿线变细、排尿费力）。
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

### 胸部外伤

#### Q21. 纵隔扑动
- **来源**: 19预防
- **答案**: **开放性气胸**或**连枷胸**时，纵隔随呼吸运动**左右摆动**。吸气时纵隔移向健侧，呼气时移向伤侧，严重影响静脉回流和心排血量，是致命性病理生理改变。
- **详见**: [[胸部外伤]]

#### Q22. Beck 三联征
- **来源**: 19临五下, 22临五下
- **答案**: **心音遥远 + 颈静脉怒张 + 动脉压降低**。为急性**心脏压塞（心包填塞）** 的典型体征，见于胸部穿透伤或心脏外科术后，需紧急心包穿刺减压或开胸探查。
- **详见**: [[胸部外伤]]

### 骨科

#### Q23. Bryant 三角
- **来源**: 20临八
- **答案**: 患者仰卧，从髂前上棘向床面作垂线，再从大转子尖向该垂线作垂线，形成的三角形。用于判断**大转子是否上移**，**Bryant 三角底边缩短**提示股骨颈骨折或髋关节后脱位后大转子上移。
- **详见**: [[骨折概述]]

#### Q24. Codman 三角
- **来源**: 22口腔, 18预防
- **答案**: **骨肉瘤**特征性 X 线表现。肿瘤生长掀起骨膜，骨膜下新骨形成三角形骨膜反应，在 X 线上呈现 **Codman 三角**。常与"日光射线"征并存。
- **详见**: [[骨肿瘤]]

#### Q25. 疲劳性骨折
- **来源**: 20预防
- **答案**: 骨骼在**长期、反复、轻微的应力**作用下发生的骨折，好发于**跖骨、胫骨**（如行军骨折）。特点是骨折和修复过程同时进行，无明确的急性外伤史。
- **详见**: [[骨折概述]]

#### Q26. 骨筋膜室综合征
- **来源**: 19临五下, 22临五下
- **答案**: **Osteofascial compartment syndrome**。骨筋膜室内压力增高（> 30mmHg）→室内肌肉和神经**缺血坏死**。常见于前臂掌侧和小腿。典型体征 **5P**：疼痛（Pain）、苍白（Pallor）、无脉（Pulselessness）、感觉异常（Paresthesia）、麻痹（Paralysis）。紧急处理：**切开减压**。
- **详见**: [[骨折概述]]

#### Q27. Pilon 骨折
- **来源**: 20临八（缓）
- **答案**: 胫骨远端关节内粉碎性骨折，由轴向压缩暴力（高处坠落）引起，胫骨远端关节面塌陷伴干骺端粉碎。治疗困难，常需切开复位内固定。
- **详见**: [[骨折概述]]

#### Q28. Cooper 韧带
- **来源**: 20临八（缓）
- **答案**: 即**乳房悬韧带**，连接乳腺皮肤与胸大肌筋膜。乳腺癌侵犯此韧带使其缩短→皮肤凹陷（"酒窝征"），为乳腺癌重要体征。
- **详见**: [[乳腺疾病]]

#### Q29. 冷脓肿
- **来源**: 18预防
- **答案**: 脊柱结核形成的**寒性脓肿**，由结核坏死物和渗出物形成，无红、热、痛等急性炎症表现，沿筋膜间隙流注至远处。需与化脓性脓肿鉴别，治疗以抗结核为主辅以手术清除。
- **详见**: [[关节感染]]

### 结直肠外科

#### Q30. Anal fissure（肛裂）
- **来源**: 21预防/基医/临药
- **答案**: 肛管齿状线以下全层皮肤的**纵行裂伤**，好发于**后正中线**。典型表现：**排便时剧痛（撕裂样）+ 便后少量滴血 + 便秘**三联征。新鲜肛裂可保守治疗，陈旧性需手术。
- **详见**: [[结直肠常见良性疾病]]

#### Q31. Scrotum Paget's disease（阴囊 Paget 病）
- **来源**: 20预防
- **答案**: 阴囊皮肤的**表皮内腺癌**，起源于顶泌汗腺导管开口，表现为红斑、糜烂、渗液、结痂，边界清晰。治疗以局部广泛切除为主，需排除合并内脏恶性肿瘤。
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

### 其他

#### Q32. 前哨淋巴结
- **来源**: 18临八床旁
- **答案**: 原发肿瘤淋巴引流区域中**最先接受淋巴引流的淋巴结**，是肿瘤淋巴转移的第一站。前哨淋巴结活检用于乳腺癌、黑色素瘤等，如前哨淋巴结阴性可免行区域淋巴结清扫。
- **详见**: [[乳腺疾病]]

#### Q33. 间歇性跛行
- **来源**: 20临八
- **答案**: 行走一段距离后出现下肢**疼痛、麻木、乏力**，休息后缓解，再走又出现。分为：①**血管性**（动脉供血不足）；②**神经源性**（腰椎管狭窄症，骑车可减轻可鉴别）。
- **详见**: [[腰椎退行性疾病]]

#### Q34. 导尿试验
- **来源**: 20临八
- **答案**: 经导尿管注入生理盐水 300mL 至膀胱，5 分钟后回抽，若回抽量明显少于注入量（如 < 200mL），提示膀胱破裂（腹腔内型），液体漏入腹腔。
- **详见**: [[无菌术与外科感染]]

## 三、简答题

### 无菌术与外科感染

#### Q1. 革兰阴性菌脓毒血症的临床表现
- **来源**: 20临八
- **答案**: ①**低排高阻型休克（冷休克）**：心排血量降低、外周血管收缩、四肢湿冷、发绀；②**体温不升或低热**（有别于 G⁺菌的高热）；③白细胞计数可**正常或降低**；④易发生 **DIC** 和多器官功能衰竭；⑤致病菌多为大肠杆菌、铜绿假单胞菌、克雷伯菌等。
- **详见**: [[无菌术与外科感染]]

### 休克

#### Q2. 休克微循环障碍的分期和特点
- **来源**: 18临八床旁
- **答案**: ①**微循环缺血期（代偿期）**：儿茶酚胺大量释放→微动脉和毛细血管前括约肌收缩→毛细血管灌注减少（"少灌少流"）；②**微循环淤血期（失代偿期）**：酸中毒→微动脉扩张但微静脉仍收缩→毛细血管淤血（"灌大于流"）→血浆外渗；③**微循环衰竭期（不可逆期）**：血液高凝→**DIC**→细胞死亡→多器官功能衰竭。
- **详见**: [[休克]]

#### Q3. 简述休克的一般监测内容
- **来源**: 22临五上
- **答案**: ①**神志**（反映脑灌注）；②**皮肤色泽温度**（反映外周灌注）；③**血压**（收缩压 < 90mmHg 或较基础值下降 > 40mmHg 为休克）；④**脉率**（> 100 次/分）和**休克指数**（脉率/收缩压 > 1.0 提示休克）；⑤**尿量**（< 30mL/h 提示肾灌注不足，最重要的内脏灌注指标）。
- **详见**: [[休克]]

### 高渗性脱水

#### Q4. 高渗性脱水的分类和治疗原则
- **来源**: 18临八床旁
- **答案**: **分类**（按缺水量）：①**轻度**（缺水量占体重 2-4%）：口渴；②**中度**（4-6%）：严重口渴、皮肤干燥、尿少、乏力；③**重度**（> 6%）：意识障碍、休克、高钠血症。**治疗**：①补水为主（口服或 5% 葡萄糖溶液静滴）；②补钠为辅（0.45% 低渗盐水）；③纠正高钠不宜过快（避免脑水肿），24h 血钠下降 < 10mmol/L。
- **详见**: [[休克]]

### 输血

#### Q5. 输血的适应证
- **来源**: 22临五上
- **答案**: ①**大量失血**（> 20% 血容量或 > 1000mL）；②**贫血**（Hb < 70g/L 或 < 100g/L 合并缺血性心脏病）；③**凝血功能障碍**（血小板、新鲜冰冻血浆、冷沉淀）；④**低蛋白血症**（白蛋白 < 25g/L）。
- **详见**: [[无菌术与外科感染]]

### 甲状腺疾病

#### Q6. 甲状腺术后呼吸困难和窒息的原因和处理方式
- **来源**: 21预防/基医/临药
- **答案**: **原因**：①**切口内出血/血肿压迫**（最常见，术后 24-48h）；②喉头水肿（气管插管、手术操作）；③气管软化塌陷（巨大甲状腺肿长期压迫）；④双侧喉返神经损伤（声带内收）。**处理**：立即床旁**敞开切口、清除血肿**，若无效→紧急气管插管或气管切开。
- **详见**: [[甲状腺疾病]]

#### Q7. 甲状腺癌的病理类型及相应特点
- **来源**: 20预防
- **答案**: ①**乳头状癌**（占 80-85%）：生长缓慢、预后最佳、早期淋巴转移（不影响预后）；②**滤泡状癌**（占 10-15%）：血行转移（肺、骨）多于淋巴转移；③**髓样癌**（5-10%）：来自滤泡旁 C 细胞、**降钙素升高**、有遗传性（MEN2）；④**未分化癌**（< 5%）：生长迅速、预后极差、多见于老年人。
- **详见**: [[甲状腺疾病]]

#### Q8. 甲亢手术的主要并发症
- **来源**: 22口腔
- **答案**: ①**术后呼吸困难和窒息**（最危险，术后 24-48h）；②**甲状腺危象**（术后 12-36h，高热、心动过速）；③**喉返神经损伤**（单侧→声嘶，双侧→窒息）；④**喉上神经损伤**（外支→音调降低，内支→呛咳）；⑤**甲状旁腺功能减退**（低钙抽搐）；⑥**甲减**。
- **详见**: [[甲状腺疾病]]

### 乳房疾病

#### Q9. 乳房的特殊检查方法
- **来源**: 20临八（缓）
- **答案**: ①**乳腺钼靶**（X 线摄影，40 岁以上首选筛查方法）；②**乳腺超声**（年轻女性、致密型乳腺首选，鉴别囊实性）；③**乳腺 MRI**（高危人群筛查、评价病变范围）；④**活检**（粗针穿刺活检/真空辅助旋切活检，是确诊金标准）；⑤**乳管镜**（乳头溢液者）。

### 腹外疝

#### Q10. 腹股沟疝的原因
- **来源**: 22口腔
- **答案**: ①**先天性因素**：鞘状突未闭（斜疝）、腹股沟管发育薄弱；②**后天性因素**：腹壁强度降低（老年肌肉萎缩、胶原代谢异常）+ 腹内压增高（慢性咳嗽、便秘、排尿困难、妊娠、重体力劳动）。
- **详见**: [[腹外疝]]

#### Q11. 腹股沟直疝与斜疝的鉴别要点
- **来源**: 22临五上
- **答案**: | | 斜疝 | 直疝 |
|------|------|------|
| **发病年龄** | 儿童及青壮年 | 老年 |
| **突出途径** | 经腹股沟管（外环突出） | 经直疝三角 |
| **疝块外形** | 椭圆或梨形 | 半球形、基底宽 |
| **回纳后压住内环** | 疝块不再突出 | 疝块仍可突出 |
| **与精索关系** | 疝囊在精索前方 | 疝囊在精索后方 |
| **嵌顿机会** | 较多 | 较少 |
- **详见**: [[腹外疝]]

#### Q12. 股疝容易形成嵌顿疝的原因
- **来源**: 18预防
- **答案**: ①**股管解剖特点**：上下口小而中间膨大，呈漏斗状；②**股环狭小**且周围为坚韧的韧带（髂耻束、Cooper 韧带等）；③疝内容物（常为小肠）一旦进入股管后不易自行回纳。股疝嵌顿率远高于腹股沟疝，一旦确诊应尽早手术。
- **详见**: [[腹外疝]]

### 肠梗阻

#### Q14. 简述如何根据梗阻原因区分不同类型的肠梗阻
- **来源**: 20预防
- **答案**: ①**机械性肠梗阻**（最常见）：肠腔内、肠壁或肠外原因致肠腔堵塞→肠内容物通过障碍（粘连、疝、肿瘤、扭转）；②**动力性肠梗阻**：肠壁肌肉运动障碍，无器质性狭窄（麻痹性—腹膜炎、腹部术后；痉挛性—铅中毒）；③**血运性肠梗阻**：肠系膜血管栓塞或血栓形成→肠缺血坏死→肠蠕动障碍。
- **详见**: [[肠梗阻]]

#### Q15. 判断肠梗阻的步骤
- **来源**: 22口腔
- **答案**: ①**是不是肠梗阻**（痛、吐、胀、闭+气液平）；②**是机械性还是动力性**（有无器质性阻塞）；③**是单纯性还是绞窄性**（有无血运障碍，需急诊手术鉴别，最关键）；④**是高位还是低位**（呕吐特点、腹胀部位、扩张肠管形态）；⑤**是完全性还是不完全性**；⑥**是什么原因**（粘连、疝、肿瘤、扭转等）。
- **详见**: [[肠梗阻]]

#### Q16. 绞窄性肠梗阻的特征
- **来源**: 20临八（缓）
- **答案**: ①持续性剧烈腹痛，阵发性加重；②早期出现**休克**且抗休克治疗效果不佳；③腹膜刺激征阳性（压痛、反跳痛、肌紧张）；④呕吐物或肛门排出物为血性，**腹腔穿刺抽出血性液体**；⑤X 线示**孤立、胀大、固定的肠襻**（咖啡豆征）；⑥积极非手术治疗（12-24h）后症状体征无改善反而加重。
- **详见**: [[肠梗阻]]

### 结直肠癌

#### Q17. 大肠癌的转移途径
- **来源**: 18预防
- **答案**: ①**直接蔓延**：沿肠壁环形浸润或向肠壁深层浸润→穿透浆膜侵犯邻近器官；②**淋巴转移**（主要途径）：结肠旁淋巴结→中间淋巴结→肠系膜根部淋巴结；直肠癌→直肠上动脉旁→肠系膜下动脉旁→腹主动脉旁/向上至髂内淋巴结（下段）；③**血行转移**：门静脉→肝（最常见远处转移）、肺、骨、脑；④**种植转移**：脱落癌细胞在腹腔内脏器表面种植。
- **详见**: [[结直肠癌]]

### 肝脏疾病

#### Q18. 简述体检发现肝脏占位性病变的诊疗程序
- **来源**: 19预防
- **答案**: ①**无创检查**：增强 CT/MRI（快进快出→肝癌；持续性强化→血管瘤；无强化→囊肿）+ 肿瘤标志物（AFP、CEA、CA199）；②**良性可能性大**（血管瘤、FNH、囊肿）→定期随访（3-6 月复查影像）；③**恶性不能排除**→**肝脏穿刺活检**（超声/CT 引导）；④**仍不确定**→腹腔镜探查 ± 术中超声 ± 手术切除活检。
- **详见**: [[肝脏疾病]]

### 胆道疾病

#### Q19. 急性梗阻性化脓性胆管炎（AOSC）的诊断和治疗
- **来源**: 18临八床旁
- **答案**: **诊断**：Charcot 三联征（**腹痛、寒战高热、黄疸**）+ **休克** + **神志改变** = **Reynolds 五联征**。**治疗**：①抗休克+抗生素同时**急诊胆道减压引流**（ERCP + ENBD/支架首选，或 PTBD，或急诊手术 T 管引流）；②延迟手术待病情稳定后再行根治性手术。
- **详见**: [[胆道外科疾病]]

### 胰腺疾病

#### Q20. 急性胰腺炎的治疗方式哪些不是？
- **来源**: 21预防/基医/临药
- **答案**: [根据考点提示整理] 急性胰腺炎治疗：①**禁食、胃肠减压**；②液体复苏；③镇痛（哌替啶而非吗啡，后者致 Oddi 括约肌痉挛）；④抑制胰液分泌（生长抑素、PPI）；⑤抗生素（感染性胰腺坏死时）；⑥营养支持（早期肠内营养）。**以下不是**：常规预防性使用抗生素、早期积极手术。
- **详见**: [[急性胰腺炎]]

### 食管癌

#### Q21. 食管癌的手术方式
- **来源**: 21预防/基医/临药
- **答案**: ①**经胸食管癌切除 + 食管胃吻合术**（最常用，胃代食管）；②**经食管裂孔食管切除术**（不开胸，适用于早期、老年、心肺功能差者）；③**颈段食管癌**：全咽喉+食管切除+游离空肠/胃代食管。切除范围：距肿瘤上下缘 **5-7cm** 以上，清扫区域淋巴结。

### 胸部外伤与肺癌

#### Q22. 肺癌后期侵犯周围器官时的临床表现和体征
- **来源**: 20预防
- **答案**: ①侵犯**喉返神经**→声音嘶哑（左侧多见）；②侵犯**上腔静脉**→上腔静脉梗阻综合征（头面水肿、颈静脉怒张）；③侵犯**胸膜/胸壁**→剧烈胸痛；④**Pancoast 瘤**（肺尖部）→Horner 综合征（同侧瞳孔缩小、上睑下垂、眼球内陷、面部无汗）+ 臂丛神经痛；⑤侵犯**食管**→吞咽困难；⑥**远处转移**症状（肝、骨、脑、肾上腺）。
- **详见**: [[肺癌]]

#### Q23. 开放性气胸的急救和治疗原则
- **来源**: 20临八（缓）
- **答案**: **急救**：立即将开放性气胸变为**闭合性气胸**（无菌敷料/凡士林纱布封闭胸壁伤口，固定时不密封以免形成张力性气胸）→**胸腔闭式引流**。**治疗原则**：①纠正休克（补液、供氧）；②胸腔闭式引流排气减压；③清创缝合胸壁伤口；④应用抗生素预防感染；⑤必要时剖胸探查（持续漏气、进行性血胸、胸内器官损伤）。
- **详见**: [[胸部外伤]]

#### Q24. 胸部损伤中开胸探查的适应证
- **来源**: 19临五下, 22临五下
- **答案**: ①**进行性血胸**（闭式引流量 ≥ 200mL/h，持续 3 小时）；②**心脏大血管损伤**（Beck 三联征、心包穿刺抽出血液）；③**食管破裂**；④**气管支气管断裂**；⑤**大量气胸引流后持续漏气**，肺不能复张；⑥**凝固性血胸**；⑦**胸腹联合伤**。
- **详见**: [[胸部外伤]]

### 骨折

#### Q25. 骨折的治疗原则
- **来源**: 19临五下
- **答案**: **复位、固定、功能锻炼**（三大原则）。①**复位**：恢复骨折端的解剖关系（解剖复位或功能复位）；②**固定**：维持复位后的位置直至临床愈合（外固定—石膏/夹板/牵引；内固定—钢板/髓内钉/螺钉）；③**功能锻炼**：在不影响固定的前提下尽早开始（防止关节僵硬、肌肉萎缩、促进骨折愈合）。
- **详见**: [[骨折概述]]

#### Q26. 骨折功能复位的标准
- **来源**: 20临八（缓）
- **答案**: ①**短缩**：下肢 < 2cm，上肢可略多但功能可耐受；②**成角**：与关节活动方向一致的轻微成角可接受；③**旋转**：必须完全纠正；④**分离**：必须完全纠正（分离影响愈合）；⑤**侧方移位**：< 1/4-1/3 骨干直径可接受。达不到功能复位标准需手术切开复位。
- **详见**: [[骨折概述]]

#### Q27. 骨折远期并发症
- **来源**: 23口腔
- **答案**: ①**创伤性关节炎**（关节内骨折复位不良）；②**缺血性骨坏死**（股骨颈骨折→股骨头坏死；腕舟骨骨折→骨坏死）；③**骨化性肌炎**（肘关节周围血肿骨化）；④**关节僵硬**（长期固定未功能锻炼）；⑤**骨折延迟愈合/不愈合/畸形愈合**；⑥**骨筋膜室综合征后遗症**（Volkmann 挛缩）；⑦**周围神经损伤**。
- **详见**: [[骨折概述]]

#### Q28. 骨骼晚期并发症
- **来源**: 19预防
- **答案**: 同 [[#Q27. 骨折远期并发症|骨折远期并发症]]。再加：**骨质疏松**（长期制动）、**骨萎缩**（Sudeck 萎缩）、**生长障碍**（儿童骨骺损伤）。
- **详见**: [[骨折概述]]

### 关节与骨感染

### 腰椎退行性疾病

#### Q30. 腰椎间盘突出非手术治疗的适应证
- **来源**: 23口腔
- **答案**: ①**初次发作或病程短**；②**症状轻**（仅有腰痛或轻度腿痛，无马尾神经症状）；③**无神经功能进行性加重**；④**无马尾综合征**；⑤影像学无巨大突出或游离碎片。方法：卧床休息、牵引、物理治疗、NSAID、硬膜外激素注射等。
- **详见**: [[腰椎退行性疾病]]

#### Q31. 腰椎间盘突出症的手术适应证
- **来源**: 22临五下
- **答案**: ①**非手术治疗 3-6 个月无效**；②**进行性神经功能障碍**（肌力进行性下降）；③**马尾综合征**（鞍区感觉障碍+大小便功能障碍→急诊手术）；④**剧烈疼痛严重影响生活**。
- **详见**: [[腰椎退行性疾病]]

#### Q32. 腰4-5椎间盘突出症（侧后方）的临床症状及体征
- **来源**: 19预防
- **答案**: 腰 4-5 椎间盘突出压迫 **L5 神经根**。①**疼痛**：腰部+臀部+大腿后外侧+小腿前外侧+足背放射痛；②**感觉**：小腿前外侧及足背感觉减退；③**运动**：**踇趾背伸力减弱**（L5 支配胫前肌+踇长伸肌）；④**反射**：无明显改变（L4→膝反射，S1→踝反射，L5 一般无特征性反射改变）；⑤**直腿抬高试验阳性**。
- **详见**: [[腰椎退行性疾病]]

### 泌尿外科

#### Q33. 双侧上尿路结石手术治疗原则
- **来源**: 22口腔, 19临五下, 22临五下
- **答案**: ①先处理**梗阻严重侧**（积水重、肾功能差的一侧）；②先处理**易处理侧**（结石小、位置好的一侧）；③**两侧肾功能均严重受损**→先处理手术简单安全的一侧，或经皮肾镜同时双侧处理；④**一侧肾已无功能**→先处理有功能侧，无功能侧后期切除；⑤总原则：最大限度保护肾功能。
- **详见**: [[泌尿系结石]]

#### Q34. 膀胱癌的治疗方式
- **来源**: 21预防/基医/临药
- **答案**: ①**非肌层浸润性**（NMIBC，Ta/T1/Tis）：**TURBT** + 术后**膀胱灌注**（化疗药—丝裂霉素，或免疫治疗—卡介苗 BCG，尤其适用于高危/CIS）；②**肌层浸润性**（MIBC，T2-T4）：**根治性膀胱切除术** + 尿流改道（回肠膀胱/原位新膀胱）+ 盆腔淋巴结清扫；③**转移性**：全身化疗（含铂方案）+ 免疫治疗/靶向治疗。
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

#### Q35. 肾损伤的手术治疗指征
- **来源**: 22临五下
- **答案**: ①**血流动力学不稳定**经积极补液输血无效；②**肾蒂损伤**（迅速大量失血）；③**持续血尿**伴血流动力学不稳定；④**进行性增大或搏动性肾周血肿**；⑤**肾盂输尿管连接部撕脱或输尿管断裂**。大多数肾挫伤和轻度裂伤可保守治疗（卧床、止血、抗感染）。
- **详见**: [[泌尿系结石]]

#### Q36. 输尿管结石的好发部位和病理生理
- **来源**: 18预防
- **答案**: **好发部位**（三个生理狭窄）：①**肾盂输尿管连接处**；②**输尿管跨髂血管处**；③**输尿管膀胱壁内段**。**病理生理**：结石嵌顿→输尿管梗阻→**肾积水**→肾盂肾盏内压升高→肾小球滤过率下降→肾功能损害→长期梗阻→肾实质萎缩、肾功能丧失。伴感染可致肾盂肾炎或脓肾。
- **详见**: [[泌尿系结石]]

#### Q37. 前列腺癌与良性前列腺增生的鉴别诊断要点
- **来源**: 19预防
- **答案**: | | BPH | 前列腺癌 |
|------|-----|---------|
| **好发部位** | 移行带（尿道周围） | 外周带（直肠指检可触及） |
| **PSA** | 可轻度升高（< 10ng/mL） | 显著升高（常 > 10ng/mL） |
| **直肠指检** | 光滑、有弹性 | 硬结、不规则 |
| **确诊方法** | 超声+症状评分（IPSS） | 穿刺活检 |
| **骨转移** | 无 | 可有（成骨性转移） |
- **详见**: [[泌尿系肿瘤与前列腺疾病]]

### 颅脑与神经外科

#### Q38. 脑疝的定义与病因
- **来源**: 20临八
- **答案**: **定义**：颅内某一分腔的占位性病变使该分腔压力增高→脑组织从高压力区**经解剖间隙或孔道**向低压力区移位→压迫脑干、颅神经和血管。**病因**：①颅内血肿（外伤性、自发性）；②大面积脑梗死/脑水肿；③颅内肿瘤；④脑积水；⑤颅内感染/脓肿。脑疝是神经外科最紧急的致死性状态，需立即降颅压（甘露醇）+ 急诊手术减压。
- **详见**: [[腰椎退行性疾病]]

### 围手术期与综合

#### Q39. 癌症三级预防
- **来源**: 20临八（缓）
- **答案**: ①**一级预防**（病因预防）：减少或消除致癌因素（戒烟、疫苗接种—乙肝/HPV、健康饮食）；②**二级预防**（早筛早诊）：高危人群筛查（乳腺钼靶、宫颈 TCT+HPV、结肠镜、低剂量 CT 筛查肺癌）；③**三级预防**（临床预防）：规范治疗、防止复发转移、提高生存质量、姑息治疗。
- **详见**: [[无菌术与外科感染]]

#### Q40. 急性肾衰竭的病因
- **来源**: 20临八（缓）
- **答案**: ①**肾前性**（肾灌注不足→占 55-60%）：低血容量、休克、心衰；②**肾性**（肾实质损伤→占 35-40%）：急性肾小管坏死（ATN）、肾小球肾炎、间质性肾炎、肾毒性药物；③**肾后性**（尿路梗阻→占 5%）：结石、肿瘤、BPH →双侧/孤立肾梗阻。
- **详见**: [[泌尿系结石]]

## 四、病例分析

### 肠梗阻

#### Q1. 肠梗阻病例
**题干**：女，70 岁，间歇腹胀、停止排便排气伴腹痛 2 周，加重 2 天。近 2 周间歇发作，每次 3 天左右，服药可缓解。2 天前再次发作且加重，不排便不排气，呕吐一次。乏力，消瘦。全腹明显膨隆，左下腹深部可及 5cm 包块，实性，轻压痛。X 线腹平片：右上腹可见液气平面。
- **来源**: 18临八床旁
- **Q1. 诊断及诊断依据**
- **答案**: **结肠癌致闭襻性肠梗阻**。依据：①老年女性 + 慢性间歇性肠梗阻 + 近期加重；②左下腹实性包块；③X 线示液气平面（肠梗阻）；④排便排气停止+腹胀+呕吐；⑤乏力+消瘦（恶性消耗）。
- **Q2. 鉴别诊断**
- **答案**: ①单纯性粘连性肠梗阻（无腹部包块、既往有手术史）；②乙状结肠扭转（X 线有特征性"鸟嘴征"）；③粪石性肠梗阻（多见于老年人、便秘史）。
- **Q3. 进一步检查**
- **答案**: 结肠镜检查（取活检明确病理）、腹部增强 CT（评估肿瘤范围和有无肝转移）、CEA 肿瘤标志物。
- **Q4. 治疗原则**
- **答案**: ①禁食、胃肠减压、补液纠正水电解质紊乱；②若为不完全性梗阻→限期手术（结肠癌根治术）；③若为完全性梗阻→急诊手术（可先行术中灌洗后行一期吻合，或造口术二期吻合）。
- **详见**: [[肠梗阻]], [[结直肠癌]]

### 胆道疾病

#### Q2. 急性梗阻性化脓性胆管炎（AOSC）病例
**题干**：老年女性，上腹疼痛，寒战高热，伴黄疸，低血压，神志模糊；三年前有胆囊结石病史；检查示胆总管增粗，直径 1.5cm。
- **来源**: 22临五上
- **Q1. 诊断和诊断依据**
- **答案**: **急性梗阻性化脓性胆管炎（AOSC）**。依据：①Charcot 三联征（腹痛+寒战高热+黄疸）+ 休克+神志模糊 = **Reynolds 五联征**；②既往胆囊结石病史；③胆总管增粗（> 8mm = 扩张）→胆总管结石嵌顿致梗阻。
- **Q2. 鉴别诊断**
- **答案**: ①**急性胆囊炎**（Murphy 征阳性、超声示胆囊增大、壁厚、胆囊结石）；②**肝脓肿**（高热+右上腹痛+超声示肝内低密度灶）；③**急性胰腺炎**（上腹痛+血尿淀粉酶升高+CT 示胰腺水肿）。
- **Q3. 进一步检查**
- **答案**: 血常规+CRP+降钙素原、肝功能、凝血功能、血培养；急诊 B 超（首选）/ MRCP / ERCP（兼具诊断和治疗）。
- **Q4. 治疗原则和治疗方法**
- **答案**: ①**抗休克+抗感染同时急诊胆道减压引流**（ERCP + EST + 取石 + ENBD 为首选）；②若 ERCP 不可行→PTBD 或急诊胆总管探查+T 管引流术；③病情稳定后行胆囊切除+胆总管探查。
- **详见**: [[胆道外科疾病]]

### 胸部外伤

#### Q3. 张力性气胸/血胸病例
**题干**：男，24 岁，高处坠地（3 米），左侧胸先着地，呼吸困难 20 分钟。查体：T 36.5°C，P 148 次/分，R 40 次/分，BP 80/50mmHg。口唇青紫，气管移向右侧。左胸廓饱满，呼吸运动弱。左胸壁第 4、5 肋有骨擦音。上自颈部至腹部可触及皮下气肿。左胸叩鼓，呼吸音消失。心音较弱。
- **来源**: 20临八
- **Q1. 诊断与诊断依据**
- **答案**: **左侧张力性气胸 + 左侧肋骨骨折（4、5肋）+ 皮下气肿 + 失血性休克**。依据：①外伤史；②呼吸困难、发绀、气管向健侧移位；③左胸叩鼓+呼吸音消失+皮下气肿（张力性气胸三联）；④肋骨骨擦音（骨折）；⑤BP 80/50、P 148（失血性休克）。
- **Q2. 鉴别诊断**
- **答案**: ①**开放性气胸**（有胸壁破损）；②**大量血胸**（叩诊浊音、呼吸音减弱但非消失，气管可移位但无气胸体征）；③**心脏压塞**（Beck 三联征，但无气胸体征）。
- **Q3. 进一步检查**
- **答案**: 胸部 X 线（床边）；血气分析；Hb+Hct 动态监测（评估失血）；必要时胸部 CT。
- **Q4. 治疗原则**
- **答案**: ①立即**胸腔闭式引流**（左侧锁骨中线第 2 肋间）；②补充血容量、纠正休克；③吸氧；④肋骨骨折固定；⑤若持续漏气或进行性血胸→开胸探查。
- **详见**: [[胸部外伤]]

### 肝脏肿瘤

#### Q4. 肝癌病例
**题干**：男性，50 余岁，20 年乙肝史，右上腹疼痛 2 月，体重下降 5kg，AFP 800μg/L，影像显示右肝 5cm 占位，动脉期快进快出。
- **来源**: 23口腔
- **Q1. 诊断和诊断依据**
- **答案**: **原发性肝细胞肝癌（HCC）**。依据：①慢性乙肝病史（高危因素）；②右上腹痛+消瘦（典型临床表现）；③AFP 800μg/L（> 400 持续 4 周高度提示 HCC）；④增强 CT/MRI "**快进快出**"（动脉期早期强化、门静脉期快速廓清，HCC 特征性影像）。
- **Q2. 后续治疗方案**
- **答案**: ①**首选手术切除**（单个肿瘤、Child-Pugh A 级、无肝外转移）；②若不宜手术→**TACE**（经肝动脉化疗栓塞）、**消融**（射频/微波，适用于 < 3cm 肿瘤）、**靶向治疗**（索拉非尼/仑伐替尼）+ **免疫治疗**（阿替利珠单抗+贝伐珠单抗）；③若合适→肝移植（符合米兰标准）。
- **详见**: [[肝脏疾病]]

### 骨科

#### Q5. 髋关节后脱位病例
**题干**：男性，40 岁，乘车时右下肢搭于左腿上（翘二郎腿），突然急刹车时右膝顶撞于前座椅背上，即感右髋部剧痛、不能活动。查体：右下肢短缩，右髋呈屈曲内收内旋畸形，右大粗隆上移，右下肢感觉正常。
- **来源**: 19临五下, 22临五下
- **Q1. 初步诊断及诊断依据**（5分）
- **答案**: **右髋关节后脱位**。依据：①特殊受伤机制（屈髋屈膝位，膝前方向后方的轴向暴力→股骨头向后脱出）；②典型畸形：**屈曲、内收、内旋、短缩**；③大粗隆上移（Bryant 三角底边缩短）。
- **Q2. 鉴别诊断**（3分）
- **答案**: ①**股骨颈骨折**（外旋畸形，而非内旋，下肢短缩和外旋角度通常更明显）；②**股骨转子间骨折**（外旋畸形更明显，> 60°）。
- **Q3. 下一步检查**（3分）
- **答案**: **骨盆正位 X 线片 + 右髋侧位片**（必要时 CT 三维重建，排除合并骨折）。
- **Q4. 治疗原则**（4分）
- **答案**: ①**尽早复位**（局麻/全麻下闭合复位，常用 Allis 法/Stimson 法），越早越好（< 6 小时）；②复位后**皮肤牵引**或髋人字石膏固定 **3-4 周**；③固定期间**早期功能锻炼**（股四头肌等长收缩、踝关节活动）；④去除固定后逐渐下床负重，2-3 月后完全恢复活动。
- **详见**: [[关节脱位]]

#### Q6. 肱骨髁上骨折病例（儿童）
**题干**：6 岁女性，两小时前跳动中向前跌倒，手掌着地，右肘痛、不敢活动。查体：右肘向后突出处于半屈曲位，肘部肿胀、皮下瘀斑，压痛明显，轴心挤压痛，肘前方可及骨折近端，肘后三角关系正常，右桡动脉搏动稍弱。
- **来源**: 22临五下
- **Q1. 诊断及诊断依据**（5分）
- **答案**: **右肱骨髁上骨折（伸直型）**。依据：①好发年龄（< 10 岁）；②典型受伤机制（手掌着地，肘关节过伸）；③轴心挤压痛并触及骨折近端；④**肘后三角关系正常**（区别于肘关节脱位—脱位肘后三角异常）；⑤桡动脉搏动减弱—提示血管受压。
- **Q2. 鉴别诊断**（4分）
- **答案**: **肘关节后脱位**：①肘后三角异常（鹰嘴向后上移位）；②弹性固定（被动活动有弹性阻力）；③多见于青壮年而非儿童。
- **Q3. 进一步检查与治疗原则**（6分）
- **答案**: **检查**：右肘正侧位 X 线片（明确骨折线、移位情况）；必要时血管超声（评估肱动脉）。**治疗**：①无移位→**屈肘位石膏后托固定** 3-4 周；②有移位→**手法复位**+ 屈肘位石膏固定；③手法复位失败或血管神经损伤→切开复位内固定；④密切观察前臂肿胀和桡动脉搏动。
- **详见**: [[骨折概述]]

## 五、考试提示

### 整体特点
- 外科学分为**外科 B（上）**（总论+普外科+胸外科神经外科基础）和**外科 B（下）**（骨科+泌尿外科+胸心外科）两个考试
- 外科（上）侧重：无菌术与外科感染、休克、输血与围手术期、甲状腺和乳房、腹外疝、胃肠肝胆胰、结直肠和肛管、食管
- 外科（下）侧重：胸部外伤与肺癌、骨折概论与各论、关节脱位与感染、腰椎退行性疾病、骨肿瘤、泌尿系结石/感染/肿瘤/BPH
- 选择题以病例分析型（A2/A3 型）为主，综合性很强
- 名词解释和简答题覆盖范围广，有超纲现象（如 Child-Pugh 分级）
- 历年题覆盖率中等，建议 DCF+课本结合复习

### 各章节高频提示
- **无菌术与外科感染**：痈（切开引流）、破伤风（特异性感染）、抗生素预防指征
- **休克**：分期特点、监测（尿量最重要）、脓毒性休克处理
- **甲状腺**：术后呼吸困难和窒息（血肿压迫）、甲亢术后并发症、甲状腺癌病理类型
- **乳腺**：酒窝征（Cooper 韧带）、乳腺癌临床表现和检查、改良根治术
- **腹外疝**：直疝/斜疝鉴别、股疝（嵌顿率高、McVay 法）、疝修补术式选择
- **阑尾炎**：McBurney 点、淋巴滤泡增生为最常见病因、特殊类型阑尾炎
- **胃十二指肠**：胃大部切除术后近期和远期并发症、倾倒综合征、残胃癌
- **肠梗阻**：绞窄性肠梗阻特征（孤立扩大肠襻、血性腹水）、鉴别诊断步骤
- **结直肠癌**：左右半结肠癌差异、转移途径、直肠指检的地位
- **胆道**：AOSC/Reynolds 五联征、ERCP 治疗、Mirizzi 综合征
- **肝脏**：AFP（HCC 标志物）、Child-Pugh 分级、肝脓肿感染途径
- **胰腺**：胰腺癌好发胰头、Grey-Turner 征、手术指征
- **食管癌**：进行性吞咽困难、好发胸中段、Lugol 染色、手术方式
- **胸部外伤**：张力性气胸/开放性气胸/连枷胸、纵隔扑动、Beck 三联征、进行性血胸（200mL/h×3h）、开胸探查指征
- **肺癌**：Pancoast 瘤/Horner 综合征、中央型vs周围型、小细胞肺癌手术+化疗
- **骨折**：愈合分期和标准、三大治疗原则、桡神经/腋神经损伤、骨筋膜室综合征（5P）
- **关节脱位**：弹性固定、肩关节前脱位（Dugas 征）、髋关节后脱位（屈曲内收内旋畸形）
- **腰椎**：腰椎间盘突出症 vs 腰椎管狭窄症（间歇性跛行鉴别）
- **骨肿瘤**：Codman 三角（骨肉瘤）、骨软骨瘤（无症状）、Bence Jones 蛋白（多发性骨髓瘤）
- **泌尿外科**：无痛性血尿（膀胱癌）、PSA（前列腺癌）、BPH 手术指征、双侧上尿路结石处理原则

## 考点出题频数统计

```dataviewjs
const file = dv.current().file;
const content = await dv.io.load(file.path);
const lines = content.split('\n');

const totalCounts = new Map();
const bpCounts = new Map();

let currentSource = '';

for (const line of lines) {
  const sourceMatch = line.match(/- \*\*来源\*\*:\s*(.+)/);
  if (sourceMatch) {
    currentSource = sourceMatch[1];
    continue;
  }

  const detailMatch = line.match(/- \*\*详见\*\*:\s*(.+)/);
  if (detailMatch && currentSource) {
    const linkText = detailMatch[1];
    const wikiLinks = linkText.match(/\[\[([^\]]+)\]\]/g);
    if (wikiLinks) {
      const isBPMajor = /预防|基医|临药|口腔/.test(currentSource);
      for (const link of wikiLinks) {
        let noteName = link.slice(2, -2);
        if (noteName.includes('|')) noteName = noteName.split('|')[0];
        if (noteName.includes('#')) noteName = noteName.split('#')[0];
        totalCounts.set(noteName, (totalCounts.get(noteName) || 0) + 1);
        if (isBPMajor) {
          bpCounts.set(noteName, (bpCounts.get(noteName) || 0) + 1);
        }
      }
    }
    currentSource = '';
  }
}

const allNotes = [...new Set([...totalCounts.keys(), ...bpCounts.keys()])];
const sorted = allNotes
  .map(note => ({
    note,
    total: totalCounts.get(note) || 0,
    bp: bpCounts.get(note) || 0
  }))
  .sort((a, b) => b.total - a.total);

const totalQuestions = sorted.reduce((sum, item) => sum + item.total, 0);
const totalBP = sorted.reduce((sum, item) => sum + item.bp, 0);

dv.paragraph("共 **" + sorted.length + "** 个知识点被关联，总关联 **" + totalQuestions + "** 题次（其中预防/基医/临药/口腔 **" + totalBP + "** 题次）");

dv.table(
  ["排名", "知识点", "总出题数", "预防/基医/临药/口腔"],
  sorted.map((item, i) => [
    "#" + (i + 1),
    dv.fileLink(item.note),
    item.total,
    item.bp
  ])
);
```
