# 急性白血病（Acute Leukemia, AL）

## 概述

急性白血病是造血干/祖细胞的恶性克隆性疾病，起病急、病情重，自然病程一般在六个月以内。骨髓及外周血中主要为异常的原始细胞和早期幼稚细胞，正常造血受抑并浸润其他器官或组织。

## 分类

### FAB分型（法美英合作组，1976年）—— 形态学分型

**急性淋巴细胞白血病（ALL）** ：

| 亚型 | 特征 |
|------|------|
| **L1型** | 细胞分化较好，以小淋巴细胞为主（≤12μm），治疗反应较好 |
| **L2型** | 以大淋巴细胞为主，有大小不均，治疗反应相对较差 |
| **L3型（Burkitt型）** | 以大细胞为主（＞12μm），大小较一致，治疗缓解率低 |

**急性髓系白血病（AML）** ：

| 亚型 | 名称 | 关键特征 |
|------|------|---------|
| **M0** | 急性髓细胞白血病微分化型 | 原始细胞类似淋巴细胞，MPO染色弱，电镜下MPO（+），CD13/CD33（+） |
| **M1** | 急性粒细胞白血病未分化型 | 未分化原粒细胞占骨髓非幼红细胞≥90%，MPO（+）>3% |
| **M2** | 急性粒细胞白血病部分分化型 | 原粒细胞占骨髓非幼红30-89%，单核细胞<20%；M2b：中性中幼粒≥30% |
| **M3** | 急性早幼粒细胞白血病（APL） | 颗粒增多的异常早幼粒细胞增生，可见Auer小体或"柴捆细胞" |
| **M4** | 急性粒-单核细胞白血病 | 粒系、单核系同时增生；M4Eo：嗜酸粒细胞≥5% |
| **M5** | 急性单核细胞白血病 | 原始/幼单核细胞增生 |
| **M6** | 急性红白血病 | 骨髓幼红细胞≥50%，非红系细胞中原始细胞≥30% |
| **M7** | 急性巨核细胞白血病 | 原巨核细胞＞30%，血小板抗原阳性，骨髓往往干抽 |

### MICM分型（WHO分型）

- **M**orphology（细胞形态）
- **I**mmunotype（免疫表型）
- **C**ytogenetics（细胞遗传学）
- **M**olecular biology（分子生物学）

为血液肿瘤患者预后判断、个体化治疗方案的选择提供依据。

## 临床表现

![[内科-白血病-临床表现.webp]]

### 正常造血受抑表现

- **[[贫血]]**：表现为乏力、苍白、头晕、心悸
- **出血**：皮肤瘀点/瘀斑、鼻出血、牙龈出血，严重者内脏出血；APL患者易合并[[弥散性血管内凝血|DIC]]
- **发热/感染**：中性粒细胞减少所致，可表现为口腔炎、咽喉炎、肺炎、肛周感染等

### 器官/组织浸润表现

- **肝、脾、[[淋巴结]]肿大**：多见于ALL
- **骨及关节表现**：胸骨压痛是白血病常见的特异性体征
- **皮肤黏膜浸润**：牙龈增生肿胀（M4/M5多见）
- **绿色瘤**：粒细胞白血病形成的髓外肿瘤
- **中枢神经系统白血病（CNS-L）**：常见于ALL（尤其儿童），AML中M4、M5、M2多见；也是白血病复发的根源

![[内科-白血病-髓外浸润.webp]]

#### 脑膜白血病诊断标准（具备1项即可）

1. 头痛、恶心、呕吐、脑膜刺激征、意识障碍
2. [[颅神经]]受损表现
3. 脑脊液压力 ＞ 200mmH₂O
4. 脑脊液生化及常规：蛋白质升高或糖定量下降
5. 脑脊液涂片：找到白血病细胞

## 辅助检查

### 血象

- **白细胞增多性白血病**：白细胞 ＞ 10×10⁹/L，多在 10～50×10⁹/L，部分 ＞ 100×10⁹/L，血涂片可见原始和幼稚细胞
- **白细胞不增多性白血病**：白细胞正常或减少，外周血原始细胞极少或缺如，需骨髓穿刺确诊
- 常有不同程度正细胞性贫血、[[血小板]]减少

### 骨髓象

**诊断急性白血病的重要方法**

- 有核细胞增生明显活跃或极度活跃
- 增生的有核细胞主要是原始细胞和早期幼稚细胞（原粒Ⅰ型+Ⅱ型、原单+幼单或原淋+幼淋）
- 白血病细胞形态异常：核浆比例失调，核形态不规则（扭折、分叶、切迹、双核），核仁明显，核浆发育不平衡
- 胞浆出现**Auer小体**是AML的重要标记之一

### 细胞化学

| 染色 | 急粒（AML） | 急淋（ALL） | 急单（AMoL） |
|------|:-----------:|:-----------:|:------------:|
| 髓过氧化酶（POX） | **+++** | - | ± |
| 苏丹黑（SBB） | **+++** | - | ± |
| 非特异酯酶（NSE） | ± | - | **+++**（被NaF抑制≥50%） |
| 特异性酯酶（AS-DCE） | **++** | - | － |
| 糖原（PAS） | - | **+++** | － |

![[内科-白血病-细胞化学.webp]]

### 免疫分型

**B-ALL**：CD19、CD10、CD22、CD20；HLA-DR（+）
**T-ALL**：CD7、CD5、CD2、CD1；CyCD3、SmCD3
**AML**：CD13、CD33、CD14（单核系）、CD34、HLA-DR；M3缺乏HLA-DR和CD34表达

### 染色体检查

**重现性染色体异常**（即使骨髓涂片白血病细胞＜20%也可诊断为急性白血病）：

- **t(15;17)** → PML::RARα → APL（M3）
- **t(8;21)** → AML（M2）
- **inv(16)** → AML（M4Eo）
- **t(9;22)** → BCR::ABL1 → Ph⁺ ALL
- **t(9;11)**、t(6;9)、t(3;3)、inv(3)、t(16;16)、t(1;22)

![[内科-白血病-染色体.webp]]

### 分子生物学

- FAB分型：原始细胞 ≥ 骨髓有核细胞（ANC）的 **30%**
- WHO分型：≥ **20%**（伴重现性遗传学异常的AML ＜ 20%也可诊断，除外BCR::ABL1融合或CEBPA突变的AML）

### 其他实验室检查

- 尿酸 ↑
- 乳酸脱氢酶（LDH）↑
- 电解质及酸碱平衡异常
- [[凝血]]象异常

## 诊断与鉴别诊断

### 诊断标准

综合血象、骨髓象（原始细胞≥20%）、细胞化学、免疫分型、细胞遗传学和分子生物学结果（MICM分型）确立诊断。

### 鉴别诊断

1. **[[骨髓增生异常性肿瘤|MDS]]**：病态造血、原始细胞＜20%，骨髓活检可见ALIP现象；特定遗传学异常（5q-、TP53双等位基因失活、SF3B1突变）
2. **[[再生障碍性贫血]]**：白细胞不增多性白血病易混淆；骨髓脂肪组织增多，有核细胞增生低下，巨核细胞显著减少或缺如，罕有染色体异常
3. **[[巨幼细胞贫血]]**：M6易混淆；巨幼贫骨髓原始细胞不增多，幼红细胞PAS阴性，叶酸/维生素B₁₂治疗有效
4. **类白血病反应**：见于肿瘤或感染，原始细胞比例低，NAP ↑，积极寻找原发病
5. **[[传染性单核细胞增多症]]**：EB病毒感染，三联征（发热、咽痛、颈部淋巴结肿大），异型淋巴细胞与原始细胞不同，自限性病程

## 治疗

![[内科-白血病-治疗总览.webp]]

### 支持治疗

- 病室环境清洁、个人卫生护理、保证足够营养
- 成分输血、抗感染、细胞因子
- 防治尿酸性肾病：水化、碱化、[[别嘌呤醇]]

### 高白细胞急性白血病治疗

目的：避免白细胞淤滞，预防化疗过程中发生"溶瘤综合征"
- 血细胞分离机 —— 白细胞单采术
- 预治疗降低肿瘤负荷：AML —— [[羟基脲]]；ALL —— [[强的松]]
- 充分水化、碱化，预防高尿酸血症、酸中毒、电解质紊乱

### 化疗原则

- **早期、足量、联合、间歇、个体化**
- **诱导缓解治疗** → **缓解后治疗**（巩固强化 + 维持治疗）
- 联合意义：CCSA与CCNSA联合；不同周期药物联合；减轻毒副作用、增加疗效

![[内科-白血病-化疗方案.webp]]

### 标准诱导方案

| 类型 | 标准诱导方案 | 备注 |
|------|------------|------|
| **AML（非M3）** | **DA方案（3+7）** ：DNR 40-60mg/m² d1-3 + Ara-C 100-200mg/m² d1-7 | 不耐受强化疗：维奈克拉+去甲基化药物（阿扎胞苷/地西他滨） |
| **ALL** | **VDLP方案** ：VCR 2mg/m² weekly + DNR 30-60mg/m² d1-3 + L-ASP 500IU/m²·d×10d + Pred 40mg/m²·d | Ph⁺ ALL联用TKI（CR率提高至90-95%） |

### APL（M3）的治疗

- **临床特征**：弥散性血管内凝血（DIC）→ 出血倾向（70-90%）
- **双诱导方案**：**ATRA + 砷剂**（+/- 蒽环类防治维A酸综合征/分化综合征）
- **作用机制**：
  - ATRA：下调PML::RARα表达，促进APL细胞分化、成熟 —— 抗肿瘤促分化治疗的第一次成功实践
  - 砷剂（As₂O₃）：促进凋亡、下调PML::RARα、DNA断裂破坏
- **DIC治疗**：输注单采血小板、新鲜冰冻血浆、纤维蛋白原 +/- 低分子肝素

![[内科-白血病-ATRA机制.webp]]

### 靶向与免疫治疗

- **去DNA甲基化药物**：地西他滨、阿扎胞苷
- **小分子靶向药物**：BCL-2抑制剂（[[维奈托克]]）、FLT3抑制剂、IDH1/2抑制剂
- **酪氨酸激酶抑制剂（TKI）** ：伊马替尼、尼洛替尼、达沙替尼、奥雷巴替尼
- **免疫治疗**：抗CD33单抗、抗CD45单抗、抗CD47单抗、贝林妥欧双抗（CD3-CD19）、ADC（CD22-卡奇霉素）、[[CAR-T细胞治疗]]

### 造血干细胞移植

- **异基因造血干细胞移植（allo-HSCT）** ：目前唯一可能治愈白血病的手段
- **自体外周血干细胞移植（Auto-PBSCT）**
- **供者淋巴细胞输注（DLI）**

![[内科-白血病-移植.webp]]

### 完全缓解（CR）标准

1. **形态学CR**：ANC ＞ 1.0×10⁹/L，PLT ≥ 100×10⁹/L，骨髓原始细胞 ＜ 5%，无髓外残留病灶，无输血依赖
2. **细胞遗传学CR**：恢复正常细胞遗传学
3. **CRi**：骨髓原始细胞＜5%，但血细胞持续减少（ANC ＞ 1.0×10⁹/L 或 PLT ＜ 100×10⁹/L）

### CNS-L的治疗

- **预防**：CR后鞘内注射（MTX + 阿糖胞苷 + 地塞米松）或颅脊椎放疗（尤其ALL及高危AML）
- **治疗**：针对已确诊的CNS-L

## 预后

急性白血病预后取决于：分型（ALL儿童预后较好）、遗传学异常（如t(15;17)的APL预后较好，TP53异常预后差）、年龄、初诊白细胞计数、治疗反应（MRD转阴者预后较好）及是否接受HSCT。
