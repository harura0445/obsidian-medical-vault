# 上腔静脉压迫综合征

## 概述

上腔静脉压迫综合征（superior vena cava syndrome, SVCS）是指由各种原因导致上腔静脉回流受阻，引起头面部、颈部及上肢静脉回流障碍，产生一系列临床表现的综合征。上腔静脉是收集头、颈、上肢、胸壁血液回流入右心房的主要静脉通道，其管壁薄、内压低，易受邻近结构压迫。SVCS 是胸部肿瘤（尤其是[[肺癌]]和[[淋巴瘤]]）常见的并发症，也是**肿瘤急症**之一。

## 病因与发病机制

### 病因

SVCS 的病因分为**恶性**和**良性**两大类，目前以恶性病因为主（约占 90%）。

| 病因分类 | 常见疾病 | 说明 |
|----------|----------|------|
| **恶性肿瘤** | [[肺癌]]（尤右肺中心型/小细胞癌） | 最常见原因，占 70%~80% |
| | [[淋巴瘤]]（霍奇金/非霍奇金） | 占 10%~15% |
| | 纵隔转移性肿瘤（如乳腺癌、睾丸癌等） | 转移至纵隔淋巴结 |
| | 原发性纵隔肿瘤（胸腺瘤、畸胎瘤、生殖细胞瘤等） | 直接压迫上腔静脉 |
| | 气管肿瘤 | 晚期可合并 SVCS |
| **良性疾病** | 纵隔纤维化/慢性纵隔炎（结核性、组织胞浆菌病等） | 慢性肉芽肿性病变 |
| | 上腔静脉血栓形成（中心静脉置管、起搏器电极等） | 医源性因素 |
| | 胸骨后甲状腺肿 | 良性压迫 |
| | 主动脉瘤 | 罕见 |

### 发病机制

上腔静脉位于上纵隔，周围被胸骨、气管、右主支气管、主动脉弓和奇静脉等结构包绕，位置相对固定。当上腔静脉受压迫、浸润或阻塞时：

1. **静脉回流受阻** → 头、颈、上肢及上胸部的静脉压力升高
2. **侧支循环建立** → 奇静脉、胸廓内静脉、胸壁浅静脉、椎静脉丛等代偿扩张
3. **急性/亚急性起病** → 若侧支代偿不足（如奇静脉同时受累），症状迅速加重

> 恶性病因中，肿瘤直接侵犯纵隔、转移的肿大淋巴结压迫上腔静脉、或腔静脉内癌栓阻塞，均可引起静脉回流受阻。

## 临床表现

临床表现的轻重取决于**上腔静脉阻塞的速度、程度**以及**侧支循环的代偿情况**。

### 症状

| 症状 | 特点 |
|------|------|
| 头面部肿胀感 | 晨起加重，抬头/活动后稍缓解 |
| 呼吸困难 | 最常见的症状，可伴喘鸣，活动后加重 |
| 咳嗽 | 刺激性干咳，平卧位加重 |
| 声音嘶哑 | 喉返神经受压所致 |
| 吞咽困难 | 食管受压 |
| 头晕、头痛 | 颅内静脉压升高，严重者可致视物模糊、意识改变 |
| 胸痛 | 纵隔受压或肿瘤侵犯 |

### 体征

| 体征 | 描述 |
|------|------|
| **面部水肿、发绀** | 面部呈暗红色至紫绀色，眼睑水肿明显 |
| **颈部增粗** | 颈部软组织水肿，颈围增加 |
| **颈静脉怒张** | 颈外静脉明显充盈、迂曲 |
| **胸壁静脉曲张** | 前胸壁浅静脉扩张、迂曲，血流方向向下 |
| **上肢水肿** | 双上肢对称性肿胀，以右侧为著 |
| **眼结膜充血** | 球结膜水肿、充血 |
| 呼吸困难 | 严重时可出现端坐呼吸 |

> **查体要点**：嘱病人**举臂**（Pemberton 征）— 双臂上举 1~2 分钟后，若面部充血、水肿加重，伴呼吸困难或头晕，即为阳性，提示上腔静脉受压。

## 辅助检查

### 影像学检查

| 检查方法 | 价值 |
|----------|------|
| **胸部 X 线** | 可发现纵隔增宽、右上纵隔肿块、胸腔积液等，但约 16% 的病人 X 线平片正常 |
| **胸部 CT（增强）** | 首选检查，可明确阻塞部位、范围、侧支循环，以及肿瘤与周围组织的关系 |
| **MRI** | 对碘过敏者替代 CT，可多平面显示血管受累情况 |
| **上腔静脉造影** | 诊断金标准，可精确显示阻塞部位、程度和侧支循环，但为有创检查 |
| **超声** | 可评估上腔静脉内血栓、肿瘤浸润，但对纵隔显示有限 |

### 实验室检查

- **血常规**：可有贫血、白细胞升高（合并感染时）
- **肿瘤标志物**：根据原发肿瘤选择（如 NSE、CYFRA21-1 等）
- **病理活检**：确诊原发病的关键手段（支气管镜、纵隔镜、EBUS-TBNA、胸腔镜等）

## 诊断与鉴别诊断

### 诊断

典型的 SVCS 诊断主要依据**临床表现 + 影像学证据**：

1. **典型临床表现**：面部/上肢水肿 + 颈静脉怒张 + 胸壁静脉曲张
2. **影像学确认**：增强 CT 显示上腔静脉受压、阻塞，侧支循环开放
3. **明确病因**：通过病理活检确定原发疾病（肺癌、淋巴瘤等）

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| 心力衰竭 | 下肢水肿为主、颈静脉怒张伴全身性表现，超声显示心功能异常 |
| 心包疾病（缩窄性心包炎） | Kussmaul 征阳性、奇脉、心包钙化，超声/CT 可鉴别 |
| 上腔静脉血栓形成 | 有中心静脉置管史、起搏器植入史，增强 CT/静脉造影可鉴别 |
| 甲状腺功能减退所致黏液性水肿 | 全身性非凹陷性水肿，伴甲减相关表现 |

## 治疗

### 治疗原则

SVCS 为**肿瘤急症**，治疗原则为：**缓解症状 + 处理原发病**。治疗方案取决于病因、阻塞严重程度和病人全身状况。

### 一般处理

| 措施 | 目的 |
|------|------|
| **半卧位/头高卧位** | 利用重力减轻头部水肿 |
| **吸氧** | 改善呼吸困难 |
| **限制液体、低盐饮食** | 减轻水肿 |
| **利尿剂**（如呋塞米） | 短期减轻水肿（效果有限，不常规推荐） |
| **糖皮质激素**（如地塞米松） | 减轻肿瘤周围水肿和炎症反应，尤其适用于淋巴瘤 |
| **抬高上肢** | 促进静脉回流 |

### 针对病因治疗

#### 恶性肿瘤所致 SVCS

| 原发肿瘤类型 | 推荐治疗 |
|--------------|----------|
| **小细胞肺癌** | 化疗 ± 放疗（SVCS 对化疗敏感） |
| **非小细胞肺癌** | 放疗（姑息性，缓解阻塞症状）；根据基因突变情况考虑靶向治疗 |
| **淋巴瘤** | 化疗 ± 放疗（对化疗高度敏感） |
| **纵隔生殖细胞瘤** | 化疗 ± 放疗 |
| **其他转移性肿瘤** | 根据原发肿瘤病理类型选择治疗方案 |

#### 良性疾病所致 SVCS

- **纵隔纤维化**：糖皮质激素、免疫抑制剂；严重者考虑手术
- **血栓形成**：抗凝治疗（肝素 → 华法林/NOAC）；溶栓治疗
- **胸骨后甲状腺肿**：手术切除

### 介入治疗

对于症状严重、对放化疗不敏感或急需缓解症状者：

| 方法 | 说明 |
|------|------|
| **上腔静脉支架置入术** | 经皮血管内支架置入，可快速缓解症状，有效率达 90% 以上 |
| **球囊扩张成形术** | 适用于良性狭窄 |
| **经导管溶栓/取栓** | 适用于合并血栓形成者 |

### 手术治疗

| 术式 | 适应证 |
|------|--------|
| 上腔静脉旁路转流术 | 良性病变或恶性病变预计生存期较长者 |
| 肿瘤切除 + 上腔静脉重建 | 可根治性切除的恶性肿瘤 |
| 纵隔镜/胸腔镜活检 + 减瘤术 | 明确诊断同时缓解压迫 |

> **注意**：上腔静脉压迫综合征合并喉返神经麻痹或远处转移者，手术为相对禁忌证。

## 并发症

| 并发症 | 说明 |
|--------|------|
| **喉水肿/气道阻塞** | 严重上腔静脉阻塞可致声门水肿，危及生命 |
| **颅内静脉压升高** | 可致脑水肿、视神经乳头水肿、癫痫、意识障碍 |
| **上腔静脉血栓形成** | 血流淤滞导致继发性血栓，加重阻塞 |
| **反复胸腔积液** | 静脉回流障碍致胸膜渗出 |
| **原发肿瘤进展** | 肺癌/淋巴瘤等未控可导致病情恶化 |

## 预后

SVCS 的预后主要取决于**原发肿瘤的性质和分期**：

- **恶性 SVCS**：小细胞肺癌和淋巴瘤所致者，对放化疗敏感，症状缓解快，但原发病总体预后较差；非小细胞肺癌所致者预后相对更差
- **良性 SVCS**：经规范治疗后预后良好，但慢性纵隔纤维化者症状改善较慢
- 支架置入后可快速缓解症状，但需关注再狭窄和支架内血栓形成
