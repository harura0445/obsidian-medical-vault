# 肺结核

> 肺结核是由结核分枝杆菌引起的慢性传染性肺疾病，以肉芽肿性炎和干酪样坏死为病理特征，是全球重大公共卫生问题。

## 概述

肺结核（pulmonary tuberculosis）在21世纪仍然是严重危害人类健康的主要传染病。我国作为结核病高负担国家，2021年结核病发病例数占全球的7.4%。我国2020年发病率已降至47.76/10万，2000年以来发病率下降38.5%，死亡率下降70.1%。

结核分枝杆菌潜伏感染者全球约20亿人（1/3人口）。2021年全球新发结核病约640万例，约160万人死于结核病。全球约新发45万例利福平耐药结核病（RR-TB），治疗成功率仅约60%。

## 病原学

结核病的病原菌为结核分枝杆菌复合群，人肺结核的致病菌90%以上为**结核分枝杆菌**（*Mycobacterium tuberculosis*, MTB）。

| 特性 | 说明 |
|------|------|
| 形态 | 细长、稍弯曲、两端圆形，抗酸染色呈红色（抗酸杆菌） |
| 代谢 | 专性需氧菌，增代时间14\~20小时，培养需2\~8周 |
| 抵抗力 | 对干燥、冷、酸、碱抵抗力强；对紫外线敏感，日光直射2\~7小时可杀灭痰中菌 |
| 菌体成分 | 类脂质（50%\~60%，与坏死、空洞、变态反应有关）、蛋白质（结核菌素主要成分）、多糖类 |

## 传播途径与发病机制

### 传播途径

- **传染源**：痰直接涂片阳性的结核病病人
- **传播途径**：主要通过**呼吸道飞沫传播**，为最重要途径；经消化道和皮肤传播现已罕见
- **传染性影响因素**：病人排菌量、空间气溶胶密度及通风情况、接触密切程度与时间、个体免疫力

### 发病机制

**危险因素**：[[糖尿病]]、HIV感染、酗酒、吸烟、营养不良、COVID-19、硅沉着病、抗TNF-α治疗、透析治疗、免疫抑制剂使用等。

#### 1. 原发感染

首次吸入含MTB的气溶胶后，MTB在肺泡巨噬细胞内外生长繁殖，形成**原发病灶**。原发病灶中的MTB沿引流淋巴管到达肺门淋巴结，引起淋巴结肿大，形成**原发综合征**（原发病灶 + 肿大的气管支气管淋巴结）。

大多数原发感染为良性过程：机体产生细胞免疫使病灶停止繁殖，原发病灶吸收或钙化，淋巴结纤维化/钙化。但少量MTB可长期处于休眠期，成为继发性结核病的来源。

#### 2. 免疫与迟发性变态反应

- **主要免疫机制**：以T细胞为主的细胞免疫（体液免疫不重要）
- **关键细胞**：肺泡巨噬细胞（最早）、CD4+T细胞（核心作用）、CD8+T细胞（直接杀菌）
- **Koch现象**：机体对MTB再感染与初感染表现不同的现象——局部快速红肿溃烂为迟发性变态反应；无播散和淋巴结肿大、较快愈合为免疫力

#### 3. 继发性结核病

发病方式有两种：
- **内源性复发**：潜伏病灶中MTB重新活动（约10%的感染者一生中会发生）
- **外源性重染**：MTB再感染而发病

## 病理学

### 基本病理变化

| 病理类型 | 特点 |
|----------|------|
| 渗出性病变 | 结核病炎症初期或恶化复发时出现，以中性粒细胞浸润为主，后由巨噬细胞/淋巴细胞取代 |
| 增生性病变 | 机体抵抗力较强、病变恢复阶段，形成**结核结节**（由淋巴细胞、上皮样细胞、朗汉斯巨细胞及成纤维细胞组成） |
| 干酪样坏死 | MTB毒力强、菌量多、超敏反应增强时发生，肉眼呈淡黄色、状似奶酪 |

三种病理变化可同时存在，以某一种为主，且可相互转化。

### 病理转归

化学治疗后：早期渗出性病变可完全吸收消失；增生病变或较小干酪样坏死可纤维化、钙化。未经治疗者常发生液化坏死形成空洞，液化物经支气管播散。

## 临床分型

### 按病变部位分类

#### 1. 原发性肺结核

包括原发综合征和胸内淋巴结结核。多见于少年儿童，多有结核病接触史，结核菌素试验多呈强阳性。X线胸片表现为**哑铃形阴影**（原发病灶 + 引流淋巴管炎 + 肿大的肺门淋巴结）。

#### 2. 血行播散性肺结核

| 类型 | 特点 |
|------|------|
| 急性血行播散性肺结核（急性粟粒性肺结核） | 多见于婴幼儿及青少年，起病急、高热、中毒症状重；双肺均匀分布的大小密度一致的粟粒阴影；可伴脑膜刺激征、脉络膜结核结节 |
| 亚急性/慢性血行播散性肺结核 | 起病较缓，症状较轻；双肺中上部分布大小不一、密度不等的弥漫病灶，新鲜渗出与陈旧硬结钙化共存 |

#### 3. 继发性肺结核

成人肺结核最常见类型。

| 亚型 | 特点 |
|------|------|
| 浸润性肺结核 | 最常见亚型，病灶多在肺尖和锁骨下，呈小片状/斑点状阴影，可形成空洞。空洞可分为虫蚀样空洞、薄壁空洞、张力性空洞、"净化空洞"、"开放菌阴综合征" |
| 干酪性肺炎 | 免疫力低下、大量MTB感染时发生。大叶性呈磨玻璃状阴影、虫蚀样空洞，痰菌阳性 |
| 结核球 | 干酪样病变被纤维膜包裹形成，直径2\~4cm（多<3cm），80%以上有卫星灶 |
| 慢性纤维空洞性肺结核 | 病程长，反复恶化，双侧/单侧纤维厚壁空洞和广泛纤维增生，肺组织破坏重，胸廓塌陷，代偿性肺气肿 |

#### 4. 气管、支气管结核

发生在气管、支气管黏膜及黏膜下层。表现为管壁不规则增厚、管腔狭窄或阻塞，远端可出现肺不张、肺实变、[[支气管扩张]]等。

#### 5. 结核性胸膜炎

含干性胸膜炎、渗出性胸膜炎和结核性脓胸。

### 按病原学检查结果分类

- **病原学阳性**：痰涂片阳性、培养阳性或分子生物学阳性
- **病原学阴性**：上述检查均阴性
- **病原学未查**

### 按耐药状况分类

| 类型 | 定义 |
|------|------|
| 敏感肺结核 | 对一线抗结核药物敏感 |
| 单耐药 | 对一种一线药物耐药 |
| 多耐药 | 对≥2种一线药物耐药（不同时耐INH和RFP） |
| 耐多药（MDR-TB） | 至少耐异烟肼和利福平 |
| 广泛耐药 | MDR基础上还耐氟喹诺酮类和≥1种二线注射剂 |
| 利福平耐药（RR-TB） | 对利福平耐药 |

### 按既往治疗史分类

| 分类 | 定义 |
|------|------|
| 初治 | 未开始抗结核治疗；正进行标准化疗方案未满疗程；不规则化疗<1个月 |
| 复治 | 初治失败；规律用药满疗程后痰菌复阳；不合理/不规律抗结核治疗≥1个月 |

### 肺结核的记录方式

按分类、病变部位、范围、痰菌情况、化疗史顺序书写。示例：继发性肺结核，双上肺，涂（+），复治。

## 临床表现

### 症状

#### 呼吸系统症状

| 症状 | 特点 |
|------|------|
| 咳嗽、咳痰 | ≥2周为常见可疑症状，干咳或少量黏液痰；空洞形成时痰量增多；合并支气管结核为刺激性咳嗽 |
| [[咯血]] | 约1/3病人咯血，多为少量，少数为大咯血 |
| 胸痛 | 结核病灶累及胸膜时出现胸膜性胸痛，随呼吸和咳嗽加重 |
| [[呼吸困难]] | 多见于干酪样肺炎和大量胸腔积液病人 |

#### 全身中毒症状

| 症状 | 特点 |
|------|------|
| [[发热]] | 最常见症状，多为**长期午后潮热**（下午或傍晚升高，翌晨降至正常） |
| 盗汗 | 夜间入睡后出汗 |
| 其他 | 倦怠乏力、食欲减退、体重减轻；育龄期女性可有月经不调 |

### 体征

体征取决于病变性质和范围：
- 病变范围小者：可无任何体征
- 渗出性病变范围大或干酪样坏死：肺实变体征（触觉语颤增强、叩诊浊音、支气管呼吸音）
- 结核性胸膜炎：[[胸腔积液]]体征（气管向健侧移位、患侧胸廓饱满、触觉语颤减弱、叩诊实音、呼吸音消失）
- 支气管结核：局限性哮鸣音
- 结核性风湿症：少数青少年女性出现类似风湿热表现，四肢大关节受累，结节性红斑或环形红斑

## 辅助检查

### 影像学检查

| 检查方法 | 作用 |
|----------|------|
| 胸部X线 | 首选常规方法，发现早期病变，判断定位、形态、活动性、空洞 |
| 胸部CT | 提高分辨率，早期发现粟粒阴影和微小病变，清晰显示各型特点，用于鉴别诊断和引导穿刺 |

肺结核影像特点：病变多发生在上叶尖后段、下叶背段和后基底段，呈**多态性**（浸润、增殖、干酪、纤维钙化可同时存在）。

### 痰结核分枝杆菌检查

确诊肺结核的主要方法，也是制订化疗方案和考核疗效的主要依据。

| 方法 | 特点 |
|------|------|
| 痰涂片（齐-尼染色/LED荧光法） | 简便快速但欠敏感，需≥5,000\~10,000个菌/ml方可阳性；不能区分MTB与非结核分枝杆菌 |
| 培养法（改良罗氏法/BACTEC-TB 960） | 诊断"金标准"，灵敏度高于涂片；传统法需2\~8周，BACTEC法约10日 |
| 分子生物学检查（Xpert MTB/RIF、LAMP等） | 敏感性高、特异性强、快速，可同时检测利福平耐药，可作为病原学阳性的诊断依据 |
| 药物敏感性测定 | 初治失败、复发及复治病人应进行；比例法为"金标准" |

**注意**：初诊病人至少送3份痰标本（清晨痰、夜间痰、即时痰）；复诊病人每次送2份。

### 免疫学检查

| 方法 | 特点 |
|------|------|
| 结核菌素试验（PPD） | 广泛用于检出MTB感染；对儿童/少年/青年有参考意义；不能区分自然感染与卡介苗接种；免疫抑制者可呈阴性 |
| γ-干扰素释放试验（IGRAs） | 可区分MTB自然感染与卡介苗接种和大部分非结核分枝杆菌感染，特异性显著高于PPD |

### 支气管镜检查

用于支气管结核和淋巴结支气管瘘的诊断，可行组织病理学检查和MTB培养，也可获取灌洗液标本或经支气管肺活检。

## 诊断

### 诊断程序

1. **可疑症状筛选**：咳嗽咳痰≥2周和咯血，午后低热、乏力、盗汗
2. **是否为肺结核**：胸部影像学异常者须确定性质（病原学、病理学为确诊依据）。难以确定时可抗感染治疗10\~14天后复查
3. **有无活动性**：活动性病变影像学表现为边缘模糊斑片状阴影、中心溶解或空洞、播散病灶
4. **是否排菌**：确定传染源的唯一方法
5. **是否耐药**：药敏试验确定
6. **明确初/复治**：两者治疗方案不同

### 病原学检测阴性肺结核的诊断

需排除其他非结核性肺部疾病，同时符合：
1. 典型肺结核胸部影像学表现
2. 典型肺结核临床表现
3. 任一免疫学检查阳性（PPD中度以上阳性/IGRA阳性/MTB抗体阳性）
4. 肺外组织病理证实为结核病变（肺组织结核须同时具备1 + 2\~4中任一项）

### 鉴别诊断

| 需鉴别的肺结核类型 | 需鉴别的疾病 |
|-------------------|-------------|
| 浸润性肺结核 | 细菌性[[肺炎]]、肺真菌病、肺寄生虫病 |
| 肺结核球 | 周围型肺癌、炎性假瘤、肺错构瘤、肺隔离症 |
| 血行播散性肺结核 | 支气管肺泡癌、肺含铁血黄素沉着症、弥漫性间质性肺疾病 |
| 支气管淋巴结结核 | 中央型肺癌、淋巴瘤、结节病 |
| 肺结核空洞 | 癌性空洞（壁不规则、内壁结节、无卫星灶、增长快）、肺囊肿（无卫星灶、多年无变化）、囊性支气管扩张 |
| 非结核分枝杆菌（NTM）肺病 | 临床表现酷似肺结核，需培养和菌种鉴定鉴别 |

## 治疗

### 化学治疗原则

**早期、规律、全程、适量、联合**。分强化期和巩固期两个阶段。

### 化学治疗的主要作用

| 作用 | 说明 |
|------|------|
| 杀菌 | 迅速杀灭A菌群，使病人由传染性转为非传染性，痰菌迅速阴转 |
| 防止耐药菌产生 | 联合用药通过交叉杀菌防止获得性耐药变异菌 |
| 灭菌 | 彻底杀灭半静止或代谢缓慢的B、C菌群（"顽固菌"），防止复发 |

### 生物学机制

结核分枝杆菌按代谢状态分为四个菌群：

| 菌群 | 代谢状态 | 位置 | 药物敏感性 |
|------|----------|------|-----------|
| A菌群 | 快速繁殖，数量最大 | 巨噬细胞外、空洞干酪液化部分 | INH > SM > RFP > EMB |
| B菌群 | 半静止 | 巨噬细胞内酸性环境、空洞壁坏死组织 | PZA > RFP > INH |
| C菌群 | 半静止，间歇短暂繁殖 | — | RFP > INH |
| D菌群 | 休眠，不繁殖 | — | 药物无作用 |

- **早期杀菌作用**：INH和RFP在治疗48小时内迅速杀菌
- **间歇化疗基础**：MTB接触药物后产生延缓生长期（INH 6\~9日，RFP 2\~3日）
- **顿服优势**：每日剂量一次顿服产生的高峰血药浓度是分次服用的3倍

### 常用抗结核药物

| 药物（缩写） | 成人每日剂量 | 主要作用 | 主要不良反应 |
|-------------|-------------|---------|-------------|
| 异烟肼（INH, H） | 0.3g | 早期杀菌力最强，对巨噬细胞内外的MTB均有杀菌作用 | 周围神经炎（用维生素B6预防），偶有肝功能损害 |
| 利福平（RFP, R） | 0.45\~0.6g | 对巨噬细胞内外的MTB快速杀菌，特别是C菌群有独特杀菌作用 | 肝功能损害、过敏反应；排泄物呈橘红色 |
| 吡嗪酰胺（PZA, Z） | 1.5\~2.0g | 杀灭巨噬细胞内酸性环境中的B菌群，仅强化期使用2个月 | 高尿酸血症、肝损害、关节痛 |
| 乙胺丁醇（EMB, E） | 0.75\~1.0g | 抑菌 | 视神经炎（儿童不使用） |
| 链霉素（SM, S） | 0.75g | 对巨噬细胞外碱性环境中的MTB杀菌 | 耳毒性、前庭功能损害、肾毒性 |

### 标准化学治疗方案

#### 初治活动性肺结核

**标准化方案：2HRZE/4HR**

| 阶段 | 时间 | 方案 |
|------|------|------|
| 强化期 | 2个月 | 异烟肼 + 利福平 + 吡嗪酰胺 + 乙胺丁醇，顿服 |
| 巩固期 | 4个月 | 异烟肼 + 利福平，顿服 |

也可采用间歇方案：2H~3~R~3~Z~3~E~3~/4H~3~R~3~（隔日一次或每周3次）。

**注意事项**：
- 2个月末痰菌仍阳性：延长强化期1个月（3HRZE/4HR）
- 5个月末或疗程结束时痰菌仍阳性：初治失败
- 初治失败者用复治方案治疗
- WHO推荐：≥12岁药物敏感肺结核可接受4个月短程方案2HPMZ/2HPM（H:异烟肼，P:利福喷丁，M:莫西沙星，Z:吡嗪酰胺）

#### 复治肺结核

2020年规范不再规定标准复治方案，应对所有复治病人进行**药物敏感性试验**，根据耐药结果制订个体化方案。利福平敏感者按初始标准化疗方案治疗。

### MDR-TB / RR-TB 的治疗

| 方案类型 | 疗程 | 核心内容 |
|---------|------|---------|
| 长程方案 | 18\~20个月 | 至少4种有效药物，包括所有A组+至少1种B组 |
| 短程方案 | 9\~12个月 | 标准化方案（氟喹诺酮类和二线注射剂敏感者为适用人群） |

**A组（首选药物）**：左氧氟沙星/莫西沙星、贝达喹啉、利奈唑胺
**B组（次选药物）**：氯法齐明、环丝氨酸
**C组（备选药物）**：乙胺丁醇、德拉马尼、吡嗪酰胺、阿米卡星等

### 咯血处理

| 咯血量 | 处理 |
|--------|------|
| 少量咯血 | 安慰病人、消除紧张、卧床休息为主；可用氨基己酸、氨甲苯酸、酚磺乙胺等止血 |
| 大咯血 | **垂体后叶素**收缩小动脉，减少肺循环血量——高血压、冠心病、心力衰竭和孕妇**禁用**；注意低钠血症、低钾血症等不良反应 |
| 大咯血药物治疗无效 | 支气管动脉栓塞术 |
| 咯血窒息 | 为大咯血最严重并发症。病人突然停止咯血，出现呼吸急促、面色苍白、口唇发绀、烦躁不安时，应及时抢救 |

### 其他治疗

- **糖皮质激素**：仅用于结核毒性症状严重者，须在有效抗结核药物治疗下使用。泼尼松20mg/d，1\~2周后每周递减5mg，用药4\~8周
- **外科手术**：适应证为合理化疗后无效、MDR厚壁空洞、大块干酪灶、结核性脓胸、支气管胸膜瘘和大咯血保守治疗无效者

## 结核病控制策略

| 措施 | 说明 |
|------|------|
| **全程督导化疗（DOTS）** | 每次用药在医务人员或培训家庭督导员监督下进行，提高依从性和治愈率，减少MDR发生 |
| 病例报告和转诊 | 肺结核属**乙类传染病**，须及时准确报告 |
| 病例登记管理 | 长期随访，掌握从发病到治愈的全过程 |
| 卡介苗接种 | 对预防成人肺结核效果差，但对预防儿童结核性脑膜炎和粟粒性肺结核效果较好 |
| 预防性化疗 | 用于结核潜伏感染者中高风险人群（见下表） |

### 预防性治疗方案

| 方案 | 药物 | 用法 | 疗程 |
|------|------|------|------|
| 单用异烟肼 | INH 300mg/d | 每日1次 | 6\~9个月 |
| INH+RFT联合间歇 | INH 500\~600mg + RFT 450\~600mg | 每周2次 | 3个月 |
| INH+RFP联合 | INH 300mg + RFP 450\~600mg | 每日1次 | 3个月 |
| 单用利福平 | RFP 450\~600mg | 每日1次 | 4个月 |

## 结核病与相关疾病

| 合并疾病 | 注意事项 |
|---------|---------|
| HIV/AIDS | 结核病是HIV/AIDS最常见的机会感染，两者相互恶化，死亡率极高 |
| 肝炎 | INH、RFP、PZA均有潜在肝毒性，用药前和用药中须监测肝功能 |
| [[糖尿病]] | 两病相互影响，须在控制糖尿病基础上行抗结核治疗 |
| 硅沉着病 | Ⅲ期硅沉着病合并结核比例>50%，强调多次查痰和培养法 |
| COVID-19 | 结核病人感染COVID-19死亡风险更高 |

## 预后

规范完成全程化疗的初治病人治愈率高（95%以上）。耐药结核病治疗成功率较低（全球约60%）。未经治疗的活动性结核病死亡率较高。

## 预防

- 控制传染源（痰菌阳性者隔离治疗）
- 切断传播途径（通风换气、减少空间气溶胶密度）
- 保护易感人群（卡介苗接种、结核潜伏感染者预防性化疗）
