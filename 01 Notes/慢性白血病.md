# 慢性白血病（Chronic Leukemia, CL）

慢性白血病起病隐匿、发展缓慢，自然病程数年，骨髓和外周血以较成熟阶段的细胞占多数。主要包括**慢性髓系白血病（CML）**和**慢性淋巴细胞白血病（CLL）**两大类型。

---

## 慢性髓系白血病（CML）

起源于多能造血干细胞的恶性骨髓增殖性肿瘤（MPN），细胞分化阻滞在中、晚幼粒阶段。绝大多数CML血细胞中有异常的**Ph染色体**（BCR::ABL1融合）。

![[内科-白血病-Ph染色体.webp]]

### 流行病学

- 发病率 0.39~0.99/10万，中位发病年龄 45~50岁，男性多于女性
- 起病隐匿，最突出特征：**脾大（巨脾）**

### 分期（2022 ICC分类）

| 分期 | 关键指标 |
|------|---------|
| **慢性期（CP）** | 外周血或骨髓原始细胞＜10%，未达AP/BP标准 |
| **加速期（AP）** | 原始细胞10-19%，嗜碱性粒细胞≥20%，出现额外染色体异常（+Ph、+8、i(17q)、+19、3q26.2重排、复杂核型） |
| **急变期（BP）** | 原始细胞≥20%，骨髓活检成片原始细胞浸润，髓外原始细胞浸润；急淋变时淋巴母细胞＞5% |

### 诊断依据

- 不明原因持续白细胞增高、脾大
- 特征性血象、骨髓象：粒系增生显著，中晚幼粒细胞为主，伴嗜酸性粒细胞、嗜碱性粒细胞增多
- **NAP（-）**
- **Ph染色体（+）和/或 BCR::ABL 融合（+）**

### 鉴别诊断

1. **其他骨髓增殖性肿瘤（MPD）**：真红、原发性血小板增多症、原发性骨髓纤维化
2. **其他原因引起的脾肿大**：酒精性肝病、[[肝硬化|血吸虫性肝病]]、肝炎后肝硬化、脾功能亢进、慢性疟疾等，有原发病表现，Ph染色体/BCR::ABL（-）
3. **类白血病反应**：见于肿瘤或重症感染，WBC＜10万/ul，中幼粒＜15%，中性粒细胞有中毒颗粒及空泡，NAP强阳性，Ph染色体/BCR::ABL（-）

### 治疗

- **靶向治疗（首选）** ：TKI —— 伊马替尼、尼洛替尼、达沙替尼、氟马替尼、博纳替尼、奥瑞巴替尼。**作用机制**：特异性阻断ATP在abl激酶上的结合位点，抑制酪氨酸残基磷酸化
- **传统治疗**：羟基脲（降白细胞）、干扰素-α（不适合TKI者及妊娠期患者）
- **联合化疗**：Ara-C、高三尖杉酯碱（HHT）、砷剂；多用于加速期/急变期
- **allo-HSCT**：目前唯一能治愈CML的方法
- 加速期/急变期：TKI基础上根据转变类型联合化疗→CP，序贯allo-HSCT

## 慢性淋巴细胞白血病（CLL）

类似成熟B淋巴细胞克隆性增生，慢性、惰性病程。

### 流行病学

- 西方最多见的白血病类型（占25-35%）
- 欧美发病率4-5/10万，东亚为欧美的1/10
- 多见于50岁以上，男女比 1.2~1.7:1

### 临床表现

- 乏力，[[贫血]]，出血
- 免疫异常：伴发[[自身免疫性溶血性贫血]]（AIHA）、ITP、纯红再障（PRCA）
- 常有反复感染
- [[淋巴结]]、肝、脾肿大
- **Richter综合征**（转化为弥漫性大B细胞淋巴瘤）

### 诊断标准（中国2022版CLL/SLL指南）

1. 外周血单克隆B淋巴细胞计数 ≥ **5×10⁹/L**
2. 外周血涂片：成熟小淋巴细胞显著增多，胞质少、核致密、核仁不明显，易见**涂抹细胞**；幼稚淋巴细胞 ≤ 55%
3. 典型免疫表型：**CD19（+）、CD5（+）、CD23（+）、CD200（+）**，sIg、CD20及CD79b弱表达，限制性表达κ或λ轻链（κ:λ > 3:1 或 < 0.3:1）

![[内科-白血病-CLL实验室.webp]]

### 鉴别诊断

- **反应性淋巴细胞增多症**：病毒感染，淋巴细胞多克隆性增殖，可见异型淋巴细胞
- **单克隆B淋巴细胞增多症（MBL）** ：无症状，B淋巴细胞＜5×10⁹/L，无肝脾淋巴结肿大
- **其他B淋巴细胞增殖性肿瘤（B-PLCD）**

### 临床分期

- **Rai分期**（0-Ⅳ）
- **Binet分期**（A-C）

### CLL国际预后指数（CLL-IPI）

| 参数 | 不良预后因素 | 积分 |
|------|------------|:----:|
| TP53异常 | 缺失或突变 | 4 |
| IgHV突变状态 | 未突变 | 2 |
| β₂微球蛋白 | ＞3.5mg/L | 2 |
| 临床分期 | Rai Ⅰ-Ⅳ或Binet B-C | 1 |
| 年龄 | ＞65岁 | 1 |

| 积分 | 危险分层 | 5年生存率 |
|:----:|:--------:|:---------:|
| 0～1 | 低危 | 93.2% |
| 2～3 | 中危 | 79.4% |
| 4～6 | 高危 | 63.6% |
| 7～10 | 极高危 | 23.3% |

### 治疗指征（符合任何1项即可启动）

- 进行性骨髓衰竭（Hb＜100g/L 和/或 PLT＜100×10⁹/L）
- 巨脾（左肋缘下＞6cm）或进行性/有症状的脾大
- 巨块型淋巴结肿大（最长直径＞10cm）
- 初始淋巴细胞≥30×10⁹/L，进行性增多（2月内增多50%或LDT＜6个月）
- 自身免疫性溶血性贫血和/或血小板减少对皮质类固醇或其他治疗反应不佳
- 有症状的结外病灶
- 疾病相关症状：6个月内体重下降≥10%、疲乏（ECOG≥2）、持续发热＞38.0℃＞2周、夜间盗汗＞1个月

### 治疗

- **靶向治疗**：BTK抑制剂（伊布替尼、泽布替尼、奥布替尼）、BCL-2抑制剂（维奈克拉）
- **化学免疫治疗**：利妥昔单抗 + FC方案（氟达拉滨 + 环磷酰胺）
- **传统化疗**：苯丁酸氮芥（瘤可宁）、氟达拉滨
- **allo-HSCT**：高危（TP53、IGHV未突变）、难治/复发年轻患者的二线治疗，目前仍是唯一治愈手段
