# 原发性肾小球疾病

> 复旦内科学 课程笔记 | 2026/4/20

## 概述

**肾小球疾病** 是指病变主要累及双侧肾小球的疾病，分为**原发性**、**继发性**和**遗传性**三大类。

- **原发性肾小球疾病**：病因多不明，肾小球为唯一或主要受累器官
- **继发性肾小球疾病**：全身性疾病（如 SLE、[[继发性肾病|糖尿病]]、乙肝等）引起的肾小球损害
- **遗传性肾小球疾病**：Alport 综合征、Fabry 病等

临床表现以 [[血尿]]、[[蛋白质代谢功能检测|蛋白尿]]、[[水肿]]、[[高血压]] 和不同程度 [[肾小球功能检测|肾功能损害]] 为主要特征。

### 临床评估指标

| 指标 | 意义 |
|------|------|
| [[肾小球的滤过功能|GFR]]（肾小球滤过率） | 评估肾功能分期 |
| CGA 分类 | 病因（Cause）- [[肾清除率测定及功能评价|GFR]]- [[蛋白质代谢功能检测|白蛋白尿]]（Albuminuria） |

### 发病机制

免疫介导是主要原因，涉及三种机制：

![[04 Attachments/原发性肾小球疾病-循环免疫复合物沉积.webp]]

1. **循环免疫复合物沉积**：外源性抗原（如链球菌）→ 抗体 → 循环免疫复合物 → 沉积于系膜区和/或内皮下
2. **原位免疫复合物形成**：抗原先植入肾小球 → 抗体原位结合 → 主要位于 GBM 上皮侧
3. **自身抗体**：如抗 GBM 抗体、[[ANCA]] 等

![[04 Attachments/原发性肾小球疾病-电子致密物沉积部位.webp]]

电子致密物可沉积于上皮下、基底膜内、内皮下或系膜区，不同沉积部位对应不同病理类型。

![[04 Attachments/原发性肾小球疾病-滤过屏障.webp]]

肾小球滤过屏障由**分子屏障**和**电荷屏障**组成，损伤后导致蛋白尿。

## 病理分类（WHO 1995）

原发性肾小球疾病的病理类型：

### 1. 轻微肾小球病变（Minor Glomerular Lesion）
- **微小病变肾病（Minimal Change Disease, MCD）**
- 光镜下肾小球基本正常，电镜下见足细胞足突融合
- 儿童 [[肾病综合征]] 最常见病因

### 2. 局灶节段性病变
- **局灶节段性肾小球硬化（Focal Segmental Glomerulosclerosis, FSGS）**
- 部分肾小球（局灶）及肾小球的部分毛细血管袢（节段）发生硬化

### 3. 弥漫性肾小球肾炎（Diffuse Glomerulonephritis）

#### （1）膜性肾病（Membranous Nephropathy, MN）
- 肾小球基底膜（GBM）弥漫性增厚
- 免疫复合物在上皮下沉积

#### （2）增生性肾小球肾炎（Proliferative GN）
- **系膜增生性肾小球肾炎**（Mesangial Proliferative GN）
- **毛细血管内增生性肾小球肾炎**（Endocapillary Proliferative GN）— 如急性链球菌感染后肾炎
- **系膜毛细血管性肾小球肾炎**（Mesangial Capillary GN）/ **膜增生性肾小球肾炎（MPGN）**
  - 包括致密物沉积病（Dense Deposit Disease）
- **新月体性肾小球肾炎**（Crescentic GN）— 即急进性肾小球肾炎（RPGN）

#### （3）硬化性肾小球肾炎（Sclerosing GN）

### 4. 未分类肾小球肾炎（Unclassified GN）

## 肾小球疾病的临床表现

肾小球疾病可表现为以下临床综合征，同一病理类型可呈现不同临床表现，不同病理类型也可呈现相同临床综合征。

### 肾炎综合征（Nephritic Syndrome）
- **经典三联征**：[[血尿]]、[[水肿]]、[[高血压]]
- 伴程度不等的 [[蛋白质代谢功能检测|蛋白尿]] 和肾功能损害
- 代表疾病：急性链球菌感染后肾炎、IgA 肾病

### 肾病综合征（Nephrotic Syndrome）
- **大量蛋白尿**（>3.5g/24h）
- **低白蛋白血症**（<30g/L）
- **高度[[水肿]]**
- **[[高脂血症]]**
- 代表疾病：MCD、膜性肾病、FSGS、MPGN

### 无症状性尿检异常
- 无症状 [[血尿]] 和/或 [[蛋白质代谢功能检测|蛋白尿]]
- 常见于 IgA 肾病早期

### 急进性肾炎综合征
- 肾功能在数周至数月内进行性恶化
- 常伴少尿或无尿

### 慢性肾炎综合征
- 缓慢进展，最终致 [[肾小球功能检测|慢性肾衰竭]]

## 急性肾小球肾炎（Acute Glomerulonephritis）

最常见为 **急性链球菌感染后肾小球肾炎（Poststreptococcal Glomerulonephritis, PSGN）**

### 病因
- **A 族 β-溶血性链球菌**（Group A β-hemolytic Streptococcus）感染
- 常见于上呼吸道感染（咽炎）或皮肤感染（脓疱疮）后 1-3 周

### 发病机制
- 链球菌抗原成分激活免疫反应
- **免疫复合物沉积**于肾小球（CIC + C3 沉积）
- 激活补体系统（C5b-9 等）

### 病理

![[04 Attachments/原发性肾小球疾病-PSGN病理三联.webp]]

- **光镜**：毛细血管内增生性肾小球肾炎（Endocapillary Proliferative GN）
  - 内皮细胞和系膜细胞增生
  - 中性粒细胞浸润
  - 驼峰样沉积物（Hump）
- **免疫荧光**：IgG + C3 沿 GBM 颗粒状沉积（"满天星"样）
- **电镜**：上皮下电子致密物沉积（驼峰）

### 临床表现
- 发病前 1-3 周有链球菌感染史
- **[[血尿]]**（几乎 100%，部分为肉眼血尿）
- **[[水肿]]**（90%，首先出现于眼睑）
- **[[高血压]]**（75%）
- **一过性肾功能减退**
- 儿童多见，预后良好（**>95% 可完全恢复**）

### 实验室检查
- **ASO 升高**（抗链球菌溶血素 O）
- **补体 C3 下降**（起病 8 周内恢复正常）
- C5b-9 升高

### 诊断要点
1. 链球菌感染后 1-3 周发病
2. [[血尿]] + [[水肿]] + [[高血压]]
3. C3 下降、ASO 升高
4. 8 周内 C3 恢复

> 鉴别诊断：C3 持续不恢复应怀疑其他肾小球疾病（如 MPGN、[[继发性肾病|狼疮性肾炎]]）

### 治疗
- **以对症支持治疗为主**
  - 休息、限盐、[[利尿药|利尿]]、降压
- 抗生素：清除感染灶（不是针对肾小球病变）
- **无需使用 [[糖皮质激素类药物|激素]] 或免疫抑制剂**
- **80% 可自行恢复**，约 15% 遗留少量蛋白尿

## 急进性肾小球肾炎（Rapidly Progressive Glomerulonephritis, RPGN）

也称 **新月体性肾小球肾炎（Crescentic GN）**

### 病理
- **新月体（Crescent）形成** >50% 肾小球
- 新月体由增生的壁层上皮细胞和巨噬细胞组成
- 压迫毛细血管襻，导致 GFR 快速下降

### 分型（基于免疫病理）

![[04 Attachments/原发性肾小球疾病-RPGN免疫分型.webp]]

| 分型 | GBM（抗 GBM 抗体） | ANCA | 免疫荧光 | 代表疾病 |
|------|:---:|:----:|:--------:|---------|
| **I 型** | + | - | IgG 线样沉积 | 抗 GBM 病（Goodpasture 综合征） |
| **II 型** | - | - | 免疫复合物颗粒状沉积 | 免疫复合物介导（感染后、SLE、IgA 等） |
| **III 型** | - | + | 寡免疫（少量或无沉积） | [[ANCA]] 相关性血管炎（MPA、GPA 等） |
| **IV 型** | + | + | 混合型 | 双阳性 |
| **V 型** | - | - | 寡免疫 | 特发性 |

### 临床表现
- **急性肾炎综合征 + 进行性肾功能恶化**
- 可在数周至数月内进展至终末期肾病（ESRD）
- **少尿/无尿**、[[水肿]]、[[高血压]]
- **>50% 新月体** 预后差
- **6 个月内不经治疗 90% 进入 ESRD**
- **50% 需长期 [[透析]]**

### 治疗
- **强化免疫抑制治疗**：**[[糖皮质激素类药物|糖皮质激素]]** + **[[环磷酰胺]]（CTX）**
- **血浆置换（Plasma Exchange）**：尤其 I 型（抗 GBM）和 ANCA 阳性
- [[利妥昔单抗]]（Rituximab）用于 ANCA 相关血管炎
- 维持治疗：低剂量激素 + 免疫抑制剂
- 支持治疗：[[透析]]

## IgA 肾病（IgA Nephropathy）

又称 **Berger 病**，**全球最常见原发性肾小球肾炎**

### 发病机制
- **IgA1 分子**（特别是铰链区半乳糖缺乏的 IgA1）
- 半乳糖缺乏的 IgA1 → 抗糖抗体识别 → 形成免疫复合物
- **系膜区 IgA 沉积**，伴 C3 沉积
- 遗传因素和环境因素（如上呼吸道感染）共同参与

### 病理特征

![[04 Attachments/原发性肾小球疾病-IgA肾病病理.webp]]

- **免疫荧光**：系膜区 **IgA** 为主（伴 C3）的颗粒状沉积
- **光镜**：系膜细胞增生 + 系膜基质增宽
- 变异较大，从轻微病变到新月体形成均可出现

### 牛津分型（MEST-C 评分）

| 指标 | 含义 |
|:----:|------|
| **M**（系膜增生） | M0 ≤ 50%，M1 > 50% |
| **E**（内皮增生） | E0 无，E1 有 |
| **S**（节段硬化） | S0 无，S1 有 |
| **T**（肾小管萎缩/间质纤维化） | T0 0-25%，T1 25-50%，T2 > 50% |
| **C**（新月体） | C0 无，C1 < 25%，C2 ≥ 25% |

### 临床表现
- **[[血尿]]**：感染后发作性肉眼血尿（上呼吸道感染同步或 1-2 天内出现）
- **[[蛋白质代谢功能检测|蛋白尿]]**：程度不一（从微量到肾病范围）
- **[[高血压]]**
- 10-20% 在 10 年内进展至 ESRD

### 诊断
- 肾活检是确诊金标准
- 排除：过敏性紫癜、SLE、乙肝相关性肾炎、肝硬化继发 IgA 沉积

### 治疗

#### 基础支持治疗
- 严格 **[[高血压|血压控制]]**（<130/80 mmHg）
- **[[ACEI]]/[[ARB]]**：降低蛋白尿、保护肾功能
- **[[SGLT2抑制剂]]**：近年证实有效（DAPA-CKD 等研究）
- 蛋白尿 >0.5g/d 时积极干预
- 生活方式：低盐饮食、控制体重、避免肾毒性药物

#### 免疫抑制治疗
- **仅用于高危患者**（蛋白尿 >1g/d 经足量支持治疗 3-6 月后仍不改善）
- [[糖皮质激素类药物|糖皮质激素]]
- [[霉酚酸酯]]（MMF）/ [[环磷酰胺]]
- 羟氯喹

### 预后
- 约 30-40% 在 20 年内进入 ESRD
- 不良预后因素：[[高血压]]、大量蛋白尿、肾功能受损、牛津分型 T2

## 肾病综合征（Nephrotic Syndrome）

### 定义
- **大量蛋白尿**：>3.5g/24h
- **低白蛋白血症**：<30g/L
- **高度[[水肿]]**
- **[[高脂血症]]**（总胆固醇、LDL、HDL 升高）

> 前三项为必备条件

### 常见病理类型

| 病理类型 | 好发人群 | 特点 |
|---------|---------|------|
| **微小病变（MCD）** | 儿童 | 高度选择性蛋白尿，[[糖皮质激素类药物|激素]] 敏感 |
| **膜性肾病（MN）** | 中老年 | 非选择性蛋白尿，易血栓 |
| **FSGS** | 青中年 | 部分激素抵抗 |
| **MPGN** | 青少年 | 持续低补体，预后较差 |
| **系膜增生性 GN** | 不定 | 轻症预后好 |

### 并发症
1. **感染**：免疫功能低下（IgG 丢失、补体下降、T 细胞功能异常）
2. **血栓/栓塞**：抗凝血酶 III 丢失，[[高脂血症]]，血液浓缩
   - 膜性肾病最易发生
3. **急性肾损伤（AKI）**
4. **脂代谢紊乱**

### 治疗

#### 一般治疗
- **低盐饮食**（<3g/d）
- **优质蛋白饮食**（0.8-1.0g/kg/d）— 避免过度高蛋白饮食加重蛋白尿
- **控制[[高血压|血压]]**：[[ACEI]]/[[ARB]] 一线
- **[[利尿药|利尿]]消肿**
- **抗凝预防**：白蛋白 <20g/L 时考虑抗凝

#### 免疫抑制治疗——**按病理类型选择**

**MCD：**
- 儿童：**泼尼松** 足量 4-6 周 → 逐渐减量
- 成人：[[糖皮质激素类药物|激素]] + 必要时 CTX/CNI

**膜性肾病：**
- **[[利妥昔单抗]]（Rituximab）**：抗 CD20 单抗，清除 B 细胞
- **[[钙调神经磷酸酶抑制剂]]（CNI）**：环孢素、他克莫司
- **[[糖皮质激素类药物|糖皮质激素]] + [[环磷酰胺|CTX]]**（改良 Ponticelli 方案）
- 低危可保守治疗

**FSGS：**
- 激素疗程长（16 周），部分抵抗
- CNI 或 [[霉酚酸酯|MMF]] 用于激素抵抗型

**MPGN：**
- 治疗原发病（如感染、SLE）
- 补体介导型：**依库珠单抗（Eculizumab）** 抗 C5

## 膜性肾病（Membranous Nephropathy, MN）

中老年 [[肾病综合征]] 最常见病因（约 30%）

### 病因分类
- **原发性（特发性）**：约 75%，**抗 PLA2R 抗体** 阳性
- **继发性**：SLE（[[继发性肾病|狼疮肾炎]] V 型）、乙肝、药物（金制剂、[[NSAIDs]]）、肿瘤

### 病理
- **光镜**：GBM 弥漫性增厚，钉突（Spike）形成
- **PASM** 银染可见 **GBM 钉突**
- **免疫荧光**：**IgG + C3** 沿 GBM 颗粒状沉积
- **电镜**：上皮下电子致密物沉积（I-IV 期）

### 临床表现
- 起病隐匿
- 非选择性蛋白尿
- 约 30% 可自发缓解
- 血栓栓塞并发症突出（肾静脉血栓）

### 诊断
- **抗 PLA2R 抗体**：特异性 >90%，与疾病活动相关
- 肾活检确诊

### 治疗
- **支持治疗**：[[ACEI]]/[[ARB]]、[[SGLT2抑制剂|SGLT2i]]、控制[[高血压|血压]]
- **免疫抑制**：[[利妥昔单抗|Rituximab]]（一线）、CNI、[[糖皮质激素类药物|激素]] + [[环磷酰胺|CTX]]

---

## 膜增生性肾小球肾炎（MPGN）

**病理模式**：系膜细胞增生 + 毛细血管袢增厚（双轨征）

![[04 Attachments/原发性肾小球疾病-MPGN双轨征.webp]]

### 分类

| 类型 | 特点 |
|------|------|
| **免疫球蛋白介导** | IgG + C3 沉积，如感染、SLE |
| **补体介导（C3 肾小球病）** | C3 为主沉积，C4 正常 |
| **不典型 HUS/TMA** | 无免疫沉积 |

### 临床
- [[蛋白质代谢功能检测|蛋白尿]]、[[血尿]]、肾功能减退
- 常伴 **低补体血症**（C3 ↓、C4 正常或↓）

### 治疗
- 治疗原发病
- C3 肾小球病：Eculizumab（抗 C5）
- 免疫复合物型：按免疫抑制方案

---

## 慢性肾小球肾炎（Chronic Glomerulonephritis, CGN）

### 特点
- 起病隐匿，进展缓慢
- **持续性 [[蛋白质代谢功能检测|蛋白尿]] + [[血尿]] + [[高血压]] + 肾功能减退**
- 多种病理类型的终末共同通路
- 最终进入 **终末期肾病（ESRD）**

### 治疗原则
1. **延缓肾功能恶化**
2. **控制[[高血压|血压]]**（核心治疗）
   - 蛋白尿 >1g/d：血压 <130/80
   - 蛋白尿 <1g/d：血压 <125/75
3. **[[ACEI]]/[[ARB]]**：首选，降蛋白、保护肾脏
4. **[[SGLT2抑制剂]]**：延缓 CKD 进展
5. **限制蛋白摄入**：0.8g/kg/d（CKD 3-4 期可 0.3g/kg/d + α-酮酸）
6. **避免肾毒性药物**（[[NSAIDs]]、氨基糖苷类、造影剂）

---

## 治疗总结

### 基础治疗 —— 所有肾小球疾病通用
- **RAAS 阻断**：[[ACEI]]/[[ARB]]，降低肾小球内高压
- **[[SGLT2抑制剂]]**：近年进展，循证医学证据充分
- **[[高血压|血压]]管理**：严格达标
- **低盐饮食**
- **[[利尿药]]**：对症消肿

### 免疫抑制阶梯（需病理指导）
1. **[[糖皮质激素类药物|糖皮质激素]]**
2. **[[环磷酰胺]]（CTX）**
3. **钙调神经磷酸酶抑制剂（CNI）**：环孢素、他克莫司
4. **[[霉酚酸酯]]（MMF）**
5. **[[利妥昔单抗]]（Rituximab）**：CD20+B 细胞清除
6. **依库珠单抗（Eculizumab）**：抗 C5 补体抑制剂

- Kidney International (2019) 95, 268-280 综述

## 经典考点自测

1. **急性链球菌感染后肾炎与 IgA 肾病的鉴别要点？**
   - PSGN：感染后 1-3 周发病，C3 下降 8 周恢复，ASO 升高
   - IgA 肾病：感染同步或 1-2 天内发作血尿，C3 正常

2. **RPGN 最关键的病理特征？**
   - 新月体形成（>50% 肾小球）

3. **肾病综合征的必备诊断条件？**
   - 大量蛋白尿 >3.5g/d + 低白蛋白血症 <30g/L

4. **膜性肾病最特异的血清学标记？**
   - 抗 PLA2R 抗体

5. **微小病变在电镜下的特征性改变？**
   - 足细胞足突融合（Foot Process Effacement）
