# 呼吸衰竭

> 呼吸衰竭是指原发性肺通气和/或换气功能严重损害，导致低氧血症和/或CO₂潴留，并引起一系列生理功能异常和代谢紊乱的临床综合征。诊断以动脉血气为客观标准：海平面、静息状态、呼吸空气条件下，**PaO₂ < 60mmHg 或 PaCO₂ > 50mmHg**。

---

## 分类

### 按动脉血气分类

| 类型 | 血气特征 | 主要机制 | 常见病因 |
|------|----------|----------|----------|
| **Ⅰ型呼吸衰竭**（低氧性） | PaO₂ < 60mmHg，PaCO₂ 降低或正常 | 换气功能障碍（V/Q失调、弥散障碍、分流） | 严重肺部感染、间质性肺疾病、急性肺栓塞 |
| **Ⅱ型呼吸衰竭**（高碳酸血症性） | PaCO₂ > 50mmHg，伴或不伴低氧 | 通气功能障碍（肺泡通气不足） | [[慢性阻塞性肺疾病|慢阻肺病]]、呼吸肌无力、胸廓畸形、中枢抑制 |

### 按发病急缓分类

| 类型 | 特点 |
|------|------|
| **急性呼吸衰竭** | 短时间内发生，机体不能代偿，不及时抢救危及生命 |
| **慢性呼吸衰竭** | 较长时间逐渐发展，早期机体代偿、pH正常；可在此基础上急性加重 |

---

## 病理生理机制

### Ⅰ型呼吸衰竭（低氧性）的发生机制

| 机制 | 说明 | 特点 |
|------|------|------|
| 吸入气氧分压降低 | 高海拔、氧疗装置故障等 | 临床容易识别 |
| 肺泡低通气 | 肺泡通气量减少致PaCO₂升高、PAO₂下降 | 低氧幅度有限，增加吸氧浓度可纠正 |
| **通气血流比例失调（V/Q失调）** | 部分肺泡通气不足→功能性分流；部分肺泡血流不足→无效腔样通气 | **Ⅰ型呼衰最常见机制**，对氧合影响大 |
| **真性分流（V/Q=0）** | 静脉血未经气体交换直接进入动脉 | 提高吸氧浓度**无效**，是难治性低氧的主因 |
| 弥散障碍 | 肺泡-毛细血管膜弥散受阻 | CO₂弥散速度为O₂的20倍，故单纯引起低氧 |

### Ⅱ型呼吸衰竭（高碳酸血症性）的发生机制

核心机制为**肺泡通气量不足** → CO₂排出减少。

- 每分通气量下降：阻塞性通气功能障碍（慢阻肺病、[[支气管哮喘|哮喘]]）、限制性通气功能障碍（神经肌肉疾病、[[胸膜疾病|气胸/胸腔积液]]、肥胖）
- 无效腔量增加

## 急性呼吸衰竭

### 病因

- **呼吸系统疾病**：严重肺部感染、急性气道阻塞、重度哮喘、急性肺水肿、肺栓塞、气胸、大量胸腔积液等
- **中枢神经系统疾病**：颅内感染、颅脑外伤、脑血管病变等直接或间接抑制呼吸中枢
- **神经肌肉疾病**：脊髓灰质炎、重症肌无力、有机磷中毒、颈椎外伤等

### 临床表现

| 系统 | 表现 |
|------|------|
| **呼吸系统** | 呼吸困难最早出现：呼吸频率增快、辅助呼吸肌参与（三凹征）；中枢性呼衰出现潮式呼吸、比奥呼吸 |
| **发绀** | SaO₂ < 90% 时出现口唇、指甲发绀（中央性发绀 vs 外周性发绀） |
| **精神神经** | 急性缺氧：精神错乱、躁狂、昏迷、抽搐；合并CO₂潴留：嗜睡、淡漠、扑翼样震颤 |
| **循环系统** | 心动过速；严重低氧/酸中毒致心肌损害、心律失常、心搏停止 |
| **消化泌尿系统** | 肝肾功能受损（ALT、尿素氮↑）；胃肠道黏膜屏障受损致应激性溃疡、上消化道出血 |

### 诊断

动脉血气分析为诊断核心依据：

- 明确Ⅰ型或Ⅱ型呼衰及严重程度
- pH反映代偿状况：PaCO₂升高 + pH正常 → **代偿性**呼吸性酸中毒；PaCO₂升高 + pH < 7.35 → **失代偿性**呼吸性酸中毒
- Ⅰ型呼衰诊断流程：胸部影像大致正常 → 定位于右心-肺血管疾病；影像异常 → 鉴别肺源性 vs 心源性肺水肿
- Ⅱ型呼衰诊断流程：主要原因为二氧化碳排出减少（通气功能障碍/无效腔增加）

辅助检查：肺功能（判断通气障碍性质）、胸部影像学、支气管镜等协助病因诊断。

### 治疗原则

| 方面 | 措施 |
|------|------|
| **呼吸支持** | 尽快改善低氧及高碳酸血症，纠正内环境紊乱，维持循环稳定（详见氧疗与机械通气） |
| **对因治疗** | 针对不同病因采取相应治疗（抗感染、解除气道阻塞等），是治疗呼衰的根本 |
| **并发症处理** | 监测重要脏器功能，预防和治疗肺动脉高压、[[慢性肺源性心脏病|肺源性心脏病]]、肺性脑病、肾功能不全、消化道功能障碍、DIC等 |

## 慢性呼吸衰竭

### 病因

多由支气管-肺疾病引起，如[[慢性阻塞性肺疾病|慢阻肺病]]（最常见）、严重[[肺结核]]、肺间质纤维化、肺尘埃沉着症等。胸廓和神经肌肉病变亦可导致。

### 代偿机制

早期虽有低氧或伴高碳酸血症，但机体通过代偿适应，动脉血气pH可维持在正常范围，仍保持一定生活活动能力。**慢性呼吸衰竭急性加重**是在此基础上因感染、气道痉挛或并发气胸等导致急性恶化。

### 临床表现特点

| 表现 | 说明 |
|------|------|
| **呼吸困难** | 慢阻肺病：呼吸费力伴呼气延长→浅快呼吸；CO₂麻醉时转为浅慢呼吸或潮式呼吸 |
| **神经症状（CO₂潴留）** | **先兴奋后抑制**：兴奋期失眠、烦躁、昼夜颠倒（禁用镇静催眠药）；抑制期为肺性脑病（淡漠、震颤、抽搐、昏睡、昏迷） |
| **循环系统** | CO₂潴留致外周血管扩张：皮肤温暖多汗、脉搏洪大、搏动性头痛 |

### 治疗

与急性呼衰一致，特别注意以下要点：

#### 氧疗与CO₂潴留的矛盾

慢阻肺病所致慢性呼衰常伴CO₂潴留，**必须保持低浓度吸氧**。原因：慢性高碳酸血症病人呼吸中枢对CO₂反应性差，呼吸主要靠低氧对外周化学感受器的刺激维持。若吸入高浓度氧 → 低氧刺激解除 → 呼吸抑制 → CO₂进一步升高 → CO₂麻醉。

| 病人类型 | 氧疗目标SpO₂ |
|----------|-------------|
| 无高碳酸血症风险 | 94%~98% |
| 存在高碳酸血症风险（慢阻肺病等） | **88%~92%** |

#### 长期家庭氧疗（LTOT）

慢性呼衰病人出院后常需家庭长期氧疗和/或家庭机械通气，需配备氧气罐、制氧机、呼吸机等设备。

#### 无创正压通气

慢阻肺病急性加重早期及时应用无创机械通气可防止呼吸功能不全加重，缓解呼吸肌疲劳，减少气管插管率，改善预后。

## 呼吸支持技术

### 氧疗

| 装置 | 特点 | 吸入氧浓度 |
|------|------|-----------|
| 鼻塞导管（低流量） | 最常用，廉价舒适；氧流量 < 8L/min | FiO₂(%) = 21 + 4×氧流量(L/min) |
| 简单面罩（储存装置） | 吸氧浓度相对稳定 | 35%~55% |
| 文丘里面罩（高流量） | 可精确调节氧浓度，适用于慢阻肺病 | 精确可调，低浓度时输送高流量 |
| 经鼻高流量吸氧（HFNC） | 可单独调节流量和氧浓度，最大流量 ≥ 60L/min；产生气道正压（2~7cmH₂O），改善通气效率，气道湿化好 | FiO₂ 0.21~1.0 |

### 机械通气

| 方式 | 适应证 | 禁忌/慎用 |
|------|--------|----------|
| **无创正压通气（NPPV）** | 慢阻肺病急性加重早期、心源性肺水肿、免疫力低下者、有创-无创序贯通气 | 心跳呼吸骤停、昏迷、上气道梗阻、严重血流动力学不稳定、未引流气胸 |
| **有创正压通气** | 经积极治疗仍恶化、意识障碍、呼吸频率 > 35~40或 < 6~8次/分、PaO₂ < 50mmHg（充分氧疗后仍 < 60）、PaCO₂进行性上升、pH下降 | 相对禁忌：未引流张力性气胸、大咯血窒息、低血容量休克未纠正 |

### 体外膜肺氧合（ECMO）

| 模式 | 用途 |
|------|------|
| VV-ECMO（静脉-静脉） | 仅用于**呼吸功能支持** |
| VA-ECMO（静脉-动脉） | 同时用于**呼吸+心脏功能支持** |

ECMO是严重呼吸/循环衰竭的终极呼吸支持方式，为原发病的治疗争取时间。

### 人工气道的建立与管理

建立人工气道的目的：①解除气道梗阻；②清除呼吸道内分泌物；③防止误吸；④实行正压通气。

途径：经口/鼻气管插管（喉上途径）、环甲膜穿刺或气管切开（喉下途径）。

管理要点：固定防移位、清除分泌物、口腔护理、气囊压力维持25~30cmH₂O、加温湿化吸入气体。
