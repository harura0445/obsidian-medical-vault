# 唾液 *saliva*
1. [[唾液腺]]：腮腺、颌下腺、舌下腺；分泌量1~1.5 L/天 
2. 成分： 
	水 (约占99%)<br>
	无机物：Na+、K+、Cl-、Ca2+、HCO3-、硫氰酸盐离子浓度和渗透压随分泌速度变化<br>
	有机物**：黏蛋白、唾液淀粉酶、溶菌酶、IgA、氨基酸、尿酸、尿素等**
3. 作用：
	1. 消化作用稀释和溶解食物, 以利咀嚼、吞咽和引起味觉
	2. 润滑作用，湿润口腔和食物，便于说话和吞咽
	3. 清洁口腔和抗菌作用 (溶菌酶和IgA) 
	4. 排毒 (进入体内的铅、汞、药物和某些病毒)
4. 唾液的分泌调节：完全属于**神经调节**
	1. 条件反射：由视、听、嗅觉传入 (生活经验) 引起
	2. 非条件反射：食物入口腔, 咀嚼和吞咽刺激引起
	- 传入神经：**5 、7 、9 、10** 
	- 泌涎中枢：延髓上涎核、下涎核
	- 传出神经： 
		- 副交感神经（主要）：9 、12 (鼓索支) <br>
			分泌大量**稀薄**唾液，有机物少<br>
			递质：乙酰胆碱；**M受体**；拮抗剂阿托品
		- 交感神经：颈上神经节  
			分泌少量**黏稠**唾液，含酶及黏蛋白多  
			递质：去甲肾上腺素；**β-肾上腺素能受体**
