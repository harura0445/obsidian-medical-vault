# 盆腔炎性疾病及生殖器结核


## 盆腔炎性疾病

### 概述

盆腔炎性疾病（PID）指女性上生殖道的一组感染性疾病，主要包括子宫内膜炎、输卵管炎、输卵管卵巢脓肿（TOA）、盆腔腹膜炎。炎症可局限于一个部位，也可同时累及多个部位，以输卵管炎、输卵管卵巢炎最常见。多发生在性活跃的生育期女性。PID可由[[外阴及阴道炎|下生殖道感染]]（如BV、滴虫）、[[子宫颈炎|子宫颈炎]]（淋球菌/衣原体）上行蔓延所致。

PID若未能得到及时、彻底治疗，可导致不孕、[[异位妊娠|输卵管妊娠]]、慢性盆腔痛、炎症反复发作，严重影响女性生殖健康。

### 女性生殖道的自然防御机制

| 防御层次 | 机制 |
|---------|------|
| **解剖** | 两侧大阴唇合拢；阴道口闭合、前后壁紧贴；子宫颈内口紧闭、黏液栓屏障；子宫内膜周期性剥脱；输卵管纤毛向宫腔摆动 |
| **生化** | 子宫颈黏液栓含乳铁蛋白、溶菌酶；子宫内膜与输卵管分泌液同样含抗菌物质 |
| **免疫** | 生殖道黏膜聚集T细胞、B细胞、中性粒细胞、巨噬细胞、补体及细胞因子 |

### 病原体及感染途径

**病原体来源**：

| 来源 | 病原体 | 特点 |
|------|--------|------|
| **外源性** | 沙眼衣原体、淋病奈瑟球菌 | 性传播疾病病原体 |
| **内源性** | 需氧菌（金葡菌、溶血链球菌、大肠埃希菌等）+ 厌氧菌（脆弱拟杆菌、消化球菌等） | 混合感染多见；厌氧菌感染易形成盆腔脓肿 |

**感染途径**：

| 途径 | 常见病原体 | 常见情况 |
|------|-----------|---------|
| **沿生殖道黏膜上行蔓延** | 淋球菌、沙眼衣原体、葡萄球菌 | 非妊娠期、非产褥期PID的主要途径 |
| **经淋巴系统蔓延** | 链球菌、大肠埃希菌、厌氧菌 | 产褥感染、流产后感染、IUD后感染 |
| **经血液循环传播** | 结核分枝杆菌 | 结核菌感染的主要途径 |
| **直接蔓延** | 大肠埃希菌 | 阑尾炎→右侧输卵管炎 |

### 高危因素

年龄（25～44岁高发）、性活动（多性伴侣、初次性交年龄小）、下生殖道感染（淋球菌/衣原体性子宫颈炎、BV）、宫腔手术后感染、性卫生不良、邻近器官炎症、PID史。

### 临床表现

症状轻重不一，轻者可无症状。

**症状**：
- **下腹痛、阴道分泌物增多**：最常见，腹痛持续性，活动/性交后加重
- **月经异常**：经量增多、经期延长
- **消化道症状**：食欲减退、恶心呕吐、腹胀腹泻（腹膜炎）；里急后重（子宫后方脓肿）
- **泌尿系统症状**：尿急、尿频、尿痛
- **全身症状**：发热、寒战、头痛、乏力

**体征**：子宫颈举痛、子宫体压痛、附件区压痛；严重者下腹压痛反跳痛肌紧张。阴道见脓性臭味分泌物；子宫两侧压痛明显，可触及增粗输卵管或包块。

**肝周围炎（Fitz-Hugh-Curtis综合征）**：5%～10%输卵管炎可出现，表现为继下腹痛后出现右上腹痛。肝包膜炎症而无肝实质损害，常见于淋球菌及衣原体感染。

### 诊断

**CDC诊断标准（2021）**：

| 标准等级 | 内容 |
|---------|------|
| **最低标准** | 子宫颈举痛或子宫压痛或附件区压痛 |
| **附加标准** | 体温>38.3℃；子宫颈异常黏液脓性分泌物；阴道分泌物湿片大量WBC；ESR↑；CRP↑；子宫颈淋球菌/衣原体阳性 |
| **特异标准** | 子宫内膜活检证实子宫内膜炎；影像学（输卵管增粗、积液、TOA）；腹腔镜见PID征象 |

> 最低诊断标准：性活跃年轻女性或STD高危人群出现下腹痛，排除其他原因，妇科检查符合最低标准，即可给予抗菌药物治疗。

### 治疗

以抗菌药物治疗为主，必要时手术。治疗原则：**及时、广谱、个体化**。诊断48小时内用药将明显减少后遗症。

**非静脉给药方案**（症状轻、能耐受口服）：

| 方案 | 药物 |
|------|------|
| **首选** | 头孢曲松钠0.5g单次肌注 + 甲硝唑0.4g bid po×14d + 多西环素0.1g bid po×14d |
| **可选1** | 左氧氟沙星0.5g qd po×14d + 甲硝唑0.4g bid po×14d |
| **可选2** | 阿奇霉素+甲硝唑方案 |

**静脉给药方案**（病情严重、TOA、妊娠、门诊无效等）：首选β-内酰胺类+四环素类（+甲硝唑）方案。临床症状改善后继续静脉给药≥24h，再转为口服，总疗程≥14日。

**影像学引导穿刺治疗**：适用于脓肿较大/药物治疗效果差者。

**手术治疗指征**：
1. 药物治疗无效（48～72h体温不降、中毒症状加重或包块增大）
2. 脓肿持续存在或复发
3. 脓肿破裂（需立即手术）

### 盆腔炎性疾病后遗症


| 后遗症 | 发生率 |
|--------|--------|
| **不孕** | 20%～30%（输卵管粘连阻塞） |
| **异位妊娠** | 正常女性8～10倍 |
| **慢性盆腔痛** | 约20% |
| **PID反复发作** | 有PID史者约25% |

治疗：不孕需辅助生殖技术；慢性盆腔痛对症处理或中药、理疗；反复发作可在抗菌药物基础上择期手术。

### 预防

注意性生活卫生、及时治疗[[外阴及阴道炎|下生殖道感染]]、严格掌握妇科手术指征、及时治疗PID防止后遗症。产后[[产后出血|产褥感染]]也可引起PID。

## 生殖器结核

### 概述

由结核分枝杆菌引起的女性生殖器炎症，又称结核性盆腔炎。多见20～40岁女性。包括输卵管结核、子宫内膜结核、卵巢结核、子宫颈结核、盆腔腹膜结核。常继发于身体其他部位结核，潜伏期可达1～10年。

### 传播途径

**血行传播**为最主要途径。结核分枝杆菌首先侵袭输卵管，然后依次扩散到子宫内膜、卵巢。

### 病理

| 部位 | 占生殖器结核比例 | 特点 |
|------|-----------------|------|
| **输卵管结核** | 90%～100% | 双侧居多；分增生粘连型（80%）和渗出型 |
| **子宫内膜结核** | 50%～80% | 由输卵管蔓延；可使宫腔粘连变形、缩小 |
| **卵巢结核** | 20%～30% | 多由输卵管蔓延，常有卵巢周围炎 |
| **子宫颈结核** | 10%～20% | 外观易与宫颈癌混淆 |
| **盆腔腹膜结核** | 合并输卵管结核 | 分渗出型（腹腔积液）和粘连型 |

### 临床表现

**症状**：不孕（最常见就诊原因）、月经失调（早期经量过多，晚期稀少或闭经）、下腹坠痛（经期加重）、全身症状（发热、盗汗、乏力、食欲缺乏、体重减轻）。

**体征**：差异较大。严重者腹部柔韧感或腹腔积液征；子宫活动受限；附件区可触及不规则包块。

### 诊断

详细询问病史（原发性不孕、月经稀少或闭经、低热盗汗、既往结核病史/接触史）。

**辅助检查**：

| 方法 | 特点 |
|------|------|
| **子宫内膜病理检查** | 最可靠的诊断依据。经前1周或月经来潮6h内刮宫，刮取子宫角部内膜 |
| **子宫输卵管造影** | 宫腔变形呈锯齿状、输卵管串珠状、盆腔钙化灶 |
| **腹腔镜/宫腔镜** | 直接观察并取活检 |
| **结核分枝杆菌检查** | 涂片抗酸染色、培养、PCR |
| **T-SPOT.TB** | 灵敏度和特异度最高 |
| **结核菌素试验** | 强阳性提示活动性病灶 |

### 鉴别诊断

需与PID后遗症、子宫内膜异位症、卵巢恶性肿瘤（尤其上皮性癌）鉴别。

### 治疗

**抗结核药物治疗为主**，休息营养为辅，必要时手术。遵循**早期、联合、规律、适量、全程**原则。90%女性生殖器结核药物治疗有效。

**手术指征**：盆腔包块药物治疗后不能消退；治疗无效或反复发作；难以与恶性肿瘤鉴别；形成较大包块或包裹性积液；子宫内膜破坏广泛、药物治疗无效。

手术前后需应用抗结核药物。年轻女性尽量保留卵巢功能。

### 预后与随访

规范治疗疗效良好，但治疗后妊娠成功率极低，部分可行辅助生殖技术助孕。
