# 妊娠生理

## 概述

妊娠是胚胎和胎儿在母体内生长发育的过程。成熟卵子受精是妊娠的开始，胎儿及其附属物自母体排出是妊娠的终止。全过程约280日（40周）。

## 受精及受精卵发育、输送与着床

### 受精

获能的精子与次级卵母细胞在输卵管内结合形成受精卵的过程。受精多发生在排卵后数小时内，不超过24小时。

**精子获能**：精子离开精液经宫颈管、宫腔进入输卵管腔的过程中，顶体表面糖蛋白被降解，顶体膜稳定性降低，需7小时左右。

**顶体反应**：精子头部顶体外膜破裂，释放顶体酶（顶体素、玻璃酸酶、酯酶），溶解卵子外围放射冠和透明带。

**透明带反应**：精子与卵子表面接触时，卵子皮质颗粒释放溶酶体酶，改变透明带结构，阻止其他精子进入。

受精后30小时开始卵裂，受精后72小时形成16细胞桑葚胚，第4日进入宫腔，第5～6日囊胚孵化。

### 受精卵着床

约受精6～7日后胚胎植入子宫内膜，经过**定位→黏附→侵入**三个过程。

着床必备条件：①透明带消失；②囊胚细胞滋养细胞分化出合体滋养细胞；③囊胚和子宫内膜同步发育且功能协调；④体内分泌足量的雌、孕激素。子宫内膜容受性仅在月经周期第20～24日（窗口期）。

着床后子宫内膜蜕膜化，分为**底蜕膜、包蜕膜、真蜕膜**。

## 胚胎、胎儿发育特征

| 孕周 | 身长/体重 | 发育特征 |
|------|-----------|----------|
| 8周末 | — | 胚胎初具人形，心脏已形成 |
| 12周末 | 9cm | 外生殖器可初辨性别 |
| 16周末 | 16cm/110g | 可确认性别，出现呼吸运动，孕妇自觉胎动 |
| 20周末 | 25cm/320g | 出现胎脂、毳毛，开始吞咽排尿，胎动明显 |
| 24周末 | 30cm/630g | 各脏器均已发育，出生后可有呼吸但生存力极差 |
| 28周末 | 35cm/1000g | 出生后可存活，但早产儿并发症多 |
| 32周末 | 40cm/1700g | 存活率较高 |
| 36周末 | 45cm/2500g | 接近足月，存活能力强 |
| 40周末 | 50cm/3400g | 胎儿发育成熟，能很好存活 |

### 胎儿生理特点

- **循环系统**：胎儿体内**无纯动脉血**，为动静脉混合血。脐静脉→静脉导管→下腔静脉→右心房→卵圆孔→左心房→左心室→升主动脉（含氧较高供头部）。上腔静脉血→右心室→肺动脉→动脉导管→主动脉。出生后卵圆孔、动脉导管、静脉导管、脐血管均闭锁
- **呼吸系统**：**肺表面活性物质**（卵磷脂、磷脂酰甘油）由Ⅱ型肺泡细胞板层小体合成，决定胎肺成熟度，与新生儿生存能力密切相关。糖皮质激素可刺激其产生
- **血液系统**：妊娠32周后红细胞生成素大量产生。胎儿血红蛋白至临产时仅占25%
- **肝脏**：缺乏许多酶，不能结合游离胆红素，胆绿素降解产物使胎粪呈黑绿色

## 胎儿附属物的形成与功能

### 胎盘

由胎儿部分的羊膜和叶状绒毛膜及母体部分的底蜕膜构成。足月胎盘重450～650g，直径16～20cm，厚1～3cm。

**绒毛发育三阶段**：初级绒毛→次级绒毛→三级绒毛（形成胎儿血管）。绒毛间隙充满母血，母胎物质交换在悬浮于母血的绒毛处进行。

**子宫螺旋动脉重塑**是子宫-胎盘循环建立的关键。重塑障碍可导致子痫前期、FGR。

**胎盘功能**：

| 功能 | 要点 |
|------|------|
| 气体交换 | O₂和CO₂以简单扩散方式交换，胎儿Hb对O₂亲和力强 |
| 营养物质供应 | 葡萄糖（易化扩散，胎儿主要能源）；氨基酸、钙、铁（主动运输） |
| 排出代谢产物 | 尿素、肌酐等经胎盘入母血 |
| 防御功能 | 屏障作用**极为有限**，病毒、大部分药物可通过；IgG可通过使胎儿获得被动免疫 |
| 合成功能 | hCG、hPL、雌激素、孕激素、缩宫素酶等 |
| 免疫功能 | 同种半异体移植物不被排斥，机制未完全明确 |

**胎盘合成的重要激素**：

| 激素 | 特点与功能 |
|------|-----------|
| hCG | 受精卵着床后1日可测出，**8～10周达高峰**。维持月经黄体，促进孕酮分泌，抑制免疫排斥 |
| hPL | 妊娠5周可测出，晚期达高峰。促进乳腺发育，脂解供能，是胎儿主要能源的"代谢调节因子" |
| 雌激素 | 妊娠10周后主要由**胎儿-胎盘单位**合成，末期雌三醇值×1000 |
| 孕激素 | 妊娠8～10周后胎盘合体滋养细胞是主要来源 |

### 胎膜

由平滑绒毛膜和羊膜组成，维持羊膜腔完整性，保护胎儿。含大量花生四烯酸磷脂，在分娩发动中有一定作用。

### 脐带

长30～100cm（平均55cm），内含**1条脐静脉、2条脐动脉**，华通胶保护血管。脐带受压可致胎儿缺氧。

### 羊水

- **来源**：早期为母体血清透析液；中期后胎儿尿液为主要来源；晚期胎肺参与生成（～350ml/d）
- **吸收**：胎儿吞咽是主要方式（近足月500～700ml/d），膜内转运亦有协同作用
- **羊水量**：妊娠38周约1000ml，40周约800ml，过期妊娠明显减少（<300ml）
- **功能**：保护胎儿（缓冲、防粘连、促肺发育），保护母体（减轻胎动不适、扩张宫口、减少感染）

## 妊娠期母体的变化

### 生殖系统

- **子宫**：妊娠期变化最大的器官。容量增至5000ml（×500～1000），重量增至1100g（×20）。子宫增大主要因肌细胞肥大，晚期轻度右旋。出现**Braxton Hicks收缩**（不规律无痛性宫缩）。子宫峡部伸展形成**子宫下段**（临产后7～10cm）
- **卵巢**：妊娠6～7周前产雌/孕激素维持妊娠，10周后黄体功能由胎盘取代
- **阴道**：充血呈紫蓝色（Chadwick征），糖原增加→乳酸增加→pH降低，抗感染

### 循环系统

- **心输出量**：自8～10周增加，**32～34周达高峰**（增加约30%），持续至分娩，是妊娠期循环系统最重要的改变
- **血压**：早中期偏低，晚期仰卧位可致**仰卧位低血压综合征**（子宫压迫下腔静脉）
- 有基础心脏病者易在妊娠期和分娩期发生心力衰竭

### 血液系统

- **血容量**：6～8周开始增加，**32～34周达高峰**（增加40%～45%），血浆增加>红细胞增加→生理性血液稀释
- **血红蛋白**：约110～130g/L
- **凝血**：**高凝状态**（凝血因子Ⅱ、Ⅴ、Ⅶ、Ⅷ、Ⅸ、Ⅹ↑），为产后止血做准备。血栓风险增加5～6倍

### 其他系统变化

- **泌尿系统**：RPF↑35%，GFR↑50%，约15%孕妇出现生理性糖尿。右侧输尿管易受压→肾盂积水，**右侧急性肾盂肾炎多见**
- **呼吸系统**：通气量↑40%，PO₂↑、PCO₂↓，呼吸较深大
- **消化系统**：胃贲门括约肌松弛→胃灼热感；肠蠕动减弱→便秘、痔疮
- **内分泌系统**：FSH/LH↓（负反馈抑制）；PRL↑10倍；皮质醇↑3倍（游离10%）；甲状腺中度增大
- **新陈代谢**：BMR晚期增高15%～20%。空腹血糖略低，餐后高血糖。妊娠期需铁1000mg，钙30g
- **皮肤**：妊娠黄褐斑、妊娠纹（弹力纤维断裂）
