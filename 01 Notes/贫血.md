# 贫血

> 贫血（anemia）是指外周血单位容积内血红蛋白（Hb）量、红细胞（RBC）数及（或）血细胞比容（Hct）低于正常参考值的一种常见临床症状，而非独立疾病。

## 定义与诊断标准

**诊断标准**（海平面地区）：

| 人群 | 血红蛋白（Hb） | 红细胞计数（RBC） | 血细胞比容（Hct） |
|------|---------------|-------------------|-------------------|
| 成年男性 | <120 g/L | <4.0×10¹²/L | <42% |
| 成年女性 | <110 g/L | <3.5×10¹²/L | <37% |
| 孕妇 | <100 g/L | — | <30% |

**影响因素**：高原反应、[[血液一般检测|血液]]稀释/浓缩等可影响上述指标。

**严重程度分级**：

| 分级 | 血红蛋白范围 |
|------|-------------|
| 轻度 | >90 g/L（>参考值下限） |
| 中度 | 60–90 g/L |
| 重度 | 30–60 g/L |
| 极重度 | <30 g/L |

## 病因与发病机制

### 红细胞的生成与调节

[[贫血的实验室检测|红细胞]]起源于骨髓中的全能造血干细胞（HSC）。HSC 分化为多向骨髓祖细胞（CFU-S），再分化为红系定向祖细胞（BFU-E）→ 原红细胞 → 经四次分裂 → 网织红细胞 → 成熟红细胞。

红细胞生成所需的要素：
- **造血干细胞**：骨髓微环境正常
- **营养物质**：铁、[[维生素B12]]、叶酸、原卟啉等
- **造血刺激因子**：促红细胞生成素（EPO）等

![[04 Attachments/内科-贫血-造血与发病机制.webp]]

### 病因分类

根据发病机制分为三大类：

#### 一、红细胞生成减少

| 亚类 | 机制 | 临床类型 |
|------|------|----------|
| 造血干细胞复制与分化障碍 | 干细胞/微环境损害 | [[再生障碍性贫血]]（AA） |
|  | 免疫性破坏 | 单纯红细胞再生障碍性贫血 |
|  | 骨髓被异常细胞浸润 | 骨髓病性贫血 |
| 分化细胞生成和成熟障碍 | DNA合成障碍 | [[巨幼细胞贫血]]（叶酸/VitB12缺乏） |
|  | 血红蛋白合成障碍 | [[缺铁性贫血]]、铁粒幼细胞性贫血 |
|  | 珠蛋白合成障碍 | [[α-地中海贫血]]、[[β-地中海贫血]] |
| EPO产生减少 | 肾功能损害 | [[慢性病贫血]]、肾性贫血 |

#### 二、红细胞破坏过多（[[溶血性贫血]]）

| 分类 | 机制 | 临床类型 |
|------|------|----------|
| 红细胞内异常 | 膜结构缺陷 | 遗传性球形红细胞增多症 |
|  | 酶活性缺陷 | G6PD缺乏症、丙酮酸激酶缺乏症 |
|  | 珠蛋白异常 | [[镰状细胞贫血]]、[[α-地中海贫血|地中海贫血]] |
| 红细胞外异常 | 免疫性 | [[自身免疫性溶血性贫血]]（AIHA） |
|  | 机械性 | [[微血管病性溶血性贫血]]、TTP |
|  | 化学/物理/生物 | 蛇毒、烧伤、感染 |
|  | 脾脏阻留 | [[脾功能亢进]] |

#### 三、失血

- **急性失血** → 急性失血后贫血
- **慢性失血** → 常导致[[缺铁性贫血]]

![[04 Attachments/内科-贫血-病因分类.webp]]

### 细胞形态学分类

此为最实用的临床分类思路，依据 **MCV（平均红细胞体积）、MCH（平均红细胞血红蛋白量）、MCHC（平均红细胞血红蛋白浓度）** 三指标：

| 类型 | MCV（fl） | MCH（pg） | MCHC（%） | 常见疾病 |
|------|-----------|-----------|-----------|----------|
| **大细胞性贫血** | >100 | >32 | 31–35 | [[巨幼细胞贫血]] |
| **正细胞性贫血** | 80–100 | 26–32 | 31–35 | [[再生障碍性贫血]]、急性失血、[[溶血性贫血]] |
| **小细胞低色素性贫血** | <80 | <26 | <31 | [[缺铁性贫血]]、铁粒幼细胞性贫血、[[α-地中海贫血|地中海贫血]]、[[慢性病贫血]] |

## 临床表现

贫血的临床表现取决于贫血的**程度**、**发生速度**、**病因**以及机体的代偿能力。

### 一般表现

- **皮肤黏膜苍白**：最客观的体征，见于皮肤、口唇、睑结膜、甲床

### 呼吸循环系统

- 心悸、气短、活动后加重
- 各瓣膜区收缩期杂音
- 心脏扩大
- 心电图：S-T段降低、T波低平或倒置
- **贫血性心脏病**：Hb持续<30 g/L达3个月以上

### 神经肌肉系统

- 头晕、头痛、失眠、乏力、易疲劳
- 严重者可出现晕厥、昏迷

### 消化系统

- 食欲不振、厌食、恶心、腹胀
- 舌质改变（[[缺铁性贫血|缺铁]]时舌炎、[[巨幼细胞贫血|巨幼贫]]时镜面舌）

### 泌尿生殖系统

- 多尿、尿比重低、蛋白尿
- 月经紊乱、闭经、性功能减退

### 特殊表现（病因相关）

- [[缺铁性贫血]]：反甲、异食癖
- [[巨幼细胞贫血]]：神经系统症状（手足麻木、感觉障碍、共济失调）
- [[溶血性贫血]]：黄疸、脾大、血红蛋白尿
- [[再生障碍性贫血]]：出血倾向、反复感染

## 辅助检查

### 诊断流程（三步法）

**第一步**：确定贫血的存在与程度
- 病史、体格检查
- [[血液一般检测|血常规]]：Hb、Hct、RBC
- 症状评估（苍白、头晕、乏力等）

**第二步**：贫血的形态学分类与病因定位
- **红细胞参数**（MCV、MCH、MCHC）→ 形态学归类
- **网织红细胞计数（Ret）** → 判断骨髓代偿能力
- 结合病史、体格检查、实验室检查进行鉴别

| Ret 增高 | Ret 减低 |
|-----------|----------|
| [[溶血性贫血]] | [[再生障碍性贫血]] |
| 急性失血后 | 骨髓病性贫血 |
| 缺铁/巨幼贫治疗后 | 肾性贫血 |

**第三步**：针对性的病因检查
- [[贫血的实验室检测|血清铁、铁蛋白、总铁结合力]]（缺铁性贫血）
- 叶酸、维生素B12水平（巨幼细胞贫血）
- [[贫血的实验室检测|骨髓穿刺+活检]]（再障、MDS、白血病）
- Coombs试验（自身免疫性溶血）
- Ham试验、CD55/CD59（PNH）
- Hb电泳（地中海贫血）

![[04 Attachments/内科-贫血-诊断步骤.webp]]

### 常用实验室检查

- **血清铁（SI）** <500 μg/L、**总铁结合力（TIBC）** >3600 μg/L、**转铁蛋白饱和度（TS）** <15% → 缺铁性贫血
- **血清铁蛋白（SF）**：反映铁储备的可靠指标
- **骨髓铁染色**：缺铁性贫血诊断的金标准

## 诊断与鉴别诊断

### 诊断思路

1. 明确有无贫血（血常规）
2. 判断贫血程度（轻、中、重、极重）
3. 形态学分类（大细胞/正细胞/小细胞）
4. 病因学定位（生成减少/破坏过多/失血）
5. 最终病因确定

### 鉴别诊断要点

- **Ret增高相关疾病**：溶血性贫血 vs 失血性贫血 vs 治疗后反应 vs MDS
- **胆红素增高相关疾病**：溶血性黄疸 vs 肝细胞性黄疸 vs 先天性非溶血性黄疸
- **幼粒-幼红血症相关疾病**：骨髓纤维化 vs 骨髓转移癌 vs 白血病/MDS vs 严重溶血

## 治疗

### 对因治疗（核心原则）

1. **造血因子治疗**：
   - 铁剂 → [[缺铁性贫血]]
   - 叶酸、维生素B12 → [[巨幼细胞贫血]]
   - 促红细胞生成素（EPO）→ 肾性贫血、慢性病贫血

2. **免疫抑制剂治疗**：
   - 肾上腺糖皮质激素 → [[自身免疫性溶血性贫血|AIHA]]
   - ATG + CSA → [[再生障碍性贫血]]

3. **手术治疗**：
   - 脾切除 → 遗传性球形红细胞增多症、AIHA、地中海贫血

4. **补充造血干细胞**：
   - [[造血干细胞移植]] → 重症再障、重症地中海贫血

### 支持治疗

- **输血治疗**：根据贫血程度决定，慢性贫血应严格掌握指征
  - 成分输血：浓缩红细胞、三洗红细胞（PNH、AIHA）
  - 血小板输注（再障伴严重出血）
- 防治感染
- 营养支持

### 常见贫血的治疗要点

| 类型 | 核心治疗 | 备注 |
|------|---------|------|
| [[缺铁性贫血]] | 补铁+去除病因 | 口服铁剂为主，Hb正常后续服3–6月 |
| [[巨幼细胞贫血]] | 补充叶酸+VitB12 | 先补B12再补叶酸（防神经系统症状加重） |
| [[再生障碍性贫血]] | IST（ATG+CSA）或移植 | ≤40岁有供者→移植；>40岁→IST |
| [[溶血性贫血]] | 激素（AIHA）、脾切除、免疫抑制剂 | 针对病因治疗 |

## 常见贫血类型概述

### 缺铁性贫血

最常见的贫血类型。由于铁缺乏导致血红蛋白合成障碍，引起小细胞低色素性贫血。
- 发病率：成年男性10%、成年女性20%、孕妇40%、儿童50%
- 病因：摄入不足、需要量增加（生长发育/妊娠）、慢性失血（月经过多、消化道出血）
- 治疗：补铁+根治病因

### 巨幼细胞贫血

由于维生素B12和/或叶酸缺乏导致DNA合成障碍，引起大细胞性贫血。
- 特点：巨幼变（幼核老浆）、中性粒细胞核右移、可伴神经系统症状
- 诊断：骨髓巨幼变+叶酸/B12水平降低+试验性治疗有效

### 再生障碍性贫血（AA）

骨髓衰竭综合征，以骨髓增生低下和造血干细胞缺乏为特征。
- 发病高峰：15–25岁和60岁
- 发病机制：T细胞介导的自身免疫性骨髓衰竭
- 分型：重型（SAA）和轻型（NSAA）
- 治疗：IST（ATG+CSA）或造血干细胞移植

### 溶血性贫血

红细胞寿命缩短、破坏加速超过骨髓代偿能力所致。
- 血管内溶血：血红蛋白尿、含铁血黄素尿、Ham试验(+)
- 血管外溶血：肝脾肿大、胆红素升高（间接胆红素为主）
- 诊断：Ret↑ + 胆红素↑ + 骨髓红系代偿增生

## 预后

取决于基础病因：
- [[缺铁性贫血]]：病因去除后预后良好
- [[巨幼细胞贫血]]：治疗反应迅速，预后好
- [[再生障碍性贫血]]：IST有效率达60–70%，5年生存率70–80%
- [[α-地中海贫血|重型地中海贫血]]：需长期输血/移植，预后差
- [[溶血性贫血]]：取决于具体病因及治疗反应

## 预防

- 合理膳食：保证铁、叶酸、维生素B12的摄入
- 积极防治慢性失血性疾病（消化道溃疡、痔疮、寄生虫感染等）
- 高危人群筛查：孕妇、儿童、老年人定期检测血常规
- 避免接触苯类化学物质、过量放射线
- 慎用骨髓抑制药物
