# 感染性心内膜炎

> 感染性心内膜炎（IE）是指病原体循血行途径或直接感染心瓣膜、心内膜或邻近大血管内膜所致的感染性疾病，最常累及瓣膜，常伴赘生物形成、局部结构与功能受损、终末器官栓塞及全身炎症反应。

## 概述

| 项目 | 内容 |
|------|------|
| **全球发病率** | 约 13.8/10万/年（2019年），男女比例≥2∶1 |
| **最常见病原体** | 链球菌、葡萄球菌（欧美以葡萄球菌居多，我国两者并重） |
| **易患因素** | 基础心脏病（瓣膜病、先天性心脏病）、免疫低下（艾滋病、糖尿病）、心脏器械植入（起搏器、人工瓣膜）、医疗操作（血透、导管）、静脉药物成瘾 |

## 分类

| 分类依据 | 类型 | 特点 |
|----------|------|------|
| **病程急缓** | 急性IE | 起病急骤、进展快（数天致瓣膜破坏），中毒症状明显，感染迁移多见，多为金黄色葡萄球菌 |
| | 亚急性IE | 起病缓、进展慢（数周至数月），中毒症状轻，感染迁移少见，多为草绿色链球菌 |
| **感染途径** | 社区获得性 | 链球菌居多 |
| | 医源性/医院获得性 | 金黄色葡萄球菌居多 |
| **瓣膜性质** | 自体瓣膜心内膜炎（NVE） | 主要类型 |
| | 人工瓣膜心内膜炎（PVE） | 手术1年内=早期PVE；1年后=晚期PVE |

## 发病机制

正常心内膜→内皮损伤→血小板和纤维蛋白聚集→**无菌性赘生物**形成→菌血症时病原体种植→**感染性赘生物**→赘生物碎片脱落→远处栓塞播散

## 临床表现

### 核心临床表现

| 症状与体征 | 特点 |
|-----------|------|
| **发热** | 最常见（几乎所有病人），亚急性者呈不规则低热（<39℃）伴乏力、盗汗、消瘦；急性者呈高热、寒战 |
| **心脏杂音** | 85%的病人有杂音；新发杂音或杂音性质变化（海鸥音）最具特征性，提示瓣膜关闭不全 |
| **动脉栓塞** | 25%有症状；左心IE→体循环栓塞（脑最常见，15%~20%）；右心IE→肺栓塞 |
| **周围体征**（现已少见） | 瘀点（锁骨以上皮肤、口腔黏膜、睑结膜）、指/趾甲下线状出血、Roth斑、Osler结节（痛性）、Janeway损害（无痛性） |
| **其他** | 脾大、贫血、杵状指 |

### 急性与亚急性IE鉴别

| 特征 | 急性IE | 亚急性IE |
|------|--------|----------|
| **主要致病菌** | 金黄色葡萄球菌 | 草绿色链球菌 |
| **起病** | 急骤（败血症过程） | 隐匿 |
| **中毒症状** | 明显（高热、寒战） | 轻（低热、盗汗） |
| **感染迁移** | 多见 | 少见 |
| **瓣膜破坏** | 数天内 | 数周至数月 |
| **周围体征** | Janeway损害多见 | Osler结节、Roth斑多见 |

## 并发症

| 系统 | 并发症 |
|------|--------|
| **心脏** | [[心力衰竭]]（最常见，瓣膜穿孔/腱索断裂致急性瓣膜关闭不全）、心肌脓肿（可致传导阻滞）、心包炎 |
| **脑部** | 脑栓塞（最常见，大脑中动脉最常受累）、细菌性脑动脉瘤、脑出血、化脓性脑膜炎、脑脓肿 |
| **肾脏** | 肾梗死、免疫复合物性肾小球肾炎（亚急性者多见）、肾脓肿 |
| **脾脏** | 脾梗死（无症状居多） |
| **血管** | 细菌性动脉瘤（3%~5%）、主动脉近端及窦部多见 |
| **肺部** | 右心IE→肺栓塞→肺坏死/空洞/脓气胸 |

## 辅助检查

### 血培养（诊断基石之一）

**血培养是诊断IE最重要的实验室方法。**

| 操作要点 | 内容 |
|----------|------|
| **亚急性/未用抗生素** | 入院首日每隔1小时采血1次，共3次；次日若未生长，再采3次后开始抗生素治疗 |
| **急性** | 入院后立即每隔1小时采血1次，共3次后开始抗生素治疗 |
| **已用抗生素** | 病情允许时停药2~7天后采血 |
| **采血量** | 每次取周围静脉血20ml，等分作需氧+厌氧培养，至少培养3周 |
| **注意事项** | IE菌血症为持续性，无需发热时采血；每次应更换部位，严格消毒 |

> 约 2.5%~31% 血培养阴性（近期用抗生素、真菌、苛养菌/非典型病原体）。对培养阴性者可考虑 mNGS（宏基因组下一代测序）快速获得病原学诊断。

### 超声心动图（诊断基石之二）

| 方法 | 赘生物检出敏感性（NVE） | 赘生物检出敏感性（PVE） | 特异性 |
|------|:---:|:---:|:---:|
| 经胸超声心动图（TTE） | 75% | 50% | ~90% |
| 经食管超声心动图（TEE） | **96%** | **92%** | ~90% |

TEE 优于 TTE，尤其是赘生物 <3mm、人工瓣膜或胸部透声差者。TTE 阴性或不确定时应行 TEE。

### 其他辅助检查

| 检查 | 意义 |
|------|------|
| **CT** | 瓣周病变检测优于TEE；远处病变和菌血症来源评估；已被纳入IE诊断标准 |
| **MRI** | 神经系统并发症检测优于CT |
| **¹⁸F-FDG PET-CT / SPECT-CT** | 检出心脏和心外隐蔽性感染灶，辅助确诊/排除IE |
| **心电图** | 偶见急性心梗、新发传导阻滞（提示瓣环或室间隔脓肿） |

## 诊断标准（2023 ESC 诊断标准）

确诊需满足：**2项主要标准**，或 **1项主要标准+≥3项次要标准**，或 **5项次要标准**。

### 主要标准

**（一）血培养阳性（符合以下至少一项）**：
1. 两次不同时间血培养检出符合典型IE的致病微生物（草绿色链球菌、牛链球菌、HACEK菌群、金黄色葡萄球菌、社区获得性肠球菌）
2. 持续性菌血症：①2次至少间隔12小时的血培养阳性；②所有3次血培养均阳性，或≥4次多数血培养阳性（首次与末次间隔≥1小时）
3. Q热立克次体1次血培养阳性或I期IgG抗体滴度>1∶800

**（二）影像学阳性证据**：
1. 超声心动图：赘生物、脓肿/假性动脉瘤/心内瘘、瓣膜穿孔或动脉瘤、新发人工瓣膜部分破裂
2. CT/CTA：自体/人工瓣周病灶
3. ¹⁸F-FDG PET-CT或SPECT-CT：自体/人工瓣周等部位活动性病灶

### 次要标准

| 类别 | 内容 |
|------|------|
| **易患因素** | 心脏存在中高危易患因素，或静脉药物成瘾者 |
| **感染发热** | 体温 >38℃ |
| **栓塞播散** | 体/肺循环栓塞/梗死和脓肿；血源性骨关节脓毒性并发症；细菌性动脉瘤；颅内缺血/出血病灶；结膜出血；Janeway损害 |
| **免疫现象** | 肾小球肾炎；Osler结节和Roth斑；类风湿因子阳性 |
| **感染证据** | 血培养阳性但不符合主要标准，或与IE一致的活性致病微生物感染的血清学证据 |

## 治疗

### 抗生素治疗原则

| 原则 | 内容 |
|------|------|
| **早期治疗** | 连续3~6次血培养后立即开始 |
| **联合用药** | 应包括2种具协同作用的杀菌剂（繁殖期+静止期） |
| **长程足量** | NVE 2~6周，PVE 6~8周 |
| **静脉用药** | 保持稳定有效的血药浓度 |
| **药敏指导** | 根据病原体和MIC调整 |

### 经验治疗（病原未知）

| 临床情况 | 推荐方案 |
|----------|---------|
| **社区获得性NVE/晚期PVE** | 覆盖葡萄球菌+链球菌+肠球菌：氨苄西林+耐酶青霉素+庆大霉素三联方案 |
| **早期PVE/医源性NVE** | 覆盖MRSA/MSSA+肠球菌+非HACEK革兰阴性菌：万古霉素（或达托霉素）+庆大霉素+利福平三联方案 |

### 特定病原治疗

| 病原体 | 首选方案 |
|--------|---------|
| **MSSA** | 氯唑西林或头孢唑林单药 |
| **MRSA** | 万古霉素单药 |
| **青霉素敏感链球菌** | 青霉素G、阿莫西林或头孢曲松单药 |
| **青霉素耐药链球菌** | 青霉素G（增量）+庆大霉素 |
| **肠球菌（敏感株）** | 氨苄西林+头孢曲松或氨基糖苷类 |
| **HACEK菌群** | 产酶株→三代头孢菌素（头孢曲松）；不产酶→氨苄西林+庆大霉素 |
| **真菌** | 假丝酵母→高剂量两性霉素B±氟胞嘧啶；曲霉菌→首选伏立康唑；需降低手术门槛 |

### 外科手术适应证

| 时机 | 适应证 |
|------|--------|
| **紧急手术（<24小时）** | 主动脉瓣/二尖瓣IE伴急性重度反流、阻塞或瓣周瘘导致难治性[[心力衰竭]]、肺水肿、心源性休克 |
| **择期手术（<7天）** | ①急性重度反流致症状性心衰或UCG示血流动力学异常；②未能控制的局部感染灶（脓肿、假性动脉瘤、瘘、赘生物增大）；③真菌或多重耐药菌感染；④规范抗感染下血培养仍阳性；⑤≥1次栓塞事件且赘生物 >10mm；⑥赘生物 >10mm伴严重瓣膜狭窄或反流；⑦单个巨大赘生物（>30mm） |

## 特殊类型IE

### 人工瓣膜感染性心内膜炎（PVE）

| 特征 | 早期PVE（术后<1年） | 晚期PVE（术后>1年） |
|------|-------------------|---------------------|
| **致病菌** | 葡萄球菌、革兰阴性杆菌、真菌 | 类似NVE（葡萄球菌、链球菌、肠球菌） |
| **临床特点** | 常不典型，多无发热 | — |
| **抗生素疗程** | 延长至 6~8周 |

> PVE 是IE最严重形式，住院死亡率 20%~40%。预后不良因素：高龄、糖尿病、葡萄球菌/真菌感染、早期PVE、心力衰竭、脑卒中、心内脓肿。

### 静脉药物成瘾者IE（DAIE）

- 主要累及**右心系统**（三尖瓣最常见）
- 致病菌：金黄色葡萄球菌（60%~90%，MRSA为主）
- 特征：持续发热、菌血症、**多发性感染性肺栓塞**（X线可见肺部多处小片状浸润阴影）
- 三尖瓣受累时常无心脏杂音

## 预防

- **最有效措施**：良好的口腔卫生习惯和定期的牙科检查
- 高危牙科操作前30~60分钟预防性用抗生素：阿莫西林/氨苄西林 2g 口服或静脉
- 任何有创操作过程必须严格无菌操作

## 预后

- 院内死亡率 15%~30%
- 主要死因：[[心力衰竭]]、肾衰竭、细菌性栓塞、细菌性动脉瘤破裂或严重感染
