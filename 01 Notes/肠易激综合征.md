# 肠易激综合征

> 肠易激综合征（irritable bowel syndrome，IBS）是一种以**腹痛、腹胀伴排便习惯和（或）粪便性状改变**为主要表现的功能性肠病，缺乏可解释症状的器质性改变，诊断基于症状学标准（罗马 IV 标准）。

## 概述

IBS 是一种常见的功能性胃肠病，全球患病率约 10%~15%，女性略多于男性，以中青年为主。虽不危及生命，但显著影响病人生活质量。其发病机制与内脏高敏感、肠道动力异常、[[肠道微生态]]失衡、肠屏障功能障碍、脑-肠轴失调及精神心理因素等有关。

## 病因与发病机制

| 因素 | 机制 |
|------|------|
| **内脏高敏感** | 肠道对生理性刺激（如扩张、收缩）的感受阈值降低，是 IBS 核心病理生理机制之一 |
| **肠道动力异常** | 结肠动力紊乱：腹泻型动力加快、便秘型动力减慢 |
| **肠道微生态失衡** | 菌群多样性下降，产气菌和致病菌增多，部分病人有**小肠细菌过度生长（SIBO）** |
| **肠黏膜屏障功能障碍** | 肠黏膜通透性增加，低度炎症反应 |
| **脑-肠轴失调** | 精神应激（焦虑、抑郁）通过自主神经和内分泌系统影响肠道功能 |
| **遗传因素** | 部分有家族聚集现象 |

**诱因**：饮食因素（FODMAPs、产气食物、酒精）、肠道感染（**感染后 IBS**），精神心理应激（[[焦虑障碍|焦虑]]、[[抑郁障碍|抑郁]]）。

## 临床表现

| 表现 | 说明 |
|------|------|
| **腹痛/腹部不适** | 反复发作，与排便相关（排便后减轻），部位多变，无进行性加重 |
| **排便习惯改变** | 腹泻（次数增多、稀便/水样便）、便秘（排便费力、硬便）或腹泻便秘交替 |
| **粪便性状改变** | 糊状便/水样便或硬块状便，可有黏液，**绝无脓血** |
| **腹胀** | 白天加重，夜间睡眠后减轻 |
| **其他** | 排便不尽感（里急后重）、消化不良、上腹饱胀 |
| **肠外症状** | 头痛、腰背痛、心悸、尿频、月经不调、焦虑、抑郁 |

### 警报征象（提示器质性疾病）

出现以下情况应警惕器质性疾病而非 IBS：
- 年龄 >50 岁新发起病
- 便血或黑便
- 夜间腹泻
- 进行性腹痛
- 不明原因体重下降
- 贫血
- 实验室检查异常（CRP↑、粪便钙卫蛋白↑）
- 结肠癌家族史

## 诊断

### 罗马 IV 诊断标准（2016）

最近 3 个月内**每周至少发作 1 天**腹痛，且伴有以下 **≥2 项**：

| 标准 | 说明 |
|------|------|
| ① 与排便相关 | 腹痛在排便后减轻或加重 |
| ② 伴排便频率改变 | 排便次数增多或减少 |
| ③ 伴粪便性状改变 | 大便变稀或变硬 |

**诊断前症状出现至少 6 个月，且近 3 个月符合上述标准。**

### 分型（基于粪便性状 — Bristol 粪便分型表）

| 分型 | 硬便/干球便比例 | 稀便/水样便比例 |
|------|-----------------|------------------|
| **IBS-C**（便秘型） | ≥25% | ≤25% |
| **IBS-D**（腹泻型） | ≤25% | ≥25% |
| **IBS-M**（混合型） | ≥25% | ≥25% |
| **IBS-U**（未定型） | <25% | <25% |

> 粪便性状比例判断基于未使用止泻药或缓泻药时的排便。

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| [[炎症性肠病]]（IBD） | 黏液脓血便、发热、贫血、粪便钙卫蛋白↑、结肠镜有器质性改变、内镜下黏膜糜烂/溃疡 |
| [[结直肠癌]] | 便血、体重下降、贫血、结肠镜+活检确诊 |
| 感染性肠炎 | 粪便病原学阳性，急性起病 |
| [[肠结核]] | 结核中毒症状，影像学/活检发现干酪样肉芽肿 |
| [[结直肠常见良性疾病|乳糜泻]] | 小肠绒毛萎缩，麸质过敏，特异性抗体阳性 |
| [[甲状腺功能亢进症|甲状腺功能异常]] | 甲亢（腹泻）、甲减（便秘） |
| 药物性腹泻/便秘 | 药物史（抗生素、泻药、阿片类等） |

## 治疗

IBS 治疗以**消除病人顾虑、改善症状、提高生活质量**为目标，采取个体化综合治疗，主要依赖症状分型。

### 一般治疗

| 措施 | 说明 |
|------|------|
| 建立良好医患关系 | 解释疾病性质（功能性、良性经过），消除恐癌心理 |
| 饮食调整 | 便秘型增加膳食纤维（可溶性）；腹泻型减少产气食物、避免生冷辛辣；排除诱发食物 |
| **低 FODMAP 饮食** | 限制可发酵寡糖、双糖、单糖及多元醇（如小麦、洋葱、牛奶、苹果、蜂蜜等），对改善腹胀和腹痛有证据支持 |
| 规律生活习惯 | 适当运动，充足睡眠，保持排便规律 |
| 心理行为治疗 | 认知行为治疗、催眠疗法、生物反馈等适用于难治性 IBS |

### 药物治疗

| 症状类型 | 药物类别 | 代表药物 | 说明 |
|----------|----------|----------|------|
| **腹痛** | 解痉药 | 匹维溴铵、奥替溴铵、丁溴东莨菪碱 | 短期使用缓解腹痛 |
| **IBS-D**（腹泻型） | 止泻药 | 洛哌丁胺 | 排便前或按需使用 |
| | 5-HT3 受体拮抗剂 | 昂丹司琼 | 减少结肠传输，缓解腹泻 |
| | 肠道微生态调节剂 | 益生菌 | 证据有限但安全性好 |
| | 抗生素 | **利福昔明** | 非吸收性抗生素，适用于 IBS-D，尤其伴 SIBO |
| **IBS-C**（便秘型） | 渗透性泻药 | 聚乙二醇、乳果糖 | 仅增加排便频率，对腹痛改善有限 |
| | 促分泌剂 | **利那洛肽**（GC-C 激动剂）、鲁比前列酮（Cl 通道激活剂） | 增加肠液分泌、加速结肠传输 |
| | 5-HT4 受体激动剂 | 普芦卡必利 | 促进肠道动力 |
| **全分型** | 神经调节剂 | 三环类抗抑郁药（TCA）、SSRI | 改善内脏高敏感和肠-脑轴功能；适用于中重度、难治性 IBS，尤其合并焦虑/抑郁者；低剂量起始 |
| | 肠道微生态调节剂 | 益生菌、益生元 | 改善菌群失衡 |

### 治疗策略

| 病情程度 | 策略 |
|----------|------|
| **轻度** | 健康教育 + 饮食调整 + 必要时对症用药 |
| **中度** | 上述 + 规律对症药物治疗 |
| **重度/难治性** | 上述 + 心理行为治疗 + 神经调节剂（TCA/SSRI），必要时多学科联合 |

## 预后

IBS 为良性过程，不影响生存期。随着综合治疗，症状可明显缓解。但症状易反复，需长期管理。感染后 IBS 部分病人可自愈。

> 应注意：随访中如出现警报征象，应及时复查结肠镜排除器质性疾病。
