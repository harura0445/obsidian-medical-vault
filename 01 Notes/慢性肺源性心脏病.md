# 慢性肺源性心脏病

> 慢性肺源性心脏病（肺心病）是由支气管-肺组织、胸廓或肺血管病变致肺血管阻力增加，产生肺动脉高压，继而右心室结构和/或功能改变的疾病。按病程可分为急性和慢性两类，急性肺心病常见于急性大面积肺栓塞。

## 概述

肺源性心脏病（cor pulmonale）简称肺心病，核心病理环节为 **肺动脉高压 → 右心室负荷增加 → 右心室肥厚/扩大 → 右心衰竭**。

**流行病学要点**：我国 >14 岁人群患病率约 4.8‰，北方高于南方、农村高于城市，随年龄增长而增加。吸烟者患病率明显高于不吸烟者。冬春季节和气候骤然变化时易出现急性发作。

## 病因

按原发病的不同部位分类：

| 病因类别 | 占比/举例 | 说明 |
|----------|----------|------|
| **支气管、肺疾病** | **占 80%~90%** | 以[[慢性阻塞性肺疾病]]（COPD）最为多见；其他包括间质性肺疾病、[[支气管哮喘]]、支气管扩张、肺结核等 |
| **胸廓运动障碍性疾病** | 较少见 | 严重胸廓/脊椎畸形、神经肌肉疾病 → 胸廓活动受限、肺受压、支气管扭曲、反复感染 → 肺气肿或纤维化 |
| **肺血管疾病** | — | 特发性肺动脉高压、慢性栓塞性肺动脉高压、肺动脉炎 |
| **其他** | — | 原发性肺泡通气不足、睡眠呼吸暂停低通气综合征（OSAHS） |

## 发病机制

### 一、肺动脉高压的形成

#### 1. 肺血管阻力增加的功能性因素（肺血管收缩）

**缺氧是肺动脉高压形成最重要的因素**。高碳酸血症和呼吸性酸中毒可加重肺血管收缩。

| 机制 | 详情 |
|------|------|
| **缩血管活性物质增多** | 白三烯、5-羟色胺（5-HT）、血管紧张素Ⅱ、血小板活化因子（PAF）等 |
| **内皮因子失衡** | 内皮源性舒张因子（EDRF）与内皮源性收缩因子（EDCF）平衡失调 |
| **平滑肌细胞钙内流** | 缺氧使平滑肌细胞膜对 Ca²⁺ 通透性增加，细胞内 Ca²⁺ 增高，肌肉兴奋-收缩偶联增强 |
| **高碳酸血症** | H⁺ 产生过多，使血管对缺氧的收缩敏感性增强 |

#### 2. 肺血管阻力增加的解剖学因素（血管结构改变）

| 机制 | 详情 |
|------|------|
| **肺血管重塑** | 慢性缺氧 → 多种生长因子刺激管壁平滑肌细胞、内膜弹力纤维及胶原纤维增生 |
| **肺小动脉炎** | 慢阻肺病及支气管周围炎反复发作，累及邻近肺小动脉 → 管壁增厚、管腔狭窄/闭塞 |
| **肺泡毛细血管受压/毁损** | 肺气肿 → 肺泡内压增高压迫毛细血管；肺泡壁破裂致毛细血管网毁损（减损 >70% 时阻力明显增大） |
| **血栓形成** | 部分病人存在多发性肺微小动脉原位血栓形成 |

#### 3. 血液黏稠度增加和血容量增多

- 慢性缺氧 → 继发性红细胞增多 → 血液黏稠度增加
- 缺氧 → 醛固酮增加 + 肾小动脉收缩 → 水钠潴留 → 血容量增多

### 二、心脏病变与心力衰竭

```text
肺循环阻力增加 → 肺动脉高压 → 右心室代偿性肥厚
    ↓（持续进展，尤其急性加重期）
右心失代偿 → 右心室扩大 → 右心衰竭
```

### 三、其他重要脏器的损害

缺氧和高碳酸血症可导致脑、肝、肾、胃肠及内分泌、血液系统等多脏器功能损害。

## 临床表现

### 代偿期与失代偿期对比

| | 肺、心功能代偿期 | 肺、心功能失代偿期 |
|------|----------|----------|
| **核心特点** | 右心室肥厚，功能尚可代偿 | [[呼吸衰竭]] + 右心[[心力衰竭]] |
| **症状** | 咳嗽、咳痰、气促，活动后心悸、[[呼吸困难]]、乏力、劳动耐力下降 | **呼吸衰竭**：呼吸困难加重，头痛、失眠、白天嗜睡，甚至肺性脑病（表情淡漠、神志恍惚、谵妄）**右心衰竭**：明显气促，心悸、食欲缺乏、腹胀、恶心 |
| **呼吸系统体征** | 不同程度发绀，原发肺疾病体征（肺气肿、干湿啰音） | 发绀明显，球结膜充血水肿，严重者视网膜血管扩张、视盘水肿（颅内压升高） |
| **循环系统体征** | P2 > A2，三尖瓣区收缩期杂音，剑突下心脏搏动增强 | 颈静脉怒张，心率增快、[[心律失常]]，肝大压痛、肝颈静脉回流征阳性，下肢水肿，重者腹腔积液 |
| **其他体征** | 部分因肺气肿致颈静脉充盈、横膈下降肝界下移 | 皮肤潮红、多汗（高碳酸血症致周围血管扩张），腱反射减弱或消失、病理反射 |

## 辅助检查

### X 线检查

除肺、胸基础疾病及肺部感染征象外，肺动脉高压的 X 线征象包括：

| 征象 | 标准 |
|------|------|
| 右下肺动脉干扩张 | 横径 **≥15 mm**，或右下肺动脉横径与气管横径比值 **≥1.07**，或动态观察增宽 >2 mm |
| 肺动脉段突出 | 突出或其高度 **≥3 mm** |
| 中心肺动脉扩张、外周分支纤细 | 形成"**残根**"征 |
| 圆锥部显著凸出 | 右前斜位 45° 高度 **≥7 mm** |
| 右心室增大 | 心尖上凸 |

### 心电图检查

诊断阳性率 60.1%~88.2%。慢性肺心病心电图诊断标准（**具有一条即可诊断**）：

| 序号 | 标准 |
|------|------|
| ① | 额面平均电轴 **≥ +90°** |
| ② | V₁ R/S ≥ 1 |
| ③ | 重度顺钟向转位（V₅ R/S ≤ 1） |
| ④ | **RV₁ + SV₅ ≥ 1.05 mV** |
| ⑤ | aVR 导联 R/S 或 R/Q ≥ 1 |
| ⑥ | V₁~V₃ 呈 QS、Qr 或 qr（酷似心肌梗死，需鉴别） |
| ⑦ | **肺型 P 波** |

典型表现：电轴右偏、顺钟向转位、肺性 P 波、V₁ 导联 QRS 波群呈 qR，V₅ R/S < 1。

### 超声心动图

诊断阳性率 60.6%~87.0%。诊断标准：

| 标准 |
|------|
| 右心室流出道内径 **≥ 30 mm** |
| 右心室内径 **≥ 20 mm** |
| 右心室前壁厚度 ≥ 5 mm 或前壁搏动幅度增强 |
| 左、右心室内径比值 **< 2** |
| 右肺动脉内径 ≥ 18 mm 或肺动脉干 ≥ 20 mm |
| 右室流出道/左房内径 > 1.4 |
| 肺动脉瓣曲线出现肺动脉高压征象（a 波低平或 < 2 mm，或有收缩中期关闭征等） |

### 其他检查

| 检查 | 表现 |
|------|------|
| **血气分析** | 低氧血症，可出现呼吸衰竭或合并高碳酸血症 |
| **血液化验** | 红细胞及血红蛋白可升高；全血黏度及血浆黏度可增加；心功能不全时可伴肝肾功能异常 |
| **痰病原学** | 指导抗生素选用 |

## 诊断与鉴别诊断

### 诊断标准

根据以下条件综合判断：
1. 有慢阻肺病或其他胸肺疾病病史
2. 出现肺动脉压增高、右心室增大或右心功能不全的征象：P2 > A2、剑突下心脏搏动增强、颈静脉怒张、肝大压痛、肝颈静脉反流征阳性、下肢水肿等
3. 心电图、X 线胸片、超声心动图有肺动脉增宽和右心增大/肥厚的征象

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| **冠心病** | 典型心绞痛、心肌梗死病史或心电图表现；左心衰竭发作史；有[[高血压]]、高脂血症、[[糖尿病|糖尿病史]]；体格检查、X 线、心电图、超声心动图以**左心室肥厚**为主；冠脉造影可确诊 |
| **风湿性心脏病** | 多有风湿性关节炎和心肌炎病史；可累及二尖瓣、主动脉瓣等多瓣膜；超声心动图有特殊表现 |
| **原发性心肌病** | 多为全心增大；无慢性支气管、肺疾病史；无肺动脉高压的 X 线表现 |

## 治疗

### 代偿期治疗

综合治疗延缓基础疾病进展：预防感染、减少/避免急性加重、加强康复锻炼和营养，必要时长期家庭氧疗或家庭无创呼吸机治疗。

### 失代偿期治疗

治疗原则：**积极控制感染，通畅呼吸道，改善呼吸功能，纠正缺氧和/或二氧化碳潴留，控制[[呼吸衰竭]]和[[心力衰竭]]，防治并发症。**

#### 1. 控制感染

呼吸系统感染是引起慢性肺心病急性加重的最常见原因，需积极使用抗生素控制感染。

#### 2. 控制心力衰竭

一般在积极控制感染、改善呼吸功能、纠正缺氧和二氧化碳潴留后，心力衰竭可改善，无需常规使用利尿药和正性肌力药。对上述治疗无效或严重心衰病人，可选用：

| 药物类别 | 原则 | 具体用法 |
|----------|------|----------|
| **利尿药** | 作用温和、联合保钾利尿药、**小剂量、短疗程**。注意：易致低钾、低氯性碱中毒、痰液黏稠和血液浓缩 | 氢氯噻嗪 25 mg，1~3 次/日 + 螺内酯 20~40 mg，1~2 次/日 |
| **正性肌力药（洋地黄类）** | 慢性缺氧及感染使病人对洋地黄耐受性低、易中毒。**指征**：①感染已控制、呼吸功能已改善，利尿后右心功能无改善者；②以右心衰竭为主要表现而无明显感染者；③合并室上性快速型心律失常（室上速、房颤心室率 >100 次/分）；④合并急性左心衰竭。**原则**：作用快、排泄快的药物，**小剂量**（常规剂量 1/2~2/3） | 毒毛花苷 K 0.125~0.25 mg，或毛花苷丙 0.2~0.4 mg + 10% 葡萄糖缓慢静注 |
| **血管扩张药** | 对慢阻肺病、间质性肺病所致肺心病者，可能加重通气血流比例失调和缺氧，且扩张体循环引起血压下降，**临床应用受限** | — |

> 用药前注意纠正缺氧，防治低钾血症。低氧血症、感染等均可使心率增快，故**不宜以心率作为洋地黄应用和疗效考核指征**。

#### 3. 防治并发症

| 并发症 | 处理要点 |
|--------|----------|
| **肺性脑病** | 由呼吸衰竭引起的神经精神障碍综合征。需除外脑血管疾病、感染中毒性脑病、严重电解质紊乱。治疗参见呼吸衰竭处理 |
| **酸碱失衡及电解质紊乱** | 呼酸以通畅气道、纠正缺氧和解除 CO₂ 潴留为主。呼酸 + 代酸：pH < 7.2 时补 5% 碳酸氢钠。呼酸 + 代碱：常合并低钠、低钾、低氯，应补充纠正（低钾低氯性代碱多为医源性，应注意预防） |
| **心律失常** | 多为房性期前收缩及阵发性室上性心动过速，以**紊乱性房性心动过速**最具特征性。控制感染、纠正缺氧和电解质紊乱后多可消失；持续存在者选用抗心律失常药物 |
| **休克** | 发生率不高但预后不良。原因：严重感染、上消化道出血、严重心力衰竭或心律失常 |
| **消化道出血** | 因感染、呼吸衰竭、心衰致胃肠道淤血及糖皮质激素应用等诱发 |
| **DIC** | 弥散性血管内凝血 |
| **深静脉血栓形成** | 低剂量普通肝素或低分子量肝素用于预防 |

## 预后

慢性肺心病常反复急性加重，随肺功能损害病情逐渐加重，病死率约 10%~15%。经积极治疗可延长寿命、提高生活质量。

## 预防

主要是防治支气管、肺和肺血管等基础疾病，预防肺动脉高压和慢性肺心病的发生发展。对慢阻肺病患者积极控制病情，减少急性加重，可参阅[[慢性阻塞性肺疾病]]相关章节。
