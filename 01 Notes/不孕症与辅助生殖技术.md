# 不孕症与辅助生殖技术

## 概述

女性未避孕正常性生活至少 **12 个月**未孕称为不孕症（infertility），对男性则称为不育症。我国不孕症发病率为 7%~10%。

- **原发性不孕**：既往从未妊娠
- **继发性不孕**：既往有过妊娠

## 不孕症的病因

### 女方因素

| 因素 | 占比 | 常见病因 |
|------|------|----------|
| **盆腔因素** | 约 35% | 输卵管病变（梗阻、积水）、子宫病变（肌瘤、息肉、粘连）、子宫内膜异位症、生殖器畸形 |
| **排卵障碍** | 25%~35% | 下丘脑病变、垂体病变（高催乳素血症）、卵巢病变（PCOS、POI）、其他内分泌疾病 |
| **卵巢储备功能下降** | — | 年龄 >35~37 岁，卵母细胞数量和质量下降 |

### 男方因素

- 精液异常：少精子症、弱精子症、畸形精子症、无精子症
- 男性性功能障碍：勃起功能障碍、不射精/逆行射精
- 免疫因素

### 不明原因不孕症

占 10%~20%，双方不孕常规检查均未发现异常。

## 诊断

**夫妇双方同时就诊**，主要检查：
1. 精液分析（男方首选）
2. 排卵功能评估（超声监测+B超+激素测定+基础体温）
3. 输卵管通畅性检查（子宫输卵管造影）
4. 妇科超声、宫腔镜/腹腔镜（必要时）

### 女方检查流程

| 检查 | 内容 |
|------|------|
| **病史** | 现病史、月经史、性生活史、婚育史、既往史 |
| **体检** | 身高、体重、体脂分布、多毛、痤疮、黑棘皮征；妇科检查 |
| **超声** | 子宫卵巢形态、窦状卵泡计数（AFC） |
| **激素测定** | 月经第 2~4 日：FSH、LH、E₂、T、PRL、P、**AMH**（反映卵巢储备） |
| **输卵管通畅性** | 子宫输卵管 X 线造影（首选），月经干净后 3~7 日进行 |

## 治疗

### 对因治疗

1. **输卵管病变**：期待疗法或腹腔镜下输卵管成形术。严重积水→输卵管切除/结扎
2. **子宫病变**：黏膜下肌瘤、息肉、宫腔粘连→手术治疗
3. **子宫内膜异位症**：腹腔镜诊断和治疗；药物抑制卵巢治疗不提高妊娠率。Ⅰ/Ⅱ 期 EFI>4 分→促排卵+IUI；Ⅲ/Ⅳ 期或 EFI≤4→IVF-ET
4. **排卵障碍**：诱导排卵

### 诱导排卵药物

| 药物 | 机制与用法 |
|------|-----------|
| **氯米芬（CC）** | 竞争雌激素受体→负反馈解除→FSH/LH↑。月经第 3~5 日始，50mg/d ×5 日。排卵率 70%~80% |
| **来曲唑（LE）** | 芳香化酶抑制剂→低雌激素→FSH↑。2.5~5mg/d，适应证同 CC |
| 尿促性素（hMG） | 绝经后尿提取 FSH+LH，75~150U/d 肌注 |
| 绒促性素（hCG） | 模拟 LH 峰诱发排卵，5000~10000U 肌注 |
| 溴隐亭 | 多巴胺激动剂，抑制 PRL，适用于高催乳素血症 |

## 辅助生殖技术（ART）

### 人工授精（AI）

将精子通过非性交方式注入女性生殖道内。包括：
- **夫精人工授精（AIH）** 和 **供精人工授精（AID）**

**IUI（宫腔内人工授精）**最常用：精液洗涤后经导管注入宫腔。适应证：男性不育（少/弱精）、子宫颈因素、不明原因不育。

### 体外受精-胚胎移植（IVF-ET，试管婴儿）

**适应证**：输卵管性不孕、内异症、排卵障碍、男性因素、不明原因不孕等其他治疗失败者。

主要步骤：
1. 药物刺激卵巢（控制性超促排卵）
2. 阴道超声引导下取卵
3. 体外受精 + 胚胎培养 3~5 日
4. 胚胎移植至子宫腔 + 黄体支持
5. 移植 2 周后血/尿 hCG 确定妊娠

### 衍生技术

| 技术 | 适应证 |
|------|--------|
| **ICSI**（卵胞质内单精子注射） | 严重少/弱/畸形精子症、不可逆梗阻性无精子症、前次 IVF 受精失败 |
| **PGT**（胚胎植入前遗传学检测） | 单基因遗传病、染色体结构异常、非整倍体筛查（PGT-M/SR/A） |
| 配子/胚胎冷冻 | 全胚冷冻策略 → 冻融胚胎移植（FET） |

### 并发症

| 并发症 | 要点 |
|--------|------|
| **OHSS** | 卵巢过度刺激综合征：血管通透性↑→腹水、胸水、血液浓缩、血栓。PCOS 为高危因素。扩容、防止血栓 |
| **多胎妊娠** | 增加母婴并发症。目前推荐**选择性单胚胎移植（eSET）** |
| 取卵并发症 | 出血、感染、邻近器官损伤 |

> 我国 2003 年《人类辅助生殖技术规范》限制移植胚胎数 ≤2~3 枚。目前广泛推行单胚胎移植以杜绝三胎及以上多胎妊娠。
