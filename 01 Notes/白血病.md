# 白血病（Leukemia）

白血病是一类**造血干/祖细胞的恶性克隆性疾病**。白血病细胞自我更新增强、增殖失控、分化障碍、凋亡受阻，而停滞在细胞发育的不同阶段。骨髓或其他造血组织中，白血病细胞大量增生累积，使正常造血受抑并浸润其他器官或组织。临床以[[贫血]]、出血、感染及白血病细胞组织/器官浸润为主要表现。

![[内科-白血病-概念.webp]]

## 分类

按自然病程及细胞分化程度分为两大类：

| 类型 | 特点 |
|------|------|
| **[[急性白血病]]** | 起病急、病情重，自然病程 ≤ 6个月；骨髓及外周血中主要为异常的原始细胞和早期幼稚细胞 |
| **[[慢性白血病]]** | 起病隐匿、发展缓慢，自然病程数年；骨髓和外周血以较成熟阶段的细胞占多数 |

## 流行病学

- 我国发病率约 **3～4/10万**人口
- **急性白血病（AL）** ：**慢性白血病（CL）** = **5.5 : 1**
  - 急性髓系白血病（AML）：1.62/10万
  - 急性淋巴细胞白血病（ALL）：0.69/10万
  - 慢性髓性白血病（CML）：0.7/10万
  - 慢性淋巴细胞白血病（CLL）：0.05/10万

## 病因与危险因素

| 类别 | 因素 |
|------|------|
| **物理因素** | 电离辐射等 |
| **化学因素** | 有机苯、乙双吗啉、抗肿瘤药物 |
| **生物因素** | 病毒感染、[[免疫治疗药物|免疫]]异常 |
| **遗传因素** | [[21三体综合征|Down综合征]]、家族性白血病 |
| **其他血液病** | [[骨髓增生异常性肿瘤]]（MDS）、[[阵发性睡眠性血红蛋白尿]]（PNH） |

## 预后

白血病预后取决于多种因素：分型（ALL儿童预后较好）、遗传学异常（如t(15;17)的APL预后较好，TP53异常预后差）、年龄、白细胞计数、治疗反应（MRD转阴者预后较好）及是否接受HSCT。

## 预防

避免电离辐射、有机苯等化学物质暴露，积极治疗MDS等可能转化为白血病的血液疾病。
