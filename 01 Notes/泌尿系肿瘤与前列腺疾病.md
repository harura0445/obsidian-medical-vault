# 泌尿系肿瘤与前列腺疾病

## 肾细胞癌（肾癌）

最常见的肾脏恶性肿瘤（占肾恶性肿瘤的80%~90%）。**好发50~70岁**，男:女=2:1。

### 病理

- 起源于肾小管上皮
- 透明细胞癌（最常见，~75%）、乳头状细胞癌、嫌色细胞癌
- **转移**：直接侵犯肾周脂肪/静脉→肾静脉癌栓→下腔静脉；淋巴转移；血行转移至**肺、骨、肝**

### 临床表现

**经典三联征**（仅见于晚期，约占10%）：**肉眼血尿（无痛性全程）**+**腰痛**+**腹部肿块**

早期多无症状，体检偶然发现（影像学肾占位）。肾外表现（副癌综合征）：发热、高钙血症（PTHrP）、红细胞增多（EPO分泌）、高血压（肾素分泌）。

### 诊断

| 检查 | 用途 |
|------|------|
| **腹部增强CT** | **首选确诊**——肾脏占位+强化特征+Bosniak分级 |
| 超声 | 筛查（实性占位、回声不均） |
| MRI | CT不确定、静脉癌栓评估 |
| 胸腹盆腔CT | 分期——明确有无远处转移 |

**鉴别**：肾错构瘤（血管平滑肌脂肪瘤→超声高回声/CT含脂肪成分，良性，无需手术）。

### 肾盂癌

来源于肾盂尿路上皮。**无痛性全程肉眼血尿**（最常见，比肾癌更突出）。治疗：根治性肾输尿管切除术+膀胱袖状切除。

> **肾盂癌与肾细胞癌的区别**：肾盂癌血尿更早、更明显，影像学见肾盂内充盈缺损，病理为尿路上皮癌。

### 治疗

| 分期 | 治疗 |
|------|------|
| **局限性肾癌** | **根治性肾切除术**（T1期可行肾部分切除术/保留肾单位手术NSS） |
| 局部晚期 | 根治性肾切除术+淋巴结清扫 |
| 转移性 | 靶向治疗（舒尼替尼/培唑帕尼等TKI）+免疫治疗（PD-1抑制剂） |

## 膀胱癌

**最常见的泌尿系统恶性肿瘤**。

### 病因

- **吸烟**（最重要危险因素）
- 职业暴露（芳香胺类——染料/橡胶/皮革工业）
- 慢性刺激/感染（埃及血吸虫感染→鳞癌）

### 病理

| 类型 | 占比 | 特点 |
|------|------|------|
| **尿路上皮癌（移行细胞癌）** | **>90%** | 膀胱癌最常见类型 |
| 鳞癌 | <5% | 慢性感染相关 |
| 腺癌 | <2% | 罕见 |

**分期重点**：**非肌层浸润性**（Ta/T1，表浅） vs **肌层浸润性**（T2及以上，较深）——治疗策略截然不同。

### 临床表现

| 表现 | 特点 |
|------|------|
| **无痛性肉眼血尿** | **最常见、最早的症状**——间歇性、全程性，血尿可自行停止（给病人错觉） |
| 膀胱刺激征 | 原位癌（CIS）→尿频、尿急、尿痛 |

### 诊断

| 检查 | 用途 |
|------|------|
| **膀胱镜+活检** | **诊断金标准**——直视肿瘤+TURBT病理分期 |
| 尿脱落细胞学 | 筛查（高级别/CIS阳性率高，低级别阳性率低） |
| 超声/CT尿路造影 | 初步筛查+上尿路评估 |

### 治疗

| 类型 | 治疗 |
|------|------|
| **非肌层浸润性（Ta/T1）** | **TURBT**（经尿道膀胱肿瘤切除术）+ **膀胱灌注**（化疗药/卡介苗BCG） |
| **肌层浸润性（T2+）** | **根治性膀胱切除术**+尿流改道+新辅助化疗 |
| 转移性 | 化疗（以顺铂为基础的联合化疗）+免疫治疗（PD-1/PD-L1抑制剂） |

## 前列腺增生（BPH）

老年男性常见病，良性病变。发病率随年龄增长上升→60岁以上约60%，80岁以上约80%。

### 病理生理

双氢睾酮（DHT）驱动→前列腺移行带（尿道周围）增生→尿道受压→**膀胱出口梗阻**。

### 临床表现

- **储尿期症状**：尿频（最早出现）、尿急、夜尿增多
- **排尿期症状**：排尿等待、尿线细弱、排尿费力、排尿中断、**终末滴沥**
- **并发症**：急性尿潴留（饮酒/受凉/憋尿诱发）、膀胱结石、反复尿路感染、肾积水→肾功能不全

### 诊断

| 检查 | 用途 |
|------|------|
| **直肠指诊** | 判断前列腺大小、质地、有无结节 |
| **PSA** | 排除前列腺癌（必须查！） |
| 超声 | 测残余尿、前列腺体积、肾积水 |
| 尿流率 | 最大尿流率<10ml/s提示梗阻 |

### 治疗

| 方法 | 适用 |
|------|------|
| 观察等待 | 轻症，IPSS<7分 |
| **药物** | α₁受体阻断药（坦索罗辛，松弛膀胱颈）为首选 → [[治疗前列腺增生的药物]]；5α还原酶抑制剂（非那雄胺，缩小前列腺体积，适用于体积>40ml者） |
| **手术（TURP）** | 中重度（IPSS>19分）、药物治疗失败、并发症（尿潴留/结石/肾积水）——**经尿道前列腺电切术**为金标准 |

## 前列腺癌

### 流行病学与危险因素

- 欧美最常见男性恶性肿瘤，我国发病率逐年增高
- 危险因素：高龄、家族史、高脂肪饮食

### 临床表现

**早期多无症状**。进展后：排尿困难（易与BPH混淆）、血尿、骨转移（骨痛——最常见远处转移，以成骨性转移为主）。

### 诊断

| 检查 | 要点 |
|------|------|
| **PSA** | 筛查首选——PSA>4ng/ml需活检 |
| **直肠指诊** | 前列腺硬结/质地硬、表面不平 |
| **前列腺穿刺活检** | **确诊金标准**——经直肠超声引导下系统穿刺（12针） |
| MRI | 评估局部浸润 |
| **同位素骨扫描** | 骨转移筛查（PSA>20ng/ml或高危者常规做） |

**Gleason评分**：评估肿瘤分化程度（病理分级），2~10分，越高分化越差。

### 治疗

| 分期/危险度 | 治疗 |
|-------------|------|
| **局限性/局部晚期** | **根治性前列腺切除术**（开放/腹腔镜/机器人）或根治性放疗 |
| 低危无症状 | 主动监测（定期PSA+活检） |
| 局部晚期高危 | 放疗+内分泌治疗 |
| **转移性** | **内分泌治疗**（药物/手术去势+抗雄激素）——基础治疗 |

> **前列腺癌与BPH鉴别**：PSA持续升高+直肠指诊质硬结节+影像学异常→活检确诊。
> 内分泌治疗：GnRH激动剂（戈舍瑞林）→药物去势 + 抗雄激素（比卡鲁胺）。
