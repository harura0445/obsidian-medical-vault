# 绝经综合征

![[04 Attachments/妇产科-内分泌_p31.webp]]

## 概述

绝经指月经的永久性停止，属回顾性临床诊断：40岁以上女性停经≥12个月，排除妊娠及其他导致闭经的疾病后可诊断。本质是[[女性生殖系统生理|卵巢功能]]衰竭。绝经相关症状与雌激素水平下降有关，详见[[女性生殖系统生理|女性生殖内分泌变化]]。GSM与外阴阴道萎缩相关，可参考[[外阴及阴道炎|萎缩性阴道炎]]。绝经后骨质疏松、心血管疾病等远期问题需长期管理。POI是40岁前的提前绝经，处理详见[[闭经]]卵巢性闭经部分。

| 概念 | 定义 |
|------|------|
| **围绝经期** | 卵巢功能开始衰退至末次月经后1年 |
| **绝经综合征（MPS）** | 绝经前后因性激素波动或减少所致的一系列躯体及精神心理症状 |
| **自然绝经** | 卵泡耗竭，残余卵泡对促性腺激素丧失反应 |
| **人工绝经** | 双侧卵巢手术切除/放射照射/化疗所致（更易发生MPS） |

中国女性围绝经期起始平均年龄46岁，绝经年龄多在48～52岁，中位绝经年龄49岁。40～45岁绝经称为早绝经。

## 病理生理变化

| 激素 | 变化 |
|------|------|
| **雌激素** | 绝经过渡期波动大；绝经后主要来自肾上腺和卵巢雄烯二酮经芳香化酶转化的E₁（E₂/E₁<1） |
| **孕酮** | 绝经过渡期黄体功能不良→分泌减少；绝经后无分泌 |
| **雄激素** | 总水平下降；睾酮因LH刺激可较绝经前增高 |
| **FSH/LH** | 绝经过渡期FSH波动性升高（≥25IU/L提示进入晚期）；绝经后FSH、LH明显升高，FSH/LH>1 |
| **AMH** | 绝经过渡期早期即明显下降，较E₂下降早且明显 |
| **抑制素B** | 变化趋势与AMH一致，可能更为敏感 |

## 临床表现

大多数女性存在绝经相关症状困扰。

### 近期症状

| 症状类别 | 表现 |
|---------|------|
| **月经改变** | 月经周期不规则、经期延长、经量增多或减少（稀发排卵/无排卵） |
| **血管舒缩症状** | 潮热、多汗（特征性症状）。起自前胸→头颈部→全身，持续数秒至数分钟，夜间/应激易促发。可持续1～2年或更长 |
| **精神心理症状** | 注意力不集中、情绪波动（易怒、焦虑、抑郁）、记忆力减退、睡眠障碍 |
| **躯体症状** | 乏力虚弱、肌肉骨骼关节疼痛 |

### 远期症状

| 症状 | 特点 |
|------|------|
| **绝经生殖泌尿综合征（GSM）** | >50%绝经后女性发生。外阴阴道萎缩、干涩、烧灼、瘙痒、性交痛；尿频、尿急、反复下尿路感染 |
| **骨质疏松** | 绝经早期骨量快速丢失。最常见椎体；可致压缩性骨折、身高缩短、驼背 |
| **心血管疾病和代谢异常** | 体重增加、糖脂代谢异常；动脉硬化、冠心病风险增加 |

## 诊断

根据病史及临床表现诊断，排除器质性疾病及精神类疾病。

**辅助检查**：

| 检查 | 发现 |
|------|------|
| **FSH、E₂** | 绝经过渡期FSH>10IU/L提示卵巢储备下降；FSH>40IU/L且E₂<10～20pg/ml提示卵巢衰竭 |
| **AMH** | <1.1ng/ml提示卵巢储备下降；<0.2ng/ml提示即将绝经 |
| **超声** | 窦状卵泡计数减少，卵巢体积缩小 |
| **骨密度** | T值≤-2.5SD诊断骨质疏松；-2.5～-1SD为低骨量 |

## 治疗

### 健康指导

心理调适；健康生活方式（合理饮食、适度锻炼、保持体重）；补充钙剂（1500mg/d）和维生素D（400～500IU/d）。

### 绝经激素治疗（MHT）

![[04 Attachments/妇产科-内分泌_p36.webp]]

对绝经相关症状最有效的治疗方法。年龄<60岁或绝经10年内、无禁忌证者受益风险比最高。

#### 适应证

①绝经相关症状（血管舒缩症状、精神神经症状）；②GSM（生殖道干燥、反复泌尿系统感染等）；③低骨量、骨质疏松症及骨折风险；④过早低雌激素状态（POI、手术绝经等）。

#### 禁忌证

已知或可疑妊娠；原因不明阴道流血；已知或可疑乳腺癌/性激素相关恶性肿瘤；最近6个月内活动性静脉或动脉血栓栓塞性疾病；严重肝肾功能不全。

#### 慎用情况

子宫肌瘤、子宫内膜异位症/子宫腺肌病、子宫内膜增生病史、血栓形成倾向、胆石症、免疫系统疾病（SLE、RA等）、乳腺良性疾病及乳腺癌家族史、癫痫、偏头痛、哮喘等。

#### 常用药物

| 类别 | 药物 |
|------|------|
| **口服雌激素** | 17β-雌二醇、戊酸雌二醇、结合雌激素 |
| **口服孕激素** | 微粒化孕酮（天然）、地屈孕酮（接近天然）、醋酸甲羟孕酮、炔诺酮、屈螺酮 |
| **复方制剂** | 雌二醇/雌二醇地屈孕酮片、戊酸雌二醇/戊酸雌二醇醋酸环丙孕酮片、雌二醇屈螺酮片 |
| **替勃龙** | 组织选择性雌激素活性调节剂（无需加孕激素） |
| **经皮雌激素** | 雌二醇凝胶、半水合雌二醇贴片（VTE、心血管事件、胆囊疾病风险低于口服） |
| **经阴道激素** | 普罗雌烯、雌三醇乳膏（局部作用，对全身影响小） |

#### 方案选择

| 方案 | 适用 |
|------|------|
| **单孕激素** | 绝经过渡期早期，调整周期（后半周期/连续/LNG-IUS） |
| **单雌激素** | 已切除子宫者 |
| **雌孕激素序贯** | 有完整子宫、希望有月经样出血者 |
| **雌孕激素连续联合** | 绝经≥1年，不想有周期性出血者 |
| **替勃龙** | 绝经≥1年，不愿有出血者（非预期出血少） |
| **阴道局部雌激素** | GSM首选，可单独使用或配合全身MHT |

#### 不良反应及风险

- **子宫出血**：非预期出血应查明原因，必要时宫腔镜排除内膜病变
- **肿瘤**：有子宫者长期单用雌激素→内膜癌风险↑（加孕激素可降低）；MHT与乳腺癌关系复杂（天然孕激素/地屈孕酮风险低于合成孕激素）
- **VTE**：口服MHT增加风险，经皮雌激素不增加；天然孕激素VTE风险小于合成孕激素

#### 随访

初始治疗1、3、6、12个月复诊评估，以后每年至少1次全面评估。

### 非激素治疗

中药/植物药（黑升麻提取物、谷维素）；SSRI（盐酸帕罗西汀20mg/d）；镇静药（睡眠障碍）；阴道保湿剂/润滑剂。

## 预后与随访

绝经是女性必经的生理过程。通过积极心理调适、生活方式调整和必要的医疗干预（MHT），可缓解症状、提高生活质量。应每年健康体检，多学科共同管理。
