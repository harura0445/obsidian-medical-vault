# 过敏性紫癜

> 以IgA免疫复合物沉积为主要特征，累及细小血管和毛细血管，以非血小板减少性可触性紫癜、腹痛、关节炎、肾炎为特征的系统性血管炎。

## 概述

过敏性紫癜又称IgA血管炎，是一种**白细胞破裂性血管炎**，常见于儿童和青少年，男性多于女性，秋冬季相对高发。多数有前驱感染史。

## 病因

尚不明确，可能相关因素：

| 因素 | 举例 |
|------|------|
| **感染**（最常见） | 乙型溶血性链球菌上呼吸道感染、幽门螺杆菌、肺炎支原体、副流感病毒 |
| 药物 | 克拉霉素、阿莫西林、头孢菌素、保泰松 |
| 遗传 | HLA基因、家族性地中海基因等 |

## 发病机制

以**IgA介导的体液免疫异常**为主：

1. 感染原等激活遗传易感者的T细胞 → T细胞功能紊乱
2. B细胞多克隆活化 → 分泌IgA、IgG、IgM及炎症因子
3. 形成**IgA免疫复合物** → **IgA1沉积于小血管壁**引发炎症反应和组织损伤
4. 大分子IgA1-IgG循环免疫复合物沉积于肾脏 → **紫癜性肾炎**

## 分型

| 分型 | 主要表现 |
|------|----------|
| **单纯型**（皮肤型） | 仅皮肤紫癜 |
| **关节型** | 皮肤紫癜 + 关节肿痛 |
| **腹型** | 皮肤紫癜 + 胃肠道症状 |
| **肾型** | 皮肤紫癜 + 肾脏损害 |
| **混合型** | 上述两型以上并存 |

## 临床表现

多数患者发病前**1~3周**有上呼吸道感染等前驱症状。

### 1. 皮肤紫癜（最常见）

| 特点 | 描述 |
|------|------|
| 性质 | **可触性**紫癜（略高起皮肤），紫红色，压之不褪色 |
| 分布 | 四肢远端和臀部多见，伸侧为主，**对称性** |
| 演变 | 7~14天消退，可成批反复出现，严重可融合成疱或中心坏死 |

### 2. 胃肠道症状（腹型）

- **阵发性绞痛**，压痛但无腹肌紧张，反跳痛少见
- 可伴呕吐、腹泻、便血
- 并发症：肠套叠、肠梗阻、肠穿孔、出血性小肠炎
- 腹部症状可与紫癜同时发生，偶可先于紫癜

### 3. 关节症状（关节型）

- 膝、踝、肘、腕关节肿痛及功能障碍
- 游走性、反复性发作，数日而愈
- **不遗留关节畸形**

### 4. 肾脏损害（肾型）

- 血尿、蛋白尿
- 10%~20%的青少年和成人出现进行性肾功能损害
- 可发展为慢性肾炎或肾病综合征

### 5. 其他

睾丸炎、头痛、咯血、间质性肺炎、心肌炎、神经系统受累等（少见）。

## 实验室检查

| 检查 | 结果 |
|------|------|
| 血小板计数 | **正常或升高**（与ITP的关键鉴别） |
| 凝血功能 | 正常，部分BT延长 |
| 尿常规 | 血尿、蛋白尿、管型尿（肾型） |
| 粪便隐血 | 可阳性（腹型） |
| 血清IgA | 部分患者升高 |
| 皮肤活检 | 白细胞破裂性血管炎，免疫荧光示IgA、C3、纤维蛋白沉积 |

## 诊断

**EULAR/PRINTO/PRES 2010标准**：

**必要条件**：典型皮疹

加上以下至少**1条**：
1. 弥漫性腹痛
2. 组织病理：IgA沉积的白细胞破裂性血管炎或膜增生性肾小球肾炎
3. 关节炎/关节痛
4. 肾脏受累（血尿＞5 RBC/HPF，或蛋白尿＞0.3g/24h）

## 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| [[特发性血小板减少性紫癜]] | ITP有血小板减少，无关节/腹部症状 |
| [[类风湿关节炎]] | 关节破坏畸形，RF/抗CCP阳性 |
| [[系统性红斑狼疮]] | ANA/抗dsDNA阳性，多系统受累 |
| 外科急腹症 | 无紫癜，有肌紧张和反跳痛 |

## 治疗

本病具有**自限性**，单纯皮疹通常不需治疗。

### 一般治疗

| 措施 | 说明 |
|------|------|
| 控制饮食 | 胃肠道损害给予少渣易消化食物，严重者禁食+肠外营养 |
| 抗感染 | 急性期呼吸道/胃肠道感染适当给予抗生素 |

### 药物治疗

| 药物 | 适应证 | 用法 |
|------|--------|------|
| 维生素C + 曲克芦丁 | 增加血管抗力 | 常规剂量 |
| NSAIDs | 关节症状 | 对症 |
| 阿托品/山莨菪碱 | 腹痛 | 解痉 |
| ARB/ACEI | 轻中度蛋白尿 | 肾脏保护 |
| **糖皮质激素** | 胃肠道症状、关节肿痛、严重肾脏病变 | 泼尼松1~2mg/(kg·d)，重症甲泼尼龙5~10mg/(kg·d)，疗程≤30天 |
| 免疫抑制剂 | 激素反应不佳/依赖 | MMF、硫唑嘌呤、环孢素、他克莫司 |

### 其他

IVIG、血浆置换、白细胞去除法（证据待进一步验证）。

## 预后

- 近期预后与**消化道症状**有关
- 远期预后与**肾炎**有关，约2%发展为终末期肾炎
