# 肺炎

> 肺炎是指终末气道、肺泡和肺间质的炎症，细菌性肺炎是最常见的肺炎类型。按患病环境分为社区获得性肺炎（CAP）和医院获得性肺炎（HAP），是指导经验性治疗的关键分类。

## 概述

肺炎（pneumonia）指终末气道、肺泡和肺间质的炎症，可由病原微生物、理化因素、免疫损伤、过敏及药物所致。细菌性肺炎是最常见的肺炎，也是最常见的感染性疾病之一。尽管应用强力抗菌药物和有效疫苗，肺炎的病死率并未进一步降低，甚至有所上升，原因与社会人口老龄化、吸烟、基础疾病、免疫功能低下、病原体变迁及细菌耐药性增加等有关。

**流行病学**：
- CAP 年发病率约（5～11）/1 000 人口，门诊治疗病死率 < 1%～5%，住院治疗平均 12%，ICU 约 40%
- HAP 年发病率约（5～10）/1 000 住院病人，相关病死率 15.5%～38.2%

## 病因与发病机制

是否发生肺炎取决于两个因素：**病原体**和**宿主因素**。

正常的呼吸道免疫防御机制（支气管内黏液-纤毛运载系统、肺泡巨噬细胞等）使下呼吸道免于感染。当病原体数量多、毒力强，和/或宿主呼吸道局部及全身免疫防御系统损害时，即可发生肺炎。

**病原体到达下呼吸道的途径**：

| 途径 | 常见场景 |
|------|----------|
| 空气吸入 | CAP 主要途径 |
| 血行播散 | 金黄色葡萄球菌等 |
| 邻近感染部位蔓延 | 膈下脓肿穿破膈肌 |
| 上呼吸道定植菌的误吸 | CAP、HAP 均可见；HAP 更多通过误吸胃肠道定植菌（胃食管反流）和/或人工气道吸入 |

## 分类

### 解剖分类

| 类型 | 病理特点 | 常见病原体 | X 线表现 |
|------|----------|------------|----------|
| **大叶性（肺泡性）肺炎** | 病原体先在肺泡引起炎症，经 Cohn 孔扩散至肺段/肺叶；不累及支气管 | 肺炎链球菌 | 肺叶/**肺段实变阴影** |
| **小叶性（支气管性）肺炎** | 病原体经支气管入侵，引起细支气管、终末细支气管及肺泡炎症；常继发于其他疾病 | 肺炎链球菌、葡萄球菌、病毒、肺炎支原体、军团菌 | 沿肺纹理分布的不规则斑片状阴影，**边缘密度浅而模糊**，无实变征象 |
| **间质性肺炎** | 以肺间质受累为主，累及支气管壁、支气管周围组织及肺泡壁；呼吸道症状轻，病变广泛则呼吸困难明显 | 细菌、支原体、衣原体、病毒、肺孢子菌 | **一侧或双侧肺下部不规则阴影，磨玻璃状、网格状** |

### 病因分类

| 类别 | 常见病原体 |
|------|------------|
| **细菌性肺炎** | 肺炎链球菌、金葡菌、甲型溶血性链球菌、肺炎克雷伯菌、流感嗜血杆菌、铜绿假单胞菌、鲍曼不动杆菌 |
| **非典型病原体肺炎** | 军团菌、支原体、衣原体 |
| **病毒性肺炎** | 冠状病毒、腺病毒、呼吸道合胞病毒、流感病毒、麻疹病毒、巨细胞病毒、单纯疱疹病毒 |
| **肺真菌病** | 念珠菌、曲霉、隐球菌、肺孢子菌、毛霉 |
| **其他病原体** | 立克次体、弓形体、寄生虫（肺包虫、肺吸虫、肺血吸虫） |
| **理化因素** | 放射性肺炎、化学性肺炎（胃酸吸入）、类脂性肺炎（通常所说的肺炎不包括此类） |

### 患病环境分类（临床最常用）

| 特征 | CAP | HAP |
|------|-----|-----|
| **定义** | 在医院外罹患的感染性肺实质炎症，包括入院后潜伏期内发病者 | 住院 ≥48h 后在医院内新发生的肺炎（无有创机械通气） |
| **常见病原体** | **肺炎链球菌、支原体、衣原体、流感嗜血杆菌、呼吸道病毒** | **鲍曼不动杆菌、铜绿假单胞菌、肺炎克雷伯菌、大肠埃希菌、金葡菌（MDR 菌株多见）** |
| **特殊亚型** | — | VAP（机械通气 48h 后至拔管 48h 内发生的肺炎） |

## 临床表现

细菌性肺炎的症状可轻可重，取决于病原体和宿主状态。

- **常见症状**：咳嗽、咳痰（脓性痰或血痰），伴或不伴胸痛；病变范围大者可有呼吸困难、呼吸窘迫；大多数有发热
- **早期体征**：无明显异常；重症者呼吸频率增快、鼻翼扇动、发绀
- **肺实变体征**：叩诊浊音、语颤增强、支气管呼吸音；可闻及湿啰音
- **胸腔积液**：患侧叩诊浊音、语颤减弱、呼吸音减弱

## 辅助检查

### 病原学检查

| 方法 | 阳性判断标准/说明 |
|------|-------------------|
| **痰培养（最常用）** | 合格标本：每低倍视野鳞状上皮细胞 < 10 个、白细胞 > 25 个；致病菌 ≥10⁷ cfu/ml |
| **经支气管镜/人工气道吸引** | ≥10⁵ cfu/ml 为致病菌 |
| **防污染样本毛刷** | ≥10³ cfu/ml |
| **支气管肺泡灌洗（BAL）** | ≥10⁴ cfu/ml（防污染 BAL ≥10³ cfu/ml） |
| **血/胸腔积液培养** | 血和痰培养分离到相同细菌，或胸腔积液培养阳性，可确定为病原菌 |
| **尿抗原试验** | 军团菌、肺炎链球菌 |
| **血清学检查** | 特异性 IgM 抗体；急性期和恢复期抗体滴度 4 倍增高（多用于回顾性诊断） |
| **分子诊断（PCR、mNGS）** | CAP 核酸检测可提高检出率；mNGS 用于重症、疑似特殊病原体、聚集性感染 |

> 注意：仍有 40%～50% 的肺炎不能确定病原体，初始治疗多为经验性。

### 影像学检查

**胸部 X 线/CT 显示片状、斑片状浸润性阴影或间质性改变，伴或不伴胸腔积液**。

## 诊断与鉴别诊断

### CAP 临床诊断标准

同时满足以下三项：
1. **社区发病**
2. **肺炎相关临床表现**（具备任 1 项）：①新近出现的咳嗽、咳痰或原有呼吸道症状加重伴脓性痰，伴或不伴胸痛/呼吸困难/咯血；②发热；③肺实变体征和/或湿啰音；④WBC > 10×10⁹/L 或 < 4×10⁹/L，伴或不伴核左移
3. **胸部影像学**示片状、斑片状浸润性阴影或间质性改变，伴或不伴胸腔积液

需除外：[[肺结核]]、[[肺癌]]、非感染性肺间质性疾病、肺水肿、肺不张、肺栓塞、肺嗜酸性粒细胞浸润症及肺血管炎等。

### HAP/VAP 临床诊断标准

胸部 X 线或 CT 显示新出现或进展性的浸润影、实变影、磨玻璃影，加上以下 3 项中 ≥2 项：
- 发热，体温 > 38℃
- 脓性气道分泌物
- 外周血 WBC > 10×10⁹/L 或 < 4×10⁹/L

### 严重程度评估

**CURB-65 评分**（判断 CAP 病人是否需要住院）：

| 指标 | 标准 |
|------|------|
| C — 意识障碍（Confusion） | 意识模糊 |
| U — 尿素氮（Uremia） | > 7 mmol/L |
| R — 呼吸频率（Respiratory rate） | ≥ 30 次/分 |
| B — 血压（Blood pressure） | 收缩压 < 90 mmHg 或舒张压 ≤ 60 mmHg |
| 65 — 年龄 | ≥ 65 岁 |

- 0～1 分：门急诊治疗
- 2 分：建议住院或严格随访下院外治疗
- 3～5 分：应住院治疗

**重症肺炎标准**（符合 1 项主要标准或 ≥3 项次要标准）：

| 主要标准 | 次要标准 |
|----------|----------|
| ①需要气管插管行机械通气治疗 | ①呼吸频率 ≥ 30 次/分 |
| ②感染性休克经积极液体复苏后仍需血管活性药物 | ②PaO₂/FiO₂ ≤ 250 mmHg |
|  | ③多肺叶浸润 |
|  | ④意识障碍和/或定向障碍 |
|  | ⑤血尿素氮 ≥ 7.14 mmol/L |
|  | ⑥收缩压 < 90 mmHg 需积极液体复苏 |

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| **[[肺结核]]** | 全身中毒症状（午后低热、盗汗、乏力、体重减轻）；X 线病变多在肺尖/锁骨上下，密度不匀，消散缓慢，可形成空洞/肺内播散；痰中可找到结核分枝杆菌；一般抗菌治疗不佳 |
| **[[肺癌]]** | 多无急性感染中毒症状，痰中带血丝，WBC 不高；阻塞性肺炎抗菌治疗后阴影不消或同一部位反复出现；需 CT/MRI/支气管镜/痰脱落细胞检查 |
| **肺栓塞** | 多有静脉血栓危险因素；呼吸困难明显，可咯血、晕厥；X 线示区域性肺血管纹理减少或尖端指向肺门的楔形阴影；D-二聚体、CTPA 可鉴别 |
| **急性上呼吸道感染与气管支气管炎** | 有咳嗽、咳痰和发热，但无肺实质浸润，胸部 X 线可鉴别 |
| **非感染性肺部浸润** | 需与间质性肺炎、肺水肿、肺不张、肺血管炎等鉴别 |

## 治疗

### 抗感染治疗原则

抗感染治疗是关键环节，分为**经验性治疗**和**抗病原体治疗**。应尽早进行，一旦怀疑即应马上给予首剂抗菌药物。

**经验性方案选择**：

| 病人类型 | 常用方案 |
|----------|----------|
| 青壮年、无基础疾病 CAP | 青霉素类、第一代头孢菌素；肺炎链球菌对大环内酯类耐药率高，不单独使用 |
| 耐药肺炎链球菌 | 呼吸氟喹诺酮类（莫西沙星、吉米沙星、左氧氟沙星） |
| 老年人、有基础疾病/住院 CAP | 呼吸氟喹诺酮类；第二、三代头孢菌素；β-内酰胺类/β-内酰胺酶抑制剂或厄他培南，可联合大环内酯类 |
| 重症 CAP | β-内酰胺类联合大环内酯类或氟喹诺酮类；青霉素过敏者用呼吸氟喹诺酮类 + 氨曲南 |
| HAP | 抗假单胞菌 β-内酰胺类或碳青霉烯类联合呼吸氟喹诺酮类或氨基糖苷类；怀疑 MDR 球菌加万古霉素/替考拉宁/利奈唑胺 |

**疗程**：
- 轻中度 CAP：5～7 天
- 非典型病原体：10～14 天
- 金葡菌/铜绿假单胞菌/克雷伯菌/厌氧菌：14～21 天
- 停药指征：热退 2～3 天且主要呼吸道症状明显改善后停药（不必以肺部阴影吸收程度为准）

**72 小时疗效评估**：临床稳定标准——体温 ≤ 37.8℃、心率 ≤ 100 次/分、呼吸频率 ≤ 24 次/分、收缩压 ≥ 90 mmHg、SaO₂ ≥ 90%（或 PaO₂ ≥ 60 mmHg）。

72 小时后症状无改善可能原因：药物未覆盖致病菌或耐药、特殊病原体感染（结核、真菌、病毒）、并发症或宿主因素、非感染性疾病误诊、药物热。

## 细菌性肺炎

### 肺炎链球菌肺炎

肺炎链球菌肺炎（Streptococcal pneumoniae pneumonia）约占 CAP 的半数，是 CAP 最常见的病原体。

**病因**：肺炎链球菌（SP）为革兰氏阳性球菌，多成双排列或短链排列。有荚膜，根据荚膜多糖分为 86 个血清型。成人致病多属 1～9 型及 12 型，第 3 型毒力最强。SP 不产生毒素，不引起组织坏死或形成空洞（区别于金葡菌）。

**致病机制**：高分子多糖体荚膜对组织有侵袭作用 → 肺泡壁水肿 → 白细胞与红细胞渗出 → 含菌渗出液经 Cohn 孔向中央扩散 → 累及多个肺段或整个肺叶 → 病变始于肺外周，易累及胸膜，引起渗出性胸膜炎。

**病理分期**（四期，抗菌药物使用后少见典型分期）：充血期 → 红肝变期 → 灰肝变期 → 消散期。消散后肺组织结构多无损坏，不留纤维瘢痕。极个别可发生机化性肺炎。

**临床表现**：

| 特征 | 描述 |
|------|------|
| **好发季节/人群** | 冬季与初春；原为健康的青壮年或老年与婴幼儿，男性较多；吸烟、慢性支气管炎、[[支气管扩张]]、[[心力衰竭]]、慢性病及免疫抑制者易感 |
| **前驱** | 受凉、淋雨、疲劳、醉酒、病毒感染史；多有上呼吸道感染前驱症状 |
| **典型症状** | 起病急骤，高热、寒战，体温 39～40℃，稽留热；患侧胸痛（咳嗽或深呼吸加剧），放射到肩部或腹部；痰少，可带血或呈**铁锈色痰** |
| **体征** | 急性热病容，面颊绯红，鼻翼扇动，口角/鼻周单纯疱疹；肺实变体征：叩诊浊音、语颤增强、支气管呼吸音；消散期可闻及湿啰音 |
| **自然病程** | 1～2 周；有效抗菌药物后体温 1～3 天内恢复正常 |

**并发症**：感染性休克（老年人多见）、胸膜炎、脓胸、心包炎、脑膜炎、关节炎。

**辅助检查**：
- 血 WBC 升高，中性粒细胞 > 80% 伴核左移
- 痰涂片革兰氏染色：革兰氏阳性、带荚膜的双球菌或链球菌
- 痰培养 24～48h 确定病原体
- 尿 SP 抗原可阳性
- 约 10%～20% 合并菌血症，重症应做血培养
- X 线：大片炎症浸润阴影或实变影，可见支气管充气征，肋膈角少量胸腔积液；消散期出现"假空洞"征，多数 3～4 周完全消散

**治疗**：
- **首选青霉素 G**（根据 MIC 敏感阈值提高，欧洲指南建议大剂量：320 万 U，每 4h 一次）
- 青霉素过敏或耐药菌株：呼吸氟喹诺酮类、头孢噻肟、头孢曲松
- MDR 菌株：万古霉素、替考拉宁、利奈唑胺
- 支持治疗：休息、补液、氧疗（PaO₂ < 60 mmHg 或有发绀）；禁用阿司匹林等解热镇痛药（干扰热型判断）；禁用抑制呼吸的镇静药

### 葡萄球菌肺炎

葡萄球菌肺炎（staphylococcal pneumonia）是由葡萄球菌引起的急性肺化脓性炎症，多发生于有基础疾病者（糖尿病、血液病、艾滋病、肝病、营养不良、酒精中毒、静脉吸毒）。

| 特征 | 描述 |
|------|------|
| **病原体** | 金黄色葡萄球菌（凝固酶阳性）为主；致病物质为毒素与酶（溶血毒素、杀白细胞素、肠毒素） |
| **临床表现** | 起病急骤，高热（39～40℃），寒战，胸痛，痰量多、带血丝或呈脓血状；全身中毒症状明显，可早期出现周围循环衰竭 |
| **X 线特征** | 肺段/肺叶实变，可早期形成空洞；小叶状浸润中见单个或多发液气囊腔；**阴影易变性**（一处消失、另一处出现新病灶） |
| **诊断** | 全身中毒症状 + 咳嗽、脓血痰 + 白细胞增高伴核左移及中毒颗粒 + X 线特征；细菌学检查确诊 |
| **治疗** | 耐酶半合成青霉素（苯唑西林、氯唑西林）或头孢菌素联合氨基糖苷类；MRSA 选用万古霉素、替考拉宁、利奈唑胺 |

## 常见肺炎的临床鉴别

| 病原体 | 症状与体征特征 | X 线特征 |
|--------|---------------|----------|
| **肺炎链球菌** | 起病急，寒战高热，铁锈色痰，胸痛，肺实变体征 | 肺叶/肺段实变，无空洞，可伴胸腔积液 |
| **金黄色葡萄球菌** | 起病急，寒战高热，脓血痰，毒血症症状，休克 | 肺叶/小叶浸润，早期空洞，脓胸，液气囊腔 |
| **肺炎克雷伯菌** | 起病急，寒战高热，全身衰竭，砖红色胶冻状痰 | 肺叶/肺段实变，蜂窝状脓肿，叶间隙下坠 |
| **铜绿假单胞菌** | 毒血症明显，脓痰，可呈蓝绿色 | 弥漫性支气管炎，早期肺脓肿 |
| **流感嗜血杆菌** | 高热、呼吸困难、衰竭 | 支气管肺炎，肺叶实变，无空洞 |
| **厌氧菌** | 吸入病史，高热，腥臭痰，毒血症明显 | 支气管肺炎，脓胸，脓气胸，多发性肺脓肿 |
| **军团菌** | 高热、肌痛、相对缓脉 | 下叶斑片浸润，进展迅速，无空洞 |
| **支原体** | 起病缓，可小流行，乏力、肌痛、头痛 | 下叶间质性支气管肺炎，3～4 周自行消散 |
| **念珠菌** | 慢性病史，畏寒、高热、黏痰 | 双下肺纹理增多，支气管肺炎或大片浸润，可有空洞 |
| **曲霉** | 免疫抑制宿主，发热、干咳或棕黄色痰、胸痛、咯血、喘息 | 胸膜为基底楔形影，结节/团块影，空洞；晕轮征和新月征 |

## 细菌性 vs 病毒性 vs 非典型病原体肺炎鉴别

| 特征 | 细菌性肺炎 | 病毒性肺炎 | 非典型病原体肺炎（支原体/衣原体/军团菌） |
|------|-----------|-----------|----------------------------------|
| **起病** | 急骤 | 较急 | 缓慢（军团菌可急性） |
| **发热** | 高热，寒战 | 发热，全身症状突出 | 中等度发热或不发热（军团菌可高热） |
| **咳嗽** | 咳脓性痰、血痰或铁锈色痰 | 少痰，白色黏液痰 | 阵发性干咳（支原体典型），夜间为重 |
| **WBC** | 升高，核左移 | 正常、稍高或偏低 | 正常或略增高 |
| **痰涂片** | 大量中性粒细胞，可见致病菌 | 以单核细胞为主，无致病菌 | 无致病细菌 |
| **X 线** | 大片实变或支气管肺炎 | 肺纹理增多，磨玻璃影，小片浸润 | 下叶间质性改变 |
| **病原学** | 痰/血培养阳性 | 病毒核酸/抗体检测 | 血清学抗体（冷凝集试验、IgM）；培养困难 |
| **治疗** | 抗菌药物 | 对症为主，抗病毒药物（利巴韦林、奥司他韦等） | 大环内酯类/氟喹诺酮类（**青霉素/头孢无效**） |
| **病程** | 治疗 1～3 天退热 | 吸收慢，病程长 | 3～4 周自行消散 |

### 支原体肺炎、衣原体肺炎与军团菌肺炎

| 特征 | 肺炎支原体肺炎 | 肺炎衣原体肺炎 | 军团菌肺炎 |
|------|---------------|---------------|-----------|
| **病原体** | 肺炎支原体（无细胞壁） | 肺炎衣原体（专性细胞内） | 嗜肺军团菌（革兰氏阴性，约 90%） |
| **好发人群** | 儿童、青少年，可小流行 | 学龄儿童，半封闭环境小流行 | 免疫力低下者，老年 |
| **传播** | 飞沫传播，潜伏期 2～3 周 | 人-人飞沫传播 | 吸入污染水源气溶胶 |
| **临床表现** | 起病缓，乏力、头痛、咽痛，**持久的阵发性剧咳**，体征与 X 线不符 | 起病隐匿，咽痛声嘶，**双阶段病程**：咽炎→肺炎/支气管炎 | 寒战、高热（> 38.8℃）、干咳、呼吸困难；**肺外表现**：腹泻、谵妄、肌痛 |
| **重要检查** | 冷凝集试验 ≥ 1:32；血清 IgM ≥ 1:64 | 血清学 IgM≥1:32 或 4 倍升高 | **尿抗原检测**（床旁快速，敏感性和特异性高）；培养为金标准 |
| **治疗** | **大环内酯类**首选（阿奇霉素等）；氟喹诺酮类、四环素类有效；**青霉素/头孢无效** | **大环内酯类**首选；氟喹诺酮类、四环素类有效 | 喹诺酮类、大环内酯类、多西环素；替加环素、复方磺胺甲噁唑、利福平也有效 |

## 病毒性肺炎

**常见病原体**：甲/乙型流感病毒、腺病毒、副流感病毒、呼吸道合胞病毒、冠状病毒（SARS-CoV、SARS-CoV-2、H5N1、H7N9 等）。

**临床特点**：
- 好发于病毒疾病流行季节，起病较急
- **全身症状突出**：发热、头痛、全身酸痛、倦怠
- 呼吸道症状：咳嗽、少痰或白色黏液痰、咽痛
- 小儿或老年人易发生重症肺炎，可发生 [[呼吸衰竭]]、[[心力衰竭]]、[[急性呼吸窘迫综合征|ARDS]]
- 体征常不显著，与症状程度不成比例

**诊断**：血清病毒特异性 IgM 抗体（早期诊断）、双份血清抗体 4 倍增高（确诊）、PCR 检测病毒核酸。痰涂片仅见散在细菌及大量有核细胞（无致病菌生长）。

**治疗**：以对症为主，必要时氧疗。抗病毒药物包括：利巴韦林（广谱）、阿昔洛韦（疱疹病毒）、更昔洛韦（CMV）、奥司他韦（甲/乙型流感）、阿糖腺苷（广谱）。原则上不宜常规使用抗生素预防细菌感染。

**COVID-19** 分型：轻型（上呼吸道感染为主）、中型（持续高热 > 3 天或咳嗽气促但 RR < 30、SpO₂ > 93%）、重型（RR ≥ 30 或 SpO₂ ≤ 93% 或 PaO₂/FiO₂ ≤ 300 mmHg 或影像学 24～48h 进展 > 50%）、危重型（呼衰需机械通气、休克、其他器官衰竭需 ICU）。

## 肺真菌病（概述）

肺真菌病是最常见的深部真菌病。近年因广谱抗生素、糖皮质激素、免疫抑制剂广泛使用，器官移植及艾滋病增多，发病率有上升趋势。

| 类型 | 关键特征 | 治疗 |
|------|----------|------|
| **肺念珠菌病** | 支气管炎型（阵发性咳嗽、白泡沫痰）和肺炎型（高热、白色泡沫黏痰、酵臭味）；G 试验连续 2 次阳性 | 氟康唑、伊曲康唑、伏立康唑、棘白菌素类 |
| **侵袭性肺曲霉病** | 最常见类型，免疫抑制宿主；晕轮征 → 新月征；GM 试验阳性 | **伏立康唑**首选（疗程 ≥ 6～12 周） |
| **慢性肺曲霉病** | 简单型曲霉球（反复间歇性咯血，Monad 征）/ CCPA / CFPA / 曲霉结节 / SAIA | 伊曲康唑/伏立康唑口服 |
| **ABPA（变应性支气管肺曲霉病）** | 对曲霉过敏，哮喘发作，血嗜酸性粒细胞增高，血清 IgE > 1 000 IU/ml，中央性支气管扩张 | 糖皮质激素 + 抗真菌药 |
| **肺隐球菌病** | 鸽粪接触史，免疫抑制宿主多见；墨汁染色镜检 → 圆形厚壁菌体 | 氟康唑、伊曲康唑、两性霉素 B |
| **肺孢子菌肺炎（PCP）** | HIV/AIDS 最常见机会性感染；**症状体征分离**（症状重、体征缺如）；G 试验升高 | **复方磺胺甲噁唑（TMP-SMZ）** 首选 |

## 预防

- 加强体育锻炼，增强体质
- 减少危险因素：戒烟、限酒
- ≥ 65 岁或有心血管疾病/肺疾病/糖尿病/酗酒/肝硬化/免疫抑制者：接种**流感疫苗**和**肺炎疫苗**
