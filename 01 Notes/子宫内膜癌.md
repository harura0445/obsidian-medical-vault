# 子宫内膜癌

## 概述

子宫内膜癌是发生于子宫内膜的上皮性恶性肿瘤，是女性生殖系统三大恶性肿瘤之一。好发于围绝经期及绝经后女性，近年来发病率呈上升趋势。

## 发病相关因素

| 因素 | 说明 |
|------|------|
| **雌激素长期刺激** | **无孕激素拮抗的雌激素长期作用**是主要发病机制 |
| 肥胖 | 脂肪细胞芳香化酶将雄激素转化为雌酮 |
| 糖尿病 | 胰岛素抵抗→高胰岛素血症→雄激素水平升高 |
| 高血压 | — |
| 未产/不孕 | — |
| 晚绝经 | 长期雌激素暴露 |
| 长期单一雌激素替代治疗 | 缺乏孕激素对抗 |
| 他莫昔芬 | 乳腺组织抗雌激素，子宫内膜拟雌激素 |
| Lynch 综合征 | 遗传性非息肉性结直肠癌（HNPCC）相关 |
| 多囊卵巢综合征 | 无排卵→缺乏孕激素→雌激素持续刺激 |

## 病理

### 大体类型

| 类型 | 特点 |
|------|------|
| **弥漫型** | 内膜大部分或全部受累，表面粗糙不平、质脆易出血 |
| **局限型** | 局灶性隆起，多见于宫底部和宫角部 |

### 组织学类型

| 类型 | 占比 | 特点 |
|------|------|------|
| **子宫内膜样癌** | 80%~90% | 最常见，预后较好，ER/PR 阳性率高 |
| 浆液性癌 | 5%~10% | 恶性程度最高，预后差 |
| 透明细胞癌 | <5% | |
| 黏液性癌 | <5% | |
| 混合型 | — | |

## 临床表现

| 症状 | 要点 |
|------|------|
| **阴道流血** | **最常见首发症状**。绝经后→阴道流血；围绝经期→不规则阴道流血；生育期→经量增多/经期延长 |
| **阴道排液** | 浆液性或浆液血性，合并感染→脓血性、恶臭 |
| 下腹痛 | 晚期宫腔积脓/积血→下腹胀痛 |
| 晚期表现 | 消瘦、贫血、恶液质，宫旁/远处转移相应症状 |

**体征**：早期子宫正常大；晚期子宫增大、质软。宫腔积脓→子宫增大、压痛。

## 诊断

### 有序化诊断流程

1. **病史与体检**：高危因素 + 异常阴道流血/排液
2. **超声**：首选筛查，内膜厚度。绝经后内膜 ≤4~5mm 恶性风险低
3. **子宫内膜病理检查**（确诊金标准）：
   - **子宫内膜吸管吸取活检**：简便、创伤小、准确率高
   - **宫腔镜检查+活检**：直视下取样，定位准确
   - **分段诊刮**：分别搔刮子宫颈管和子宫腔，判断病变范围
4. **MRI/CT**：评估肌层浸润深度、淋巴结转移

### 临床分期（FIGO 2023）

| 分期 | 标准 |
|------|------|
| **Ⅰ期** | 肿瘤局限于子宫体 |
| ⅠA | 浸润肌层 <1/2 |
| ⅠB | 浸润肌层 ≥1/2 |
| **Ⅱ期** | 肿瘤侵犯子宫颈间质，未超出子宫 |
| **Ⅲ期** | 肿瘤超出子宫，未达真骨盆 |
| **Ⅳ期** | 侵犯膀胱/直肠黏膜，或远处转移 |

## 治疗

以**手术为主的综合治疗**。

### 手术治疗

- **分期手术**是首选治疗
- 术式：筋膜外全子宫切除 + 双侧附件切除 + 盆腔/腹主动脉旁淋巴结清扫（或前哨淋巴结活检）
- 年轻、早期、高分化、有生育要求者→保守治疗（高效孕激素），严密随访

### 辅助治疗

| 方式 | 适应证 |
|------|--------|
| **放疗** | 术后辅助（有高危因素）或不能手术者 |
| **化疗** | 晚期/复发/特殊病理类型（浆液性癌、透明细胞癌） |
| **内分泌治疗** | 孕激素（甲羟孕酮、甲地孕酮），用于晚期/复发、ER/PR 阳性、年轻有生育要求保留生育功能者 |

## 预后与随访

- 80% 患者为 Ⅰ 期，5 年生存率 >90%
- 高危因素：非子宫内膜样癌、低分化、深肌层浸润、淋巴血管间隙浸润（LVSI）
- 术后 2~3 年内每 3~6 个月随访 1 次
