# 肺血栓栓塞症

> 肺血栓栓塞症（PTE）是来自静脉系统或右心的血栓阻塞肺动脉或其分支所致的疾病，以肺循环和呼吸功能障碍为主要临床特征，是肺栓塞最常见的类型。PTE 与深静脉血栓形成（DVT）合称为静脉血栓栓塞症（VTE），两者是同一疾病过程在不同部位、不同阶段的表现。

## 概述

肺栓塞（pulmonary embolism，PE）是以各种栓子阻塞肺动脉或其分支为发病原因的一组疾病的总称，包括 PTE、脂肪栓塞综合征、羊水栓塞、空气栓塞、肿瘤栓塞等。其中 PTE 为最常见的类型，引起 PTE 的血栓主要来源于下肢深静脉血栓形成（DVT）。

肺动脉内反复血栓栓塞及血栓不溶、机化，可发展为慢性血栓栓塞性肺疾病（CTEPD），后期引起肺动脉高压及右心衰竭，称为慢性血栓栓塞性肺动脉高压（CTEPH）。

**流行病学要点**：VTE 发病率随年龄增加而增加，年龄 >40 岁者风险约每 10 年增加 1 倍。我国 PTE 患病率从 2007 年的 1.2/10 万上升至 2016 年的 7.1/10 万，住院病死率由 8.5% 下降至 3.9%。

## 危险因素

任何可以导致 Virchow 三联征（静脉血流淤滞、血管内皮损伤、血液高凝状态）的因素均为 VTE 的危险因素，分为遗传性和获得性两类。

| 类别 | 危险因素 |
|------|----------|
| **遗传性（易栓症）** | 抗凝血酶缺乏、蛋白 C 缺乏、蛋白 S 缺乏、V 因子 Leiden 突变、凝血酶原 20210A 基因变异、纤溶酶原缺乏、异常纤维蛋白原血症、凝血酶调节蛋白异常、纤溶酶原激活物抑制因子过量、Ⅷ/Ⅸ/Ⅺ 因子水平升高、非"O"血型 |
| **获得性 — 血液高凝状态** | 高龄、恶性肿瘤（VTE 重要危险因素）、抗磷脂综合征、口服避孕药、妊娠/产褥期、VTE 个人史/家族史、炎症性肠病、肥胖、肾病综合征、真性红细胞增多症、巨球蛋白血症、吸烟、高同型半胱氨酸血症、肿瘤静脉化疗 |
| **获得性 — 血管内皮损伤** | 手术（尤其全髋/膝关节置换）、创伤/骨折、中心静脉置管、植入人工假体 |
| **获得性 — 静脉血流淤滞** | 瘫痪、长途航空或乘车旅行、急性内科疾病住院、居家养老护理 |

- 年龄是 VTE 发生的独立危险因素
- <50 岁无明显诱因反复发生 VTE 或呈家族性发病倾向者，需警惕遗传性易栓症
- 部分特发性 VTE 病人存在隐匿性恶性肿瘤，应注意筛查和随访
- VTE 与动脉性疾病（如冠心病）有共同危险因素：吸烟、肥胖、高胆固醇血症、高血压、糖尿病等

## 病理生理

PTE 血栓约 70% 来源于下肢深静脉，多在 DVT 形成后脱落，随静脉血流移行至肺动脉内。其病理生理改变主要包括两方面：

### 1. 血流动力学改变 — 肺动脉高压与右心功能不全

| 机制环节 | 病理生理变化 |
|----------|------------|
| 机械阻塞 | 栓子阻塞肺动脉 >30%～50% → 肺血管阻力（PVR）增加 |
| 右心室后负荷增加 | PVR 升高 → 肺动脉压力升高 → 右心室扩大 → 室间隔左移 |
| 左心功能受损 | 左心室舒张早期充盈受阻 → 心排血量降低 → 体循环低血压 |
| 心肌缺血 | 主动脉低血压 + 右心室压升高 → 冠状动脉灌注压下降 → 右心室内膜下心肌低灌注 |

### 2. 气体交换障碍 — 呼吸功能不全

| 机制 | 结果 |
|------|------|
| 心排血量降低 | 混合静脉血氧饱和度下降 |
| 栓塞部位血流减少 | 肺泡无效腔量增大 |
| 未阻塞血管灌注增加 | 通气血流比例失调 → 低氧血症 |
| 右心房压力升高 → 卵圆孔开放（约 1/3 病人） | 右向左分流 → 严重低氧血症，增加矛盾性栓塞和猝死风险 |
| 远端小栓子 → 出血性肺不张（肺梗死） | 咯血、胸膜炎、胸腔积液 |

## 临床分型

### 急性 PTE 危险分层

| 分型 | 血流动力学 | 右心功能不全（RVD） | 心脏生物学标志物 | 早期死亡风险 |
|------|-----------|-------------------|-----------------|------------|
| **高危** | 不稳定（休克/持续低血压/心搏骤停） | — | — | 高 |
| **中高危** | 稳定 | + | +（两者均存在） | 中 |
| **中低危** | 稳定 | 仅 RVD 或仅标志物升高 | 中 |
| **低危** | 稳定 | - | - | 低 |

> 血流动力学不稳定定义（具备任意一条）：①心搏骤停，需心肺复苏；②梗阻性休克（收缩压 <90 mmHg 或需升压药维持，且伴外周器官低灌注）；③持续低血压（收缩压 <90 mmHg 或下降 ≥40 mmHg，持续 >15 分钟，除外其他原因）。

**RVD 诊断标准**：
- 超声心动图/CTPA 示右心室扩张（右心室舒张末期内径/左心室舒张末期内径 >1.0）
- 超声：右心室游离壁运动幅度减低、三尖瓣反流速度增快、三尖瓣环收缩期位移 <17 mm

**心脏生物学标志物**：BNP、NT-proBNP、肌钙蛋白（cTnI/cTnT）

### 慢性血栓栓塞性肺动脉高压（CTEPH）

急性 PTE 后血栓未完全溶解、机化，或 DVT 反复脱落栓塞肺动脉，导致肺血管慢性阻塞和重塑，最终引起肺动脉高压（静息 mPAP ≥25 mmHg）和右心衰竭。多存在进行性呼吸困难、乏力，影像学可见肺动脉内慢性栓塞征象（贴壁、偏心、钙化）。

## 临床表现

急性 PTE 临床表现缺乏特异性，严重程度差异很大，轻者无症状，重者可发生猝死。

### 症状

| 症状 | 特点 |
|------|------|
| [[呼吸困难]] 及气促 | **最多见**，尤以活动后明显，静息时缓解 |
| 胸痛 | 胸膜炎样胸痛（多见，呼吸/咳嗽时加重）；心绞痛样胸痛（少数，胸骨后挤压痛） |
| [[咯血]] | 约 1/3 病人，常为小量咯血，多发生于肺梗死后 24 小时内 |
| 烦躁不安、惊恐、濒死感 | 机制不明，可能与胸痛或低氧血症有关 |
| [[咳嗽与咳痰]] | 约 1/3 病人，多为干咳或有少量白痰 |
| [[晕厥]] | 可为唯一或首发症状，大块血栓阻塞 >50% 肺血管致心排血量显著减少 |

**"肺梗死三联征"**：同时出现呼吸困难、胸痛及咯血，但仅见于约 **20%** 的病人。

### 体征

| 系统 | 体征 |
|------|------|
| **呼吸系统** | 呼吸频率增快、发绀；肺部可闻及哮鸣音和/或细湿啰音；偶可闻及血管杂音；合并肺不张、胸腔积液时有相应体征 |
| **循环系统** | 窦性心动过速最常见；可有 P2 > A2 或分裂；三尖瓣区收缩期杂音；颈静脉充盈或异常搏动；右心奔马律；严重者血压下降甚至休克 |
| **其他** | 可伴[[发热|低热]]（肺梗死、肺出血、继发感染或下肢血栓性静脉炎引起） |

### DVT 的临床表现

患肢肿胀、周径增粗、疼痛或压痛、皮肤色素沉着。双侧下肢周径测量：髌骨上缘以上 15 cm 及髌骨下缘以下 10 cm 处，双侧相差 **>1 cm** 即有临床意义。约半数以上下肢 DVT 病人无明显自觉症状。

## 辅助检查

### 疑诊检查

| 检查 | 临床意义 |
|------|----------|
| **血浆 D-二聚体** | 敏感度 92%~100%，阴性预测价值高。D-二聚体 **<500 μg/L** 可基本排除急性 PTE（低度临床可能性病人）。>50 岁病人可用年龄调整临界值：年龄 ×10 μg/L。肿瘤、炎症、创伤、手术等可致升高，需动态观察 |
| **动脉血气分析** | 常表现为低氧血症、低碳酸血症、P(A-a)O₂ 增大。部分可正常 |
| **血浆肌钙蛋白**（cTnI/cTnT） | 升高提示 RVD 及心肌损伤，水平越高预后越差 |
| **BNP/NT-proBNP** | 反映右心功能不全及血流动力学紊乱严重程度，可用于评估预后 |
| **心电图** | 多数为非特异性异常。最常见窦性心动过速、V₁~V₄ T 波改变和 ST 段异常。较特异：**SⅠQⅢTⅢ 征**（Ⅰ导联 S 波加深，Ⅲ导联 Q 波及 T 波倒置）。其他：完全或不完全右束支传导阻滞、肺型 P 波、电轴右偏、顺钟向转位。**动态改变较静态异常更有意义** |
| **超声心动图** | 提示右心室后负荷增加；少数可发现右心房/室及肺动脉内血栓。用于排除其他心血管疾病 |

### 临床可能性评估量表

| 量表 | 评估项目 | 用途 |
|------|---------|------|
| **Wells 评分** | DVT 临床征象、PTE 可能性大于其他诊断、心率 >100 次/分、4 周内制动/手术、既往 DVT/PTE 史、咯血、恶性肿瘤 | 将疑诊病人分为低/中/高临床可能性 |
| **修订版 Geneva 评分** | 年龄、既往 DVT/PTE 史、近期手术/骨折、活动性恶性肿瘤、单侧下肢疼痛、咯血、心率、单侧下肢深静脉触痛及水肿 | 完全基于客观指标，不使用临床主观判断 |

### 确诊检查

| 检查 | 特点 |
|------|------|
| **CTPA**（CT 肺动脉造影） | **首选确诊方法**。直接征象：肺动脉内充盈缺损（轨道征）或完全充盈缺损、远端血管不显影。间接征象：肺野楔形高密度影、盘状肺不张、中心肺动脉扩张及远端血管分支减少 |
| **V/Q 显像**（肺通气/灌注显像） | 典型征象：呈肺段分布的肺灌注缺损，与通气显像不匹配。对远端栓塞诊断价值更高。优先适用于：临床可能性低的门诊病人、年轻/妊娠女性、造影剂过敏、严重肾功能不全 |
| **MRPA**（磁共振肺动脉造影） | 无 X 线辐射，不使用含碘造影剂。对肺段以下水平诊断价值有限。适用于肾功能严重受损、碘造影剂过敏或妊娠病人 |
| **肺动脉造影** | **诊断金标准**，敏感度和特异度均高。为有创检查，致命并发症 0.1%、严重并发症 1.5%，应严格掌握适应证 |

## 诊断流程

诊断按 **疑诊 → 确诊 → 求因** 三步进行：

```
临床评估（症状 + 体征 + 危险因素）
        ↓
Wells 评分 / 修订版 Geneva 评分 → 评估临床可能性
        ↓
┌───────────────────────────────────────┐
│ 血流动力学不稳定              血流动力学稳定        │
│      ↓                                ↓              │
│ 可行 CTPA → 确诊/排除    D-二聚体检测          │
│ 无条件 → 床旁超声       ↓                      │
│    (发现右心负荷增加/   <500 μg/L    >500 μg/L  │
│     血栓 → 按 PTE 治疗)  基本排除       ↓          │
│                               CTPA（首选）        │
│                               V/Q 显像/MRPA（备选）│
└───────────────────────────────────────┘
```

**求因**：明确有无 DVT（下肢深静脉加压超声等）及寻找危险因素（制动、创伤、肿瘤、易栓症筛查等）。对 <50 岁、复发性 PTE 或有突出 VTE 家族史者，应评估遗传性易栓症（抗凝血酶、蛋白 C、蛋白 S 缺陷等）。

## 鉴别诊断

| 临床特征 | 需鉴别的疾病 |
|----------|------------|
| 合并胸痛 | 急性冠脉综合征（冠心病）、主动脉夹层 |
| 合并呼吸困难 | 肺炎、[[支气管哮喘]] |
| 合并胸腔积液 | 结核、肺炎、肿瘤、左心功能不全 |
| 合并晕厥 | 迷走反射性晕厥、脑血管性晕厥、[[心律失常]]所致晕厥 |
| 合并休克 | 心源性休克、低血容量性休克、分布性休克（PTE 属**梗阻性休克**：动脉压低而静脉压升高） |
| 合并咯血 | 结核、支气管扩张、肿瘤、左心功能不全 |
| 肺动脉腔内占位 | 脂肪栓塞、羊水栓塞、空气栓塞、肿瘤栓塞、肺动脉肉瘤、肺动脉炎 |

## 治疗

### 一般支持治疗

- 严密监测生命体征及血气变化
- 低氧血症者吸氧（鼻导管/面罩/经鼻高流量），呼吸衰竭者行无创或有创机械通气
- 血管活性药物（多巴胺、多巴酚丁胺、去甲肾上腺素）维持血流动力学，改善右心功能
- 适当镇静、止痛，保持大便通畅，避免用力

### 抗凝治疗（基础治疗）

一旦明确急性 PTE，宜尽早启动抗凝治疗。

| 药物类别 | 代表药物 | 用法要点 |
|----------|---------|---------|
| **胃肠外 — 普通肝素（UFH）** | — | 静脉给药，2 000~5 000 U 或 80 U/kg 静注后 18 U/(kg·h) 持续泵入，监测 APTT 调整剂量；需监测血小板计数（警惕肝素诱导血小板减少症） |
| **胃肠外 — 低分子量肝素（LMWH）** | — | 按体重给药，1~2 次/日皮下注射；需监测血小板计数；肾功能不全者慎用（经肾脏清除） |
| **胃肠外 — 磺达肝癸钠** | — | 选择性 Xa 因子抑制剂，按体重 5~10 mg 每日一次皮下注射 |
| **口服 — 华法林** | — | 初始 3.0~5.0 mg（>75 岁/出血高危者 2.5~3.0 mg），目标 INR **2.0~3.0** |
| **口服 — DOACs** | 利伐沙班、阿哌沙班、艾多沙班（Xa 因子抑制剂）；达比加群酯（直接凝血酶抑制剂） | 直接抑制凝血路径中某一靶点，起效快，无需常规监测 INR |

**抗凝疗程**：
- 所有明确诊断的急性 PTE：至少 **3 个月**抗凝
- 继发于短暂/可逆危险因素的初发病人：3 个月后可考虑停药
- 无短暂/可逆危险因素（复发性 VTE、抗磷脂综合征、遗传性易栓症等）：延长抗凝
- 合并肿瘤：长期甚至终身抗凝，直至肿瘤完全缓解

### 溶栓治疗

| 项目 | 内容 |
|------|------|
| **时间窗** | 一般 ≤14 天 |
| **主要适应证** | **高危 PTE**（血流动力学不稳定），无禁忌证时积极、尽早溶栓 |
| **中危 PTE** | 不常规推荐；权衡效益与风险，个体化决定 |
| **低危 PTE** | 不建议溶栓 |
| **抢救性溶栓** | 抗凝过程中血流动力学恶化者 |
| **常用药物** | 尿激酶、链激酶、rt-PA（低剂量 50 mg 与 100 mg 疗效相似而安全性更好） |
| **主要并发症** | 出血（最严重），其他：发热、过敏反应（链激酶）、低血压、恶心、呕吐等 |

> 溶栓结束后 2 小时测 APTT，当其 < 正常值 2 倍时，重新开始规范抗凝治疗（首选 UFH）。

**溶栓禁忌证**：

| 绝对禁忌证 | 相对禁忌证 |
|-----------|-----------|
| 结构性颅内疾病 | 收缩压 >180 mmHg 或舒张压 >110 mmHg |
| 出血性脑卒中病史 | 近期非颅内出血 |
| 3 个月内缺血性脑卒中 | 近期侵入性操作/手术 |
| 活动性出血 | 3 个月以上缺血性脑卒中 |
| 近期脑或脊髓手术 | 口服抗凝药物（华法林）治疗 |
| 近期头部骨折性外伤或头部损伤 | 创伤性心肺复苏 |
| 出血倾向（自发性出血） | 心包炎或心包积液 |
| — | 糖尿病视网膜病变 |
| — | 妊娠 |
| — | 年龄 >75 岁 |

> 对于致命性高危 PTE，绝对禁忌证亦应视为相对禁忌证。

### 介入与手术治疗

| 治疗方式 | 适应证与说明 |
|----------|------------|
| **经导管碎解和抽吸血栓** | 可同时行局部小剂量溶栓；并发症：远端栓塞、肺动脉穿孔、肺出血、心脏压塞等 |
| **下腔静脉滤器** | 不推荐常规植入。适应证：有抗凝禁忌的急性 PTE 病人，防止下肢深静脉大块血栓再次脱落。建议应用可回收滤器，通常 **2~4 周**内取出 |
| **肺动脉血栓切除术** | 作为全身溶栓的替代补救措施，适用于经积极内科或介入治疗无效的急性高危 PTE |

### CTEPH 的治疗

- **基础治疗**：长期抗凝、家庭氧疗、改善心功能和康复治疗
- **手术治疗**：阻塞部位位于手术可及的肺动脉近端 → 首选肺动脉内膜剥脱术
- **介入治疗**：远端病变 → 球囊肺动脉成形术
- **药物治疗**：不能手术/介入或术后残余肺动脉高压者 → 肺动脉高压靶向药物治疗

## 预防

| 预防类型 | 措施 |
|----------|------|
| **基本预防** | 加强健康教育、适当活动、避免脱水 |
| **药物预防** | VTE 高风险且出血风险低者：LMWH、UFH、磺达肝癸钠、DOACs 等 |
| **机械预防** | VTE 高风险但存在活动性出血或出血风险者：间歇充气加压泵、分级加压弹力袜、足底静脉泵 |

## 预后

PTE 致死率及致残率较高，国际注册研究显示 7 天和 30 天全因病死率分别为 1.9%~2.9% 和 4.9%~6.6%。我国急性 PTE 住院病死率从 2007 年的 8.5% 已降至 2016 年的 3.9%。
