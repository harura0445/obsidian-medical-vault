# 妊娠合并糖尿病


## 概述

妊娠期高血糖包括**孕前糖尿病合并妊娠（PGDM）**、糖尿病前期合并妊娠和**妊娠期糖尿病（GDM）**。其中85%以上为GDM。妊娠期高血糖对母儿均有较大危害。

- **孕前糖尿病（PGDM）**：包括1型糖尿病和2型糖尿病合并妊娠
- **妊娠期糖尿病（GDM）**：妊娠前血糖正常，妊娠期才出现的糖代谢异常，产后大多恢复正常，但将来患2型糖尿病风险增加

## 妊娠期糖代谢特点

- 妊娠早中期：空腹血糖约降低10%（胎儿摄取增加、肾糖排出增加、雌孕激素促进母体葡萄糖利用）
- 妊娠中晚期：拮抗胰岛素样物质增加（hPL、雌激素、孕激素、皮质醇等）→胰岛素敏感性下降→胰岛素需求量增加
- 胰岛素分泌不能满足需求者→血糖升高→GDM

**GDM高危因素**：高龄、超重/肥胖、多囊卵巢综合征、前次GDM史、巨大胎儿分娩史、慢性高血压、糖尿病家族史。

## 一、妊娠期糖尿病（GDM）

### 对母儿的影响

| 对象 | 影响 |
|------|------|
| **孕妇** | 妊娠期高血压疾病风险增加；泌尿生殖道感染；羊水过多；巨大胎儿→难产、产后出血；产后2型糖尿病及心血管疾病风险增加；再次妊娠GDM复发率近50% |
| **胎儿** | 巨大胎儿（高胰岛素血症→蛋白脂肪合成↑）；早产（8%～12%）；胎儿窘迫；FGR（过度限食者）；胎儿畸形（血糖控制不理想时） |
| **新生儿** | NRDS（高胰岛素血症拮抗糖皮质激素→肺表面活性物质↓）；新生儿低血糖（脱离母体高血糖环境后高胰岛素血症仍存在） |

### 诊断

- 妊娠24～28周行**75g OGTT**：空腹、1h、2h血糖阈值分别为**5.1、10.0、8.5 mmol/L**，任一点达到或超过即诊断
- 医疗资源缺乏地区：FBG≥5.1mmol/L可直接诊断
- GDM分型：A1型（饮食+运动控制达标）、A2型（需药物控制）

### 处理

**血糖控制目标**：餐前及空腹＜5.3mmol/L，餐后1h＜7.8mmol/L，餐后2h＜6.7mmol/L，夜间≥3.3mmol/L。HbA1c宜≤6.0%。

1. **医学营养治疗**：最主要手段，妊娠中晚期1800～2200kcal/d，分3正餐+2～3次加餐，低GI食物
2. **运动指导**：每周至少5日、每日30分钟中等强度运动
3. **药物治疗**：首选**胰岛素**，约10%的GDM需药物。从小剂量开始，逐步调整
4. **母儿监护**：定期超声监测胎儿生长和羊水量；A1型从34周、A2型从32周开始胎心监护

### 分娩时机与方式

| 分型 | 终止时机 |
|------|---------|
| A1型（无并发症） | 期待至妊娠40周 |
| A2型（血糖控制好） | 妊娠39周 |
| 血糖控制差/有并发症 | 个体化决定 |

GDM不是剖宫产指征。产程中将血糖控制在5.0～8.0mmol/L。产后胰岛素需求量骤减，鼓励母乳喂养。产后4～12周复查OGTT。

## 二、孕前糖尿病合并妊娠（PGDM）

### 诊断

符合以下任一项：①妊娠前已确诊糖尿病；②FBG≥7.0mmol/L，或有高血糖症状+任意血糖≥11.1mmol/L，或HbA1c≥6.5%。

### White分类法

| 级别 | 标准 |
|------|------|
| A级 | 妊娠期诊断糖尿病（A1：饮食控制，A2：需降糖药） |
| B级 | 20岁后发病，病程＜10年 |
| C级 | 发病10～19岁，或病程10～19年 |
| D级 | 10岁前发病，或病程≥20年，或合并单纯性视网膜病变 |
| F级 | 糖尿病性肾病 |
| R级 | 增生性视网膜病变或玻璃体积血 |
| H级 | 冠状动脉粥样硬化性心脏病 |
| T级 | 有肾移植史 |

### 处理

- **孕前**：评估心血管、眼底、肾功能，HbA1c尽量＜6.5%；口服降糖药改用胰岛素；ACEI/ARB类药物停用
- 血糖管理原则同GDM，多数PGDM需胰岛素治疗
- **DKA**：妊娠期出现不明原因恶心呕吐乏力+高血糖应警惕。血糖＞13.9mmol/L伴血酮体≥3mmol/L、血pH＜7.3可诊断。治疗：补液（首选NS）、胰岛素持续静滴、纠正电解质紊乱
- 血糖控制良好且无并发症者，妊娠39周终止；控制欠佳者个体化决定

### 分娩期及产褥期

处理同GDM。PGDM产后胰岛素需求减少，需及时调整。鼓励母乳喂养。
