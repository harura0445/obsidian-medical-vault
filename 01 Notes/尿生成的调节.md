## 肾内自身调节
### 球-管平衡 *glomerulotubular balance*
 - 近端小管对溶质（特别是Na+）和水的重吸收随肾小球滤过率的变化而改变，即当肾小球滤过率增大时，近端小管对Na+和水的重吸收也增大；反之，肾小球滤过率减少时， 近端小管对Na+和水的重吸收也减少。 
 - **近端小管中Na+和水的重吸收总是占肾小球滤过率的65%~70%,即近端小管的定比重吸收（constant fraction reabsorption）**

+ 近端小管定比重吸收的机制： 与肾小管周围的毛细血管压和胶体渗透压改变有关
+ 近段小管周围毛细血管内血流来自出球小动脉滤过之后，血管内成分的改变情况
+ 肾血流量不变而肾小球滤过率增加——进入近端小管旁毛细血管的血量就会减少——毛细血管血压下降而血浆胶体渗透压升高——有利于近端小管对Na+和水的重吸收

- 上皮细胞间存在紧密连接，细胞间隙内的静水压升高可促使Na+和水进入毛细血管而被重吸收，同时也有少量 Na+和水通过紧密连接回漏到小管腔内，这一现象称为泵- 漏现象
- 管周毛细管压增加或管周毛细管胶体渗透压降低导致管周毛细管重吸收减少时，则通过小管上皮细胞的紧密连接回漏到小管腔的溶质和水的量增加，从而减少对溶质和水的净的重吸收。**泵-漏现象也参与了球-管平衡的形成机制**

+ 尿中排出的Na+和水不会随肾小球滤过率的增减而出现大幅度的变化，从而保持尿钠和尿量的相对稳定。

### 小管液的溶质浓度对肾小管功能的调节
- 小管液中溶质浓度升高——**渗透压增高——肾小管对水的重吸收减少**——小管液中Na+浓度降低，和上皮细胞内Na+的浓度梯度减小——Na+重吸收减少——尿量增多，NaCl排出增多——这种现象称为**渗透性利尿（osmotic diuresis）**
- 糖尿病患者多尿；临床静脉滴注甘露醇（mannitol）
## 神经调节
### 肾交感神经的作用
- 肾交感神经支配：肾脏血管、肾小管上皮细胞（以近端小管和远端小管为主）和球旁器。
- 运动、高温、大出血、缺氧或剧痛
- 肾交感神经（递质为去甲肾上腺素）的作用途径：
	- **肾脏血管平滑肌的α受体——肾血管收缩**（入球小动脉比出球小动脉收缩更明显）— —肾小球滤过率下降
	- 近端小管和髓袢（主要是近端小管）上的α受体，增强基底侧膜钠泵，直接促进Na+、Cl-和水的重吸收。
	- **球旁细胞上的β受体——肾素释放增多**——循环血中的血管紧张素II和醛固酮增多；
- 肾交感神经活动的影响因素
	- 循环血量↑—心肺感受器/容量感受器—反射抑制—肾血流↑ 
	- 动脉血压↑ —压力感受器—减弱
	- 感觉传入神经支配（肾盂区域，感受牵张变化/尿液中化学成份的改变）：肾神经—中间神经元—投射到心血管调节相关中枢神经（延髓孤束核等）；释放递质：P-物质、降钙素基因相关肽
	- 肾-肾反射：牵拉肾盂壁/肾静脉壁—**兴奋传入神经—抑制肾交感传出神经**—尿钠、尿量↑

### 肾素-血管紧张素-醛固酮系统 （renin-angiotensin-aldosterone system, RAAS）

![[生理学3.pdf#page=45&rect=9,8,711,531|生理学3, p.45]]
- 肾素分泌的调节——肾内机制
	- 动脉血压下降——肾血流量减少——肾入球小动脉血压下降——**对小动脉壁牵张刺激减弱**——近球细胞分泌肾素增加
	- 肾入球小动脉血压下降——肾小球滤过率降低——**流过致密斑的小管液中Na+量减少**—致密斑化学感受器—刺激近球细胞分泌肾素增加
- 肾素分泌的调节——神经体液机制
	- 如急性失血——肾交感神经兴奋——去甲肾上腺素——近球细胞β受体——直接刺激肾素的释放
	- 血液循环的**肾上腺素和去甲肾上腺素**——刺激近球细胞释放肾素
	- 肾内生成的**前列腺素E2和前列环素**——刺激近球细胞释放肾素
	- **血管紧张素II、心房钠尿肽、NO**——抑制肾素的释放

+ 血管紧张素的调节作用
	+ **肾小球滤过：收缩血管减少肾血流量（入、出）**
		+ AngII 浓度低：出球小动脉敏感性>>入球—肾血流↓ &毛细血管血压↑↑ — GFR变化不大—利于肾灌注压下降时保持GFR稳定
		+ AngII 浓度高：入球小动脉敏感性*>>出球—肾血流 ↓ &毛细血管血压↓ — GFR ↓
	+ **促进近端小管重吸收NaCl：**
		+ 直接刺激：AngII受体
	+ **刺激肾上腺皮质球状带合成分泌醛固酮：**
		+ 血管紧张素II、血管紧张素III 
		+ 远曲小管、集合管重吸收水钠、分泌钾
	+ 神经系统间接作用
		+ 作用于下丘脑--释放抗利尿激素 & 引起渴觉和饮水

- 醛固酮的作用
	- 远曲小管和集合管
	- “保Na+排K+”
	- 增强顶端膜上质子泵活性，促H+分泌
	- 醛固酮诱导蛋白质
		- 钠通道，线粒体ATP合成酶，钠泵
- 醛固酮的调节
	- **血管紧张素**
	- **血K+（↑）和血Na+（↓）浓度的负反馈调节 ，直接刺激肾上腺皮质球状带分泌醛固酮↑**
	- Addison Disease 肾上腺功能损伤或者功能减退，醛固酮缺失，Na+ 重吸收↓，K+分泌↓，“排Na+保K+” —K+蓄积 
	- Cushing Syndrome 肾上腺肿瘤，过量分泌醛固酮，“保Na+排 K+”—Na+潴留 K+缺乏
### 心房钠尿肽 （atrial natriuretic peptide, ANP）
- 心房肌细胞合成并释放的肽类激素。
- **心房壁受牵拉（血量↑ ，中心静脉压↑ 等）——ANP释放**
- 乙酰胆碱、去甲肾上腺素、血管升压素和高血钾—— ANP释放

+ 心房钠尿肽的主要作用
	+ 血管平滑肌舒张和促进肾脏排Na+、排水
	+ ANP——cGMP——平滑肌细胞Ca2+浓度下降——入球小动脉舒张——肾小球滤过率增大
	+ ANP——cGMP——集合管上皮细胞顶端膜上钠通道关闭——抑制NaCl的重吸收 
	+ ANP——抑制其他激素：肾素、醛固酮和血管升压素的分泌
## 其他因素
- 激肽释放酶-激肽系统
	- 舒张肾的小动脉
	- 促进肾内NO和前列腺素的生成，使肾血流量↑，肾小球滤过率↑
	- 抑制集合管对Na和水的重吸收，对抗抗利尿激素
	- 肾素-血管紧张素系统和激肽释放酶-激肽系统在功能上相互制约、协调
	- ACE：将血管紧张素I转化为血管紧张素II，同时也可以降解缓激肽
- 前列腺素
	- GE2和PGI2，乳头部的间质细胞和集合管细胞产生
	- 正常安静的情况下，无紧张性的舒血管作用； 失血、低Na+、禁水等--交感神经兴奋或RAAS系统活动↑--去甲肾上腺素或血管紧张素Ⅱ↑--刺激PGE2& PGI2生成
	- 临床对于本身存在肾损害或肾小球灌注不足的患者，**应慎用抑制前列腺素合成的非甾体抗炎药如阿司匹林**，避免造成缺血性肾损伤、水钠潴留而加重患者的病情。
	- 负反馈调节，使缩血管效应不致过强，防止过度的肾血流量降低
	- 抑制近端小管和髓袢升支粗段对Na+的重吸收，导致尿钠排出增多
	- 在集合管，对抗抗利尿激素，导致尿量增加;
	- 刺激球旁细胞释放肾素。
- 内皮素(endothelin，ET)
	- 已知的最强烈的缩血管物质之一
	- 内皮素在内皮细胞内合成后不能储存，被立即释放。
	- 刺激因素：血管内皮所受的切应力增加、血管紧张素Ⅱ、缓激肽、儿茶酚胺、凝血酶等
	- 抑制因素：一氧化氮、心房利尿钠肽、前列腺素E、前列环素
- 一氧化氮(nitric oxide,NO)
	- 血管内皮细胞合成和释放
	- 在生理情况下，舒张血管平滑肌，并对抗AngII和NE的缩血管作用，在局部对血管的紧张性进行精细调节。
- 肾上腺素(epinephrine)和去甲肾上腺素(NE)
	- 肾上腺髓质分泌、交感神经末梢释放
	- 使肾小动脉的阻力增加，减少肾血流量
	- 促近端小管和髓袢升支粗段等部位重吸收Na+和水。
## 尿生成调节的生理意义
- 保持机体水和钠平衡
- 保持机体钾和钙磷平衡
	- 醛固酮是肾调节 K+ 和Na+排出量最重要的体液因素
	- 经肾小球滤过的Ca2+绝大部分被重吸收，随尿排出的 Ca2+ 不足 1%。
		- 最主要的因素是甲状旁腺激素（受Ca2+浓度的调控）；
		- 肾对Ca2+重吸收和排泄还受维生素D3（可促进远端小管对Ca2+的重吸收） 和降钙素（增加尿中Ca2+的排出，减少骨钙进入血液，降低细胞外液中的Ca2+ 浓度）的调控
	- 经肾小球滤过的磷大部分被肾小管(主要为近曲小管)重吸收，随尿排出的量约为10%
		- 血浆中钙、磷浓度关系密切
		- 甲状旁腺激素：抑制肾小管上皮细胞管腔膜上Na+-HPO42- 转运蛋白， 减少近曲小管对磷酸盐的重吸收； 维生素D3,可促进肾小管对磷的重吸收； 降钙素则能增加尿中磷的排出。
- 维持机体酸碱平衡
	- 肺：改变可挥发性酸(CO2)排出量来缓冲体内的酸性产物， 
	- 肾(机体内缓冲酸碱最重要、作用最持久的器官）：将固定酸排出体外并保留 HCO3-，从而保持细胞外液中的pH于正常范围内。
	- H+与HCO3-的重吸收相耦联：Na+-H+交换和质子泵主动分泌H+
	- 分泌NH₃和NH4+：降低小管液中的 H+ 浓度--保持H+ 和NH4+的分泌，& 能促进 HCO3- 重吸收
