# 肾盂肾炎

> 尿路感染（UTI）是病原体侵犯尿路上皮或组织引起的炎症反应，最常见的致病菌为大肠埃希菌，上行感染为主要感染途径。

## 分类

| 分类依据 | 类型 |
|----------|------|
| 感染部位 | 上尿路感染（肾盂肾炎）、下尿路感染（膀胱炎） |
| 有无症状 | 症状性UTI、无症状细菌尿 |
| 尿路状态 | 非复杂性UTI、复杂性UTI |
| 发作次数 | 孤立发作、反复发作性UTI（6个月内≥2次或1年内≥3次） |

约90%表现为膀胱炎，约10%为肾盂肾炎。女性发病率远高于男性，50%~80%女性一生至少发生一次UTI。

## 病因和发病机制

### 致病菌

| 类别 | 常见致病菌 |
|------|-----------|
| 社区获得性（G-杆菌为主） | **大肠埃希菌**（约85%），其次为变形杆菌、克雷伯菌 |
| 复杂性UTI | 大肠埃希菌比例降低，产ESBL耐药菌株增加，肠球菌和金黄色葡萄球菌比例增加 |

### 感染途径

| 途径 | 占比 | 特点 |
|------|------|------|
| **上行感染** | ~95% | 致病菌经尿道上行至膀胱、输尿管及肾盂 |
| 血行感染 | <2% | 多发生于免疫抑制病人，金黄色葡萄球菌、沙门菌等 |
| 直接感染 | 少见 | 邻近器官炎症直接侵入 |
| 淋巴道感染 | 罕见 | 盆腔感染经淋巴道侵入 |

### 主要易感因素

- **尿路梗阻**：结石、前列腺增生、狭窄、肿瘤
- **泌尿系统结构异常**：肾发育不全、多囊肾病、膀胱输尿管反流
- **机体免疫力低下**：糖尿病、免疫抑制剂、长期卧床、高龄
- **性别和性生活**：女性尿道短而宽，性生活可挤压致病菌入膀胱
- **妊娠**：2%~8%妊娠妇女发生UTI
- **医源性因素**：留置导尿管（1天感染率~50%，>3天>90%）

### 细菌致病力

大肠埃希菌的致病力与O、H、K抗原及P型和I型菌毛有关。具有大量K抗原的菌株易引起肾盂肾炎，菌毛可与尿道上皮细胞受体结合，促进定植和繁殖。

## 病理改变

| 类型 | 病理特征 |
|------|----------|
| 急性膀胱炎 | 膀胱黏膜血管扩张、充血、水肿，重者出血或溃疡 |
| 急性肾盂肾炎 | 肾盂肾盏黏膜充血水肿，肾间质中性粒细胞浸润和小脓肿形成，尖端指向肾乳头的楔形炎症病灶 |
| 慢性肾盂肾炎 | 肾脏体积缩小、表面不光滑，肾盂肾盏粘连变形，肾小管萎缩、间质纤维化 |

## 临床表现

### 急性膀胱炎

| 表现 | 说明 |
|------|------|
| 尿路刺激征 | 尿频、尿急、尿痛，排尿烧灼感 |
| 局部症状 | 耻骨上膀胱区疼痛不适 |
| 尿液改变 | 尿液浑浊，可有肉眼血尿 |
| 全身症状 | 一般无 |

### 急性肾盂肾炎

| 类别 | 表现 |
|------|------|
| 泌尿系统症状 | 尿路刺激征、血尿、一侧或双侧腰部疼痛、肋脊角压痛或叩击痛 |
| 全身症状 | **寒战、高热**，头痛、恶心、呕吐、食欲减退 |

### 慢性肾盂肾炎

临床表现复杂、不典型。主要表现为：
- 夜尿增多、低比重尿、白细胞尿
- 可伴低热、不同程度的腰部酸痛
- 病情持续可发展为[[慢性肾衰竭]]

### 无症状细菌尿

有真性细菌尿，缺乏临床症状和体征，诊断依靠尿细菌培养。

### 复杂性尿路感染

发生于泌尿系统结构或功能异常及合并基础疾病（糖尿病、免疫抑制等）者，治疗困难，可进展为全身重症感染。

## 并发症

| 并发症 | 表现 |
|--------|------|
| **肾乳头坏死** | 寒战高热、剧烈腰痛、腹痛和血尿，可伴败血症和AKI |
| **肾周围脓肿** | 原有症状加剧，明显单侧腰痛，向健侧弯腰时加重 |
| **尿源性脓毒血症** | 寒战高热、全身炎症反应、器官功能障碍，可致感染性休克，死亡率~30% |

## 实验室和辅助检查

### 尿液检查

| 项目 | 诊断价值 |
|------|----------|
| 尿常规 | 白细胞尿（>5个/HPF）、白细胞酯酶阳性、亚硝酸盐阳性 |
| 尿细菌涂片 | 清洁中段尿沉渣涂片细菌>1个/HPF，检出率80%~90% |
| **尿细菌培养** | 诊断UTI的关键手段。清洁中段尿细菌培养计数≥10⁵ CFU/ml为真性细菌尿 |

### 血液检查

急性肾盂肾炎时血白细胞升高、中性粒细胞增多、CRP升高、降钙素原升高。

### 影像学检查

反复发作性UTI应行B超、CT或静脉尿路造影，排除结石、梗阻、反流、畸形等。

## 诊断

### 诊断标准

| 类型 | 标准 |
|------|------|
| 急性非复杂性膀胱炎 | 尿路刺激征 + 清洁中段尿培养≥10³ CFU/ml |
| 急性非复杂性肾盂肾炎 | 寒战发热腰痛 + 清洁中段尿培养≥10⁴ CFU/ml |
| 无症状细菌尿 | 两次清洁中段尿培养为同一菌种且≥10⁵ CFU/ml |
| 复杂性UTI | 尿培养≥10⁵ CFU/ml + 泌尿系统结构/功能异常或基础疾病 |

### 定位诊断（上/下尿路感染鉴别）

| 提示上尿路感染 | 提示下尿路感染 |
|---------------|---------------|
| 寒战、发热、腰痛、恶心呕吐 | 尿路刺激征、耻骨上疼痛 |
| 尿白细胞管型 | 可有肉眼血尿 |
| 肾小管功能受损 | 肾小管功能正常 |
| CRP升高、血培养阳性 | 全身炎症反应轻 |

### 慢性肾盂肾炎诊断

除反复发作UTI病史外，需满足：
1. 肾外形凹凸不平且双肾大小不等
2. 静脉肾盂造影见肾盂肾盏变形缩窄
3. 持续性肾小管间质功能损害

以上（1）（2）任意一项 +（3）可诊断。

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| 尿道综合征 | 有尿路刺激征，多次尿培养无真性细菌尿 |
| 泌尿系统结核 | 更明显的尿路刺激征，抗生素无效，尿沉渣抗酸杆菌阳性 |
| [[原发性肾小球疾病\|慢性肾小球肾炎]] | 双侧对称受累，肾小球功能受损>肾小管，有蛋白尿、水肿病史 |

## 治疗

### 一般治疗

多饮水、勤排尿、碱化尿液，去除诱因。

### 抗感染治疗原则

1. 选用敏感抗生素，初发UTI经验性首选对G-杆菌有效药物
2. 选择尿液和肾脏浓度高的抗生素
3. 选用肾毒性小的抗生素
4. 严重感染或耐药菌时联合用药
5. 根据不同UTI类型选择种类、剂量和疗程

### 各类型UTI治疗

| 类型 | 治疗方案 |
|------|----------|
| **急性膀胱炎** | 短程疗法（推荐首选）：呋喃妥因5天、TMP-SMZ 3天、磷霉素氨丁三醇单剂量；7天疗法用于孕妇、老年、糖尿病、男性 |
| **急性肾盂肾炎（轻）** | 口服喹诺酮类或头孢菌素类，疗程7~14天 |
| **急性肾盂肾炎（重）** | 住院，静脉用头孢菌素/喹诺酮类，体温正常后继续静脉3天再改口服，总疗程2周 |
| **慢性肾盂肾炎** | 积极寻找并去除易感因素，急性发作治疗同急性肾盂肾炎 |
| **反复发作性UTI** | 急性期同首次发作，预防：多饮水、性生活后单次口服抗生素、长程低剂量抗生素 |

### 特殊类型

| 类型 | 处理 |
|------|------|
| 无症状细菌尿 | 仅孕妇和即将行泌尿系统手术者需治疗 |
| 妊娠期UTI | 膀胱炎用呋喃妥因/头孢菌素3~7天；肾盂肾炎住院静脉用第三代头孢 |
| 糖尿病并发UTI | 严格控制血糖，严重者联合静脉抗生素 |
| 复杂性UTI | 14天或更长程治疗，同时去除易感因素 |

### 疗效评定

| 结果 | 标准 |
|------|------|
| 治愈 | 症状消失，停药后2周、6周尿细菌培养阴性 |
| 治疗失败 | 治疗后尿细菌仍阳性，或2周/6周复查阳性（同一菌株） |

## 预后和预防

非复杂性UTI经及时治疗预后较好。复杂性UTI临床治愈率低，容易复发。预防措施：
- 多饮水、勤排尿
- 注意会阴部清洁
- 避免不必要的尿路器械使用
- 膀胱输尿管反流者"二次排尿"
- 去除复杂因素
