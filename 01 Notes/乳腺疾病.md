# 乳房疾病

## 解剖生理概要

乳房位于胸大肌浅面，第2~6肋水平。乳腺由15~20个腺叶组成，腺叶及乳管以乳头为中心呈**放射状**排列。Cooper韧带连接皮肤与浅筋膜深层，起支持固定作用。

**淋巴引流**（4条途径）：
① 大部分→腋淋巴结（以胸小肌为标志分Ⅰ、Ⅱ、Ⅲ组）
② 内侧→内乳淋巴结
③ 两侧乳房皮下交通
④ 深部→腹直肌鞘和肝镰状韧带→肝

## 乳房检查

### 视诊与触诊

- 视诊：形状、大小对称，乳头有无回缩/凹陷/分泌物，皮肤有无"橘皮样"改变、酒窝征
- 触诊：手指掌面按外上→外下→内下→内上→中央区顺序，注意肿块大小、硬度、边界、活动度、与皮肤/深部粘连

### 特殊检查

| 检查 | 特点 |
|------|------|
| 超声 | 不受乳腺密度影响，分辨囊/实性病灶 |
| 乳房X线摄影 | 对细小钙化敏感，用于乳腺癌筛查 |
| MRI | 软组织分辨力高，对多中心病灶优势 |
| 活组织病理 | 空芯针穿刺活检准确率90%~97% |

## 急性乳腺炎

- **病因**：乳汁淤积+细菌入侵（多为金黄色葡萄球菌），经乳管或破损乳头侵入
- **好发**：产后哺乳期妇女，初产妇多见，产后3~4周
- **临床表现**：乳房红、肿、热、痛，可触及硬块，伴发热等全身症状，可形成脓肿
- **治疗**：
  - 早期：排空乳汁（可继续哺乳）、热敷、抗生素（青霉素/头孢）
  - 脓肿形成：**切开引流**——放射状切口（乳晕区→弧形，深部/乳房后→下皱襞弧形）

## 乳腺囊性增生病

- 中年妇女常见，与激素水平波动有关
- 临床表现：乳房胀痛（月经前加重）+ 多个大小不等的结节
- 处理：定期随访，对症治疗，警惕与乳腺癌鉴别

## 乳房纤维腺瘤

- 青年妇女最常见的乳房良性肿瘤
- 特点：单个、圆形、边界清、质韧、活动度大（"乳房内的弹珠"）
- 治疗：手术切除，肿瘤+包膜完整切除

## 乳管内乳头状瘤

- 多见于经产妇，**乳头溢液**（血性或浆液性）为主要症状
- 好发于乳晕区大乳管
- 治疗：病变导管+所属腺叶切除

## 乳腺癌

### 病因与高危因素

- 遗传（BRCA1/BRCA2突变）→ [[遗传性乳腺癌-卵巢癌综合征]]
- 激素因素（初潮早、绝经晚、未生育/晚育）
- 乳腺良性病变（不典型增生）
- 环境与生活方式（高脂饮食、饮酒、肥胖）

### 病理类型

| 类型 | 特点 |
|------|------|
| 非浸润性癌 | 导管原位癌（DCIS）、小叶原位癌（LCIS），预后好 |
| 浸润性导管癌（最常见~70%） | — |
| 浸润性小叶癌 | 易双侧、多灶性 |
| 特殊类型 | 髓样癌、黏液癌、管状癌、乳头状癌等 |
| 炎性乳腺癌 | 罕见，高度恶性，预后极差 |
| 湿疹样乳腺癌（Paget病） | 乳头乳晕湿疹样改变 |

### 临床表现

| 表现 | 说明 |
|------|------|
| **乳房肿块** | 最常见首发症状，单发、质硬、边界不清、活动差，好发于外上象限 |
| **酒窝征** | 肿瘤侵犯Cooper韧带→皮肤凹陷 |
| **橘皮样改变** | 肿瘤阻塞皮下淋巴管→淋巴水肿 |
| **乳头改变** | 凹陷、偏斜、溢液（血性） |
| **皮肤卫星结节** | 肿瘤沿淋巴管扩散 |
| **铠甲胸** | 晚期大片皮肤硬结 |
| **腋淋巴结肿大** | 最常见的转移部位 |

### 转移途径

- **淋巴转移**：主要途径，腋窝→锁骨下→锁骨上；内乳淋巴结
- **血行转移**：肺、肝、骨、脑
- **直接浸润**：皮肤、胸大肌、胸壁

### 辅助检查

- 乳腺X线摄影（钼靶）：**微小钙化**是乳腺癌重要征象
- 超声：区分囊实性
- MRI：高危人群筛查、保乳术前评估
- 病理活检：确诊金标准（空芯针穿刺/真空辅助活检）

### 诊断与TNM分期

**临床分期**：
- Ⅰ期：肿瘤≤2cm，无淋巴结转移
- Ⅱ期：肿瘤2~5cm和/或同侧腋淋巴结转移（可推动）
- Ⅲ期：局部晚期（肿瘤>5cm或淋巴结融合/固定，或侵犯胸壁/皮肤）
- Ⅳ期：远处转移

### 鉴别诊断

- 纤维腺瘤、乳腺囊性增生病、乳管内乳头状瘤、叶状肿瘤

### 治疗原则

**综合治疗**——手术为主，辅助放/化疗、内分泌治疗、靶向治疗。

**手术治疗**：

| 术式 | 范围 |
|------|------|
| 乳腺癌改良根治术 | 全乳+腋淋巴结清扫，保留胸大肌/胸小肌 |
| 保乳手术 | 肿瘤扩大切除+腋淋巴结清扫+术后放疗 |
| 全乳切除术 | 全乳切除，不清扫腋淋巴结 |

**辅助治疗**：
- **化疗**：术后辅助化疗提高生存率（CAF、TAC等方案）
- **放疗**：保乳术后必放疗；根治术后高危者（≥4个淋巴结阳性）放疗
- **内分泌治疗**：ER/PR阳性者用他莫昔芬（绝经前）/芳香化酶抑制剂（绝经后）
- **靶向治疗**：HER-2阳性者用曲妥珠单抗
