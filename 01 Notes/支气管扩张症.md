# 支气管扩张症

> 支气管扩张症是各种原因引起支气管壁结构破坏，导致支气管异常和持久性扩张的一类异质性疾病，以慢性咳嗽、大量脓痰和反复咯血为特征。

## 概述

支气管扩张症（bronchiectasis）指急、慢性呼吸道感染和支气管阻塞后，反复发生支气管化脓性炎症，致使支气管壁结构破坏、管壁增厚，引起支气管异常和持久性扩张。主要分为囊性纤维化（CF）导致的支气管扩张症和非囊性纤维化导致的支气管扩张症，本章主要讨论后者。

**流行病学**：患病率各国报道差别较大，约（1～52）/10 万。我国 40 岁以上人群中患病率可达 1.2%。部分 [[慢性阻塞性肺疾病]] 病人合并支气管扩张的比例高达 30%。反复感染导致肺功能下降，最终可出现 [[慢性呼吸衰竭]]，整体预后较差。

## 病因与危险因素

本病分为先天性和继发性。

| 类别 | 病因 |
|------|------|
| **感染** | 细菌（铜绿假单胞菌、流感嗜血杆菌、肺炎克雷伯菌、金葡菌等）、真菌（曲霉菌）、分枝杆菌（结核分枝杆菌、NTM）、病毒（腺病毒、流感病毒、麻疹病毒等） |
| **免疫缺陷/异常** | 原发性低免疫球蛋白血症（IgG 亚群缺陷）、继发性（HIV、长期免疫抑制药、慢性淋巴细胞白血病、肺移植后）、免疫异常（干燥综合征、ABPA、类风湿关节炎） |
| **先天性遗传病** | α₁-抗胰蛋白酶缺乏、原发性纤毛不动综合征/Kartagener 综合征、囊性纤维化（白种人常见） |
| **先天性结构缺损** | 巨气管支气管症、支气管软骨发育缺陷、肺隔离症、Marfan 综合征 |
| **气道阻塞** | 外源性压迫、异物、肿瘤、黏液阻塞、肺叶切除后解剖移位 |
| **其他** | 毒性物质吸入（氨气、氯气）、炎症性肠病（溃疡性结肠炎） |

**高危人群筛查指征**：
1. 慢性咳嗽咳痰，尤其有脓性痰或咯血者
2. 慢阻肺病频繁急性加重（≥2 次/年），重症哮喘或控制不佳，且曾有痰培养铜绿假单胞菌（+）
3. 慢性鼻窦炎、风湿性疾病或其他结缔组织疾病，出现慢性咳嗽咳痰或反复肺部感染
4. HIV 感染、实体器官移植、接受免疫抑制剂治疗出现慢性咳嗽咳痰者

## 发病机制

**"恶性循环"学说**为核心机制：

```
感染/炎症 → 气道黏液高分泌 → 黏液清除障碍
    ↑                            ↓
    │                      细菌定植与繁殖
    │                            ↓
    └──────── 气道和肺结构性破坏 ←┘
              （肺功能恶化）
```

各种诱因导致慢性支气管感染，引起呼吸道炎症反应，致使气道黏液高分泌、黏液清除障碍，细菌定植和繁殖，造成气道和肺的结构性破坏，肺功能恶化，进一步促进肺感染发生。各环节相互促进，形成恶性循环。治疗需在各个节点阻断该循环。

继发性支气管扩张大多为细菌、结核/NTM、病毒、真菌感染后出现。反复感染使充满炎症介质和病原菌的黏稠脓性液体的气道逐渐扩大、形成瘢痕和扭曲。支气管壁因水肿、炎症和新血管形成而增厚。周围间质组织和肺泡破坏导致纤维化、肺气肿或二者兼有。

## 病理

病变常位于段或亚段支气管。受累管壁的软骨、肌肉和弹性组织被破坏，由纤维组织替代。

**三种病理类型**：

| 类型 | 特征 |
|------|------|
| **柱状扩张** | 支气管呈均一管形扩张，突然在一处变细，远处小气道被分泌物阻塞 |
| **囊状扩张** | 支气管腔呈囊状改变，末端盲端呈无法辨认的囊状结构 |
| **不规则扩张** | 支气管腔呈不规则或串珠样改变 |

显微镜下可见支气管炎症和纤维化、管壁溃疡、鳞状上皮化生和黏液腺增生。病变支气管相邻肺实质可有纤维化、肺气肿、支气管肺炎和肺萎陷。炎症致支气管壁血管增多，伴支气管动脉扩张及支气管动脉-肺动脉吻合。

肺功能方面，50% 的病人可有阻塞性通气功能障碍，限制性通气功能障碍更为常见。

## 临床表现

### 症状

**稳定期**：持续或反复的咳嗽、咳痰或咳脓痰。痰液为黏液性、黏液脓性或脓性，可呈黄绿色，收集后分层：
- 上层：泡沫
- 中层：浑浊黏液
- 下层：脓性成分
- 最下层：坏死组织

**咯血**：50%～70% 的病例可发生咯血，大咯血常为小动脉被侵蚀或增生血管被破坏所致。部分病人以反复咯血为唯一症状，称为**"干性支气管扩张症"**。

**急性加重期**（BTS 指南标准）：48 小时内出现以下 6 项中 ≥3 项症状恶化——
- 咳嗽程度加重
- 咳痰量增加
- 脓性痰
- 呼吸困难或活动耐受度下降
- 乏力或不适
- 咯血

呼吸困难和喘息常提示广泛支气管扩张或有潜在的 [[慢性阻塞性肺疾病]]。

### 体征

- 听诊可闻及**湿啰音和干啰音**
- 病变严重者（尤其伴慢性缺氧、[[慢性肺源性心脏病]] 和右心衰竭者）可出现**杵状指（趾）**
- 右心衰竭体征（见 [[心力衰竭]]）

## 辅助检查

### 影像学检查

| 检查方法 | 表现 |
|----------|------|
| **胸部 X 线** | 严重者可见"卷发征"；囊状支气管扩张可见囊腔，腔内可有气液平面 |
| **HRCT（确诊主要方法）** | 支气管内径/伴行肺动脉直径比值 >1；柱状/囊状改变；气道壁增厚；黏液阻塞；树芽征；呼气相"马赛克征"及气体陷闭；"双轨征""印戒征""蜂窝状/卷发状"改变 |

> HRCT 兼具无创、易重复、易接受的特点，已成为支气管扩张症的主要诊断方法（层厚 ≤1mm）。支气管碘油造影已被 HRCT 取代。

### 实验室检查

- **血常规及炎症标志物**：急性加重时白细胞、中性粒细胞百分比、CRP 升高
- **血清免疫球蛋白**：合并免疫功能缺陷者 IgG、IgA、IgM 缺乏
- **血气分析**：判断是否合并低氧血症和/或高碳酸血症
- **微生物学检查**：痰涂片 + 培养 + 药敏；痰中找抗酸杆菌（区分结核分枝杆菌 vs NTM）
- **病因学检查**：类风湿因子、抗核抗体、抗中性粒细胞胞质抗体；怀疑 ABPA 时查血清 IgE、烟曲霉皮试、曲霉沉淀素；怀疑 PCD 时查鼻呼出气 NO 测定、纤毛电镜检查、基因检测

### 其他检查

- **纤维支气管镜**：局灶性且位于段支气管以上时可发现弹坑样改变，用于病原学诊断、病理诊断及明确出血/阻塞部位，还可局部灌洗
- **肺功能**：部分病人存在限制性、阻塞性或混合性通气功能障碍

## 诊断与鉴别诊断

### 诊断标准

根据**反复咳脓痰、咯血**病史和既往诱发支气管扩张症的呼吸道感染病史，**HRCT 显示支气管扩张的异常影像学改变**，即可明确诊断。诊断后还应进一步明确病因。

### 严重程度评估

| 评分工具 | 用途 | 分级 |
|----------|------|------|
| **BSI（支气管扩张严重指数）** | 预测病情恶化、住院、死亡风险 | 0～4 轻度，5～8 中度，≥9 重度 |
| **E-FACED** | 预测未来急性加重和住院风险 | 0～3 轻度，4～6 中度，7～9 重度 |

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| **慢性支气管炎** | 中年以上，冬春季节多发，咳白色黏液痰，感染时可有脓性痰，无反复咯血史；听诊双肺散在干湿啰音 |
| **肺脓肿** | 起病急，高热、咳嗽、大量脓臭痰；X 线见局部浓密炎症阴影，内有空腔液平 |
| **[[肺结核]]** | 低热、盗汗、乏力、消瘦等结核毒性症状；干湿啰音多局限于上肺；痰结核菌检查可确诊 |
| **先天性肺囊肿** | X 线见多个边界纤细的圆形/椭圆形阴影，壁薄，周围无炎症浸润 |
| **弥漫性泛细支气管炎** | 慢性咳嗽、咳痰、活动时呼吸困难及慢性鼻窦炎；X 线/CT 示弥漫分布小结节影；大环内酯类治疗有效 |
| **[[肺癌]]（支气管肺癌）** | 40 岁以上多见，咳嗽、咳痰、胸痛，痰中带血；大咯血少见；影像学、痰细胞学、支气管镜可确诊 |

## 并发症

- [[慢性呼吸衰竭]]
- [[慢性肺源性心脏病]]
- 大咯血（小动脉被侵蚀或增生血管被破坏）
- 肺气肿、肺大疱
- 铜绿假单胞菌定植（肺功能下降更明显）
- 曲霉菌定植/感染（曲霉球、慢性纤维空洞样改变、侵袭性感染）

## 治疗

### 治疗基础疾病

活动性 [[肺结核]] 伴支气管扩张症应积极抗结核治疗；低免疫球蛋白血症可用免疫球蛋白替代治疗。

### 控制感染

**急性加重期**：应用抗菌药物前常规送痰培养。根据有无铜绿假单胞菌感染高危因素选择方案：

| 危险分层 | 抗菌方案 |
|----------|----------|
| **无铜绿假单胞菌高危因素** | 氨苄西林/舒巴坦、阿莫西林/克拉维酸；第二代头孢菌素；第三代头孢菌素（头孢曲松、头孢噻肟）；莫西沙星、左氧氟沙星 |
| **有铜绿假单胞菌高危因素**（4 条中 ≥2 条见下） | 抗假单胞菌 β-内酰胺类（头孢他啶、头孢吡肟、哌拉西林/他唑巴坦、头孢哌酮/舒巴坦）；碳青霉烯类（亚胺培南、美罗培南）；氨基糖苷类；环丙沙星/左氧氟沙星（可单用或联合） |

**铜绿假单胞菌高危因素**（4 条中 ≥2 条）：
1. 近期住院
2. 每年 4 次以上或近 3 个月以内应用抗生素
3. 重度气流阻塞（FEV₁ < 30% 预计值）
4. 最近 2 周每日口服泼尼松 > 10mg

**长期抗生素治疗**：十四元环/十五元环大环内酯类（阿奇霉素、克拉霉素、红霉素）利用免疫调节作用，长期口服（可达一年）可减少急性加重频率。需监测肝肾功能、心电图（Q-T 间期）、听力。雾化吸入妥布霉素可清除定植微生物、减少急性加重。

**首次分离铜绿假单胞菌**：环丙沙星 500mg bid × 2 周口服 + 后续 3 个月吸入妥布霉素。

### 改善气流受限

长效支气管扩张剂（LABA、LAMA、ICS/LABA）可改善气流受限并帮助清除分泌物，对伴有气道高反应及可逆性气流受限者有一定疗效。

### 清除气道分泌物

- **物理排痰**：体位引流（头低臀高，配合震动拍背）、胸壁震荡、正压通气、主动呼吸训练
- **雾化吸入**：生理盐水、高渗盐水、黏液溶解剂（乙酰半胱氨酸）
- **药物**：黏液溶解剂（乙酰半胱氨酸）、痰液促排剂、抗氧化剂

### 免疫调节

使用细菌细胞壁裂解产物等免疫增强剂可减少急性发作。大环内酯类长期治疗兼具免疫调节作用。

### 咯血治疗

| 出血量 | 处理 |
|--------|------|
| **少量咯血** | 对症治疗，口服卡巴克洛、卡络磺钠、云南白药 |
| **中等量** | 静脉给予垂体后叶素或酚妥拉明（注意低钠血症） |
| **大量咯血（内科治疗无效）** | 介入栓塞治疗（支气管动脉栓塞术）或手术切除 |

### 外科治疗

- 局限性支气管扩张、经充分内科治疗仍顽固反复发作 → 外科手术切除病变肺组织
- 大出血来自增生支气管动脉、保守治疗不能缓解、病变局限者 → 手术；否则行支气管动脉栓塞术
- 所有治疗仍致残的病例、合适者 → 肺移植

## 预后

取决于支气管扩张范围和有无并发症：
- **范围局限**：积极治疗可改善生命质量、延长寿命
- **范围广泛**：易损害肺功能，可发展至 [[慢性呼吸衰竭]] 而死亡
- **预后不良因素**：大咯血、合并铜绿假单胞菌定植、肺实质损害（肺气肿和肺大疱）、合并 [[慢性阻塞性肺疾病]]

## 预防

- 接种肺炎球菌疫苗、流感疫苗和新冠病毒疫苗
- 免疫调节剂减轻症状和减少发作
- 戒烟
- 康复锻炼保持肺功能
