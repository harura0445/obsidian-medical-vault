# 结直肠常见良性疾病

## 痔

**定义**：肛垫的支持结构、静脉丛及动静脉吻合发生病理性改变→肛垫充血增生肥大移位形成内痔。齿状线远侧皮下静脉丛扩张或结缔组织增生形成外痔。内痔+外痔融合→混合痔。

**病因学说**：
- **肛垫下移学说**：Treitz肌弹性回缩减弱→肛垫充血下移
- **静脉曲张学说**：直肠静脉无瓣膜、管壁薄、位置低→易淤血扩张

### 分类与临床表现

| 类型 | 部位 | 主要表现 |
|------|------|----------|
| **内痔** | 齿状线以上（截石位3、7、11点好发） | 出血（间歇性便后滴血）+脱出，无疼痛（除非血栓/嵌顿） |
| **外痔** | 齿状线以下 | 肛缘皮赘、不适、瘙痒 |
| **血栓性外痔** | — | 肛周剧痛、暗紫色卵圆形肿物 |
| **混合痔** | 齿状线上下融合 | 内痔+外痔症状 |

**内痔分度**：

| 度 | 特点 |
|----|------|
| Ⅰ度 | 便时带血/滴血，无脱出 |
| Ⅱ度 | 排便时脱出，自行还纳，可伴出血 |
| Ⅲ度 | 脱出需手推还纳，可伴出血 |
| Ⅳ度 | 脱出不能还纳或还纳后再脱出 |

### 诊断

**体位**：排便后蹲位观察最清晰。直肠指诊排除直肠癌。肛门镜检查痔核。

**鉴别**：直肠癌（指诊+肠镜）、直肠息肉、肥大肛乳头、直肠脱垂。

### 治疗

**原则**：无症状不治疗、有症状减轻/消除症状（非根治）、以非手术为主。

| 方法 | 适用 |
|------|------|
| 一般治疗 | 增加膳食纤维、改变排便习惯、热水坐浴 |
| 注射疗法 | Ⅰ、Ⅱ度出血性内痔（硬化剂注射使痔萎缩） |
| 胶圈套扎疗法 | Ⅰ、Ⅱ、Ⅲ度内痔（弹性胶圈阻断血运→坏死脱落） |
| 手术治疗（痔切除术） | Ⅲ、Ⅳ度内痔、混合痔、血栓性外痔 |

## 肛裂

肛裂是齿状线下肛管皮肤全层裂伤后形成的小溃疡，方向与肛管纵轴平行。好发于**后位**，青壮年多见。

### 病因

- **解剖因素**：肛管后方韧带硬、弹性差、血供差，排便时后壁承受压力大
- **损伤**：便秘、干硬粪便、分娩
- **感染**：慢性炎症刺激→肛管皮肤纤维化→弹性减弱

### 临床表现

**肛裂三联征**：裂口、前哨痔、肛乳头肥大。

| 症状 | 特点 |
|------|------|
| **疼痛** | **周期性疼痛**：排便时撕裂样痛→便后缓解间隙期→括约肌痉挛再次剧痛（持续1h~数h） |
| 便血 | 便后滴血/手纸染血，量少，鲜红 |
| 便秘 | 怕痛不敢排便→粪干便秘→排便更痛→恶性循环 |

### 诊断

典型病史+周期性肛门疼痛即可诊断。直肠指诊在肛门剧痛时需在局麻下进行。

### 治疗

**原则**：消除症状、解除痉挛、中断恶性循环。

- **非手术**：膳食纤维+温水坐浴+润肠通便+扩肛
- **手术**：肛裂切除术、内括约肌切断术

## 肛周脓肿

肛管直肠周围软组织或其间隙的急性化脓性感染。青壮年男性多见。

**病因**：绝大部分由**肛腺感染**所致。肛窦开口向上→粪渣存留→肛窦炎→肛腺感染→括约肌间感染→各间隙脓肿。

### 分类（以肛提肌为界）

| 低位脓肿 | 高位脓肿 |
|----------|----------|
| 肛周皮下脓肿（最常见） | 骨盆直肠间隙脓肿 |
| 坐骨直肠窝脓肿 | 直肠后间隙脓肿 |
| 肛管后间隙脓肿 | 直肠黏膜下脓肿 |
| 低位肌间脓肿 | 高位肌间脓肿 |

### 临床表现

| 类型 | 局部表现 | 全身表现 |
|------|----------|----------|
| 肛周皮下脓肿 | 明显红肿、疼痛、波动感 | 不明显 |
| 坐骨直肠窝脓肿 | 持续性胀痛→跳痛、局部大片红肿 | 较明显（发热、寒战） |
| 骨盆直肠间隙脓肿 | 会阴/直肠坠胀感、定位不清 | 严重（高热、寒战、中毒） |

### 治疗

脓肿**一旦确诊应尽早切开引流**。切开挂线术可一次治愈避免二次肛瘘手术。

## 肛瘘

肛瘘是指肛管直肠周围的肉芽肿性管道，由**内口、瘘管、外口**组成。多为肛周脓肿破溃或切开引流后形成。特点：**反复发作、经久不愈**。

### Parks分类（按瘘管与括约肌关系）

| 类型 | 占比 | 特点 |
|------|------|------|
| **肛管括约肌间型** | ~70% | 瘘管走行于内外括约肌之间，多为低位肛瘘 |
| 经肛管括约肌型 | ~25% | 瘘管穿过外括约肌→坐骨直肠窝→肛周皮肤 |
| 肛管括约肌上型 | ~4% | 高位肛瘘 |
| 肛管括约肌外型 | ~0.5% | 处理最难，多由其他原因引起 |

### 临床表现

外口反复流出脓性/血性分泌物→肛周潮湿瘙痒。外口愈合→脓肿形成→疼痛+全身感染→穿破/切开→症状缓解→**反复发作**。

**Goodsall规律**：横线前方→瘘管直型；横线后方→瘘管弯型。

### 治疗

肛瘘极少自愈，以手术治疗为主。
- **瘘管切开术**：适用低位肛瘘
- **挂线疗法**：利用橡皮筋缓慢切开→防止严重肛门失禁
- **肛瘘切除术**：切除瘘管壁至健康组织

## 直肠息肉

### 非肿瘤性息肉

- 增生性息肉（最常见非肿瘤性息肉，多发、直径<5mm）
- 炎性息肉
- 错构瘤性息肉

### 肿瘤性息肉（腺瘤）

- 管状腺瘤
- 绒毛状腺瘤（恶变率最高）
- 无蒂锯齿状腺瘤/息肉（SSA/P，BRAF突变相关癌前病变）
- 传统锯齿状腺瘤（TSA，KRAS突变相关）

**治疗**：有蒂或直径<2cm的无蒂腺瘤→内镜下切除；更大者→手术治疗。

### Peutz-Jeghers综合征

错构瘤性息肉病，口唇及四肢末端色素沉着（黑色/棕黄色斑）。息肉可遍布全消化道，多见于小肠。

### 家族性腺瘤性息肉病（FAP）

APC基因突变（常染色体显性遗传），结直肠布满腺瘤（>100颗）。**不治疗几乎100%癌变**，平均癌变年龄~39岁。 → [[多发性家族性结肠息肉]]

### Gardner综合征

FAP伴肠外表现（骨瘤、软组织瘤），癌变倾向明显。
