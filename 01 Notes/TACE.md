# TACE

**经导管动脉化疗栓塞术（Transarterial Chemoembolization, TACE）** 是将化疗药物与栓塞剂经肝动脉注入肿瘤供血动脉，实现 **局部化疗 + 动脉栓塞** 双重作用的介入治疗手段。是**不可切除中晚期肝细胞癌（HCC）** 的一线标准疗法。

---

## 原理

### 解剖/生理基础

| 血供来源 | HCC 占比 | 正常肝组织占比 |
|---------|----------|--------------|
| 肝动脉 | **90%–95%** | 25%–30% |
| 门静脉 | 5%–10% | 70%–75% |

> TACE 利用 HCC 几乎完全依赖肝动脉供血的特点，通过肝动脉（而非门静脉）定向给药和栓塞，**最大限度地杀伤肿瘤、最小限度损伤正常肝组织**。

### 双重作用机制

1. **化疗作用**：高浓度化疗药物选择性灌注至肿瘤区域，局部药物浓度可达全身化疗的数十至上百倍
2. **栓塞作用**：栓塞剂阻断肿瘤供血动脉，导致肿瘤 **缺血坏死**；同时减缓血流冲刷，延长化疗药物在肿瘤区域的滞留时间

## 适应证

依据《[[原发性肝癌诊疗指南（2024年版） 肝脏疾病|国家卫健委原发性肝癌诊疗指南（2024年版）]]》及相关共识，TACE 适用于：

### 标准适应证

- **不能手术切除的中晚期 HCC**（BCLC B 期首选，部分 BCLC C 期）
- **[[肝功能分级|肝功能]] Child-Pugh A / B 级**
- **ECOG PS 0–2 分**
- 肿瘤占肝脏体积 < 70%

### 特殊应用

- **移植前桥接治疗**：等待肝移植期间控制肿瘤进展（符合 Milan/up-to-seven 标准）
- **术后辅助/预防性 TACE**：高复发风险 HCC 术后（微血管侵犯、切缘可疑阳性等）
- **降期治疗**：将超出 Milan/transplant 标准的肿瘤降期至符合标准
- **联合治疗**：与消融、放疗、[[分子靶向药|靶向药物]] 或 [[免疫治疗药物|免疫治疗]] 联合

---

## 禁忌证

| 分类 | 具体 |
|------|------|
| **绝对** | — [[肝功能分级|肝功能]] **Child-Pugh C 级**（无肝移植计划）<br>— 严重 **门静脉主干完全阻塞**，且无侧支循环形成<br>— 肿瘤占肝体积 ≥ 70%<br>— 弥漫性肝外广泛转移<br>— 严重凝血功能障碍（INR > 2.0，PLT < 50×10⁹/L）<br>— 肾功能不全（Cr > 2 mg/dL 或 CrCl < 30 mL/min）<br>— 活动性感染、败血症 |
| **相对** | — 门静脉分支癌栓<br>— 胆道梗阻/支架术后<br>— 大量腹水<br>— 既往经肝动脉化疗栓塞后肝功能严重恶化 |

> **关于门静脉癌栓**：既往被认为是绝对禁忌，目前对于 **门静脉分支癌栓（Vp1–Vp3）** 或主干癌栓但侧支循环良好者，可行 **TACE + 放疗/靶向/免疫** 联合治疗。

## 操作流程

### 术前准备

- 影像学评估：增强 CT / MRI（明确肿瘤数目、大小、血供、门静脉情况）
- 肝功能、凝血功能、血常规、肾功能、AFP / 肿瘤标志物
- 术前禁食 4–6 h
- 碘过敏试验（若使用含碘对比剂）

### 手术步骤

```
Seldinger 技术穿刺股动脉（或桡动脉）
       ↓
插管至腹腔干 → 肝总动脉 → 肝固有动脉
       ↓
造影明确肿瘤供血动脉和门静脉血流
       ↓
微导管超选择性插管至肿瘤供血动脉
       ↓
缓慢注入 (化疗药 + 碘化油) 混合乳剂
       ↓
注入颗粒栓塞剂（PVA / 微球 / DEB）至血流停滞
       ↓
复查造影确认栓塞满意
       ↓
拔管、压迫止血、加压包扎
```

### 术后处理

- 卧床 24 h，术侧肢体制动
- 监测生命体征、肝肾功能、血常规
- 对症处理 **栓塞后综合征**（见并发症）

## 常用药物与栓塞材料

### 化疗药物

| 药物 | 常用剂量 | 备注 |
|------|---------|------|
| 表阿霉素（Epirubicin） | 40–80 mg | 最常用 |
| 阿霉素（Doxorubicin） | 30–60 mg | 心脏毒性 |
| 顺铂（Cisplatin） | 40–60 mg | 肾毒性，需水化 |
| 丝裂霉素 C（Mitomycin C） | 10–20 mg | 骨髓抑制 |
| 洛铂（Lobaplatin） | 30–50 mg | 肾毒性较低 |

### 栓塞材料

| 类型 | 代表 | 特点 |
|------|------|------|
| **碘化油** | Lipiodol（超液化碘油） | 传统 cTACE 核心；选择性滞留肿瘤血管，兼具载体和栓塞作用；可携带化疗药物 |
| **颗粒栓塞剂** | PVA 颗粒、明胶海绵 | 机械栓塞；非永久/永久 |
| **载药微球** | DC-Bead、HepaSphere、CalliSpheres（国产） | **DEB-TACE**；可装载化疗药物缓慢释放，血药浓度低，全身副作用小 |

## 分类

### cTACE（Conventional TACE）vs DEB-TACE

| 项目 | cTACE | DEB-TACE |
|------|-------|----------|
| 载体 | 碘化油 + 化疗药物乳剂 | 载药微球（DEB） |
| 栓塞程度 | 末梢 + 近端栓塞 | 末梢栓塞为主 |
| 药物释放 | 快速洗脱 | **缓慢持续释放** |
| 全身药物暴露 | 相对较高 | 更低 |
| 客观缓解率（ORR） | ~52% | ~62%（部分研究更高） |
| 不良反应 | 栓塞后综合征较明显 | 栓塞后综合征较轻 |
| 费用 | 较低 | 较高 |

> 目前 **DEB-TACE 在客观缓解率和不良反应方面优于或非劣于 cTACE**，但两者在总生存期（OS）获益上尚无一致结论。

## 并发症

### 栓塞后综合征（Post-embolization Syndrome, PES）

- **发生率**：50%–80%
- **表现**：发热、腹痛、恶心呕吐
- **机制**：肿瘤坏死 + 炎症反应
- **处理**：对症支持（镇痛、止吐、退热）；通常 3–7 天自行缓解

### 其他并发症

| 并发症 | 处理 |
|--------|------|
| **肝脓肿** | 抗生素；必要时穿刺引流（有胆道手术/支架史者风险↑） |
| **肝衰竭** | 保肝、支持；严重者肝移植评估 |
| **胆囊炎/胆囊梗死** | 栓塞剂误入胆囊动脉；保守或抗生素 |
| **胰腺炎** | 栓塞剂反流至胰十二指肠动脉；禁食、生长抑素等 |
| **消化道出血** | 应激性溃疡 / 门脉高压性胃病 |
| **对比剂肾病** | 水化、限对比剂用量 |
| **穿刺点并发症** | 血肿、假性动脉瘤、动静脉瘘 |

## 疗效评价

### 评价标准

- **mRECIST**（改良 RECIST 标准）：基于存活肿瘤（增强动脉期强化区域）测量
- 常用指标：CR（完全缓解）、PR（部分缓解）、SD（稳定）、PD（进展）
- **客观缓解率（ORR）** = CR + PR

### 近期疗效（参考数据）

| 指标 | 数值 |
|------|------|
| ORR（cTACE） | 52%–63% |
| ORR（DEB-TACE） | 58%–72% |
| 疾病控制率（DCR） | 75%–85% |
| 中位 OS（BCLC B 期） | 26–30 个月 |

> TACE 需要**重复治疗**（一般 1–3 次，间隔 4–8 周），至肿瘤完全灭活或出现无法耐受的不良反应。

## 联合治疗策略

TACE 与其他治疗手段的联合是当前 HCC 治疗的重要方向：

### TACE + 消融（RFA/MWA）

| 适用情况 | 理由 |
|---------|------|
| 单发 3–7 cm 肿瘤 | TACE 缩小肿瘤、减少散热效应，提高消融完全灭活率 |
| 多发结节（≤ 3 个） | 消融处理残余活性灶 |

### TACE + 靶向治疗

- **索拉非尼**、**仑伐替尼**：抑制 VEGF / FGF 等信号通路，对抗 TACE 术后 VEGF 升高（"TACE 术后 VEGF 反弹"）
- 循证基础：TACTICS 试验（TACE + 索拉非尼→ PFS 显著获益）

### TACE + 免疫治疗

- **PD-1/PD-L1 抑制剂**（信迪利单抗、替雷利珠单抗、阿替利珠单抗 + 贝伐珠单抗等）
- TACE 引起的肿瘤坏死释放 **肿瘤抗原** → 可能增强免疫应答（"冷"→"热"肿瘤转化）
- 多项 III 期临床（如 LAUNCH、EMERALD-1、EMERALD-2）支持联合方案的 OS/PFS 获益

### TACE + HAIC

**HAIC**（肝动脉灌注化疗）与 TACE 的区别：

| 项目 | TACE | HAIC |
|------|------|------|
| 操作 | 一次性完成灌注 + 栓塞 | 留置导管连续输注（如 FOLFOX 方案 46 h） |
| 化疗持续时间 | 数分钟（与碘油混合后缓慢释放） | 持续 24–48 h |
| 栓塞 | 是（核心步骤之一） | 否 |
| 适用 | 富血供结节型/块状 HCC | 伴门静脉癌栓、弥漫型 HCC |
| 联合 | — | 可与 TACE 序贯使用 |

## 与 BCLC 分期对应关系

```
BCLC 0（极早期）         → 手术 / 消融
BCLC A（早期）           → 手术 / 消融 / 移植
BCLC B（中期）           → TACE（首选） ←
BCLC C（晚期）           → 系统治疗（靶免）；部分可 TACE + 系统治疗
BCLC D（终末期）         → 最佳支持治疗
```
