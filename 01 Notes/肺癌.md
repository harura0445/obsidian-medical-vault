# 肺癌

> 肺癌（原发性支气管癌）是起源于呼吸上皮细胞的最常见肺部原发性恶性肿瘤，分为小细胞肺癌和非小细胞肺癌两大类，发病率和死亡率在中国恶性肿瘤中均居首位。

## 概述

肺癌（lung cancer）或称原发性支气管癌，WHO定义为起源于呼吸上皮细胞（支气管、细支气管和肺泡）的恶性肿瘤。发病高峰55\~65岁，男性多于女性（男女比约2.1:1）。约75%病人出现症状就诊时已属晚期，整体5年生存率约20%。

### 流行病学

- 2020年全球新发肺癌220.0万（占所有癌症11.4%），死亡180.0万（占所有癌症死亡18.0%）
- 2022年中国新发肺癌87.0万，死亡76.6万
- 中国男性发病率和死亡率在所有癌症中列**首位**，女性发病率第三位、死亡率第二位

## 病因与危险因素

| 危险因素 | 说明 |
|---------|------|
| **吸烟** | 约85%肺癌病人有吸烟史，吸烟者肺癌风险比不吸烟者平均高10倍（重度吸烟者10\~25倍）；二手烟增加风险20%\~30%；开始吸烟年龄越小风险越大 |
| 职业致癌因子 | 石棉、砷、铬、镍、铍、多环芳香烃、氡及氡子体、电离辐射等，风险增加3\~30倍 |
| 空气污染 | PM2.5与肺癌发病率和死亡率相关；室内煤烟污染对女性腺癌影响较大 |
| 电离辐射 | 自然界和医疗照射（X线诊断占36.7%） |
| 饮食与体力活动 | 水果蔬菜摄入量低、血清β胡萝卜素水平低者风险升高；中高强度体力活动可使风险下降13%\~30% |
| 遗传因素 | 肺癌家族史（60岁前）风险升高2倍；涉及癌基因（*HER*、*RAS*、*MYC*、*ALK*、*Sox*、*MDM2*）激活和抑癌基因（*TP53*、*RB1*、*CDKN2A*、*PTEN*）失活 |
| 其他肺部疾病 | 结核病（风险增加10倍）、[[慢性阻塞性肺疾病]]、结节病、特发性肺纤维化、硬皮病等 |

## 病理分类

### 按解剖学部位分类

| 类型 | 定义 | 常见病理类型 |
|------|------|------------|
| 中央型肺癌 | 发生在段及以上支气管 | 鳞状细胞癌、小细胞肺癌 |
| 周围型肺癌 | 发生在段支气管以下 | 腺癌 |

### 按组织病理学分类

#### 非小细胞肺癌（NSCLC，约占85%）

| 亚型 | 占比 | 特点 |
|------|------|------|
| **腺癌** | 最常见类型 | 女性多见，周围型为主；起源于支气管黏液腺；富含血管，血行转移较早；易累及胸膜致[[胸腔积液]]。亚型包括微浸润性腺癌（MIA）、浸润性非黏液腺癌（贴壁型/腺泡型/乳头型/微乳头型/实体型）、浸润性黏液腺癌、胶样型腺癌等 |
| **鳞状细胞癌** | 约25% | 老年男性多见，中央型为主，与吸烟关系最密切；易坏死形成空洞或癌性肺脓肿；生长较慢，转移晚，手术机会多；免疫组化CK5/6、p40、p63阳性 |
| 大细胞癌 | <10% | 未分化NSCLC，诊断仅限于手术切除标本；转移较晚，手术切除机会较大 |
| 其他 | 少见 | 腺鳞癌、肉瘤样癌、肺NUT癌、唾液腺型癌等 |

**肺腺癌IASLC分级（浸润性非黏液腺癌）**：
- 1级（高分化）：贴壁为主型，无或<20%高级别成分
- 2级（中分化）：腺泡或乳头为主型，无或<20%高级别成分
- 3级（低分化）：任何类型伴有≥20%高级别成分

#### 小细胞肺癌（SCLC，约占15%）

| 特征 | 说明 |
|------|------|
| 分化 | 低分化神经内分泌肿瘤，包括小细胞癌和复合性小细胞癌 |
| 细胞 | 小圆形或卵圆形，胞质少，核细颗粒状，核仁不明显 |
| 免疫组化 | CD56、突触素、嗜铬粒蛋白阳性；Ki-67（50%\~100%） |
| 生物学行为 | **增殖快速、早期广泛转移**，初次确诊时60%\~88%已有脑/肝/骨/肾上腺转移 |
| 部位 | 多为中央型，典型表现为肺门肿块和纵隔淋巴结肿大 |
| 治疗反应 | 对化疗和放疗敏感 |
| 副肿瘤综合征 | 最常见，可产生5-HT、儿茶酚胺、组胺等致[[类癌综合征]] |

## 临床表现

5%\~15%的病人无症状，仅在体检时发现。

### 原发肿瘤引起的症状和体征

| 症状 | 特点 |
|------|------|
| **[[咳嗽与咳痰]]** | 最常见早期症状，常为无痰或少痰的**刺激性干咳**；肿瘤致支气管狭窄时为持续性高调金属音咳嗽；黏液型腺癌可有大量黏液痰 |
| 痰血或[[咯血]] | 多见于中央型肺癌，间歇或持续性痰中带血；侵蚀大血管可致大咯血 |
| 气短或喘鸣 | 气道阻塞、淋巴结压迫、胸腔积液、心包积液等引起；听诊可有局限或单侧哮鸣音 |
| 胸痛 | 胸部隐痛（非侵犯性）；侵犯胸膜或胸壁时为不规则钝痛或剧痛 |
| [[发热]] | 肿瘤坏死或阻塞性肺炎所致，抗生素治疗效果不佳 |
| 消瘦 | 晚期可出现恶病质 |

### 肿瘤局部扩展引起的症状和体征

| 表现 | 侵犯/压迫结构 |
|------|-------------|
| 胸痛 | 侵犯胸膜或胸壁，呼吸/咳嗽时加重 |
| **声音嘶哑** | 压迫喉返神经（左侧多见），致声带麻痹 |
| 吞咽困难 | 侵犯或压迫食管 |
| [[胸腔积液]] | 胸膜转移或淋巴回流受阻 |
| 心包积液 | 直接蔓延或淋巴引流阻塞，可致心脏压塞 |
| **[[上腔静脉压迫综合征|上腔静脉阻塞综合征]]** | 上腔静脉回流受阻→上肢、颈面部水肿，胸壁静脉曲张，眼结膜充血，头晕头痛 |
| **[[Horner综合征]]** | 肺上沟瘤（Pancoast瘤）压迫颈交感神经→患侧眼睑下垂、瞳孔缩小、眼球内陷、同侧额部与胸壁少汗或无汗 |

### 远处转移引起的症状和体征

| 转移部位 | 表现 |
|---------|------|
| 中枢神经系统（脑） | 头痛、恶心呕吐（颅内压增高），癫痫，偏瘫，共济失调 |
| 骨骼 | 局部疼痛和压痛，病理性骨折，多见于肋骨、脊椎、骨盆和四肢长骨；多为溶骨性病变 |
| 肝脏 | 肝区疼痛、黄疸、肝大、腹腔积液 |
| 淋巴结 | **锁骨上窝淋巴结**最常见（胸锁乳突肌附着处后下方），固定质硬，可融合，多无疼痛 |

转移频率：SCLC（95%以上）> 腺癌/大细胞癌（80%）> 鳞癌（50%以上）。

### 副肿瘤综合征（胸外表现）

以SCLC多见，可为首发症状或复发征象。

| 类型 | 表现 | 常见于 |
|------|------|--------|
| **抗利尿激素分泌失调综合征（SIADH）** | 低钠血症、低渗透压血症，厌食、恶心、嗜睡、癫痫样发作或昏迷 | SCLC |
| **异位ACTH综合征** | 库欣综合征（色素沉着、水肿、肌萎缩、低钾血症、代谢性碱中毒、高血糖），向心性肥胖和紫纹少见 | SCLC，类癌 |
| 高钙血症 | 口渴、多尿、恶心、便秘、嗜睡甚至昏迷 | 鳞癌 |
| 肥大性骨关节病 | 杵状指（趾），骨膜炎（长骨远端疼痛、压痛、肿胀） | NSCLC |
| **肌无力样综合征（Lambert-Eaton综合征）** | 近端肌力减退（活动后暂时改善），腱反射减弱；新斯的明反应欠佳，高频重复刺激波幅升高 | SCLC |
| 类癌综合征 | 喘息、皮肤潮红、水样腹泻、阵发性心动过速 | SCLC，腺癌 |
| 血液学异常 | 游走性血栓性静脉炎（Trousseau综合征）、非细菌性血栓性心内膜炎、DIC | 各型 |

## 辅助检查

### 影像学检查

| 检查 | 用途与特点 |
|------|-----------|
| **胸部X线** | 最常用初筛方法，但分辨率低，对早期肺癌和小病灶易漏诊 |
| **胸部CT（增强）** | **首选影像学检查**，高分辨率，可发现<5mm结节和隐蔽部位病灶；低剂量CT（LDCT）可有效筛查早期肺癌 |
| 胸部MRI | 明确肿瘤与大血管关系、发现脑实质/脑膜转移较CT优越；对小病灶（<5mm）不如CT |
| PET-CT | 获得生物代谢信息+精准解剖定位，用于分期和疗效评价优于其他检查；阳性仍需病理确诊 |
| 骨γ闪烁显像 | 了解骨转移（敏感性91%，特异性88%） |

#### 肺癌X线胸片特征

| 类型 | 直接征象 | 间接征象 |
|------|---------|---------|
| 中央型肺癌 | 一侧肺门类圆形阴影，边缘毛糙，分叶或切迹；右上叶中央型可呈**倒S状影像** | 局限性肺气肿、肺不张、阻塞性肺炎、继发性肺脓肿 |
| 周围型肺癌 | 早期呈局限性小斑片状阴影或磨玻璃影；增大后呈圆形/类圆形，分叶状，细毛刺，**胸膜牵拉**；癌性空洞为**厚壁、偏心、内缘凹凸不平**，继发感染时有液平面 | 引流淋巴管增粗、肺门淋巴结增大、胸腔积液、肋骨破坏 |

### 病理学诊断检查

| 方法 | 适用范围 | 特点 |
|------|---------|------|
| 痰液细胞学检查 | 中央型肺癌 | 最简单方便的无创方法，至少送检3次；敏感性<70%，特异性高；分型困难 |
| 胸腔积液细胞学检查 | 合并胸腔积液者 | 检出率40%\~90%，细胞块切片可提高阳性率 |
| **支气管镜+活检** | 中央型肺癌 | **诊断主要方法之一**，可进入4\~5级支气管；活检+刷检+灌洗联合提高检出率；EBUS有助于TNM分期 |
| CT引导下经皮肺穿刺活检 | 周围型肺癌（胸膜下/近胸壁） | 创伤小、操作简便、迅速获结果 |
| 胸腔镜/纵隔镜 | 胸膜下病变、纵隔淋巴结 | 取样较多，但创伤和风险相对较大 |
| 浅表淋巴结活检 | 可扪及肿大淋巴结 | 操作简便，门诊完成 |
| 开胸肺活检 | 上述均未确诊 | 需权衡利弊后决定 |

### 肿瘤标志物与基因检测

| 检测项目 | 用途 |
|---------|------|
| **肿瘤标志物** | CEA、NSE（SCLC）、CYFRA21-1（鳞癌）、ProGRP（SCLC），联合检测有一定参考价值 |
| **驱动基因检测** | EGFR突变、ALK融合、ROS1融合、BRAF V600E、RET重排、MET14外显子跳跃突变、NTRK重排等 |
| **耐药基因检测** | EGFR T790M/C797S、MET扩增等 |
| **PD-L1免疫组化** | 筛选免疫检查点抑制剂获益人群 |
| 液体活检（ctDNA） | 难以获取组织标本时的补充评估 |

## TNM 分期（IASLC 第9版，2023）

### TNM 定义

| 分期 | 定义 |
|------|------|
| **Tis** | 原位癌 |
| **T1** | 肿瘤最大径≤3cm，未侵及主支气管 |
| T1a ≤1cm \| T1b >1\~2cm \| T1c >2\~3cm |
| **T2** | 肿瘤>3\~5cm；或侵犯主支气管（未及隆突）；或侵犯脏胸膜；或有阻塞性肺炎/肺不张 |
| T2a >3\~4cm \| T2b >4\~5cm |
| **T3** | 肿瘤>5\~7cm；或侵犯胸壁（含肺上沟瘤）/膈神经/心包；或全肺不张；或同一肺叶孤立癌结节 |
| **T4** | 肿瘤>7cm；或侵犯纵隔/心脏/大血管/隆突/喉返神经/气管/食管/椎体/膈肌；或同侧不同肺叶孤立癌结节 |
| **N1** | 同侧支气管周围和/或同侧肺门淋巴结及肺内淋巴结转移 |
| **N2** | 同侧纵隔内和/或隆突下淋巴结转移（N2a:单发；N2b:多发） |
| **N3** | 对侧纵隔、对侧肺门、同侧或对侧斜角肌或锁骨上淋巴结转移 |
| **M1a** | 胸膜播散（恶性胸腔积液/心包积液/胸膜结节）及对侧肺叶癌结节 |
| **M1b** | 远处器官单发转移灶 |
| **M1c1/M1c2** | 单个胸腔外器官内多发转移 / 多个胸腔外器官多发转移 |

## 诊断与鉴别诊断

### 诊断步骤

1. **CT确定部位**：怀疑肺癌者先行胸腹部CT，明确原发部位、淋巴结侵犯和播散情况
2. **组织病理学诊断**：必须获得组织学标本（支气管镜、胸腔镜、穿刺活检等），不推荐单一痰细胞学确诊
3. **分子病理学诊断**：检测EGFR/ALK/ROS1/BRAF/RET/MET14等驱动基因，以及PD-L1表达

### 鉴别诊断

| 需鉴别的疾病 | 鉴别要点 |
|-------------|---------|
| **[[肺结核]]球** | 年轻病人，无症状；病灶多位于肺上叶尖后段和下叶背段，边界清楚，可有钙化，周围卫星灶，多年不变 |
| 肺门淋巴结结核 | 儿童/青年，有结核中毒症状，PPD阳性，抗结核有效 |
| 急性粟粒性肺结核 | 年龄较轻，发热盗汗，粟粒样结节细小均匀密度较淡；腺癌播散灶大小不等、边界清、密度高、进行性增大 |
| 细菌性[[肺炎]] | 发热、咳嗽、咳痰，抗生素治疗有效；若同一部位反复发生肺炎应警惕肺癌 |
| [[肺脓肿]] | 起病急，中毒症状重，大量脓臭痰，空洞内常见液平面；癌性空洞壁厚、偏心、内壁不平 |
| 炎性假瘤 | 慢性感染史，病灶形态不整，核心密度较高，长期无明显变化 |
| 结核性胸膜炎 | 应与癌性胸腔积液鉴别 |

## 治疗

治疗应根据体力活动状态（PS）评分、病理学类型（含分子病理）、临床分期，采取**多学科综合治疗**，强调个体化。

### 体力活动状态（PS）评分

| 评分 | 状态 | 能否化疗 |
|------|------|---------|
| 0分 | 正常 | ≤2分可化疗 |
| 1分 | 可自由行走/从事轻体力劳动 | ≤2分可化疗 |
| 2分 | 可自由行走及生活自理，但失去工作能力，日间≥一半时间可起床 | ≤2分可化疗 |
| 3分 | 生活部分自理，日间一半时间卧床 | 不适合 |
| 4分 | 卧床不起，生活不能自理 | 不适合 |

### 手术治疗

**NSCLC**：Ⅰ期及Ⅱ期首选根治性手术切除（肺叶切除 + 纵隔淋巴结清扫）；部分Ⅲa期需多学科讨论综合治疗。Ⅱ\~Ⅲ期根治术后需术后辅助化疗。

**SCLC**：90%以上就诊时已有转移，一般不推荐手术；仅T1\~2N0（病理学纵隔分期阴性）可考虑肺叶切除+淋巴结清扫，术后均需化疗4\~6个疗程。

### 药物治疗

#### 化疗

| 类型 | 方案 |
|------|------|
| **NSCLC一线** | 含铂两药方案（顺铂/卡铂+紫杉醇/吉西他滨/培美曲塞/长春瑞滨/多西他赛），4\~6个周期 |
| **SCLC一线** | 依托泊苷或伊立替康+顺铂/卡铂，4\~6个周期 |
| 维持治疗 | 化疗后肿瘤缓解或稳定且无进展者可维持治疗 |
| 二线治疗 | 多西他赛或培美曲塞单药 |

#### 靶向治疗

| 驱动基因 | 靶向药物（举例） |
|---------|----------------|
| *EGFR* 突变 | 奥希替尼、阿美替尼、吉非替尼、厄洛替尼、阿法替尼 |
| *ALK* 融合 | 阿来替尼、克唑替尼、色瑞替尼、洛拉替尼 |
| *ROS1* 融合 | 克唑替尼、恩曲替尼 |
| *MET14* 外显子跳跃突变 | 谷美替尼 |
| *BRAF V600E* | 达拉非尼+曲美替尼 |
| *RET* 融合 | 塞普替尼 |
| *EGFR T790M* 耐药 | 奥希替尼、阿美替尼、伏美替尼 |

**抗血管生成治疗**：贝伐珠单抗（抗VEGF单抗）联合化疗；安罗替尼（多靶点TKI）用于三线及以上治疗。

#### 免疫治疗（免疫检查点抑制剂，ICIs）

| 药物 | 适应情况 |
|------|---------|
| 帕博利珠单抗、阿替利珠单抗等 | **PD-L1高表达（≥50%）驱动基因阴性NSCLC**：单药一线 |
| 化疗+免疫联合 | PD-L1阳性（≥1%）驱动基因阴性NSCLC一线 |
| 化疗+免疫联合 | 广泛期SCLC一线（依托泊苷+卡铂+阿替利珠单抗等方案） |

ICIs使晚期驱动基因阴性NSCLC的5年生存率从5%提升至13.4%\~23.2%。

### 放射治疗

| 类型 | 用途 |
|------|------|
| 根治性放疗 | 病灶局限、不能手术或不适合手术者 |
| 姑息性放疗 | 缓解咯血、[[上腔静脉压迫综合征|上腔静脉阻塞综合征]]、骨转移疼痛、脑转移症状 |
| 辅助放疗 | 术前放疗、术后切缘阳性 |
| 预防性颅脑放疗 | 全身治疗有效的SCLC（降低脑转移风险） |

对放疗敏感性：SCLC > 鳞癌 > 腺癌。

### 综合治疗策略总结

| 病理类型 | 分期 | 主要治疗 |
|---------|------|---------|
| **NSCLC** | Ⅰ\~Ⅱ期 | 根治性手术 ± 辅助化疗 |
| | Ⅲ期 | 多学科综合：手术+化疗/放化疗，或同步放化疗 |
| | Ⅳ期 | 驱动基因阳性→靶向治疗；PD-L1高表达→免疫治疗；其他→化疗±免疫±抗血管 |
| **SCLC** | 局限期 | 化疗+放疗为主的综合治疗 |
| | 广泛期 | 化疗+免疫治疗为主的综合治疗 |

## 预防

| 预防级别 | 措施 |
|---------|------|
| 一级预防 | 病因预防：戒烟、改善空气质量、合理饮食、避免职业暴露 |
| 二级预防 | 早诊早治：对高危人群使用**低剂量CT（LDCT）**筛查（可使肺癌死亡率下降20%） |
| 三级预防 | 临床防治/康复：减少并发症，防止恶化，提高生活质量 |

## 预后

肺癌预后取决于早发现、早诊断、早治疗。约80%在确诊后5年内死亡。仅15%确诊时病变局限，5年生存率可达50%。Ⅰ期NSCLC 5年生存率约70%以上，晚期<5%；SCLC未经治疗中位生存期极短。
