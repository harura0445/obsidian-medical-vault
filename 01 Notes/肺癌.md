# 肺癌

## 流行病学

**最常见**的恶性肿瘤之一（中国发病率和死亡率均居首位）。

## 病理与分类

| 分类 | 占比 | 特点 |
|------|------|------|
| **非小细胞肺癌（NSCLC）** | ~85% | |
| — 腺癌 | ~40% | 最常见类型，周围型多见，不吸烟女性多见，EGFR/ALK突变常见 |
| — **鳞状细胞癌** | ~25% | 中央型多见，与吸烟关系最密切 |
| — 大细胞癌 | ~1% | 高度恶性 |
| **小细胞肺癌（SCLC）** | ~15% | 中心型多见，高度恶性，早期转移，对放化疗敏感 |

### 转移途径

- **直接扩散**：侵犯胸膜、胸壁、纵隔
- **淋巴转移**（最常见）：肺门→纵隔→锁骨上
- **血行转移**：脑、骨、肝、肾上腺

## 临床表现

### 原发肿瘤引起的症状

- **刺激性干咳**（最常见首发症状）、痰中带血、胸闷、气短、发热

### 局部扩散症状

| 表现 | 侵犯结构 |
|------|----------|
| **声音嘶哑** | 侵犯左喉返神经 |
| 吞咽困难 | 侵犯食管 |
| **Horner综合征** | 侵犯颈交感神经→患侧瞳孔缩小、眼睑下垂、面颈部无汗 |
| **Pancoast综合征** | 肺尖肿瘤侵犯臂丛+交感神经→肩臂疼痛+Horner综合征 |
| 上腔静脉压迫综合征 | 面颈部肿胀、颈静脉怒张、口唇发绀 |

### 远处转移症状

脑转移（头痛、偏瘫）、骨转移（骨痛、病理性骨折）、肝转移（黄疸、肝肿大）。

### 副癌综合征（肺外表现）

- 杵状指、Cushing综合征（ACTH分泌）、高钙血症（PTHrP）、肌无力（Lambert-Eaton综合征）

## 辅助检查

| 检查 | 用途 |
|------|------|
| **胸部CT** | 首选影像学检查，评估原发灶 |
| PET-CT | 分期（判断淋巴结和远处转移） |
| **支气管镜+活检** | 中心型肺癌确诊的主要方法 |
| CT引导下经皮肺穿刺活检 | 周围型肺癌 |
| 痰细胞学检查 | 筛查，阳性率低 |
| 肿瘤标志物 | CEA、CYFRA21-1（鳞癌）、NSE（小细胞肺癌） |

## 临床分期（TNM）

- Ⅰ期：T1-2aN0M0
- Ⅱ期：T1-2bN1M0，T3N0M0
- Ⅲ期：局部晚期（N2/N3或T3~4）
- Ⅳ期：M1（远处转移）

## 诊断与鉴别诊断

**诊断**：影像学+支气管镜活检/穿刺活检病理确诊。

**鉴别诊断**：肺结核球、肺炎性假瘤、肺脓肿、支气管腺瘤、肺转移瘤。

## 治疗原则

### 非小细胞肺癌（NSCLC）

| 分期 | 治疗 |
|------|------|
| **Ⅰ期、Ⅱ期** | **手术根治切除**（肺叶切除+纵隔淋巴结清扫）——首选 |
| Ⅲ期 | 手术+新辅助/辅助化疗+放疗（综合治疗） |
| Ⅳ期 | 化疗 ± 靶向 ± 免疫（姑息） |

### 小细胞肺癌（SCLC）

**以化疗为主**+放疗，手术仅适用于极早期（T1-2N0）。

### 靶向治疗与免疫治疗

- EGFR突变：吉非替尼/奥希替尼
- ALK融合：克唑替尼/阿来替尼
- PD-L1高表达：帕博利珠单抗

## 预后

- NSCLC：Ⅰ期5年生存率~70%，晚期<5%
- SCLC：未经治疗中位生存期极短，化疗有效率60%~80%但易复发
