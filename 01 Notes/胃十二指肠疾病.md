# 胃十二指肠疾病

## 解剖生理概要

### 胃的解剖

- **分区**：贲门胃底区、胃体区、幽门区
- **动脉**：胃左动脉（腹腔干）、胃右动脉（肝固有动脉）、胃网膜左右动脉（来自胃十二指肠动脉和脾动脉）、胃短动脉
- **淋巴**：腹腔淋巴结群、幽门上、幽门下、胰脾淋巴结群
- **神经**：交感神经抑制胃运动和分泌，副交感神经（迷走神经）兴奋胃运动和分泌；Latariet前后神经终末支分布于胃窦呈"鸦爪"状
- **胃腺**：壁细胞（胃酸+内因子）、主细胞（胃蛋白酶原）、黏液细胞、G细胞（胃泌素）、D细胞（生长抑素）

### 十二指肠的解剖

十二指肠分四段：球部（溃疡好发部位）→降部（十二指肠乳头开口）→水平部→升部（Treitz韧带固定）

## 胃十二指肠溃疡

> 参见 [[抗胃溃疡药的选择]]

### 溃疡的外科手术适应证

① 顽固性溃疡（内科治疗无效）；② 并发大出血；③ 并发穿孔；④ 瘢痕性幽门梗阻；⑤ 疑恶变

### 急性穿孔

- **病史**：多有溃疡病史
- **临床表现**：突发上腹部刀割样剧痛→蔓延全腹，腹膜炎体征（腹肌紧张"板状腹"、压痛、反跳痛）
- **X线**：膈下游离气体（约80%）
- **治疗**：
  - 非手术：禁食、胃肠减压、抗生素、PPI（适用于空腹穿孔、腹膜炎局限者）
  - 手术：穿孔修补术（腹腔镜/开腹）+ 溃疡灶活检

### 大出血

- **临床表现**：呕血+黑便（柏油样便）+失血性休克
- **诊断**：急诊胃镜（明确出血部位+可行止血治疗）
- **治疗**：
  - 保守：补充血容量+PPI+内镜下止血
  - 手术指征：24h内输血>1600ml仍不平稳、复发性大出血、内镜止血失败

### 瘢痕性幽门梗阻

- **临床表现**：进食后上腹胀、呕吐隔夜宿食（不含胆汁）、振水音阳性
- **诊断**：胃镜（排除恶性）+胃潴留
- **治疗**：胃肠减压稀释胃酸→纠正水电解质紊乱（低氯低钾性碱中毒）→手术

### 手术方式

| 术式 | 要点 |
|------|------|
| 毕Ⅰ式（Billroth Ⅰ） | 胃大部切除+胃十二指肠吻合 |
| 毕Ⅱ式（Billroth Ⅱ） | 胃大部切除+胃空肠吻合（十二指肠残端关闭） |
| 迷走神经切断术 | 高选择性迷走神经切断（保留幽门功能） |

### 术后并发症

| 早期并发症 | 晚期并发症 |
|------------|------------|
| 出血 | 倾倒综合征 |
| 十二指肠残端漏 | 吻合口溃疡 |
| 吻合口漏 | 输入袢综合征 |
| 胃排空障碍 | 残胃癌（Billroth Ⅱ术后>10年风险增加） |
| | 碱性反流性胃炎 |

## 胃癌

### 病因与高危因素

幽门螺杆菌感染（Ⅰ类致癌物）、慢性萎缩性胃炎、肠上皮化生、胃息肉、家族史

### 病理

- **好发部位**：胃窦部
- **大体分型**（Borrmann）：
  - Ⅰ型：息肉型；Ⅱ型：溃疡型；Ⅲ型：溃疡浸润型（最常见）；Ⅳ型：弥漫浸润型（革囊胃/Linitis plastica）
- **组织学**：腺癌为主（管状、乳头状、黏液、印戒细胞）
- **转移**：淋巴转移（主要途径，最早转移至胃周淋巴结）→ 血行（肝）→ 种植（Krukenberg瘤—卵巢转移）

### 临床表现

早期多无症状，进展期出现：
- 上腹痛（无规律、进行性加重）
- 食欲减退、消瘦、贫血
- 幽门梗阻→呕吐宿食
- 左锁骨上淋巴结肿大（Virchow淋巴结）

### 诊断

**胃镜+活检**为金标准。CT/MRI评估肿瘤浸润深度和远处转移。肿瘤标志物CEA、CA19-9。

### 治疗原则

**手术根治性切除是惟一可能治愈的方法**。

- 根治性胃切除术：胃切除+区域淋巴结清扫（D2为标准清扫范围）
- 化疗（术前新辅助/术后辅助/晚期姑息）
- 靶向治疗（HER-2阳性者用曲妥珠单抗）

## 胃间质瘤（GIST）

- 来源于胃肠道Cajal间质细胞
- 最常见于胃（50%~60%）
- 免疫组化：CD117（c-Kit）+、DOG1+
- 临床表现：腹痛、消化道出血、腹部肿块
- 危险度分级：肿瘤大小+核分裂象
- 治疗：手术完整切除（R0）+伊马替尼辅助治疗（高危/复发转移者）

## 先天性肥厚性幽门狭窄

- **好发**：出生后2~3周男婴
- **临床表现**：喷射性呕吐（不含胆汁）、右上腹可触及"橄榄样"肿块、胃蠕动波
- **诊断**：超声（幽门肌层厚>4mm、幽门管长>16mm）
- **治疗**：Ramstedt幽门肌切开术
