# 胰腺疾病

## 解剖生理概要

- 胰腺：腹膜后位器官，长约15~20cm，分为头（被十二指肠C形包绕）、颈、体、尾四部分
- **主胰管（Wirsung管）**：约85%与胆总管汇合→Vater壶腹→十二指肠主乳头
- **外分泌**：胰液（750~1,500ml/日，pH 7.4~8.4），含胰蛋白酶、糜蛋白酶、脂肪酶、淀粉酶等（以酶原形式储存，肠激酶激活）
- **内分泌**：胰岛（B细胞→胰岛素、A细胞→胰高血糖素、D细胞→生长抑素）

## 急性胰腺炎

### 致病危险因素

| 因素 | 机制 | 占比 |
|------|------|------|
| **胆道疾病** | 结石阻塞→胆汁反流入胰管→激活消化酶→"自我消化" | **>50%**（胆源性胰腺炎） |
| **饮酒** | 直接损伤胰腺+刺激分泌+Oddi括约肌痉挛 | 常见 |
| 高脂血症/高钙血症 | 损伤胰腺 | 发病率逐渐增高 |
| 十二指肠液反流 | 憩室、解剖异常等 | — |
| 医源性 | ERCP术后（约2%~10%） | — |

### 发病机制

各种因素→胰管内高压→胰蛋白酶原被激活为胰蛋白酶→激活其他酶（磷脂酶A、弹性蛋白酶等）→胰腺自溶→炎症级联反应→全身炎症反应综合征（SIRS）→多器官功能衰竭（MOF）。

### 病理

| 程度 | 病理 |
|------|------|
| 水肿型（轻症） | 胰腺水肿、体积增大，自限性，预后好 |
| 坏死型（重症） | 胰腺实质坏死、出血、脂肪坏死皂化→腹膜炎、休克、MOF |

### 临床表现

| 症状/体征 | 特点 |
|-----------|------|
| **腹痛** | 最突出——突发性上腹剧痛，"束带状"，向左腰背放射，前倾坐位稍缓解 |
| 恶心呕吐 | 频繁，吐后腹痛不缓解（与胃炎重要区别） |
| 腹胀 | 麻痹性肠梗阻 |
| **Cullen征** | 脐周皮肤青紫 |
| **Grey-Turner征** | 双侧腰部皮肤青紫（腹膜后出血渗入皮下） |
| 发热、黄疸 | 胆源性胰腺炎可有黄疸 |

### 辅助检查

| 检查 | 用途 |
|------|------|
| **血淀粉酶** | 起病后6~12h升高，>正常上限3倍可诊断，3~5天降至正常 |
| **血脂肪酶** | 特异性优于淀粉酶，持续时间更长 |
| **腹部增强CT** | 评估胰腺坏死程度、有无积液/脓肿——**最可靠的影像学检查** |
| 超声 | 发现胆囊结石（判断胆源性病因） |

### 诊断

**诊断标准**（符合以下2条）：
1. 突发上腹部持续性剧痛，向背腰部放射
2. 血淀粉酶/脂肪酶 > 正常上限3倍
3. 影像学（CT/MRI/超声）示胰腺炎症/坏死

### 病情严重度评估

- Ranson评分、APACHE Ⅱ评分、CT严重度指数（CTSI）
- 器官功能衰竭≥48h为重症急性胰腺炎

### 并发症

| 类型 | 并发症 |
|------|--------|
| 局部 | 急性胰周液体积聚、胰腺假性囊肿、胰腺坏死感染、胰腺脓肿、腹腔间隔隔室综合征（ACS） |
| 全身 | SIRS→MODS（急性呼吸窘迫综合征、急性肾衰竭、休克）、胰性脑病 |

### 治疗原则

| 治疗 | 要点 |
|------|------|
| **禁食+胃肠减压** | 减少胰液分泌 |
| **液体复苏** | 早期大量晶体液（最重要） |
| 营养支持 | 早期肠内营养（48~72h内，鼻空肠管/鼻饲） |
| 抑制胰液分泌 | 生长抑素/奥曲肽 |
| 镇痛 | 哌替啶（勿用吗啡——Oddi括约肌痉挛） |
| 抗生素 | 仅用于明确感染（胰腺坏死感染） |
| 病因治疗 | **胆源性胰腺炎+胆道梗阻→24~48h内行ERCP** |

**手术适应证**：
- 胰腺坏死感染（穿刺培养阳性）
- 腹腔间隔隔室综合征（保守无效）
- 胆源性胰腺炎伴胆道梗阻ERCP失败时

手术方式：坏死组织清创引流（微创优先，阶梯式处理）。

## 胰腺癌

### 胰头癌

- **最常见**的胰腺恶性肿瘤，预后极差（5年生存率<5%）
- 病理：导管腺癌为主
- **临床表现**：
  - **进行性无痛性黄疸**（最典型，肿瘤压迫胆总管）
  - Courvoisier征：**无痛性黄疸+可触及肿大无痛的胆囊**
  - 上腹部隐痛不适、消瘦明显
- **诊断**：增强CT首选；CA19-9（肿瘤标志物）；超声内镜+活检
- **治疗**：胰十二指肠切除术（Whipple手术）→唯一可能根治的方法

### 慢性胰腺炎

- 病因：长期饮酒（最常见）、胆道疾病
- 病理：胰腺纤维化、钙化→内外分泌功能不全
- **临床表现**：腹痛（最常见）、脂肪泻（外分泌功能不全→消化吸收障碍）、糖尿病（内分泌功能不全）
- 诊断：CT（胰腺钙化、胰管扩张/结石）
- 治疗：戒酒、胰酶替代+胰岛素，手术（胰管引流/胰腺切除）
