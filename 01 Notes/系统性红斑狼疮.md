# 系统性红斑狼疮

> 以致病性自身抗体和免疫复合物形成为特征，可累及全身多系统、多器官的自身免疫病，血清存在以ANA为代表的多种自身抗体。

## 概述

SLE好发于**20~40岁育龄女性**，男女比约1:9（育龄期）至1:3（儿童及老人）。我国患病率（30.13~70.41）/10万。通过早期诊断及综合治疗，预后已显著改善。

## 病因

### 遗传

- 第1代亲属患病风险为无SLE家庭的**8倍**
- 单卵双胞胎患病一致率5~10倍于异卵双胞胎
- 多基因相关：HLA-DR2、DR3、C2/C4缺失

### 环境因素

| 因素 | 机制 |
|------|------|
| **紫外线** | 使皮肤上皮细胞凋亡，新抗原暴露成为自身抗原 |
| 药物 | 降低DNA甲基化 → 药物相关狼疮 |
| 病毒 | 巨细胞病毒、新冠病毒等可诱发 |

### 雌激素

女性患病率远高于男性，围绝经期前男女比达9:1。

## 发病机制

外来抗原 → 易感者B细胞活化（免疫耐受减弱）→ 交叉反应 → T细胞活化 → B细胞产生大量**致病性自身抗体** → 免疫复合物沉积 → 组织损伤。

### 致病性自身抗体

| 抗体 | 致病效应 |
|------|----------|
| 抗dsDNA抗体 | 直接与肾组织结合 → 肾小球损伤 |
| 抗血小板/抗红细胞抗体 | 血小板减少、溶血性贫血 |
| 抗SSA抗体 | 经胎盘 → 新生儿心脏传导阻滞 |
| 抗磷脂抗体 | [[抗磷脂综合征]]（血栓、流产、血小板减少） |
| 抗核糖体抗体 | 与神经精神狼疮相关 |

## 病理

- 主要改变：**炎症反应和血管异常**
- 特征性改变：
  - **苏木紫小体**（细胞核变性为嗜酸性团块）
  - **"洋葱皮样病变"**（小动脉周围向心性纤维增生）
  - Libman-Sacks心内膜炎（瓣膜赘生物）

## 临床表现

### 全身表现

活动期常见发热（低~中度为主）、疲倦、乏力、食欲缺乏、体重下降。

### 各系统受累

| 系统 | 发生率 | 主要表现 |
|------|--------|----------|
| **皮肤黏膜** | 80% | 颧部蝶形红斑（最具特征性）、盘状红斑、光过敏、口腔溃疡、脱发 |
| **关节肌肉** | ~90% | 对称性多关节肿痛（非侵蚀性）、Jaccoud关节病、肌炎 |
| **浆膜炎** | ＞50% | 胸膜炎、心包炎，双侧中小量积液 |
| **肾脏** | 27.9%~70% | 蛋白尿、血尿、管型尿、水肿、高血压 → 肾衰竭（详细见狼疮性肾炎） |
| **心血管** | 常见 | 心包炎、Libman-Sacks心内膜炎、心肌损害、冠状动脉病变 |
| **呼吸系统** | 常见 | 肺间质病变、弥漫性肺泡出血（病死率＞50%）、肺动脉高压 |
| **神经系统** | 不一 | 神经精神狼疮（NPLE）：癫痫、头痛、脑血管病变、脱髓鞘、认知障碍、精神病 |
| **消化系统** | 常见 | 腹痛、腹泻、肝损伤、胰腺炎、肠坏死 |
| **血液系统** | 活动期常见 | 贫血、白细胞减少、血小板减少、10%Coombs阳性溶血性贫血 |
| **抗磷脂综合征** | ~1/3 | 动静脉血栓、病理妊娠、血小板减少 |
| **继发性[[干燥综合征]]** | ~30% | 口干、眼干 |
| **眼部** | ~15% | 视网膜出血/渗出、视神经炎 |

## 实验室与辅助检查

### 自身抗体

| 抗体 | 灵敏度 | 特异度 | 临床意义 |
|------|--------|--------|----------|
| **ANA** | ~98% | 低 | 筛查，几乎全部SLE阳性 |
| **抗dsDNA** | 60% | 高 | **标记抗体**，滴度与活动性相关 |
| **抗Sm** | 25% | **99%** | **标记抗体**，有助于早期/不典型诊断 |
| 抗SSA/Ro | 30%~40% | — | 光过敏、新生儿狼疮、干燥综合征 |
| 抗SSB/La | 10%~15% | — | 继发干燥综合征 |
| 抗RNP | 40% | — | 雷诺现象、肺动脉高压 |
| 抗rRNP | 10% | — | 神经精神狼疮 |

### 其他检查

| 项目 | 意义 |
|------|------|
| **补体C3/C4** | 低下提示SLE活动，C4低下也可能提示易感性 |
| 血沉/CRP | 炎症指标，提示活动 |
| 尿常规 | 蛋白尿、血尿、管型尿 |
| 肾活检 | 狼疮性肾炎的诊断、分型和治疗指导 |

## 诊断

### SLICC 2012分类标准

需满足**≥4条**，包括**至少1条临床标准 + 至少1条免疫学标准**；或肾活检证实狼疮性肾炎且ANA/抗dsDNA阳性。

| 临床标准（11项） | 免疫学标准（6项） |
|------------------|-------------------|
| 急性/亚急性皮肤狼疮 | ANA阳性 |
| 慢性皮肤狼疮 | 抗dsDNA阳性 |
| 口腔/鼻咽部溃疡 | 抗Sm阳性 |
| 非瘢痕性脱发 | 抗磷脂抗体阳性 |
| 炎性滑膜炎（≥2关节） | 低补体（C3/C4/CH50） |
| 浆膜炎 | 直接Coombs试验阳性 |
| 肾脏（蛋白尿/红细胞管型） | |
| 神经系统（癫痫/精神异常等） | |
| 溶血性贫血 | |
| 白细胞减少或淋巴细胞减少 | |
| 血小板减少 | |

灵敏度97%，特异度84%。

## 病情活动度评估

### SLEDAI评分

对前10天内症状进行评分，总分105分：

| 评分 | 病情状态 |
|------|----------|
| ≤4分 | 病情稳定 |
| 5~9分 | **轻度活动** |
| 10~14分 | **中度活动** |
| ≥15分 | **重度活动** |

**8分项目**：抽搐、精神病、器质性脑病、视觉障碍、脑神经病变、狼疮性头痛、脑血管意外、血管炎

**狼疮危象**：急进性狼疮性肾炎、严重中枢神经系统损害、严重溶血性贫血、血小板减少性紫癜、粒细胞缺乏、严重心脏损害、弥漫性肺泡出血等。

## 治疗

### 一般治疗

- 心理治疗，树立乐观情绪
- 急性活动期卧床休息
- 及早发现和治疗感染
- 避免可能诱发狼疮的药物
- **避免强阳光暴晒和紫外线照射**
- 缓解期可防疫注射，但尽可能不用活疫苗

### 药物治疗

#### 基础治疗

| 药物 | 作用 |
|------|------|
| **羟氯喹** | 所有SLE患者如无禁忌均应服用，降低活动度、减少器官损伤和血栓风险 |

#### 诱导缓解

| 药物 | 用法 | 适应证 |
|------|------|--------|
| **糖皮质激素** | 泼尼松0.5~1mg/(kg·d)，稳定后2~6周缓慢减量；维持：＜10mg/d | 基本治疗 |
| **激素冲击** | 甲泼尼龙500~1 000mg/d×3~5天 | 狼疮危象 |
| CTX | 0.4g/周，或0.5~1.0g/m²每3~4周 | 重要脏器受累首选之一 |
| MMF | 1.5~2g/d | 重要脏器受累首选之一 |

#### 常用免疫抑制剂

| 药物 | 主要副作用 |
|------|------------|
| CTX（环磷酰胺） | 胃肠道反应、骨髓抑制、感染、性腺抑制、出血性膀胱炎、致癌 |
| MMF（吗替麦考酚酯） | 胃肠道反应、骨髓抑制、感染、致畸 |
| CsA（环孢素） | 肾毒性、高血压、高尿酸、高血钾 |
| FK506（他克莫司） | 高血压、肾毒性、高血钾 |
| AZA（硫唑嘌呤） | 骨髓抑制、肝功能损害 |
| MTX（甲氨蝶呤） | 口腔黏膜糜烂、肝损害、肺纤维化 |

#### 生物制剂

用于难治性或复发性SLE：
- **贝利尤单抗**：已获适应证
- **泰它西普**：已获适应证
- **利妥昔单抗**：用于顽固性狼疮性肾炎和血液系统受累（未获适应证但指南推荐）

## 预后

- 10年存活率已达**90%以上**
- 急性期死因：多脏器严重损害和感染（尤其是严重NPLE、肺动脉高压、急进性肾炎）
- 远期死因：慢性肾功能不全、药物不良反应、冠心病
