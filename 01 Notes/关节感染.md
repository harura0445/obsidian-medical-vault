# 关节感染

## 化脓性关节炎

### 概述与发病机制

关节腔的化脓性感染。致病菌多为**金黄色葡萄球菌**（最常见），其次为溶血性链球菌、大肠埃希菌。感染途径：血行播散（最常见）、直接蔓延（邻近化脓性病灶）、创伤后直接污染。

### 临床表现

- **好发部位**：髋关节、膝关节
- **好发人群**：儿童
- **急性起病**：寒战高热、关节剧痛、肿胀、局部皮温升高
- **关节功能障碍**：关节呈屈曲位（关节腔最大容积位）以减少疼痛

### 早期诊断

- 关节穿刺+关节液检查：**最重要诊断依据**
- 关节液：混浊→脓性→WBC>50,000/μL→细菌培养（+）
- 及时诊断至关重要：延误→关节软骨破坏→关节强直→功能丧失

### 治疗原则

1. **早期足量有效抗生素**：先经验性→根据细菌培养+药敏调整
2. 关节穿刺引流或切开引流：减轻腔内压力+冲洗
3. 关节制动（急性期）+ 早期功能锻炼（炎症控制后）
4. 关节镜下冲洗引流：创伤小，恢复快

## 骨关节炎（OA）

### 病因

关节软骨退行性变+继发性骨质增生。最常见类型为原发性（与年龄、肥胖、遗传相关）。女性多于男性。

### 临床表现

| 特征 | 说明 |
|------|------|
| **关节痛** | 活动后加重、休息缓解（机械性痛）；晚期静息痛 |
| **晨僵** | <30分钟（与类风湿关节炎的重要鉴别点） |
| **好发关节** | 膝、髋、手远端指间关节（Heberden结节）、近端指间关节（Bouchard结节） |
| **体征** | 关节肿胀（滑膜增生/积液）、骨性膨大、摩擦音/感、活动受限 |

### 诊断

临床表现+影像学（关节间隙变窄、骨赘形成、软骨下骨硬化/囊变）。

### 治疗

- **非药物**：减重、运动疗法、拐杖
- **药物**：NSAIDs、关节腔注射（糖皮质激素/透明质酸）
- **手术**：终末期→人工关节置换术

## 类风湿关节炎（RA）

### 概述

慢性、对称性、多关节炎为主要表现的系统性自身免疫疾病。女性多于男性（3:1），好发年龄30~50岁。

### 临床表现

| 特征 | 说明 |
|------|------|
| **关节表现** | 对称性多关节炎，好发MCP、PIP、腕关节 |
| **晨僵** | **>1小时**（OA<30min） |
| **关节外表现** | 类风湿结节（最常见）、肺间质病变、贫血、干燥综合征 |
| **典型畸形** | 手指尺侧偏斜、天鹅颈畸形、纽扣花畸形 |

### 实验室检查

RF（+）（70%~80%）、抗CCP抗体（更具特异性）、ESR↑、CRP↑、关节X线（晚期→骨侵蚀/关节间隙变窄/骨性强直）

### 治疗

改善病情抗风湿药（DMARDs）：甲氨蝶呤（首选）、来氟米特、生物制剂（TNF-α抑制剂等）。

- **NSAIDs** → 改善症状
- **DMARDs** → 延缓病情进展（早用、联合用）
- **手术** → 滑膜切除（早期）、关节置换（晚期）
