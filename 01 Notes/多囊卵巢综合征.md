# 多囊卵巢综合征

## 概述

多囊卵巢综合征（PCOS）是最常见的妇科内分泌疾病之一，我国生育期女性患病率5.6%～7.8%。以稀发排卵或无排卵、雄激素过高的临床或生化表现、卵巢多囊样改变为特征，常伴有胰岛素抵抗和肥胖。PCOS是导致[[排卵障碍性异常子宫出血|异常子宫出血]]和[[闭经]]的常见病因，长期无排卵可致子宫内膜增生甚至癌变。其胰岛素抵抗与[[妊娠合并糖尿病|2型糖尿病]]相关。

## 发病相关因素

病因未完全阐明，可能是遗传因素与环境因素共同作用。

- **遗传因素**：家族聚集性；GWAS在汉族女性中确认11个PCOS易感基因（LHCGR、DENND1A、THADA等）
- **环境因素**：孕期高雄激素/高AMH暴露；出生后肥胖、高胰岛素血症等代谢异常

## 病理生理与内分泌特征

**四大内分泌特征**：

| 特征 | 机制 |
|------|------|
| **雄激素过多** | 垂体分泌过量LH→卵巢间质、卵泡膜细胞产生过量雄激素 |
| **雌酮过多** | 雄烯二酮在外周转化为雌酮（E₁） |
| **LH/FSH比值增大** | LH持续高水平，FSH相对较低（负反馈） |
| **胰岛素过多** | 约50%患者存在胰岛素抵抗和代偿性高胰岛素血症 |

**恶性循环**：高雄激素→卵泡发育停滞→无优势卵泡→无排卵→持续雌激素→正反馈LH→更多雄激素；胰岛素→增强LH释放→促进卵巢和肾上腺分泌雄激素→抑制SHBG→游离睾酮↑

## 病理

- **卵巢**：双侧均匀增大（2～5倍），白膜增厚，包膜下多个2～9mm卵泡≥12枚（"项链征"）
- **子宫内膜**：长期单一雌激素刺激→不同程度增生→增加内膜癌风险

## 临床表现

多起病于青春期。

| 表现 | 特点 |
|------|------|
| **月经失调** | 最主要症状。月经稀发（周期35日～6个月）或闭经；也可不规则出血 |
| **不孕** | 排卵障碍所致 |
| **多毛、痤疮** | 高雄激素血症最常见表现。性毛为主，男性型分布 |
| **肥胖** | 腹型肥胖为主（腰围≥85cm或腰臀比≥0.85） |
| **黑棘皮症** | 皮肤皱褶部位灰褐色色素沉着 |

## 辅助检查

| 检查 | 发现 |
|------|------|
| **BBT** | 单相型 |
| **超声** | PCOM：单侧/双侧卵巢直径2～9mm卵泡≥12个，和/或卵巢体积≥10ml |
| **血清雄激素** | 睾酮正常或轻中度升高（≤正常上限2倍） |
| **LH/FSH** | LH/FSH≥2（非肥胖型明显） |
| **AMH** | 同龄女性2～4倍 |
| **代谢评估** | OGTT+胰岛素释放试验评估胰岛素抵抗；血脂、肝功能 |

## 诊断

**鹿特丹标准**（国际常用）：①稀发排卵或无排卵；②高雄激素临床表现和/或高雄激素血症；③PCOM。3项中符合2项，排除其他病因。

**中国标准**（2011年卫生部）：月经稀发/闭经/不规则子宫出血为**必需条件**，再加①高雄激素临床表现/高雄激素血症，或②PCOM。排除其他病因。

> 青春期PCOS诊断强调必须同时具备排卵障碍和高雄激素，避免过度诊断。

## 鉴别诊断

| 疾病 | 鉴别要点 |
|------|---------|
| **卵泡膜细胞增殖症** | 更严重，睾酮升高更显著 |
| **肾上腺皮质增生/肿瘤** | DHEAS>正常上限2倍；ACTH兴奋试验、地塞米松抑制试验 |
| **分泌雄激素的卵巢肿瘤** | 单侧、实性，超声/MRI可协助 |
| **垂体催乳素腺瘤** | PRL明显升高 |

## 治疗

需进行慢病管理（涉及代谢、心血管、肿瘤、情绪等多系统问题）。

### 调整生活方式

一线治疗。肥胖者减重可增加胰岛素敏感性，降低胰岛素、睾酮水平，恢复排卵。

### 药物治疗

#### 调节月经周期

| 方法 | 适用 |
|------|------|
| **复方短效口服避孕药** | 暂无生育需求+高雄激素症状的生育期女性 |
| **孕激素后半周期疗法** | 青春期、围绝经期首选；有妊娠计划者 |
| **雌孕激素序贯治疗** | 内源性雌激素不足致内膜薄者 |

#### 降低血雄激素水平

- **复方短效口服避孕药**：首选。含环丙孕酮或屈螺酮者效果好。痤疮3～6月见效，多毛6～12月
- **螺内酯**：40～100mg/d（监测血钾）
- **糖皮质激素**：肾上腺来源的雄激素过多

#### 改善胰岛素抵抗

**二甲双胍**：500mg bid/tid。增加胰岛素敏感性，降低胰岛素水平，改善排卵，提高促排卵效果。胰岛素抵抗与[[妊娠合并糖尿病|糖尿病]]的病理机制相似。

#### 诱导排卵

| 药物 | 用法 |
|------|------|
| **氯米芬（CC）** | 一线，第2～5日，50mg/d×5d，可增至150mg/d |
| **来曲唑（LE）** | 一线，第2～5日，2.5mg/d×5d，可增至5.0～7.5mg/d |
| **促性腺激素** | 二线 |

警惕卵巢过度刺激综合征（OHSS）。

### 手术治疗

**腹腔镜下卵巢打孔术（LOD）**：不常规推荐。对LH和游离睾酮升高者效果较好。风险：盆腔粘连、卵巢功能不全。

### 辅助生殖技术

IVF-ET：经各种治疗未孕，或合并其他不孕因素时。

### 心理治疗

PCOS患者易有焦虑/抑郁，应关注心理健康。

## 预后与随访

PCOS是终身性疾病，需要长期管理。重点在于预防远期并发症（2型糖尿病、心血管疾病、子宫内膜癌等），[[排卵障碍性异常子宫出血|子宫内膜保护]]是治疗的核心目标之一。改变生活方式是贯穿始终的基础治疗。
