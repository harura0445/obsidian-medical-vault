# 闭经

![[04 Attachments/妇产科-内分泌_p11.webp]]

## 概述

闭经指无月经或月经停止6个月。与[[排卵障碍性异常子宫出血|异常子宫出血]]同为月经异常的重要表现。[[女性生殖系统生理|HPO轴功能]]异常是闭经的核心机制。[[多囊卵巢综合征|PCOS]]和早发性卵巢功能不全是继发性闭经的常见病因，甲状腺功能异常也可引起闭经。POI详见[[绝经综合征|绝经管理]]相关内容。

| 类型 | 定义 |
|------|------|
| **原发性闭经** | 年龄>13岁第二性征未发育；或年龄>15岁第二性征已发育但月经未潮 |
| **继发性闭经** | 曾有月经后停止：原月经正常者停经≥3个月，或原月经稀发者停经≥6个月 |

> 青春期前、妊娠期、哺乳期及绝经后为生理性闭经。

**WHO分型**：
- **Ⅰ型**：内源性E₂不足，FSH正常/低下，PRL正常，无HPO病变证据
- **Ⅱ型**：内源性E₂>早卵泡期水平，FSH及PRL正常
- **Ⅲ型**：E₂低、FSH升高，提示卵巢功能衰竭

## 病因

### 原发性闭经

较少见，多为遗传原因或先天性发育缺陷。

**第二性征存在的原发性闭经**：

| 病因 | 特点 |
|------|------|
| **MRKH综合征** | 46,XX；始基子宫/无子宫、无阴道；约15%伴肾异常，5%～12%伴骨骼畸形 |
| **生殖道闭锁** | 处女膜闭锁、阴道横隔、阴道闭锁；46,XX，卵巢功能正常；周期性腹痛 |
| **雄激素不敏感综合征** | 46,XY；X染色体雄激素受体基因缺陷；睾丸在腹腔/腹股沟；表型为女性，无子宫及输卵管 |
| **真两性畸形** | 46,XX/46,XY/嵌合体；同时有卵巢和睾丸组织 |
| **卵巢抵抗综合征** | 原始卵泡+FSH升高（20～40IU/L）；对外源促性腺激素不敏感 |

**第二性征缺乏的原发性闭经**：

| 病因 | 特点 |
|------|------|
| **低促性腺激素性性腺功能减退** | 下丘脑GnRH不足或垂体Gn不足；约50%合并嗅觉缺陷（Kallmann综合征） |
| **特纳综合征** | 45,XO或其嵌合型；条索性腺，身材矮小，蹼颈、盾胸等躯体异常 |
| **46,XX单纯性腺发育不全** | 体格发育正常，卵巢条索状 |
| **Swyer综合征** | 46,XY单纯性腺发育不全；条索性腺，易发生性腺肿瘤，确诊后应切除 |
| **酶缺陷** | 17α-羟化酶缺失等 |

### 继发性闭经

发生率明显高于原发性。以下丘脑性闭经最常见。

| 类型 | 病因 | 特点 |
|------|------|------|
| **下丘脑性闭经** | 精神应激、体重减轻（神经性厌食）、运动过度、药物、颅咽管瘤 | 低促性腺激素性闭经 |
| **垂体性闭经** | **希恩综合征**（产后大出血→垂体坏死）、垂体肿瘤（最常见PRL腺瘤）、空蝶鞍综合征、垂体炎症 | Gn↓→卵巢功能↓ |
| **卵巢性闭经** | **POI/POF**、卵巢功能性肿瘤、PCOS | 高促性腺激素性闭经 |
| **子宫性闭经** | **Asherman综合征**（宫腔粘连）、子宫颈粘连 | HPO正常，第二性征正常 |

其他内分泌异常：甲状腺功能减退/亢进、肾上腺皮质功能异常等也可引起闭经。与[[排卵障碍性异常子宫出血|AUB-O的鉴别诊断]]有重叠。

## 诊断

![[04 Attachments/妇产科-内分泌_p16.webp]]

### 诊断步骤

闭经的诊断需先寻找原因，确定病变部位，再明确具体疾病。

**1. 病史**：月经史、诱因（精神应激、体重变化、剧烈运动、药物）、伴随症状（周期性腹痛、头痛、泌乳等）、手术史、家族史。

**2. 体格检查**：第二性征发育、身高体重、甲状腺、泌乳、妇科检查（内外生殖器发育）。

**3. 辅助检查（排除妊娠后）**：

| 检查 | 内容 |
|------|------|
| **激素测定** | 雌二醇、孕酮、睾酮；PRL；FSH、LH；TSH |
| **孕激素试验** | 阳性（撤退性出血）→内膜已受雌激素影响，流出道通畅 |
| **雌孕激素序贯试验** | 孕激素试验阴性者→阳性可排除子宫性闭经；阴性（重复一次）→子宫性/下生殖道性 |
| **垂体兴奋试验** | LH升高→垂体正常，病变在下丘脑；LH无升高→垂体功能减退 |
| **超声** | 子宫/卵巢形态、内膜厚度、卵泡数目 |
| **MRI/CT** | 头部蝶鞍区、盆腔 |
| **染色体检查** | 原发性闭经、高Gn性闭经、性发育异常 |
| **宫腔镜** | 排除宫腔粘连 |

### 诊断步骤图解

**原发性闭经**：体格检查→第二性征评估→子宫有无→激素测定→染色体核型分析。

**继发性闭经**：排除妊娠→孕激素试验→（阳性→无排卵；阴性→）雌孕激素序贯试验→（阳性→查FSH/PRL等定位；阴性→子宫性）→根据FSH/LH/PRL水平定位下丘脑/垂体/卵巢。

## 治疗

**治疗原则**：首选病因治疗，性激素治疗为主，促进第二性征发育，恢复月经，帮助生育。

### 全身治疗

积极治疗全身性疾病，保持标准体重，心理治疗，对因治疗（肿瘤、PCOS等）。

### 内分泌治疗

**性激素补充治疗**：

| 方案 | 适用 |
|------|------|
| **雌激素补充** | 青春期性幼稚小剂量起始，逐渐增至成人量 |
| **人工周期疗法** | 有子宫者。雌激素21d + 后10d加孕激素 |
| **孕激素疗法** | 体内有一定雌激素水平的II型闭经 |
| **口服避孕药** | 有避孕需求者；高雄激素PCOS |

### 促排卵治疗

有生育要求者：低促性腺激素→hMG+hCG；正常FSH/PRL的闭经→氯米芬；高FSH→不建议促排卵（卵巢衰竭）。

### 其他药物

溴隐亭（高PRL血症/垂体PRL瘤）、肾上腺皮质激素（CAH）、甲状腺素（甲减）。

### 手术治疗

生殖器畸形矫正、Asherman综合征宫腔镜分离粘连+支架+大剂量雌激素、肿瘤切除。含Y染色体的高促性腺激素闭经者，应切除性腺。

## 预后与随访

取决于病因。功能性闭经去除诱因后可恢复；POI/POF不可逆；激素治疗需长期管理。
