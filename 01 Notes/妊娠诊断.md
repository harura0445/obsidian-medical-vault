# 妊娠诊断

## 概述

妊娠期从末次月经第1日开始计算，约280日（40周）。临床上分为三个时期：**早期妊娠**（<14周）、**中期妊娠**（14～27周）、**晚期妊娠**（≥28周）。

## 早期妊娠的诊断

### 症状与体征

| 表现 | 要点 |
|------|------|
| 停经 | 最早症状，但非特有症状。过期10日以上尤其高度怀疑 |
| 早孕反应 | 停经6周左右出现，畏寒、头晕、乏力、恶心、晨吐，12周左右自行消失 |
| 尿频 | 增大子宫压迫膀胱，子宫超出盆腔后消失 |
| 乳房变化 | 胀痛，增大，乳晕色素加深，**蒙氏结节**（皮脂腺增生结节） |
| 妇科检查 | 阴道黏膜和宫颈紫蓝色；**黑加征（Hegar sign）**：妊娠6～8周宫颈与宫体间似不相连 |
| 其他 | 蜘蛛痣、肝掌、皮肤色素沉着 |

### 辅助检查

- **妊娠试验**：检测血或尿hCG，受精卵着床后不久即可测出。早孕试纸阳性结合临床表现可确诊妊娠
- **超声检查**：停经35日可见**孕囊**（GS），6周见胚芽和**原始心管搏动**。彩色多普勒见心管搏动可确诊为早期妊娠活胎。14周前测量**顶臀长（CRL）**估计孕周最准确。11～13周测量**NT厚度**和鼻骨，作为早期染色体疾病筛查指标

**诊断标准**：血或尿hCG阳性 + 超声见宫内孕囊/胚芽 + 心管搏动 = 确诊正常宫内妊娠活胎。

## 中、晚期妊娠的诊断与监测

### 体征与检查

**子宫增大与宫底高度**：

| 妊娠周数 | 手测宫底高度 | 尺测平均长度 |
|----------|-------------|-------------|
| 12周末 | 耻骨联合上2～3横指 | — |
| 16周末 | 脐耻之间 | — |
| 20周末 | 脐下1横指 | 18cm |
| 24周末 | 脐上1横指 | 24cm |
| 28周末 | 脐上3横指 | 26cm |
| 32周末 | 脐与剑突之间 | 29cm |
| 36周末 | 剑突下2横指 | 32cm |
| 40周末 | 脐与剑突之间或略高 | 33cm |

- **胎动**：16～20周开始自觉，28周后正常≥3次/小时或≥10次/2小时
- **胎心音**：12周多普勒可测，18～20周一般听诊器可闻，正常110～160次/分。需与子宫杂音、腹主动脉音、脐带杂音鉴别
- **胎体**：24周后可区分胎头（圆硬浮球感）、胎背（宽平）、胎臀（宽软不规则）、肢体

### 超声检查

- 妊娠20～24周：系统超声筛查胎儿结构畸形
- 彩色多普勒：检测子宫动脉、脐动脉和胎儿动脉血流。脐动脉PI和RI评估胎盘血流阻力，MCA的PSV判断胎儿贫血程度

## 胎姿势、胎产式、胎先露、胎方位

### 定义

| 术语 | 定义 |
|------|------|
| **胎姿势** | 胎儿在子宫内的姿势。正常为胎头俯屈，颏贴胸壁，四肢屈曲交叉于胸腹前 |
| **胎产式** | 胎体纵轴与母体纵轴的关系。纵产式（99.75%）、横产式（0.25%） |
| **胎先露** | 最先进入骨盆入口的胎儿部分。纵产式→头先露/臀先露，横产式→肩先露 |
| **胎方位** | 胎儿先露部指示点与母体骨盆的关系 |

### 指示点与胎方位

| 先露类型 | 指示点 | 胎方位种类 |
|----------|--------|-----------|
| 枕先露 | 枕骨 | 枕左前(LOA)、枕左横(LOT)、枕左后(LOP)、枕右前(ROA)、枕右横(ROT)、枕右后(ROP) |
| 面先露 | 颏骨 | 颏左前、颏左横、颏左后、颏右前、颏右横、颏右后 |
| 臀先露 | 骶骨 | 骶左前、骶左横、骶左后、骶右前、骶右横、骶右后 |
| 肩先露 | 肩胛骨 | 肩左前、肩左后、肩右前、肩右后 |

妊娠28周前胎位不固定。妊娠32周后胎位相对恒定。
