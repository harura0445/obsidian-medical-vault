# 高血压

> 高血压是以体循环动脉压升高为主要临床表现的心血管综合征，是心脑血管疾病最重要的危险因素之一，可损伤心、脑、肾等重要脏器的结构和功能，最终导致这些器官的功能衰竭。

## 概述

高血压可分为**原发性高血压**（essential hypertension，又称高血压病）和**继发性高血压**（secondary hypertension）。原发性高血压是多因素、多环节、多阶段、多机制和个体差异性较大的疾病，占高血压人群的绝大多数。

我国高血压患病率总体呈上升趋势，2015年调查显示患病率约27.9%，但知晓率（51.6%）、治疗率（45.8%）和控制率（16.8%）依然很低。

## 血压分类和定义

血压分类和标准（诊室血压，单位：mmHg）：

| 分类 | 收缩压 | | 舒张压 |
|------|--------|------|--------|
| 正常血压 | <120 | 和 | <80 |
| 正常高值血压 | 120~139 | 和/或 | 80~89 |
| 高血压 | ≥140 | 和/或 | ≥90 |
| — 1级高血压（轻度） | 140~159 | 和/或 | 90~99 |
| — 2级高血压（中度） | 160~179 | 和/或 | 100~109 |
| — 3级高血压（重度） | ≥180 | 和/或 | ≥110 |
| 单纯收缩期高血压 | ≥140 | 和 | <90 |
| 单纯舒张期高血压 | <140 | 和 | ≥90 |

> 当收缩压和舒张压分属于不同分级时，以较高的级别作为标准。

## 病因和发病机制

原发性高血压是遗传和环境因素交互作用的结果。

### 与高血压发病有关的因素

| 因素 | 说明 |
|------|------|
| **遗传因素** | 明显的家族聚集性，父母均有高血压者子女发病概率达46% |
| **饮食** | 钠盐摄入量与血压呈显著正相关（盐敏感性人群）；钾摄入量呈负相关；高蛋白、高饱和脂肪酸为升压因素；饮酒量与血压线性相关 |
| 精神应激 | 脑力劳动者患病率高，精神紧张度高者发生可能性大 |
| 吸烟 | 使交感神经末梢释放去甲肾上腺素增加，通过氧化应激损害NO介导的血管舒张 |
| **体重** | 体重增加是重要危险因素，腹型肥胖者易发生高血压 |
| 药物 | 口服避孕药、麻黄碱、糖皮质激素、NSAIDs、甘草等 |
| 睡眠呼吸暂停低通气综合征（SAHS） | SAHS病人50%有高血压 |
| 大气污染 | PM2.5、PM10、SO₂、O₃等污染物暴露增加发病风险 |

### 发病机制

| 机制 | 核心内容 |
|------|----------|
| **神经机制** | 交感神经系统活性亢进：心率增快、心肌收缩力加强、心排血量增加；小动脉收缩、外周阻力增加；肾交感活性增强致钠水重吸收增加、RAAS激活 |
| **肾脏机制** | 肾性水钠潴留→心排血量增加→外周血管阻力和血压升高；遗传性或获得性肾脏排钠能力下降为基本病理生理异常 |
| **激素机制（RAAS激活）** | AngⅡ收缩血管、刺激醛固酮分泌、促进去甲肾上腺素释放；组织RAAS在靶器官损害中作用更大 |
| **血管机制** | 血管重塑：大动脉弹性减退→收缩压升高脉压增大；内皮功能障碍→NO灭活增强、血管炎症和氧化应激 |
| **胰岛素抵抗（IR）** | 约50%原发性高血压病人存在IR，是2型糖尿病和高血压的共同病理生理基础；继发性高胰岛素血症致水钠重吸收增强、交感活性亢进 |

### 我国人群高血压特点

- 高钠、低钾膳食是主要危险因素
- 脑卒中/心肌梗死发病比值约（5~8）∶1（西方人群约1∶1）
- 人群叶酸普遍缺乏，同型半胱氨酸水平增高与脑卒中风险增加相关

## 病理生理和靶器官损害

> 平均动脉血压（MBP）= 心排血量（CO）× 总外周血管阻力（PR）

血管内皮功能障碍是高血压**最早期和最重要的血管损害**。

### 靶器官损害

#### 心脏——高血压心脏病

| 改变 | 机制 | 后果 |
|------|------|------|
| 左心室肥厚和扩大 | 长期压力负荷增高+儿茶酚胺与ATⅡ刺激心肌细胞肥大和间质纤维化 | 冠状动脉血流储备下降、心内膜下心肌缺血 |
| 合并[[冠心病]] | 动脉粥样硬化和微血管病变 | 心绞痛、[[急性心肌梗死]]、[[心力衰竭]]、[[慢性肺源性心脏病]] |

#### 脑

| 病变 | 机制 | 结果 |
|------|------|------|
| 脑出血 | 长期高血压使脑血管发生缺血变性，形成微动脉瘤，破裂出血 | 常累及壳核、丘脑、尾状核、内囊 |
| 脑血栓形成 | 脑动脉粥样硬化斑块破裂 | 缺血性脑卒中 |
| 腔隙性脑梗死 | 脑小动脉闭塞性病变 | 小灶性脑梗死 |
| 短暂性脑缺血发作 | 脑血管痉挛或微栓塞 | 一过性神经功能缺损 |

#### 肾脏

长期高血压→肾小球内囊压力升高→肾小球纤维化、萎缩→肾动脉硬化→肾实质缺血和肾单位不断减少→[[慢性肾脏病|慢性肾衰竭]]。合并[[糖尿病]]时更易发生。恶性高血压时入球小动脉及小叶间动脉发生增殖性内膜炎及纤维素样坏死，短期内出现肾衰竭。

#### 视网膜

Keith-Wagener眼底分级法：

| 分级 | 表现 |
|------|------|
| Ⅰ级 | 视网膜动脉变细、反光增强 |
| Ⅱ级 | 视网膜动脉狭窄、动静脉交叉压迫 |
| Ⅲ级 | 上述基础上出现眼底出血及棉絮状渗出 |
| Ⅳ级 | 上述基础上出现视盘水肿 |

## 临床表现及并发症

### 症状

大多数起病缓慢，缺乏特殊临床表现，仅在测血压时或发生并发症时才发现。常见症状包括：头晕、头痛、颈项板紧、疲劳、心悸等。突然发生严重头晕与眩晕时需注意脑血管病或降压过度的可能。

### 体征

- 周围血管搏动、血管杂音、心脏杂音为重点检查项目
- 重视颈部、背部肋脊角、上腹部脐两侧、腰部肋脊处的血管杂音
- 主动脉瓣区第二心音亢进、收缩期杂音或喀喇音
- 继发性高血压提示体征：腰部肿块（多囊肾/嗜铬细胞瘤）、股动脉搏动减弱（主动脉缩窄）、向心性肥胖和紫纹（皮质醇增多症）

### 并发症

| 并发症 | 具体疾病 |
|--------|----------|
| 脑血管病 | 脑出血、脑血栓形成、腔隙性脑梗死、短暂性脑缺血发作 |
| 心脏疾病 | [[心力衰竭]]、[[冠心病]]、[[急性心肌梗死|心肌梗死]]、[[心脏瓣膜病]] |
| 肾脏疾病 | [[慢性肾脏病|慢性肾衰竭]] |
| 主动脉疾病 | [[主动脉夹层]] |
| 视网膜病变 | 视网膜出血、渗出、视盘水肿 |

## 辅助检查

### 基本项目

血液生化（钾、钠、空腹血糖、血脂、尿酸、肌酐）；全血细胞计数；尿液分析；心电图。

### 推荐项目

| 检查 | 意义 |
|------|------|
| 24小时动态血压监测（ABPM） | 诊断白大衣高血压、隐蔽性高血压、评估血压昼夜节律及治疗效果 |
| 超声心动图 | 评估左心室肥厚、心功能 |
| 颈动脉超声 | 评估动脉粥样硬化 |
| 眼底检查 | 评估高血压视网膜病变 |
| 血同型半胱氨酸、尿白蛋白定量/尿蛋白定量 | 危险分层 |
| 脉搏波传导速度（PWV）、踝肱指数（ABI） | 评估动脉硬化 |

### 选择项目

怀疑继发性高血压时：肾素、醛固酮、皮质醇、儿茶酚胺、肾及肾上腺超声/CT/MRI、睡眠呼吸监测等。

## 诊断与危险分层

### 诊断标准

非同日三次测量血压值：收缩压≥140mmHg和/或舒张压≥90mmHg可诊断高血压。既往有高血压史，正在使用降压药物，血压虽然正常也诊断为高血压。

家庭自测血压：收缩压≥135mmHg和/或舒张压≥85mmHg为高血压。

### 高血压病人心血管危险分层

| 其他危险因素和病史 | 1级高血压 | 2级高血压 | 3级高血压 |
|---------------------|-----------|-----------|-----------|
| 无 | 低危 | 中危 | 高危 |
| 1~2个其他危险因素 | 中危 | 中/高危 | 很高危 |
| ≥3个危险因素或靶器官损害或CKD 3期，无并发症的糖尿病 | 高危 | 高危 | 很高危 |
| 临床合并症，或CKD≥4期，有并发症的糖尿病 | 高/很高危 | 很高危 | 很高危 |

### 影响预后的重要因素

| 心血管危险因素 | 靶器官损害 | 伴随临床疾病 |
|----------------|------------|--------------|
| 年龄（男>55岁，女>65岁） | 左心室肥厚（心电图/超声） | 脑血管病 |
| 吸烟或被动吸烟 | 颈动脉粥样硬化斑块（IMT≥0.9mm） | 心脏疾病（心梗、心绞痛、心衰、房颤） |
| 糖耐量受损/空腹血糖受损 | PWV≥12m/s或ABI<0.9 | 肾脏疾病（CKD、蛋白尿） |
| 血脂异常 | eGFR 30~59ml/(min·1.73m²) | 周围血管病 |
| 早发心血管病家族史 | 尿微量白蛋白30~300mg/24h | 视网膜病变（出血/渗出、视盘水肿） |
| 腹型肥胖或肥胖（BMI≥28） | — | [[糖尿病]] |
| 血同型半胱氨酸升高（≥10μmol/L） | — | — |

## 治疗

降压治疗的最终目的：**减少心脑血管病的发生率和死亡率**。收缩压下降10~20mmHg或舒张压下降5~6mmHg，3~5年内脑卒中减少38%、冠心病减少16%、心脑血管死亡减少20%、心力衰竭减少50%以上。

### 血压控制目标值

| 人群 | 目标值 |
|------|--------|
| 一般高血压病人 | <140/90mmHg |
| 合并糖尿病、慢性肾脏病、心衰或稳定冠心病 | <130/80mmHg |
| 老年收缩期高血压 | <150mmHg（可耐受降至140mmHg以下） |
| 80岁以上高龄老人 | <150/90mmHg |

### 治疗性生活方式干预（所有高血压病人）

| 措施 | 目标 |
|------|------|
| 减轻体重 | BMI<24kg/m² |
| 减少钠盐摄入 | 每日食盐不超过6g |
| 补充钾盐 | 每日吃新鲜蔬菜和水果 |
| 减少脂肪摄入 | 减少食用油，少吃肥肉和动物内脏 |
| 戒烟限酒 | — |
| 增加运动 | 中等强度有氧运动，每周4~7次，每次30~60分钟 |
| 减轻精神压力 | 保持心态平衡 |
| 补充叶酸 | 必要时 |

### 降压药物治疗对象

| 危险分层 | 策略 |
|----------|------|
| 高危和很高危 | 及时启动药物治疗 |
| 中危 | 观察数周，改善生活方式后不达标则启动药物治疗 |
| 低危 | 观察1~3个月，改善生活方式后不达标则开始药物治疗 |

### 五大类降压药

| 药物类别 | 代表药物 | 作用机制 | 适应证 | 禁忌证/不良反应 |
|----------|----------|----------|--------|-----------------|
| **利尿剂**（噻嗪类） | 氢氯噻嗪 | 排钠减少细胞外容量，降低外周血管阻力 | 单纯收缩期高血压、盐敏感性高血压、合并[[心力衰竭|心衰]]、老年人 | 低钾血症、影响血脂血糖尿酸、痛风 |
| **β受体拮抗剂** | 美托洛尔、比索洛尔 | 抑制中枢和周围RAAS，减慢心率降低心肌收缩力 | 心率较快的中青年、合并心绞痛和慢性心衰 | 急性心衰、病态窦房结综合征、严重房室传导阻滞；不良反应：心动过缓、乏力 |
| **CCB（钙通道阻滞剂）** | 硝苯地平（二氢吡啶类）、维拉帕米（非二氢吡啶类） | 阻滞L型钙通道，减少钙进入血管平滑肌，降低血管阻力 | 老年高血压、合并糖尿病/冠心病/外周血管病；长期治疗有抗动脉粥样硬化作用 | 反射性心率增快、面部潮红、头痛、下肢水肿；非二氢吡啶类不宜用于HFrEF和传导阻滞 |
| **ACEI** | 卡托普利、依那普利 | 抑制ACE减少ATⅡ生成，抑制缓激肽降解 | 合并心衰、心梗、房颤、蛋白尿、糖尿病肾脏病 | 刺激性干咳（10%~20%）、血管性水肿；妊娠、双侧肾动脉狭窄、高钾血症禁用 |
| **ARB** | 氯沙坦、缬沙坦 | 阻断AT1受体，更充分阻断AngⅡ效应 | 同ACEI，ACEI不耐受者的替代 | 一般不引起干咳，禁忌证同ACEI |

### ARNI（血管紧张素受体脑啡肽酶抑制剂）

沙库巴曲缬沙坦：同时阻断AT1受体+抑制利钠肽降解，增强利尿钠肽的降压作用。治疗对象和禁忌证与ACEI类似。

### 降压药物应用原则

| 原则 | 说明 |
|------|------|
| 个体化 | 根据血压水平、危险分层、合并症、耐受性和个人意愿选择 |
| 起始剂量 | 一般用常规剂量，老年人从小剂量开始 |
| 优先长效制剂 | 每日1次、持续24小时降压，控制夜间和晨峰血压 |
| 联合用药 | 血压≥160/100mmHg或高危及以上病人起始即可联合治疗 |

### 推荐联合治疗方案

| 组合 | 说明 |
|------|------|
| ACEI/ARB + 二氢吡啶类CCB | 主要推荐 |
| ARB/ACEI + 噻嗪类利尿剂 | 主要推荐 |
| 二氢吡啶类CCB + 噻嗪类利尿剂 | 主要推荐 |
| 二氢吡啶类CCB + β受体拮抗剂 | 主要推荐 |

三种降压药联合一般应包含利尿剂。多数病人4~12周内可达到血压控制目标值。

## 特殊类型高血压

### 老年高血压

- 特点：收缩压增高、舒张压下降、脉压增大；血压波动性大，易出现直立性低血压；昼夜节律异常多见
- 治疗：强调收缩压达标，避免过度降舒张压，避免过快降压。CCB、ACEI、ARB、利尿剂均可选用

### 难治性高血压

在改善生活方式基础上，应用可耐受的足够剂量且合理的3种降压药物（包括利尿剂）至少4周后血压仍未达标。须排查：
- 假性难治性高血压（白大衣现象、血压测量错误）
- 生活方式未改善
- 治疗方案不合理
- 干扰降压的其他药物（NSAIDs、拟交感胺类、口服避孕药、糖皮质激素）
- 容量超负荷
- 胰岛素抵抗
- 继发性高血压（如[[原发性醛固酮增多症]]、[[嗜铬细胞瘤]]、肾动脉狭窄等）

### 高血压急症和亚急症

| 对比 | 高血压急症 | 高血压亚急症 |
|------|------------|--------------|
| 定义 | 血压明显升高（一般>180/120mmHg），**伴有进行性靶器官功能不全** | 血压明显升高，**不伴**严重临床症状及进行性靶器官损害 |
| 处理 | 迅速降低血压（静脉途径给药） | 24~48小时内降低血压（口服降压药） |

#### 高血压急症包括

高血压脑病、颅内出血、脑梗死、[[心力衰竭|急性左心衰竭]]、[[急性心肌梗死|急性冠脉综合征]]、[[主动脉夹层]]、子痫、急进性肾小球肾炎、嗜铬细胞瘤危象等。

> **恶性高血压**：舒张压持续≥130mmHg，伴头痛、视力模糊、眼底出血渗出和视盘水肿、肾脏损害突出（蛋白尿、血尿）。

#### 高血压急症处理原则

| 原则 | 内容 |
|------|------|
| 迅速降压 | 静脉滴注给药，同时严密监测血压 |
| 控制性降压 | 初始1小时内平均动脉压降低不超过治疗前25%；随后2~6小时降至160/100mmHg左右；24~48小时逐步降至正常 |
| 合理选药 | 起效迅速、作用持续短、停药后消失快、不良反应小、不明显影响心率和脑血流 |
| 避免药物 | 利血平（蓄积效应致严重低血压）、强力利尿剂（存在容量不足风险） |

#### 高血压急症常用静脉降压药

| 药物 | 特点 | 主要适应证 |
|------|------|------------|
| 硝普钠 | 动静脉双重扩张，起效快停药后2~10分钟作用消失 | 各种高血压急症；含氰化物，使用不超过72小时 |
| 硝酸甘油 | 扩张静脉和冠状动脉 | 合并急性心衰或急性冠脉综合征 |
| 尼卡地平 | 二氢吡啶类CCB，改善脑血流 | 合并急性脑血管病 |
| 拉贝洛尔 | α+β受体拮抗剂 | 合并妊娠或肾功能不全 |

## 继发性高血压

下列情况应筛查继发性高血压：
- 中、重度血压升高的年轻病人
- 症状、体征或实验室检查有怀疑线索（如肢体脉搏不对称、腹部血管杂音、低钾血症）
- 药物联合治疗效果差，或血压曾经控制良好近期又明显升高
- 恶性高血压病人

| 继发性高血压类型 | 病因 | 特征 |
|-------------------|------|------|
| **肾实质性高血压** | 急慢性肾小球肾炎、糖尿病肾脏病、多囊肾等 | 最常见继发性高血压；常伴蛋白尿、血尿 |
| **肾血管性高血压** | 肾动脉狭窄（动脉粥样硬化、大动脉炎、纤维肌发育不良） | 进展迅速或突然加重；上腹部或肋脊角血管杂音 |
| 原发性醛固酮增多症 | 肾上腺皮质增生或肿瘤 | 高血压+低血钾（部分血钾正常） |
| 嗜铬细胞瘤 | 肾上腺髓质或嗜铬组织肿瘤 | 阵发性血压升高伴心动过速、头痛、出汗 |
| 皮质醇增多症 | 肾上腺分泌糖皮质激素过多 | 高血压+向心性肥胖、满月脸、紫纹 |
| 主动脉缩窄 | 先天性或多发性大动脉炎 | 上肢血压升高、下肢血压降低 |

## 预后

高血压的预后取决于血压水平、危险因素、靶器官损害和并发症的综合情况。血压长期达标可显著降低心脑血管事件风险。病人需长期坚持降压治疗，不应随意停止或频繁改变治疗方案。
