# 炎症性肠病

> 炎症性肠病（inflammatory bowel disease，IBD）是一组病因未明的慢性非特异性肠道炎症性疾病，主要包括[[溃疡性结肠炎]]（UC）和[[克罗恩病]]（CD），由环境因素作用于遗传易感者、在肠道微生物参与下引起免疫失衡所致。

## 概述

IBD 发病率近年在我国逐渐上升。UC 主要表现为慢性腹痛、腹泻及黏液脓血便，病变主要累及结直肠，呈连续性分布。CD 是一种慢性炎性肉芽肿性疾病，可累及全消化道，以末段回肠及邻近结肠多见，呈节段性分布。两者均好发于青壮年。

## 病因与发病机制

| 因素 | 机制 |
|------|------|
| 环境因素 | 经济发达地区发病率高，我国随经济发展发病率上升 |
| 遗传因素 | 一级亲属发病率显著高于普通人群，单卵双胞发病率高于双卵双胞 |
| 肠道微生态 | IBD 病人存在菌群丰度与多样性下降 |
| 免疫失衡 | Th1/Th2/Th17 炎症通路激活，TNF-α、IFN-γ、IL-1β、IL-6 等炎症因子增多，炎症因子/抗炎因子失衡 |

发病机制概括：**环境因素 → 遗传易感者 → 肠道微生物参与 → 免疫失衡 → 肠黏膜屏障损伤 → 持续炎症损伤**。

## 第一节 | 溃疡性结肠炎（UC）

### 病理

- **病变部位**：主要局限于结直肠黏膜与黏膜下层，呈**连续性弥漫性分布**
- **病变方向**：多自直肠开始，逆行向结肠近段发展
- **活动期**：固有层内弥漫性炎症细胞浸润，黏膜糜烂、溃疡、隐窝炎及隐窝脓肿
- **慢性期**：隐窝结构紊乱，杯状细胞减少，潘氏细胞化生及炎性息肉
- 病变限于黏膜与黏膜下层，**穿孔、瘘管少见**

### 临床表现

#### 消化系统表现

| 表现 | 说明 |
|------|------|
| **腹泻和黏液脓血便** | 活动期最重要的临床表现；轻者 2~3 次/日，重者 >10 次/日 |
| **腹痛** | 轻至中度，左下腹或下腹隐痛，有里急后重感，便后缓解 |
| 其他 | 腹胀、食欲缺乏、恶心、呕吐 |
| 体征 | 轻中度仅有左下腹轻压痛，重度有明显压痛 |

#### 全身反应

- 发热（中重度病人，低至中度）
- 营养不良（衰弱、消瘦、贫血、低白蛋白血症）

#### 肠外表现

| 类别 | 具体表现 |
|------|----------|
| 皮肤 | 结节性红斑、坏疽性脓皮病 |
| 关节 | 外周关节炎、骶髂关节炎、强直性脊柱炎 |
| 眼部 | 巩膜外层炎、前葡萄膜炎 |
| 口腔 | 复发性口腔溃疡 |
| 肝胆 | 原发性硬化性胆管炎 |

### 临床分型

| 分类依据 | 分型 |
|----------|------|
| 临床类型 | 初发型、慢性复发型（最多见） |
| 严重程度 | 轻度（排便 ≤3 次/日），中度，重度（排便 ≥6 次/日、明显血便） |
| 病变范围 | 直肠炎、左半结肠炎、广泛结肠炎 |

### 并发症

| 并发症 | 说明 |
|--------|------|
| **中毒性巨结肠** | 约 5% 重症 UC，结肠急性扩张，易穿孔，预后差 |
| **癌变** | 病程 >20 年者结肠癌风险增高 10~15 倍 |
| 结肠大出血 | 发生率约 3% |
| 肠穿孔 | 多与中毒性巨结肠有关 |

### 辅助检查

| 检查 | 表现 |
|------|------|
| **结肠镜**（最重要） | 连续性弥漫性分布，从直肠开始逆行；黏膜血管纹理模糊/消失、充血水肿、糜烂及浅溃疡、脓性分泌物；慢性期黏膜粗糙呈细颗粒状、炎性息肉、结肠袋变浅或消失 |
| 血液 | 贫血、白细胞↑、血沉↑、CRP↑（提示活动期） |
| 粪便 | 黏液脓血，镜下红细胞和脓细胞，钙卫蛋白↑（提示活动期） |
| X 线钡剂灌肠 | 黏膜粗乱、多发浅溃疡、结肠袋消失呈铅管状（重症不宜做） |

### 诊断与鉴别诊断

**诊断依据**：持续或反复发作腹泻/黏液脓血便/腹痛/里急后重 + 结肠镜表现 + 黏膜活检组织学改变，排除感染性肠炎及其他疾病。

| 鉴别疾病 | 要点 |
|----------|------|
| 感染性肠炎（细菌性痢疾、阿米巴肠炎等） | 粪便病原学检查阳性，抗生素/抗阿米巴有效 |
| 结肠 CD | 见下表 |
| [[结直肠癌]] | 直肠指检触及肿块，结肠镜+活检确诊 |
| [[肠易激综合征]] | 粪便无脓血，隐血阴性，结肠镜无器质性病变 |
| 血吸虫病 | 疫水接触史，粪便查见虫卵 |

### 治疗

| 药物类别 | 适用 | 代表药物 |
|----------|------|----------|
| **氨基水杨酸制剂** | 轻中度 UC 诱导缓解及维持治疗 | 5-ASA（3~4g/d 口服）、柳氮磺吡啶（SASP） |
| **糖皮质激素** | 5-ASA 疗效不佳的中重度病人首选 | 泼尼松 0.75~1mg/(kg·d)；只用于活动期诱导缓解，不宜长期用 |
| **免疫抑制剂** | 5-ASA 维持治疗不佳、激素依赖者的维持 | 硫唑嘌呤、巯嘌呤（治疗前检测 NUDT15 基因） |
| **生物制剂/小分子药物** | 激素抵抗或依赖、传统治疗无效 | 英夫利昔单抗（抗 TNF-α）、维得利珠单抗、乌司奴单抗、乌帕替尼（JAK 抑制剂） |

手术指征：中毒性巨结肠内科治疗无效、大出血、肠穿孔、癌变、内科治疗不佳影响生活质量。

## 第二节 | 克罗恩病（CD）

### 病理

| 特征 | 说明 |
|------|------|
| 大体形态 | ①节段性分布；②纵行溃疡及**鹅卵石样外观**；③肠壁全层受累，肠壁增厚、肠腔狭窄 |
| 组织学 | ①**非干酪样肉芽肿**（特征性）；②裂隙状溃疡；③肠壁各层炎症 |

### 临床表现

| 表现 | 说明 |
|------|------|
| **腹痛** | 最常见症状，多位于右下腹或脐周，间歇性发作 |
| **腹泻** | 糊状便，可有血便，黏液脓血便不如 UC 明显 |
| 腹部包块 | 10%~20%，右下腹与脐周多见 |
| **瘘管形成** | CD 较为特异的表现，分为内瘘（通向肠段/膀胱/阴道）和外瘘（通向腹壁/肛周） |
| 肛周病变 | 肛周瘘管、脓肿及肛裂，可为首发症状 |

**全身表现**：发热（间歇性低热或中度热）、体重下降、贫血、低白蛋白血症。肠外表现与 UC 相似但发生率较高。

### 临床分型

| 分类依据 | 分型 |
|----------|------|
| 疾病行为（B） | B1 非狭窄非穿透型，B2 狭窄型，B3 穿透型，可伴有肛周病变（P） |
| 病变部位（L） | L1 回肠末段型，L2 结肠型，L3 回结肠型，L4 上消化道型 |
| 严重程度 | 按 CDAI 评分分为活动期/缓解期，轻/中/重度 |

### 辅助检查

| 检查 | 表现 |
|------|------|
| **结肠镜**（常规首选） | 节段性、非对称性炎症；特征性：非连续性病变、纵行溃疡、鹅卵石样外观 |
| **CTE/MRE** | 评估肠壁炎症、狭窄、瘘管、脓肿；活动期典型："靶征"/"双晕征"、"梳样征" |
| 胶囊内镜/小肠镜 | 适用于怀疑小肠 CD |
| 胃肠钡剂造影 | 纵行溃疡、鹅卵石征、假息肉、多发性狭窄、瘘管形成 |

### 诊断

慢性起病 + 反复腹痛/腹泻/体重下降 + 肠梗阻/腹块/肠瘘/肛周病变 → 内镜+影像支持 → 病理组织学支持，排除其他病因后诊断。

**支持征象越多，可能性越大**：①非连续性或节段性病变；②鹅卵石样或纵行溃疡；③全层炎症；④非干酪样肉芽肿；⑤裂沟、瘘管；⑥肛周病变。

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| [[肠结核]] | 结核中毒症状，病变以回盲部为主，干酪样肉芽肿 |
| 肠淋巴瘤 | 进展较快，X 线见指压痕、充盈缺损，淋巴结肿大 |
| UC | 见下表 |
| 急性阑尾炎 | 转移性右下腹痛，腹泻少见 |

## UC 与 CD 对比

| 鉴别要点 | UC | CD |
|----------|-----|-----|
| **症状** | 脓血便多见 | 脓血便较少见 |
| **病变分布** | 连续性 | 节段性 |
| **直肠受累** | 绝大多数受累 | 少见 |
| **肠腔狭窄** | 少见，中心性 | 多见，偏心性 |
| **溃疡特征** | 溃疡浅，黏膜弥漫性充血水肿、颗粒状，脆性增加 | 纵行溃疡，黏膜呈鹅卵石样，病变间黏膜正常 |
| **组织病理** | 固有膜全层弥漫性炎症、隐窝脓肿、隐窝结构异常、杯状细胞减少 | **非干酪样肉芽肿**、裂隙状溃疡、黏膜下层淋巴细胞聚集 |
| **穿孔/瘘管** | 少见（多限于黏膜/黏膜下层） | 多见（全层炎症） |
| **癌变风险** | 病程 >20 年，风险增高 | 炎症迁延不愈者风险增加 |

### CD 治疗

| 药物类别 | 适用 | 备注 |
|----------|------|------|
| **糖皮质激素** | 活动期症状缓解 | 泼尼松 0.75~1mg/(kg·d)；局限回盲部者可用布地奈德 |
| **免疫抑制剂** | 激素无效或依赖的维持治疗 | 硫唑嘌呤 1.5~2.5mg/(kg·d)，起效慢（3~4 月），监测骨髓抑制 |
| **生物制剂/小分子药物** | 传统治疗无效的活动性 CD | 英夫利昔单抗、阿达木单抗、维得利珠单抗、乌司奴单抗、乌帕替尼 |
| 全肠内营养 | 常规治疗效果欠佳、青少年病人 | 有助于诱导缓解 |
| 抗生素 | 合并腹腔脓肿或肛周脓肿 | 硝基咪唑类、喹诺酮类 |

手术适应证：肠梗阻、腹腔脓肿、急性穿孔、不能控制的大出血及癌变（术后复发率高，需药物预防复发）。

## 预后

UC：大部分反复发作，轻度及长期缓解者预后好；病程 8 年以上广泛结肠炎和 15 年以上左半结肠炎病人应每 1~2 年行监测性结肠镜检查。

CD：大多数反复发作、迁延不愈；部分因并发症需要手术；规范治疗对恢复生活质量非常重要。**吸烟是 CD 活动及复发的危险因素，病人必须戒烟**。
