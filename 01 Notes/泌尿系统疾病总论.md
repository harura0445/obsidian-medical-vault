# 泌尿系统疾病总论

> 来源：内科学课件《23泌尿系统疾病总论》—— 华东医院肾内科 张晓丽

## 第一节 肾脏的结构

### 大体解剖

肾脏位于**第12胸椎至第3腰椎**，右侧比左侧低0.5–1个椎体。肾脏大小为：长10.5~11.5cm，宽5.0~7.2cm，厚2.0~3.0cm，重量约100~140g。

肾脏剖面结构：**肾包膜 → 皮质（肾小球）→ 皮髓交界 → 髓质（集合管）**。

**肾门**：肾动脉、肾静脉、神经、输尿管、淋巴管出入之处。

![[04 Attachments/内科学-肾脏大体解剖.webp]]

### 肾脏的血液循环

肾脏血流量占心输出量的**20~25%**。皮质血流占85~90%，外髓10%，内髓仅1~2%。

特点：肾小球毛细血管网内的压力**比普通毛细血管网高**；肾脏血流有**自身调节**特点。

### 肾单位（nephron）

**肾单位是肾脏的基本功能单位**，每个肾脏约有**100万个肾单位**。组成：

- **肾小体**：[[肾小球]]、[[肾小囊]]（鲍曼囊）、入球和出球动脉
- **肾小管**：[[近曲小管]]、髓袢降支和升支、[[远端小管]]（有极性——定向转运）

![[04 Attachments/内科学-肾单位结构.webp]]

### 肾小球

包括**肾小球毛细血管丛**和**包曼囊**两部分。

- 毛细血管丛含三种细胞：**内皮细胞、系膜细胞、脏层上皮细胞（足细胞）**，以及基底膜、系膜组织
- 包曼囊：**壁层上皮细胞**

### 滤过屏障

由三层结构组成，由内向外：

| 层次 | 结构 | 关键特征 |
|------|------|---------|
| **内皮细胞** | 窗孔 | 带负电荷 |
| **基底膜**（GBM） | 厚270~350nm，主要由IV型胶原组成 | 带负电荷 |
| **脏层上皮细胞（足细胞）** | 足突间的裂隙——裂孔，含nephrin、podocin等 | 裂隙蛋白异常→滤过膜通透性↑ |

![[04 Attachments/内科学-滤过屏障.webp]]

### 系膜区

- **支撑作用**
- **内分泌功能**
- **收缩调节滤过膜**
- **吞噬和清除功能**

### 肾小球旁器（Juxtaglomerular Apparatus）

| 组成 | 位置 | 功能 |
|------|------|------|
| **球旁细胞** | 入球小动脉壁平滑肌细胞衍化 | 分泌[[肾素]] |
| **致密斑** | 远端肾小管起始部紧靠肾小球一侧的上皮细胞 | 感受尿液NaCl浓度，调节肾素分泌（管球反馈） |
| **球外系膜细胞** | 血管极入/出球小动脉和致密斑之间 | 可转化为具有肾素颗粒的细胞 |
| **极周细胞** | 肾小囊壁层与脏层上皮细胞的移行处 | 分泌促进肾小管对钠离子重吸收的物质 |

![[04 Attachments/内科学-肾小球旁器.webp]]

### 肾小管与肾间质

- **肾小管**：包括近曲小管、髓袢（降支/升支）、远端小管
- **肾间质组成**：间质细胞 + 细胞外基质（胶原、纤维连接蛋白、层粘蛋白等）
- **肾间质功能**：
  - 支撑、连接
  - 产生和调节细胞外基质
  - 维持水和溶质的交换及浓度梯度
  - 参与肾组织损伤、炎症修复及[[肾间质纤维化|纤维化]]过程
  - 以旁分泌/内分泌方式产生生物活性物质（如[[促红细胞生成素|促红素]]）

## 第二节 肾脏的生理功能

### 三大功能

| 功能 | 内容 |
|------|------|
| **排泄** | 清除新陈代谢废物 |
| **重吸收和分泌** | 维持体液成分和酸碱度相对恒定（钾、钠、氯、HCO₃⁻等） |
| **内分泌** | 分泌[[肾素]]、[[促红细胞生成素]]（EPO）、合成活性[[维生素D]]等 |

![[04 Attachments/内科学-肾脏生理功能.webp]]

### 肾小球滤过作用

- **肾小球滤过率（GFR）**：通常所说的肾功能指肾脏清除代谢废物的能力，用GFR表示
- **有效滤过压** =（肾小球毛细血管压 + 囊内液胶体渗透压）-（血浆胶体渗透压 + 肾小囊内压）
  - 肾小球毛细血管压是滤过作用的**唯一动力**

#### 影响滤过的因素

1. 肾小球血流量
2. 滤过膜面积
3. 有效滤过压
4. **滤过膜的通透性**：
   - **机械屏障**：内皮细胞 → 基底膜致密层 → 足突裂孔膜
   - **电荷屏障**：阴电荷（内皮细胞、基底膜、足突）
5. 滤过物质的分子量

### 水钠调节

- **滤过分数**：20%
- **钠离子**：180升原尿中99%被重吸收；调节机制包括颈动脉容量感受器/交感活性/肾素释放/RAAS系统（[[醛固酮]]），以及[[心房利钠肽]]
- **渗透压平衡**：通过[[抗利尿激素]]（ADH）调节，其受体位于[[集合管]]

### 钾平衡

- 90%摄入的钾从肾脏排泄
- 近端小管及髓袢是主要吸收部位
- **远端小管是调节钾排泄的主要场所**
- 主要调节激素：[[醛固酮]]

### 调节酸碱平衡

- 重吸收滤过的碳酸氢根（近端小管重吸收占90%，泌H⁺）
- 重新生成碳酸氢根
- 分泌氢离子（连接管和皮质集合管——闰细胞）
- 分泌铵离子（NH₄⁺）
- 可滴定酸

### 肾脏的内分泌功能

| 活性物质 | 产生部位 | 作用 |
|---------|---------|------|
| [[肾素]] | 近球旁器（低灌注、交感兴奋等触发） | RAAS激活 |
| [[促红细胞生成素]]（EPO） | 间质细胞 | 促进[[红细胞]]生成 |
| 1α-羟化酶 | 肾脏 | 生成活性[[维生素D₃]] |
| [[前列腺素]] | PGI₂/PGE₂/PGF₂/TXA₂ | 调节肾血流 |
| [[激肽释放酶]] | 肾皮质 | 激肽原→激肽 |

## 第三节 肾脏病的临床表现和实验室检查

### 临床表现

**肾脏疾病的表现**：
- [[水肿]]：眼睑和下肢
- 腰酸、腰痛
- 尿量或尿色异常（混浊、发红、泡沫），[[夜尿]]多
- 尿检异常
- 肾功能异常
- 肾脏形态改变
- **后期的肾衰表现**：[[贫血]]、[[高血压]]
- **继发性肾脏病病因的表现**：如关节痛、[[糖尿病]]眼底病变等

![[04 Attachments/内科学-肾脏病临床表现.webp]]

#### 1. 血尿

- **概念**：眼观血尿、[[尿隐血]]、尿镜检（RBC数/HP，RBC管型）、尿RBC计数
- 尿液中的红细胞可来源于**尿路任何部位**，不代表一定是肾脏病
- **诊断程序**：是不是血尿（排除假性）→ 血尿来源鉴别

详见[[血尿]]。

#### 2. 蛋白尿

- 正常肾小球滤过膜允许分子量 < 4×10⁴ Da的蛋白质通过，滤出蛋白95%在近曲小管重吸收
- 终尿正常：蛋白质 < 150mg/d，分子量小（白蛋白或小分子蛋白）
- **蛋白尿定义**：24h尿蛋白持续 > 150mg，或尿蛋白/肌酐 > 200mg/g

**根据发生机理分类**：

| 类型 | 特点 |
|------|------|
| **生理性蛋白尿** | — |
| **体位性（直立性）蛋白尿** | 尿蛋白不超过1g/d |
| **功能性蛋白尿** | 运动、发热、过热、交感兴奋等引起 |
| **肾小球性蛋白尿** | 选择性/非选择性 |
| **肾小管性蛋白尿** | 量少、小分子蛋白 |
| **溢出性蛋白尿** | 血低分子量蛋白过多 |
| **组织性蛋白尿** | 泌尿系统分泌的蛋白质增加 |

#### 3. 水肿

特点：**疏松、低垂部位**
- **肾炎性水肿**：滤过减少
- **肾病性水肿**：[[低白蛋白血症]]
- **其他**：内分泌改变

详见[[水肿]]。

#### 4. 高血压

- 包括[[肾血管性高血压|肾血管性]]和[[肾实质性高血压]]
- **高血压和肾脏损害可互为因果**——肾脏病患者需经常查血压，高血压患者需经常查尿
- 肾实质性高血压主要是**水钠潴留**所致，RAAS也发挥重要作用

### 相关检查

#### （一）尿液分析

- **尿常规**：定性检查（比重、pH、细胞、蛋白、管型等）
- **尿相差显微镜**：观察[[红细胞]]形态
- **尿蛋白检测**：24h总量、随机尿白蛋白/肌酐
- **尿白蛋白**：24h尿白蛋白、尿白蛋白/肌酐
- **其他**：转铁蛋白、β₂微球蛋白、尿轻链等

**重要概念**：
1. 尿常规是诊断肾脏病的**重要线索**
2. 尿常规异常 ≠ 一定是肾脏病
3. 尿常规正常 ≠ 不存在肾脏疾病
4. 尿液异常程度 ≠ 肾脏病严重程度
5. 尿液异常可以是原发或继发肾脏病引起

![[04 Attachments/内科学-尿液分析.webp]]

#### （二）肾功能测定

**肾功能包括**：
- **肾小球功能**：滤过
- **肾小管功能**：浓缩、稀释、酸化、重吸收
- **内分泌功能**

**评估GFR的指标**：

| 方法 | 说明 |
|------|------|
| **金标准** | 菊粉清除率；其次为⁹⁹ᵐTc-DTPA、⁵¹Cr-EDTA等核素或碘海醇 |
| **血肌酐（Scr）** | 肌酐与GFR呈**非线性关系**。GFR下降到50ml/min左右时Scr仍可在正常范围，故不能反映早期肾功能减退 |
| **血清胱抑素C（CysC）** | 低分子量蛋白（13kd），所有有核细胞恒定速率产生。FDA认为性能优于肌酐，尤其肾功能轻度减退时更敏感 |
| **公式估算** | CKD-EPI目前首选；基于Scr和CysC的联合公式更准确 |

**血肌酐的非GFR影响因素**：
- 检测方法（苦味酸 vs 酶法）
- 肌肉质量（年龄、性别、种族）
- 食用大量肉类、补充肌酸
- 肌损伤（横纹肌溶解）
- 血稀释
- 药物（安体舒通、丙磺舒、西米替丁等使Scr升高）

**肾小管功能检测**：
- 酸化功能（重吸收HCO₃⁻、尿可滴定酸、NH₄⁺）
- 浓缩稀释功能（随机尿比重、尿渗透压、禁水12h尿渗透压等）
- 近端肾小管重吸收功能（尿β₂微球蛋白等）

#### （三）影像检查

超声、CT、核磁共振、腹平片/静脉或逆行肾盂造影、膀胱镜、放射性核素

#### 肾脏活检

常具有**确诊价值**——了解疾病是否活动及严重程度。

#### 其他相关检查

- 继发性肾脏病相关：血糖、肝炎标志物、肿瘤标志物、血浆蛋白固定电泳、风湿指标
- 肾脏病并发症：甲状旁腺激素等
- 合并症检查：高血压或糖尿病靶器官损害

## 第四节 肾脏病的诊断

### 肾脏病的分类

三种分类方式，**三者之间没有一一对应关系**：
1. **临床分类**：综合征（不是最后诊断！）
2. **病理分类**
3. **功能分类**

![[04 Attachments/内科学-肾脏病分类与诊断.webp]]

### 常见临床综合征

| 综合征 | 要点 |
|--------|------|
| **急性肾损伤（AKI）** | 肾功能急剧下降 |
| **肾炎综合征** | 血尿、蛋白尿、高血压为突出表现；包括急性/急进性/慢性 |
| **肾病综合征** | 大量蛋白尿、低白蛋白血症、水肿、高脂血症；原发性vs继发性 |
| **无症状性蛋白尿和/或血尿** | 尿常规正常也不能排除严重肾脏病 |
| **肾小管-间质疾病** | 蛋白尿少，常<1g/d |
| **肾血管疾病** | [[肾动脉狭窄]]（动脉粥样硬化、大动脉炎、纤维肌性发育不良）；肾小血管病变（结节性多动脉炎等） |
| **慢性肾脏病（CKD）** | 肾损害≥3个月，伴或不伴GFR降低；或GFR<60≥3个月 |

### CKD分期

参见 CGA 分期（绿色=低，黄色=中度，橙色=高，红色=非常高）。

![[04 Attachments/内科学-CKD分期.webp]]

### 诊断思路（六步法）

1. **是不是肾脏病**：尿液检查异常→是不是由肾脏病引起
2. **临床类型**：属于哪种综合征
3. **病理诊断**：注意病理诊断不能替代病因诊断
4. **病因诊断**：原发还是继发？诊断原发性者仍要始终警惕继发性
5. **功能诊断**
6. **并发症诊断 + 合并症诊断**

## 肾脏疾病防治原则

| 治疗层次 | 具体措施 |
|---------|---------|
| **一般治疗** | 休息、[[戒烟]]；饮食：低盐、控制蛋白摄入 |
| **病因治疗** | 免疫抑制剂等 |
| **非免疫机制治疗** | • [[降压]]：首选RAS阻断剂，须达靶目标<br>• 减少蛋白尿和肾损害：RAS阻断剂、[[SGLT2抑制剂]]、醛固酮受体阻断剂 |
| **并发症治疗** | [[促红细胞生成素|促红素]]、活性维生素D、他汀类 |
| **替代治疗** | [[血液透析]]、[[腹膜透析]]、[[肾脏移植]] |
| **中西医结合治疗** | |
