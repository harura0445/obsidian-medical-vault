# 糖尿病

> 糖尿病（DM）是一组由多病因引起的以慢性高血糖为特征的代谢性疾病，由胰岛素分泌和/或作用缺陷引起，长期代谢紊乱可致多系统损害（眼、肾、神经、心脏、血管等）。

## 流行病学

- 2021年全球成年糖尿病患者5.37亿，预计2045年达7.83亿
- 中国2021年成人糖尿病患者1.41亿，患病率11.7%
- 约50%未被诊断；T2DM占90%~95%，T1DM<5%

## 糖尿病分型（WHO 2019）

| 分型 | 特点 |
|------|------|
| **[[1型糖尿病]]（T1DM）** | 免疫介导的胰岛β细胞破坏，常导致胰岛素绝对缺乏 |
| **[[2型糖尿病]]（T2DM）** | 胰岛素抵抗为主伴进行性分泌不足，或以胰岛素进行性分泌不足为主伴胰岛素抵抗 |
| 混合型糖尿病 | 缓慢进展的免疫介导成人糖尿病、酮症倾向的T2DM |
| 其他特殊类型 | 单基因糖尿病（MODY、线粒体基因突变糖尿病）、胰腺外分泌疾病、内分泌疾病（库欣病、肢端肥大症）、药物所致、感染、免疫介导等 |
| 未分类糖尿病 | 暂时不能明确归类 |
| 妊娠期首次发现高血糖 | 妊娠期间的糖尿病（诊断标准同非妊娠）、妊娠糖尿病（GDM，切点更低） |

## 病因和发病机制

| 要点 | T1DM | T2DM |
|------|------|------|
| 核心机制 | 自身免疫→选择性破坏胰岛β细胞 | 胰岛素抵抗 + 胰岛β细胞功能缺陷 |
| 遗传因素 | HLA基因为主效基因（贡献近50%遗传易感性） | 多基因遗传，>100个易感位点，同卵双生同病率近100% |
| 环境因素 | 病毒感染（风疹、腮腺炎、柯萨奇）、化学毒物、肠道菌群 | 年龄、营养过剩、体力活动不足、肥胖（中心性肥胖） |
| 自身免疫 | 90%患者存在胰岛β细胞自身抗体（ICA、IAA、GAD65、IA-2A、ZnT8A） | 免疫失衡及慢性低度炎症 |
| 胰高血糖素 | — | 分泌增多（α/β细胞比例增加、GLP-1下降） |
| 自然史 | 遗传易感→环境触发→胰岛炎→β细胞破坏→胰岛素缺乏→需外源性胰岛素 | 胰岛素抵抗→代偿→失代偿→IGR→T2DM→部分需胰岛素 |

## 临床表现

### 典型"三多一少"

| 症状 | 机制 |
|------|------|
| **多尿** | 渗透性利尿 |
| **多饮** | 多尿→脱水→口渴 |
| **多食** | 组织不能利用葡萄糖→饥饿 |
| **体重减轻** | 脂肪分解增多、蛋白质负平衡 |

可有皮肤瘙痒（尤其外阴）、视物模糊（晶状体渗透压改变）。

### T1DM vs T2DM 临床特点

| 特征 | T1DM | T2DM |
|------|------|------|
| 起病年龄 | 多青少年 | 多>40岁 |
| 起病 | 较急 | 隐匿 |
| 三多一少 | 典型、明显 | 轻或无症状 |
| DKA倾向 | 有自发倾向 | 应激时发生 |
| 家族史 | 少见 | 常见 |
| 胰岛自身抗体 | 70%~90%阳性 | 阴性 |
| 胰岛素治疗 | 终身依赖 | 部分需要 |
| 肥胖 | 多消瘦 | 多超重/肥胖 |

## 诊断标准

| 诊断标准（满足其一） | 静脉血浆葡萄糖/HbA1c水平 |
|---------------------|--------------------------|
| 典型糖尿病症状 + 随机血糖 | ≥11.1mmol/L |
| 或 + 空腹血糖（FPG） | ≥7.0mmol/L |
| 或 + OGTT 2h血糖 | ≥11.1mmol/L |
| 或 + HbA1c | ≥6.5% |

无典型症状者须改日复查确认。空腹指至少8小时内无热量摄入。

### 糖代谢状态分类

| 状态 | FPG（mmol/L） | 2hPG（mmol/L） |
|------|-------------|--------------|
| 正常血糖 | <6.1 | <7.8 |
| 空腹血糖受损（IFG） | 6.1~<7.0 | <7.8 |
| 糖耐量减低（IGT） | <7.0 | 7.8~<11.1 |
| **糖尿病** | ≥7.0 | ≥11.1 |

IFG和IGT合称"糖尿病前期"。

## 并发症

### 急性代谢紊乱

| 类型 | DKA | HHS |
|------|-----|-----|
| **血糖** | 11.1~33.3mmol/L | ≥33.3mmol/L |
| **酮体** | 阳性++以上 | 阴性或弱阳性 |
| **酸中毒** | 有（pH<7.3） | 一般无 |
| **渗透压** | 轻度升高 | ≥320mOsm/kg |
| **失水** | 达体重10% | 达体重10%~15% |
| **病死率** | 低于HHS | 高于DKA |

### 慢性并发症

| 类别 | 表现 |
|------|------|
| **微血管病变**（特异性） | **糖尿病肾脏病（DKD）**：持续性蛋白尿+GFR进行性下降，DKD是ESRD主要原因；**糖尿病视网膜病变（DR）**：NPDR（I~III期）→PDR（IV~VI期），糖尿病失明主要原因；糖尿病心肌病 |
| **ASCVD**（大血管病变） | 冠心病、脑血管病、肾动脉硬化、肢体动脉硬化，是糖尿病患者主要死因 |
| **神经系统病变** | 远端对称性多发性神经病变（最常见，袜套样分布）；自主神经病变（胃轻瘫、直立性低血压、无症状心梗） |
| **糖尿病足** | 下肢远端神经异常+周围血管病变→足部溃疡/感染/坏疽，非创伤性截肢最主要原因 |

## 糖尿病管理

### 综合管理"五驾马车"

| 要点 | 内容 |
|------|------|
| **糖尿病教育** | 自我管理教育和支持（DSMES），是决定管理成败的关键 |
| **医学营养治疗（MNT）** | 总热量控制、合理分配营养、低GI食物、规律进餐 |
| **运动治疗** | 150分钟中等强度有氧运动/周 + 2~3次抗阻运动/周 |
| **血糖监测** | SMBG/CGM、HbA1c每3个月、TIR目标>70% |
| **药物治疗** | 口服降糖药 + GLP-1RA + 胰岛素 |

### T2DM综合控制目标

| 指标 | 目标值 |
|------|--------|
| 空腹血糖 | 4.4~7.0mmol/L |
| 非空腹血糖 | <10.0mmol/L |
| **HbA1c** | **<7.0%**（个体化：≤6.5%或≥8.0%） |
| 血压 | <130/80mmHg |
| LDL-C（未合并ASCVD） | <2.6mmol/L |
| LDL-C（合并ASCVD） | <1.8mmol/L |
| BMI | <24.0kg/m² |

### 口服降糖药分类

| 类别 | 代表药物 | 机制 | HbA1c降幅 | 特点 |
|------|----------|------|-----------|------|
| **双胍类** | **二甲双胍**（一线/基础用药） | 抑制肝糖输出、改善胰岛素敏感性 | 1%~2% | 不增加体重，eGFR<30禁用 |
| 磺酰脲类（SU） | 格列美脲、格列齐特 | 刺激胰岛β细胞分泌胰岛素 | 1%~2% | 低血糖常见，体重增加 |
| 格列奈类 | 瑞格列奈、那格列奈 | 刺激早时相胰岛素分泌 | 0.5%~1.5% | 控制餐后血糖，起效快 |
| TZD（PPARγ） | 罗格列酮、吡格列酮 | 增加靶组织对胰岛素敏感性 | 0.7%~1.0% | 体重增加+水肿，心衰禁用 |
| α-葡萄糖苷酶抑制剂 | 阿卡波糖 | 抑制小肠α-葡萄糖苷酶→延缓碳水化合物吸收 | 0.5%~0.8% | 降低餐后血糖，胃肠反应 |
| DPP-4抑制剂 | 西格列汀、沙格列汀 | 减少GLP-1失活→增加内源性GLP-1 | 0.5%~1.0% | 不增加体重，低血糖风险低 |
| **SGLT-2i** | 达格列净、恩格列净 | 抑制肾小管葡萄糖重吸收→尿糖排泄 | 0.5%~1.2% | 减重降压，心肾保护 |
| GKA | 多格列艾汀 | 激活葡萄糖激酶 | ~1% | |

### 胰岛素适应证

| 适应证 |
|--------|
| T1DM（终身替代治疗） |
| 各种严重的糖尿病急/慢性并发症 |
| 手术、妊娠和分娩 |
| 新诊断T2DM伴明显高血糖（HbA1c≥9.0%或FPG≥11.1） |
| T2DM胰岛β细胞功能明显减退 |
| 无明显诱因体重显著下降 |

### 胰岛素制剂分类

| 类别 | 代表药物 | 起效 | 持续时间 |
|------|----------|------|----------|
| 速效类似物 | 门冬胰岛素、赖脯胰岛素 | 10~15min | 3~5h |
| 短效 | 正规胰岛素（RI） | 15~60min | 5~8h |
| 中效 | NPH | 2.5~3h | 13~16h |
| 长效类似物 | 甘精胰岛素、德谷胰岛素 | 1~3h | 24~42h |
| 预混 | 门冬胰岛素30 | 10~20min | 14~24h |

## DKA的治疗

| 要点 | 方案 |
|------|------|
| **补液** | 关键环节。"先快后慢，先盐后糖"。首1~2h输入NS 1000~2000ml。血糖降至13.9时改用含糖液体 |
| **胰岛素** | 小剂量短效胰岛素持续静滴，0.1U/(kg·h)；血糖下降2.8~4.2mmol/(L·h) |
| **补钾** | 至关重要！血钾<3.3优先补钾再开始胰岛素；治疗期间持续监测血钾和尿量 |
| **补碱** | 一般不补碱；pH≤6.9时用1.25%~1.4%等渗NaHCO₃缓慢输注 |
| **处理诱因和并发症** | 防治休克、严重感染、心衰、肾衰竭、脑水肿、低血糖 |
