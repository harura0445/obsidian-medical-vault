# 消化道平滑肌的生理特性
## 一般生理特性
1. *excitability*：较低，收缩较缓慢
2. *extensibility*
3. *tonus*
4. *auto rhythmicity*：慢，不如心肌规则
5. 对不同刺激有不同的敏感性：对**机械牵拉、温度和化学性刺激** 敏感；对针刺、刀割和电刺激相对不敏感
## 电生理特性
1. *resting membrane potential, RMP*
	**–60 ~ –50 mV**，主要由EK（钾离子平衡电位）形成
2. **慢波 *slow wave, SW*  / 基本电节律 *basic electric rhythm, BER***
	**RP基础上的自动节律性低频低幅去极化波**<br>幅度：5-15mV，持续时间：数秒-数十秒<br>起源：**[[cajal间质细胞]]** *interstitial Cajal cell, ICC*<br>机制：anoctamin-1（ANO1）蛋白：**钙激活的氯离子通道（CaCC）**![[生理学 概述.pdf#page=8&rect=191,6,751,418|生理学 概述, p.8]]
3. *AP*
	在慢波基础上触发<br>主要**由Ca2+内流引起：L型钙离子通道，钙-钠通道**
4. 慢波、动作电位与收缩的关系
	- 机械阈或收缩阈 (mechanical or contraction threshold) 达此阈 → Ca2+↑ → 收缩 (不需通过产生AP)
	- 电阈或兴奋阈 (electrical or excitatory threshold ) 达此阈 → AP → Ca2+i↑↑ → 收缩↑↑
