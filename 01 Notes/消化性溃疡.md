# 消化性溃疡

> 消化性溃疡（peptic ulcer，PU）指胃、十二指肠黏膜发生的炎性缺损，与胃酸和胃蛋白酶的消化作用有关，病变穿透黏膜肌层或达更深层次。

## 概述

PU 是全球性常见病，男性多于女性，约有 10% 的人一生中患过本病。[[十二指肠溃疡]]（DU）多于胃溃疡（GU），DU 多见于青壮年，GU 多见于中老年。近年随着 PPI 等抑酸药物应用，PU 发病率下降，但老年 NSAIDs 相关溃疡有所增多。

## 病因与危险因素

PU 的发病是**侵袭因素**与**防御因素**失衡的结果。

| 分类 | 因素 | 机制 |
|------|------|------|
| 侵袭因素 | 胃酸与胃蛋白酶 | 胃蛋白酶活性依赖 pH（pH 2~3 激活，pH>4 失活）；抑酸可同时降低胃蛋白酶活性 |
| 侵袭因素 | [[幽门螺杆菌]]（Hp）感染 | DU 感染率 >90%，GU 60%~90%；根除 Hp 可显著降低复发率 |
| 侵袭因素 | NSAIDs | 阿司匹林、布洛芬、吲哚美辛等长期服用；糖皮质激素、氯吡格雷等也相关 |
| 侵袭因素 | 其他诱因 | 大量饮酒、长期吸烟、应激、胃石症、放疗 |
| 防御因素 | 黏膜防御与修复异常 | 胃黏膜屏障功能受损、修复能力下降 |
| 宿主因素 | 遗传易感性 | 部分病人有家族史 |

## 病理

| 特征 | GU | DU |
|------|-----|-----|
| 好发部位 | 胃角附近及胃窦小弯侧 | 十二指肠球部（前壁或后壁） |
| 大小 | 多数 <10mm | 多数 <10mm |
| 形态 | 圆形或卵圆形，边缘规整 | 同 GU，反复发作可致球部变形 |
| 底部 | 肉芽组织构成 | 同 |
| 深度 | 可累及肌层或浆膜层 | 同 |

镜下由内向外四层结构：**渗出层**（纤维蛋白+中性粒细胞）→ **坏死层** → **肉芽组织层** → **瘢痕层**。

## 临床表现

### 典型症状

| 特点 | 说明 |
|------|------|
| 慢性过程 | 可达 10 余年或更长 |
| 周期性发作 | 发作期数周或数月，秋冬和冬春之交多发 |
| 节律性上腹痛 | **GU**：餐后痛（餐后 0.5~1h）；**DU**：饥饿痛/夜间痛，进餐缓解 |
| 可被抑酸剂缓解 | 抑酸或抗酸药可缓解疼痛 |

疼痛性质：钝痛、隐痛、灼痛、胀痛、剧痛或饥饿样不适。

### 特殊类型溃疡

| 类型 | 特点 |
|------|------|
| 复合溃疡 | 胃和十二指肠均有活动性溃疡，幽门梗阻发生率高 |
| 幽门管溃疡 | 餐后很快疼痛，易出现幽门梗阻、出血、穿孔 |
| 球后溃疡 | 十二指肠降段/水平段，疼痛可向右上腹及背部放射 |
| 巨大溃疡 | 直径 >2cm，常见于 NSAIDs 服用史及老年病人 |
| 老年人溃疡 | 症状多不典型，可无症状，表现为体重减轻和贫血 |
| 难治性溃疡 | 正规治疗仍未愈合，需排查 Hp 未除、特殊病因等 |

## 并发症

| 并发症 | 发生率 | 临床特点 |
|--------|--------|----------|
| **出血** | 15%~25%（最常见） | 轻者黑便/隐血阳性，重者呕血/暗红血便；DU 较 GU 多见 |
| **穿孔** | ~5% | 三种后果：①游离穿孔→弥漫性腹膜炎（突发剧痛、板状腹）；②穿透性溃疡（穿透至胰腺等）；③瘘管形成 |
| **幽门梗阻** | 2%~3% | 上腹胀痛餐后加重，呕吐宿食，振水声 |
| **癌变** | <1% | GU 可癌变（反复发作、病程长者风险高），DU 一般不癌变 |

## 辅助检查

### 上消化道内镜检查（首选 + 金标准）

- 确定病变有无、部位及分期
- 鉴别良恶性溃疡（GU 应常规取活检）
- 评价治疗效果
- 合并出血者可行止血治疗

### Hp 检测

| 方法 | 说明 |
|------|------|
| 快速尿素酶试验 | 内镜下取活检，侵入性 |
| 组织学染色 | 活检标本 |
| 细菌培养 | 药敏指导 |
| ^13^C/^14^C 尿素呼气试验 | 非侵入性，检测 Hp 的金标准之一 |
| 粪便 Hp 抗原检测 | 非侵入性 |
| 血清 Hp 抗体检测 | 不能区分现症感染与既往感染 |

有 PU 病史者，无论溃疡处于活动还是瘢痕期，均应检测 Hp。

### 其他检查

| 方法 | 适用情况 |
|------|----------|
| X 线钡剂造影 | 胃镜禁忌者、了解胃运动功能；直接征象为龛影 |
| CT | 穿透性溃疡或穿孔有较高价值，对游离气体显示优于立位胸片 |
| 血常规 + 粪便隐血 | 了解有无活动性出血 |

## 诊断与鉴别诊断

### 诊断

慢性病程 + 周期性发作 + 节律性上腹痛 + NSAIDs 服药史 → 疑诊 PU → 上消化道内镜确诊。

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| [[胃癌]] | 溃疡形态多不规则，常 >2cm，边缘不规则，底部凹凸不平、覆污秽苔；活检确诊 |
| 胃泌素瘤（Zollinger-Ellison 综合征） | 多发溃疡、部位不典型、易出现并发症、正规抗溃疡药物疗效差、血胃泌素升高 |
| [[慢性胃炎]] | 内镜+活检区分，炎症为主而无明显溃疡 |
| [[急性胰腺炎]] | 上腹痛剧烈，血淀粉酶/脂肪酶升高，CT 可鉴别 |
| [[肝功能不全|慢性肝胆胰疾病]] | 需排除 |
| 功能性消化不良 | 内镜检查无溃疡 |

## 治疗

### 治疗目标

去除病因 → 控制症状 → 促进溃疡愈合 → 预防复发 → 避免并发症。

### 药物治疗

#### 1. 抑制胃酸分泌

| 药物类别 | 代表药物 | 疗程与疗效 |
|----------|----------|------------|
| **PPI**（首选） | 奥美拉唑、兰索拉唑、泮托拉唑、雷贝拉唑、埃索美拉唑、艾普拉唑 | DU 4 周，GU 6~8 周；GU 愈合率 80%~96%，DU 愈合率 90%~100%。见[[质子泵阻断药]] |
| **H2RA** | 法莫替丁、尼扎替丁、雷尼替丁 | GU/DU 6 周愈合率 80%~95%。见[[H2受体阻断药]] |
| **P-CAB** | 伏诺拉生 | 与钾离子竞争 H^+-K^+-ATP 酶，酸环境稳定，起效更快 |

> PPI 是治疗 PU 的首选药物，口服时不宜破坏肠衣保护膜。治疗 GU 时需排除溃疡型胃癌，因 PPI 可能掩盖病情。

#### 2. 根除 Hp

Hp 阳性病人均应根除 Hp。**四联方案**为目前推荐方案：
- PPI + 铋剂 + 两种抗生素（阿莫西林、克拉霉素、甲硝唑、四环素等）
- 疗程 10~14 天

根除 Hp 可显著降低溃疡复发率。

#### 3. 保护胃黏膜

| 药物 | 机制 | 备注 |
|------|------|------|
| 铋剂（枸橼酸铋钾） | 形成蛋白-铋复合物覆盖溃疡表面 | 推荐为四联方案组成之一；肾功能不良者忌用 |
| 弱碱性抗酸剂（铝碳酸镁、硫糖铝等） | 中和胃酸，短暂缓解疼痛 | 已不作为主要或单独治疗药物 |

#### 4. 维持治疗

适用于溃疡多次复发者：较长时期服用维持剂量 H2RA 或 PPI，疗程 3~6 个月至 1~2 年。

### 内镜治疗与外科手术

| 治疗方式 | 适用情况 |
|----------|----------|
| **内镜治疗** | PU 出血：喷洒蛋白胶、注射肾上腺素、热凝固、钳夹止血；幽门狭窄：气囊扩张 |
| **外科手术** | 大出血药物/内镜/介入治疗无效；急性穿孔/慢性穿透溃疡；瘢痕性幽门梗阻内镜治疗无效；GU 疑有癌变 |

### 病人教育

- 戒烟、戒酒、少饮浓茶和浓咖啡
- 停服不必要的 NSAIDs；若必须服用，餐后服用并加用胃黏膜保护药物
- 改善进食规律，减轻精神压力

## 预后

有效药物治疗使溃疡愈合率达 95% 以上，青壮年死亡率接近零，老年主要死于大出血和急性穿孔（病死率 <1%）。
