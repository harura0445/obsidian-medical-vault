# 消化性溃疡
- 由酸性胃液自身消化作用引起消化道黏膜缺损（>98%为胃或十二指肠溃疡）—慢性溃疡
- 与胃酸和胃蛋白酶的消化密切相关

## 病因和发病机制
- 胃酸和胃蛋白酶的消化侵袭作用  
- 侵害因素

1. HP感染：
	- HP产生NH4+,增强胃酸和胃蛋白酶的分泌
	- 十二指肠发生胃黏膜化生，HP克隆性生长 
2. 缺血/休克使胃黏膜血流减少 
3. 胃排空时间延迟 
4. 十二指肠-胃返流

## 病理变化
### 肉眼
-  好发部位：十二指肠球部（前>后）；胃窦部小弯侧
- 形状：圆或椭圆，以溃疡为中心，周围黏膜呈放射状边缘整齐，底部平坦，污秽（活动），干净（静止）
- 深度：溃疡深，可达黏膜下，肌层，浆膜（渗出、机化、粘连） 
- 大小：胃溃疡: 直径1~2cm；十二指肠溃疡：直径0.5-1 cm
- 数量：多单个(>80%) <br>≥2个 多发性溃疡（同一器官）<br>胃溃疡 + 十二指肠溃疡：复合性溃疡
- 切面：呈斜面漏斗状，肌层破坏；灰白色纤维瘢痕中可见僵硬的动脉贲门部呈潜掘形，幽门侧呈阶梯形

### 镜下
由内向外 **4** 层结构
- **渗出层：纤维蛋白+中性粒细胞** 
- **坏死层** 
- **肉芽组织层** 
- **瘢痕层**

## 临床病理联系
- 一般症状：泛酸，嗳气－蠕动减少
- 疼痛的原因：
	1. 胃酸刺激溃疡壁神经末梢（胃溃疡）氧化铝（[[抗酸药]]） 
	2. 运动改变或溃疡处肌张力增强（十二指肠溃疡）阿托品（[[M1胆碱受体阻断药]]）
- 诊断：内窥镜+活检

## 转归
- 愈合－肉芽组织

## 并发症
1. 出血（15% -25%）：最常见并发症[[呕血]]、[[黑便]] 
2. [[穿孔]]（5%）：死亡原因的2/3；局限性/弥漫性腹膜炎<br>游离性穿孔最危险：好发十二指肠球部前壁、胃小弯
3. 梗阻（2-3%）
4. 癌变＜1%：十二指肠溃疡几乎无癌变
