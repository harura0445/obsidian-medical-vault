# 疟原虫
- Plasmodium falciparum, Pf 恶性疟原虫
- Plasmodium vivax, Pv 间日疟原虫

|特征|**间日疟原虫**|**恶性疟原虫**|
|---|---|---|
|**被寄生红细胞**|**出现薛氏点**（Schüffner's dots），细小粉红色颗粒，遍布整个细胞浆||
|**寄生阶段**|**外周血中可见所有发育阶段**（环状体、滋养体、裂殖体）|**通常仅见环状体和配子体**；成熟滋养体和裂殖体不见于外周血|
|**环状体（早期滋养体）**|形态多变，可呈阿米巴状|形态典型，常呈“戒指”状|
||一个红细胞可有多环感染，但不常见|**常见多重感染**（一个红细胞内有2个或以上环状体）|
|**成熟裂殖体**|**较大**，几乎充满胀大的红细胞|**通常不见于外周血**|
||含有 **12-24个（通常16-18个）** 裂殖子||
||裂殖子排列不规则||
|**配子体**|**圆形或卵圆形**|**特征性的新月形或香蕉形**|
||雄配子体：较大，细胞质淡蓝色，核大疏松|雄配子体：新月形，两端较圆钝|
||雌配子体：稍小，细胞质深蓝色，核致密|雌配子体：新月形，两端较尖细|
||存在于胀大的红细胞内|
## 生活史
![[04 Attachments/06节肢动物传播的寄生虫及其感染 3.webp]]
- 人体内发育
	- 红细胞外期
		- **子孢子** *sporozoite* 侵入肝细胞
	- 红细胞内期
		- **裂殖子** *merozoite* →
		- **环状体** *ringform* → 
		- **滋养体** *Trophozoite* *amoeboid form* →
		- **裂殖体** *schizont* → 新的裂殖子
	- 配子体形成
		- **一部分裂殖子** → **直接发育为配子体**
- 蚊体内发育
	- 配子体被蚊子吸食 → 在蚊中肠释放出配子 → 受精形成合子（动合子） → 进入蚊胃壁 → 形成卵囊 → **产生子孢子** → 移行至蚊唾液腺
	- 雌配子进行染色体减数分裂
	- 雄配子分裂成4-8个细丝

+ 疟原虫**子孢子**是感染期
+ 在肝细胞内的裂体生殖称为红细胞外期
+ 红细胞内发育包括红细胞内裂体生殖期和配子体形成期，称红细胞内期
+ 间日疟原虫和卵形疟原虫的子孢子有两种遗传类型，即速发型子孢子和迟发型子孢子。迟发型子孢子进入肝细胞后形成**休眠子**，造成**复发**

## 致病
- 潜伏期：即从病原体侵入机体到出现症状的时间
- 发作：**冷（20min-1hr）、热（1-4hrs）、汗（2-3hrs）**
	- 原因：红内期裂殖体成熟，裂殖子胀破红细胞后疟原虫代谢产物残余、变性的血红蛋白和红细胞碎片进入血液，刺激MΦ产生内源性致热：作用于下丘脑体温中枢
	- 疟原虫代谢产物中引起机体发热等症状的成分称为疟疾毒素(malaria toxin)
	- 引起疟疾发作所需要的**最低原虫血症**
## 临床表现
- **周期性发作的冷、热、汗是疟疾的典型症状**
- 但也可因为是初发或重复感染或混合感染而使周期性不明显

+ **[[贫血]]**
	+ 原因：大量破坏 
	+ **脾功能亢进**
	+ 免疫反应(自身抗体和免疫复合物形成) 
	+ 骨髓抑制
+ **[[肝脾肿大]]**
	+ 疟疾患者常有脾肿大，主要是是脾充血和单核-巨噬细胞增生
	+ **热带巨脾综合症：巨脾、肝肿大、血IgM升高，抗疟药有效**
	+ 急性疟疾者常有肝肿大，边缘变钝，呈棕色或瓦灰色
+ 疟性肾病
	+ 由P.m引起多见，可致低蛋白血症、水肿、蛋白尿、高血压等肾病综合征的表现
+ 黑水热
	+ 恶性疟患者多见,病人有高热、贫血、腰痛、血红蛋白尿、衰竭

- 凶险型疟疾
	- 包括脑型疟、急性肾衰竭、呼吸窘迫综合征和严重贫血、低血糖症等。凶险型疟疾来势凶猛，若不能及时治疗，死亡率很高。多发生于流行区儿童、无免疫力的旅游者和流动人口
- 孕妇疟疾
	- 由于妊娠时孕妇的免疫力降低，在妊娠期间或原先体内带有疟原虫但不发病的隐性疟疾的孕妇，在妊娠后期、临产期、产褥期可转为显性感染，出现临床发作
- 先天性疟疾
	- 出生后4周-12周的新生儿，在没有按蚊感染或输血等情况下由母体传给新生儿的疟疾。先天性疟疾系因胎盘受损或在分娩过程中母体血污染胎儿伤口所致的产道感染引起的，胎儿出生后即见贫血、脾肿大， 血中可查见疟原虫
- 婴幼儿疟疾
	- 起病较慢，患儿精神迟钝或不安，厌食，呕吐，腹痛伴腹胀或腹泻，无典型疟疾症状，热型不规则 ，仅畏寒而无寒战，热退后 50%不出汗，高热伴抽搐。贫血发展快，脾脏肿大， 可有肺部炎症。出生一个月后多见，死亡率高
