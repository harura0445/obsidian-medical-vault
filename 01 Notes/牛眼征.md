# 牛眼征

> 参见：[[转移性肝癌]] | [[肝脏疾病]] | [[影像学诊断]]

## 概述

**牛眼征**（Bull's Eye Sign / Target Sign）是[[转移性肝癌]]在影像学上的特征性表现，因病灶呈**三层同心圆样结构**、形似牛眼或靶心而得名。该征象在超声和增强 CT 上均可见到。

## 影像学表现

### 超声

- 中心：**高回声**——肿瘤组织
- 中层：**低回声环**（"晕圈"）——肿瘤周围水肿或坏死区
- 外层：**高回声**——肿瘤压迫周围肝组织形成的炎性反应带

### 增强 CT

- 动脉期：病灶边缘环状强化
- 门脉期/延迟期：中心呈低密度，周边环状强化持续，形成"靶心"外观

## 病理基础

转移性肝癌的病理特点决定了牛眼征的形态：

| 层次 | 病理基础 |
|------|----------|
| 中心区 | 肿瘤细胞团，血供相对丰富 |
| 中层低密度/低回声区 | 肿瘤细胞坏死、液化，或肿瘤周围水肿带 |
| 外层高密度/高回声区 | 肿瘤压迫周围肝实质引起的炎性反应和纤维组织增生，形成假包膜 |

## 临床意义

牛眼征是**鉴别肝脏占位性质**的重要影像学依据：

| 病变类型 | 影像学特征 |
|----------|------------|
| **转移性肝癌** | **牛眼征**、多发、边界清晰 |
| **肝细胞癌（HCC）** | 快进快出（动脉期强化→门脉期/延迟期廓清） |
| **肝内胆管癌（ICC）** | 慢进慢出、无包膜、周边胆管扩张 |
| **肝海绵状血管瘤** | 周边结节状渐进性强化 |
| **肝脓肿** | 环形强化、壁厚、中央液化坏死 |

## 常见原发肿瘤

肝脏是最常见的血行转移器官。表现为牛眼征的转移性肝癌，其原发肿瘤以以下途径转移：

| 转移途径 | 常见原发肿瘤 |
|----------|--------------|
| **门静脉**（最常见） | 结直肠癌（57%）、胃癌、胰腺癌 |
| **肝动脉** | 肺癌、乳腺癌、肾癌 |
| **淋巴管** | 胆囊癌等 |
| **直接蔓延** | 胃癌、胆囊癌等 |

## 诊断价值

- 牛眼征对转移性肝癌具有**较高的提示价值**，但并非绝对特异性
- 需结合**病史**（原发肿瘤史）、**肿瘤标志物**（CEA、CA19-9、CA125 升高，AFP 不高）及**影像学复查**综合判断
- 怀疑转移性肝癌时，应寻找原发肿瘤病灶
