# 自然流产

## 概述

胚胎或胎儿尚未具有生存能力而自发性丢失者，称为自然流产。我国定义为妊娠未达到28周、胎儿体重不足1000g而终止者。自然流产约占所有妊娠的15%～25%，其中80%为早期流产（妊娠12周前）。

- 发生在妊娠12周前者为**早期流产**
- 发生在妊娠12周或之后者为**晚期流产**
- 约2/3发生在月经期前，称为**生化妊娠**

## 病因

1. **胚胎因素**：胚胎染色体异常是早期流产最常见原因，占50%～60%，以三体最多见（13、16、18、21、22-三体），其次为X单体
2. **母体因素**：
   - 全身性疾病（严重感染、高热、严重贫血、心衰、血栓性疾病等）
   - 生殖器异常（子宫畸形、子宫肌瘤、宫腔粘连、**宫颈机能不全**——晚期流产常见原因）
   - 内分泌异常（黄体功能不全、甲减/甲亢、糖尿病血糖控制不佳等）
   - 强烈应激与不良习惯
   - 免疫功能异常（抗磷脂综合征、SLE等自身免疫病）
   - 血栓前状态（易栓症）
3. **父亲因素**：精子染色体异常
4. **环境因素**：放射线、砷、铅、甲醛等化学物质

## 临床类型与表现

按自然流产发展的不同阶段分型：

| 类型 | 出血量 | 下腹痛 | 组织排出 | 宫颈口 | 子宫大小 |
|------|--------|--------|----------|--------|---------|
| **先兆流产** | 少 | 无或轻 | 无 | 闭 | 与孕周相符 |
| **难免流产** | 中→多 | 加剧 | 无 | 扩张 | 相符或略小 |
| **不全流产** | 少→多 | 减轻 | 部分排出 | 扩张/有组织物堵塞 | 小于孕周 |
| **完全流产** | 少→无 | 无 | 全部排出 | 闭 | 正常或略大 |

### 特殊类型

| 类型 | 特点 |
|------|------|
| **稽留流产** | 胚胎/胎儿死亡后滞留宫腔未排出；子宫缩小，胎动消失；可致凝血功能障碍（DIC） |
| **复发性流产（RSA）** | 同一性伴侣连续≥2次自然流产。早期RSA常见原因为胚胎染色体异常、免疫异常、黄体功能不全；晚期RSA常见原因为子宫解剖异常、自身免疫异常、血栓前状态 |
| **流产合并感染** | 阴道流血时间长+组织残留→宫腔感染，常为厌氧菌+需氧菌混合感染 |

## 临床表现

- **早期流产**：先有阴道流血，后出现阵发性下腹痛，妊娠物排出后出血停止
- **晚期流产**：临床过程与早产相似，先有腹痛，后排出胎儿胎盘

## 辅助检查

- **超声检查**：确定孕囊位置、形态及胎心搏动，是判断妊娠预后的关键
- **血hCG测定**：动态测定可判断妊娠转归
- 孕酮测定：波动大，临床指导意义有限

## 处理

| 类型 | 处理 |
|------|------|
| **先兆流产** | 适当休息、禁性生活；黄体功能不全者补充孕激素；甲减者补充甲状腺素 |
| **难免流产** | 尽早行清宫术；晚期流产可用宫缩剂促进子宫收缩 |
| **不全流产** | 尽快行刮宫术/钳刮术；大出血休克者同时输血输液+抗菌药物 |
| **完全流产** | 超声证实无残留妊娠物，无感染征象则无须处理 |
| **稽留流产** | 处理前查凝血功能；妊娠≤12周可选手术/药物/期待治疗；妊娠＞12周选药物或手术（钳刮术）；凝血功能障碍者纠正后方可刮宫 |
| **复发性流产** | 针对病因治疗：染色体异常→遗传咨询；子宫畸形→宫腔镜手术；宫颈机能不全→宫颈环扎术；自身免疫病→与风湿免疫科共管 |
| **流产合并感染** | 控制感染+清除宫内残留物；出血不多→先用抗菌药物2～3日再刮宫；出血多→抗感染同时用卵圆钳夹出大块组织，**禁用刮匙全面搔刮** |
