# 休克

> 机体有效循环血容量减少、组织灌注不足，导致细胞代谢紊乱和功能受损的病理生理过程，本质是组织氧供需失衡。

## 概述

休克的核心是**组织氧供给不足和需求增加**，产生炎症介质是其特征。恢复组织供氧、重建氧供需平衡、维护正常细胞功能是治疗的关键。

## 分类

| 类型 | 机制 | 常见原因 |
|------|------|----------|
| **低血容量性** | 血容量绝对减少 | 大出血（失血性）、严重脱水、烧伤、创伤 |
| **感染性** | 血管扩张+毛细血管渗漏 | 严重感染（革兰阴性/阳性菌） |
| **心源性** | 心泵功能衰竭 | 心肌梗死、心肌病、心律失常 |
| **神经性** | 交感神经活性丧失 | 脊髓损伤、严重疼痛 |
| **过敏性** | 组胺大量释放 | 药物/食物过敏、蜂蜇 |

**低血容量性和感染性休克在外科最常见。**

## 病理生理

### 微循环变化（三期）

| 分期 | 微循环特征 | 机制 | 可逆性 |
|------|-----------|------|--------|
| **微循环收缩期**（代偿期） | "只出不进" | 儿茶酚胺致毛细血管前括约肌收缩，动静脉短路开放，保证心脑灌注 | **可逆** |
| **微循环扩张期**（失代偿期） | "只进不出" | 无氧代谢→酸中毒→前括约肌舒张、后括约肌仍收缩→血液淤滞→血浆外渗 | 可逆 |
| **微循环衰竭期**（不可逆期） | 微血栓形成 | 血液高凝→DIC→细胞自溶→多器官功能衰竭 | **不可逆** |

### 代谢改变

| 变化 | 机制 | 后果 |
|------|------|------|
| **代谢性酸中毒** | 无氧糖酵解→乳酸堆积 | pH＜7.2时心血管对儿茶酚胺反应↓ |
| 能量代谢障碍 | 应激→蛋白分解、糖异生增加 | 酶蛋白消耗→MODS |
| 脂肪分解增强 | 应激反应 | 成为主要能量来源 |

### 炎症介质与缺血再灌注损伤

过量炎症介质（IL、TNF、NO等）形成"瀑布样"反应 → 中性粒细胞激活 → 活性氧损伤 → 与**MODS**相关。

### 内脏器官继发性损害

| 器官 | 损害机制 | 后果 |
|------|----------|------|
| **肺** | 毛细血管内皮受损、表面活性物质减少 | **ARDS**（48~72h内发生） |
| **肾** | 入球血管痉挛、肾血流重分布 | **急性肾衰竭** |
| **脑** | 灌注压↓、脑细胞肿胀 | 脑水肿、颅内压增高、脑疝 |
| **心** | 冠脉血流↓、微循环血栓 | 心肌缺血/坏死 |
| **胃肠道** | 肠系膜血流减少70%、黏膜缺血 | **细菌/内毒素移位** → 肠源性感染 |
| **肝** | 缺血缺氧+内毒素 | 代谢解毒功能↓、内毒素血症 |

## 临床表现

### 休克代偿期（早期）

| 项目 | 表现 |
|------|------|
| 神志 | 清楚，精神紧张、兴奋或烦躁 |
| 皮肤 | 苍白、四肢厥冷 |
| 脉搏 | 加快，＜100次/分 |
| 血压 | 收缩压正常或稍升，舒张压增高，**脉压缩小** |
| 尿量 | 正常或减少 |

### 休克失代偿期

| 程度 | 神志 | 皮肤 | 脉搏 | 血压 | 尿量 | 失血量 |
|------|------|------|------|------|------|--------|
| **中度** | 尚清楚、表情淡漠 | 苍白、发冷 | 100~120次/分 | 收缩压70~90mmHg | 少尿 | 20%~40% |
| **重度** | 意识模糊、昏迷 | 显著苍白、肢端青紫、厥冷 | 细弱、摸不清 | 收缩压＜70mmHg | 无尿 | ＞40% |

## 监测

### 一般监测

| 指标 | 意义 |
|------|------|
| **精神状态** | 反映脑灌注 |
| 皮肤温度/色泽 | 反映体表灌注 |
| **血压** | 收缩压＜90mmHg、脉压＜20mmHg提示休克 |
| **脉率** | 休克早期脉率变化在血压变化之前 |
| **尿量** | 反映肾灌注，＜25ml/h提示灌注不足，＞30ml/h提示好转 |

### 特殊监测

| 指标 | 正常值 | 临床意义 |
|------|--------|----------|
| **CVP**（中心静脉压） | 5~10cmH₂O | ＜5：血容量不足；＞15：心功能不全；＞20：充血性心衰 |
| **动脉血乳酸** | ＜2mmol/L | 持续高乳酸提示死亡风险增加 |
| 动脉血气 | PaO₂ 80~100mmHg | 评估氧合和酸碱状态 |
| PiCCO | — | 连续心排血量、胸内血容量、血管外肺水监测 |

### CVP与补液的关系

| CVP | 血压 | 原因 | 处理 |
|-----|------|------|------|
| 低 | 低 | 血容量严重不足 | 充分补液 |
| 低 | 正常 | 血容量不足 | 适当补液 |
| 高 | 低 | 心功能不全/容量过多 | 强心+扩张血管 |
| 高 | 正常 | 容量血管过度收缩 | 扩张血管 |
| 正常 | 低 | 心功能不全或容量不足 | **补液试验** |

## 治疗

### 紧急治疗

- 积极处理原发伤病（创伤制动、大出血止血、保证呼吸道通畅）
- 体位：**头/躯干抬高20°~30°，下肢抬高15°~20°**（增加回心血量）
- 及早建立静脉通路
- 早期吸氧，保持体温

### 补充血容量（关键）

- **晶体液**仍为容量复苏第一线选择
- 大量液体复苏时可联合胶体液
- 争取在**诊断后第1小时**积极输液复苏，达到早期达标治疗（EGDT）
- 根据CVP和血压指导补液

### 积极处理原发病

外科疾病引起的休克，应在恢复有效循环血量后及时手术（如内脏出血、消化道穿孔、坏死肠袢等），必要时**边抗休克边手术**。

### 纠正酸碱平衡失调

- 原则：**宁酸毋碱**
- 根本措施是改善组织灌注
- 使用碱性药物须保证呼吸功能完整

### 血管活性药物

| 类别 | 药物 | 作用 |
|------|------|------|
| **血管收缩剂** | 多巴胺（小剂量） | 强心+扩张内脏血管 |
| | 去甲肾上腺素 | 兴奋α受体，收缩血管升血压 |
| | 间羟胺 | 作用类似去甲肾上腺素但较弱 |
| **血管扩张剂** | 酚妥拉明 | α受体阻断 |
| | 山莨菪碱/阿托品 | 抗胆碱，用于感染性休克 |
| **强心药** | 多巴酚丁胺 | 增强心肌收缩力 |

- 感染性休克：去甲肾上腺素 + 多巴酚丁胺为最理想组合
- 休克早期：用血管扩张剂配合扩容
- 扩容未完成需要时可短暂使用血管收缩剂

### 治疗DIC

诊断明确的DIC：肝素抗凝，可联合抗纤溶药及抗血小板药。

### 糖皮质激素

用于感染性休克和其他严重休克，主张**早期、大剂量、短期**（不超过48小时）。
