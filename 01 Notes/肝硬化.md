# 肝硬化

> 肝硬化（liver cirrhosis）是各种慢性肝病进展至以**肝脏慢性炎症、弥漫性纤维化、假小叶、再生结节和肝内外血管增殖**为特征的病理阶段，代偿期无明显症状，失代偿期以**门静脉高压**和**肝功能减退**为临床特征。

## 概述

肝硬化是消化系统常见慢性病。我国目前仍以[[病毒性肝炎|乙型肝炎病毒（HBV）]]为主要病因；欧美国家以酒精及丙型肝炎病毒（HCV）为多见病因。代偿期中位生存时间 12 年以上，进入失代偿期后降至约 2~4 年，因并发食管胃底静脉曲张出血、[[肝性脑病]]、感染、[[肝肾综合征]]和门静脉血栓等多器官功能慢性衰竭而死亡。

## 病因

| 病因类别 | 具体原因 |
|----------|----------|
| **病毒性肝炎** | HBV（我国首位）、HCV、HDV |
| **酒精** | 欧美国家多见病因，长期大量饮酒 |
| **脂肪性肝病** | [[非酒精性肝病|非酒精性脂肪性肝病]]、[[酒精性肝病]] |
| **胆汁淤积** | 原发性胆汁性肝硬化、继发性胆汁性肝硬化（肝内外胆道梗阻） |
| **循环障碍** | 布-加综合征（肝静脉/下腔静脉阻塞）、慢性心功能不全（心源性肝硬化） |
| **药物或化学毒物** | [[药物性肝损伤]]、工业毒物 |
| **免疫疾病** | [[自身免疫性肝病]] |
| **寄生虫感染** | 血吸虫病（门静脉高压突出）、华支睾吸虫 |
| **遗传代谢性疾病** | [[肝豆状核变性]]（Wilson 病）、原发性血色病、α1-抗胰蛋白酶缺乏症 |
| **原因不明** | 隐源性肝硬化（诊断需谨慎） |

## 发病机制及病理

### 发病过程

各种致病因素 → **慢性炎症** → 激活[[肝星形细胞]] → 增殖和移行 → **胶原合成增加、降解减少** → 沉积于窦周隙（Disse 间隙） → **肝纤维化**

纤维束向肝小叶中央静脉延伸扩展 → 纤维间隔包绕再生结节 → 将肝小叶重新分割改建 → **假小叶形成**（典型组织病理特点）

### 肝细胞消亡方式

| 方式 | 说明 |
|------|------|
| 变性、坏死 | 最常见的损伤结局 |
| 变性、凋亡 | 程序性死亡 |
| 上皮间质转化（EMT） | 肝细胞丧失上皮特征，转化为间质细胞，促进肝纤维化 |

### 肝窦毛细血管化

肝内血管增殖使肝窦内皮细胞窗孔变小、数量减少、间隙消失、基底膜形成，导致：
- 肝窦狭窄、血流受阻 → 肝细胞缺氧、养料供给障碍
- 肝内血管阻力增加 → **门静脉压力升高**
- 血管内皮生长因子正反馈 → 肝内外血管进一步增殖

### 肝内外血管增殖的后果

| 后果 | 机制 |
|------|------|
| 肝内门静脉/肝静脉/肝动脉交通吻合支形成 | 三个血管系正常关系丧失 |
| 肝外血管增殖、门静脉属支血容量增加 | 加重门静脉高压 |
| [[食管胃底静脉曲张]]（EGV） | 胃冠状静脉与食管静脉、奇静脉吻合 |
| 脾大 | 脾静脉回流阻力增加 + 抗原刺激增生 |
| 门静脉高压性胃肠病 | 门静脉属支血管增殖、毛细血管扩张 |

## 临床表现

### 代偿期

- 大部分病人无症状或症状较轻
- 可有腹部不适、乏力、食欲减退、消化不良、腹泻（间歇性）
- 营养状态尚可，脾脏常轻中度肿大，肝功能正常或轻度异常

### 失代偿期

#### 肝功能减退

| 表现 | 机制 |
|------|------|
| **消化吸收不良** | 胃肠道淤血水肿、消化吸收障碍、肠道菌群失调 |
| **营养不良与肌少症** | 消瘦、乏力，皮肤干枯或水肿 |
| **黄疸** | 肝细胞性黄疸，肝衰竭时持续加重 |
| **出血和贫血** | 肝合成凝血因子减少 + 脾功能亢进 + 毛细血管脆性增加 → 鼻出血、牙龈出血、皮肤瘀斑、消化道出血 |
| **内分泌失调** | 见下表 |
| **不规则低热** | 致热因子灭活降低 / 继发感染 |
| **低白蛋白血症** | 下肢水肿及腹腔积液 |

**内分泌失调的表现**：

| 激素变化 | 表现 |
|----------|------|
| **雌激素增多**/雄激素减少 | 男性：性欲减退、睾丸萎缩、毛发脱落、乳房发育；女性：月经失调、闭经、不孕 |
| 蜘蛛痣、肝掌 | 雌激素增多，皮肤小动脉末端分支性扩张 |
| 肾上腺皮质功能减退 | 促黑素细胞激素增加 → **肝病面容**（面色黑黄、晦暗无光） |
| 抗利尿激素增多 | 促进腹腔积液形成 |
| 甲状腺激素异常 | T3 降低，与肝病严重程度相关 |

#### 门静脉高压

多属肝内型，是继病因之后推动肝功能减退的重要病理生理环节，是肝硬化的**主要死因之一**。

| 表现 | 说明 |
|------|------|
| **门腔侧支循环形成** | EGV、腹壁静脉曲张、痔静脉曲张、Retzius 静脉曲张、脾肾分流 |
| **脾功能亢进及脾大** | 较早出现的体征；外周血小板及白细胞减少 |
| **腹腔积液** | 肝功能减退 + 门静脉高压的共同结果，失代偿期突出的临床表现 |

**腹腔积液形成机制**：

| 因素 | 机制 |
|------|------|
| 门静脉高压 | 腹腔内脏血管床静水压增高 → 组织液漏入腹腔（**决定性因素**） |
| 低白蛋白血症（<30g/L） | 血浆胶体渗透压降低 |
| 有效循环血容量不足 | 肾素-血管紧张素系统激活 → 水钠潴留 |
| 继发性醛固酮/ADH 增多 | 钠水重吸收增加 |
| 肝淋巴生成增多 | 超过淋巴循环引流能力 → 自肝包膜漏入腹腔 |

## 并发症

| 并发症 | 临床要点 |
|--------|----------|
| **食管胃底静脉曲张出血（EGVB）** | 突发大量呕血或柏油样便，死亡率高，是**最常见并发症** |
| **[[肝性脑病]]（HE）** | 以代谢紊乱为基础的中枢神经系统功能失调综合征，分 0~4 期，详见[[肝性脑病]] |
| **自发性细菌性腹膜炎（SBP）** | 非腹腔内脏器感染引发的急性细菌性腹膜炎，致病菌多为革兰氏阴性杆菌 |
| **[[肝肾综合征]]（HRS）** | 肾脏无实质性病变，因严重门静脉高压导致肾皮质灌注不足；急进型 2 周内死亡 |
| **原发性肝癌** | 见[[原发性肝癌]] |
| **门静脉血栓/海绵样变** | 门静脉血流淤滞所致，可加速肝衰竭 |
| **胆石症** | 患病率约 30% |
| **肝肺综合征** | 肺内血管扩张和动脉血氧合障碍，预后差 |
| **电解质和酸碱平衡紊乱** | 低钾低氯性碱中毒易诱发 HE；重度低钠（<125mmol/L）易引起 HRS |

### 肝性脑病分期

| 分期 | 名称 | 表现 |
|------|------|------|
| 0 期 | 潜伏期 | 无行为性格异常，仅心理/智力测试轻微异常 |
| 1 期 | 前驱期 | 轻度性格改变，欣快/激动/淡漠，可有扑翼样震颤 |
| 2 期 | 昏迷前期 | 嗜睡，行为异常，腱反射亢进，扑翼样震颤，脑电图异常 |
| 3 期 | 昏睡期 | 昏睡但可唤醒，神志不清或幻觉，各种神经体征持续 |
| 4 期 | 昏迷期 | 昏迷无法唤醒，各种反射消失 |

## 辅助检查及诊断

### 确定有无肝硬化

| 方法 | 表现 |
|------|------|
| **影像学** | 肝轮廓波浪样改变、肝叶萎缩、超声回声增强不均、结节样改变 |
| **肝功能减退证据** | 临床表现 + 实验室（转氨酶、胆红素、白蛋白、凝血功能） |
| **门静脉高压证据** | 侧支循环形成 + 脾大 + 腹腔积液 |
| **肝组织病理** | **假小叶形成可确诊**（影像学不明确时） |

### 门静脉高压检测

| 指标 | 标准 |
|------|------|
| 腹部超声 | 门静脉主干内径 >13mm，脾静脉内径 >8mm |
| 腹腔积液分析 | 无感染时为漏出液；SAAG ≥11g/L 提示门静脉高压性 |
| 腹部增强 CT + 门静脉成像 | 全面评估门静脉属支形态、血栓、海绵样变 |

### 评估

- **寻找病因**：病毒学、自身抗体、铁/铜代谢等
- **肝功能评估**：Child-Pugh 分级（见[[肝功能分级]]）
- **肝硬化分期**：见下表

### 肝硬化分期

| 分期 | EGV | 腹腔积液 | 临床并发症 |
|------|-----|----------|------------|
| **代偿期** | | | |
| 1 期 | 无 | 无 | 无 |
| 2 期 | 有 | 无 | 无 |
| **失代偿期** | | | |
| 3 期 | 有/无 | 有 | 无 |
| 4 期 | 有 | 有/无 | EGVB、感染、HE、HRS 等 |

**再代偿**：有效控制和去除病因、降低门静脉压力及改善肝脏免疫微环境后，符合以下条件并稳定 ≥12 个月：①不依赖利尿剂的腹腔积液消退；②无 EGVB 复发；③不依赖乳果糖/利福昔明的 HE 缓解；④白蛋白和胆红素持续稳定。

## 治疗

### 治疗目标

| 分期 | 目标 |
|------|------|
| 代偿期 | 延缓肝功能失代偿、预防肝细胞肝癌、争取逆转病变 |
| 失代偿期 | 改善肝功能、治疗并发症、延缓或减少对肝移植的需求 |

### （一）保护或改善肝功能

| 措施 | 说明 |
|------|------|
| **去除或减轻病因** | 抗肝炎病毒治疗（HBV/HCV）及其他对因治疗 |
| **慎用损肝药** | 避免不必要、疗效不明确的药物 |
| **维护肠内营养** | 以碳水化合物为主，蛋白质摄入以病人可耐受为宜；肝衰竭或 HE 先兆时减少蛋白摄入 |
| **保护肝细胞** | 熊去氧胆酸（胆汁淤积时）、腺苷蛋氨酸等 |

### （二）门静脉高压症状及其并发症治疗

#### 1. 腹腔积液

| 措施 | 说明 |
|------|------|
| 限制钠水摄入 | 氯化钠 <2.0g/d，入水量 <1000ml/d（低钠血症时 <500ml） |
| 利尿 | 螺内酯 + 呋塞米，比例约 100:40，从 60mg/d+20mg/d 开始递增 |
| **TIPS** | 肝静脉与门静脉间建立分流道，降低门静脉压力；可长期维持疗效 |
| 排放腹腔积液 + 输注白蛋白 | 姑息治疗，每放 1000ml 输注白蛋白 8g |
| SBP 抗感染 | 首选第三代头孢类抗生素，疗程 ≥2 周 |

#### 2. EGVB 的治疗及预防

| 时机 | 措施 |
|------|------|
| **急性出血** | ①药物：生长抑素/奥曲肽、特利加压素（收缩内脏血管）；②内镜：EVL（套扎）、组织胶注射（胃底静脉）；③TIPS（72h 内，最好 24h 内）；④气囊压迫（临时"桥梁"） |
| **一级预防**（未出血者） | 对因治疗 + 非选择性 β 受体拮抗剂（普萘洛尔/卡维地洛）+ 中度食管静脉曲张可做 EVL |
| **二级预防**（再出血预防） | TIPS、EVL/断流术、药物，根据门静脉成像结果个体化选择 |

#### 3. 肝性脑病

| 措施 | 说明 |
|------|------|
| 去除诱因 | 纠正电解质紊乱、控制感染、慎用镇静药 |
| 减少肠内氮源性毒物 | **乳果糖**（降低肠道 pH，促进 NH3→NH4^+）+ 口服抗生素（利福昔明） |
| 促进氨代谢 | L-鸟氨酸-L-天冬氨酸 |
| 调节神经递质 | 氟马西尼（苯二氮䓬受体拮抗剂，3~4 期促醒）；支链氨基酸（减少假性神经递质） |
| 营养支持 | 急性期禁蛋白 → 神志清楚后蛋白从 20g/d 逐渐增加至 1g/(kg·d) |

#### 4. 其他并发症

| 并发症 | 治疗 |
|--------|------|
| 胆石症 | 内科保守为主，Child-Pugh C 级应避免手术 |
| 感染 | 立即经验性抗感染，首选第三代头孢 |
| 门静脉血栓 | 抗凝（华法林/低分子肝素/新型口服抗凝）；TIPS |
| 低钠血症 | 轻症限水，中重度用托伐普坦 |
| 肝肾综合征 | TIPS + 白蛋白 + 血管升压素；肝移植是最有效方法 |
| 肝肺综合征 | 吸氧/高压氧（轻症）；肝移植可逆转肺血管扩张 |
| 脾功能亢进 | 部分脾动脉栓塞/TIPS |

### （三）手术与肝移植

- 各种分流、断流及限流术已被内镜及 TIPS 等微创技术替代
- **肝移植**是对终末期肝硬化治疗的最佳选择

### 病人教育

- 不宜进行重体力活动，失代偿期多卧床休息
- **严格禁酒**
- 已有 EGV 者：进食不宜过快过多，食物不宜辛辣粗糙
- 坚持对因治疗，每 3~6 个月医疗随访
- 轻微 HE 病人不宜驾车和高空作业
- 切断血液/体液传播途径

## 预后

代偿期肝硬化中位生存时间 12 年以上；失代偿期约 2~4 年。去除病因和控制并发症可显著改善预后，部分失代偿病人可实现再代偿。
