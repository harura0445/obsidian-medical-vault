# 甲状腺功能亢进症

> 甲状腺功能亢进症（甲亢）是指甲状腺本身产生甲状腺激素过多而引起的甲状腺毒症，以Graves病（GD）为主要病因，表现为高代谢症群、甲状腺肿大和突眼。

## 甲状腺毒症的病因分类

| 类别 | 病因 |
|------|------|
| **甲亢（甲状腺合成增多）** | Graves病（最常见）、毒性结节性甲状腺肿、甲状腺高功能腺瘤、碘致甲亢、HCG相关性甲亢、TSH腺瘤 |
| **非甲亢（甲状腺激素释放增多）** | 亚急性甲状腺炎、产后甲状腺炎、损伤性甲状腺炎、外源性甲状腺激素过量 |

## Graves病病因和发病机制

GD是一种以促甲状腺激素受体抗体（TRAb）为特征的多系统自身免疫病，女性是男性的4倍。

- **遗传因素**：HLA、CTLA-4、PTPN22等基因多态性
- **环境因素**：感染、碘摄入量、吸烟、应激、药物
- **自身免疫**：TSHR为主要自身抗原，B细胞转化为分泌TRAb的浆细胞

### TRAb亚型

| 亚型 | 功能 |
|------|------|
| **TSAb**（甲状腺刺激性抗体） | GD甲亢的致病抗体，与TSHR结合→激活腺苷酸环化酶→过量甲状腺激素，不受负反馈调节 |
| TBAb（甲状腺阻断性抗体） | 阻断TSH与TSHR结合→减少激素合成 |
| 甲状腺中性抗体 | 不影响甲状腺功能 |

两种抗体可互相转化，占优势的抗体决定甲状腺功能。

## 临床表现

### 一、甲状腺毒症表现

| 系统 | 表现 |
|------|------|
| **高代谢症群** | 多汗、不耐热、食欲增加、体重下降、乏力 |
| 精神神经系统 | 烦躁、易激动、失眠、注意力不集中、伸手细颤 |
| **心血管系统** | 持续性心悸，窦性心动过速、房颤，收缩压升高/舒张压下降→脉压增大，周围血管征 |
| 消化系统 | 易饥饿、多食、消瘦，大便次数增加 |
| 肌肉骨骼系统 | 慢性肌病（近端肌群）、周期性瘫痪（亚洲青年男性，低钾）、骨质疏松 |
| 造血系统 | 白细胞总数↓、淋巴细胞比例↑ |
| 生殖系统 | 月经稀少、闭经，男性阳痿 |

### 甲状腺毒症性心脏病

长期未控制甲亢所致，满足以下之一且排除其他心脏病：
- 严重心律失常（房颤、频发室早、II~III度AVB）
- 心力衰竭
- 心脏扩大
- 心绞痛或心肌梗死

### 二、甲亢危象（甲状腺危象）

| 项目 | 内容 |
|------|------|
| 诱因 | 感染、创伤、精神刺激、¹³¹I治疗、甲状腺手术、分娩 |
| 表现 | **高热、大汗、心悸**（心率>140次/分）、烦躁、谵妄、恶心呕吐腹泻、严重者心衰休克昏迷 |
| 诊断 | 主要靠临床表现综合判断 |
| 死亡率 | 高 |

### 淡漠型甲亢

多见于老年患者，起病隐袭，可表现为心力衰竭伴心律失常、不明原因体重减轻，高代谢症状不明显。

### 三、Graves病特征性表现

| 特征 | 描述 |
|------|------|
| **甲状腺肿** | 弥漫性肿大，质地软或韧，可触及细震颤及血管杂音 |
| **Graves眼病（GO）** | 25%~50% GD患者伴GO，表现为突眼、眼睑退缩、眼内异物感、畏光流泪、复视、视力下降 |
| **胫前黏液性水肿** | 少数，胫前皮肤增厚变粗，橘皮样 |

### GO临床活动性评分（CAS，≥3分=活动期）

| 项目 |
|------|
| 自发性球后疼痛 |
| 眼球运动时疼痛 |
| 眼睑/结膜充血 |
| 眼睑/球结膜/泪阜肿胀 |
| 突眼度增加≥2mm |
| 眼球运动减少≥8° |
| 视力下降≥1行 |

## 实验室检查

| 指标 | 特点 |
|------|------|
| **TSH** | 最敏感指标，下降，是筛查甲亢的第一线指标 |
| **FT₃、FT₄** | 升高，诊断临床甲亢的主要指标，FT₃升高可早于FT₄ |
| T₃型甲亢 | 仅FT₃升高，FT₄正常 |
| T₄型甲亢 | 仅FT₄升高，FT₃正常 |
| **TRAb** | 阳性率80%~100%，鉴别甲亢病因、诊断GD |
| **RAIU**（¹³¹I摄取率） | 甲亢时升高或正常+高峰前移；破坏性甲状腺毒症时降低（分离现象） |

## 诊断

### 甲亢诊断
TSH降低 + FT₄或FT₃升高 = 临床甲亢；TSH降低 + T₃、T₄正常 = 亚临床甲亢。

### GD诊断
1. 甲亢诊断确立（必备）
2. 甲状腺弥漫性肿大（必备，少数可无）
3. ③⁓⑤具备其一即可：
   - Graves眼病
   - 胫前黏液性水肿或指端粗厚
   - TRAb水平升高

### 鉴别：GD vs 破坏性甲状腺毒症

| | GD | 破坏性甲状腺毒症 |
|------|-----|------|
| RAIU | 升高或正常 | **降低**（分离现象） |
| 甲状腺超声血流 | 增多 | 不增多 |

## 治疗

### 三种经典疗法

| 疗法 | 特点 |
|------|------|
| **ATD** | 最常用，治愈率~50%，复发率40%~60% |
| **¹³¹I** | 治愈率>85%，最终可能甲减需替代治疗 |
| **手术** | 甲状腺全切/近全切除 |

### 一、抗甲状腺药物（ATD）

| 药物 | 类别 | 特点 |
|------|------|------|
| **甲巯咪唑（MMI）** | 咪唑类 | 首选，10~30mg/d起始，qd或tid |
| 丙硫氧嘧啶（PTU） | 硫脲类 | 优先用于妊娠早期、甲状腺危象，100~300mg/d起始，tid |

**机制**：抑制甲状腺过氧化物酶（TPO），减少激素合成；可能有免疫抑制作用。

**疗程**：18~24个月，分初治期→减量期→维持期。

**停药条件**：足疗程 + TRAb正常 + 最小ATD剂量维持TSH正常。

**副作用**：

| 副作用 | 发生率 | 处理 |
|--------|--------|------|
| 皮疹 | ~5% | 抗组胺药，严重者停药 |
| 粒细胞缺乏症 | ~0.37% | 停药、升白细胞药，不能换用另一种ATD |
| 肝损伤 | 0.1%~0.2% | PTU以肝细胞损伤为主，MMI以胆汁淤积为主 |
| ANCA相关血管炎 | 罕见 | 见于长期用PTU的女性 |

### 二、¹³¹I治疗

- **适应证**：ATD失败/不良反应、手术禁忌、合并肝功能损伤/白细胞减少/糖尿病/房颤、老年患者
- **禁忌证**：妊娠、哺乳期、甲状腺癌
- **并发症**：放射性甲状腺炎（7~10天）、甲减（需替代治疗）、加重活动期GO

### 三、手术治疗

- **适应证**：中重度甲亢ATD无效、甲状腺肿大压迫、胸骨后甲状腺肿、合并甲状腺癌、患者主观愿望

### 四、甲状腺危象治疗

| 步骤 | 方案 |
|------|------|
| ①抑制合成 | **PTU 600mg/d**（首选，可抑制T₄→T₃转换），最大1200mg/d |
| ②抑制释放 | 服PTU 1~2h后加卢戈碘液，4~8滴/6~8h |
| ③抑制T₄→T₃ | PTU+碘剂+普萘洛尔+糖皮质激素联用 |
| ④降低激素浓度 | 血浆置换或血液透析 |
| ⑤支持治疗 | 监护、补液、纠正电解质、补充能量、物理降温（避免用阿司匹林） |

### 五、Graves眼病治疗

| 程度 | 治疗 |
|------|------|
| 轻度 | 控制危险因素（戒烟）、补硒、随访 |
| 中重度活动期 | 糖皮质激素（甲泼尼龙静脉冲击）、眼眶放疗、靶向免疫抑制剂 |
| 威胁视力（DON） | 大剂量甲泼尼龙冲击或紧急眼眶减压术 |

### 六、妊娠期甲亢

- 首选**PTU**（与蛋白结合不易通过胎盘），最小有效剂量
- 哺乳期PTU和MMI均可，MMI<20mg/d或PTU<300mg/d安全
