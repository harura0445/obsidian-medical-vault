# 胸膜疾病

> 胸膜疾病是以胸膜腔解剖结构和生理功能异常为特征的一类疾病，主要包括以液体为主的[[#胸腔积液]]、以气体为主的[[#气胸]]和以固体为主的胸膜肿瘤。

胸膜是覆盖在胸膜腔内表面的一层薄膜，由结缔组织和纤维弹力组织支持的间皮细胞层组成。脏胸膜覆盖于肺表面，壁胸膜覆盖肋骨、膈肌和纵隔表面，两者之间闭合形成胸膜腔。壁胸膜血供来自体循环，含有感觉神经和淋巴管；脏胸膜主要由肺循环供血，不含感觉神经。

## 胸腔积液

胸膜腔是位于肺和胸壁之间的潜在腔隙，正常时有少量液体起润滑作用。任何因素造成胸膜腔内液体产生过快和/或吸收过缓，即产生**胸腔积液（pleural effusion）**。

### 发病机制

| 机制 | 病理生理 | 常见病因 | 积液性质 |
|------|----------|----------|----------|
| 胸膜毛细血管静水压升高 | 体循环/肺循环静水压增高，滤出超过重吸收 | [[心力衰竭|充血性心力衰竭]]、缩窄性心包炎、[[上腔静脉压迫综合征|上腔静脉受阻]] | 漏出液 |
| 胸膜毛细血管胶体渗透压降低 | 血浆白蛋白减少，胶体渗透压下降 | 低蛋白血症、[[肝硬化]]、肾病综合征、急性肾小球肾炎 | 漏出液 |
| 胸膜通透性增加 | 炎症或肿瘤致毛细血管通透性增加 | [[肺结核|结核性胸膜炎]]、[[肺炎]]、结缔组织病、胸膜肿瘤、[[急性胰腺炎]] | 渗出液 |
| 壁胸膜淋巴回流受阻 | 淋巴管阻塞致回流障碍 | 癌性淋巴管阻塞、先天性淋巴管发育异常 | 渗出液（高蛋白） |
| 损伤 | 血管/管道破裂 | 主动脉瘤破裂、食管破裂、胸导管破裂 | 血胸、脓胸、乳糜胸 |
| 医源性 | 药物、操作等 | 放射治疗、中心静脉置管穿破、腹膜透析 | 渗出液或漏出液 |

### 临床表现

**症状**：与积液量有关。积液量 < 0.3~0.5L 时症状不明显；大量积液时**呼吸困难**为最常见症状，多伴胸痛、咳嗽。原发病不同症状有所差别——结核性胸膜炎多见于青年人，伴发热、干咳、胸痛；心力衰竭所致者有心功能不全表现。

**体征**：与积液量有关。少量积液可无明显体征，或可触及胸膜摩擦感、闻及胸膜摩擦音；中至大量积液时患侧胸廓饱满、触觉语颤减弱、叩诊浊音、呼吸音减低或消失，气管及纵隔向健侧移位。

### 辅助检查

**影像学检查**：

| 检查 | 价值 |
|------|------|
| X线胸片 | 少量积液肋膈角变钝，中量呈外高弧形上缘影，大量呈致密影伴纵隔移位 |
| 胸部CT | 显示少量积液、包裹性积液，评估肺内及纵隔病变 |
| 超声 | 灵敏度高，可评估深度和积液量，协助穿刺定位 |
| MRI | 对软组织分辨率高，可鉴别良恶性 |
| PET-CT | 鉴别良恶性、辅助肿瘤分期及寻找原发灶 |

**实验室检查**（诊断性胸腔穿刺是关键）：

| 项目 | 漏出液 | 渗出液 |
|------|--------|--------|
| 外观 | 淡黄、清亮、不凝固 | 混浊、草黄/棕黄/血性、可凝固 |
| 比重 | < 1.016~1.018 | > 1.018 |
| 蛋白质 | < 30g/L，Rivalta试验阴性 | > 30g/L，胸腔积液/血清蛋白 > 0.5 |
| LDH | 低 | 高，胸腔积液/血清LDH > 0.6 |
| 有核细胞数 | < 100×10⁶/L | > 500×10⁶/L |

重要生化指标：
- **ADA**：> 45IU/L 提示结核性胸膜炎（敏感度高）
- **葡萄糖**：< 3.3mmol/L 见于复杂性肺炎旁积液、脓胸、类风湿关节炎
- **pH**：< 7.0 仅见于脓胸及食管破裂
- **CEA**：> 10μg/L 或积液/血清 > 1 提示恶性胸腔积液
- **淀粉酶**：升高见于急性胰腺炎、食管破裂
- **甘油三酯**：> 1.24mmol/L 为乳糜胸

**胸膜活检**：经皮穿刺或胸腔镜下活检，对肿瘤、结核诊断有重要价值。

### 诊断与鉴别诊断

诊断三步骤：

1. **确定有无胸腔积液**：症状、体征 + 影像学（超声/CT确认）
2. **区分漏出液和渗出液**：采用 **Light 标准**

| 指标 | 渗出液 | 漏出液 |
|------|--------|--------|
| 胸腔积液/血清蛋白比值 | **> 0.5** | ≤ 0.5 |
| 胸腔积液LDH | **> 血清正常值上限的2/3** | ≤ 血清正常值上限的2/3 |
| 胸腔积液/血清LDH比值 | **> 0.6** | ≤ 0.6 |

> 符合任意1项即为渗出液，3项均不满足为漏出液。约25%的漏出液可能被误判为渗出液。

3. **寻找病因**：
   - 漏出液：心衰（双侧、右侧多）、肝硬化（伴腹水、右侧多）、肾病综合征
   - 渗出液：肺炎旁积液、结核性胸膜炎、恶性胸腔积液最常见

### 常见病因分述

#### 肺炎旁胸腔积液

| 特征 | 单纯性 | 复杂性 | 脓胸 |
|------|--------|--------|------|
| 外观 | 浆液样 | 混浊 | 脓性 |
| pH | > 7.2 | < 7.2 | — |
| 葡萄糖 | > 3.3mmol/L | < 3.3mmol/L | — |
| LDH | < 1000IU/L | > 1000IU/L | — |
| 培养 | 阴性 | 可能阳性 | 阳性 |

**治疗**：单纯性以抗生素为主即可吸收；复杂性及脓胸需控制感染 + 引流积液 + 营养支持，疗程2~6周。慢性脓胸需考虑胸膜剥脱术等外科治疗。

#### 结核性胸膜炎

可发生于任何年龄，常与[[肺结核]]或其他部位结核并存。表现为胸痛、气短，伴潮热、盗汗、消瘦等结核中毒症状。胸腔积液以淋巴细胞为主，ADA > 45IU/L，间皮细胞 < 5%。抗酸染色阳性率不足10%，培养阳性率18%~40%。

**治疗**：
- **抽液治疗**：尽快抽尽积液或置管引流，首次 ≤ 800ml，以后每次 ≤ 1000ml，不宜过快，防止复张后肺水肿和胸膜反应
- **抗结核治疗**：原则同活动性肺结核（早期、规律、全程、足量、联合）
- **糖皮质激素**：疗效不肯定，仅用于全身毒性症状严重、大量积液者（泼尼松20~30mg/d，4~6周）
- 可胸腔内注入尿激酶或链激酶防止胸膜粘连

#### 恶性胸腔积液

最常见病因：[[肺癌]]、乳腺癌。中老年人多见，积液呈血性、量大、增长迅速，LDH > 500IU/L，CEA升高。确诊依靠积液脱落细胞学或胸膜活检病理证实恶性肿瘤细胞。治疗包括原发肿瘤治疗 + 胸腔积液引流（肺可复张者可行胸膜固定术，肺不可复张者首选胸腔置管引流）。

### 治疗原则

| 积液类型 | 治疗要点 |
|----------|----------|
| 漏出液 | 纠正原发病（如纠正心衰、补充蛋白）后积液可吸收 |
| 肺炎旁积液（单纯性） | 抗生素治疗可吸收 |
| 胸腔感染（复杂性/脓胸） | 抗感染 + 引流 + 营养支持 |
| 结核性胸膜炎 | 尽早抽液 + 抗结核治疗 |
| 恶性胸腔积液 | 治疗原发肿瘤 + 姑息引流/胸膜固定术 |

## 气胸

胸膜腔内不含气体，正常情况下为负压。任何原因导致气体进入胸膜腔造成积气状态，称为**气胸（pneumothorax）**。可分为自发性（原发性和继发性）、外伤性和医源性三类，是常见的内科急症。

### 病因和发病机制

胸膜腔内出现气体的三种情况：①肺泡与胸腔之间产生破口；②胸壁与外界创伤交通；③胸腔内出现产气微生物（罕见）。

| 类型 | 特点 |
|------|------|
| **原发性自发性气胸** | 无基础肺疾病的健康人，多见瘦高体型男性青壮年。胸膜下微小疱/肺大疱破裂为主要机制，吸烟、体型和家族史为危险因素 |
| **继发性自发性气胸** | 有基础肺疾病（[[肺结核]]、[[慢性阻塞性肺疾病|慢阻肺病]]、[[肺癌]]、肺脓肿等），由于基础病变存在，症状更重、耐受更差，绝大多数需积极干预 |
| 月经性气胸 | 与月经周期相关（月经前后24~72h），与异位子宫内膜结节破裂有关 |
| 妊娠期气胸 | 每次妊娠发生，可能与激素变化和胸廓顺应性改变有关 |

### 临床分型（按脏胸膜破裂情况）

| 类型 | 破裂口特征 | 胸膜腔内压 | 抽气后压力变化 |
|------|-----------|------------|---------------|
| **闭合性（单纯性）气胸** | 破口小，随肺萎陷而闭合 | 接近或略高于大气压 | 抽气后压力不再升高 |
| **开放性（交通性）气胸** | 破口大或粘连牵拉，持续开放 | 0cmH₂O上下波动 | 抽气后可呈负压，但数分钟后又复升 |
| **张力性（高压性）气胸** | 单向活瓣，吸气进呼气闭，只进不出 | > 10cmH₂O，甚至 > 20cmH₂O | 抽气后可下降但迅速复升 |

> **张力性气胸**对呼吸循环影响最大，需紧急抢救处理——纵隔移位、循环障碍、甚至窒息死亡。

### 临床表现

**症状**（严重程度与基础肺功能、肺压缩程度、发生速度有关）：
- **呼吸困难**：程度与基础肺功能密切相关，慢阻肺病患者即使肺轻度压缩也可出现明显呼吸困难
- **胸痛**：突发单侧前胸/腋下尖锐刺痛或刀割样痛，吸气时加剧
- **刺激性干咳**：气体刺激胸膜所致

> 张力性气胸表现为：高度紧张、胸闷、挣扎坐起、烦躁不安、发绀、冷汗、脉速、虚脱、心律失常，甚至意识不清、[[呼吸衰竭]]。

**体征**：
- 少量气胸：听诊呼吸音减弱最具意义
- 大量气胸：气管向健侧移位，患侧胸廓隆起，语颤减弱，叩诊过清音/鼓音，呼吸音减弱或消失
- **Hamman征**：左侧少量气胸或纵隔气肿时，左心缘处听到与心跳一致的气泡破裂音
- 液气胸时有振水声

### 辅助检查

- **X线胸片**：确诊依据。典型表现为**气胸线**（外凸弧形细线条影，为肺组织和胸膜腔空气的交界线），线外透亮度增高无肺纹理，线内为压缩肺组织
  - 气胸量评估：肺尖气胸线至胸腔顶部 ≥ 3cm 为大量气胸；侧胸壁至肺边缘 ≥ 2cm 为大量气胸
- **胸部CT**：对小量气胸、局限性气胸、气胸与肺大疱鉴别更敏感准确
- **动脉血气**：PaO₂降低，PaCO₂多正常或降低

### 诊断

根据突发胸痛 + 呼吸困难 + 患侧呼吸音消失的临床表现，X线或CT显示气胸线即可确诊。病情危重无法搬动时，可在患侧胸腔体征最明显处试验穿刺，抽出气体可证实诊断。

**严重程度评估**：

| 类型 | 标准 |
|------|------|
| 稳定型 | 呼吸频率 < 24次/分；心率 60~120次/分；血压正常；呼吸室内空气 SaO₂ > 90%；两次呼吸间隔说话成句 |
| 不稳定型 | 不符合上述任一条件 |

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| [[支气管哮喘|哮喘]]与[[慢性阻塞性肺疾病|慢阻肺病]] | 哮喘有反复阵发性喘息史；慢阻肺病为长期缓慢进行性加重。两者突发严重呼吸困难且支气管扩张剂治疗无效时需警惕并发气胸 |
| 急性心肌梗死 | 有高血压/冠心病史，心电图及血清酶学有助鉴别 |
| 急性肺栓塞 | 可有咯血、低热、晕厥，常有下肢深静脉血栓/手术后/房颤等病史，CT肺动脉造影可鉴别 |
| 肺大疱 | 起病缓慢，呼吸困难不重，影像呈圆形/椭圆形透光区，无气胸线 |

### 治疗

**治疗目的**：促进患侧肺复张，消除病因，减少复发。

| 治疗方法 | 适应证 | 要点 |
|----------|--------|------|
| **保守治疗** | 稳定型小量气胸（肺压缩 < 20%）、首次发作、无明显肺大疱 | 卧床休息、吸氧（高浓度吸氧可加快气体吸收，促进氮-氧转换）、密切观察24~48h |
| **胸腔穿刺排气** | 单侧肺压缩20%~50%、闭合性气胸、症状轻 | 锁骨中线第2前肋间穿刺，一次抽气 ≤ 1000ml |
| **胸腔闭式引流** | 不稳定型、交通性/张力性气胸、反复气胸、继发性气胸、肺压缩 > 50% | 锁骨中线第2肋间或腋前线第4~5肋间置管，水封瓶水面下1~2cm，必要时加负压吸引（-10~-20cmH₂O） |
| **胸膜固定术** | 持续性/复发性气胸、双侧气胸、合并肺大疱、不能耐受手术者 | 注入滑石粉等硬化剂产生无菌性胸膜炎症使脏壁胸膜粘连 |
| **外科手术** | 反复发作、长期气胸、血气胸、张力性气胸引流失败、多发肺大疱 | 肺大疱切除 + 胸膜固定术，成功率高、复发率低 |

> **张力性气胸紧急处理**：紧急情况下可用粗针头迅速刺入胸膜腔以达到减压目的，再行胸腔闭式引流。

**拔管指征**：水封瓶无气体逸出、症状消失、继续观察24~48h无变化，夹管再观察24h，X线显示肺已复张。

### 并发症

| 并发症 | 处理 |
|--------|------|
| 脓气胸 | 抗生素 + 插管引流 + 胸腔冲洗，必要时手术 |
| 血气胸 | 肺复张后多可自行止血；持续出血需手术结扎 |
| 纵隔气肿与皮下气肿 | 随胸腔气体排出可自行吸收；高浓度吸氧促进消散；张力过高影响呼吸循环时行胸骨上窝切开排气 |

### 预防

去除病因、规范治疗原发疾病。气胸病人禁止乘坐飞机，肺完全复张后1周方可乘坐；未接受手术治疗者建议气胸后1年内不乘飞机。
