# 慢性阻塞性肺疾病

> 慢性阻塞性肺疾病（COPD）是一种异质性肺部疾病，以因气道异常（支气管炎、细支气管炎）和/或肺泡异常（肺气肿）导致慢性呼吸道症状（呼吸困难、咳嗽、咳痰）及**持续性、进行性加重的气流受限**为特征。

**诊断关键**：吸入支气管扩张剂后 **FEV1/FVC < 70%** 表明存在持续气流受限。

## 概述

慢阻肺病与[[慢性支气管炎]]、肺气肿密切相关：

| 概念 | 定义 |
|------|------|
| 慢性支气管炎 | 除外其他原因后，每年咳嗽咳痰 ≥ 3 个月并连续 ≥ 2 年 |
| 肺气肿 | 终末细支气管远端气腔异常持久扩张，伴肺泡和细支气管破坏，无明显肺纤维化 |
| **COPD** | 慢性支气管炎/肺气肿 + 肺功能检查示持续气流受限 |

一些已明确病因的疾病（[[支气管扩张]]、肺结核纤维化、严重间质性肺疾病等）即使有持续气流受限，也不属于慢阻肺病。

**流行病学**：40 岁以上人群患病率 13.7%，是我国慢性呼吸衰竭和[[慢性肺源性心脏病]]最常见的病因（约占 80%）。

## 病因与危险因素

与[[慢性支气管炎]]相似，为环境因素与机体自身因素长期相互作用的结果：

- **吸烟**：最重要的环境因素，吸烟者患病率比不吸烟者高 2~8 倍
- **职业/环境粉尘**：烟雾、变应原、有害颗粒
- **空气污染**：PM2.5、SO₂、NO₂、氯气等
- **感染因素**：病毒（流感病毒、鼻病毒、腺病毒、呼吸道合胞病毒）、细菌（肺炎链球菌、流感嗜血杆菌）
- **其他**：免疫功能紊乱、气道高反应性、年龄增大、寒冷气候

## 发病机制

1. **炎症机制**：气道、肺实质和肺血管的慢性炎症，中性粒细胞活化和聚集是关键环节
2. **蛋白酶-抗蛋白酶失衡**：α1-AT 缺乏（北欧血统多见）或蛋白酶增多致肺组织破坏
3. **氧化应激**：氧化物直接损伤生物大分子，破坏细胞外基质，加重蛋白酶-抗蛋白酶失衡
4. **其他**：异常肺发育、儿童期哮喘、营养不良等

最终导致两种重要病变：
- **小气道病变**：小气道炎症、纤维化、黏液栓 → 小气道阻力升高
- **肺气肿病变**：肺泡弹性回缩力降低，小气道易塌陷

## 分型/分类

### 肺气肿病理分型

| 分型 | 特点 |
|------|------|
| **小叶中央型**（最常见） | 终末细支气管/一级呼吸性细支气管炎症致管腔狭窄，远端二级呼吸性细支气管囊状扩张 |
| **全小叶型** | 呼吸性细支气管狭窄，所属终末肺组织（肺泡管、肺泡囊、肺泡）扩张 |
| **混合型** | 两型共存 |

### 严重程度分级（GOLD 分级）

| GOLD 分级 | FEV1 占预计值% |
|-----------|---------------|
| GOLD 1 级（轻度） | ≥ 80% |
| GOLD 2 级（中度） | 50% ~ < 80% |
| GOLD 3 级（重度） | 30% ~ < 50% |
| GOLD 4 级（极重度） | < 30% |

### 综合评估分组（A-B-E 分组）

| 分组 | 特征 | 首选治疗 |
|------|------|----------|
| **A 组** | 低风险，症状少 | 一种支气管扩张剂 |
| **B 组** | 低风险，症状多 | LABA + LAMA |
| **E 组** | 高风险（≥ 2 次中度加重或 ≥ 1 次住院） | LABA+LAMA（EOS ≥ 300 时加 ICS） |

## 临床表现

### 症状

- **慢性咳嗽**：常晨间明显，随病程发展可终身不愈
- **咳痰**：白色黏液或浆液泡沫性痰，急性期可有脓性痰
- **气短或呼吸困难**：**标志性症状**，从剧烈活动时出现逐渐进展到静息时也感气短
- **喘息和胸闷**：重度病人或急性加重时出现
- **晚期**：体重下降、食欲减退

### 体征

| 检查方式 | 体征 |
|----------|------|
| 视诊 | 桶状胸（胸廓前后径增大、肋间隙增宽） |
| 触诊 | 双侧语颤减弱 |
| 叩诊 | 过清音，心浊音界缩小，肺下界下降 |
| 听诊 | 呼吸音减弱，呼气期延长，可闻及干/湿啰音 |

## 辅助检查

### 肺功能检查
- **诊断必备**：吸入支气管扩张剂后 **FEV1/FVC < 70%**
- TLC、FRC、RV 增高，VC 减低 → 肺过度充气

### 影像学检查
- **X 线**：早期无异常，后期肺纹理增粗紊乱，特异性不高；对鉴别其他肺病和并发症有价值
- **CT/HRCT**：辨别肺气肿类型、肺大疱大小数量；吸烟者推荐低剂量 CT 筛查[[肺癌]]

### 其他检查
- **血气分析**：判断低氧血症、高碳酸血症及呼吸衰竭类型
- **血常规**：合并感染时白细胞计数增高
- **痰培养**：病原菌检测

## 诊断与鉴别诊断

### 诊断标准

1. 高危因素史（吸烟等）+ 临床症状 + 体征 → 临床怀疑
2. **肺功能检查确定持续气流受限**（吸入支气管扩张剂后 FEV1/FVC < 70%）
3. 排除其他已知病因的气流受限疾病

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| [[支气管哮喘]] | 儿童/青少年起病，症状起伏大，气流受限可逆性显著，常有过敏史 |
| [[支气管扩张]] | 反复咳嗽、咳大量脓痰或咯血，HRCT 可确诊 |
| [[心力衰竭]] | 劳力性气促，需综合分析 |
| [[肺结核]] | 发热、乏力、盗汗、消瘦，痰找抗酸杆菌 + X 线鉴别 |
| [[肺癌]] | 顽固性刺激性咳嗽，痰中带血，CT + 支气管镜 |
| 特发性肺纤维化 | Velcro 啰音，HRCT 鉴别 |
| 代偿性/老年性肺气肿 | 气腔均匀扩大不伴肺泡壁破坏，无气流受限 |

## 并发症

- **[[呼吸衰竭]]**：急性加重时发生低氧血症和/或高碳酸血症
- **[[胸膜疾病#气胸|自发性气胸]]**：突然加重呼吸困难 + 发绀 + 患侧鼓音
- **[[慢性肺源性心脏病]]**：肺动脉高压 → 右心衰

## 治疗

### 稳定期治疗

**1. 教育与管理**：**戒烟**是减慢肺功能损害最有效的措施

**2. 支气管扩张剂**（控制症状的主要措施）

| 类别 | 短效 | 长效 |
|------|------|------|
| β2 受体激动剂 | 沙丁胺醇 | 沙美特罗、福莫特罗、茚达特罗 |
| 抗胆碱药 | 异丙托溴铵 | 噻托溴铵、格隆溴铵、乌美溴铵 |
| 茶碱类 | — | 茶碱缓释片、氨茶碱 |

**3. ICS（吸入型糖皮质激素）**
- 指征：有急性加重住院史、每年 ≥ 2 次中度加重、EOS ≥ 300/μl、有哮喘病史
- 不建议使用：EOS < 100/μl、反复肺炎、合并分枝杆菌感染

**4. 祛痰药**：氨溴索、乙酰半胱氨酸、羧甲司坦

**5. 长期家庭氧疗（LTOT）**
- PaO₂ ≤ 55 mmHg 或 SaO₂ ≤ 88%
- PaO₂ 55~60 mmHg 伴肺动脉高压/右心衰/红细胞增多症
- 鼻导管吸氧 1~2 L/min，> 15 h/d，目标 PaO₂ ≥ 60 mmHg / SaO₂ ≥ 90%

**6. 康复治疗**：呼吸生理治疗、肌肉训练、营养支持

### 急性加重期治疗

- **支气管扩张剂**：大剂量雾化吸入
- **低流量吸氧**：鼻导管 28%~30% 浓度，避免吸入氧浓度过高
- **抗生素**：脓性痰增加时依据当地病原菌和药敏选用
- **糖皮质激素**：泼尼松龙 30~40 mg/d 或甲泼尼龙 40~80 mg/d × 5 天
- **机械通气**：并发严重呼吸衰竭时
- 维持水电解质平衡，营养支持，处理并发症

### 其他治疗

- **介入治疗**：支气管镜介入（单向活瓣、热蒸汽消融、弹簧圈肺减容等）
- **外科治疗**：肺大疱切除、肺减容手术、肺移植（终末期）

## 预后

不可逆气流受限，患病后疗效常不理想。预防为主，戒烟是关键。

## 预防

- 戒烟（最重要，任何阶段戒烟均有益）
- 控制环境污染，减少有害气体吸入
- 积极防治婴幼儿和儿童期呼吸系统感染
- 流感疫苗、肺炎链球菌疫苗
- 对高危人群定期肺功能监测
