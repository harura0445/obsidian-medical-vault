# 血友病

> 一组由遗传性凝血活酶生成障碍引起的出血性疾病，X连锁隐性遗传，以关节和肌肉深部出血为特征。

## 概述

血友病分为**血友病A**（FⅧ缺乏）和**血友病B**（FⅨ缺乏），以血友病A最常见（占80%~85%）。社会人群发病率（5~10）/10万。

## 病因与遗传规律

### 分型

| 类型 | 缺乏因子 | 基因定位 | 占比 |
|------|----------|----------|------|
| **血友病A** | FⅧ（抗血友病球蛋白） | Xq28 | 80%~85% |
| **血友病B** | FⅨ（血浆凝血活酶成分） | Xq27 | 15%~20% |

### 遗传方式

**X连锁隐性遗传**。遗传规律：

| 亲代 | 子代结果 |
|------|----------|
| 男性患者 × 正常女性 | 女儿全部为携带者，儿子全部正常 |
| 女性携带者 × 正常男性 | 儿子50%患病，女儿50%为携带者 |
| 男性患者 × 女性携带者 | 子女各50%患病 |

## 病理生理

FⅧ/FⅨ缺陷 → **内源性凝血途径障碍** → 凝血活酶生成障碍 → 出血倾向。

FⅧ在循环中与[[vWF]]以复合物形式存在，vWF有稳定和保护FⅧ的作用。

## 临床表现

### 出血的严重程度分型

| 分型 | 因子活性 | 临床表现 |
|------|----------|----------|
| **重型** | ＜1% | 自幼反复自发性出血 |
| **中型** | 1%~5% | 轻度外伤后严重出血 |
| **轻型** | 5%~40% | 手术或严重外伤后出血 |

### 出血特征

| 特征 | 描述 |
|------|------|
| 发病年龄 | **自幼发病**，伴随终身 |
| 常见部位 | 软组织、**深部肌肉血肿** |
| 特征部位 | 负重关节（膝、踝）**反复出血** → 关节肿胀、僵硬、畸形 |
| 创伤后出血 | 拔牙、扁桃体切除后出血不止 |

### 血肿压迫症状

| 压迫部位 | 症状 |
|------|------|
| 周围神经 | 局部疼痛、麻木、肌肉萎缩 |
| 血管 | 缺血性坏死或淤血水肿 |
| 输尿管 | 排尿障碍 |
| 口腔底部/咽后壁/喉 | 呼吸困难、窒息 |
| 肠壁 | 肠套叠、肠梗阻 |

### 并发症

| 类型 | 具体 |
|------|------|
| 急性/反复出血并发症 | 血友病关节病、假肿瘤、骨筋膜隔室综合征 |
| 治疗相关并发症 | 输血相关肝炎/HIV、**FⅧ/FⅨ抑制物** |

## 实验室检查

| 检查 | 结果 |
|------|------|
| **血小板计数** | **正常** |
| **PT** | **正常** |
| **APTT** | **延长**（轻型可正常） |
| **TT** | 正常 |
| 纤维蛋白原 | 正常 |
| **FⅧ：C** | 血友病A↓ |
| **FⅨ：C** | 血友病B↓ |
| 基因检测 | 确定致病基因，为携带者和产前诊断提供依据 |

## 诊断

### 诊断标准

1. **临床表现**：男性患者，有/无家族史，关节/肌肉/深部组织出血，可自发性或轻度外伤后
2. **实验室**：APTT延长 + FⅧ：C或FⅨ：C降低

### 鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| 血管性血友病（vWD） | vWF：Ag降低，男女均可发病，皮肤黏膜出血为主 |
| 其他遗传性凝血因子缺乏 | 相应因子活性测定 |
| 获得性凝血因子缺乏 | 无家族史，有基础疾病（如肝病），多种因子减少 |

## 治疗

### 治疗原则

1. 以**替代治疗**为主的综合治疗
2. 加强自我保护，预防损伤出血
3. 尽早处理出血，避免并发症
4. **禁用**阿司匹林、NSAIDs及其他抗血小板药物
5. 重型患者提倡**预防治疗**
6. 遗传咨询、产前诊断

### 替代疗法

| 制剂 | 说明 |
|------|------|
| 基因重组FⅧ/FⅨ浓缩物 | 首选 |
| 新鲜冰冻血浆 | 含全部凝血因子 |
| 冷沉淀物 | 富含FⅧ |
| 凝血酶原复合物 | 含FⅡ、Ⅶ、Ⅸ、Ⅹ |

**剂量计算**：
- FⅧ剂量（IU）= 体重（kg）× 所需提高活性（%）÷ 2
- FⅨ剂量（IU）= 体重（kg）× 所需提高活性（%）

**给药频率**：FⅧ每日2次（半衰期8~12h）；FⅨ每日1次（半衰期18~24h）。

**止血要求**：最低FⅧ/FⅨ达20%以上；严重出血或大手术需40%以上。

### 预防治疗

规律性应用止血药物（凝血因子或非因子类），方案根据年龄、临床分型、出血情况、有无抑制物等个体化制定。

### 关节出血的RICE原则

| 字母 | 含义 |
|------|------|
| R | 休息制动（Rest） |
| I | 冰敷（Ice） |
| C | 局部压迫（Compression） |
| E | 抬高患肢（Elevation） |

### 并发症处理

合并**抑制物**的血友病患者：免疫抑制治疗 + 旁路治疗（rFⅦa、凝血酶原复合物等）。

### 新疗法

- **非因子类药物**：FⅨa/FⅩ双特异抗体、抗TFPI抗体
- **基因治疗**：将正常FⅧ/FⅨ基因通过载体转导入体内，国外已有产品上市

## 预后

规范替代治疗和预防治疗可显著减少出血事件和关节畸形。抑制物的产生是治疗的主要挑战。
