# 急性心肌梗死

> 在冠状动脉不稳定斑块破裂、糜烂基础上继发血栓形成，导致冠脉持续完全闭塞，引起心肌严重而持久的急性缺血性坏死。

## 定义与病理

急性心肌梗死（acute myocardial infarction, AMI）是[[冠心病]]的最严重临床类型，属于急性冠脉综合征（ACS）。

### 分型

| 分型 | 定义 | 备注 |
|------|------|------|
| **1 型** | 自发性 AMI：原发冠脉不稳定斑块破裂/糜烂/侵蚀 → 血栓形成 | **最常见** |
| 2 型 | 继发性心肌氧供需失衡（冠脉痉挛、栓塞、自发性夹层、贫血、低血压等） | MINOCA 部分属于此型 |
| 3 型 | 冠心病猝死 | 最严重 |
| 4 型 | PCI 相关 | 围手术期 |
| 5 型 | CABG 相关 | 围手术期 |

### 基本病因与发病机制

```
不稳定粥样斑块破裂/糜烂/侵蚀
        ↓
   内皮下组织因子暴露
        ↓
   血小板黏附、聚集、活化
        ↓
   凝血级联反应 → 血栓形成
        ↓
   冠脉血管持续完全闭塞（≥ 20~30 分钟）
        ↓
   心肌凝固性坏死 → AMI
```

**诱发因素**：

| 诱因 | 机制 |
|------|------|
| 晨起 6~12 时 | 交感活性增加，心率/血压/冠脉张力增高 |
| 饱餐（尤其是多量脂肪后） | 血脂增高，血黏稠度增高 |
| 重体力活动、情绪激动、用力排便 | 左心室负荷明显加重 |
| [[休克]]、脱水、出血、手术、严重[[心律失常]] | 心排血量骤降，冠脉灌注锐减 |

少数（约 14%）AMI 病人冠脉造影未见明显阻塞（MINOCA），原因包括：斑块破裂/侵蚀（可自溶）、冠脉痉挛、自发夹层（SCAD）、Takotsubo 心肌病，以及 2 型心梗的各种诱因。

### 病理演变

| 时间 | 病理变化 |
|------|----------|
| 梗死后 20~30 分钟 | 少数心肌开始坏死 |
| 1~2 小时 | 绝大部分心肌凝固性坏死，间质充血、水肿，炎症细胞浸润 |
| 1~2 周 | 坏死组织开始吸收，肉芽组织形成 |
| 6~8 周 | 瘢痕愈合 → **陈旧性心肌梗死** |

### 冠脉闭塞部位与梗死区域

| 闭塞血管 | 梗死区域 |
|----------|----------|
| **左前降支（LAD）** | 左心室前壁、心尖部、下侧壁、前间隔、二尖瓣前乳头肌 |
| **右冠脉（RCA）** | 左心室膈面（右优势时）、后间隔、右心室、窦房结和房室结 |
| **左回旋支（LCX）** | 左心室高侧壁、膈面（左优势时）、左心房、房室结 |
| **左主干（LM）** | 左心室广泛梗死 |

## 临床表现

### 症状

| 症状类型 | 特征 |
|----------|------|
| **胸痛** | **最先出现的症状**，多发生于清晨安静时，疼痛部位和性质与心绞痛相似但更剧烈，持续时间长达数小时或更长，休息/硝酸甘油**不能完全缓解**；常伴烦躁、出汗、恐惧、濒死感 |
| 全身症状 | 发热（24~48h 后出现，38℃左右，持续约一周）、心动过速、WBC 增高、ESR 增快——由坏死物质吸收所致 |
| 胃肠道症状 | 频繁恶心、呕吐、上腹胀痛——迷走神经受刺激 + 心排血量降低 |
| [[心律失常]] | 见于 **75%~95%** 病人，起病 1~2 天内最多见，**24h 内最多**；以室性心律失常最常见（室早、室速、室颤）；室颤是 STEMI 早期入院前主要死因 |
| 低血压和[[休克]] | 疼痛缓解后收缩压 < 80mmHg、烦燥、面色苍白、皮肤湿冷、尿量 < 20mL/h；见于约 20% 病人，主要是心源性（心肌 > 40% 广泛坏死） |
| [[心力衰竭]] | 主要为急性左心衰竭，发生率 32%~48%；右心室 AMI 可一开始即表现为右心衰竭 |

#### 心功能分级（Killip 分级）

| 分级 | 描述 |
|------|------|
| Ⅰ级 | 无明显心力衰竭 |
| Ⅱ级 | 有左心衰竭，肺部啰音 < 50% 肺野 |
| Ⅲ级 | 急性肺水肿，全肺大、小、干、湿啰音 |
| Ⅳ级 | 心源性休克 |

### 体征

| 体征类型 | 具体表现 |
|----------|----------|
| 心脏 | 心界正常或轻度增大；心率多增快；S1 减弱；可出现 S3、S4 奔马律；10%~20% 有**心包摩擦音**（第 2~3 天，反应性纤维性心包炎）；可有二尖瓣乳頭肌功能失调杂音；室间隔穿孔可有左缘粗糙收缩期杂音 + 震颤 |
| 血压 | 除极早期可有血压增高外，几乎所有病人血压都降低 |
| 其他 | 与心律失常、休克或心衰相关的体征 |

## 辅助检查

### 心电图（ECG）

> 急性胸痛病人 FMC 后 **10 分钟内** 必须完成 ECG，是 STEMI 诊断的关键。

#### 特征性改变

| 图形 | 对应状态 | 面向坏死区导联 |
|------|----------|----------------|
| **ST 段弓背向上抬高** | 心肌损伤 | 出现 |
| **宽而深的 Q 波（病理性 Q 波）** | 心肌坏死（透壁） | 出现 |
| **T 波倒置** | 周围心肌缺血 | 出现 |

> 背向梗死区的导联出现镜像改变：R 波增高、ST 段压低、T 波直立。

#### 动态演变（四期）

| 分期 | 时间 | ECG 特点 |
|------|------|----------|
| **超急性期** | 起病数小时内 | 可尚无异常，或出现异常高大、两肢不对称的 T 波 |
| **急性期** | 数小时 ~ 2 日 | ST 段明显弓背向上抬高，与直立 T 波连接形成单相曲线；出现病理性 Q 波，R 波减低 |
| **亚急性期** | 数日 ~ 2 周 | ST 段逐渐回到基线，T 波变为平坦或倒置 |
| **慢性期（陈旧期）** | 数周 ~ 数月后 | T 波呈 V 形倒置，两肢对称，波谷尖锐；Q 波 70%~80% 永久存在 |

> **ST 段持续抬高提示室壁瘤形成。**

#### 定位诊断

| 梗死部位 | 出现特征性改变的导联 |
|----------|----------------------|
| 前间隔 | V1~V3 |
| 局限前壁 | V3~V5 |
| 前侧壁 | V5~V7、Ⅰ、aVL |
| 广泛前壁 | V1~V6、Ⅰ、aVL |
| **下壁（膈面）** | Ⅱ、Ⅲ、aVF |
| 下间壁 | Ⅱ、Ⅲ、aVF + V1~V3 |
| 下侧壁 | Ⅱ、Ⅲ、aVF + V5~V7 |
| 高侧壁 | Ⅰ、aVL |
| 正后壁 | V7~V9（V1~V3 出现 R 波增高） |

> **右心室梗死**：V3R~V5R 导联 ST 段抬高（尤其是下壁 MI 时应注意）。

### 心肌损伤标志物

| 标志物 | 开始升高 | 达峰时间 | 恢复正常 | 临床评价 |
|--------|----------|----------|----------|----------|
| 肌红蛋白（Mb） | 2h | 12h | 24~48h | 最早出现，敏感但不特异 |
| **cTnI** | 3~4h | 11~24h | 7~10d | **诊断金标准**，特异性最高 |
| **cTnT** | 3~4h | 24~48h | 10~14d | **诊断金标准**，升高持续时间更长 |
| CK-MB | 4h | 16~24h | 3~4d | 反映梗死范围，可判断再梗死（恢复正常后再次升高提示新梗死） |

> **综合评价**：cTn（cTnI/cTnT）是诊断 AMI 的**金标准**。症状出现 6h 内 cTn 阴性者，需 1~2h 后复查；连续两次阴性可排除 AMI。CK-MB 可评估梗死范围和判断溶栓是否成功（酶峰提前到 14h 内出现）。

### 其他检查

| 检查 | 用途 |
|------|------|
| 超声心动图 | 评估室壁运动、心功能、诊断室壁瘤、乳头肌功能失调、室间隔穿孔、心包积液 |
| 心脏磁共振（CMR） | 评估心肌水肿、坏死、纤维化瘢痕、心肌存活性 |
| 血常规 | WBC 增高（24~48h 后，10~20×10⁹/L），ESR 增快，CRP 增高，持续 1~3 周 |

## 诊断与鉴别诊断

### 诊断标准（1+1 模式）

**心肌损伤标志物升高（cTn 超过正常上限 99 百分位）+ 至少一项以下证据：**

1. 心肌缺血的临床症状（胸痛等）
2. ECG 新发缺血性改变（ST-T 改变或新发左束支传导阻滞）
3. ECG 出现病理性 Q 波
4. 影像学证据：新发存活心肌丢失或节段性室壁运动异常
5. 冠脉造影或尸检证实冠脉内血栓

### 鉴别诊断

| 疾病 | 关键鉴别点 |
|------|-----------|
| 稳定性心绞痛 | 疼痛持续时间短（< 30min），硝酸甘油缓解；无心肌标志物升高；ECG 无动态演变 |
| 主动脉夹层 | 胸痛一开始即达高峰，撕裂样，可放射至背/腹部；两上肢血压/脉搏不对称；D-二聚体升高；心肌标志物正常（除非累及冠脉开口） |
| 急性肺动脉栓塞 | 胸痛 + 咯血 + 呼吸困难 + 晕厥；右心负荷增加表现（P2 亢进、颈静脉充盈）；ECG 示 SⅠQⅢTⅢ |
| 急腹症（急性胰腺炎、溃疡穿孔、胆囊炎等） | 上腹痛为主；查体腹部体征；ECG 和心肌标志物正常 |
| 急性心包炎 | 疼痛与发热同时出现，呼吸/咳嗽加重；早期即有**心包摩擦音**；ECG 示弥漫性弓背向下的 ST 段抬高（除 aVR），无 Q 波 |
| 嗜铬细胞瘤 | 头痛 + 心悸 + 出汗波动性高血压；冠脉多无狭窄；血/尿儿茶酚胺升高 |

### STEMI 与 NSTEMI 的鉴别

| 特征 | STEMI | NSTEMI |
|------|-------|--------|
| ECG | ST 段弓背向上抬高，动态演变 | ST 段压低或 T 波倒置，无 ST 段抬高 |
| 病理 | 大多数为冠脉完全闭塞（透壁梗死） | 多为非完全闭塞（心内膜下梗死） |
| 再灌注策略 | 直接 PCI 或溶栓（< 12h） | 根据危险分层选择侵入策略（< 2h / < 24h / < 72h） |
| 溶栓治疗 | 有适应证 | **不溶栓**（无效且有害） |

## 并发症

| 并发症 | 发生率 | 特点 |
|--------|--------|------|
| 乳头肌功能失调或断裂 | 高达 50% | 二尖瓣脱垂/关闭不全；心尖区收缩中晚期喀喇音 + 吹风样杂音；断裂者迅速肺水肿，数日内死亡 |
| **心脏破裂** | 少见 | 起病 1 周内，多为心室游离壁破裂 → 心包积血 → 心脏压塞 → 猝死；室间隔穿孔 → 胸骨左缘响亮的全收缩期杂音 + 震颤 |
| 栓塞 | 1%~6% | 起病后 1~2 周，左心室附壁血栓脱落（脑、肾、脾、四肢动脉）；或下肢静脉血栓 → 肺栓塞 |
| **心室壁瘤** | 5%~20% | 多见于左心室前壁；心界扩大，搏动弥漫；ECG 示 ST 段持续抬高；可致心衰、栓塞、室性心律失常 |
| 心肌梗死后综合征（Dressler 综合征） | 1%~3% | AMI 数周至数月后出现心包炎/胸膜炎/肺炎，发热、胸痛，可能为自身免疫反应 |

## 治疗

**治疗原则**：尽快恢复心肌再灌注（FMC 后 30min 内溶栓或 90min 内 PCI）、挽救濒死心肌、防止梗死扩大、处理并发症、防止猝死。

### 一、监护和一般治疗

| 措施 | 内容 |
|------|------|
| 休息 | 急性期卧床，环境安静 |
| 监测 | CCU 监护 ECG、血压、呼吸、血氧饱和度 |
| 吸氧 | SaO₂ < 90% 或呼吸困难者 |
| 护理 | 12h 卧床，24h 后床上肢体活动，3d 后走动，4~5d 逐步步行 |
| 饮食与排便 | 易消化，保持大便通畅 |

### 二、解除疼痛

| 药物 | 用法 | 备注 |
|------|------|------|
| 吗啡 | 2~4mg 静脉注射，必要时 5~10min 重复 | 减轻交感过度兴奋和濒死感；注意低血压和呼吸抑制 |
| 哌替啶 | 50~100mg 肌内注射 | 替代吗啡 |
| 硝酸酯类 | 静脉或口服 | 下壁 MI、可疑右室 MI、明显低血压者不适合 |
| β 受体拮抗剂 | 口服（美托洛尔等），无禁忌时 24h 内尽早使用 | 减少心肌耗氧、缩小梗死面积、减少室颤 |

### 三、再灌注治疗（核心治疗）

> **起病 3~6h，最多 12h 内开通闭塞冠脉。**

#### 策略选择

| 情况 | 首选策略 | 目标时间 |
|------|----------|----------|
| 能在 120min 内到达 PCI 医院并完成手术 | **直接 PCI** | FMC → 球囊 < 90min（入院 → 球囊 < 60min） |
| 预计 PCI 时间 > 120min | **溶栓治疗** | FMC → 溶栓 < 30min（ECG 明确后 < 10min 给药） |

#### 直接 PCI 适应证

- 症状发作 **12h 内** + ST 段持续抬高或新发左束支传导阻滞
- 12~48h 内仍有心肌缺血证据（胸痛 + ECG 变化）者亦可考虑
- **休克或急性重度心衰者**不论发病时间早晚均应急诊 PCI

#### 溶栓治疗

**适应证**：

- 相邻 ≥ 2 个导联 ST 段抬高（胸导联 ≥ 0.2mV，肢导联 ≥ 0.1mV），或 AMI 伴左束支传导阻滞
- 起病时间 < 12h，年龄 < 75 岁
- 年龄 > 75 岁者经慎重权衡，**溶栓药物剂量减半**
- 发病 12~24h 内，仍有进行性缺血性胸痛和广泛 ST 段抬高者也可考虑

**绝对禁忌证**：

- 既往出血性脑卒中；6 个月内缺血性脑卒中
- 中枢神经系统损伤/肿瘤/畸形
- 近期活动性内脏出血（2~4 周）
- 可疑主动脉夹层
- 严重未控制高血压（> 180/110 mmHg）

| 溶栓药物 | 分类 | 特点 |
|----------|------|------|
| 尿激酶（UK） | 非特异性 | 再通率低，出血风险大，近年少用 |
| 重组人尿激酶原（pro-UK） | 特异性 | 再通率高，脑出血发生率低 |
| 阿替普酶（rt-PA） | 特异性 | 需按体重给药，分次静推 + 静滴 |
| 瑞替普酶（r-PA） | 特异性 | 两次静脉推注，间隔 30min |
| 替奈普酶（TNK-tPA） | 特异性 | **单次静脉推注**，使用方便，适用于院前溶栓 |

#### 溶栓再通判断标准

1. ECG 抬高的 ST 段于 **2h 内回降 > 50%**
2. 胸痛 **2h 内** 基本消失
3. 2h 内出现再灌注性心律失常
4. **血清 CK-MB 酶峰提前出现（14h 内）**

### 四、抗血小板治疗（同 UA/NSTEMI）

| 药物 | 方案 |
|------|------|
| 阿司匹林 | 负荷量 150~300mg → 维持量 75~100mg/d，长期 |
| 替格瑞洛（首选）或氯吡格雷 | DAPT 至少 12 个月 |
| GP IIb/IIIa 受体拮抗剂（替罗非班） | PCI 术中应用 |

### 五、抗凝治疗

所有 STEMI 病人在抗血小板基础上常规联用抗凝治疗：

| 药物 | 说明 |
|------|------|
| 比伐芦定 | 直接 PCI 尤其是出血风险高时推荐 |
| 普通肝素 / 低分子量肝素 | 溶栓病人常规使用 |
| 磺达肝癸钠 | 选择性 Xa 因子抑制剂 |
| 口服抗凝药（华法林/NOAC） | STEMI 合并心室内血栓或房颤时联用 |

### 六、药物治疗（改善预后）

| 药物类别 | 核心药物 | 说明 |
|----------|----------|------|
| **RAAS 抑制剂**（ACEI/ARB/ARNI） | 卡托普利、依那普利、沙库巴曲缬沙坦等 | 所有无禁忌证者均应使用，改善心室重塑、降低病死率和心衰 |
| **β 受体拮抗剂** | 美托洛尔、比索洛尔 | 无禁忌时 24h 内尽早使用；减少心血管事件 |
| **他汀类** | 阿托伐他汀、瑞舒伐他汀等 | 无论基线血脂水平，尽早启用；目标 LDL-C < 1.4 mmol/L |

### 七、抗心律失常治疗

| 心律失常 | 处理 |
|----------|------|
| **室颤 / 持续性多形性室速** | 立即**非同步直流电除颤**或同步电复律 |
| 室早 / 室速 | 利多卡因 50~100mg 静推（总量 ≤ 300mg），后 1~4mg/min 静滴；反复发作可用胺碘酮 |
| 缓慢型心律失常 | 阿托品 0.5~1mg 肌注或静推 |
| 二度或三度 AVB 伴血流动力学障碍 | 临时起搏 |
| 室上性快速型心律失常 | 美托洛尔、胺碘酮；必要时同步电复律（AMI 急性期**不用**维拉帕米） |

### 八、抗休克治疗

| 措施 | 内容 |
|------|------|
| 补充血容量 | 低分子右旋糖酐/葡萄糖液（CVP > 18 cmH₂O 或 PCWP > 15~18 mmHg 时停止） |
| 升压药 | 多巴胺、去甲肾上腺素或多巴酚丁胺 |
| 血管扩张剂 | 硝普钠、硝酸甘油（用于 PCWP 增高、外周血管收缩时） |
| 器械辅助 | 主动脉内球囊反搏（IABP）、左心室辅助装置 |

### 九、右心室梗死的处理

- 右心衰竭 + 低血压，而无左心衰竭表现
- 宜**扩张血容量**（静脉输液至 PCWP 达 15 mmHg）
- 输液 1~2L 后仍低血压者用正性肌力药（多巴酚丁胺）
- **不宜用利尿剂**

## 预后

- AMI 相关死亡约一半发生于院前（院外猝死比例高）
- 住院死亡率已从 30% 降至约 4%（得益于 CCU、再灌注治疗等综合措施）
- 死亡多发生在第一周内，尤以数小时为高发
- 发生严重心律失常、休克或心衰者病死率高

## 预防

- **一级预防**：在正常人群中预防动脉粥样硬化和冠心病
- **二级预防**：已有冠心病和 MI 病史者预防再梗死和心血管事件（ABCDE 方案，参见 [[冠心病]]）
