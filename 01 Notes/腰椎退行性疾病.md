# 腰椎退行性疾病

## 腰椎间盘突出症

腰椎间盘退行性改变后，纤维环破裂，髓核突出，刺激或压迫窦椎神经和神经根→**腰腿痛**。

### 病因

- **椎间盘退变**（根本原因）：含水量下降→髓核失弹→纤维环裂隙
- **积累损伤**：反复弯腰、扭转→退变加速（驾驶员、重体力劳动者高危）
- 妊娠（韧带松弛+腰骶承重大）
- 遗传、发育异常（腰椎骶化、骶椎腰化）

### 分型

| 类型 | 病理 | 治疗倾向 |
|------|------|----------|
| 膨出型 | 纤维环表层完整，髓核均匀隆起 | 保守 |
| 突出型 | 纤维环完全破裂，后纵韧带完整 | 部分需手术 |
| 脱出型 | 穿破后纵韧带，根部仍在椎间隙 | 手术 |
| 游离型 | 完全脱入椎管，与原间盘脱离 | 手术 |
| Schmorl结节 | 髓核突入椎体松质骨 | 无症状，不手术 |

### 临床表现

**好发人群**：20~50岁，女:男=1:4~6。好发节段：**L4~L5、L5~S1**（约95%）。

**症状**：

| 症状 | 特点 |
|------|------|
| **腰痛** | 最常见首发症状（窦椎神经受刺激） |
| **坐骨神经痛** | 臀部→大腿后外侧→小腿外侧→足跟/足背放射痛 |
| 马尾神经受压 | 大小便障碍、鞍区麻木（急诊手术指征） |

**体征**：

| 体征 | 说明 |
|------|------|
| **直腿抬高试验（Lasègue征）** | 仰卧伸膝抬腿<60°→放射性疼痛=阳性（高度提示L4~L5、L5~S1突出） |
| 股神经牵拉试验 | 俯卧屈膝→大腿前侧痛=阳性（L3~L4突出） |

**定位诊断**：

| 节段 | 受压神经根 | 感觉异常区 | 肌力下降 | 反射异常 |
|------|-----------|-----------|---------|---------|
| **L4~L5** | L5 | 小腿外侧、足背 | 足背伸（足下垂） | 一般无 |
| **L5~S1** | S1 | 足外侧、足底 | 足跖屈 | **跟腱反射减弱** |
| L3~L4 | L4 | 小腿前内侧 | 股四头肌 | 膝反射减弱 |

### 辅助检查

- **MRI**：首选确诊方法，清晰显示椎间盘、神经根硬膜囊受压
- CT：显示椎间盘钙化/骨化、骨性改变
- X线：排除其他病变（骨折、结核、肿瘤）

### 鉴别诊断

腰肌劳损、梨状肌综合征、腰椎管狭窄症、脊柱结核、脊柱肿瘤

### 治疗

**80%~90%可保守治疗好转**。

| 方法 | 要点 |
|------|------|
| 卧床休息 | 硬板床，急性期2~3周 |
| NSAIDs | 消炎镇痛 |
| 理疗/牵引 | 缓解痉挛 |
| **手术** | 持续坐骨神经痛>6~12周不缓解；进行性肌力下降；马尾综合征（急诊手术） |

手术方式：椎间盘镜下髓核摘除术、椎间孔镜（微创）。

## 腰椎管狭窄症

椎管、神经根管骨性或纤维性狭窄→压迫脊髓/神经根。

### 病因

- **退行性**：最常见，椎间盘突出+黄韧带肥厚+小关节增生→椎管容积减小
- 发育性（先天性短椎弓根）
- 术后、外伤

### 临床表现

**间歇性跛行**：最特征性症状——行走一段距离（数百米）→双下肢疼痛麻木→蹲下/休息→症状缓解→可继续行走。

与**血管性间歇性跛行**鉴别：腰椎管狭窄症者站立/后伸腰椎诱发疼痛，而前屈位（骑车、推车）无痛；血管性者任何体位均痛，下肢动脉搏动减弱+皮肤苍白。

### 诊断

MRI显示椎管矢状径<10mm（正常≥12mm）。

### 治疗

- 保守（轻~中度）：NSAIDs+理疗+硬膜外注射
- 手术（保守无效/严重/进行性）：椎板减压术+/-融合术
