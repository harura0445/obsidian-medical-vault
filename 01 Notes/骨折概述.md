# 骨折概述

## 概述

骨折（fracture）是指骨的完整性和连续性中断。临床以创伤性骨折多见，由骨骼疾病（如骨髓炎、骨肿瘤）导致的骨折称为病理性骨折，如 [[成骨不全]] 患者轻微外力即可骨折。

## 病因与发病机制

| 成因 | 机制 | 示例 |
|------|------|------|
| 直接暴力 | 暴力直接作用于受伤部位 | 小腿受撞击致胫腓骨骨折 |
| 间接暴力 | 力量通过传导、杠杆、旋转使远处骨折 | 跌倒手掌撑地致桡骨远端骨折 |
| 疲劳骨折 | 长期、反复、轻微损伤累积 | 远距离行军致第2、3跖骨骨折 |

**骨折端移位的影响因素**：暴力的作用方向、肌肉牵拉、不恰当的搬运。

## 分类

### 按骨折处皮肤/黏膜完整性

| 类型 | 特点 |
|------|------|
| 闭合性骨折 | 骨折处皮肤或黏膜完整，骨折端不与外界相通 |
| 开放性骨折 | 骨折处皮肤或黏膜破裂，骨折端与外界相通 |

### 按骨折的程度和形态

| 类型 | 特点 |
|------|------|
| 横形骨折 | 骨折线与骨干纵轴接近垂直 |
| 斜形骨折 | 骨折线与骨干纵轴呈一定角度 |
| 螺旋形骨折 | 骨折线呈螺旋状 |
| 粉碎性骨折 | 骨质碎裂成三块及以上 |
| 青枝骨折 | 儿童长骨弯曲，无明显断裂和移位 |
| 嵌插骨折 | 骨折片相互嵌插，多见于股骨颈骨折 |
| 压缩骨折 | 松质骨因外力压缩变形，多见于椎体 |
| 骨骺损伤 | 骨折线经过骨骺（Salter-Harris 分5型） |

### 按骨折端稳定程度

| 类型 | 特点 | 举例 |
|------|------|------|
| 稳定性骨折 | 骨折端不易移位 | 裂缝骨折、青枝骨折、横形骨折、压缩骨折、嵌插骨折 |
| 不稳定性骨折 | 骨折端易移位 | 斜形骨折、螺旋形骨折、粉碎性骨折 |

### 骨折端移位方式

成角移位、短缩移位、旋转移位、侧方移位、分离移位。

## 临床表现

### 全身表现

- **休克**：主要因骨折出血所致，骨盆骨折、股骨骨折出血量可达2000ml以上
- **发热**：一般体温正常，出血量较大时血肿吸收可致低热（<38℃）；开放性骨折高热提示感染

### 局部表现

**一般表现**：局部疼痛、肿胀、功能障碍

**骨折特有体征**（有三者之一即可诊断）：
- **畸形**：缩短、成角或旋转畸形
- **异常活动**：正常情况下不能活动的部位出现活动
- **骨擦音或骨擦感**：骨折端相互摩擦产生

> 裂缝骨折、嵌插骨折、脊柱骨折、骨盆骨折可能无典型特有体征，应常规行影像学检查。

## 辅助检查

> 详见 [[影像学诊断]]

### X线检查

常规检查，应拍摄包括邻近一个关节在内的正、侧位片。轻微裂缝骨折急诊未见骨折线者，应于伤后2周复查（骨折断端吸收后可显示骨折线）。

### CT检查

用于解剖部位复杂或X线难以检查的部位：骨盆、髋、骶骨、骶髂关节、胸骨、脊柱。

### MRI检查

显示软组织层次、椎体周围韧带和脊髓损伤情况优于X线和CT，可发现隐匿性骨折并确定骨挫伤范围。

## 并发症

### 早期并发症

| 并发症 | 要点 |
|--------|------|
| 休克 | 严重创伤、骨折大出血或重要器官损伤 |
| 脂肪栓塞综合征 | 股骨干骨折→髓腔内脂肪滴入血→肺、脑脂肪栓塞；表现为低氧血症、神经系统异常、瘀点状皮疹 |
| 重要内脏器官损伤 | 肝脾破裂（下胸壁损伤）、肺损伤（肋骨骨折致气胸/血胸）、膀胱尿道损伤（骨盆骨折）、直肠损伤（骶尾骨骨折） |
| 重要血管损伤 | 股骨髁上骨折→腘动脉；胫骨上段骨折→胫前/胫后动脉；伸直型肱骨髁上骨折→肱动脉 |
| 周围神经损伤 | 肱骨中下1/3骨折→桡神经损伤 |
| 脊髓损伤 | 脊柱骨折/脱位→损伤平面以下瘫痪 |
| 骨筋膜隔室综合征 | 骨筋膜室内压力增高→肌肉神经缺血→缺血性肌挛缩或坏疽；好发于前臂掌侧和小腿 |

**骨筋膜隔室综合征诊断体征**：患肢感觉异常、被动牵拉痛（阳性）、主动屈曲痛、筋膜隔室压痛。筋膜室压力>30mmHg 或 ΔP（舒张压−筋膜室压力）<30mmHg 时，应及时切开减压。

### 晚期并发症

- **坠积性肺炎**：长期卧床，老年体弱者
- **压疮**：骨突起处长期受压，截瘫病人尤甚
- **下肢深静脉血栓**：下肢长时间制动+创伤后高凝状态
- **感染**：可致化脓性骨髓炎
- **创伤性骨化性肌炎**：肘关节附近骨折后骨膜下血肿机化骨化
- **创伤性关节炎**：关节内骨折未能解剖复位，关节面不平整
- **关节僵硬**：长时间固定→纤维粘连+关节囊和肌肉挛缩
- **急性骨萎缩**（Sudeck萎缩）：手、足骨折后疼痛性骨质疏松，伴血管舒缩紊乱
- **缺血性骨坏死**：腕舟骨骨折→近侧骨折端坏死，股骨颈骨折→股骨头坏死
- **缺血性肌挛缩**（Volkmann挛缩）：骨筋膜隔室综合征处理不当的严重后果，典型畸形为爪形手/爪形足

## 骨折愈合过程

骨折愈合分三个阶段，相互交织、逐渐演进：

| 阶段 | 时间 | 过程 |
|------|------|------|
| 血肿炎症机化期 | 伤后~2周 | 血肿凝结→无菌性炎症→肉芽组织形成→纤维连接 |
| 原始骨痂形成期 | 3~6个月 | 膜内成骨（内骨痂+外骨痂），以骨外膜成骨为主；骨折达临床愈合 |
| 骨痂改造塑形期 | 1~2年 | 板层骨替代原始骨痂，应力轴线上新骨生成、轴线外骨痂吸收，髓腔再通 |

**临床愈合标准**：①局部无压痛及纵向叩击痛；②局部无异常活动；③X线显示连续性骨痂，骨折线模糊。

## 影响骨折愈合的因素

### 全身因素

- **年龄**：儿童愈合快，老年人愈合慢（新生儿股骨骨折2周愈合，成人需3个月）
- **健康状况**：慢性消耗性疾病（糖尿病、营养不良、恶性肿瘤）延长愈合时间

### 局部因素

| 因素 | 影响 |
|------|------|
| 骨折类型 | 螺旋形/斜形（接触面大，愈合快）> 横形骨折 |
| 骨折部位血供 | 血供越差，愈合越差（如股骨颈头下型骨折） |
| 软组织损伤程度 | 损伤越重，愈合越差 |
| 软组织嵌入 | 阻碍骨折端对合→不愈合 |
| 感染 | 致化脓性骨髓炎→严重影响愈合 |

### 不当的治疗方法

- 反复多次手法复位→损伤骨外膜
- 切开复位剥离骨膜过多→破坏血供
- 清创时过多摘除碎骨片→骨缺损
- 骨牵引力量过重→骨折端分离
- 固定不牢固→干扰骨痂生长
- 过早/不恰当功能锻炼→妨碍固定

## 骨折的急救

急救目的：抢救生命、保护患肢、迅速转运。

1. **抢救休克**：保温、减少搬动、输液输血，昏迷者保持呼吸道通畅
2. **包扎伤口**：加压包扎止血，大血管出血可用止血带（记录压力和时间）；骨折端已戳出伤口且已污染但未压迫重要血管神经者，不应复位
3. **妥善固定**：凡疑有骨折均按骨折处理；目的为避免搬运中损伤周围组织、减轻疼痛、便于运送
4. **迅速转运**：初步处理后尽快送医

## 治疗原则

三大原则：**复位、固定、康复治疗（功能锻炼）**。

### 复位

**复位标准**：

| 标准 | 要求 |
|------|------|
| 解剖复位 | 对位对线完全恢复正常解剖关系 |
| 功能复位 | 旋转移位、分离移位必须完全矫正；成角移位必须完全复位；长骨干横形骨折对位≥1/3，干骺端骨折对位≥3/4 |

**复位方法**：

| 方法 | 要点 |
|------|------|
| 手法复位（闭合复位） | 动作轻柔，争取一次成功，达到功能复位即可 |
| 切开复位 | 直视下复位；指征：软组织嵌入、关节内骨折、并发血管神经损伤、多处骨折、不稳定骨折、老年人需尽早离床 |

### 固定

**外固定**：

| 方法 | 适用情况 |
|------|----------|
| 小夹板 | 四肢闭合性、无移位、稳定性骨折（现已少用） |
| 骨科支具 | 四肢闭合性稳定骨折及关节周围软组织损伤 |
| 石膏绷带 | 开放性骨折清创术后、切开复位内固定术后辅助固定、畸形矫正后、感染患肢固定 |
| 持续牵引 | 颈椎骨折脱位（颅骨/枕颌带牵引）、股骨骨折（股骨/胫骨结节骨牵引）、胫骨骨折（跟骨牵引） |
| 骨外固定器 | 开放性骨折、闭合骨折伴广泛软组织损伤、骨折合并感染、截骨矫形/关节融合术后 |

**石膏绷带注意事项**：抬高患肢消肿、不可用手指顶压、凝固前不改变位置、观察远端血运感觉、过紧立即纵行剖开、过松及时更换。

**内固定**：接骨板、螺丝钉、加压钢板、带锁髓内钉等。

### 康复治疗

| 阶段 | 时间 | 要点 |
|------|------|------|
| 早期 | 1~2周 | 患肢肌肉主动舒缩活动为主，促进血液循环、消肿 |
| 中期 | 2周后 | 逐渐增加活动强度和范围 |
| 晚期 | 临床愈合后 | 康复关键期，恢复关节活动范围和肌力 |

## 开放性骨折的处理

处理原则：及时正确处理创口，防止感染，力争将开放性骨折转化为闭合性骨折。

### 开放性骨折分度

| 分度 | 软组织损伤 |
|------|-----------|
| 第一度 | 骨折端自内向外刺破皮肤，软组织损伤轻 |
| 第二度 | 皮肤破裂或压碎，皮下组织与肌肉中度损伤 |
| 第三度 | 广泛皮肤、皮下组织与肌肉严重损伤，常合并血管神经损伤 |

> Gustilo-Anderson Ⅲ度亚型：ⅢA（软组织严重缺损，骨膜可覆盖骨质）、ⅢB（软组织严重缺损伴骨外露）、ⅢC（软组织严重缺损+重要血管损伤+骨外露）。

### 清创

- **时间**：伤后6~8小时内为黄金时间，超过24小时原则上不彻底清创，仅清除明显坏死组织和异物、建立引流
- **要点**：清洗→切除创缘皮肤1~2mm→由浅至深清除失活组织→尽量保留骨膜、肌腱、神经、血管→粉碎骨片有软组织连接者保留→再次清洗消毒
- **骨折固定**：最简单快捷的方法；第三度及超过6~8小时的第二度不宜内固定，选用外固定器
- **创口闭合**：争取一期愈合，是转化为闭合性骨折的关键；皮肤缺损可行减张缝合、植皮或皮瓣移植

## 骨折延迟愈合、不愈合和畸形愈合

| 类型 | 定义 | X线表现 | 处理 |
|------|------|---------|------|
| 延迟愈合 | 超过通常愈合时间（4~8个月）仍未连接 | 骨痂少、轻度脱钙、骨折线明显、无骨硬化 | 延长治疗时间 |
| 骨折不愈合 | 超过9个月+再治疗3个月仍达不到骨性愈合 | 肥大型：骨折端膨大硬化（象足样）；萎缩型：无骨痂、断端分离萎缩、髓腔封闭 | 切除硬化骨+打通髓腔+植骨+内固定 |
| 畸形愈合 | 愈合位置未达到功能复位要求 | 存在成角、旋转或重叠畸形 | 畸形明显影响功能者需矫正 |
