# 水电解质代谢和酸碱平衡失常

> 水、电解质代谢和酸碱平衡失常是临床最常见的代谢紊乱，可发生容量不足、低钠/高钠血症、低钾/高钾血症及代谢性酸中毒等改变，重者可危及生命。

## 体液组成

| 指标 | 数值 |
|------|------|
| 成年男性总水量 | 体重的60% |
| 成年女性总水量 | 体重的50% |
| 细胞内液 | 占体重的35%~40%（总液量2/3） |
| 血浆 | 占体重的4%~5% |
| 组织间液 | 占体重的11%~15% |
| 血浆渗透压正常范围 | 280~310 mOsm/(kg·H₂O) |

血浆渗透压（mOsm/kg）= 2×(Na⁺+K⁺)+血糖+尿素氮（单位均为mmol/L）

# 第一节 | 水、钠代谢失常

## 一、失水（容量不足）

失水是指体液丢失造成的体液容量不足。

### 三种失水对比

| 指标 | 高渗性失水 | 等渗性失水 | 低渗性失水 |
|------|-----------|-----------|-----------|
| 失水vs失钠 | 失水>失钠 | 等比例 | 失水<失钠 |
| 血钠 | >145mmol/L | 130~145 | <130 |
| 血浆渗透压 | >310 | 正常 | <280 |
| 口渴 | 明显 | 有 | 无 |
| 血压 | 正常→下降 | 降低 | 降低→休克 |
| 尿量 | 很少 | 减少 | 正常→减少 |
| 精神状态 | 烦躁、谵妄 | 烦躁/淡漠 | 淡漠、嗜睡 |
| **常见病因** | 摄水不足、尿崩症、大量出汗 | 呕吐、腹泻、大面积烧伤 | 补充水过多、排钠利尿药过量、肾上腺皮质功能减退 |

### 失水程度

| 程度 | 失水量占体重 | 临床表现 |
|------|-------------|----------|
| 轻度 | 2%~3% | 口渴、尿少 |
| 中度 | 4%~6% | 严重口渴、心率快、皮肤弹性下降、乏力头晕 |
| 重度 | 7%~14% | 脑细胞失水：谵妄、定向力障碍、幻觉、晕厥 |

### 补液原则

| 失水类型 | 补液方案 |
|----------|----------|
| 高渗性 | 补水为主（5%葡萄糖/0.9%NaCl），含钠液~1/3 |
| 等渗性 | 等渗溶液为主，首选0.9%NaCl，含钠液~1/2 |
| 低渗性 | 补充高渗液为主，含钠液~2/3，血钠升高速度≤0.5mmol/L·h |

补液速度"先快后慢"，重症前4~8h补充总量的1/3~1/2。

## 二、低钠血症

血清钠<135mmol/L。

| 类型 | 机制 | 常见原因 |
|------|------|----------|
| **缺钠性低钠血症** | 体内总钠量减少 | 呕吐、腹泻、利尿药、失盐性肾炎、[[肾上腺皮质功能减退症\|Addison病]] |
| **稀释性低钠血症** | 水过多，血钠被稀释 | 精神性多饮、SIADH、肝硬化腹水、心衰 |
| 转移性低钠血症 | 钠从细胞外移入细胞内 | 少见 |
| 特发性低钠血症 | 消耗性疾病，细胞内渗透压降低 | 恶性肿瘤、肝硬化晚期、营养不良 |
| 脑盐耗综合征(CSWS) | 下丘脑-肾联系中断，渗透性利尿 | 下丘脑或脑干损伤 |

CSWS与SIAD鉴别要点：CSWS血容量降低，SIAD血容量增多。

## 三、高钠血症

血清钠>145mmol/L。

| 类型 | 特点 | 常见原因 |
|------|------|----------|
| **浓缩性高钠血症** | 最常见，即高渗性失水 | 单纯失水或失水>失钠 |
| 潴钠性高钠血症 | 肾排钠减少/入量过多 | 右心衰、肾病综合征、[[Cushing综合征]]、原发性醛固酮增多症 |
| 特发性高钠血症 | AVP分泌的渗透压阈值升高 | 较少见 |

以神经精神症状为主（脑细胞失水），补液过快可致脑水肿。

# 第二节 | 钾代谢失常

## 一、低钾血症

血清钾<3.5mmol/L。

### 病因分类

| 类型 | 机制 | 
|------|------|
| **缺钾性低钾血症** | 摄入不足（长期禁食<3g/d）、胃肠道丢失（呕吐腹泻）、肾丢失（利尿药、肾小管性酸中毒、醛固酮增多症） |
| **转移性低钾血症** | 钾从细胞外转入细胞内：碱中毒（pH每升高0.1，血钾约降0.7）、大量葡萄糖+胰岛素、周期性瘫痪 |
| 稀释性低钾血症 | 水过多，血钾被稀释 |

### 临床表现

| 系统 | 血清钾<3.0时 | 血清钾<2.5时 |
|------|-------------|-------------|
| 骨骼肌 | 疲乏、软弱乏力 | 全身性肌无力、软瘫、呼吸肌麻痹 |
| 消化系统 | 恶心、呕吐、腹胀、便秘 | 肠麻痹 |
| 中枢神经 | 萎靡、反应迟钝 | 嗜睡或昏迷 |
| **循环系统** | 心动过速、房性/室性早搏 | 低钾性心肌病、室速、室颤 |

### ECG改变

| 血钾水平 | ECG表现 |
|----------|---------|
| <3.5mmol/L | T波宽而低、QT间期延长、出现U波 |
| 重度 | T波倒置、ST段下移、多源性早搏→室速→室颤→心搏骤停 |

### 治疗

| 程度 | 血清钾 | 补钾量（氯化钾） |
|------|--------|-----------------|
| 轻度 | 3.0~3.5 | 补钾100mmol（约8g） |
| 中度 | 2.5~3.0 | 补钾300mmol（约24g） |
| 重度 | 2.0~2.5 | 补钾500mmol（约40g） |

- 每日补钾≤200mmol（约15g KCl）
- 静脉补钾速度20~40mmol/h，不超过50~60mmol/h
- 补钾前提：尿量>500ml/d或>30ml/h
- 首选氯化钾口服，严重者静脉滴注
- 注意纠正碱中毒和低镁血症

## 二、高钾血症

血清钾>5.3mmol/L。

### 病因

| 类型 | 机制 | 常见原因 |
|------|------|----------|
| **钾过多性高钾血症** | 肾排钾减少或摄入过多 | CKD/AKI、[[肾上腺皮质功能减退症]]、潴钾利尿药、ACEI/ARB、β阻滞剂 |
| 转移性高钾血症 | 细胞内钾释放 | 溶血、大面积烧伤、横纹肌溶解、代谢性酸中毒 |
| 浓缩性高钾血症 | 血液浓缩 | 重度失水、休克 |
| 假性高钾血症 | 试管内溶血等 | 采血操作不当等 |

### 临床表现

| 血钾水平 | 表现 |
|----------|------|
| 轻中度 | 通常无症状 |
| **>6.0mmol/L** | 基底窄而高尖的T波 |
| **7~9mmol/L** | PR间期延长、P波消失、QRS变宽 |
| **>9~10mmol/L** | 正弦波→室颤、心搏骤停 |
| 心脏外 | 感觉异常、震颤→弛缓性麻痹、四肢无力 |

### 治疗（紧急处理）

| 措施 | 方法 | 机制 |
|------|------|------|
| **葡萄糖酸钙** | 10%葡萄糖酸钙10~20ml静注 | 对抗钾的心肌毒性（最快） |
| **碳酸氢钠** | 5% NaHCO₃ 100~200ml静滴 | 碱化血液，促进K⁺进入细胞内 |
| **葡萄糖+胰岛素** | 25%~50%GS + RI (3~4g:1U) | 促进K⁺转移至细胞内 |
| **袢利尿剂** | 呋塞米40~80mg静注 | 促进肾排钾 |
| **阳离子交换树脂** | 聚苯乙烯磺酸钙 | 肠道排钾 |
| **血液透析** | 血钾>6.5mmol/L | 最有效 |

# 第三节 | 代谢性酸中毒

代谢性酸中毒（代酸）是CKD最常见的酸碱平衡紊乱，详见[[慢性肾衰竭]]。此处简要概述酸碱平衡指标。

### 酸碱平衡主要指标

| 指标 | 正常值 | 意义 |
|------|--------|------|
| pH | 7.35~7.45 | <7.35酸中毒，>7.45碱中毒 |
| PaCO₂ | 35~45mmHg | 呼吸因素：↑通气不足（呼酸），↓通气过度（呼碱） |
| SB（标准碳酸氢盐） | 22~26mmol/L | 代谢因素：↓代酸，↑代碱 |
| AB（实际碳酸氢盐） | 22~26mmol/L | 同时受呼吸和代谢影响 |
| BE（碱剩余） | 0±2.3mmol/L | 正值代碱，负值代酸 |
| AG（阴离子间隙） | 8~16mmol/L | >16提示高AG代酸（有机酸增多） |

### AG与代酸类型

| 类型 | AG | 机制 |
|------|-----|------|
| 高AG代酸 | >16 | 内源性酸产生过多（DKA、乳酸酸中毒、尿毒症） |
| 正常AG代酸（高氯性） | 正常 | HCO₃⁻丢失过多（腹泻、肾小管性酸中毒） |

### 常见酸碱失衡组合

| 类型 | pH | PaCO₂ | HCO₃⁻ |
|------|-----|--------|--------|
| 代偿性代酸 | 正常 | ↓ | ↓ |
| 代偿性代碱 | 正常 | ↑ | ↑ |
| 代酸+呼酸 | ↓↓ | ↑ | ↓ |
| 代碱+呼碱 | ↑↑ | ↓ | ↑ |

### 代谢性碱中毒

多见于呕吐/胃引流致大量HCl丢失（容量不足性代碱）、低钾性代碱、利尿药致低氯性代碱。
