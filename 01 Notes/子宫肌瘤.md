# 子宫肌瘤


## 概述

子宫肌瘤是女性生殖器官最常见的良性肿瘤，由平滑肌及结缔组织组成。常见于 30~50 岁女性，60%~80% 女性患有大小不等的子宫肌瘤。是**性激素依赖性肿瘤**，青春期前少见，绝经后萎缩或消退。

## 发病机制

- 好发于生育期，绝经后萎缩→与雌、孕激素明确相关
- 肌瘤局部对雌激素的高敏感性：雌二醇的雌酮转化低于正常肌组织，ER 表达量高于正常肌组织
- 孕激素促进肌瘤细胞有丝分裂、刺激肌瘤生长
- 细胞遗传学：染色体易位、缺失、MED12 基因突变

## 分类

按与子宫肌壁的关系分 3 类：

| 类型 | 占比 | 特点 |
|------|------|------|
| **肌壁间肌瘤** | 60%~70% | 肌瘤位于子宫肌壁间，周围均被肌层包围 |
| **浆膜下肌瘤** | ~20% | 向子宫浆膜面生长，突出于子宫表面，可形成带蒂浆膜下肌瘤 |
| **黏膜下肌瘤** | 10%~15% | 向子宫腔方向生长，表面为子宫内膜覆盖，常引起子宫收缩，可被挤出子宫颈外口 |

按生长部位：子宫体肌瘤（约 90%）、子宫颈肌瘤（约 10%）。

## 病理

- **大体观**：实质性球形包块，表面光滑，质较肌层硬，有假包膜。切面灰白色，旋涡状或编织状结构
- **镜下**：梭形平滑肌细胞 + 纤维结缔组织，排列成旋涡状/束状

### 肌瘤变性

| 变性类型 | 特点 |
|----------|------|
| **玻璃样变性** | 最常见，旋涡状结构消失，为均匀透明样物质取代 |
| **囊性变** | 玻璃样变性继续发展，肌瘤内出现囊腔 |
| **红色变性** | 多见于妊娠期或产褥期，剧烈腹痛+恶心、呕吐、发热，剖面暗红色如半熟牛肉 |
| 钙化 | 多见于血供不足的浆膜下肌瘤及绝经后 |
| **肉瘤变** | 0.4%~0.8%，绝经后肌瘤增大应警惕恶变 |

## 临床表现

### 症状

| 症状 | 要点 |
|------|------|
| **经量增多及经期延长** | **最常见症状**。肌壁间肌瘤及黏膜下肌瘤→子宫内膜面积增加、影响子宫收缩 |
| 下腹部包块 | 子宫超过妊娠 3 个月大时可从下腹部触及 |
| 阴道分泌物增多 | 宫腔面积增大→腺体分泌增多 |
| 压迫症状 | 前壁→尿频；后壁→便秘；阔韧带肌瘤→输尿管扩张、肾盂积水 |
| 不孕 | 1%~2% 不孕由肌瘤引起，黏膜下肌瘤最常见 |
| 疼痛 | 红色变性→急性下腹痛；浆膜下肌瘤蒂扭转→急性腹痛 |

### 体征

子宫增大、表面不规则结节状突起。浆膜下肌瘤→单个实质性球状肿块与子宫有蒂相连。黏膜下肌瘤脱出→阴道检查见子宫颈口处粉红色肿物。

## 辅助检查

- **超声**：首选，可区分子宫肌瘤与其他盆腔包块
- **MRI**：准确判断肌瘤大小、数目和位置
- 宫腔镜、腹腔镜、子宫输卵管造影等可酌情选择

## 诊断与鉴别诊断

| 疾病 | 鉴别要点 |
|------|----------|
| 妊娠子宫 | 停经史、hCG 阳性、超声确诊 |
| 卵巢肿瘤 | 多无月经改变，肿块位于子宫一侧 |
| 子宫腺肌病 | 继发性痛经明显，子宫均匀增大，CA125 升高 |
| 子宫肉瘤 | 围绝经期和老年女性，生长迅速，MRI 协助鉴别 |

## 治疗

### 观察
无症状者一般不需治疗，每 3~6 个月随访 1 次。围绝经期肌瘤多可萎缩。

### 药物治疗

| 药物 | 用途 |
|------|------|
| **GnRH-a** | 缩小瘤体、缓解症状，术前用药纠正贫血；不推荐长期使用（围绝经综合征） |
| 米非司酮（SPRM） | 缩小肌瘤，术前用药或提前绝经；不宜长期使用（内膜病变风险） |
| COC、LNG-IUS | 缓解月经过多，缩小肌瘤作用不明显 |
| 止血药（氨甲环酸）、NSAID | 对症治疗 |

### 手术治疗（最有效方法）

**手术适应证**：①月经过多致继发性贫血；②肌瘤体积过大；③有疼痛或压迫症状；④影响妊娠；⑤可疑恶变。

| 术式 | 适用人群 |
|------|----------|
| **子宫肌瘤切除术** | 希望保留生育功能者（经腹/腹腔镜/宫腔镜/经阴） |
| **子宫切除术** | 肌瘤多而大、症状明显、无生育要求或怀疑恶变 |

### 其他治疗
子宫动脉栓塞术（UAE）、高强度聚焦超声（HIFU）——适用于不能耐受/不愿手术者，不推荐常规应用。

## 子宫肌瘤合并妊娠

- 超声发现率 3%~12%
- 黏膜下肌瘤→影响受精卵着床→早期流产
- 位置较低的肌瘤→妨碍胎先露下降
- 妊娠期/产褥期易发生红色变性，通常保守治疗可缓解
- 若肌瘤阻碍胎儿下降→剖宫产

## 预后与随访

良性肿瘤，绝经后多萎缩。肌瘤切除术后有残留及复发可能。肉瘤变率 0.4%~0.8%，绝经后肌瘤增大应警惕。
