# 卵巢肿瘤

## 概述

卵巢肿瘤是女性生殖系统常见肿瘤之一，**卵巢恶性肿瘤**是女性生殖系统三大恶性肿瘤之一，病死率居妇科恶性肿瘤**首位**。卵巢深居盆腔，早期无症状，筛查方法有限，70% 确诊时已属晚期。

## 组织学分类（WHO 2020）

| 类别 | 常见肿瘤 | 占比 |
|------|----------|------|
| **上皮性肿瘤** | 浆液性囊腺瘤/癌、黏液性囊腺瘤/癌、子宫内膜样癌、透明细胞癌 | 最常见（良性 ~50%，恶性 85%~90%） |
| **生殖细胞肿瘤** | 畸胎瘤（成熟性/未成熟性）、无性细胞瘤、卵黄囊瘤 | 多见于年轻女性 |
| **性索-间质肿瘤** | 颗粒细胞瘤、卵泡膜细胞瘤、支持-间质细胞瘤 | 常有内分泌功能 |
| 转移性肿瘤 | **Krukenberg 瘤**（胃癌转移至卵巢） | — |

## 临床表现

### 良性肿瘤

- 早期多无症状，常在体检时偶然发现
- 肿瘤增大→腹胀、腹部包块
- 妇科检查：囊性或囊实性包块，活动好，无压痛

### 恶性肿瘤

| 症状 | 要点 |
|------|------|
| 腹胀、腹部包块 | 最常见早期症状 |
| **腹水** | 肿瘤腹膜种植→腹腔积液 |
| **消瘦、贫血、恶液质** | 晚期表现 |
| 压迫症状 | 尿频、便秘等 |
| 功能性症状 | 颗粒细胞瘤→雌激素→不规则阴道流血/性早熟 |

**体征**：附件区**实性或囊实性包块**，活动差，表面不平。子宫直肠陷凹可触及散在质硬结节。腹水征阳性。

## 并发症

| 并发症 | 临床表现 | 处理 |
|--------|----------|------|
| **蒂扭转** | 突发一侧下腹剧烈疼痛，恶心呕吐。**最常见并发症**，好发于中等大小、瘤蒂长的良性肿瘤 | **急诊手术** |
| **破裂** | 突发剧烈腹痛→腹膜刺激征 | 急诊手术 |
| **感染** | 发热、腹痛、白细胞升高 | 抗感染后手术 |
| **恶变** | 短期内生长迅速、出现腹水 | 手术 |

## 诊断

- **超声**：首选辅助检查，区分囊性/实性/囊实性、有无腹水
- **肿瘤标志物**：
  - **CA125**：上皮性卵巢癌标志物，80% 卵巢上皮癌升高（灵敏但非特异）
  - **HE4**（人附睾蛋白 4）：对上皮性卵巢癌特异性优于 CA125
  - **AFP**：卵黄囊瘤 — 显著升高；未成熟畸胎瘤也可升高
  - **hCG**：卵巢原发性绒癌
  - **LDH**：无性细胞瘤
- **MRI/CT/PET-CT**：评估肿瘤范围、转移灶
- **腹水细胞学检查**：查找癌细胞
- **腹腔镜检查 + 活检**：确诊 + 分期

### 良恶性鉴别

| 特征 | 良性 | 恶性 |
|------|------|------|
| 病史 | 生长缓慢，病程长 | 生长迅速，病程短 |
| 一般情况 | 良好 | 消瘦、贫血、恶液质 |
| 包块 | 囊性、光滑、活动好 | 实性/囊实性、不光滑、固定 |
| 腹水 | 无 | 常伴（血性） |
| CA125/HE4 | 正常/轻度升高 | 显著升高 |

## 恶性肿瘤分期（FIGO 2014）

| 分期 | 标准 |
|------|------|
| **Ⅰ期** | 肿瘤局限于卵巢（或输卵管） |
| **Ⅱ期** | 盆腔内扩散 |
| **Ⅲ期** | 腹腔腹膜转移 / 区域淋巴结转移 |
| **Ⅳ期** | 远处转移（肝实质、胸水细胞学阳性等） |

## 治疗

### 良性肿瘤

- 囊肿直径 <5cm、无月经改变→定期随访
- 囊肿持续存在或增大→腹腔镜卵巢囊肿剥除术

### 恶性肿瘤

以**手术为主的综合治疗**。

**1. 手术治疗（分期手术或肿瘤细胞减灭术）**

| 目标 | 术式与要点 |
|------|-----------|
| 早期（Ⅰ/Ⅱ期） | 全面分期手术：全子宫+双附件+大网膜切除 + 腹膜活检 + 淋巴结清扫 |
| 早期保育（年轻、ⅠA 期、高分化） | 患侧附件切除 + 对侧卵巢活检 + 大网膜切除 + 分期，完成生育后补充手术 |
| 晚期（Ⅲ/Ⅳ期） | **肿瘤细胞减灭术**：最大限度切除肿瘤（理想减灭：残余灶 <1cm） |

**2. 化疗**

- **上皮性卵巢癌**：紫杉醇 + 卡铂（TC 方案），6 周期，为一线方案
- **生殖细胞肿瘤**：BEP 方案（博来霉素 + 依托泊苷 + 顺铂）

**3. 靶向治疗**

- **PARP 抑制剂**（奥拉帕利、尼拉帕利）：BRCA 突变阳性或 HRD 阳性，用于维持治疗
- 贝伐珠单抗：抗血管生成

## 预后与随访

- 卵巢上皮癌 5 年生存率：Ⅰ期 ~90%，Ⅲ期 ~30%~40%
- 生殖细胞肿瘤预后优于上皮性癌
- 术后 2 年内每 2~4 个月随访，3~5 年每 3~6 个月随访
