# 负荷试验

> 通过增加心脏负荷（运动或药物）诱发心肌缺血，以心电图上 ST 段改变为判断依据，用于诊断 [[冠心病]] 的无创功能性检查方法。

## 概述

心脏负荷试验（cardiac stress test）的原理基于冠心病患者冠脉存在固定狭窄（≥50%~75%），静息状态下冠脉血流量尚能满足心肌需氧，但当运动或药物等负荷增加心肌耗氧量时，冠脉血流不能相应增加，导致心肌缺血，心电图上出现特征性 ST 段改变。

负荷试验主要用于：
- **诊断**：疑似冠心病的无症状或症状不典型者
- **评估**：已确诊冠心病的缺血程度和危险分层
- **预后判断**：心肌梗死或血运重建术后的心功能评估

## ECG 负荷试验（运动负荷试验）

### 适应证

| 情况 | 说明 |
|------|------|
| 疑似冠心病，静息 ECG 正常 | 典型或非典型胸痛，需明确心肌缺血诊断 |
| 稳定型心绞痛严重度评估 | 判断运动耐量和缺血阈值 |
| 血运重建（PCI/CABG）后评估 | 评估疗效及有无再狭窄 |
| 冠心病危险分层 | 高危患者进一步行冠脉造影 |
| 特殊职业健康评估 | 飞行员、消防员等高体力负荷职业 |

### 禁忌证

#### 绝对禁忌

| 禁忌 | 原因 |
|------|------|
| 急性心肌梗死（2 天内） | 加重心肌损伤，诱发心脏破裂 |
| 不稳定型心绞痛 | 诱发急性冠脉事件 |
| 未控制的有症状[[心力衰竭]] | 血流动力学不稳定 |
| 严重[[心律失常]] | 室性心动过速、高度房室传导阻滞 |
| 急性心肌炎、心包炎 | 炎症活动期加重病情 |
| 严重主动脉瓣狭窄 | 运动诱发晕厥、猝死 |
| 急性肺栓塞/肺梗死 | 加重右心负荷 |
| 急性主动脉夹层 | 运动加重撕裂 |

#### 相对禁忌

| 禁忌 | 说明 |
|------|------|
| 左主干狭窄 | 极高风险 |
| 中度瓣膜病 | 需评估风险收益 |
| 电解质异常 | 影响 ECG 判读 |
| 严重高血压（收缩压 > 200 mmHg 或舒张压 > 110 mmHg） | 需先控制血压 |
| 严重贫血 | 影响氧供 |
| 未控制的代谢性疾病（甲亢、糖尿病） | 运动诱发危象 |

### 试验方法

最常用 **分级活动平板运动试验**（Bruce 方案或改良 Bruce 方案），亦可用踏车运动试验。

| 步骤 | 内容 |
|------|------|
| 准备 | 试验前停用可能影响结果的心血管药物（β 受体阻断剂、硝酸酯类等）；禁食 2~3 小时 |
| 目标心率 | 亚极量运动：**85%~90% 预计最大心率（220 - 年龄）**；极量运动：预计最大心率 |
| 过程 | 逐级增加运动负荷，持续监测 12 导联 ECG 和血压 |
| 记录 | 运动前、每级负荷增加时、运动终止即刻及每 2 分钟记录 ECG，直至心率恢复运动前水平 |
| 终止标准 | 达到目标心率、出现典型心绞痛、ST 段显著压低 ≥ 0.2mV、血压下降、严重心律失常、步态不稳 |

### 阳性判断标准

| 标准 | 具体内容 |
|------|----------|
| **ST 段压低**（主要标准） | ST 段水平形或下斜形压低 **≥ 0.1mV**（J 点后 60~80ms 处测量），持续 ≥ 2 分钟 |
| **症状标准** | 运动中诱发典型心绞痛 |
| **血压反应** | 运动负荷增加时收缩压下降 ≥ 10mmHg（提示严重缺血） |
| ST 段抬高 | 运动中 ST 段抬高 ≥ 0.1mV（提示透壁性缺血） |

### 临床意义与局限性

| 方面 | 说明 |
|------|------|
| 敏感性 | 约 68%~81%（单支病变较低，多支病变较高） |
| 特异性 | 约 77%~89% |
| **假阳性** | 女性、X 综合征（冠脉微循环病变）、瓣膜病、左心室肥厚、电解质紊乱、药物（洋地黄等） |
| **假阴性** | 单支血管病变、运动量不足、侧支循环丰富、β 阻断剂等药物影响 |

> 负荷试验阳性 ≠ 确诊冠心病，阴性 ≠ 排除冠心病。结果需结合临床综合判断。

## 其他类型的负荷试验

### 药物负荷试验

用于不能运动或运动能力受限者（如周围血管病、神经系统疾病、严重肺病）：

| 类型 | 药物 | 机制 | 备注 |
|------|------|------|------|
| **血管扩张剂负荷** | 腺苷、双嘧达莫、瑞加德松 | 扩张正常冠脉→窃血现象→缺血区灌注减少 | 常用心肌灌注显像联合；副作用：面红、胸闷、支气管痉挛 |
| **正性肌力药物负荷** | 多巴酚丁胺 | 增加心肌收缩力、心率→增加心肌耗氧 | 常用负荷超声心动图联合；副作用：心悸、心律失常 |

### 负荷超声心动图

- 运动或药物负荷后立即行超声心动图，比较**负荷与静息状态下室壁运动**
- 阳性标准：负荷后出现**节段性室壁运动异常**（新发或加重）
- 优势：无辐射，可同时评估心脏结构和功能
- 适用于 ECG 负荷试验不能明确诊断者

### 放射性核素负荷试验（心肌灌注显像）

- 使用 ²⁰¹Tl（铊）或 ⁹⁹ᵐTc-MIBI 示踪剂
- 负荷状态下缺血区**灌注缺损**，静息后**再分布充填**（可逆性缺损）→ 心肌缺血
- 不可逆缺损 → 心肌梗死/瘢痕组织

### 对比：各类型负荷试验

| 类型 | 方法 | 监测指标 | 优点 | 缺点 |
|------|------|----------|------|------|
| ECG 负荷试验 | 运动平板/踏车 | ST 段改变 | 简便价廉、广泛使用 | 敏感性和特异性有限 |
| 负荷超声心动图 | 运动/多巴酚丁胺 | 室壁运动 | 无辐射、结构+功能评估 | 依赖操作者经验 |
| 核素心肌灌注显像 | 运动/腺苷+核素显像 | 灌注缺损 | 定位准确、定量评估 | 有辐射、费用高 |
| 药物负荷试验 | 腺苷/多巴酚丁胺 | 视联合检查而定 | 适用于不能运动者 | 有药物副作用 |

## 负荷试验在冠心病诊断中的位置

```
临床疑诊冠心病
      ↓
静息 ECG + 危险分层
      ↓
低-中危 → 负荷试验（首选无创）
      ↓
  ↓阳性        ↓阴性
  ↓              ↓
冠脉CTA/冠脉造影   临床随访
```

> **重要原则**：负荷试验阳性 + 典型症状 = 可临床诊断稳定型心绞痛；负荷试验单纯阳性但无症状不典型者，需进一步行冠脉 CTA 或冠脉造影明确。

## 注意事项

1. 试验前需**停用 β 受体阻断剂** 24~48 小时（否则影响心率反应，降低敏感性）
2. 试验需配备**急救设备和人员**（除颤仪、抢救药物）
3. 运动中出现以下情况应**立即终止**：胸痛、ST 段显著压低 ≥ 0.2mV、血压下降、室性心动过速、头晕、步态不稳
4. 试验后仍需观察 10~15 分钟，直至 ECG 和血压恢复
