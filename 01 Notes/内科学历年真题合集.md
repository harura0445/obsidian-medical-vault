# 内科学历年真题合集

> 本合集整理了 2018~2023 级内科学考试真题回忆，来源为微信公众号「B1休息区」投稿，涵盖临床五年制、临床八年制、预防医学、口腔医学、基础医学、临床药学六个专业方向。题目按**题型→系统**分类编排，每题附答案、知识点标签及对应笔记链接。

---

## 一、选择题
### 呼吸系统

#### Q1. 肺部听诊弥漫性湿啰音的是什么疾病？
- **来源**: 23口腔
- **答案**: **慢性阻塞性肺疾病（COPD）**。弥漫性湿啰音是 COPD 的典型体征，提示气道内分泌物增多，常见于双侧肺底。需与局限性湿啰音（如肺炎、支气管扩张）鉴别。
- **知识点**: COPD 体征, 肺部听诊, 湿啰音鉴别
- **详见**: [[慢性阻塞性肺疾病]], [[呼吸系统常见疾病的主要症状和体征]]

#### Q2. 肺心病慢性呼吸衰竭患者血气分析：pH 7.188, PaCO₂ 75mmHg, PaO₂ 50mmHg, HCO₃⁻ 20.6mmol/L, BE -7mmol/L，其酸碱失衡类型是？
- **来源**: 22口腔
- **答案**: **呼吸性酸中毒合并代谢性酸中毒**。pH < 7.35 为酸中毒；PaCO₂ 75mmHg 显著升高提示呼吸性酸中毒；HCO₃⁻ 降低（正常 22-27）且 BE 为负值提示合并代谢性酸中毒。
- **知识点**: 血气分析, 酸碱失衡判断, 呼吸衰竭
- **详见**: [[呼吸衰竭]], [[慢性肺源性心脏病]], [[酸碱平衡紊乱]]

#### Q3. 肺气肿合并肺心病最常见的并发症是？
- **来源**: 23口腔
- **答案**: **呼吸衰竭**。肺气肿导致通气功能障碍，肺心病在此基础上加重心肺功能失代偿，最常见且最严重的并发症为 II 型呼吸衰竭（低氧血症合并高碳酸血症）。
- **知识点**: COPD 并发症, 肺心病, II 型呼吸衰竭
- **详见**: [[慢性阻塞性肺疾病]], [[慢性肺源性心脏病]], [[呼吸衰竭]]

#### Q4. 咳嗽变异性哮喘的诊断要点？
- **来源**: 23口腔
- **答案**: ① 咳嗽为唯一或主要症状，**无喘息、气急**；② **支气管激发试验阳性**或支气管舒张试验阳性（FEV₁ 增加 > 12%，且绝对值增加 > 200mL）；③ 支气管舒张剂治疗有效。咳嗽变异性哮喘是哮喘的一种特殊类型。
- **知识点**: 咳嗽变异性哮喘, 支气管激发试验, 不典型哮喘
- **详见**: [[支气管哮喘]]

#### Q5. 长期应用抗生素后，细菌性肺炎不同致病菌的数量会有什么变化？
- **来源**: 23口腔
- **答案**: 长期广谱抗生素使用导致**菌群失调**：敏感菌被抑制，耐药菌和条件致病菌（如**铜绿假单胞菌、MRSA、真菌**）过度生长。院内获得性肺炎（HAP）的病原谱向 **G⁻ 杆菌（鲍曼不动杆菌、铜绿假单胞菌）** 和 **MRSA** 偏移。
- **知识点**: 抗生素相关菌群失调, HAP 病原学, 二重感染
- **详见**: [[肺炎]]

#### Q6. 关于 COPD 的氨茶碱应用，说法正确的是？
- **来源**: 20预防基医临药
- **答案**: **氨茶碱**是黄嘌呤类支气管舒张剂，用于 COPD 稳定期的维持治疗。治疗窗窄（血药浓度 **8-12 μg/mL**），需监测血浆浓度；与喹诺酮类、大环内酯类合用时可升高茶碱血药浓度。不作为急性加重期首选。
- **知识点**: 氨茶碱, COPD 药物治疗, 茶碱类药物
- **详见**: [[慢性阻塞性肺疾病]]

#### Q7. 周围型肺癌的主要表现是？
- **来源**: 20预防基医临药
- **答案**: 早期多**无症状**，常在体检胸部影像学检查时发现。进展后可出现**咳嗽、胸痛、咯血**。周围型肺癌易侵犯胸膜引起胸痛及胸腔积液。病理类型以**腺癌**最常见。
- **知识点**: 周围型肺癌, 肺癌临床表现, 肺腺癌
- **详见**: [[肺癌]]

#### Q8. 肺炎链球菌肺炎的用药选择？
- **来源**: 20预防基医临药
- **答案**: 首选 **青霉素 G**。对青霉素过敏者可选**大环内酯类**（如红霉素、阿奇霉素）或**一/二代头孢菌素**。耐青霉素肺炎链球菌（PRSP）可选**呼吸氟喹诺酮类**（左氧氟沙星、莫西沙星）或万古霉素。
- **知识点**: 肺炎链球菌肺炎, 抗生素选择, 社区获得性肺炎
- **详见**: [[肺炎]]

#### Q9. 肺炎并发肺脓肿的药物治疗需加用什么药？
- **来源**: 20预防基医临药
- **答案**: 需加用**甲硝唑**或**克林霉素**覆盖厌氧菌。肺脓肿的常见病原体包括厌氧菌（如拟杆菌、消化链球菌），青霉素类对厌氧菌效果不佳，需联合抗厌氧菌药物。
- **知识点**: 肺脓肿, 厌氧菌感染, 抗生素联合用药
- **详见**: [[肺炎]]

#### Q10. 肺结核最常见的传播方式？
- **来源**: 20预防基医临药
- **答案**: **呼吸道飞沫传播**。开放性肺结核患者（痰涂片阳性）在咳嗽、打喷嚏、大声说话时排出含结核分枝杆菌的飞沫核，被他人吸入后导致感染。
- **知识点**: 肺结核传播途径, 飞沫传播, 结核分枝杆菌
- **详见**: [[肺结核]]

#### Q11. 考了 ARDS 机械通气的上机和撤机指征
- **来源**: 20临八
- **答案**: [根据考点提示整理] **上机指征**：PaO₂/FiO₂ ≤ **200mmHg**（轻中度 ARDS），重度 ≤ **100mmHg**；呼吸窘迫、RR > 30 次/分。**撤机指征**：原发病控制、氧合改善（PaO₂/FiO₂ > 200mmHg）、PEEP ≤ 5 cmH₂O、血流动力学稳定、自主呼吸试验（SBT）通过。
- **知识点**: ARDS, 机械通气, 上机指征, 撤机指征
- **详见**: [[急性呼吸窘迫综合征]], [[呼吸衰竭]]

#### Q12. 肺癌的副癌综合征中，哪个不是？
- **来源**: 20临八
- **答案**: **Horner 综合征不是副癌综合征**。Horner 综合征是肺上沟瘤（Pancoast 瘤）直接压迫颈交感神经所致，属局部侵犯表现。真正的副癌综合征包括：**抗利尿激素异常分泌综合征（SIADH）**、**库欣综合征**（异位 ACTH）、**高钙血症**（PTHrP）、**骨关节病**（杵状指）等。
- **知识点**: 副癌综合征, Horner 综合征, Pancoast 瘤, 肺癌
- **详见**: [[肺癌]]

#### Q13. 不是/不是 CRAB（碳青霉烯耐药鲍曼不动杆菌的英文缩写表述）[超纲提示]
- **来源**: 20临八
- **答案**: 本题涉及多重耐药菌的英文缩写（CRAB = Carbapenem-Resistant Acinetobacter baumannii），属于超纲内容。需注意区分：CRKP（碳青霉烯耐药肺炎克雷伯菌）、MRSA（耐甲氧西林金葡菌）、VRE（耐万古霉素肠球菌）、ESBL（超广谱β-内酰胺酶）等。
- **知识点**: 多重耐药菌, CRAB, 医院感染
- **详见**: [[肺炎]]

#### Q14. 考了肺结核的根本治疗
- **来源**: 21口腔
- **答案**: [根据考点提示整理] 肺结核的根本治疗是**抗结核化学药物治疗（化疗）**。原则：**早期、联合、适量、规律、全程**。初治方案：2HRZE/4HR（强化期 2 个月 HRZE + 巩固期 4 个月 HR）。
- **知识点**: 肺结核, 抗结核治疗原则
- **详见**: [[肺结核]]

#### Q15. 考了肺内低阻低压高容量（Swan-Ganz 相关）[超纲]
- **来源**: 21口腔
- **答案**: 本题为超纲内容，涉及肺动脉导管（Swan-Ganz 导管）的血流动力学参数。肺循环特点：低阻力、低压力、高容量。正常肺动脉压 15-30/4-12 mmHg，平均压 < 25 mmHg。
- **知识点**: 肺循环血流动力学
- **详见**: [[呼吸系统常见疾病的主要症状和体征]]


#### Q16. 肺炎最常见的感染类型是？（英文题：bac → 细菌性肺炎）
- **来源**: 21临五上
- **答案**: **细菌性肺炎**（Bacterial pneumonia），最常见病原体为肺炎链球菌（社区获得性肺炎首位）。
- **知识点**: 肺炎病原学, CAP, 细菌感染
- **详见**: [[肺炎]]


#### Q17. 咳臭痰、普通培养基无菌 — 提示什么感染？
- **来源**: 21临五上
- **答案**: **厌氧菌感染**。普通培养基在有氧条件下无菌生长，而痰液恶臭提示厌氧菌（如拟杆菌、消化链球菌）参与，常见于肺脓肿或吸入性肺炎。
- **知识点**: 厌氧菌感染, 肺脓肿, 痰培养
- **详见**: [[肺炎]]


#### Q18. 抗结核药物中损害听神经的是？
- **来源**: 21临五上
- **答案**: **链霉素**。链霉素属氨基糖苷类抗结核二线药物，主要不良反应为**耳毒性**（前庭和耳蜗损害，听力下降、耳鸣）和肾毒性。一线药物中异烟肼（周围神经炎）、利福平（肝损害）、吡嗪酰胺（关节痛/高尿酸）、乙胺丁醇（球后视神经炎）。
- **知识点**: 抗结核药物, 链霉素, 耳毒性, 抗结核药物不良反应
- **详见**: [[肺结核]]


#### Q19. COPD 的高危因素不包括？
- **来源**: 21临五上
- **答案**: **酗酒**不是 COPD 的高危因素。COPD 确定的危险因素：**吸烟**（最重要）、职业粉尘和化学物质、空气污染、α₁-抗胰蛋白酶缺乏（遗传）、呼吸道感染。
- **知识点**: COPD 危险因素, 吸烟
- **详见**: [[慢性阻塞性肺疾病]]


#### Q20. COPD 的并发症之一是？
- **来源**: 21临五上
- **答案**: **自发性气胸**。肺气肿患者肺大疱破裂可导致自发性气胸，表现为突发胸痛、呼吸困难加重，患侧呼吸音消失，需紧急胸腔穿刺抽气。
- **知识点**: COPD 并发症, 自发性气胸
- **详见**: [[慢性阻塞性肺疾病]], [[胸膜疾病]]


#### Q21. COPD 急性加重期的首要处理？
- **来源**: 21临五上
- **答案**: **增大通气量**（改善通气）。AECOPD 的核心治疗包括氧疗、支气管舒张剂、糖皮质激素、抗生素，严重者需无创或有创机械通气以增大通气量。
- **知识点**: AECOPD, 机械通气
- **详见**: [[慢性阻塞性肺疾病]]


#### Q22. 肺栓塞肝素抗凝应监测的指标？
- **来源**: 21临五上
- **答案**: **APTT 延长至正常值 2 倍**开始抗凝。普通肝素抗凝需严密监测 APTT（目标 1.5-2.5 倍正常值）；低分子肝素通常无需常规监测。
- **知识点**: 肺栓塞, 肝素抗凝, APTT 监测
- **详见**: [[肺血栓栓塞症]]


#### Q23. 支气管哮喘的机制是？（英文题）
- **来源**: 21临五上
- **答案**: **慢性气道炎症**（chronic airway inflammation）。多种炎症细胞（嗜酸性粒细胞、肥大细胞、T 淋巴细胞）和炎症介质参与的气道慢性炎症，导致气道高反应性和可逆性气流受限。
- **知识点**: 哮喘发病机制, 慢性炎症, 气道高反应性
- **详见**: [[支气管哮喘]]


#### Q24. 特发性肺纤维化特征性改变不包括？
- **来源**: 21临五上
- **答案**: **FEV₁/FVC < 70% 且 FEV₁ < 80%**, 这是 COPD 的肺功能诊断标准。IPF 的肺功能特点为**限制性通气障碍**（TLC↓、VC↓），与 COPD 的阻塞性通气障碍（FEV₁/FVC↓）不同。IPF 特征包括：杵状指、Velcro 啰音、进行性呼吸困难、预后差（中位生存 2-3 年）。
- **知识点**: IPF, 限制性通气障碍, Velcro 啰音
- **详见**: [[呼吸系统常见疾病的主要症状和体征]]


#### Q25. 肺癌的副癌综合征不包括？
- **来源**: 21临五上
- **答案**: **高镁血症**不是肺癌副癌综合征。真正的副癌综合征：SIADH（低钠血症）、Cushing 综合征（异位 ACTH）、高钙血症（PTHrP，无骨转移）、骨关节病（杵状指）等。
- **知识点**: 肺癌, 副癌综合征
- **详见**: [[肺癌]]


#### Q26. 肺癌的确诊检查不包括？
- **来源**: 21临五上
- **答案**: **痰培养**。肺癌确诊依靠**组织病理学检查**：支气管镜活检、CT 引导下经皮肺穿刺、痰脱落细胞学等。痰培养用于感染性疾病的病原学诊断。
- **知识点**: 肺癌诊断, 病理检查
- **详见**: [[肺癌]]


#### Q27. 目前治疗哮喘最有效的药物？（英文题）
- **来源**: 22临五上
- **答案**: **糖皮质激素**（Glucocorticoid）。吸入性糖皮质激素（ICS）是哮喘长期控制最有效的抗炎药物。急性发作期需联合速效 β₂ 激动剂。注意：β₂ 激动剂仅为症状缓解，非根本治疗。
- **知识点**: 哮喘, ICS, 糖皮质激素
- **详见**: [[支气管哮喘]]


#### Q28. 关于 COPD，哪项表述是错误的？
- **来源**: 22临五上
- **答案**: **"慢支和肺气肿没有气流受限也算 COPD"是错误的**。COPD 的诊断必要条件为**不完全可逆的气流受限**（FEV₁/FVC < 70%）。单纯的慢性支气管炎（无气流受限）或肺气肿（无气流受限）不属于 COPD。
- **知识点**: COPD 定义, 气流受限, 肺功能
- **详见**: [[慢性阻塞性肺疾病]]


#### Q29. 慢性肺动脉高压最重要的因素是？
- **来源**: 22临五上
- **答案**: **缺氧**（肺泡缺氧→肺血管收缩）。慢性缺氧是 COPD 等疾病导致肺动脉高压和肺心病的最重要机制。长期缺氧→肺血管平滑肌增生/收缩→肺动脉高压→右心负荷加重。
- **知识点**: 肺动脉高压, 缺氧性肺血管收缩, 肺心病
- **详见**: [[慢性肺源性心脏病]]

### 循环系统

#### Q30. 甲亢会导致哪种心律失常？
- **来源**: 23口腔
- **答案**: **心房颤动（房颤）**。甲亢时甲状腺激素过多使心肌细胞对儿茶酚胺敏感性增高，导致心房异位起搏点兴奋性增加，房颤是甲亢性心脏病最常见的心律失常表现。
- **知识点**: 甲亢, 房颤, 甲亢性心脏病
- **详见**: [[甲状腺功能亢进症]], [[心律失常]]

#### Q31. 对房性心动过速无效的药物是？
- **来源**: 23口腔, 22口腔
- **答案**: **利多卡因**。利多卡因为 **Ⅰb 类抗心律失常药**，主要作用于心室肌，对房性心律失常（包括房速、房颤、房扑）**无效**。房速的药物选择：腺苷、β 受体阻滞剂、钙通道阻滞剂（维拉帕米/地尔硫卓）、胺碘酮、普罗帕酮等。
- **知识点**: 抗心律失常药分类, 利多卡因, 房性心动过速
- **详见**: [[心律失常]]

#### Q32. 室性早搏的心电图特征？
- **来源**: 23口腔
- **答案**: ① **提前出现**的宽大畸形 QRS 波（时限 > **0.12s**）；② QRS 波前**无相关 P 波**；③ ST-T 方向与 QRS 主波方向**相反**；④ 代偿间歇**完全**（配对间期 + 代偿间歇 = 2 个正常 RR 间期）。
- **知识点**: 室性早搏, 心电图, 心律失常
- **详见**: [[心律失常]], [[心脏检查]]

#### Q33. 室速处理正确的是？（选项含"电复律"为干扰项）
- **来源**: 20临八
- **答案**: [根据考点提示整理] 室性心动过速的处理取决于血流动力学状态：① **血流动力学不稳定**→ **同步直流电复律**；② **稳定者**→ 药物复律（**胺碘酮**或利多卡因静脉注射）。室速不应用电复律的表述有误：不稳定者首选电复律而非药物。
- **知识点**: 室性心动过速, 电复律, 胺碘酮
- **详见**: [[心律失常]]

#### Q34. 下列哪些瓣膜病会导致心脏后负荷加重？
- **来源**: 20预防基医临药
- **答案**: **主动脉瓣狭窄**和**肺动脉瓣狭窄**。后负荷即压力负荷，狭窄性瓣膜病变使心室射血阻力增大。主动脉瓣狭窄增加左心室后负荷，导致左心室向心性肥厚。
- **知识点**: 瓣膜病, 心脏后负荷, 主动脉瓣狭窄
- **详见**: [[心脏瓣膜病]]

#### Q35. 高血压的诊断标准？
- **来源**: 20预防基医临药
- **答案**: 在未使用降压药物情况下，**非同日 3 次测量**，**收缩压 ≥ 140mmHg 和（或）舒张压 ≥ 90mmHg**。分级：1级 140-159/90-99；2级 160-179/100-109；3级 ≥ 180/≥ 110mmHg。
- **知识点**: 高血压诊断标准, 血压分级
- **详见**: [[高血压]]

#### Q36. 室性心动过速的心电图特征表现？
- **来源**: 20预防基医临药
- **答案**: **心室夺获**和**室性融合波**是室速最具特征性的心电图表现，可据此与室上速伴差传鉴别。其他特征：宽大畸形 QRS（> 0.12s）、房室分离、胸前导联 QRS 波同向性。
- **知识点**: 室速, 心室夺获, 室性融合波, 心电图
- **详见**: [[心律失常]], [[心脏检查]]

#### Q37. 心绞痛的发生部位？
- **来源**: 20预防基医临药
- **答案**: **胸骨中上段后方**，可放射至左肩、左臂内侧达无名指和小指，或至颈、咽、下颌部。典型心绞痛呈**压迫性、紧缩性闷痛**，持续 **3-5 分钟**，休息或含服硝酸甘油可缓解。
- **知识点**: 心绞痛, 冠心病, 胸痛鉴别
- **详见**: [[冠心病]]

#### Q38. 风湿性瓣膜心脏病最常见的病变？
- **来源**: 20预防基医临药
- **答案**: **二尖瓣病变**（二尖瓣狭窄最常见）。风湿热反复发作导致瓣膜纤维化、钙化、粘连，以二尖瓣最常受累（约 70%），其次为二尖瓣合并主动脉瓣病变。
- **知识点**: 风湿性心脏病, 二尖瓣狭窄, 瓣膜病
- **详见**: [[心脏瓣膜病]]

#### Q39. 扩张性心肌病的主要特征？
- **来源**: 20预防基医临药
- **答案**: **心脏扩大**（以左心室或双心室扩大为主），伴收缩功能障碍（LVEF 降低）。临床表现为进行性心力衰竭、心律失常、血栓栓塞及猝死。诊断需排除其他特异性心肌病。
- **知识点**: 扩张性心肌病, 心力衰竭, 心脏扩大
- **详见**: [[心力衰竭]]

#### Q40. 哪个是室速心电图的最重要特征？
- **来源**: 20预防基医临药
- **答案**: **房室分离**是室速最重要的心电图特征。心房由窦房结控制、心室由异位起搏点控制，两者独立活动。其他特征包括 QRS > 0.12s、心室夺获、室性融合波。
- **知识点**: 室性心动过速, 房室分离, 心电图
- **详见**: [[心律失常]]

#### Q41. 高血压测量最标准的方法是？
- **来源**: 20预防基医临药
- **答案**: **非同日测量多次**（至少 3 次），取平均值。测量前安静休息至少 5 分钟，测量时袖带与心脏平齐（肱动脉处），使用经校准的标准血压计。
- **知识点**: 血压测量, 高血压诊断
- **详见**: [[高血压]]

#### Q42. 原发性心肌病的特点？
- **来源**: 20预防基医临药
- **答案**: [根据考点提示整理] 原发性心肌病指病变局限于心肌，排除高血压、冠心病、瓣膜病、先天性心脏病等明确原因。分为三型：**扩张型**（最常见，心脏扩大 + 收缩障碍）、**肥厚型**（心室壁肥厚，舒张障碍）、**限制型**（舒张障碍）。
- **知识点**: 原发性心肌病, 扩张型心肌病, 肥厚型心肌病
- **详见**: [[心力衰竭]]

#### Q43. 心源性水肿最先出现的部位？
- **来源**: 20预防基医临药
- **答案**: **下肢、脚踝部位**（下垂部位）。右心衰竭导致体循环淤血，静脉压增高，液体首先积聚于身体最低垂部位（重力依赖）。区别于肾源性水肿（眼睑、颜面最先出现）和肝源性水肿（以腹水为主）。
- **知识点**: 心源性水肿, 心力衰竭, 水肿鉴别
- **详见**: [[心力衰竭]]

#### Q44. 高血压合并糖尿病不能用的降压药？
- **来源**: 20临八
- **答案**: [根据考点提示整理] 高血压合并糖尿病患者应**避免或慎用**大剂量**噻嗪类利尿剂**和**β 受体阻滞剂**（非选择性）。利尿剂可致胰岛素抵抗加重、血糖升高、电解质紊乱；非选择性 β 阻滞剂掩盖低血糖症状。优先选用 **ACEI/ARB**（肾脏保护）。
- **知识点**: 高血压合并糖尿病, 降压药选择
- **详见**: [[高血压]], [[糖尿病]]

#### Q45. 窦性心动过缓，心率不低于 50 次/分，常采取的措施是？
- **来源**: 22口腔
- **答案**: **不需特殊治疗**。无症状窦性心动过缓（心率 50-60 次/分）常见于健康人、运动员，通常无需干预。仅在出现症状（头晕、黑矇、晕厥）或心率 < 40 次/分时考虑阿托品、起搏器治疗。
- **知识点**: 窦性心动过缓, 心律失常处理原则
- **详见**: [[心律失常]]

#### Q46. 以下高血压并发症描述不正确的是？
- **来源**: 22口腔
- **答案**: **胰腺炎**不是高血压的常见并发症。高血压主要并发症为：**脑卒中**（脑出血、脑梗死）、**心脏损害**（左心室肥厚、冠心病、心力衰竭）、**肾脏损害**（高血压肾病、慢性肾衰竭）、**眼底病变**（视网膜动脉硬化）。
- **知识点**: 高血压并发症, 靶器官损害
- **详见**: [[高血压]]

#### Q47. 心率不低于 50 次/分的窦性心动过缓需特殊治疗吗？+ 考了室速、室颤、高钾血症严重程度
- **来源**: 21口腔
- **答案**: [根据考点提示整理] 无症状窦缓（≥ 50 次/分）不需治疗。**高钾血症严重程度**按血钾水平分：轻度 5.5-6.0 mmol/L，中度 6.1-7.0 mmol/L，重度 **> 7.0 mmol/L**（可引起致死性心律失常如室颤、心脏骤停）。**室颤**需立即非同步直流电除颤。
- **知识点**: 窦性心动过缓, 高钾血症, 室颤
- **详见**: [[心律失常]], [[水电解质代谢和酸碱平衡失常]]


#### Q48. 房颤药物首选？
- **来源**: 21临五上
- **答案**: **非二氢吡啶类钙通道阻滞剂**（**维拉帕米**或地尔硫卓），用于控制房颤的心室率。伴心衰时可选用地高辛或胺碘酮。血流动力学不稳定者首选同步直流电复律。
- **知识点**: 房颤, 心室率控制, 钙通道阻滞剂
- **详见**: [[心律失常]]


#### Q49. 阵发性室上速的特点不含？
- **来源**: 21临五上
- **答案**: **心律不齐**不是 PSVT 的特点。PSVT 特征为**突发突止、心律绝对规则**、心率 150-250 次/分、QRS 波正常（除非合并差传/束支阻滞）。
- **知识点**: 阵发性室上速, 心律规则, ECG 特征
- **详见**: [[心律失常]]


#### Q50. 急性心梗后猝死（阿斯综合征），最可能是什么心律失常？
- **来源**: 21临五上
- **答案**: **室颤**。AMI 后 24h 内最常见致死性心律失常为室颤，导致心输出量骤降至零 → 阿斯综合征（意识丧失、抽搐）。需立即非同步直流电除颤。
- **知识点**: 室颤, 阿斯综合征, 心源性猝死
- **详见**: [[急性心肌梗死]], [[心律失常]]


#### Q51. 主动脉瓣狭窄的典型症状？
- **来源**: 21临五上
- **答案**: **劳力性晕厥**。主动脉瓣狭窄三联征：**心绞痛 + 晕厥 + 心力衰竭**。晕厥机制：运动时外周血管扩张而狭窄的主动脉瓣限制心输出量增加 → 脑供血不足。
- **知识点**: 主动脉瓣狭窄, 晕厥, 三联征
- **详见**: [[心脏瓣膜病]]


#### Q52. 肥厚型心肌病的猝死诱因？
- **来源**: 21临五上
- **答案**: **剧烈运动**。肥厚型心肌病是年轻运动员猝死的最常见原因。运动时心肌收缩增强 → 左心室流出道梗阻加重 → 心输出量骤降 → 室性心律失常 → 猝死。
- **知识点**: 肥厚型心肌病, 运动禁忌, 心源性猝死
- **详见**: [[心力衰竭]]


#### Q53. 心包填塞的首选处理？
- **来源**: 21临五上
- **答案**: **心包穿刺引流**。急性心包填塞特征性表现为 Beck 三联征（低血压 + 颈静脉怒张 + 心音遥远），需紧急心包穿刺减压。
- **知识点**: 心包填塞, Beck 三联征, 心包穿刺
- **详见**: [[心脏瓣膜病]]


#### Q54. 高血压 190/110mmHg，伴眼底病变 — 分级与危险分层？
- **来源**: 21临五上
- **答案**: **高血压 3 级（极高危）**。血压 ≥ 180/110mmHg → 3 级；合并靶器官损害（眼底病变）→ 极高危。需立即启动药物治疗。
- **知识点**: 高血压分级, 危险分层
- **详见**: [[高血压]]


#### Q55. 56 岁，充血性心衰，有哮喘+高尿酸，降压/心衰用药选择？
- **来源**: 21临五上
- **答案**: [根据考点提示整理] 应避免：① β 阻滞剂（加重哮喘）；② 噻嗪类利尿剂（升高尿酸）。优先选择：ACEI/ARB（心衰和肾脏保护），合用选择性 β₁ 阻滞剂需谨慎评估。
- **知识点**: 心衰合并症治疗, β阻滞剂禁忌症, 利尿剂选择
- **详见**: [[心力衰竭]], [[高血压]]


#### Q56. 瓣膜病最容易累及哪个瓣膜？（英文题）
- **来源**: 22临五上
- **答案**: **二尖瓣**。风湿性心脏病最常累及二尖瓣（约 70%），其次为二尖瓣合并主动脉瓣病变。退行性瓣膜病则多见于主动脉瓣。
- **知识点**: 瓣膜病, 二尖瓣, 风湿性心脏病
- **详见**: [[心脏瓣膜病]]


#### Q57. 洋地黄的禁忌症？
- **来源**: 22临五上
- **答案**: **肥厚梗阻型心肌病伴房颤**（洋地黄增加心肌收缩力 → 加重流出道梗阻）。其他禁忌症/慎用：预激综合征合并房颤（洋地黄缩短旁路不应期可能加速室率→室颤）、严重窦房传导阻滞/高度房室传导阻滞（无起搏器保护时）、急性心梗 24h 内。
- **知识点**: 洋地黄禁忌症, 肥厚型心肌病
- **详见**: [[心力衰竭]], [[心律失常]]


#### Q58. 室速，血流动力学不稳定，首选？
- **来源**: 22临五上
- **答案**: **同步直流电复律**（紧急电复律）。血流动力学不稳定（低血压、休克、意识障碍）的室速为**电复律的绝对适应症**，药物治疗仅用于稳定型室速。
- **知识点**: 室速, 同步直流电复律, 血流动力学
- **详见**: [[心律失常]]


#### Q59. 洋地黄使用时需警惕的心电图表现？
- **来源**: 22临五上
- **答案**: [根据考点提示整理] 洋地黄中毒的心电图表现：① **室性早搏二联律**（最常见中毒性心律失常）；② 非阵发性交界性心动过速（PAT with block）；③ 房速伴房室传导阻滞；④ 双向性室速。出现任一种均需立即停药并处理。
- **知识点**: 洋地黄中毒, 心律失常, 心电图
- **详见**: [[心力衰竭]], [[心律失常]]

### 消化系统

#### Q60. UC 和 CD 的病理鉴别要点？
- **来源**: 23口腔
- **答案**: UC（溃疡性结肠炎）：**连续性弥漫性**病变，限于**黏膜及黏膜下层**，**直肠必受累**，向近端蔓延，有**假息肉**形成。CD（克罗恩病）：**节段性/跳跃性**分布，**透壁性炎症**，**直肠多不受累**，特征性表现为**纵行溃疡 + 鹅卵石样外观**，可形成瘘管和狭窄。
- **知识点**: 溃疡性结肠炎, 克罗恩病, 炎症性肠病病理鉴别
- **详见**: [[溃疡性结肠炎]], [[克罗恩病]], [[炎症性肠病]]

#### Q61. 肝硬化腹水主要的抗利尿激素（拮抗药）是什么？
- **来源**: 23口腔
- **答案**: [根据考点提示整理] 肝硬化腹水治疗中最重要的利尿药为**螺内酯**（安体舒通，抗醛固酮制剂）。肝硬化患者继发性醛固酮增多，螺内酯拮抗醛固酮而利尿。若单用效果不佳，可联合呋塞米（螺内酯：呋塞米 = **100mg：40mg**）。
- **知识点**: 肝硬化腹水, 抗醛固酮治疗, 螺内酯
- **详见**: [[肝硬化]]

#### Q62. 肝硬化腹水的治疗中不宜采用哪项？
- **来源**: 22口腔
- **答案**: **反复大量放腹水**。大量放腹水可导致有效血容量急剧下降，诱发**肝肾综合征**、**肝性脑病**和电解质紊乱。仅在难治性大量腹水时可考虑，每次放液不超过 **4-6 L**，并需同时输注白蛋白。
- **知识点**: 肝硬化腹水, 肝肾综合征, 治疗原则
- **详见**: [[肝硬化]], [[肝肾综合征]]

#### Q63. 关于肝性脑病（肝性昏迷）的处理，错误的是？
- **来源**: 22口腔
- **答案**: **用肥皂水灌肠**是错误的。肥皂水为碱性液体，可促进肠道氨的吸收（NH₄⁺ → NH₃），加重肝性脑病。应使用**弱酸性液体**（如乳果糖溶液或稀醋酸）灌肠，减少氨的吸收。
- **知识点**: 肝性脑病, 氨中毒机制, 灌肠液选择
- **详见**: [[肝性脑病]], [[肝硬化]]

#### Q64. 胃窦部溃疡最常见的病因是？
- **来源**: 20预防基医临药
- **答案**: **幽门螺杆菌（Hp）感染**。消化性溃疡的两大主因为 Hp 感染和 NSAIDs 药物使用。胃窦部溃疡尤其与 Hp 感染密切相关，根除 Hp 可显著降低溃疡复发率。
- **知识点**: 消化性溃疡, 幽门螺杆菌, 胃溃疡病因
- **详见**: [[消化性溃疡]]

#### Q65. 克罗恩病最常发生的部位是？
- **来源**: 20预防基医临药
- **答案**: **回盲部**（末端回肠和邻近结肠）。CD 可累及从口腔至肛门的任何消化道部位，但以**末端回肠和右半结肠**最常见（约 70%）。
- **知识点**: 克罗恩病, 回盲部, 消化道病变分布
- **详见**: [[克罗恩病]], [[炎症性肠病]]

#### Q66. 肝硬化的抗病毒药物是？
- **来源**: 20预防基医临药
- **答案**: **恩替卡韦**（ETV）或**替诺福韦**（TDF/TAF）为一线核苷（酸）类似物。对于乙肝后肝硬化，抗病毒治疗可抑制 HBV 复制、延缓或逆转肝纤维化、降低 HCC 发生率。需长期甚至终身服药。
- **知识点**: 肝硬化, 抗病毒治疗, 核苷类似物
- **详见**: [[肝硬化]], [[病毒性肝炎]]

#### Q67. 肝静脉压力梯度（HVPG）说法正确的是？
- **来源**: 20预防基医临药
- **答案**: [根据考点提示整理] HVPG 是评估门静脉压力的金标准，正常值 **3-5 mmHg**。HVPG **≥ 10 mmHg** 为临床显著性门静脉高压（可出现食管静脉曲张）；**≥ 12 mmHg** 易发生静脉曲张破裂出血；**≥ 20 mmHg** 预示出血难以控制、预后差。
- **知识点**: 门静脉高压, HVPG, 食管静脉曲张
- **详见**: [[肝硬化]]

- **答案**: 见[[#Q16. 肝肾综合征（HRS）|名词解释 - 肝肾综合征]]。
- **详见**: [[肝肾综合征]]

#### Q69. 肝性脑病的临床分期？
- **来源**: 18预防
- **答案**: **0 期**（轻微肝性脑病）：无明显症状，仅心理/智力测试异常。**1 期**（前驱期）：轻度性格改变、睡眠倒错，扑翼样震颤可引出。**2 期**（昏迷前期）：嗜睡、行为异常、定向力障碍，扑翼样震颤易引出。**3 期**（昏睡期）：昏睡但可唤醒、语无伦次，扑翼样震颤存在。**4 期**（昏迷期）：昏迷不能唤醒，扑翼样震颤消失。
- **知识点**: 肝性脑病, 临床分期, West-Haven 分级
- **详见**: [[肝性脑病]]

#### Q70. 门脉高压性胃病（名词解释高频考点）
- **答案**: 见[[#Q17. 门脉高压性胃病|名词解释 - 门脉高压性胃病]]。
- **详见**: [[肝硬化]]


#### Q71. 慢性胃炎最主要的病因？（英文题）
- **来源**: 21临五上
- **答案**: **幽门螺杆菌（Hp）感染**。Hp 是慢性胃炎和消化性溃疡的最主要病因，WHO 已将 Hp 列为 I 类致癌物（与胃癌相关）。
- **知识点**: 慢性胃炎, Hp, 胃癌
- **详见**: [[消化性溃疡]]


#### Q72. CD 确诊最重要的依据？
- **来源**: 21临五上
- **答案**: **活检见非干酪样肉芽肿**（排除其他疾病后）。这是 CD 最具特征性的病理学改变，是与其他肠道肉芽肿性疾病鉴别诊断的关键。
- **知识点**: 克罗恩病, 非干酪样肉芽肿, 病理诊断
- **详见**: [[克罗恩病]], [[炎症性肠病]]


#### Q73. IBS 与什么因素有关？
- **来源**: 21临五上, 22临五上
- **答案**: **焦虑/应激**（精神心理因素）。IBS 是典型的心身疾病，焦虑、抑郁等精神心理因素可诱发或加重症状。诊断标准（罗马 IV）：反复腹痛 ≥ 1 天/周持续 3 个月 + 伴随排便频率/性状改变。
- **知识点**: IBS, 心身疾病, 焦虑
- **详见**: [[肠易激综合征]]


#### Q74. NAFLD 轻度高脂血症的首选治疗？
- **来源**: 21临五上
- **答案**: **生活方式干预**（减重、饮食控制、运动）。体重下降 **7-10%** 即可显著改善肝脏脂肪变性和炎症。药物治疗（维生素 E、吡格列酮）仅用于确诊 NASH 且生活方式干预无效者。
- **知识点**: NAFLD, 生活方式干预, 减重
- **详见**: [[非酒精性肝病]]


#### Q75. 门静脉高压的临床表现？
- **来源**: 21临五上
- **答案**: **脾大 + 侧支循环开放（食管胃底静脉曲张、腹壁静脉曲张、痔静脉曲张）+ 腹水**。是肝硬化失代偿期的典型表现。
- **知识点**: 门静脉高压, 侧支循环, 脾大
- **详见**: [[肝硬化]]


#### Q76. 肝性脑病的诱因不包括？
- **来源**: 21临五上
- **答案**: **灌肠**（尤其是食醋灌肠/乳果糖灌肠）是肝性脑病的**治疗措施**，不是诱因。诱因包括：上消化道出血、高蛋白饮食、感染、电解质紊乱、镇静药、便秘、手术等。
- **知识点**: 肝性脑病, 诱因, 灌肠治疗
- **详见**: [[肝性脑病]]


#### Q77. 急性胰腺炎血清淀粉酶升高的时间窗？
- **来源**: 21临五上
- **答案**: **起病后 6-12 小时**开始升高，**24-48 小时**达高峰，**3-5 天**恢复正常。血清脂肪酶升高较淀粉酶晚（起病 24h 后），但特异性和持续时间更长（持续 7-10 天）。
- **知识点**: 急性胰腺炎, 淀粉酶, 时间窗
- **详见**: [[急性胰腺炎]]


#### Q78. SAAG ≥ 11 g/L 最可能的诊断？
- **来源**: 22临五上
- **答案**: **门静脉高压**。SAAG（血清-腹水白蛋白梯度）= 血清白蛋白 - 腹水白蛋白，**≥ 11 g/L** 提示门静脉高压（如肝硬化、肝静脉阻塞），**< 11 g/L** 提示非门脉高压性腹水（如恶性肿瘤、结核、胰腺炎）。
- **知识点**: SAAG, 门静脉高压, 腹水鉴别
- **详见**: [[肝硬化]], [[肝性腹水]]

### 肾脏系统

#### Q79. 真性细菌尿（菌尿）+ 发热 + 肾区叩击痛，提示什么疾病？
- **来源**: 22口腔
- **答案**: **急性肾盂肾炎**。典型三联征：**发热、寒战 + 尿路刺激症状（尿频/尿急/尿痛）+ 肾区叩击痛**。真性细菌尿（中段尿培养菌落计数 ≥ 10⁵/mL）是确诊依据。
- **知识点**: 急性肾盂肾炎, 真性细菌尿, 肾区叩击痛
- **详见**: [[肾盂肾炎]]

#### Q80. 尿毒症最早和最突出的表现是？
- **来源**: 20预防基医临药
- **答案**: **胃肠道表现**：食欲不振、恶心、呕吐、口腔有尿味。尿毒症时尿素分解产生的氨刺激消化道黏膜所致。其次常见的为皮肤瘙痒、贫血、水肿等。
- **知识点**: 尿毒症, 慢性肾衰竭, 胃肠道症状
- **详见**: [[慢性肾衰竭]]

#### Q81. 关于慢性肾盂肾炎的治疗，说法正确的是？
- **来源**: 20预防基医临药
- **答案**: [根据考点提示整理] 慢性肾盂肾炎治疗原则：① 寻找并解除易感因素（梗阻、反流）；② **长疗程**抗生素治疗（4-6 周）；③ 治疗后定期随访尿培养；④ 保护肾功能、控制高血压；⑤ 顽固性病例需考虑预防性抗生素（小剂量睡前服用 6 个月）。
- **知识点**: 慢性肾盂肾炎, 抗生素治疗, 尿路感染
- **详见**: [[肾盂肾炎]]

#### Q82. UTI 和 urethral syndrome（尿道综合征）的区别？
- **来源**: 20临八
- **答案**: [根据考点提示整理] 关键区别在于**真性细菌尿**的有无：UTI（尿路感染）有真性细菌尿（中段尿培养 ≥ 10⁵ CFU/mL）。尿道综合征有尿路刺激症状但**中段尿培养阴性**（无细菌尿或计数 < 10³/mL），多见于女性，可能与衣原体、解脲脲原体感染或非感染因素有关。
- **知识点**: UTI, 尿道综合征, 真性细菌尿, 尿培养
- **详见**: [[肾盂肾炎]], [[泌尿系感染]]

#### Q83. 狼疮肾炎预后和分型有关吗？
- **来源**: 21口腔
- **答案**: [根据考点提示整理] **有关**。狼疮肾炎（LN）按 WHO/ISN 分型：Ⅰ型（轻微系膜型）→ Ⅵ型（硬化型），**预后与病理分型密切相关**。Ⅳ 型（弥漫增殖型）最常见且最严重，需积极糖皮质激素 + 免疫抑制剂治疗。
- **知识点**: 狼疮肾炎, SLE, 肾脏病理分型
- **详见**: [[系统性红斑狼疮]], [[继发性肾病]]


#### Q84. 鉴别肾前性和肾性 AKI 最有用的指标？（英文题：FENa）
- **来源**: 22临五下
- **答案**: **尿钠排泄分数（FENa）**。FENa = (尿钠/血钠) / (尿肌酐/血肌酐) × 100%。**FENa < 1%** 提示肾前性 AKI（肾小管重吸收增强）；**FENa > 2%** 提示肾性/ATN（肾小管损伤重吸收障碍）。
- **知识点**: FENa, 肾前性 AKI, ATN
- **详见**: [[慢性肾衰竭]]


#### Q85. 间质性肾炎的病理学特点？（英文题）
- **来源**: 22临五下
- **答案**: **炎症细胞在肾间质堆积**（单核细胞、淋巴细胞浸润为主），肾小管萎缩/扩张，而**肾小球通常基本正常**。临床表现以肾小管功能障碍（夜尿增多、尿液浓缩障碍）为突出特征。
- **知识点**: 间质性肾炎, 肾小管, 炎症细胞
- **详见**: [[继发性肾病]]


#### Q86. 局灶节段性肾小球硬化（FSGS）的病理特点？
- **来源**: 22临五下
- **答案**: **IgM 和 C3 团块状/颗粒状在硬化区沉积**。FSGS 为肾病综合征的重要病理类型之一，光镜下见部分肾小球（局灶）和肾小球部分毛细血管襻（节段）呈硬化性病变。激素治疗反应差，易进展至 ESRD。
- **知识点**: FSGS, 肾病综合征, IgM 沉积
- **详见**: [[原发性肾小球疾病]]

#### Q87. 成人失钾的最主要原因？
- **来源**: 20预防基医临药
- **答案**: **经肾脏失钾**，最常见于**使用排钾利尿剂**（如呋塞米、氢氯噻嗪）。肾脏远曲小管钠-钾交换增加导致尿钾排出过多。其他经肾失钾原因：原发性醛固酮增多症、库欣综合征、肾小管酸中毒。
- **知识点**: 低钾血症, 经肾失钾, 利尿剂, 钾代谢
- **详见**: [[水电解质代谢和酸碱平衡失常]]

#### Q88. 高钾血症严重程度分级（超纲考点）
- **来源**: 21口腔
- **答案**: [根据考点提示整理] 血钾正常 3.5-5.5 mmol/L。轻度 5.5-6.0 mmol/L，中度 6.1-7.0 mmol/L，重度 **> 7.0 mmol/L**。重度高钾可导致**致死性心律失常**（T 波高耸、P 波消失、QRS 增宽→室颤→心脏骤停）。
- **知识点**: 高钾血症, 心电图改变, 水电解质平衡
- **详见**: [[水电解质代谢和酸碱平衡失常]], [[心律失常]]

#### Q89. 血浆晶体渗透压主要取决于？
- **来源**: 20预防基医临药
- **答案**: **血清钠浓度**（[Na⁺] × 2 + 葡萄糖/18 + 尿素氮/2.8）。Na⁺ 是细胞外液最主要的阳离子，贡献了约 95% 的晶体渗透压，是维持血浆晶体渗透压的决定性因素。
- **知识点**: 晶体渗透压, 血清钠, 体液平衡
- **详见**: [[水电解质代谢和酸碱平衡失常]]


### 血液系统

#### Q90. 不是 ITP（特发性血小板减少性紫癜）诊断原则的是？
- **来源**: 23口腔
- **答案**: [根据考点提示整理] ITP 诊断原则：① 至少 **2 次**血常规示血小板计数减少（< 100 × 10⁹/L），而红细胞和白细胞正常；② **骨髓巨核细胞**正常或增多伴成熟障碍；③ 排除其他继发性血小板减少（药物、感染、SLE、MDS 等）；④ 脾脏一般不大（或仅轻度增大）。"外周血涂片见破碎红细胞增多" **不是** ITP 的诊断要点（那是 TTP/HUS 的特征）。
- **知识点**: ITP, 血小板减少, 骨髓象, 巨核细胞
- **详见**: [[特发性血小板减少性紫癜]], [[出血性疾病]]

#### Q91. 关于 DIC 不正确的是？
- **来源**: 23口腔
- **答案**: [根据考点提示整理] DIC 的正确特征：① **血小板进行性下降**；② 凝血酶原时间（PT）、活化部分凝血活酶时间（APTT）**延长**；③ 纤维蛋白原**降低**；④ D-二聚体和 FDP **显著升高**；⑤ 外周血涂片可见**裂红细胞**（微血管病性溶血）。不正确的选项通常是与上述相反的表述或"血小板计数正常"。
- **知识点**: DIC, 血小板减少, 凝血功能障碍, D-二聚体
- **详见**: [[弥散性血管内凝血]]

#### Q92. 什么疾病会导致 NAP（中性粒细胞碱性磷酸酶）降低？
- **来源**: 23口腔
- **答案**: **慢性粒细胞白血病（CML）**。CML 时 NAP 活性显著降低或阴性，这是 CML 与类白血病反应的重要鉴别点之一（后者 NAP 活性增高）。其他 NAP 降低的疾病：PNH（阵发性睡眠性血红蛋白尿症）。
- **知识点**: NAP, 慢性粒细胞白血病, 类白血病反应鉴别
- **详见**: [[慢性粒细胞白血病]], [[慢性白血病]]

#### Q93. 细胞低色素性贫血最常见的原因是？
- **来源**: 22口腔
- **答案**: **缺铁性贫血**。低色素性贫血（MCV < 80fL, MCH < 27pg, MCHC < 320g/L）中以缺铁性贫血最常见。病因：铁摄入不足、吸收障碍、慢性失血（消化道、月经过多）。
- **知识点**: 小细胞低色素性贫血, 缺铁性贫血, MCV/MCH/MCHC
- **详见**: [[缺铁性贫血]], [[贫血]]

#### Q94. 淋巴瘤的确诊依据是？
- **来源**: 22口腔
- **答案**: **组织病理学活检**（淋巴结完整切除活检）。免疫组化 + 分子病理学分型。不可依赖细针穿刺细胞学（FNAC）单独诊断。确诊后进行 Ann Arbor 分期（含全身 CT 和 PET-CT）。
- **知识点**: 淋巴瘤, 淋巴结活检, 病理诊断
- **详见**: [[淋巴瘤]]

#### Q95. 弥漫性 DIC 以下哪项正确？
- **来源**: 22口腔
- **答案**: **血小板进行性下降**是 DIC 的特征性实验室改变。DIC 时凝血因子和血小板大量消耗，导致出血倾向。其他正确特征：PT/APTT 延长、纤维蛋白原降低、D-二聚体和 FDP 显著升高、外周血裂红细胞。
- **知识点**: DIC, 消耗性凝血病, 血小板
- **详见**: [[弥散性血管内凝血]]

#### Q96. 弥漫性大 B 细胞淋巴瘤（DLBCL）的首选免疫化疗方案？
- **来源**: 22口腔
- **答案**: **R-CHOP 方案**（利妥昔单抗 + 环磷酰胺、多柔比星、长春新碱、泼尼松）。共 6-8 个周期。DLBCL 是最常见的非霍奇金淋巴瘤类型，R-CHOP 可使约 60-70% 患者获得长期缓解。
- **知识点**: DLBCL, R-CHOP, 非霍奇金淋巴瘤治疗
- **详见**: [[淋巴瘤]]

#### Q97. 非特异酯酶染色阳性，可被氟化钠抑制的是？
- **来源**: 22口腔
- **答案**: **原始单核细胞**（急性单核细胞白血病/急性粒-单核细胞白血病的单核系细胞）。非特异酯酶（NSE）在单核系细胞为阳性且可被 NaF 抑制，粒系细胞则为阴性或不被 NaF 抑制。这是 AML-M5 和 M4 的细胞化学鉴别要点。
- **知识点**: 非特异酯酶, 原始单核细胞, AML 分型, 细胞化学染色
- **详见**: [[急性白血病]]

#### Q98. 缺铁性贫血的实验室检查结果（最典型的）？
- **来源**: 20临八
- **答案**: [根据考点提示整理] ① 血象：**小细胞低色素性贫血**（MCV↓, MCH↓, MCHC↓）；② **血清铁（SI）↓**，总铁结合力（TIBC）**↑**，转铁蛋白饱和度（TS）**↓**（< 15%）；③ **血清铁蛋白（SF）↓**（< 12 μg/L，是最敏感的指标）；④ 骨髓铁染色：**细胞外铁消失**，铁粒幼细胞 < 15%。
- **知识点**: 缺铁性贫血, 铁代谢, 血清铁蛋白
- **详见**: [[缺铁性贫血]]

#### Q99. 最常引起中枢神经系统白血病的是？
- **来源**: 20预防基医临药
- **答案**: **急性淋巴细胞白血病（ALL）**。ALL 的白血病细胞易侵犯 CNS（脑膜白血病），尤其儿童 ALL。需常规行鞘内注射化疗（甲氨喋呤 + 阿糖胞苷 + 地塞米松）进行 CNS 白血病预防。
- **知识点**: CNS 白血病, ALL, 鞘内化疗
- **详见**: [[急性白血病]]

#### Q100. 霍奇金淋巴瘤：最早累及什么淋巴结？
- **来源**: 20临八
- **答案**: [根据考点提示整理] 霍奇金淋巴瘤（HL）最早通常累及**颈部淋巴结**（单侧、无痛性进行性肿大），常向邻近淋巴结区依次扩散。组织学特征为 **RS 细胞**（Reed-Sternberg 细胞，镜影细胞）。治疗方案：ABVD 方案。
- **知识点**: 霍奇金淋巴瘤, 颈部淋巴结, RS 细胞, ABVD
- **详见**: [[淋巴瘤]]

#### Q101. 下列属于 T 细胞淋巴瘤的是？
- **来源**: 20预防基医临药
- **答案**: **间变大细胞淋巴瘤**（ALCL）属于 T 细胞淋巴瘤。弥漫性大 B 细胞淋巴瘤（DLBCL）、滤泡性淋巴瘤、套细胞淋巴瘤、边缘区淋巴瘤、Burkitt 淋巴瘤均为 B 细胞来源。
- **知识点**: T 细胞淋巴瘤, 间变大细胞淋巴瘤, NHL 分类
- **详见**: [[淋巴瘤]]

#### Q102. 小细胞性贫血中最常见的是？
- **来源**: 20预防基医临药
- **答案**: **缺铁性贫血**。小细胞性贫血包括：缺铁性贫血（最常见）、珠蛋白生成障碍性贫血（地中海贫血）、铁粒幼细胞性贫血、慢性病性贫血（部分为小细胞性）。其中缺铁性贫血占绝对多数。
- **知识点**: 小细胞性贫血, 缺铁性贫血, 贫血分类
- **详见**: [[缺铁性贫血]], [[贫血]]

#### Q103. 考了慢性肾小球肾炎、巨脾（慢粒）、霍奇金淋巴瘤（题干分析分期后选治疗）
- **来源**: 18预防
- **答案**: [根据考点提示整理] **慢粒（CML）巨脾**：巨脾是 CML 慢性期的特征体征（可达脐下甚至盆腔）。CML 分期：慢性期→加速期→急变期（急粒变/急淋变）。**霍奇金淋巴瘤分期**：Ⅰ期单区、Ⅱ期同侧多区、Ⅲ期双侧、Ⅳ期弥漫脏器侵犯。分期决定治疗策略和预后。
- **知识点**: CML 巨脾, 霍奇金淋巴瘤分期
- **详见**: [[慢性粒细胞白血病]], [[淋巴瘤]]


#### Q104. 巨幼细胞性贫血形态学中最具代表性的是？
- **来源**: 22临五下
- **答案**: **大细胞正色素性贫血（MCV > 100fL + MCH 升高的巨卵圆形红细胞）**，骨髓象见**巨幼红细胞**（细胞核发育落后于胞浆，"核幼浆老"）。血清维生素 B₁₂ 和/或叶酸降低。
- **知识点**: 巨幼细胞性贫血, MCV, 巨幼红细胞
- **详见**: [[巨幼细胞贫血]]


#### Q105. APL（急性早幼粒细胞白血病）的染色体异常？（英文题）
- **来源**: 22临五下
- **答案**: **t(15;17)(q22;q21)** → **PML-RARα 融合基因**。APL 是 AML-M3，以 DIC 出血风险极高为特征，对全反式维甲酸（ATRA）+ 砷剂治疗敏感，预后在 AML 亚型中最好。
- **知识点**: APL, t(15,17), PML-RARα, ATRA
- **详见**: [[急性白血病]]


#### Q106. M 蛋白是？
- **来源**: 22临五下
- **答案**: **单克隆免疫球蛋白**（monoclonal immunoglobulin）。由单克隆浆细胞大量产生的同质性免疫球蛋白或游离轻链（本-周蛋白/BJP），是多发性骨髓瘤（MM）的血清学标志物。血清蛋白电泳见 M 峰。
- **知识点**: M 蛋白, 多发性骨髓瘤, 单克隆免疫球蛋白
- **详见**: [[淋巴瘤]]


#### Q107. DIC 治疗最重要的是？
- **来源**: 22临五下
- **答案**: **去除病因、治疗原发病**。DIC 为消耗性凝血病，根本措施是控制诱发 DIC 的基础疾病（如脓毒症、产科并发症、恶性肿瘤）。继之才考虑补充凝血因子/血小板、抗凝等。
- **知识点**: DIC, 原发病治疗, 凝血功能紊乱
- **详见**: [[弥散性血管内凝血]]

### 内分泌系统
#### Q108. 什么不是 Cushing 综合征的体征？
- **来源**: 20临八
- **答案**: [根据考点提示整理] Cushing 综合征典型体征：**满月脸、水牛背、向心性肥胖、紫纹**（宽大紫色条纹）、多血质外貌、痤疮、多毛、皮肤变薄、容易瘀伤、近端肌无力。不属于 Cushing 体征的通常指向其他疾病（如甲亢的眼征、肢端肥大症的肢端改变等）。
- **知识点**: Cushing 综合征体征, 皮质醇增多症
- **详见**: [[Cushing 综合征]], [[肾上腺皮质功能减退症]]


#### Q109. 鉴别 1 型糖尿病和 2 型糖尿病的关键点是？
- **来源**: 22口腔
- **答案**: **胰岛自身抗体检测**：**GAD65（谷氨酸脱羧酶抗体）**、**IAA（胰岛素自身抗体）**、**ICA（胰岛细胞抗体）**、IA-2A、ZnT8A。1 型糖尿病为自身免疫性胰岛β细胞破坏，上述抗体阳性；2 型糖尿病为胰岛素抵抗 + 相对分泌不足，自身抗体阴性。
- **知识点**: 1型糖尿病, 2型糖尿病, 胰岛自身抗体, GAD65
- **详见**: [[1型糖尿病]], [[2型糖尿病]], [[糖尿病]]

#### Q110. OGTT 检查结果解读：空腹血糖 6.7mmol/L，2h 血糖 7.3mmol/L，应考虑？
- **来源**: 20预防基医临药
- **答案**: **应重复 1 次 OGTT**。空腹血糖 6.7mmol/L（≥ 6.1 但 < 7.0）为空腹血糖受损（IFG），2h 血糖 7.3mmol/L（< 7.8）为正常，此结果倾向于**空腹血糖受损（IFG）**。单次异常需重复确认。糖尿病诊断需满足：空腹 ≥ 7.0 或 OGTT 2h ≥ 11.1 或 HbA1c ≥ 6.5%。
- **知识点**: OGTT, 空腹血糖受损, 糖尿病诊断标准
- **详见**: [[糖尿病]]

#### Q111. 胰岛素注射最常见的不良反应？
- **来源**: 20预防基医临药
- **答案**: **低血糖**。其他常见不良反应：体重增加、注射部位脂肪萎缩/增生、过敏反应（少见）。糖尿病治疗中需教育低血糖识别和自救。
- **知识点**: 胰岛素治疗, 低血糖, 糖尿病
- **详见**: [[糖尿病]]

#### Q112. 甲亢最危急的临床表现？
- **来源**: 20预防基医临药
- **答案**: **甲状腺危象（甲亢危象）**。诱因：感染、手术、应激等。表现为高热（> 39°C）、心动过速（> 140 次/分）、烦躁不安、大汗、恶心呕吐、腹泻、严重可致昏迷、循环衰竭。死亡率高，需紧急处理（丙硫氧嘧啶 + 碘剂 + β 阻滞剂 + 糖皮质激素 + 支持治疗）。
- **知识点**: 甲亢危象, 甲状腺危象, Graves 病并发症
- **详见**: [[甲状腺功能亢进症]]

#### Q113. 糖尿病肾病（DKD）最敏感的早期检测指标？（英文题）
- **来源**: 22临五下
- **答案**: **微量白蛋白尿（Microalbuminuria）**：尿白蛋白排泄率（UAER）**30-300 mg/24h** 或尿白蛋白/肌酐比值（UACR）30-300 mg/g。微量白蛋白尿是 DKD 的**最早可检测阶段**，此时干预可逆。
- **知识点**: DKD, 微量白蛋白尿, UAER
- **详见**: [[糖尿病]], [[慢性肾衰竭]]


#### Q114. 甲状腺疾病最敏感的筛查指标？
- **来源**: 22临五下
- **答案**: **TSH（促甲状腺激素）**。TSH 是最敏感的甲状腺功能指标：TSH ↓ + FT₄/FT₃ ↑ → 甲亢（原发性）；TSH ↑ + FT₄/FT₃ ↓ → 甲减；仅 TSH ↓ 而 FT₄ 正常 → 亚临床甲亢。
- **知识点**: TSH, 甲状腺功能, 筛查
- **详见**: [[甲状腺功能亢进症]]


#### Q115. 胰岛素治疗的严重不良反应？
- **来源**: 22临五下
- **答案**: **低血糖**。胰岛素最常见且最危险的副作用为低血糖（血糖 < 3.9 mmol/L）。低血糖可导致意识障碍、昏迷甚至死亡，患者需接受低血糖识别和自救教育。
- **知识点**: 胰岛素, 低血糖, 糖尿病治疗
- **详见**: [[糖尿病]]

### 风湿免疫

#### Q116. SLE 治疗不包括？
- **来源**: 23口腔
- **答案**: [根据考点提示整理] SLE 标准治疗包括：① 非甾体抗炎药（关节痛/发热）；② **羟氯喹**（所有无禁忌症 SLE 患者的基础用药）；③ **糖皮质激素**（中重度活动期）；④ 免疫抑制剂（**环磷酰胺**用于狼疮肾炎、**霉酚酸酯**、**硫唑嘌呤**等）；⑤ 生物制剂（贝利尤单抗）。不包括的主要是某些不适用于 SLE 的药物或仅为部分专科用药。
- **知识点**: SLE, 羟氯喹, 免疫抑制剂, 治疗原则
- **详见**: [[系统性红斑狼疮]]

#### Q117. SLE 是哪种类型的疾病？
- **来源**: 22口腔
- **答案**: **自身免疫性疾病**。SLE 是典型的系统性自身免疫病，以**抗核抗体（ANA）** 为血清标志，免疫复合物沉积致多系统损害。女性高发（育龄女性男：女 ≈ 1:9）。
- **知识点**: SLE, 自身免疫病, 抗核抗体
- **详见**: [[系统性红斑狼疮]]

#### Q118. SLE 诊断中特异性最高的抗体是？
- **来源**: 20预防基医临药
- **答案**: **抗 Sm 抗体**。抗 Sm 抗体是 SLE 的**标记性抗体**（特异性 > 99%），但敏感性较低（约 25-30%）。与疾病活动性不平行。其他 SLE 相关抗体：抗 dsDNA 抗体（与活动性和狼疮肾炎相关）、抗 RNP、抗 Ro/SSA、抗 La/SSB。
- **知识点**: 抗Sm抗体, SLE诊断, 自身抗体
- **详见**: [[系统性红斑狼疮]]

#### Q119. Gottron 征是什么的表现？
- **来源**: 20临八
- **答案**: **皮肌炎（Dermatomyositis）**。Gottron 征是皮肌炎的特征性皮疹：**指间关节、掌指关节伸侧的紫红色丘疹**，可伴脱屑、萎缩。其他皮肌炎特征性皮疹：眶周紫红色水肿性红斑（Heliotrope rash 向阳疹）、V 领区及披肩区红斑。
- **知识点**: Gottron 征, 皮肌炎, 风湿免疫
- **详见**: [[系统性红斑狼疮]]

#### Q120. RA 最特异性的实验指标？
- **来源**: 22临五下
- **答案**: **抗瓜氨酸化蛋白抗体（ACPA/anti-CCP）**。ACPA 对 RA 的特异性 > 95%（类风湿因子 RF 特异性仅约 80%），且与更严重的骨侵蚀性病变相关，可提前出现提示预后不良。
- **知识点**: RA, anti-CCP, ACPA, 自身抗体
- **详见**: [[系统性红斑狼疮]]


#### Q121. p-ANCA(+) 累及微血管病变，诊断是？
- **来源**: 22临五下
- **答案**: **显微镜下多血管炎（MPA）**。p-ANCA 的主要靶抗原为**MPO**（髓过氧化物酶），MPA 属 ANCA 相关性血管炎（AAV），以坏死性肾小球肾炎（急进性肾炎）和肺毛细血管炎（弥漫性肺泡出血）为特征。
- **知识点**: p-ANCA, MPA, 血管炎, ANCA 相关性血管炎
- **详见**: [[系统性红斑狼疮]]


#### Q122. 干燥综合征最常受累的器官？
- **来源**: 22临五下
- **答案**: **唾液腺和泪腺**（外分泌腺）。干燥综合征（Sjögren 综合征）以淋巴细胞浸润外分泌腺导致口干、眼干为主要特征。特征性自身抗体：抗 SSA/Ro 抗体、抗 SSB/La 抗体。
- **知识点**: 干燥综合征, 外分泌腺, 口干眼干
- **详见**: [[系统性红斑狼疮]]


#### Q123. 皮肌炎的皮肤表现不包括？
- **来源**: 22临五下
- **答案**: **蝶形红斑**（蝶形红斑是 SLE 的特征性皮疹）。皮肌炎的特征性皮疹：**眶周向阳疹（Heliotrope rash）+ Gottron 丘疹 + V 领区/披肩区红斑**。
- **知识点**: 皮肌炎, Gottron 征, 蝶形红斑鉴别
- **详见**: [[系统性红斑狼疮]]

### 危重症

#### Q124. 关于休克，下列说法正确的是？
- **来源**: 22口腔
- **答案**: **有效循环容量减少，组织灌注不足，产生炎症介质**。休克的核心病理生理为微循环障碍：有效循环血容量↓→组织灌注↓→细胞缺氧→炎症介质释放→微循环进一步恶化→MODS。
- **知识点**: 休克, 微循环障碍, 有效循环容量
- **详见**: [[休克]]

#### Q125. 有机磷农药中毒诊断的最重要指标？
- **来源**: 20临八
- **答案**: [根据考点提示整理] **全血胆碱酯酶（ChE）活性测定**。有机磷中毒后 ChE 活性被不可逆抑制，活性降至正常值的 50-70% 为轻度中毒，30-50% 为中度，< 30% 为重度。具备诊断和判断治疗效果的双重价值。
- **知识点**: 有机磷中毒, 胆碱酯酶, 中毒诊断
- **详见**: [[休克]]

#### Q126. 下列有机磷农药中毒性最大的是（对硫磷）/ 考的哪种有机磷最毒？
- **来源**: 20预防基医临药
- **答案**: **对硫磷**（1605）。有机磷农药毒性分级以大鼠 LD₅₀ 为依据：对硫磷属剧毒类（LD₅₀ < 10 mg/kg）；内吸磷、甲拌磷也属高/剧毒类；敌百虫、乐果、马拉硫磷属中等毒性或低毒类。
- **知识点**: 有机磷中毒, 对硫磷, 毒性分级
- **详见**: [[休克]]

#### Q127. 考了 CO 中毒（一氧化碳中毒）
- **来源**: 21临八
- **答案**: [根据考点提示整理] CO 中毒机制：CO 与 Hb 的亲和力是 O₂ 的 **200-300 倍**，形成**碳氧血红蛋白（HbCO）** 导致组织缺氧。**口唇樱桃红色**为特征性体征。治疗：**高压氧**为首选，越早越好。
- **知识点**: CO 中毒, HbCO, 高压氧, 口唇樱桃红
- **详见**: [[休克]]


#### Q128. 不属于毒蕈碱样症状的是？
- **来源**: 22临五下
- **答案**: **肌无力**（肌无力是**烟碱样症状**）。毒蕈碱样（M 样）症状：瞳孔缩小、流涎、出汗、恶心呕吐、腹痛腹泻、支气管分泌物增多、支气管痉挛、心动过缓、大小便失禁。烟碱样（N 样）症状：肌束颤动、肌无力/麻痹、心动过速、血压升高。
- **知识点**: 有机磷中毒, M 样症状, N 样症状
- **详见**: [[休克]]


#### Q129. 不属于中毒途径的是？
- **来源**: 22临五下
- **答案**: **感染**不是中毒途径。中毒的途径包括：**消化道（经口）、呼吸道（吸入）、皮肤黏膜（接触/吸收）、注射**。感染是病原微生物侵入的过程，不属于中毒途径。
- **知识点**: 中毒途径, 毒物吸收方式
- **详见**: [[休克]]

## 二、名词解释
### 呼吸系统

#### Q1. COPD / 慢阻肺
- **来源**: 23口腔, 22口腔
- **答案**: **慢性阻塞性肺疾病（COPD）**，以**持续性气流受限**为特征的慢性气道疾病，由长期吸入有害颗粒（主要是吸烟）所致。肺功能诊断标准：吸入支气管扩张剂后 **FEV₁/FVC < 70%**。包括慢性支气管炎和肺气肿两个病理类型。
- **知识点**: COPD 定义, 肺功能诊断, FEV₁/FVC
- **详见**: [[慢性阻塞性肺疾病]]

#### Q2. 肺脓肿
- **来源**: 22预防
- **答案**: 肺组织**化脓性坏死性炎症**，多种病原体（细菌为主，厌氧菌常见）引起肺实质坏死液化形成脓腔。临床表现为高热、咳大量**脓臭痰**，胸片/CT 见**气液平面**的空洞。抗生素治疗 6-8 周，必要时引流。
- **知识点**: 肺脓肿, 脓臭痰, 气液平面
- **详见**: [[肺炎]]

#### Q3. Pancoast 瘤（肺上沟瘤）
- **来源**: 21预防/基医/临药
- **答案**: 位于**肺尖部**的肺癌（多为鳞癌）侵犯胸廓上口结构，导致：① **Horner 综合征**（同侧瞳孔缩小、眼睑下垂、眼球内陷、无汗，颈交感神经受压）；② **臂丛神经受压**（同侧肩部及上肢疼痛、肌萎缩）。X 线可见肺尖部阴影伴第 1-2 肋骨破坏。
- **知识点**: Pancoast 瘤, 肺上沟瘤, Horner 综合征
- **详见**: [[肺癌]]

#### Q4. 肺性脑病
- **来源**: 21口腔
- **答案**: 由严重呼吸衰竭（Ⅱ型呼衰：缺 O₂ + CO₂ 潴留）引起的**神经精神障碍综合征**。CO₂ 潴留→脑血管扩张、脑水肿→头痛、烦躁、嗜睡→昏迷。是慢性肺源性心脏病患者死亡的重要原因之一。
- **知识点**: 肺性脑病, II型呼衰, CO₂潴留, 肺心病
- **详见**: [[慢性肺源性心脏病]], [[呼吸衰竭]]

#### Q5. 支气管舒张试验
- **来源**: 19预防
- **答案**: 评价气道阻塞**可逆性**的肺功能检查。吸入速效支气管舒张剂（如沙丁胺醇）后，**FEV₁ 增加 ≥ 12% 且绝对值增加 ≥ 200mL** 为阳性。用于支气管哮喘的诊断及与 COPD 的鉴别。
- **知识点**: 支气管舒张试验, 肺功能, 哮喘诊断
- **详见**: [[支气管哮喘]]


#### Q6. Chronic Pulmonary Heart Disease（慢性肺源性心脏病）
- **来源**: 21临五上
- **答案**: 由支气管-肺组织、肺血管或胸廓慢性病变→**肺动脉高压**→**右心室结构和功能改变**（右心室肥厚/扩大）→最终可致**右心衰竭**的心脏病。最多见原因为 COPD。ECG 特征：电轴右偏、肺型 P 波、右心室肥厚。
- **知识点**: 肺心病, 肺动脉高压, 右心衰竭
- **详见**: [[慢性肺源性心脏病]]


#### Q7. ARDS（急性呼吸窘迫综合征）
- **来源**: 22临五上
- **答案**: 由肺内或肺外原因（脓毒症、创伤、肺炎、误吸等）引起的**急性弥漫性肺泡-毛细血管膜损伤**→**非心源性肺水肿**和**严重低氧血症**。诊断：起病 1 周内，PaO₂/FiO₂ ≤ 300mmHg（轻），PEEP ≥ 5 cmH₂O，排除心源性肺水肿，胸片示双肺弥漫性浸润影。
- **知识点**: ARDS, 非心源性肺水肿, 低氧血症
- **详见**: [[急性呼吸窘迫综合征]]


#### Q8. 肺栓塞（PE）
- **来源**: 22临五上（缓）
- **答案**: 来自静脉系统或右心的**血栓（最常见为深静脉血栓）** 脱落后**栓塞肺动脉或其分支**，导致肺循环障碍和呼吸功能障碍。典型三联征：**呼吸困难 + 胸痛 + 咯血**（但发生率仅约 20%）。确诊首选：CT 肺动脉造影（CTPA）。治疗：抗凝为主，大面积 PE 需溶栓。
- **知识点**: 肺栓塞, VTE, CTPA, 抗凝
- **详见**: [[肺血栓栓塞症]]

### 循环系统

#### Q9. 预激综合征（Wolff-Parkinson-White 综合征, WPW）
- **来源**: 23口腔, 22口腔, 19预防
- **答案**: 心房和心室之间存在**异常旁路（Kent 束）**，心房冲动经旁路提前激动心室，心电图表型：**PR 间期缩短（< 0.12s）+ δ 波（delta 波）+ QRS 增宽**。易并发**房室折返性心动过速**甚至房颤→室颤。有症状者首选**射频导管消融**。
- **知识点**: WPW 综合征, Kent 束, PR 间期, δ 波, 射频消融
- **详见**: [[心律失常]]

#### Q10. 变异型心绞痛（Prinzmetal 心绞痛）
- **来源**: 21口腔
- **答案**: 由**冠状动脉痉挛**引起的静息性心绞痛，常在午夜至清晨发作。ECG 表现为**一过性 ST 段抬高**（不同于典型心绞痛的 ST 段压低）。钙通道阻滞剂（硝苯地平/地尔硫卓）为首选治疗。预后取决于痉挛程度和持续时间。
- **知识点**: 变异型心绞痛, 冠状动脉痉挛, ST段抬高
- **详见**: [[冠心病]]

#### Q11. 急性心力衰竭
- **来源**: 22预防
- **答案**: 心功能急性失代偿导致**心排血量急剧减少→肺循环淤血（左心衰）** 和/或体循环淤血（右心衰）。急性左心衰典型表现：**呼吸困难（端坐呼吸）+ 咳粉红色泡沫痰 + 双肺底湿啰音 + 奔马律**。抢救：端坐位 + 吸氧 + 吗啡 + 利尿（呋塞米）+ 扩血管（硝普钠/硝酸甘油）+ 强心（洋地黄/多巴酚丁胺）。
- **知识点**: 急性心力衰竭, 肺水肿, 端坐呼吸, 抢救治疗
- **详见**: [[心力衰竭]]

#### Q12. 心瓣膜疾病（名词解释 20预防 4分题）
- **来源**: 20预防基医临药
- **答案**: 各种原因导致心脏瓣膜结构或功能异常，引起瓣膜**狭窄**和（或）**关闭不全**，导致血流动力学障碍。风湿热是最常见病因（二尖瓣最常受累），其他病因包括退行性变、感染性心内膜炎、先天性畸形等。
- **知识点**: 心脏瓣膜病, 狭窄, 关闭不全, 风湿热
- **详见**: [[心脏瓣膜病]]


#### Q13. Sudden Cardiac Death（SCD，心脏性猝死）
- **来源**: 20临五上
- **答案**: 由心脏原因引起的**急性症状发作后 1 小时内**发生的**意外自然死亡**。最常见病因：**冠心病**（约 80%），尤其 AMI 后室颤。其他病因：肥厚型心肌病、扩张型心肌病、致心律失常性右室心肌病（ARVC）、长 QT 综合征、Brugada 综合征等。
- **知识点**: 心脏性猝死, 室颤, 冠心病
- **详见**: [[冠心病]], [[急性心肌梗死]], [[心律失常]]


#### Q14. 急性冠脉综合征（ACS）
- **来源**: 21临五上
- **答案**: 冠状动脉粥样硬化斑块**破裂或侵蚀**→血栓形成→冠脉急性不全或完全闭塞所致的临床综合征。包括：**STEMI**（ST 段抬高型心梗）、**NSTEMI**（非 ST 段抬高型心梗）、**UAP**（不稳定心绞痛）。共同病理基础：斑块不稳定+血小板活化+血栓形成。
- **知识点**: ACS, STEMI, NSTEMI, UAP
- **详见**: [[冠心病]], [[急性心肌梗死]]


#### Q15. 病态窦房结综合征（SSS）
- **来源**: 22临五上
- **答案**: 窦房结功能障碍所致的缓慢性心律失常综合征。心电图表现：① 持续而显著的窦性心动过缓（< 50 次/分，非药物所致）；② 窦性停搏 + 窦房传导阻滞；③ **心动过缓-心动过速综合征**（快慢综合征，最常见类型）。有症状者需植入**永久心脏起搏器**。
- **知识点**: 病态窦房结综合征, 快慢综合征, 起搏器
- **详见**: [[心律失常]]

### 消化系统

#### Q16. 肝肾综合征（HRS）
- **来源**: 23口腔
- **答案**: 严重肝病（肝硬化失代偿期）基础上出现的**功能性肾衰竭**：肾脏本身无明显器质性病变，但由于内脏血管扩张 + 肾血管收缩→肾灌注不足→进行性少尿、氮质血症、稀释性低钠血症。分型：Ⅰ 型急性进展（2 周内肾功能急剧恶化），Ⅱ 型相对稳定。**TIPS 和肝移植**为有效治疗。
- **知识点**: 肝肾综合征, 功能性肾衰竭, 肝硬化并发症
- **详见**: [[肝肾综合征]], [[肝硬化]]

#### Q17. 门脉高压性胃病
- **来源**: 22口腔
- **答案**: 门静脉高压时胃黏膜发生特征性**淤血性改变**：胃黏膜充血、水肿，呈**蛇皮样（马赛克样）** 改变。可导致慢性隐匿性失血或急性上消化道出血。治疗：降低门脉压力（非选择性 β 阻滞剂如普萘洛尔）。
- **知识点**: 门脉高压性胃病, 门静脉高压, 上消化道出血
- **详见**: [[肝硬化]]

#### Q18. 中毒性巨结肠
- **来源**: 21预防/基医/临药
- **答案**: 炎症性肠病（尤其是**溃疡性结肠炎**）的严重并发症。结肠急性极度扩张（横结肠直径 > **6cm**），伴全身中毒症状（高热、脱水、白细胞增高），可导致肠穿孔、腹膜炎。死亡率高，需禁食、胃肠减压、广谱抗生素，必要时紧急手术。
- **知识点**: 中毒性巨结肠, 溃疡性结肠炎并发症, 急腹症
- **详见**: [[溃疡性结肠炎]], [[炎症性肠病]]

#### Q19. 穿孔性溃疡（消化性溃疡穿孔）
- **来源**: 20预防基医临药
- **答案**: 消化性溃疡穿破胃/十二指肠壁全层。前壁穿孔致急性弥漫性腹膜炎：**突发剧烈刀割样腹痛→板状腹+压痛/反跳痛**，立位腹平片见**膈下游离气体**。后壁穿孔可形成局限性脓肿或穿透入胰腺。需紧急手术。
- **知识点**: 消化性溃疡穿孔, 板状腹, 膈下游离气体
- **详见**: [[消化性溃疡]]


#### Q20. 非酒精性脂肪性肝病（NAFLD / MAFLD）
- **来源**: 20临五上
- **答案**: 排除酒精和其他明确肝损伤因素后，以肝细胞**脂肪变性（＞5% 肝细胞）** 为特征的代谢应激性肝病。疾病谱：单纯性脂肪肝→脂肪性肝炎（NASH）→肝硬化→HCC。与**代谢综合征**（肥胖、2 型糖尿病、血脂异常、高血压）密切相关。
- **知识点**: NAFLD, 代谢综合征, 脂肪肝
- **详见**: [[非酒精性肝病]]


#### Q21. GERD（胃食管反流病）
- **来源**: 22临五上（缓）
- **答案**: 胃内容物反流入食管引起不适症状和（或）并发症的疾病。典型症状：**烧心 + 反流**。并发症：食管炎、食管狭窄、Barrett 食管（食管腺癌的癌前病变）。诊断金标准：24h 食管 pH 监测。治疗首选：**PPI**（质子泵抑制剂）。
- **知识点**: GERD, Barrett 食管, PPI
- **详见**: [[消化性溃疡]]

### 肾脏系统

#### Q22. 肾病综合征
- **来源**: 21预防/基医/临药
- **答案**: "三高一低"综合征：① **大量蛋白尿**（≥ 3.5g/24h）；② **低白蛋白血症**（血浆白蛋白 < 30g/L）；③ **水肿**；④ **高脂血症**（胆固醇和甘油三酯升高）。前两者为诊断必备。常见病理类型：微小病变型（儿童最常见）、膜性肾病（成人最常见）、局灶节段性肾小球硬化（FSGS）。
- **知识点**: 肾病综合征, 大量蛋白尿, 低白蛋白血症, 水肿
- **详见**: [[原发性肾小球疾病]]

#### Q23. 急进性肾小球肾炎（RPGN）
- **来源**: 19预防
- **答案**: 临床表现为**急进性肾炎综合征**：血尿、蛋白尿、水肿、高血压 + **肾功能急剧恶化**（数周至数月内进展至 ESRD）。肾活检病理特征：**新月体形成**（≥ 50% 肾小球）。分型：Ⅰ 型抗 GBM 型（血浆置换 + CTX）、Ⅱ 型免疫复合物型、Ⅲ 型 pauci-immune 型（ANCA 相关）。
- **知识点**: 急进性肾炎, 新月体, ANCA, 肾功能恶化
- **详见**: [[原发性肾小球疾病]]

#### Q24. 狼疮性肾炎
- **来源**: 20预防基医临药
- **答案**: SLE 引起的**免疫复合物性肾小球肾炎**，是 SLE 最常见且最严重的内脏损害之一。临床表现：蛋白尿、血尿、管型尿，可进展至肾病综合征和慢性肾衰竭。病理分型（ISN/RPS）Ⅰ-Ⅵ 型，**Ⅳ 型**（弥漫增殖型）最常见。治疗：糖皮质激素 + 环磷酰胺/霉酚酸酯。
- **知识点**: 狼疮肾炎, SLE, 免疫复合物, 肾病理分型
- **详见**: [[系统性红斑狼疮]], [[继发性肾病]]


#### Q25. AKI（急性肾损伤）
- **来源**: 19临五下
- **答案**: 肾功能在**数小时至数日内急剧下降**，表现为血清肌酐（SCr）升高（≥ 26.5 μmol/L 在 48h 内 或 基线值 1.5 倍在 7 天内）和/或尿量减少（< 0.5 mL/kg/h 持续 6 小时）。分为**肾前性**（肾脏低灌注）、**肾性**（肾实质损伤，以 ATN 最常见）、**肾后性**（尿路梗阻）。
- **知识点**: AKI, 肌酐, 肾前/肾性/肾后性
- **详见**: [[慢性肾衰竭]]

### 血液系统

#### Q26. 再生障碍性贫血（AA）
- **来源**: 21口腔
- **答案**: 骨髓造血干细胞损伤致**全血细胞减少**（贫血 + 出血 + 感染），骨髓象呈**增生低下**（造血细胞减少，非造血细胞增多）。分为重型再障（SAA：ANC < 0.5 × 10⁹/L + 血小板 < 20 × 10⁹/L + 网织红 < 20 × 10⁹/L）和非重型。治疗：免疫抑制（ATG + 环孢素）+ 造血刺激因子 + 异基因造血干细胞移植。
- **知识点**: 再生障碍性贫血, 全血细胞减少, 骨髓增生低下
- **详见**: [[再生障碍性贫血]]

#### Q27. Iron Deficiency Anemia（缺铁性贫血）
- **来源**: 20预防基医临药, 19预防
- **答案**: 体内储存铁耗尽导致**小细胞低色素性贫血**。血清铁蛋白 **< 12 μg/L** 为诊断金标准（ID 期）；IDE 期出现转铁蛋白饱和度降低（< 15%）、FEP 升高；IDA 期出现贫血。治疗：口服**硫酸亚铁** + 维生素 C 促进吸收，补铁至血红蛋白正常后继续 3-6 个月补充储存铁。
- **知识点**: IDA, 血清铁蛋白, 小细胞低色素, 铁剂治疗
- **详见**: [[缺铁性贫血]]


#### Q28. 多发性骨髓瘤（MM）
- **来源**: 20临五下
- **答案**: 单克隆浆细胞**恶性增殖**→ **M 蛋白**（单克隆免疫球蛋白/轻链）大量产生→多系统损害。典型四联征：**CRAB** — **C**alcium ↑（高钙血症）、**R**enal（肾功能不全）、**A**nemia（贫血，正细胞正色素性）、**B**one（溶骨性骨病，骨痛/病理性骨折）。确诊需骨髓浆细胞 ≥ 10% + M 蛋白 + 靶器官损害。
- **知识点**: 多发性骨髓瘤, CRAB, M 蛋白, 浆细胞
- **详见**: [[淋巴瘤]]

### 内分泌系统

#### Q29. 甲状腺危象（Thyroid Crisis / 甲亢危象）
- **来源**: 21预防/基医/临药
- **答案**: 甲亢未控制时，在感染、应激等诱因下发生的**危及生命的严重状态**。特征：**高热（> 39°C）+ 心动过速（> 140 次/分）+ 烦躁、谵妄 + 恶心、呕吐、腹泻 → 昏迷、循环衰竭**。死亡率高，需紧急综合治疗。
- **知识点**: 甲状腺危象, Graves 病, 甲亢急症
- **详见**: [[甲状腺功能亢进症]]

#### Q30. 原发性甲减（原发性甲状腺功能减退症）
- **来源**: 22预防
- **答案**: 甲状腺本身病变致甲状腺激素合成和分泌不足。最常见病因：**桥本甲状腺炎**（自身免疫性）。特征性实验室检查：**TSH 升高 + FT₄/FT₃ 降低**。临床表现：怕冷、乏力、体重增加、记忆力减退、黏液性水肿（严重时为黏液水肿性昏迷）。
- **知识点**: 甲减, TSH, 桥本甲状腺炎, 黏液性水肿
- **详见**: [[甲状腺功能亢进症]]
### 风湿免疫

#### Q31. ANCA（抗中性粒细胞胞浆抗体）
- **来源**: 20临五下
- **答案**: 以中性粒细胞和单核细胞胞浆成分为靶抗原的自身抗体。分两型：**c-ANCA（PR3 抗体）**— 肉芽肿性多血管炎（GPA/Wegener）标记物；**p-ANCA（MPO 抗体）**— 显微镜下多血管炎（MPA）、嗜酸性肉芽肿性多血管炎（EGPA/Churg-Strauss）更多见。是 ANCA 相关性血管炎（AAV）的核心血清诊断指标。
- **知识点**: ANCA, PR3, MPO, 血管炎
- **详见**: [[系统性红斑狼疮]]


#### Q32. 类风湿因子（RF）
- **来源**: 21临五下
- **答案**: 针对 IgG Fc 段的自身抗体（多为 IgM 型）。RF 对 RA 有诊断价值，但特异性不高（约 80%），亦可见于 SLE、干燥综合征、感染（乙肝、结核、亚急性感染性心内膜炎）等。**ACPA/anti-CCP** 特异性 > 95%，是 RA 的更优诊断和预后指标。
- **知识点**: 类风湿因子, RF, anti-CCP
- **详见**: [[系统性红斑狼疮]]


#### Q33. 痛风
- **来源**: 22临五下
- **答案**: **嘌呤代谢障碍**→**高尿酸血症**→尿酸盐结晶在关节和软组织沉积→**急性关节炎**反复发作。好发于第一跖趾关节（Podagra）。实验室：血尿酸 > **420 μmol/L**（男）/> 360 μmol/L（女）。关节液镜下见**双折光针状尿酸盐结晶**是确诊金标准。慢性期：痛风石、尿酸性肾病。
- **知识点**: 痛风, 嘌呤代谢, 高尿酸血症, 尿酸盐结晶
- **详见**: [[原发性肾小球疾病]]

### 危重症及中毒

#### Q34. 休克
- **来源**: 19临五下
- **答案**: 见 [[#Q124|选择题 - 休克的病理生理]]。有效循环容量急剧减少→组织灌注不足→细胞缺氧→炎症介质释放→MODS。分型：低血容量性、心源性、分布性（感染性/过敏性/神经性）、梗阻性。
- **详见**: [[休克]]


#### Q35. MODS（多器官功能障碍综合征）
- **来源**: 21临五下
- **答案**: 在严重感染、创伤、休克、重症胰腺炎等急性损伤后，**同时或序贯出现 ≥ 2 个器官/系统功能障碍**（呼吸、循环、肾、肝、凝血、CNS 等）的临床综合征。发生机制核心：**失控的全身炎症反应（SIRS）+ 微循环障碍**。MODS 是 ICU 患者最主要的死亡原因。
- **知识点**: MODS, SIRS, 多器官功能障碍
- **详见**: [[休克]]

## 三、简答题
### 呼吸系统

#### Q1. 重症社区获得性肺炎（SCAP）的诊断标准？
- **来源**: 22预防, 21口腔
- **答案**: 主要标准（满足 1 条即可诊断）：① 需要机械通气；② 感染性休克需要血管活性药物。次要标准（≥ 3 条）：① RR ≥ 30 次/分；② PaO₂/FiO₂ ≤ 250mmHg；③ 多肺叶浸润；④ 意识障碍/定向力障碍；⑤ 尿毒症（BUN ≥ 7 mmol/L）；⑥ 白细胞减少症（< 4.0 × 10⁹/L）；⑦ 血小板减少（< 100 × 10⁹/L）；⑧ 体温过低（< 36°C）；⑨ 低血压需要积极的液体复苏。
- **知识点**: SCAP, CURB-65, IDSA/ATS 标准
- **详见**: [[肺炎]]

#### Q2. 抗结核化学药物治疗的原则？
- **来源**: 21预防/基医/临药
- **答案**: **早期、联合、适量、规律、全程**。① 早期：尽早诊断和治疗，减少传播；② 联合：≥ 2-4 种药物联合防止耐药；③ 适量：剂量适当减少不良反应；④ 规律：严格按方案规律服药；⑤ 全程：完成规定疗程（初治 6 个月，复治 8 个月），确保治愈。标准化方案：2HRZE/4HR。
- **知识点**: 抗结核, 化疗原则, DOTS
- **详见**: [[肺结核]]

#### Q3. 肺癌出现胸闷、气短的原因有哪些？
- **来源**: 19预防
- **答案**: ① 肿瘤阻塞**主支气管** → 阻塞性肺不张→通气血流失调；② 大量**胸腔积液**（胸膜转移或淋巴回流受阻）；③ 广泛的肺实质转移 → 弥散功能下降；④ **上腔静脉综合征** → 头面部及上肢水肿、呼吸困难；⑤ 肿瘤导致肺栓塞；⑥ 恶病质、贫血等全身因素。
- **知识点**: 肺癌, 呼吸困难, 肿瘤并发症
- **详见**: [[肺癌]]

#### Q4. 肺心病的临床表现和并发症？
- **来源**: 22口腔
- **答案**: **临床表现**：代偿期 — 原发肺部疾病症状（咳嗽、咳痰、气促）+ 剑突下心脏搏动、P₂ 亢进、颈静脉充盈。失代偿期 — **右心衰竭**（下肢水肿、肝大、颈静脉怒张、肝颈静脉回流征阳性）+ **II 型呼吸衰竭**（缺氧 + CO₂ 潴留→肺性脑病）。**并发症**：**肺性脑病**（最常见死亡原因）、心律失常、消化道出血、酸碱失衡及电解质紊乱、DIC、休克。
- **知识点**: 肺心病, 右心衰竭, II型呼衰, 肺性脑病
- **详见**: [[慢性肺源性心脏病]]

#### Q5. 肺癌的临床表现和鉴别诊断？
- **来源**: 20临五上
- **答案**: **临床表现**：① 原发症状：咳嗽（最常见首发症状）、咯血/痰中带血、胸痛、呼吸困难；② 局部侵犯：Horner 综合征（肺上沟瘤）、声音嘶哑（喉返神经）、上腔静脉综合征；③ 远处转移：脑、骨、肝、肾上腺；④ 副癌综合征。**鉴别诊断**：肺结核（结核中毒症状、痰找抗酸杆菌）、肺炎（抗生素治疗有效）、肺脓肿（脓臭痰、均匀气液平面）、肺良性肿瘤（生长缓慢、无转移特征）。
- **知识点**: 肺癌, 临床表现, 鉴别诊断
- **详见**: [[肺癌]]


#### Q6. 肺癌局部转移的症状与体征？
- **来源**: 21临五上
- **答案**: ① **Horner 综合征**（肺上沟瘤压迫颈交感神经：同侧瞳孔缩小+眼睑下垂+眼球内陷+无汗）；② **声音嘶哑**（左侧喉返神经受压）；③ **上腔静脉综合征**（头面部及上肢水肿、颈静脉怒张）；④ **吞咽困难**（食管受压）；⑤ **膈神经麻痹**（膈肌升高、矛盾呼吸）；⑥ **Pancoast 综合征**（臂丛神经 C8/T1：同侧肩部及上肢疼痛、肌萎缩）。
- **知识点**: 肺癌局部转移, Horner 综合征, Pancoast 综合征
- **详见**: [[肺癌]]


#### Q7. 重症哮喘的治疗原则？
- **来源**: 22临五上
- **答案**: ① **氧疗**（目标 SpO₂ > 90%）；② **反复吸入速效 β₂ 激动剂**（沙丁胺醇持续雾化）+ **异丙托溴铵**；③ **早期全身糖皮质激素**（甲泼尼龙 40-80mg/d 或氢化可的松）；④ 静脉茶碱类（二线）；⑤ 补液纠正脱水（气道分泌物黏稠）；⑥ 若恶化（PaCO₂升高、"沉默肺"）→**无创通气**→必要时**气管插管+有创通气**。
- **知识点**: 重症哮喘, 沉默肺, 机械通气
- **详见**: [[支气管哮喘]]


#### Q8. HAP 和 CAP 的定义与病原学区别（英文题）
- **来源**: 22临五上（缓）
- **答案**: **CAP**（社区获得性肺炎）：入院前或入院 48h 内发生的肺炎。主要病原体：**肺炎链球菌**（首位）、流感嗜血杆菌、非典型病原体（肺炎支原体、衣原体、军团菌）。**HAP**（医院获得性肺炎）：入院 > 48h 后发生的肺炎。主要病原体：**G⁻ 杆菌**（铜绿假单胞菌、鲍曼不动杆菌、肠杆菌科）+ **MRSA**。HAP 耐药率显著高于 CAP。
- **知识点**: CAP, HAP, 病原学, 肺炎
- **详见**: [[肺炎]]

### 循环系统

#### Q9. 冠心病的二级预防（ABCDE）
- **来源**: 18预防, 22预防
- **答案**: **A** — **Aspirin**（阿司匹林/抗血小板）+ **Anti-anginal**（抗心绞痛治疗）；**B** — **β 阻滞剂**（β-blocker）+ **Blood pressure control**（血压控制 < 130/80mmHg）；**C** — **Cholesterol lowering**（他汀降脂，LDL-C < 1.8mmol/L）+ **Cigarette cessation**（戒烟）；**D** — **Diabetes management**（糖尿病管理）+ **Diet**（合理饮食）；**E** — **Exercise**（运动）+ **Education**（患者健康教育）。
- **知识点**: 冠心病二级预防, ABCDE, 他汀, 阿司匹林
- **详见**: [[冠心病]]

#### Q10. 急性左心衰的抢救治疗？
- **来源**: 21临八
- **答案**: ① **体位**：端坐位，双腿下垂；② **吸氧**：高流量鼻导管吸氧（6-8L/min），严重者无创或有创通气；③ **吗啡**：3-5mg 缓慢静脉推注（镇静、扩血管、减轻肺水肿）；④ **利尿**：呋塞米 20-40mg 静脉推注；⑤ **扩血管**：硝普钠或硝酸甘油静脉泵入；⑥ **正性肌力药**：多巴酚丁胺/多巴胺/洋地黄类（西地兰 0.2-0.4mg 静脉推注）；⑦ **限制静脉回流**：必要时四肢轮流结扎。
- **知识点**: 急性左心衰, 肺水肿, 抢救流程
- **详见**: [[心力衰竭]]

#### Q11. ST 段抬高心梗（STEMI）的症状及心梗后心衰的 Killip 分级？
- **来源**: 20临八
- **答案**: **STEMI 症状**：① **剧烈胸痛**（胸骨后，压榨性，持续 ≥ 30 分钟，硝酸甘油不缓解）；② 可放射至左肩、左臂、颈、下颌；③ 伴大汗、濒死感、恶心呕吐；④ 可同时出现心律失常、急性左心衰或心源性休克。**Killip 分级**：Ⅰ 级 — 无心衰体征；Ⅱ 级 — 轻中度心衰（肺底啰音 < 50% 肺野 + 奔马律）；Ⅲ 级 — 重度心衰/肺水肿（全肺湿啰音）；Ⅳ 级 — 心源性休克（收缩压 < 90mmHg + 尿少 + 外周灌注不足）。
- **知识点**: STEMI, Killip 分级, 心梗并发症
- **详见**: [[急性心肌梗死]], [[冠心病]]

#### Q12. 心功能 NYHA 分级？
- **来源**: 20预防基医临药, 19预防
- **答案**: **Ⅰ 级** — 体力活动不受限，日常活动无心衰症状。**Ⅱ 级** — 体力活动轻度受限，日常活动可出现症状。**Ⅲ 级** — 体力活动明显受限，轻微活动即可出现症状。**Ⅳ 级** — 任何体力活动均不能进行，静息时即有心衰症状。注意与 Killip 分级的区别：NYHA 用于慢性心衰功能评价，Killip 用于急性心梗后心衰严重度。
- **知识点**: NYHA 分级, 慢性心力衰竭, 功能分级
- **详见**: [[心力衰竭]]

#### Q13. 心衰的 Killip 分级（补充说明）？
- **来源**: 21预防/基医/临药
- **答案**: 见 [[#Q11|ST 段抬高心梗的 Killip 分级]]。Killip 分级主要用于 **AMI 后心衰** 的严重度评估，分为 I-IV 级。I 级无心力衰竭、II 级轻中度肺淤血、III 级严重肺水肿、IV 级心源性休克。
- **知识点**: Killip 分级, AMI, 心力衰竭
- **详见**: [[急性心肌梗死]], [[心力衰竭]]


#### Q14. 原发性高血压的治疗原则？
- **来源**: 20临五上
- **答案**: ① **生活方式干预**（低盐饮食、减重、戒烟限酒、运动）贯穿始终；② **药物治疗时机**：高危/极高危立即启动，中低危可先观察生活方式 1-3 个月；③ **起始用药**：大多数患者联合用药（尤其 2 级以上），优先选择长效制剂。五大类一线药物（ACEI/ARB/CCB/利尿剂/β 阻滞剂）；④ 目标值：**< 140/90 mmHg**（一般人群），< 130/80 mmHg（糖尿病、CKD）。
- **知识点**: 高血压, 治疗原则, 降压目标
- **详见**: [[高血压]]


#### Q15. 阵发性室上性心动过速的表现和处理？
- **来源**: 20临五上
- **答案**: **表现**：突发突止的心悸、心率 150-250 次/分、心律绝对规则、QRS 波正常（除非差传/束支阻滞）。**处理**：① 血流动力学不稳定→**同步直流电复律**；② 稳定者→**刺激迷走神经**（Valsalva、颈动脉窦按摩）→无效则**腺苷** 6mg 快速静脉推注→维拉帕米或地尔硫卓→射频导管消融（根治）。
- **知识点**: PSVT, 腺苷, Valsalva, 电复律
- **详见**: [[心律失常]]


#### Q16. 心力衰竭的诱因？
- **来源**: 21临五上
- **答案**: ① **感染**（呼吸道感染最常见，占首位）；② **心律失常**（房颤最常见）；③ **容量负荷过重**（输液过多过快、高盐饮食）；④ 过度体力活动或情绪激动；⑤ **治疗不当**（停药或减量）；⑥ **心肌缺血**（AMI/不稳定心绞痛）；⑦ 妊娠与分娩；⑧ 贫血、甲亢、肺栓塞。
- **知识点**: 心力衰竭诱因, 感染, 房颤
- **详见**: [[心力衰竭]]


#### Q17. STEMI 的血流再灌注治疗方法与适应症？
- **来源**: 22临五上
- **答案**: **方法一：直接 PCI**（经皮冠状动脉介入治疗）— 适应症：发病**< 12h** 的 STEMI + 首诊可 120min 内完成球囊扩张（door-to-balloon < 90min）。**方法二：溶栓治疗**— 适应症：发病 **< 12h** 的 STEMI，且预计 PCI 延迟 > 120min（door-to-needle < 30min），无溶栓禁忌症。**方法三：CABG**— 适应症：PCI 失败或解剖不适合 PCI 的严重多支病变。
- **知识点**: STEMI, PCI, 溶栓, 再灌注
- **详见**: [[急性心肌梗死]], [[冠心病]]


#### Q18. 慢性左心衰和右心衰的临床表现区别？
- **来源**: 22临五上（缓）
- **答案**:

| | 左心衰竭 | 右心衰竭 |
|---|---------|---------|
| 核心机制 | 肺循环淤血 | 体循环淤血 |
| 呼吸症状 | **端坐呼吸 + 夜间阵发性呼吸困难 + 咳粉红色泡沫痰** | 不明显 |
| 肺部体征 | 双肺底**湿啰音**（从肺底向上扩展） | 通常清晰 |
| 心脏体征 | 左室扩大 + 奔马律（S₃ 奔马律） | 右室扩大 + 三尖瓣反流杂音 |
| 体循环淤血 | 不明显 | **颈静脉怒张 + 肝大 + 下肢水肿 + 肝颈静脉回流征阳性** |

- **知识点**: 左心衰竭, 右心衰竭, 肺淤血, 体循环淤血
- **详见**: [[心力衰竭]]


#### Q19. 房颤的治疗方案？
- **来源**: 22临五上（缓）
- **答案**: ① **抗凝治疗**（预防卒中）：CHA₂DS₂-VASc 评分评估，≥ 2 分（男）/ ≥ 3 分（女）→ 长期口服抗凝药（华法林 INR 2-3 或 NOACs）。② **心室率控制**：非二氢吡啶类 CCB（维拉帕米/地尔硫卓）或 β 阻滞剂或地高辛。③ **节律控制**：药物复律（胺碘酮/普罗帕酮）或**电复律**（血流动力学不稳定者首选）或**导管消融**（有症状的阵发性房颤，药物治疗无效者首选）。④ 上游治疗：控制危险因素（高血压、心衰、甲亢等）。
- **知识点**: 房颤, 抗凝, CHA₂DS₂-VASc, 导管消融
- **详见**: [[心律失常]]

#### Q21. 消化道溃疡的病因和发病机制？
- **来源**: 22口腔
- **答案**: **病因**：① **幽门螺杆菌（Hp）感染**（最重要原因）；② **NSAIDs/阿司匹林** 长期使用；③ 胃酸和胃蛋白酶分泌过多（如胃泌素瘤）；④ 吸烟、饮酒、遗传因素、精神紧张。**发病机制**：黏膜保护因素（黏液-HCO₃⁻屏障、前列腺素、黏膜血流）与损伤因素（胃酸、Hp、NSAIDs）之间的失衡。十二指肠溃疡以**高酸分泌 + Hp 感染**为主；胃溃疡以**黏膜防御功能减弱**为主。
- **知识点**: 消化性溃疡, Hp, NSAIDs, 黏膜防护
- **详见**: [[消化性溃疡]]

#### Q22. 肝硬化的并发症？
- **来源**: 20预防基医临药
- **答案**: ① **上消化道出血**（食管胃底静脉曲张破裂出血 — 最常见且最严重）；② **肝性脑病**（HE，氨中毒机制）；③ **感染**（自发性细菌性腹膜炎 SBP 等）；④ **肝肾综合征**（HRS，功能性肾衰竭）；⑤ **肝性腹水**；⑥ **原发性肝癌**（HCC）；⑦ **肝肺综合征**（HPS）；⑧ **门静脉血栓形成**；⑨ **电解质和酸碱平衡紊乱**（低钠血症为主）。
- **知识点**: 肝硬化, 并发症, 门静脉高压
- **详见**: [[肝硬化]]

#### Q23. 肝硬化腹水的治疗？
- **来源**: 21口腔
- **答案**: ① **限制钠水摄入**：钠 < **2g/d**（氯化钠 5g/d），水限制仅在严重稀释性低钠血症（< 125 mmol/L）时考虑；② **利尿剂**：首选**螺内酯**（安体舒通 100mg/d 起始），效果不佳联合**呋塞米**（40mg/d 起始），比例 100:40；③ **难治性腹水**：腹腔穿刺大量放液（LVP > 5L）+ 输注白蛋白（每放 1L 腹水输白蛋白 6-8g）；④ **TIPS**（经颈静脉肝内门体分流术）。
- **知识点**: 肝硬化腹水, 螺内酯, 钠限制, TIPS
- **详见**: [[肝硬化]], [[肝性腹水]]

### 肾脏系统

#### Q29. AKI 和 CKD 的鉴别诊断？
- **来源**: 21临八
- **答案**:

| 鉴别要点 | AKI（急性肾损伤） | CKD（慢性肾衰竭） |
|---------|------------------|------------------|
| 病程 | **数日-数周** | **数月-数年** |
| 肾脏大小 | 正常或增大 | **缩小**（双肾萎缩） |
| 贫血程度 | 轻度或无 | **中重度贫血**（病程长、EPO 不足） |
| 钙磷代谢 | 通常正常 | **低钙高磷**、继发性甲旁亢 |
| 可逆性 | 病因去除后可恢复 | **不可逆** |
| 尿量 | 减少（或少尿型） | 夜尿增多（多尿→少尿） |

- **知识点**: AKI, CKD, 肾脏大小, 贫血, 肾衰竭鉴别
- **详见**: [[慢性肾衰竭]]

#### Q30. 急性肾前性 AKI 的病因及对应疾病和诱发因素？
- **来源**: 20临八
- **答案**: 肾前性 AKI = **肾脏灌注不足**（尿液浓缩、尿钠低、BUN/Cr > 20、FENa < 1%）。病因分类：① **血容量真正不足** — 出血、呕吐/腹泻（消化液丢失）、烧伤、利尿过度、胰腺炎→第三间隙；② **有效循环容量不足** — 心力衰竭（心排减低）、肝硬化腹水（内脏血管扩张+全身容量不足）、肾病综合征（低白蛋白血症）、脓毒症（分布性休克）。
- **知识点**: 肾前性 AKI, 有效循环容量, FENa, BUN/Cr
- **详见**: [[慢性肾衰竭]]


#### Q31. 急性肾损伤的分类和病因？（英文题）
- **来源**: 20临五下
- **答案**: 见 [[#Q25|名词解释 - AKI]]。**肾前性**（有效循环容量不足：出血、休克、心衰、肝硬化、脱水）；**肾性**（ATN 最常见 — 缺血/肾毒性药物/感染/横纹肌溶解/血红蛋白尿；急性间质性肾炎；急性肾小球肾炎等）；**肾后性**（输尿管/膀胱/尿道梗阻 — 结石、肿瘤、血块、BPH、神经源性膀胱）。
- **知识点**: AKI 分类, 肾前性, 肾性, 肾后性
- **详见**: [[慢性肾衰竭]]


#### Q32. 尿路感染的感染途径和并发症？
- **来源**: 19临五下
- **答案**: **感染途径**：① **上行感染**（最主要，肠道菌群→尿道口→膀胱→输尿管→肾盂）；② 血行感染（金黄色葡萄球菌菌血症 → 肾）；③ 淋巴道感染（极少见）。**并发症**：① **肾乳头坏死**；② **肾周脓肿**；③ 尿源性**脓毒症**（urosepsis）；④ 慢性肾盂肾炎（反复感染→肾瘢痕→肾功能减退）；⑤ 妊娠期可引起早产/低体重儿。
- **知识点**: UTI, 上行感染, 肾盂肾炎
- **详见**: [[肾盂肾炎]]


#### Q33. 肾病综合征的并发症及其发生机制？
- **来源**: 21临五下
- **答案**: ① **感染**（最常见）：大量蛋白尿→免疫球蛋白和补体丢失→免疫功能低下→细菌感染（尤其肺炎链球菌性腹膜炎）。② **血栓栓塞**：低白蛋白血症→肝脏代偿性合成蛋白质增加（包括凝血因子）+ 抗凝物质（ATⅢ）丢失→高凝状态→肾静脉血栓/肺栓塞。③ **急性肾损伤**：有效循环容量不足（低白蛋白血症→血液浓缩→肾前性 AKI）或急性间质性肾炎。④ **蛋白质营养不良 + 高脂血症**。
- **知识点**: 肾病综合征, 并发症, 感染, 血栓栓塞
- **详见**: [[原发性肾小球疾病]]


#### Q34. 慢性肾脏病的临床分期及相应处理措施？
- **来源**: 22临五下
- **答案**:

| 分期 | GFR (mL/min/1.73m²) | 处理措施 |
|------|---------------------|---------|
| **1 期** | ≥ 90（有肾损伤证据） | 病因治疗、延缓进展 |
| **2 期** | 60-89 | 评估和延缓进展速度 |
| **3a 期** | 45-59 | 评估和治疗并发症（贫血、高血压、骨矿物质代谢异常等） |
| **3b 期** | 30-44 | 同上，更积极管理 |
| **4 期** | 15-29 | **准备肾脏替代治疗**（透析通路建立、肾移植评估） |
| **5 期** | < 15 或透析中 | **肾脏替代治疗**（血液透析/腹膜透析/肾移植） |

**处理总原则**：控制原发病 + 延缓 CKD 进展（控制血压 < 130/80、ACEI/ARB 降低蛋白尿、控制血糖、低蛋白饮食）+ 治疗并发症（贫血→ESA+铁剂、CKD-MBD→磷结合剂+活性维生素 D、心血管风险管理）。
- **知识点**: CKD 分期, GFR, 肾脏替代治疗
- **详见**: [[慢性肾衰竭]]

### 内分泌系统

#### Q40. 糖尿病的诊断标准及分型？
- **来源**: 22预防
- **答案**: **诊断标准**（满足任一条）：① **空腹血糖 ≥ 7.0 mmol/L**；② **OGTT 2h 血糖 ≥ 11.1 mmol/L**；③ **HbA1c ≥ 6.5%**；④ 有典型症状（多饮、多尿、多食、体重减轻）+ 随机血糖 ≥ 11.1 mmol/L。**分型**：**1 型**（自身免疫性胰岛β细胞破坏，胰岛素绝对缺乏，GAD65/IAA/ICA 阳性）；**2 型**（胰岛素抵抗 + 相对分泌不足，最常见）；**特殊类型**（MODY、线粒体糖尿病、继发性糖尿病）；**妊娠期糖尿病**（GDM）。
- **知识点**: 糖尿病诊断, OGTT, HbA1c, 分型
- **详见**: [[糖尿病]], [[1型糖尿病]], [[2型糖尿病]]

#### Q41. 糖尿病并发症？
- **来源**: 21临八
- **答案**: **急性并发症**：① 糖尿病酮症酸中毒（DKA）— 1 型为主；② 高血糖高渗状态（HHS）— 2 型为主；③ 乳酸性酸中毒；④ 低血糖（药物过量/饮食不当）。**慢性并发症**：① 大血管病变 — 心梗、脑卒中、周围动脉病；② 微血管病变 — **视网膜病变**（失明）、**糖尿病肾病**（终末期肾病）；③ **神经病变** — 周围神经病变（手套/袜套感）、自主神经病变（胃轻瘫、体位性低血压）；④ 糖尿病足。
- **知识点**: DKA, HHS, 糖尿病并发症, 微血管
- **详见**: [[糖尿病]]

#### Q42. 甲亢危象的治疗（英文题）？
- **来源**: 20临八
- **答案**: ① **抑制甲状腺激素合成**：口服或鼻饲 **PTU**（丙硫氧嘧啶）首次 600mg，后 200mg q4-6h；② **抑制甲状腺激素释放**：PTU 后 1h 给 **碘剂**（Lugol 液或碘化钠静滴）；③ **β 阻滞剂**：**普萘洛尔** 20-80mg q4-6h 口服或静注控制心率（注意心衰禁忌）；④ **糖皮质激素**：氢化可的松 200-300mg/d 静脉滴注（抑制 T₄→T₃ 转换+防止肾上腺功能不全）；⑤ **支持治疗**：降温、补液、纠正电解质紊乱。
- **知识点**: 甲亢危象, PTU, 碘剂, β阻滞剂
- **详见**: [[甲状腺功能亢进症]]

#### Q43. 内分泌功能亢进疾病有哪些治疗手段？
- **来源**: 20预防基医临药
- **答案**: ① **药物治疗**：抑制激素合成的药物（如 PTU 抑制甲状腺激素合成、甲巯咪唑、溴隐亭抑制 PRL）；② **放射性核素治疗**：¹³¹I 破坏过度增生的内分泌组织（如 Graves 病）；③ **手术切除**：腺瘤/增生组织切除术（如甲状旁腺腺瘤切除、肾上腺腺瘤切除、嗜铬细胞瘤切除）；④ **介入治疗**：选择性血管栓塞（如肝脏转移性内分泌肿瘤）；⑤ **靶向治疗**：肽受体放射性核素治疗（PRRT）。
- **知识点**: 内分泌功能亢进, 药物治疗, 手术治疗, 放射碘
- **详见**: [[甲状腺功能亢进症]]

#### Q44. ¹³¹I 治疗的适应症、禁忌症、并发症？
- **来源**: 20临五下
- **答案**: **适应症**：① Graves 病（尤其甲状腺肿大中度以上、对 ATD 过敏/复发/不能耐受者）；② 毒性多结节性甲状腺肿；③ 毒性甲状腺腺瘤。**禁忌症**：**妊娠和哺乳期女性**（绝对禁忌）。**并发症**：① **永久性甲减**（最主要，随着时间发生率递增，需终身 L-T₄ 替代）；② 放射性甲状腺炎（一过性疼痛）；③ 甲状腺危象（罕见，治疗前需 ATD 预处理）；④ 眼病加重（吸烟和严重 Graves 眼病患者的相对禁忌）。
- **知识点**: ¹³¹I 治疗, Graves 病, 甲减, 放射碘

#### Q46. 糖尿病患者使用胰岛素的适应证？
- **来源**: 22临五下
- **答案**: ① **1 型糖尿病**（绝对适应证，终身胰岛素替代）；② **2 型糖尿病**出现以下情况：口服降糖药失效（HbA1c ≥ 7% 经 ≥ 2 种口服药足量治疗后）、**DKA/HHS**（酮症酸中毒/高渗高血糖状态）、严重感染/手术/创伤急性期、**妊娠期糖尿病**（口服药禁忌，常用胰岛素）、严重肝肾功能不全、显著体重下降/出现消耗性症状、新诊断血糖极高（HbA1c ≥ 9.0% 或血糖 ≥ 16.7 mmol/L）伴明显症状。

#### Q47. 痛风的自然病程与临床表现？

#### Q48. 痛风的临床分期与治疗原则？
- **来源**: 21临五下

#### Q49. 中毒治疗的原则和主要方法？
- **来源**: 20临五下, 19临五下
- **答案**: **原则**：① **立即终止毒物接触**（脱离现场、脱去污染衣物、清洗皮肤/眼）；② **清除未吸收的毒物**（催吐、洗胃、活性炭吸附、导泻/灌肠）；③ **促进已吸收毒物排泄**（补液+利尿、碱化尿液、血液净化 — 血液透析/灌流/血浆置换）；④ **特效解毒剂**（有机磷→阿托品+解磷定，氰化物→亚硝酸盐+硫代硫酸钠，重金属→金属螯合剂，CO 中毒→高压氧）；⑤ **对症支持治疗**（维持呼吸循环、保护脏器功能）。

## 四、病例分析
### 呼吸系统

#### Q1. COPD / 慢性阻塞性肺疾病急性加重 + 肺心病
- **来源**: 20预防基医临药, 18预防, 22口腔
- **病例要点**: 老年男性，长期吸烟史（30余年），反复咳嗽咳痰多年，秋冬季节加重，活动后气促。查体：桶状胸，肺部叩诊过清音，双肺底闻及干湿啰音。血气：PaO₂ 降低，PaCO₂ 升高，pH 降低 → **II 型呼吸衰竭 + 呼吸性酸中毒**。胸片：肺气肿征，可能合并肺纹理增粗、右下肺动脉增宽（肺心病征象）。

- **问题与答案**:
  1. **最可能的诊断及依据**: **COPD 急性加重期（AECOPD）+ II 型呼吸衰竭 + 慢性肺源性心脏病（右心衰竭失代偿期）**。依据：① 长期大量吸烟史 + 多年慢性咳嗽咳痰；② 桶状胸、叩诊过清音（肺气肿）；③ 血气示 PaO₂ < 60mmHg + PaCO₂ > 50mmHg（II 型呼衰）；④ 双下肢浮肿、颈静脉充盈、肝大等右心衰体征。
  2. **鉴别诊断**: 支气管哮喘（发作性、可逆性、病程年轻化）；支气管扩张症（大量脓痰、反复咯血、杵状指）；充血性心力衰竭（以左心衰为主）；肺结核。
  3. **进一步检查**: 肺功能（吸入支气管扩张剂后 FEV₁/FVC）；超声心动图（评估肺动脉压力 + 右心功能）；痰培养及药敏；心电图/动态心电图；BNP/NT-proBNP；肝脏超声（排除淤血性肝病）。
  4. **治疗原则**: ① 氧疗（低流量鼻导管吸氧 1-2L/min，目标 SpO₂ 88-92%）；② 支气管舒张剂（短效 β₂ 激动剂 + 异丙托溴铵）；③ 糖皮质激素（全身 5-7 天）；④ 抗生素（如痰量增多、脓痰）；⑤ 利尿剂（呋塞米 + 螺内酯减轻右心衰水肿）；⑥ 如有肺性脑病：无创通气 → 必要时有创通气。

- **知识点**: AECOPD, II型呼衰, 肺心病失代偿, 氧疗
- **详见**: [[慢性阻塞性肺疾病]], [[慢性肺源性心脏病]], [[呼吸衰竭]]

#### Q2. 支气管哮喘急性严重发作
- **来源**: 20临八
- **病例要点**: 20 岁女性，感冒后出现咳嗽、胸闷、气促、喘息，服用氨茶碱无效，面色苍白、心率快、血压低，听诊呼吸音弱、哮鸣音，叩诊过清音。血嗜酸性粒细胞 8%（升高，正常 < 5%），ECG 窦性心动过速，X 线肺气肿。PaO₂ < 60mmHg，PaCO₂ 偏高，pH 7.30，BE -6（代谢性酸中毒合并呼吸性酸中毒 → 重症哮喘）。

- **问题与答案**:
  1. **诊断及依据**: **支气管哮喘急性严重发作（status asthmaticus）**。依据：① 年轻女性，有上感诱因→呼吸困难、喘息进行性加重；② 查体双肺哮鸣音、呼吸音减弱（"沉默肺"前兆需警惕）；③ 嗜酸性粒细胞 8%；④ 血气 PaO₂ < 60mmHg + PaCO₂ 偏高（正常哮喘 PaCO₂ 应降低，一旦 PaCO₂ 升高提示气道严重阻塞）。⑤ 对支气管舒张剂反应差。
  2. **鉴别诊断及要点**: COPD（多见于老年人、长期吸烟、不可逆性气流受限）；急性左心衰（粉红色泡沫痰、双肺底对称性湿啰音、奔马律）；上气道梗阻（吸气性呼吸困难、三凹征，胸部影像正常）；过敏性肺炎/ABPA（影像学有游走性浸润影）。
  3. **治疗措施**: ① **氧疗**（目标 SpO₂ > 90%）；② **吸入速效 β₂ 激动剂**（沙丁胺醇）持续雾化 + 异丙托溴铵；③ **全身糖皮质激素**（甲泼尼龙 40-80mg/d 或氢化可的松）；④ 静脉茶碱类（氨茶碱已无效→换其他）；⑤ 补液、纠正酸碱失衡（重点是通气支持而非 NaHCO₃）；⑥ 若恶化→**无创通气**→必要时**气管插管有创通气**。

- **知识点**: 重症哮喘, 沉默肺, 嗜酸性粒细胞, 机械通气
- **详见**: [[支气管哮喘]], [[呼吸衰竭]]

#### Q3. 肺炎/肺脓肿病例
- **来源**: 21预防/基医/临药
- **病例要点**: 发热、咳嗽、咳大量脓痰（有臭味提示合并厌氧菌感染），胸片/CT 示肺实变伴空洞形成及气液平面，白细胞明显增高。可能为吸入性所致的混合感染（需氧菌 + 厌氧菌）。

- **问题与答案**:
  1. **初步诊断和诊断依据**: **肺脓肿**（依据：咳嗽 + 大量**脓臭痰** + 影像学示空洞内**气液平面** + 白细胞增高）。
  2. **鉴别诊断**: 癌性空洞（壁厚、不规则、增强后明显强化、转移征象）；结核性空洞（壁上无液平或少量液平、结核中毒症状、痰找抗酸杆菌）；肺囊肿继发感染（囊壁薄且光滑）。
  3. **进一步检查**: 痰培养（需氧+厌氧）+ 药敏；支气管镜检查（排除支气管异物或肿瘤堵塞）；血培养（发热期）。
  4. **治疗原则**: ① **抗感染**：覆盖需氧菌 + **厌氧菌**（如**青霉素 G + 甲硝唑**或克林霉素，或**哌拉西林/他唑巴坦**）；② 体位引流促进排痰；③ 抗生素疗程 **6-8 周**（需至空洞闭合、炎症吸收）；④ 内科治疗无效者考虑经皮穿刺引流或手术切除。

- **知识点**: 肺脓肿, 厌氧菌感染, 抗生素疗程
- **详见**: [[肺炎]]
### 循环系统

#### Q4. 急性心肌梗死（STEMI）+ 心源性休克风险
- **来源**: 21口腔
- **病例要点**: 心绞痛发展而来的心梗，伴高血压、糖尿病病史（高危因素组合）。近期胸痛加重→持续不缓解→出现心衰/休克表现。

- **问题与答案**:
  1. **诊断**: **急性 ST 段抬高型心肌梗死（STEMI）+ Killip Ⅱ/Ⅲ 级**。依据：缺血性胸痛持续 ≥ 30 分钟 + ECG ST 段抬高或新出现 LBBB + cTn 升高。
  2. **进一步检查**: 18 导联 ECG、心肌标志物（hs-cTnI/cTnT q3h、CK-MB）、超声心动图（心腔大小、EF、机械并发症）、冠脉造影（确诊+直接 PCI 机会）。
  3. **处理措施**: ① **紧急再灌注**：直接 PCI（door-to-balloon < 90min）或溶栓（如 PCI 不可及且发病 < 12h）；② **双联抗血小板**：阿司匹林 300mg + 替格瑞洛 180mg 负荷量；③ 抗凝：肝素或低分子肝素；④ 控制血糖（胰岛素泵）；⑤ 降压/优化心衰治疗（避免 ACEI 在低血压时使用）；⑥ 并发症监测：心律失常（备除颤仪）、机械性并发症（室间隔穿孔、游离壁破裂、乳头肌断裂）。

- **知识点**: STEMI, PCI, 双联抗血小板, 高危因素
- **详见**: [[急性心肌梗死]], [[冠心病]]

### 消化系统

#### Q5. 肝硬化 + 食管静脉曲张破裂出血
- **来源**: 22预防
- **病例要点**: 肝硬化患者出现呕血或黑便，腹水加重。查体：肝病面容、蜘蛛痣、肝掌，腹部移动性浊音阳性。

- **问题与答案**:
  1. **主要诊断**: **肝硬化失代偿期 + 食管胃底静脉曲张破裂出血**。依据：肝硬化病史/体征 + 急性上消化道出血表现（呕血/黑便）+ 门静脉高压征象。
  2. **鉴别诊断**: 消化性溃疡出血（胃镜鉴别）、急性胃黏膜病变、门脉高压性胃病出血。
  3. **食管静脉曲张出血的治疗原则**: ① **液体复苏**（晶体液 + 血制品复苏，避免过度/过快扩容）；② **血管活性药物**（**特利加压素**/生长抑素/奥曲肽）降低门脉压；③ **预防性抗生素**（头孢曲松，降低 SBP 和死亡率）；④ **急诊胃镜检查 + 内镜下套扎术（EVL）**（12h 内实施）；⑤ 若内镜失败 → **三腔二囊管压迫**（临时桥接措施）→ TIPS 或急诊手术。
  4. **后续长期治疗**: 非选择性 β 阻滞剂（普萘洛尔/卡维地洛）一级/二级预防 + 定期胃镜套扎至曲张静脉消失。

- **知识点**: 肝硬化, 食管静脉曲张, EVL, 特利加压素, TIPS
- **详见**: [[肝硬化]], [[肝性腹水]]

#### Q6. 急性胰腺炎
- **来源**: 21临八
- **病例要点**: 中上腹持续性剧烈疼痛，向背部放射，伴恶心呕吐。血清淀粉酶/脂肪酶显著升高（≥ 正常上限 3 倍）。CT 示胰腺肿大、周围渗出。

- **问题与答案**:
  1. **诊断及其依据**: **急性胰腺炎**（轻症水肿型或重症坏死型依据是否有器官衰竭/局部并发症）。依据：① 急性上腹痛伴恶心呕吐；② 血清淀粉酶/脂肪酶 > 正常上限 **3 倍**（或脂肪酶升高）；③ CT 示胰腺肿胀、胰周渗出/积液。
  2. **鉴别诊断**（至少 2 种）: 消化性溃疡穿孔（膈下游离气体、板状腹）；急性胆囊炎/胆管炎（Murphy 征阳性 + B 超胆囊壁增厚）；肠梗阻（腹胀、气过水声、腹部立位平片液气平面）；急性心梗（尤其下壁心梗可表现为上腹痛，ECG + cTn 鉴别）。
  3. **并发症**（至少 3 种）: ① **急性胰周积液**/假性囊肿（≥ 4 周后形成囊壁，> 6cm 有症状需引流）；② **胰腺坏死 + 感染**（CT 示气泡征，细针穿刺培养，抗生素 + 必要时手术清创）；③ **SIRS → MODS**（早期最常见的死亡原因）；④ **ARDS**、AKI（严重病例并发）。
  4. **治疗原则**: ① **禁食 + 胃肠减压** + 液体复苏（大量晶体液，最初 24h 补充量可达 250-500mL/h）；② 止痛（哌替啶，避免吗啡引起 Oddi 括约肌痉挛）；③ **营养支持**（早期肠内营养优于肠外营养）；④ 抗生素仅用于感染性坏死；⑤ ERCP ± EST 用于胆源性胰腺炎。

- **知识点**: 急性胰腺炎, 淀粉酶/脂肪酶, 假性囊肿, SIRS, 液体复苏
- **详见**: [[急性胰腺炎]]


#### Q7. 肝硬化上消化道出血病例
- **来源**: 21临五上
- **病例要点**: 乙肝病史，呕血 200mL + 黑便，贫血貌，脾大，三系下降，白蛋白下降，超声示肝硬化+脾大。

- **问题与答案**:
  1. **诊断及依据**: **上消化道出血（食管胃底静脉曲张破裂出血可能大）+ 乙肝肝硬化失代偿期（Child-Pugh A 级）+ 脾肿大 + 贫血**。依据：① 呕血+黑便 → 上消出血（部位在屈氏韧带以上）；② 乙肝病史+超声肝硬化+脾大+白蛋白下降 → 肝硬化失代偿，出血最可能来源于食管胃底静脉曲张破裂；③ 三系减少 → 脾功能亢进；④ 白蛋白下降而转氨酶正常 → 肝功能受损但无明显活动性炎症（代偿期或稳定期）。
  2. **治疗原则**: ① 液体复苏（晶体+必要时血制品），避免过度扩容加重门脉压；② **血管活性药物**：特利加压素/生长抑素/奥曲肽降低门脉压；③ **预防性抗生素**（头孢曲松）；④ **急诊胃镜检查+内镜下套扎术**（12h 内）；⑤ 二级预防：非选择性 β 阻滞剂（普萘洛尔/卡维地洛）+ 定期胃镜套扎至曲张静脉消失；⑥ 护肝治疗；⑦ 必要时评估肝移植。

- **详见**: [[肝硬化]], [[肝性腹水]], [[肝性脑病]]


#### Q8. 肝硬化合并肝性脑病病例
- **来源**: 22临五上
- **病例要点**: 55 岁女性，乙肝病史 12 年未抗病毒。腹壁静脉曲张。呕血黑便入院 → 止血后出现精神错乱、胡言乱语。

- **问题与答案**:
  1. **呕血黑便的原因**: 食管胃底静脉曲张破裂出血（肝硬化门静脉高压最致命并发症之一）。
  2. **目前的诊断及处理**: **诊断**：① 乙肝肝硬化失代偿期（门静脉高压→呕血/黑便 + 腹壁静脉曲张）；② **肝性脑病**（HE，诱因：上消化道出血→肠道产氨增加→血氨升高→中枢神经系统功能障碍，表现为精神错乱/胡言乱语→符合 HE **2-3 期**）。**处理**：① 去除诱因（出血已止）；② 减少肠道氨吸收：**乳果糖**口服/灌肠（调整至 2-3 次软便/天）、**利福昔明**（不可吸收抗生素）；③ 降血氨药物（门冬氨酸鸟氨酸、精氨酸）；④ 开始抗 HBV 病毒治疗（恩替卡韦/替诺福韦）；⑤ 营养支持（限制蛋白摄入至 HE 改善，恢复后逐渐增加至 1.2-1.5 g/kg/d）；⑥ 评估肝移植。

- **详见**: [[肝性脑病]], [[肝硬化]]

### 血液系统

#### Q9. 缺铁性贫血病例
- **来源**: 21临五下
- **病例要点**: 女性，产后月经量增多 2 年，乏力、心悸。面色苍白。实验室：MCV ↓, MCH ↓, MCHC 279g/L（↓），Hb 70g/L（中度贫血），血清铁 ↓，血清铁蛋白 ↓，总铁结合力 > 80 μmol/L（↑），转铁蛋白饱和度 8%（↓ < 15%）。

- **问题与答案**:
  1. **诊断及依据**: **缺铁性贫血（IDA，中度）+ 月经过多（病因）**。依据：小细胞低色素性贫血（MCV↓, MCH↓, MCHC↓）+ 血清铁↓ + 铁蛋白↓ + TIBC↑ + TS < 15% → 经典 IDA 铁代谢谱。病史 2 年产后月经增多 → 慢性失血为铁缺乏原因。
  2. **治疗原则**: ① **口服铁剂**：硫酸亚铁 300mg tid（或富马酸亚铁等）空腹服用、同服维生素 C 促进吸收；② 补铁至 Hb 正常后继续 **3-6 个月**（补充储存铁，血清铁蛋白恢复正常方可停药）；③ 病因治疗：妇科就诊评估和处理月经过多；④ 饮食建议：增加含铁食物（红肉、动物肝脏等），但不可依赖饮食纠正已发生的 IDA。

- **详见**: [[缺铁性贫血]], [[贫血]]

## 五、考试提示

### 整体特点
- 选择题重复率较高（部分年份超过 50%），历年真题有较好的参考价值。
- 选择题有一定超纲比例（约 10-20%），不必过度焦虑。
- 大题（简答 + 病例分析）基本遵循教学大纲 "掌握" 层级的要求。
- 英文题常在名解和简答中出现（尤其是诊断标准、并发症名称、分级）。
- 不同专业侧重点不同：临八覆盖较全；预防/口腔侧重呼吸和循环系统（上册书比重较大）。

### 各系统高频提示
- **呼吸系统**：病例分析题频率最高（COPD、哮喘、肺炎/肺脓肿），血气分析判断酸碱失衡是必考技能。抗结核治疗原则反复出现。
- **循环系统**：心律失常心电图判断、高血压靶器官损害、心衰 NYHA/Killip 分级（两者要区分清楚）、冠心病二级预防（ABCDE 记忆法）。
- **消化系统**：肝硬化并发症（尤其是上消化道出血、肝性脑病、肝肾综合征）为必考内容；UC/CD 鉴别诊断定期出现。
- **血液系统**：缺铁性贫血实验室检查、淋巴瘤分型和治疗、DIC 诊断标准为高频主题。
- **泌尿系统**：肾病综合征病理分型、AKI/CKD 鉴别、肾盂肾炎。
- **内分泌系统**：糖尿病诊断标准及分型、甲亢危象（诊断+治疗流程）、胰岛素不良反应。
- **风湿免疫**：SLE 诊断标准和特异性抗体（抗 Sm、抗 dsDNA）。
- **危重症与理化因素**：休克的病理生理机制；有机磷中毒的 ChE 和毒性分级。

### 英文高频词
- Killip classification / NYHA classification
- Iron deficiency anemia / IDA
- Hepatorenal syndrome / HRS
- Hepatic encephalopathy (clinical stages of HE)
- Thyroid crisis / Thyrotoxic crisis
- Acute respiratory distress syndrome (ARDS)
- ST-segment elevation myocardial infarction (STEMI)
- Pancoast tumor
- Disseminated intravascular coagulation (DIC)
- Chronic obstructive pulmonary disease (COPD)

## 考点出题频数统计

> 以下自动统计各知识点在本题库的 `详见` 字段中被关联的次数，反映其出题频率。
```dataviewjs
// 统计内科学历年真题合集中每题 "详见" 指向知识点的出题频数
// 另立一列统计基础医学/预防医学/临床药学三个专业的出题数
const file = dv.current().file;
const content = await dv.io.load(file.path);
const lines = content.split('\n');

const totalCounts = new Map(); // 总出题数
const bpCounts = new Map();    // 基础/预防/临药出题数

let currentSource = '';

for (const line of lines) {
  // 匹配来源行
  const sourceMatch = line.match(/- \*\*来源\*\*:\s*(.+)/);
  if (sourceMatch) {
    currentSource = sourceMatch[1];
    continue;
  }

  // 匹配详见行
  const detailMatch = line.match(/- \*\*详见\*\*:\s*(.+)/);
  if (detailMatch && currentSource) {
    const linkText = detailMatch[1];
    const wikiLinks = linkText.match(/\[\[([^\]]+)\]\]/g);
    if (wikiLinks) {
      const isBPMajor = /预防|基医|临药/.test(currentSource);
      for (const link of wikiLinks) {
        let noteName = link.slice(2, -2);
        if (noteName.includes('|')) noteName = noteName.split('|')[0];
        if (noteName.includes('#')) noteName = noteName.split('#')[0];
        // 总是计入总数
        totalCounts.set(noteName, (totalCounts.get(noteName) || 0) + 1);
        // 如果是基医/预防/临药来源，额外计入
        if (isBPMajor) {
          bpCounts.set(noteName, (bpCounts.get(noteName) || 0) + 1);
        }
      }
    }
    // 处理完详见后重置当前来源，避免跨题污染
    currentSource = '';
  }
}

// 按总数降序排列
const allNotes = [...new Set([...totalCounts.keys(), ...bpCounts.keys()])];
const sorted = allNotes
  .map(note => ({
    note,
    total: totalCounts.get(note) || 0,
    bp: bpCounts.get(note) || 0
  }))
  .sort((a, b) => b.total - a.total);

const totalQuestions = sorted.reduce((sum, item) => sum + item.total, 0);
const totalBP = sorted.reduce((sum, item) => sum + item.bp, 0);

dv.paragraph("共 **" + sorted.length + "** 个知识点被关联，总关联 **" + totalQuestions + "** 题次（其中基础/预防/临药 **" + totalBP + "** 题次）");

dv.table(
  ["排名", "知识点", "总出题数", "基础/预防/临药"],
  sorted.map((item, i) => [
    "#" + (i + 1),
    dv.fileLink(item.note),
    item.total,
    item.bp
  ])
);
```
