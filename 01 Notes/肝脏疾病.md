# 肝脏疾病

> 参见：[[肝]] | [[肝硬化]] | [[门静脉高压]] | [[肝功能分级]] | [[影像学诊断]]

## 概述

肝脏是人体最大的实质性脏器，大部分位于右侧季肋部，小部分横过腹中线达左季肋部。肝的储备功能和再生能力极强，切除正常肝实质的 70%～80% 仍可维持正常生理功能，且能在半年内再生至接近原重量。肝对缺氧敏感，常温下单次入肝血流阻断不宜超过 15～20 分钟（合并肝硬化者耐受更差）。

## 肝脏外科解剖

### 韧带与固定

| 韧带 | 位置 | 作用 |
|------|------|------|
| 左三角韧带、右三角韧带 | 膈面 | 固定肝于膈肌 |
| 冠状韧带 | 膈面 | 固定肝于膈肌 |
| 镰状韧带 | 前面 | 固定肝于前腹壁 |
| 肝圆韧带 | 前面 | 脐静脉闭锁后的遗迹 |
| 肝胃韧带 | 脏面 | 连接肝与胃小弯 |
| 肝十二指肠韧带（**肝蒂**） | 脏面 | 含门静脉、肝动脉、淋巴管、淋巴结和神经 |

### 肝门

| 肝门 | 位置 | 通过结构 | 方向 |
|------|------|----------|------|
| **第一肝门** | 肝脏面横沟 | 门静脉、肝动脉、肝总管→分出左、右干入肝 | 入肝 |
| **第二肝门** | 肝后上方静脉窝 | 三条肝静脉（左、中、右）→ 下腔静脉 | 出肝 |
| **第三肝门** | 肝后方 | 数支肝短静脉（尾状叶）→ 下腔静脉 | 出肝 |

在肝实质内，门静脉、肝动脉和肝内胆管走向一致，共同包裹在 **Glisson 鞘**内。肝静脉则独立走行于 Glisson 系统之间。

### Couinaud 分段

以肝静脉及门静脉在肝内的分布为基础，将肝分为 **8 段**。每个段都有相对应的 Glisson 系统进入，也有相对应的肝静脉系统流出。IHPBA 将其稍作修整为三级划分："半肝"→"区"→"段"，将 Couinaud 的Ⅰ段划分为 1 段和 9 段。

传统的肝分区法将肝分为左外叶、左内叶、右前叶、右后叶和尾状叶。

![[04 Attachments/外科-肝脏-Couinaud分段.webp]]

### 肝小叶与微细结构

肝的基本结构为肝小叶：中央静脉 + 放射状排列的单层肝细胞索 + 肝窦（窦状隙）。肝窦壁上附有 **Kupffer 细胞**（单核吞噬细胞系统）。相邻肝小叶之间为门管区，含肝动脉、门静脉和胆管小分支。肝窦一端与肝动脉和门静脉小分支相通，另一端与中央静脉连接。肝窦面肝细胞膜微绒毛伸入 **Disse 间隙**，参与物质交换。相邻肝细胞膜凹陷形成胆小管。

### 血供

| 来源 | 供血比例 | 供氧比例 | 特点 |
|------|----------|----------|------|
| 肝动脉 | 25%～30% | 40%～60% | 压力大、含氧量高 |
| 门静脉 | 70%～75% | ~50% | 来自胃肠道富含营养的血流 |

肝总血流量约 **1500ml/min**，占心排血量的 1/4。

### 生理功能

| 功能 | 要点 |
|------|------|
| 分泌胆汁 | 800～1000ml/日，帮助脂肪消化及脂溶性维生素吸收 |
| 代谢 | 糖原合成与分解；蛋白质合成（白蛋白、纤维蛋白原、凝血酶原）、脱氨和转氨；脂肪代谢；维生素（A、B、C、D、E、K）代谢与储存；激素灭活（雌激素、抗利尿激素） |
| 凝血 | 合成除 Ⅲ、Ⅳ 外的所有凝血因子；储存维生素 K |
| 解毒 | 吞噬、分解、氧化、结合 → 将毒物转化为无毒 |
| 免疫 | Kupffer 细胞吞噬细菌和碎屑，NK 细胞 |
| 其他 | 间接参与造血；储血调节循环血量 |

> 肝硬化时雌激素灭活减退→蜘蛛痣、肝掌、男性乳房发育；抗利尿激素和醛固酮增多→水钠潴留→水肿和腹水。严重肝损害→低蛋白血症、凝血功能障碍、血氨升高（肝性脑病）。

## 肝脏偶发肿块的规范诊疗程序

对于体检偶然发现的肝脏占位性病变，应遵循以下诊疗程序：

1. **病史与体检**：肝炎病史（HBV/HCV）、饮酒史、糖尿病史、口服避孕药史、流行地区居住史（包虫病）
2. **实验室检查**：AFP、CEA、CA19-9、肝功能、乙肝/丙肝血清标志物
3. **超声**：首选筛查方法，可初步鉴别囊性/实性
4. **增强 CT/MRI**：明确性质
   - 快进快出 → 肝细胞癌（HCC）
   - 慢进慢出、周边胆管扩张 → 肝内胆管癌（ICC）
   - 周边结节状渐进性强化 → 海绵状血管瘤
   - [[牛眼征]]、多发 → [[转移性肝癌]]
5. **必要时**：肝动脉造影、超声引导下穿刺活检
6. **处理**：根据性质决定观察随访、手术切除、消融或其他治疗

## 肝脓肿

### 细菌性肝脓肿

#### 病因

全身细菌性感染（尤其腹腔内感染）时，如免疫力低下，可发生肝脓肿。**糖尿病**病人是高发人群。

细菌侵入肝脏的途径：

| 途径 | 占比 | 说明 |
|------|------|------|
| **胆道** | 41.4% | **最主要原因**：胆道梗阻→化脓性胆管炎→细菌沿胆管上行 |
| 肝动脉 | 23.9% | 菌血症（细菌性心内膜炎、化脓性骨髓炎等） |
| 门静脉 | 7.8% | 坏疽性阑尾炎、胃肠道憩室炎等→细菌突破肠道屏障 |
| 淋巴/直接蔓延 | — | 肝毗邻器官感染（胃十二指肠穿孔、膈下脓肿） |
| 开放性肝损伤 | — | 细菌直接经伤口侵入 |
| 隐源性 | 26.9% | 原因不明 |

致病菌：肺炎克雷伯菌、大肠埃希菌、厌氧链球菌、葡萄球菌等。

#### 病理

- 单发脓肿可很大；多发脓肿直径数毫米至数厘米，数个可融合成大脓肿
- 右叶脓肿可穿破形成膈下脓肿或穿入右胸腔
- 左叶脓肿偶可穿入心包
- 穿破入腹腔→急性腹膜炎
- 少数穿破血管和胆管壁→胆道大出血（上消化道出血）

![[04 Attachments/外科-肝脏-细菌性肝脓肿病因.webp]]

#### 临床表现

**典型症状：寒战、高热、肝区疼痛和肝大。**
- 体温高达 39～40℃，寒热往来，反复发作
- 肝区钝痛/胀痛（持续性），可伴**右肩牵涉痛**
- 乏力、纳差、恶心、呕吐
- 腹胀、腹泻、顽固性呃逆（膈神经受刺激）
- 肝区压痛、叩痛，肝肿大
- 右上腹肌紧张和局部触痛（前下缘表浅脓肿）
- 右季肋饱满、局限性隆起、局部皮肤红肿（巨大脓肿）
- **黄疸**→病情危重信号

#### 辅助检查

| 检查 | 表现 |
|------|------|
| 血常规 | WBC↑、中性粒细胞百分比↑ ↑ |
| 生化 | ALT↑、ALP↑、CRP↑、ESR↑；慢性者贫血、低蛋白血症 |
| **超声** | **首选**，阳性诊断率 >96%，明确部位和大小 |
| CT | 更易显示多发小脓肿 |
| MRI | 怀疑胆道疾病时帮助较大 |
| X线 | 右叶脓肿→右膈肌升高、肝影增大、反应性胸膜炎/胸腔积液 |

#### 诊断与鉴别诊断

根据病史、临床表现、实验室和超声检查即可诊断。必要时超声引导下诊断性穿刺。

**细菌性肝脓肿 vs 阿米巴肝脓肿**：

| 鉴别要点 | 细菌性肝脓肿 | 阿米巴肝脓肿 |
|----------|:-----------:|:-----------:|
| 年龄 | >50 岁 | 20～40 岁 |
| 男女比例 | 1.5∶1 | >10∶1 |
| 病史 | 胆道感染/化脓性疾病、糖尿病 | 阿米巴痢疾后 |
| 起病 | 急骤，全身中毒症状重 | 缓慢，病程长，不规则发热、盗汗 |
| 黄疸 | 部分可有 | 少见 |
| WBC | 明显增高 | 可增高 |
| 血培养 | 可阳性 | 阴性 |
| 阿米巴抗体 | — | 阳性 |
| 脓液 | 黄白色，涂片培养可发现细菌 | 棕褐色、无臭，可找到阿米巴滋养体 |
| 抗阿米巴治疗 | 无效 | 有效 |
| 脓肿 | 较小，常多发 | 较大，多单发，多见于右叶 |

#### 治疗

- **全身支持**：营养、纠正水和电解质紊乱、纠正贫血和低蛋白，增强免疫力
- **抗生素**：未确定病原菌→经验性广谱（三代头孢+甲硝唑，或氨苄西林+氨基糖苷类+甲硝唑）；获药敏后调整；大剂量、足疗程
- **经皮肝穿刺脓肿置管引流术**：直径 3～5cm 单个已液化脓肿，B 超/CT 引导下穿刺抽脓+置管；多数可经抗生素+穿刺引流治愈
- **手术治疗**适应证：
  - 脓肿较大、分隔较多
  - 已穿破入胸腔或腹腔
  - 胆源性肝脓肿
  - 慢性肝脓肿
- 手术方式：腹腔镜脓肿切开引流（首选）；慢性肝脓肿→肝叶切除
- 注意事项：穿破入胸腔者同时引流胸腔；胆道感染者同时引流胆道；血源性者积极治疗原发灶

#### 并发症

![[04 Attachments/外科-肝脏-肝脓肿并发症.webp]]

膈下脓肿、脓胸、支气管胸膜瘘、支气管胆瘘、心包积脓、腹膜炎、胆道出血。

### 阿米巴肝脓肿

- 多源于肠道阿米巴感染，绝大多数单发
- 治疗以非手术为主：抗阿米巴药物（甲硝唑、氯喹、依米丁）+ 反复穿刺吸脓 + 支持治疗
- 经皮肝穿刺置管引流术：病情重、脓肿大有穿破危险或穿刺吸脓后脓腔未缩小
- 手术切开引流适应证：抗阿米巴+穿刺引流仍高热不退；继发细菌感染不能控制；已穿破入胸腹腔

## 原发性肝癌

### 肝细胞癌（HCC）

肝细胞癌占肝原发恶性肿瘤的 **90%**。中国是肝癌高发国家，新发病例数占全球约 45%，死亡数约占 47%。HBV 感染是主要病因，患者多为中晚期，5 年生存率仅约 14%。

#### 病因

| 因素 | 说明 |
|------|------|
| **肝硬化** | 硬化形成过程中的反复肝细胞增生（最主要背景） |
| **病毒性肝炎** | HBV（中国主要）、HCV（日本）、HDV（俄罗斯）、HBV+HCV（南欧） |
| **黄曲霉毒素** | 最强致肝癌剂，污染谷物 |
| 其他 | 寄生虫（华支睾吸虫）、水土因素、化学致癌物 |

#### 三级预防

| 级别 | 对象 | 措施 |
|------|------|------|
| 一级预防 | 普通人群 | 改水、防霉、防肝炎（疫苗接种） |
| 二级预防 | 高危人群 | AFP+B 超筛查，每 6 月一次 |
| 三级预防 | 患病人群 | 综合治疗（手术、介入、靶免），预防复发转移 |

**高危人群**：
1. HBV 和/或 HCV 感染者
2. 过度饮酒者
3. 肝脂肪变性或代谢功能障碍相关性肝病
4. 黄曲霉毒素 B1 暴露者
5. 各种原因肝硬化者
6. 肝癌家族史者（尤其年龄 >40 岁男性）

#### 病理分型

**大体形态**：

| 类型 | 特征 |
|------|------|
| 巨块型 | 直径 >5cm |
| 结节型 | 直径 ≤5cm，单个或多个 |
| 弥漫型 | 结节小，弥漫分布 |

**按大小（中华医学会肝脏外科学组）**：

| 分类 | 直径 |
|------|------|
| 微小肝癌 | ≤1cm |
| 小肝癌 | >1cm，≤5cm |
| 大肝癌 | >5cm，≤10cm |
| 巨大肝癌 | >10cm |

![[04 Attachments/外科-肝脏-原发性肝癌病理分型.webp]]

**转移途径**：

| 途径 | 说明 |
|------|------|
| **门静脉肝内播散** | 最常见；癌栓阻塞门静脉主干→门静脉高压 |
| 血行肝外转移 | 肺（最多见）→ 骨 → 脑 |
| 淋巴转移 | 肝门淋巴结→胰周、腹膜后、主动脉旁、锁骨上淋巴结 |
| 直接侵犯 | 膈肌、胃、横结肠 |
| 腹腔种植 | — |

#### 临床表现

早期缺乏典型表现，出现症状多已中晚期。

| 类型 | 表现 |
|------|------|
| **肝区疼痛** | 中晚期最常见的首发症状 |
| 消化道 | 纳差、恶心呕吐、腹胀腹泻（无特异性） |
| 全身 | 消瘦、乏力、低热→恶液质 |
| **类癌综合征** | 低血糖（最常见）、红细胞增多症、**高钙血症**（最严重）、男性乳房发育、高胆固醇血症 |
| 体征 | 肝大、黄疸、腹水、肝硬化表现（肝掌、蜘蛛痣、腹壁静脉曲张） |
| 其他器官转移 | 肺、骨、脑转移相应症状 |

#### 并发症和转归

- 肝癌结节破裂出血
- 门脉高压、上消化道出血
- 肝功能衰竭、恶液质
- 感染

#### 诊断

**定性诊断 — AFP**：
- AFP≥**400**ng/ml，持续 4 周
- AFP≥**200**ng/ml，持续 2 月（排除妊娠、活动性肝病、生殖腺胚胎源性肿瘤）
- 准确率 >98%，但约 **30% 假阴性** → 检测 AFP 异质体
- 肝功能相关酶可升高但缺乏特异性

**定位诊断**：

| 检查 | 特征表现 |
|------|----------|
| 超声 | 首选筛查手段 |
| **增强 CT** | **"快进快出"**：动脉期强化→门脉期/延迟期廓清 |
| **增强 MRI** | 同 CT，"快进快出" |
| 肝动脉造影 | 可同时行 TACE 进行诊断性治疗 |

**临床诊断标准**：
- (1) 肝癌高危人群 + (2) CT/MRI 特征性改变：
  - ≥2cm：一项检查符合 → 可诊断
  - <2cm：两项检查符合 → 可诊断
- (1) + (2b/<2cm 一项符合) + (3) AFP 阳性 → 可诊断

超声引导下肝穿刺活检有确诊意义，但存在假阴性和针道出血/播散风险。

#### 鉴别诊断

- 转移性肝癌（AFP 不高，原发肿瘤病史，"牛眼征"、多发）
- 肝硬化结节
- 肝血管瘤、肝腺瘤等良性肿瘤
- 肝脓肿、肝包虫病
- 肝毗邻器官肿瘤（右肾、结肠肝曲、胃、胰腺等）

![[04 Attachments/外科-肝脏-肝癌鉴别诊断.webp]]

#### 治疗

以**手术切除为主的综合治疗**。

##### 肝切除（首选最有效方法）

**手术适应证**：
- 一般情况下较好，无明显心、肺、肾等重要脏器器质性病变
- 肝功能 **Child-Pugh A 级**；B 级经短期护肝治疗恢复至 A 级
- 肝储备功能良好（ICG 检测正常）
- 根治性切除条件：单发肿瘤，残肝体积≥全肝 50%；多发肿瘤局限在同侧半肝；无肝内多发转移及肝外转移

**根治性切除判断标准**：

| 时机 | 标准 |
|------|------|
| 术中 | 无大血管/胆管侵犯；无邻近器官侵犯及肝门/远处转移；切缘距肿瘤边界 >1.0cm（或 <1.0cm 但断面组织学阴性） |
| 术后 | 术后 2 个月影像学无肿瘤病灶；术前 AFP 升高者术后 2 个月内 AFP 降至正常 |

**术后 5 年生存率**：

| 类型 | 5 年生存率 |
|------|----------|
| 整体肝癌 | 30%～40% |
| 微小肝癌（≤2cm） | **90%** |
| 小肝癌（2～5cm） | **75%** |

影响手术效果的主要因素：肿瘤数目、血管侵犯、肿瘤分化程度和生物学特性。

##### 其他外科治疗

| 方法 | 适应证 |
|------|--------|
| **肝移植** | 肝功能 C 级或长期 B 级；肿瘤直径 ≤5cm，数目 <3 个；无血管侵犯及远处转移 |
| **消融治疗**（射频/微波/冷冻/化学） | 瘤体较小不能/不宜手术，或术后早期复发 |
| **介入治疗**（TACE/HAIC） | 不可切除肝癌的姑息治疗；可使肿瘤缩小、延长生存 |

##### 系统治疗

- **靶向治疗**：抗 VEGF 单抗、小分子 TKI
- **免疫治疗**：PD-L1/PD-1 单抗、CTLA-4 单抗；常用双免疫联合或免疫+靶向联合方案
- **放射治疗**：局限性不宜手术或术后复发
- **中医药**：槐耳颗粒可减少术后复发
- **抗病毒治疗**：HBV/HCV 相关肝癌

![[04 Attachments/外科-肝脏-肝癌治疗.webp]]
![[04 Attachments/外科-肝脏-肝癌系统治疗.webp]]

##### 并发症处理

- 癌肿破裂出血：小者可自行止血；大出血→急诊 TAE/TACE，或急诊肝切除，病情危急→纱布填塞止血
- 合并门静脉癌栓者常发生消化道出血

### 肝内胆管癌（ICC）

- 源于肝内胆管上皮细胞，多为腺癌，占原发肝恶性肿瘤约 10%
- 与 **HCV、HIV、肝硬化、糖尿病**相关
- **AFP 不高**，**CA19-9、CEA 可升高**
- CT/MRI 特征：**"慢进慢出"，无包膜**，肿块周围胆管可能扩张
- 沿胆道浸润生长，确诊时常已有肝内转移、淋巴结转移
- **手术是唯一治愈机会**，术后 5 年生存率 <50%
- 预后不良因素：肝内转移、淋巴结转移、血管侵犯、切缘阳性

![[04 Attachments/外科-肝脏-肝内胆管癌特点.webp]]

## 转移性肝癌

肝是**最常见的血行转移器官**。原发肿瘤以结直肠癌（57%）、胃癌、胰腺癌最常见。

**转移途径**：

| 途径 | 来源 |
|------|------|
| 经门静脉 | 消化道及盆腔肿瘤 |
| 经肝动脉 | 肺癌、乳腺癌、肾癌 |
| 经淋巴管 | 胆囊癌等 |
| 直接蔓延 | 胃癌、胆囊癌等 |

**分型**：早发型（先发现肝转移再找原发灶）、同步型（同时发现）、迟发型（原发癌术后数月/数年）。

**特点**：
- AFP 不高，与原发肿瘤相关的标志物升高（CEA、CA19-9、CA125）
- 影像学：**[[牛眼征]]**、多发
- 单发最有效治疗为肝切除；多发是否切除存在争议
- 不可切除者：区域灌注化疗、消融、放射、化疗、免疫+靶向
- 切除后 5 年生存率 25%～46%

## 肝脏良性肿瘤

### 肝海绵状血管瘤

- **最常见的肝良性肿瘤**，中年女性多见（与雌激素相关）
- 生长缓慢，小者无症状；大者上腹不适、腹胀、嗳气、腹痛
- 体检：肿块与肝相连，表面光滑，质软，有囊性感和压缩感
- 无症状小血管瘤→不需治疗，每 6～12 月超声随访
- **手术指征**：临床症状明显影响生活；肿瘤直径 **>10cm**（尤其位于肝缘有破裂风险）
- 手术方式：沿包膜外分离完整切除，尽量保留正常肝组织
- 最危险并发症：肿瘤破裂大出血（极少发生）

### 肝腺瘤

- 年轻女性多见（**口服避孕药相关**）
- 有恶变和破裂出血风险，应手术切除

### 其他

血管内皮瘤、胆管囊腺瘤、脂肪瘤、神经纤维瘤等均少见，有效治疗为手术切除。

![[04 Attachments/外科-肝脏-肝脏良性肿瘤.webp]]

## 肝囊肿

- 以**先天性肝囊肿**多见，分单发性和多发性
- 单发性：20～50 岁多见，男女比 1∶4，肝右叶居多
- 多发性：40～60 岁女性多见，囊肿大小不等，可分布全肝或局限
- 囊壁内层上皮可为柱状、立方形、扁平或缺如；囊液澄清透明，多不含胆汁
- 生长缓慢，小囊肿常无症状；囊内出血或增大压迫→餐后饱胀、恶心、呕吐、右上腹隐痛

**检查**：
- **超声**：首选方法
- CT/MRI：明确大小、部位、形态和数目
- 多发性者应检查肾、肺、胰等其他脏器有无囊肿（多囊病）
- 注意与 **Caroli 病**（先天性肝内胆管扩张症）鉴别

**治疗**：
- 无症状→不需处理
- 巨大有症状→超声引导下穿刺引流或腹腔镜囊肿"**开窗术**"/"**去顶术**"（切除部分囊壁，使囊腔开放）
- 并发感染/囊内出血→穿刺引流或"开窗术"后放置引流
- 囊液含胆汁→手术缝合胆管漏口，必要时肝切除
- 多发性→仅处理有症状的大囊肿；病变局限可行肝段/肝叶切除

## 肝棘球蚴病（肝包虫病）

- 棘球绦虫蚴感染的人畜共患病，犬为最常见终宿主，羊为常见中间宿主
- 肝占 75%（最常见），主要流行于西部畜牧地区
- 病理：包虫囊肿分内囊（生发层+角质层）和外囊（宿主纤维组织），在肝内膨胀性生长
- 无并发症时常无症状；囊肿破裂可致严重过敏反应、腹腔多发种植、胆道梗阻；压迫可致黄疸或巴德-吉亚利综合征
- **超声首选**，可判断发育阶段和分型；Casoni 皮内试验阳性率 90%～95%
- 治疗：**外囊完整剥（切）除术**为首选根治性术式；内囊摘除术（经典术式，注意灭活头节）；肝切除术；药物为阿苯达唑
